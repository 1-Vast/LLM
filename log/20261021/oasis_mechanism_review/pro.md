# OASIS 独立机制提案：先区分改生物模型与改测量程序

2026-10-21（Asia/Shanghai）。独立支持方。本文不使用任何封存的OASIS MT/LDH数值、形态特征或图像；只读 `oasis_source_qualification/REPORT.md` 与 `PROTOCOL.md`、公开论文和方法资料。未运行模型、程序搜索或科学性能计算，未调用DeepSeek，未下载新数据payload；只新增本文。当前不是宣布GO，而是确定一个会改变研究方向的可证伪技术缺口。

## 结论

**当前暂无足以启动扩架构的合格新机制。** 新候选收缩为“通过真实干预测量过程，判断研究失败应修复细胞模型还是测量程序，并将有效诊断程序继承”；这与先前支持分子残差传播不同。但OASIS目前只提供固定44h、单PHH混池、固定测量流程，未建立可分辨这两类错误的实验控制。因此只允许G0来源/识别资格，不应先做普通tox classifier再把它命名为世界模型或RSI。

这不是因为通用conditional predictor能表达一切。归纳偏置仍可能带来实用的样本效率。本提案未过的理由更具体：①缺少必要真实行动与裁决观测；②最小控制是成熟assay counter-screen知识，尚无新操作；③“预测后继改进效用并训练改进策略”已有很直接的2026先例，不能据此补足创新性。

## 从真实决策推导的单一机制候选

用途：一个新药族出现形态、MT与LDH不一致时，决定其剂量是否值得继续做肝细胞安全验证，以及下一步应购买什么实验。关键问题不只是预测哪个readout，而是避免把检测系统干扰误学成细胞状态变化，或把真实细胞损伤误判为检测伪影。

候选操作是**对观测过程做可执行干预，再决定更新对象**：

1. 冻结当前细胞状态模型与测量模型，给出两个相互冲突的预测：H_bio是药物改变细胞状态；H_obs是药物直接改变检测反应/光学响应。预测对象包括将来真正可执行的控制实验，不只是已有三种readout的相关性。
2. 研究程序选择一个能够区分假说的控制：同浓度药物、无细胞的试剂blank；或固定量LDH/已知活性标准物的spike-recovery；或能够保持生物材料不变而改变药物接触检测步骤的测量流程。各类控制必须由实际协议认证可行，不能由模拟器编出其数值。
3. 真实控制若证实测量干扰，仅修复测量模型/测量顺序，暂不让该信号更新细胞模型；若排除干扰且独立细胞损伤证据成立，再更新细胞模型。跨新药族继承的是“什么失败特征触发什么鉴别实验、该结果准许修改哪个程序对象”的可执行诊断程序。

与既有分子残差候选的区别：这里的识别信息来自改变实验测量过程的真实do-intervention。它不是把原有支持向量输入一个残差核，也不是替换一个预测子空间。世界模型需明确区分干预→细胞状态与细胞状态→观测；程序负责选择能使两种模型错误分离的实验。

## 最小形式化

设a=(drug,dose,exposure)，b为批次，z为44h真实细胞状态，q为测量流程。最简模型：

    z = T_theta(z0,a),
    y_j = H_j,phi(z,q_j) + I_j,psi(a,q_j) + B_j(b) + epsilon_j.

T描述细胞响应，H描述检测的细胞贡献，I是药物对检测链的直接影响。并不假设三种readout测同一个标量，也不把MT降低直接等于死亡。单44h只支持单步干预响应，不能产生长时间轨迹、恢复动力学或任意时序干预。

实验q_blank令细胞贡献为零；q_spike令被检测物贡献为已知常量k。于是：

    y_blank(a) = I(a,q_blank) + B + epsilon,
    y_spike(a;k) = H(k,q_spike) + I(a,q_spike) + B + epsilon.

控制必须实际测得，且与主实验的试剂、药物浓度及检测步骤具有认证映射。blank只排除加性背景，不能自动排除酶抑制、淬灭等乘性干扰；spike-recovery/稀释或其他适当控制也不能被一列“background”字样替代。

程序p把失败轨迹、当前假说与可用实验映射到下一步(q,a)、更新对象和更新操作：

    p(history) -> (next_experiment, update_target in {T,H/I,none}, update_code).

唯一可争取的技术增量不是写出这张因果图，而是：在同一可选控制菜单、相同先验与历史、相同实验/计算预算下，一个继承的诊断程序更少真实控制就能正确修复失败，并在未来新药族改善未参与优化的安全剂量决策。当前尚无这种结果。

## 为什么现有OASIS不能识别

当前认证仅到：1085标签、8浓度、固定44h、真实MT/LDH字段；独立培养重复、化学去重和形态well配对仍在资格。一个五供体池不等于五个独立背景。

只有固定q时，生物贡献与测量干扰在观测上混淆。对任意a相关函数g(a)，可令新的生物读出增加g(a)、新的干扰项减少g(a)，而所有已测y保持不变。多一个同well形态读出可能增加预测信息，但在没有排除形态检测干扰、cell loss和共同批次前，不能裁决错误应归T还是I。高相关或多输出模型拟合好都无法单独解决这个识别问题。

即使cell count与MT/LDH强关联，也可能只是细胞损失的一般信号。正式开发必须包括count-only、dose-response、count+structure、同监督直接形态→功能、多输出GP，以及同信息条件模型。形态特征去掉cell-count仍不保证去掉其代理；需在count匹配/低细胞损失区域检查，且这只是诊断，不更换主要终点。

published ridge-normalization可能用全体响应。未来必须从raw值与预定control建评价，任何拟合参数仅用开发资料；同plate control本身可作为实验输入，但从预留药物响应拟合归一化绝不可。不要把同well配对当独立实验复现。

## 与强方法的实质比较，而非表达包容性

| 对照 | 如果它匹配候选，解释是什么 |
|---|---|
| 同输入/同监督的形态+count+结构直接模型、多输出GP | 仅是多模态预测，世界模型或程序无独立贡献 |
| 固定counter-screen SOP，包括blank/spike与细胞独立确认 | 正常实验室流程已解决错误；不需要学习诊断程序 |
| 同行动菜单的Bayesian model discrimination / value-of-information | 是既有主动假说鉴别；不是新的Agent机制 |
| 普通T/H分模块refit与continual learning | 增量来自正确纳入控制或常规重训练 |
| 同程序指令集、同历史、同k次评价的CV/BO/random/程序搜索 | 程序继承的优势是普通结构/策略选择可解释的，或不存在 |
| 仅检索旧失败案例与distillation | 历史内容/缓存足够，无需递归改进策略 |

这些对照可以包含相同因果分解和控制知识；不能把它们只给Agent再宣称获胜。足够大的conditional NN能表示候选不是判败理由；这里判败的是具体同监督、有相同实验操作和先验的强对照在真实预算中是否匹配。

现阶段没有一个我能辩护为前述对照不已有的独有操作。若以后贡献是诊断/程序搜索效率，必须把它作为具体算法结果证明；若只是把成熟counter-screen封装成代码，则贡献是工程流程，不能当核心科研创新。

## 最小会改变研究方向的资格实验

先不训练世界模型或进化程序。先问来源是否包含**同药同浓度的测量过程控制**和独立生物损伤确认。若公开资源没有q_blank/q_spike或等价行动，当前回放对本候选为NOT_TESTABLE；应寻求有这些真实控制的来源，而不是用OASIS数值相关性代替。

若以后具备真实控制，先开发资格三个预注册问题：

1. 是否有重复可重现、足以改变安全剂量决策的assay误差，而不是低于噪声的discordance？同一单位在独立培养/检测批次验证，不能将8剂量当8独立药。
2. 在知道药物结构、浓度、count与现有readout后，控制实验是否确实区分“改T”与“改H/I”，并在未用于诊断的实际功能验证上纠错？仅预测控制值不够。
3. 与全部同知识固定SOP及Bayesian model discrimination相比，是否存在可检验的额外测量效率？若固定SOP已在可接受成本解决全部机会，则停止学习诊断程序。

正式决策可以是固定药物菜单下最大可继续验证浓度/需否追加独立肝毒性确认，但阈值、cost与终点必须先由实验用途冻结。不可依据结果挑“安全”定义。OASIS只有acute in-vitro surrogate，不能推出临床DILI、安全处方或治疗窗。

全部控制测量、未确认候选和后续确认计费。实际价格未知时只作明确query-unit情境，不承诺货币节约。δ_use要由开发重复方差、控制和最终确认成本预先定义；当前不能借用别的任务margin。头部常规方法耗尽可达机会、假说不可区分或预留精度不够时停止，不增加模块救结果。

## 继承与RSI：需要什么，而当前没有什么

先把源药族上有效诊断程序冻结，移植到共同新药族任务：相同T/H初始模型、相同历史、相同支持实验预算，继承p与重启/检索/distilled固定SOP对比，评价更后真实控制和功能确认。只更新模型参数不是程序继承。

更进一步的meta效率必须从完全相同起点p0/T0/H0分叉，冻结旧、新meta改进策略，各给k次修改/实验评价，比较未参与优化药族上的净改进；前期学meta的成本也计入。不能以新meta带着更强p或更多历史取胜。单PHH池最多是药族迁移开发；不能报告供体/细胞背景RSI确认。

## 支持方最终建议

保留**错误来源可由真实实验区分、然后改测量/模型程序**这一个技术缺口作为后续数据资格标准；它对真正科研智能体比再增加tox预测模块更有意义。当前不建议实现这个框架：OASIS尚无必要行动，成熟固定SOP/主动鉴别足以成为强解释，最新SpecRSI又覆盖meta预测框架。若新来源不能提供会区分更新对象的真实控制，就诚实记录暂无合格候选并继续寻找可识别研究单位，不将总目标收缩成普通毒性分类。
