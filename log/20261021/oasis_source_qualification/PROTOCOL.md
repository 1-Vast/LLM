# OASIS blind schema and action-coverage qualification

Frozen before any new outcome payload retrieval: 2026-10-21. This is a **new safety-dose task qualification**, not a change to any existing PTV/DMG endpoint or negative conclusion. No fitting, model selection, numerical outcome optimisation, API or GPU work is authorised in this block.

## Exposure boundary and scientific question

Prior exposure: published aggregate OASIS findings, official preparation code, S3 object names/sizes and Zenodo catalogue were read in `log/20261021/rsi_next_qualification/agents/liver_metadata_followup.md`. No OASIS individual LDH/MT values or CellPainting features have been read by the research agents. The source is one five-donor PHH pool, not five independent backgrounds.

Question: are there authenticated public functional measurements for 1085 compounds, eight concentrations and two technical replicates, with exact plate/well keys linking to CellPainting objects? Completeness is not assumed from the publication or filenames. This audit can establish source schema, missingness, identity and action coverage only. It cannot establish signal, usefulness, mechanism, prediction performance, generalisation or RSI.

Network response-body budget: **10,000,000 bytes**, with a persisted ledger and no 864.8 MB bundle download. Wall-time bound: **10 minutes**. No images or CellPainting feature payloads are downloaded. Source metadata listing/HEAD/Parquet footer requests count in the ledger; raw outcome files are stored only under `sealed_source/` in this log package.

## Permitted outputs and subprocess boundary

All source data inspection occurs in a separate audit process. Permitted outputs: URLs/file version/hash/size, schema, row count, explicit compound/dose/plate/well/source/replicate identifiers, missing counts and action-coverage counts. Compound identities in the public audit output are stable hashes; no selected compound list is produced. Source compound labels remain available only in sealed files for a future independently declared chemical split.

No LDH/MTT values, extrema, quantiles, histograms, correlations, pharmacological scores or chosen drug names may be printed or written in the audit output. The child may compute only null/non-null counts for designated functional columns. CellPainting features may not be read; only catalogue/manifest keys or footer schemas may be inspected.

`metadata.parquet` is treated as potentially containing outcomes. The child reads only explicit white-listed identifier/concentration columns from it. For functional `biochem.parquet`, output is restricted to the white-listed identifiers and null counts for named functional columns. Neither filename implies an unexposed metadata status.

## Qualification and stop rules

- Qualify a complete menu only if compound-level counts prove the announced 1085 × 8 × 2 structure after controls, with duplicate and missing-value checks, and exact measured keys link to public CellPainting source objects.
- Distinguish two observations from two independently identified replicate plates. If replicate identity is not explicit, report it unknown rather than infer it from a count of two.
- Attribute raw and normalised endpoints separately. A column generated by filling nulls or normalisation does not prove an authentic raw functional read.
- Stop on budget/time, missing/ambiguous compound or concentration identifiers, absent measurements, unsupported endpoint schema, absent assay linkage or inability to establish identity without opening excluded features. Partial coverage is a finding, never imputed to complete.
- Preserve all source hashes and unoptimised outcome status. No future split or numerical task may treat this audit as a performance result.
