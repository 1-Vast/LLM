## Chemical reservation (one declared rule, no seed search)

Input is the identity worker's STRUCTURE_MANIFEST.json; no response columns.
Retain all 1085 labels in the output. Missing/conflicting source structures are
quarantined, never assigned by chemical name guesses or functional behaviour.
At present the worker reports 960 known, 119 absent and six conflicting; the
builder must derive actual counts from the pinned manifest rather than assume.

For known source structures, use RDKit Cleanup, FragmentParent and Uncharger,
remove stereochemistry, then canonical SMILES. This standardisation is ONLY a
conservative grouping device, not a change to the physical drug, salt, dose or
functional measurement. Preserve original structure/salt provenance. Failed
standardisation is quarantined. No name-based chemical resolver is used.

Group labels by connected components of any of these pre-outcome relations:
same standard parent; same nonempty Bemis-Murcko scaffold; Morgan radius-2,
2048-bit Tanimoto >=0.70. This prevents parent, scaffold and close-analogue
overlap across roles. Empty-scaffold molecules use the identity/similarity
relations, not one universal empty-string group. Report cross-role maximum
similarity and actual group/label allocation; do not equate this with all
possible biological drug-family separation.

Group token is SHA256 of sorted distinct canonical parent strings; role is
SHA256("oasis_reservation_20261021_v1|"+group token), first 64 bits converted
to [0,1): dev <.60, selection [.60,.80), reserve >=.80. All doses, repeats,
aliases, counted cells and morphological/functional records inherit the same
compound role. Changing seed/salt/threshold to improve counts is prohibited.
If a giant connected component or insufficient independent groups prevents a
useful test, record this limitation; do not reroll. No independent claim until
the actual allocation and power are qualified.

Persist input/code/protocol/RDKit versions and exact mapping before opening
numerical development data. Rerun may only verify an identical reservation,
not replace an incompatible existing mapping. Reserve outcomes and target
morphology stay in the evaluator. Unknown structure rows remain traceable.
