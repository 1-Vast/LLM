# 候选机制交叉辩论：反方记录

2026-10-22，Asia/Shanghai。仅 OASIS 人肝细胞与一般数学。对话双方为 historical_skeptic 与 novelty_advocate，形成意见时未读 OASIS 原始结果。代理一致不是实验事实。

反方要求支持方给出最小反例：同一控制菜单和先验下，候选哪一个独有操作优于固定 counter-screen SOP、Bayesian model discrimination 或等预算程序搜索？支持方明确回复当前找不到这样的独有操作，因此不支持先实现 Agent。双方保留的最强窄主张仅是“同信息、同控制、同预算下，更少控制改善未来新药族功能决策”；这尚待真实数据验证。

双方同意不能从 blank/spike 正常推出主测量没有干扰。支持方给出的反例：状态含细胞存在 c 与损伤 d，主读出 y=d+I。世界 A 中 d=a*c、I=0；世界 B 中 d=0、I=a*c。主实验 c=1 时两者都为 y=a；无细胞 blank c=0 时均为 0，加入固定标准物 k 的无细胞 spike 均为 k。所有这些观测相同，却具有不同错误来源。控制到主测量的 matrix/浓度/接触顺序 transport 必须认证；控制名称不提供排除限制。

反方追加：损伤和干扰可同时存在，强制“只改 T 或只改 H/I”会把混合机制误标，程序至少须允许 both/abstain。即使控制完美识别更新对象，普通模块 refit 与主动鉴别也能正确路由；正确路由本身不是世界模型或 Agent 必要性的证明。

明确可反证条件为：控制 transport 失败则 NOT_IDENTIFIED；固定 SOP/同信息条件模型/普通主动鉴别在同预算匹配则无新增机制证据；独立后续功能收益的上界低于预冻实用差则无有用增益。OASIS 目前没有认证的过程干预菜单，故本机制 NOT_TESTABLE_ON_CURRENT_ACTION_MENU。

双方支持最小 dev raw MT/LDH+count 可靠性门，但强调它仅检查技术可靠性和已付费观测信息。count 不等完整形态上界；未通过 count 或 rank 门不能否定所有形态。共同 test-plate DMSO 可以是声明的 assay 输入，test-compound 响应不能用于拟合预处理。

尚未解决的科学分歧不是候选已优于常规方法，而是：若将来有可迁移的真实过程控制，因果分解是否会产生足够大的样本效率收益，以及这种收益能否超越普通模块拟合/主动鉴别。需要新的可识别数据单元，不能靠程序命名裁决。

G0 后的尾部 pilot 优先级另见 log/20261022/oasis_dev_g0/POST_RESULT_SKEPTIC.md：反方认为廉价 dev 技术描述可以先于外部裁决，但它不支持重开框架；支持方更倾向先认证独立裁决。根代理最终决定本轮不执行该 pilot，双方保留分歧。
