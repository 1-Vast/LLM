## 最简数学定义：一个候选，先不加搜索

行动为 a=(drug identity, concentration, exposure duration, context/stock)。细胞背景为c，基线输入x_c，真实分子观测m_cs、功能终点y_ct。支持行动集合S可购买分子测量，目标行动集合T没有被购买任何分子或功能观测，S与T的药物及事先固定药族不交。

冻结源世界模型预测分子状态 μθ(c,a) 和功能分数 fθ(c,a)。支持创新为：

    r_s = m_cs − μθ(c,a_s).

这里innovation只是模型预测残差，尚不意味着生物因果误差。必要对照用m_cs−baseline、m_cs−matched vehicle、以及直接观测m_cs，排除减去一个模型仅是多余重参数化。

选一个源数据上固定的低维扰动子空间P；δ表示当前任务中P坐标的共享偏差。模型给出每个支持药的分子灵敏度J_s和每个目标药的功能灵敏度g_t。最小线性化：

    r_s = J_s δ + ε_s,
    y_ct = fθ(c,a_t) + g_tᵀ δ + η_t,
    δ_hat = (λI + Σ_s J_sᵀ Σ_s_noise⁻¹ J_s)⁻¹
            Σ_s J_sᵀ Σ_s_noise⁻¹ r_s,
    y_hat_ct = fθ(c,a_t) + g_tᵀ δ_hat.

只改变一个东西：从支持药实测创新估计共享偏差，更新目标药排序。不加LLM、不加主动选择、不加档案、不加新潜态模块。λ、P、所有归一化、J/g的构造均由训练源与开发选择固定。P可由一个小线性状态模型的机制参数扰动产生，先不引入神经ODE或大模型。

**关键承认。** 这等价于一个依赖S的跨输出核：

    K_tS = g_tᵀ(λI + J_Sᵀ Σ_noise⁻¹ J_S)⁻¹J_Sᵀ Σ_noise⁻¹,
    y_hat_ct = fθ(c,a_t) + K_tS r_S.

它是条件Gaussian推断、低秩残差kernel和局部系统辨识。通用conditional support encoder也能表达它。故线性公式本身没有独有算法新颖性，不能用“真实分子创新”命名掩盖这一点。仅把固定P持续拟合或调整λ，属于普通重训练/持续学习。

## 支持方能主张的唯一潜在实质增量

最窄可争取的增量是**在相同历史、表示容量、候选规则族和测量预算下，更少真实观测就能发现一个可转移的支持→目标纠错关系，并在未来药族/背景继续有效**。这是归纳偏置/测量效率命题，不是表达能力超越通用conditional predictor，也不是已成立的生物机制。

为什么保留这个问题：直接端点分数对一个支持药正确/错误，并不告诉我们目标药该怎样变；一个有效的状态扰动模型可能借助药物目标、剂量和时间的约束，预先固定跨干预误差传播方向，因此稀疏反馈更有效。最强反面解释是目标/剂量特征加条件预测器已得到同样归纳偏置。必须在相同信息下实际比较，不能假设前者更有效。

若进一步声称“规则改进并继承”，唯一新增对象应是P或其诱导K的结构，而非权重、一般背景embedding或实例存储：真实跨药纠错失败后，候选P'改变哪些分子偏差允许传播到哪些目标药。**但P→P'仍是feature/kernel/structure selection。** 把同候选族交给无Agent的CV、BO或随机搜索，给同一历史和k次评价，若同样选出P'且匹配后续收益，就没有Agent/RSI独有增量。

因此“唯一可能超出”的含义只能是受限资源下找到有效规则的可复现效率优势；目前没有独有操作或证据说明这种优势存在。若需要把额外机制知识只给Agent才能赢，就是信息不公平。支持方接受当前新颖性NO-GO；不批准结构搜索来制造正结果。

## 可识别签名与最小反例

共享误差假说必须预报*符号和对象*，而非事后说“残差有信息”：在源资料上先固定某支持药残差经K传到某目标药的纠错方向。随后在独立批次/培养重复中评价未测目标真实功能残差。

- 支持预报：r_S相近且drug/dose/context已记录时，目标药残差按K预报同向变化；该关系在药族留出和真实独立重复保持，收益落在未测T而非已确认S。
- 反例：旧K预测同路径目标药同向，真实独立重复却稳定反向；若反向由事先记录dose或context可复现，这是可研究的K失配；若仅个别药或plate效应，不能据此宣称共享生物差错。
- 批次鉴别：同一支持和目标在不同随机plate批次重复；加入matched vehicle、plate/batch项和全局应激/细胞死亡读出。批次回归或全局细胞偏移匹配候选，则不支持跨干预机制。没有这类重复/批次标识的公开数据最多给预测增量，不能给误差原因识别。
- 生物因果加强需额外干预，例如同药在目标失活/耐药等位株中的变化；这不由当前两个DMG背景自动满足。不得用通路富集、target annotation或模型自身模拟当实验裁决。

按K和实际预测去重结构：P旋转/缩放、潜坐标重命名或形式不同但诱导同K的程序均是同一能力。仅代码hash或参数数目变动不能算结构创新。

## 一次最低成本资格，如何判败

先只资格一个窄用途：在固定且已公开的两个DMG培养背景内，给少量支持药24h RNA读出，改善未见药族的固定条件48h功能排序。独立药族可给未见药物开发证据；两个背景不能估计跨背景一般规律。

**数据先决。** 先查公开表是否实际包含完整、可比的数值功能菜单和精确drug/dose/time/stock身份；只有EC20选剂量或selected follow-up则不满足全菜单replay。不能因372药RNA表齐全就启动功能实验。开发与预留按药族固定，留出结果由独立评价器持有；文章aggregate已见，诚实标来源暴露。

**资格顺序。**

1. 相同药物条件真实分子测量→功能，只做信息上界；若无同数据强直接模型之上的实用信息，停止。即便上界正，也不构成支持药→目标药的传播。
2. 固定支持药集，测试上式与同信息直接support encoder、多任务ridge、低秩残差kernel、普通同反馈refit的配对真实目标决策。另有support残差置换、仅全局偏移、直接m而非innovation控制。分子模型MSE不是决策成功指标。
3. 仅在2通过后再比较候选探针与最强固定/主动学习策略，扣除全部分子测量及最终功能确认成本。不得跳过2直接搜agent。

**门槛。** 新资产的菜单、噪声、cost和决策单位尚未资格，不能偷搬PTV的0.40 hits门槛或事后凭结果选margin。先用开发方差和可执行的测量/最终确认合同定义δ_use，例如至少节省一个功能确认等价测量，或每固定B个测量多确认一个有效候选；再锁一个主要终点、检验单位与margin。若最强常规臂的剩余可达机会低于δ_use，立即STOP；若差的区间上界低于δ_use，NO_USEFUL_GAIN；宽区间则INCONCLUSIVE，不等于支持。独立单位是药族/培养/实验批次，不是单细胞数。

最强判败基线是**相同S观测和同样source history的条件低秩残差kernel/conditional support encoder**，并用同样drug/dose/context信息；它能匹配上述机制表达，若匹配效用与测量效率，候选没有必须以世界模型出现的理由。

## 继承与RSI需要的额外识别，当前不运行

规则继承先冻结一个有效P'/K'，移植到共同新任务模型和共同起始状态；与旧规则、source实例检索、distillation以及从同历史从头拟合比较。权重、实例量和总历史测量数完全相同。更强初始化不算更新规则更有效。

RSI另取冻结meta策略m1与m0，从完全相同的P0/模型/历史分叉，各给k次候选评估与同真实查询上限；用未来未优化任务的改进量或达到同效用所需评估量比较。必须包含同候选族CV/BO/随机搜索和前期meta训练成本。无效候选率降低本身不足以证明最终药物价值。两个DMG背景不支撑这个跨任务meta试验；不以对药族换顺序制造新的独立细胞世界。

3. 怀疑方要求把P旋转/缩放的伪变化商掉。支持方接受：按诱导K和实际support→target行为去重，源码变化不够。
4. 支持方给出可反驳签名：预报支持与目标残差的方向、药物对象和dose/context条件；独立plate/培养重复若反向则K被反驳。批次或全局应激解释掉则不称共享生物机制。
