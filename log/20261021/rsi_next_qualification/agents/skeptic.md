# 独立怀疑审稿记录：先识别信息增量，再检验 RSI

记录日期 / 一手文献访问日期：2026-10-21（Asia/Shanghai）。角色：独立怀疑审稿人。只读审计，不运行旧试验、不读 `.env`、不打开任何封存结局。本记录是新的研究设计判断，不能改写历史冻结结论。

## 结论

**当前最该检验的反例是：同样的分子监督、真实反馈和预算给一个直接多输出预测器，再做普通更新和简单混合，即可解释拟议系统的全部决策收益。** 该反例若不能排除，再加档案、代码进化或元策略没有科学识别价值。

从公开原始文献看，“世界模型 + 实验规划共同演化”和“改进程序自身改进并跨任务继承”均已有直接先例。可争取的增量必须收缩到一个具体的、可由未参与优化的真实观测裁决的机制：**在未见干预或细胞背景上，有限真实分子观测识别出可迁移的模型错误，并使后续实验决策超过相同信息的直接预测 / 普通重训练 / 主动学习；继承的改进策略进一步提高相同起点的后续改进效率。** 这是待证命题，尚无本项目正证据支持。

## 三篇直接相关一手文献与新颖性反证

以下均只按作者原始论文所报告内容解释；不把作者结论当作独立复现。此处是针对关键机制的有限检索，并非完整 novelty clearance。

1. **Zhang et al., Hyperagents，arXiv:2603.19461v1，2026-03-19。** 原始链接：[摘要](https://arxiv.org/abs/2603.19461)、[全文](https://arxiv.org/html/2603.19461v1)。访问 2026-10-21，全文可读。论文让任务程序与生成改进的 meta 程序共处可编辑程序中，并报告改进机制跨领域转移和累积；包含固定 meta、无档案、DGM 及手工定制 DGM 对照。**反证作用：**“改进策略本身可被改进”及“跨任务继承元策略”不能作为独立创新。正文保持 parent selection 固定，且任务不是真实药物决策；因而有空间检验在有限生物反馈下的特定、严格隔离的更新机制。父代和任务实例须匹配，而非只比两个不同档案的终点。

2. **Lewis & Zueco, Toward Generative Virtual Cells: Co-Evolving World Models and Perturbation Planners，ICLR 2026 Gen² Workshop。** 原始链接：[OpenReview PDF](https://openreview.net/pdf?id=64iwpu7HO0)；原始 PDF 另有版本路径 [链接](https://openreview.net/pdf/58c616e58a32446ea386695fcf2a9f5caa4f5ab1.pdf)。访问 2026-10-21。OpenReview 原始 PDF 的搜索索引可读到题名、作者、摘要和结论，但直接打开返回浏览器验证；未声称已逐页核验 PDF。作者提出世界模型和扰动规划器共同更新、外层验证/容量门控架构搜索；作者结论明确全部实验为合成五基因系统，仍需真实 Perturb-seq 验证。**反证作用：**双核、内外环、验证门控共同演化并非首创；缺口是真实观测、强直接预测/重训练竞争者与继承/元改进的分别识别。

3. **Miao et al., VCLMU: Mechanism-Centric Virtual Cell World Modeling for Perturbation Response，arXiv:2610.04475v1，2026-10-03。** 原始链接：[摘要](https://arxiv.org/abs/2610.04475)、[全文](https://arxiv.org/html/2610.04475v1)。访问 2026-10-21，全文可读。用可复用机制单元表示细胞潜状态，将遗传扰动建模为单元上的随机转移，并报告六个扰动互斥测试集上的扰动特异响应恢复。**反证作用：**机制潜状态、干预转移和可解释状态单元已有先例。该文的分子响应恢复不是药物功能/实验效用，也不识别反馈、Agent 或 RSI；本项目不能只以新潜状态命名或基因富集作为增量。

## 最小公平试验：阶段门控，避免一次堆满模块

先固定一个用途：**在一个新细胞背景，给定候选药物及精确剂量/时长，以有限支持实验改进尚未测量药物的功能候选排序。** 查询对象、最后功能确认对象分开计数；已查询药物的重复命中不能算传播。若改变用途为药物组合、时序干预或机制鉴别，必须重新建立相应真实观测合同，不能移用单药敏感标签。

### G0：数据和可识别机会；不通过就不训练新系统

- 真实行动包括 drug identity、dose、duration、cell stock/context；明确分子观测和功能观测的匹配层级、批次、culture/subject 依赖、缺失原因和可查询菜单。缺关键条件只能做来源资格研究，不能生成实验室执行条件。
- 同一模型残差在独立生物重复或真实独立批次上的相关性足够，且强基线剩余的**可达**决策改进大于预先定义的最小有用差；噪声 oracle 只能作乐观上限，不能充当可达机会。
- 候选反馈必须能区分至少两个会改变未来决策的更新假说；以开发资料上的后验预测/似然区别量说明，不能只展示模型 disagreement。若假说都是任意 per-drug offset，则问题就是普通在线重拟合。
- 精度和资源预先冻结：按独立生物/干预组的开发方差计算所需 N，不能用细胞数、重复 episode 数替代独立单位。没有足够单位则标估计 pilot，不允许用 bootstrap 窄区间升级结论。

### G1：先判断世界模型的独立贡献

使用同一输入、同一训练分子/功能监督、同一数据切分、调参次数及训练/推理预算。最少包含：

| 对照 | 区分的问题 |
| --- | --- |
| 强直接功能预测器，结构+背景+drug/item prior | 是否仅在弱基线之上获益 |
| 直接多输出 / 多任务预测器，同时监督真实分子响应与功能 | 是否只是多了分子监督 |
| 可直接消费真实支持分子观测的条件预测器 g(context, drug, measured response) | 是否只是分子测量信息，世界模型并非必要 |
| 普通 kernel / ridge 反馈更新、全量同数据重训练、预算匹配的持续学习 | 是否只是增加了标签或重拟合 |
| 固定/调优简单混合，包括 repair1 的 B1+PPODE 型形式 | 是否只是互补误差组合 |
| 真世界模型 / 匹配容量的无转移模型 / 时间或扰动结构打乱的辅助监督对照 | 状态转移结构是否独立有用 |

用固定同一策略先配对评价，再做可查询策略比较；否则 world/strategy 一起变化。世界模型预测出来的分子状态不能作真值；只用未参与优化的真实功能终点裁决。不得用测得 target 的分子响应泄露到声称“无额外测量”的预测臂。

### G2：Agent、继承及交互的最少识别

基本 2×2：`strong direct / world` × `fixed conventional / adaptive program`。所有格子拥有相同允许信息和合法 query，查询费用、延迟及最终确认预算相同。Agent 必须再胜过 A-optimal/uncertainty/exploit-first 中开发选定的最强者及相同候选评估次数、token/计算上限的普通程序搜索；不是只胜 root。

- 世界模型贡献：在固定策略下 world − direct；另以多任务直接预测器隔离转移机制。
- Agent 贡献：同一 world 下 adaptive program − 强普通策略；差异 query 被日志证明真正消费了实时反馈。
- 联合交互：`[U(world, agent)−U(world, conventional)]−[U(direct, agent)−U(direct, conventional)]`，且最终联合臂必须超过最强常规系统。正交互但绝对仍输不算成功。
- 继承：在新任务 B 上比较继承程序与重启；二者获得相同源任务 A 的可见经验、相同总历史成本。另用 retrieval/distillation/固定库基线区分更好的程序与多拿了历史信息。必须把“继承模型权重”和“继承研究程序”分开开关，冻结其中之一再测另一项。
- 内容移植：把冻结继承程序放入共同新模型 / 共同新任务；比较空白、无关/打乱内容和普通检索。不要求每个候选均升格，但若最终代码和权重均相同，不能报告“遗传优势已经检验为零”。

### G3：RSI 元策略的专门因果试验

从源流 A 学出 meta 策略 m* 后冻结。对多个独立目标流 B，从**完全相同的 task agent p0、世界模型 w0、候选空间、历史资料和资源上限**分叉：m*、初始 m0、手工调优固定策略、等预算随机/常规搜索。m* 可以改 task/update program，但不得继续看独立评价流 C。比较在固定预算 b 后对 C 的改进：`U_C(search(m*, p0, b)) − U_C(search(m0, p0, b))`，并报告无效候选率、单位真实查询/单位评估计算的增益。只比较更强起点的最终分数不识别“更会改进”。

若声称递归累积，再用源流 A1 学 m1，A2 学 m2；分别从同一起点在独立 B 上检验 m2 是否比 m1 更有效。一个更长训练流的性能斜率、更多搜索轮次或接受次数不构成 RSI 证据。跨流顺序和 parent/program 随机种子配对；多个独立搜索起点反映程序搜索方差。所有“加速”须纳入形成 m* 的前期成本，区分一次性后续效率和累计回本。

## 开发反复试验与预留评价纪律

1. 旧 PTV-1、Beat AML、PRISM 等已见结果一律标开发；换 hash split、改 drug pool、重叫 final 都不能恢复未见状态。
2. 新数据先由独立 evaluator 固定来源版本、干预/细胞/批次分组及保留 manifest，再开放开发部分。记录外部 checkpoint 的训练数据交集；未知则标预训练泄露风险，不能称全新生物泛化。
3. 开发可反复试验，但每项假说、失败、调参、查询、API 及运行账本进 `log/`。冻结一个主要终点、一个最小有用差、比较族、停止规则和全部模型/程序哈希后才开预留。
4. 预留只开一次，评价器不返回逐项结局给优化器。若出现实现错误可透明修复并称暴露后的回归；修复结果不能重获确认身份。之后新确认需要新未参与优化的观测。
5. 同时留出 perturbation scaffold/family 和 cell context 的任务只能按实际覆盖声称；只有 context 留出不等于未见药物。按干预、背景、culture/source 的依赖聚类；跨训练种子不当作生物重复。

## 停止条件及最有价值的反例

**立即停止扩架构：** 数据不能建立精确行动/匹配终点；分子查询只有合成结果；强普通模型已经耗尽可检测 headroom；更新假说不可被可获得观测区分；同一开发集反复晋级而没有新的保留资源。

**G1 停止 RSI：** 同监督直接多输出模型或简单混合匹配/超过世界模型，且决策效应的上界低于最小有用差。区间宽则“资源范围内不确定”，不以增加模块/更换指标继续宣传。

**G2 停止 Agent 新颖性：** 策略与 root 相同；Agent 胜 root 但不胜普通主动学习/程序搜索；继承收益被 retrieval/distillation 匹配；只有交互而最终输强常规臂；收集到的收益全部来自已确认药物而非未测药物。

**G3 停止 RSI 主张：** 同一 p0/w0 的新流改进效率无提高；收益只来自继承更强权重/更多历史标签；meta 优势不能转移；加入前期 meta 开销后从未累计回本。可以保留普通反馈/混合有效这一较小结论。

优先顺序：①同监督直接预测 + 普通 kernel/重训；②强固定混合；③独立重复中错误修正能否传到未查询药物；④等预算主动学习；⑤冻结 meta 的共同起点后续搜索。前三项未过，暂不投入开放式代码进化。
