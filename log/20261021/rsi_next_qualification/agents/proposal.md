## 历史排除条件

1. Beat AML 的真实漂移可被普通逐药偏移修复；组成、时间、药物族和效价没有解释可转移的决策相关漂移。不能把在线偏移称作自我修复的新机制。
2. O'Neil typed 状态/实验程序、类交互和继承未优于同数据 refit、A-optimal 或 BATCHIE-inspired 对照。普通低秩状态、加一个类坐标、预算重分配都不是新候选。
3. 程序继承审计只验证执行、分支和保存；普通 lookahead/distillation 基本匹配；新 regime 仅在最后批出现，因此并未测试“失败→改进→后续收益”。不能用这项未覆盖替代新真实数据证据。
4. PRISM 的核反馈、typed edits、探针选择、同靶点替换、RSD 校准均有明确限制或停止结论。当前候选不能复刻这些方案而改名字。
5. MIX-Seq 已有历史阴性（`EVIDENCE.md` 的 kinetic-horizon 行）：六药/48 lines 的短时分子测量未优于 DepMap prior；不能当作新且未用的确认资产。
6. PTV repair 的真实闭环有效，但无 API 程序获提升；普通 0.5 PPODE + 0.5 B1 得到 3.714 hits、B1 kernel 3.429、PPODE adaptive 2.714。混合正信号只是暴露开发证据。

## 第一顺位 G0a：混合是否已经解释全部收益？

**用途。** 判断是否值得继续研究“预测分子状态支持药物排序”，而非再次确认一个普通 blend。这个检查的价值主要是廉价排除，无论结果如何都不能单独证明模拟轨迹的因果贡献。

**最小分析。** 在严格相同的训练谱系、模型拟合信息、候选药物池和功能标签上，对 B1、M0、M1、M2 保存逐样本分数。比较每个 Mj 与 B1 的固定 0.5 混合，以及仅在开发谱系上从同一个小网格选择混合权重；全部使用同样的样本和选择预算。至少包含 B1、M0、M1、M2、B1+M0、B1+M1、B1+M2。报告每谱系 top-5 hits、配对差、实际变动的入选药物及错误互补，而不是只报 pooled AUROC。

**不能拼接现有数字。** 原 final 的 14 药池、dev+sel 训练与 repair 的 20 药池、dev 训练不同；将它们的分数/模型按 ID 交集拼接仍改变任务。需要匹配模型和池，或诚实地只对存在完整同配置分数的配置做分析。原 M1/M2 的初始化种子不可靠，同模型单种子比较有额外不确定性。

**归因边界。** `AMENDMENT.md` 明确：M1/M2 同时改变轨迹路径、phenotype head 结构/容量、辅助分子损失。因而 M1+B1 优于 M2+B1 也不能证明“世界模拟”特有价值。肯定性归因至少需要同容量、同分子监督的直接多任务模型：它预测 24h/48h 分子向量和功能，但不进行状态转移/递推；参数量、训练轮次、输入和选择预算匹配。另设 baseline+平均药物变化的简化状态对照，排除复制基线与一般辅助任务正则化。

**停止/继续。**

- 若 B1+M0 或 B1+M2 匹配/超过 B1+M1，且 M1 带来的额外入选不产生正净增益：将本地 blend 信号解释为一般分数多样性，停止据此提出“轨迹促进决策/RSI”的主张。
- 若 M1+ B1 稳定超过这些 blend，只进入等分子监督控制；不直接启动 RSI。
- 若完整等监督直接模型也匹配 M1：停止世界模型特有贡献，保留普通多任务/混合方法。
- 若小样本区间跨越实用门槛：记为 INCONCLUSIVE，不以增加搜索次数改变门槛。建议保持已有同任务门槛 0.40 hits/谱系（仅当确实沿用其五单位任务），开发下界大于零可作工程继续条件，但不足以认定 useful gain。

**最强反对理由。** 它很可能证明一个普通预测器集成已足够；17 谱系和低质量模拟器也不能给出普遍世界模型结论。它仍值得做，因为成本低，且可以防止对正 blend 信号过度解释。

## 第二顺位 G0b：真实分子创新是否具有未测药物决策信息？

**唯一值得保留的最小机制候选。** 用支持药物的真实 24h 分子创新（实测值减去模型预测；对照另用实测值减基线）识别当前细胞背景中的共享响应偏差，再修正 *未查询药物* 的功能排序。候选技术内容是“从分子残差到跨干预功能纠错的可转移映射”，而不是更大的模拟器、一般微调或一个新 planner。先验证信息存在，再设计映射和探针选择。

**两段门槛，避免偷换信息。**

1. **信息上界，开发诊断。** 在训练谱系学习 baseline+fingerprint→功能的直接预测器，再加入真实 24h 分子残差；基线、全部预处理、蛋白选择/PCA 都仅由训练数据拟合。按照药物族和谱系双不交评分。真实 molecular readout 预测同一药的功能，只能说明有用的测量读出，不能说明跨药物传播；该项可用全部真实分子值作为不计费诊断上界，但必须标为不可部署上界。若连这一上界都不能改善实际 top-k 决策，停止后续分子查询机制。
2. **合法跨药验证。** 支持药物 S 才能提供分子观测；目标药物 T 与 S 药物不交，评估谱系不参与训练。每个支持分子测量都计费；所有臂拥有相同历史和同样的合法反馈。用支持创新的低维岭映射/核传播作为最小候选，预测 T 的纠错；先固定探针集。成功后才比较探针策略。目标药的真实分子值、标签及其衍生统计绝不进入支持状态。

**必要对照。** baseline+fingerprint 直接模型；B1；B1/M0+分数混合；同分子监督直接多任务模型；同反馈普通重训练；普通逐药/核残差更新；持续学习；固定和 A-optimal/不确定性主动学习。增加 (i) 支持残差按药物/谱系置换；(ii) 仅全局细胞偏移；(iii) 同容量功能反馈模型。若置换/全局偏移也匹配，不能将收益归因于干预状态信息。

**成本与门槛。** 报告预算 B=5 下确认的不同正药物数，并保留与上一研究可比的 0.40 hits/背景门槛；分子成本 lambda 在预先列明的 {0.1,0.25,0.5,1.0} 下全部报告。主要成本点不能从结果中挑选：若无真实价格，lambda=0.5 只是预定情境，不能称现实节约。增加一次分子测量必须相对于同预算多一次直接功能确认的最强策略回本。若仅在 lambda=0.1 赢，结论是条件性信息价值，而不是普遍可用流程。

**PTV 特有限制。** 只有 17 谱系；23/63 药没有 target flag，预测轨迹对这些药相同；单药24h分子变化预测 correlation 约0.16、MSE差于基线复制。许多背景缺匹配时间 vehicle，因此“干预残差”混有培养时间效应。剂量、重复培养、数值敏感阈值不明，无法从这份发布直接输出完整可执行的实验室剂量条件。真实分子读出即使有价值，也可能只是泛细胞毒性，需对直接功能反馈/一般应激特征控制；现有资产不能裁决具体生物因果机制。

**为什么尚未被历史结果直接排除。** 旧 Q 是共享参数朴素微调，且未证明跨未见药物/谱系分子创新传播；最新修复证明概率可改变而效用不增。因此上述 *信息与跨干预纠错的上界/资格* 尚有消歧价值。它不是足以重启该封闭配置的正理由；若既有暴露数据上仍无明确信息，立即停止。

## 何时才允许研究继承与 RSI

只有 G0b 合法跨药净决策增益成立、普通更新无法解释后，才值得让程序变化；此前程序搜索为 0 次。后续至少需要三段真实测量任务流：A 学习、B 暴露失败并改进、C 评价改进的后续作用。药物族/谱系分组先锁定。继承对象分别隔离：模型权重、同量实例记忆、更新程序、改进策略。

最低证据链：世界模型 vs 等监督直接模型；固定 agent vs 同预算主动学习；继承 vs 同历史从头搜索；联合系统的差分交互；最后让“改进策略版本”随机分配到未来任务的程序提案，比较每固定 k 次真实评估所获得的净改进。RSI 所需的增量是改进策略使后续改进斜率/达到同效用所需评估数更好，不是新模型效用升高。等预算枚举/贝叶斯程序搜索、普通 refit、continual learning、实例检索与 distillation 必须共享可见历史并计入全部失败、API、候选评估及探针成本。

若只有固定微调改善、只有权重继承改善、只有更长搜索改善，分别归类为重训练、迁移或计算扩展；不称 RSI。PTV 小样本不足以同时鉴别这些因素，因此当前不建议在其上开启此阶段。
