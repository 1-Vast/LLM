# 反对方独立评审与交叉辩论：跨药分子残差纠错是否值得继续

日期：2026-10-21（Asia/Shanghai）。角色：反对方 / 方法怀疑者。对象：支持药物的实测分子响应减预测响应→识别共享模型误差→修正未查询药物功能排序→继承有效更新规则→允许 meta 策略修改诊断和更新方法。

资源：案头审查、跨代理消息、一次批量一手检索；无新模型实验、无 DeepSeek、无下载数值数据、无打开新封存结局。仅新增本文件。相关 G0a 独立代码审查见 [code_review.md](code_review.md)，较早历史和近年新颖性审计见 [skeptic.md](skeptic.md)。本记录不修改任何冻结结论。

## 独立结论：只支持一次便宜的信息资格，不支持当前创新或 RSI 主张

我支持检验“真实支持观测是否给未查询药物带来决策信息”这个可证伪问题。**目前没有找到不能被普通条件预测、系统辨识、核选择或 active meta-learning 解释的唯一技术增量。** 提案方在两轮交叉质疑后明确承认这点。

唯一仍值得保留的候选目标，是一个经真实跨药失败触发的、能够在固定后续资源下更有效找到可迁移更新规则的程序。它是否有新算法贡献和实际价值都未成立；在公平等空间搜索胜出之前，不能以“结构替换”“继承”“元策略可修改”作为创新证明。

两细胞背景**不构成窄未见药物开发任务的一票否决**。如果有足够独立药物组、完整真实功能目标、合法支持/目标划分及正确依赖统计，就可以做这两个已知背景下的药物留出开发研究。当前 DMG 资产的功能排序不合格，直接原因是功能目标尚未认证、EC20 选剂量引入结局信息，不是简单地因为背景数为二。

## 对候选的最强普通方法归约

设源模型在背景 x、支持药物 s 下预测分子响应 mhat_s；真实支持观测为 m_s，残差 r_s=m_s−mhat_s。候选方给出的具体运算是：在分子灵敏度 J_s 与噪声协方差 Σ 下识别低维误差 δ，再通过目标药物功能灵敏度 g_t 修正功能预测：

```
δ_hat = (λI + J_Sᵀ Σ⁻¹ J_S)⁻¹ J_Sᵀ Σ⁻¹ r_S
Δy_hat_t = g_tᵀ δ_hat
```

这是 δ~Normal(0, λ⁻¹I)、r_S=J_Sδ+noise 的标准线性高斯后验均值，也可由 Woodbury 恒等式写成跨输出核预测：

```
Δy_hat_t = K_y,m(t,S) [K_m,m(S,S) + Σ]⁻¹ r_S
K_m,m = J_S (λ⁻¹I) J_Sᵀ
K_y,m = g_tᵀ (λ⁻¹I) J_Sᵀ
```

因此：

- 从少量支持实验恢复背景隐变量，是普通系统辨识 / latent-context adaptation。
- 用支持集的分子观测预测其他动作的功能，是条件多输出回归 / cross-output GP / support encoder。
- 选择最能降低未来目标不确定性的支持药物，是 Bayesian experimental design / active learning；必须胜强 exploitation 和 A-optimal 等对照。
- 从历史任务学 J、g、P 或先验，是 hierarchical Bayes / representation meta-learning。
- 离散替换误差子空间 P，是 feature/kernel/model-structure selection；继承 P 是跨任务模型选择结果复用。
- 允许程序修订 P 的搜索方式，是元学习/自改进程序；Hyperagents 已有直接框架先例，不是本任务独有操作。

“所有系统都可形式化成条件函数”本身不是否定算法贡献的充分理由。我已向提案方澄清，不要求不可计算归约这种不合理门槛。可成立的增量可以是更好的归纳偏置、更少真实查询、较低搜索成本或新识别条件；但必须给出与普通方法不同的具体操作和可裁决资源收益。目前尚无此操作或证据。

另一个易被忽视的事实：给定 x、s 和同一个冻结源模型，mhat_s 是已知确定量，所以 r_s 与 m_s 相互可恢复。残差没有凭空增加信息。它可能提供好的归纳偏置，但“残差比 raw measured state 有效”必须与同时拥有 m_s、mhat_s 的同容量直接模型比较，不能把输入信息不对称当作世界模型贡献。

## 支持、反对和未决分别是什么

**支持：**

1. 有真实支持分子观测且目标药严格未查询的跨药纠错，区别于“给同一药测RNA再预测它的viability”以及重复计数已确认药物；是合理的具体用途。
2. 普通 refit 已有历史阴性不能证明新分子信息没有价值；因此新资产上的一次廉价信息资格可以提供增量知识。
3. 世界模型结构产生的敏感度可能是有用的先验。即使同属条件预测，若同监督、同容量下查询效率明显更好，仍可以形成有价值的技术结果。
4. 在两个已知背景内按药族留出，可以研究窄的药物泛化；若有足够独立药组，也可开展局部继承开发，但不能外推细胞背景分布或长期普遍RSI。

**反对：**

1. 残差、低维误差子空间、结构替换、病例库、可编辑meta策略均有普通方法解释或直接先例；串联这些模块不是自动的新机制。
2. 固定全字典＋稀疏/层级收缩通常包含 P/P' 子模型。若更强固定字典足以匹配，收益是普通正则化/模型选择，不能归因于自修订研究程序。
3. P 的名字/坐标变化不等于预测结构改变；必须比较诱导核、支持到目标的约束和真正不同的未见预测。
4. 当前新资产没有已认证的全候选功能裁决矩阵，PTV G0a又未给分数加入依据。此时直接开启程序搜索，只增加在已知开发信息上的选择机会。
5. 继承更强权重或更多经验后性能提高，不识别改进策略自身更有效；这必须在共同 task/model 起点上重做后续改进效率比较。

**未决：**

- 新数据中，支持分子观测是否有超越背景/药物先验、一般应激和功能支持的未测药物决策信息？
- 如果有，该信息能否由简单条件模型利用，还是敏感度/机制约束使其更有效？
- 是否存在重复可靠、可由可获得观测区分、会改变决策的错误结构，足以让 P→P' 有明确内容？
- 如果存在，新的更新程序如何在同候选族、同历史、同评估预算下超过普通搜索？
- 从相同起点出发，改进策略是否能在新的药族任务流更快找到有效规则？

这些均是未得到答案的问题，不是已有证据的正向解读。

## 数据方交叉审查：DMG 的具体阻断，不是背景数阻断

我向 `data_and_literature` 直接提出：若24 h分子剂量来自48 h EC20，所选剂量的viability已用于选dose，不能再当未知独立结局；EC20浓度本身可能直接泄露potency。请先明确真实功能目标是完整dose-response IC50/AUC、固定dose viability、细胞状态转换还是后续联合干预效用。

数据方回应：4份RNA孔位meta有 `drug_dose_time`，每板372药；两个细胞系中114药的剂量不同；均24 h、按EC20/Cmax选择；尚未找到全372药十剂量功能矩阵的公开发布路径。GSE264412只提供未治疗RNA。其结论是功能排序当前 NO-GO，窄药族分子预测可有条件GO；即使找到IC50/AUC，强直接模型也必须获同样dose metadata，并排除potency捷径，最好用固定外部剂量/新独立读板裁决。

我赞同这一判断。不能把每药归一到约EC20的viability当成完整药效排序标签，也不能把不可用的目标矩阵交给模拟器填补。此处尚未下载数值表达或功能载荷，不存在新的性能数字。

## 最小裁决实验与停止条件

**阶段0：先确认合法真实目标。** 保留一个精确行动/终点：drug identity、dose、exposure、背景、支持观测时间、功能读板时间、重复/批次关系。确认功能数据在决定分子dose之前是否已经被用过。若功能矩阵缺失或标签的确用于目标dose选择，只允许明确的分子预测任务，停止功能决策和RSI论证。不能以虚拟功能分数替代未知真实观测。

**阶段1：检验信息价值，先固定支持集。** 在相同支持药物S、目标药物T、背景和cost下，配对比较强直接功能模型、支持实测分子条件模型、普通多输出低秩/kernel更新、候选残差-J/g更新。所有臂获得相同源模型预测、实测支持、annotation和历史；目标药真实分子/功能不进入适配。支持和目标药按药族/化学族分离；若只两个背景则把背景视作固定条件，按独立药组和可确认plate/culture依赖统计，不能用两背景bootstrap宣称跨细胞总体结论。

必要信息对照是 measured state / measured−baseline / measured−predicted，各臂都知道相同baseline和prediction；增加跨药/跨批置换、仅背景/全局应激、仅功能支持。若测量条件模型胜 source 模型，但 J/g 更新不胜普通kernel，则保留“分子测量有用”，停止世界模型特有贡献。若分子测量不能超过同预算功能确认，停止此用途的分子查询。实用阈值要根据新任务可执行效用在开结局前设定；不能把PTV的数值阈值未经解释移到不同功能量纲。

**阶段2：只在阶段1有正信号后比较 P 修订。** 固定一个有预测内容的失配，候选P和修订族在开目标前列明。提供同一候选族给普通CV、稀疏全字典、BO/随机搜索；匹配实际候选评估数、真实查询、计算和全部失败成本。先在独立真实药组检验修订是否带来功能决策收益。若普通搜索/全字典匹配，停止“程序自修订的独有贡献”，但可以保留选出的常规模型。

**阶段3：最后才检验继承/RSI。** 将冻结后的改善策略 m* 与初始m0、固定最佳普通搜索放在共同 p0/w0 上；新药族任务流只供其有限k轮改进，另留真实裁决药组。比较每固定预算的真实功能增益，并含形成m*的前期成本。移植模型权重、实例记忆、更新程序、meta策略分别开关。若优势只来自更强起点、更多历史数据或更长搜索，则不能称策略本身更会改进。

当前建议只进行阶段0的schema/来源资格。功能目标通过后，至多预注册一次阶段1开发检查；未建议现在搭建新的P结构搜索器或RSI系统。

## 与已有工作相比，当前尚可争取的实质差异

| 对照类别 | 已覆盖的内容 | 需要另外证明的差异 |
| --- | --- | --- |
| 直接 conditional prediction / CNP | 从支持观测推断未观测目标 | 冻结世界结构在同监督/预算下带来额外决策或查询效率，而非支持输入增多 |
| 系统辨识 / 多输出GP | 从分子残差恢复共享误差并传播目标 | J/g/P 的选择或修订有更有效的可检验规则，不只换名拟合 |
| 主动/贝叶斯实验设计 | 为下游目标选择辨识实验 | 在实际功能效用和测量价格下超过强普通策略 |
| 层级/active meta-learning | 跨任务学习先验与适配过程 | 非平稳结构失配后，改进策略以相同资源更有效找到后续规则 |
| Hyperagents/通用程序搜索 | 修改task/meta程序，继承改进能力 | 真生物观测下的特定操作、等预算净收益及机制归因 |

这张表是必要性清单，不是声称已具备这些差异。若最后只剩普通方法在新数据上的应用，仍可诚实报告科研价值，但不能交付为已证明的新框架机制。

## 一手来源与访问边界

- [Garnelo et al., Conditional Neural Processes, ICML 2018](https://proceedings.mlr.press/v80/garnelo18a.html)：原始PMLR摘要和原始论文索引于2026-10-21检索；支持“从少量context预测targets”的普通归约，不用于药物效果主张。
- [Rakelly et al., Efficient Off-Policy Meta-Reinforcement Learning via Probabilistic Context Variables, ICML 2019](https://proceedings.mlr.press/v97/rakelly19a.html)：原始PMLR摘要于2026-10-21检索；潜任务变量的在线推断与探索已有先例；不将RL结果当药物证据。
- [Hyperagents, arXiv:2603.19461v1, 2026](https://arxiv.org/html/2603.19461v1)：2026-10-21已读原始全文，meta自修改与改进能力转移已有直接先例。最新虚拟细胞共同演化、VCLMU及来源访问限制详见本代理 `skeptic.md`，不另声称完整novelty检索。

上述高斯/kernel等价为本次明确写出的代数归约，不是从文献复制的公式。无模拟结果被当作生物有效性证据。
