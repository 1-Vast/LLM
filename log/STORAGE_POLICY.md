# Research storage policy

- The published `log/SOURCE_MANIFEST.json` pins key Git source representations and small exact supplements. Large data, full record bodies and research packages remain local. A new clone can inspect key protocols, source code and findings, but requires separately supplied lawful data and environments for experiments. Git LF normalization and original frozen bytes are separately identified; publication does not claim those representations are byte-identical.
- `log/RESEARCH_REPORT.md` is the single detailed scientific synthesis. `STUDY_INDEX.tsv` preserves per-study findings and source identities. `research/STUDIES.json` records study status, actual archive locations and selected evidence/decision relationships. Protected source records and a live cross-study input retain their current locations.
- `data/raw/` preserves original experimental inputs; `data/external/` preserves downloaded datasets and source material. `data/processed/` holds derived data, current models/results and research packages. Frozen and raw evidence are not rewritten to correct a maintained report.
- `data/processed/research_records/` is the exact-source collection for former reports, protocols, amendments and logs. Its index authenticates content and maps stable source IDs. Earlier path mappings are historical provenance, not a requirement to preserve old interfaces; this refactor does not add compatibility aliases.
- `data/processed/research_packages/` holds `historical_experiments.zip` (1,391 members), `historical_artifacts.zip` (3,184 members), and `workbench.zip` (168 members). Full member contents and package SHA256 were verified before 4,743 loose sources were removed. The canonical reader IDs are `packages/<package-name>/<original-relative-path>`; standard ZIP readers can also access original member paths. Existing relocated source IDs now point to the corresponding verified members.
- `research/` keeps seven current working/replay workspaces: functional-rule revision, innovation validation and repair, self-improving virtual-cell diagnostics, procedure inheritance and audit, and the latest evidence-portfolio readout. Their present dependencies and behavior tests continue to operate. Other registered implementations are retired into the experiment package, with their registry identities and original code/configuration preserved. A directory or test pass does not promote an experimental method into validated science.
- `src/`, reusable `tools/` and their behavior tests remain maintained runtime interfaces. Promotion requires an explicit scientific/engineering decision with appropriate evidence. Unique results are not deleted merely because their generator could theoretically be rerun.
- `tmp/` retains the installed GPU environment, nested DGM Git checkout, test state and explicitly protected payloads. Retired fixed-path caches/debug code are in the workbench package; old commands are not kept runnable for compatibility. Accessing sealed/blind outcomes is outside this maintenance task.
- DGM presentation deliverables stay in `data/processed/dgm_presentation/`. The saved procedure-inheritance statistics audit remains in its current `research_results/.../saved_statistics_audit.json` location; all 24 bound inputs were verified before the audit interpretation was incorporated.

Use [the record reader and explicit restoration workflow](README.md) for exact sources. Restore only required members to an isolated replay tree and assemble input/environment dependencies before running historical verification. Retrieval and byte equality do not prove immediate replayability, semantic completeness or scientific validity. Modes and access/modification times were recorded; these are not complete NTFS security-descriptor or alternate-data-stream backups.

The original collection's 11,019 exact records, 524 relocated files and 11,539 historical aliases were verified before this incremental refactor. The 77 early moves were individually hash/time/mode checked; their newly added compatibility aliases were removed when the current no-compatibility requirement was applied. Later package membership and current registry state supersede that intermediate layout. Original frozen source text retains its bytes and source identity, including historical relative references.
