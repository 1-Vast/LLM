# MAESTRO 实验记录入口

这里是所有实验方向、结果、失败原因和下一步的短索引。详细、可复核的原始记录仍在 [`research/`](../research/)；本目录只保存不会随临时文件清理而丢失的结论摘要。

- `EXPERIMENT_REGISTER.md`：九项保留研究的状态和关键数字。
- `DIRECTIONS.md`：继续、暂缓和停止的研究方向。
- `FAILURE_MODES.md`：已复现的失败/阻塞原因及对应修复。
- `COSTS.md`：调用、下载和数据资产的保留边界。
- `studies/`：每项研究的一页摘要；以研究根目录的冻结文件和验证脚本为准。

`data/external/` 是外部数据资产，`outputs/` 只存有明确研究价值的可再生输出。删除临时产物前必须先确认其结论已进入本目录或 `research/REPORT.md`、`research/EVIDENCE.md`。
