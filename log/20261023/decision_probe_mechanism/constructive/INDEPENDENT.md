2. **Sufficient Decision Proxies for Decision-Focused Learning**, Noah Schutte et al., arXiv2505.03953v3. First disclosure6May2025; this read version updated17September2026, with IJCAI2026 DOI10.24963/ijcai.2026/260 metadata. ## One precise attempted mechanism (not qualified)

Attempt: compress a finite world ensemble by each world's terminal best drug and score inexpensive probes using only the compressed class-conditional likelihoods. The hoped-for contribution is fewer world updates and likelihood evaluations when many mechanistic hypotheses induce the same drug decision. A precise simple implementation is:

    1. Compute c(h)=argmin_a L(a,h), preserving deterministic ties.
    2. Aggregate p_c=sum_{h:c(h)=c} p_h.
    3. Estimate each class/probe marginal K_q(y|c)=sum_h p_h P(y|h,q)/p_c.
    4. For a probe set S, approximate P(y_S|c)=product_{q in S} K_q(y_q|c).
    5. Enumerate feasible S and minimize expected terminal Bayes drug loss plus actual probe cost.
    6. Update class weights from acquired outcomes; return the minimum-loss drug.

The explicit restriction is conditional independence of all probe outcomes given the terminal decision class, plus a loss representation preserved by that class. It could make likelihood tables smaller, but it is neither authenticated by existing functional data nor a new estimator: an ordinary class-conditional naive-Bayes/direct decision model with the same compression reproduces every step. If correct joint observation laws are retained instead, this is ordinary Bayesian experimental planning with state aggregation, and the cost/complexity savings must actually be measured against cached/vectorized planning. No measured distinct efficiency contribution survives here. A best-drug label alone also generally omits magnitudes needed for asymmetric regret; the fixed test intentionally uses0/1decision loss to avoid that extra confound.

## Frozen exact distinguishing case and actual execution

OPERATION_PROTOCOL.md and probe_check.py were SHA-frozen before a single Fraction run. Four equiprobable worlds(d,n), two drugs a in{0,1}, loss1[a!=d]. ProbeN observes n and probeX observes d XOR n. Each costs1/8 and the budget permits two. No biological law is asserted.

The executed exact posterior risks for no probe/N/X/both are1/2,1/2,1/2,0; costs included give1/2,5/8,5/8,1/4. A myopic policy requiring positive one-probe net decision gain stops. Ordinary joint-law two-probe enumeration purchases both and attains1/4. Under the attempted decision-class factorization, both marginal observation laws are uniform given d, so the pair's represented terminal risk remains1/2: it loses the useful cross-probe correlation.

This distinguishes a concrete failed compression and myopic stopping rule from a strong ordinary planner; it does not disprove decision-focused acquisition, general class compression, ordinary EIG, OPO or the sufficient-proxy theorem. Preserving a nuisance variable can be necessary for planning an observation that will later remove decision ambiguity. Thus “only update ambiguities that directly change the drug decision now” is too strong. The salvage condition is observation/planning sufficiency (a controlled joint-law/lumpability condition), not another label for terminal sufficiency. We have not found an empirically grounded cell-specific restriction making that condition hold cheaply.

## Actual inputs, application, falsifiers and disposition

Intended application is finite-pool drug selection from costly legal assay feedback. Existing exposed BeatAML sample×drug AUC can support ordinary finite-pool feedback studies; it does not by itself supply paired different-modality assay likelihoods or authenticate the parity-style joint channels. The acquired EU-OPENSCREEN source metadata provides multi-site reference/profile routes, but a paired target assay joint-law task is not downloaded or authenticated here. Neither source justifies a novel latent pathway probe. In particular the fully observed contextual training assumed by OPO cannot be replaced by a sparsely observed action-response table without specifying estimation and its costs.

Stopping rule for this candidate: stop its novelty claim because same-information ordinary naive-Bayes or joint-law planning reproduces its operations, and stop its safety/sufficiency claim because the predeclared counterexample defeats the unverified factorization. No same exposed panel tuning, decoder extension or arbitrary two-probe policy rescue follows. To reconsider a distinct version requires one documented observable restriction giving cheaper joint-law updates than strong cached direct planning, a frozen compute/feedback advantage target, and a task with matched legal probe outcomes. Familiar components would be allowed if that specific advantage existed.

Any later performance study must share source history, probe pool, outcomes, state access and total computation across direct joint outcome models, ordinary refits/CL, legal AL/decision-value planning, simple mixtures and equal-budget program search. This phase establishes none of world, agent, inherited update, joint benefit or G1-over-G0 improvement. Terminal proxy expressiveness is not RSI.
