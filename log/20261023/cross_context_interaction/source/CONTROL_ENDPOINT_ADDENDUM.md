# Control-only relative-abundance endpoint: mathematical possibility, not acquired contract

After source's independent seal, parent requested a precise check of whether cached count scoring permits a control/single-only endpoint. A recursive cached-text search found no definition of score_fitness, calibrate_fitness or normalize_counts; the inspected entrypoint calls them but their implementation is not in the qualified cached files. No new GET or count value was read. Thus the raw-fitness pipeline cannot presently be certified source-legal by extrapolating from its name.

A possible explicitly different endpoint would use matched baseline N0 and terminal Nt construct counts, with a predeclared neutral-control set C:

    L_g = log2((Nt_g+alpha)/(N0_g+alpha))
          - median_{c in C} log2((Nt_c+alpha)/(N0_c+alpha)).

This is relative log-abundance change against controls, not automatic absolute growth, a division-normalized growth rate, the author's fitness or published GI. Shared sequencing-depth factors cancel in the ideal unregularized ratios; fixed pseudocounts and low coverage can break exact invariance and require a declared model/QC. alpha, control membership, coverage rules, aggregation and missing handling must be set from allowed source/control information before query scoring. One cannot repair the endpoint afterward by selecting favorable controls, thresholds or dropping lethal/missing queries.

For a revealed support pair, this expression can in principle use only that pair's matched baseline/terminal counts and the shared control counts. Single-effect inputs additionally require authentic single-KO/control constructs in the same context and explicit orientation/guide mappings. Unrevealed pair terminal counts are evaluation-only, not normalizers. Target all-panel means, essentiality lists fitted from target outcomes, fitted per-anchor slopes and final residual/FDR scaling cannot enter for free. Full baseline/control sequencing, sample preparation and any external common-essential reference must be counted/shared. If only ratios rather than those sample identities are available, this recipe is not acquired merely because it can be written.

Remaining real source gaps are baseline/timepoint and culture/replicate identity, actual controls and their functional interpretation, single/double construct map, guide QC/coverage, growth interval or population doublings, raw count completeness and original fitness-normalization code. AAVS/non-targeting names in downstream code do not authenticate universal neutral invariance or equivalent editing burden. No mechanistic truth is required simply to evaluate a predictive relative-abundance endpoint, but its observation semantics still must be real.

Most importantly, pooled CRISPR constructs are measured together: a full pooled culture and its sequencing generally produce the library's readouts jointly. Revealing a few archived construct endpoints is not automatically buying only a few physical assays. The actual screen/library/control and sequencing cost is a bundle. Targeted sublibrary construction could change representation, competition or measurement; equivalence to the original library is not authenticated. Therefore a limited-feedback replay might be meaningful conditional on a completed physical screen, while wet-lab savings from sparse queries require a separate actual cost/action contract. Charge the whole measured bundle where appropriate rather than assigning fictional per-pair wet costs.

Conclusion: no mathematical impossibility prevents a control-referenced sparse-information endpoint. The current cached evidence authenticates only completed-screen score schema and method dependence, not this alternative raw endpoint. It remains legitimate to propose a bounded later qualification if a specific restriction/recurring functional-error hypothesis needs it. No counts acquisition, new fit or existing STOP reopening follows from this addendum. Original report/seal preserved; no current-phase peer report read before this addendum.
