# Bounded identifier-only probe, before new payload access

2026-10-23. Purpose: test official library feature identities, GEX cell-barcode formatting, and pinned author readName grammar. This is source/data engineering, not an experiment claiming predictive performance or a new update law.

1. Acquire the four exact GSE289454 series-declared sample3 preAraC/sample4 postAraC features.tsv.gz and barcodes.tsv.gz, at most4MiB compressed per source, one logical GET each, no retry. Retain source bytes and receipts. Do not request matrix.mtx or any expression, dose-response or count payload. Feature IDs/names/type and cell barcode IDs are permitted identifiers. Export all non-Gene-Expression feature definitions, feature type counts, and barcode formatting/uniqueness aggregates. Gene feature names need not be exported.
2. Locally decompress only the previously retained lineage_pre/post.compressed_prefix from the earlier header probe, at most512KiB decompressed. Skip the header; inspect at most100 complete records. Extract second-field[:16] cell barcode and [16:28] UMI for syntax/identity checks; do not interpret or export the third-field numeric read abundance. Do not use columns keep, umi, targets, allele/merged read, read counts or any founder/clone assignment. Full rows may transiently materialize during parsing; no physical non-decoding claim.
3. Candidate identity test only: remove a trailing numeric GEX library suffix (record suffix distribution), compare extracted16base cellBCs against same-declared GEX-library barcodes. Report record count, valid grammar counts, distinct barcode count and match fraction. This finite prefix is nonrandom and cannot estimate whole-library recovery or validate FB→GEX conversion. Pre-associated raw contains multiple biological libraries; no claim of pure baseline is permitted. No reverse-complement, fuzzy or data-selected translation search. A direct match is only an identity candidate; a failed match is only failure of this prefix/direct-map candidate.
4. STOP the parser at any grammar violation, record failure and do not rewrite the frozen grammar to raise coverage. Missing or HTTP-failed sources are missing, not zero overlap. No endpoint clusters, molecular founder tags, phenotype fitting, culture assignment from expression, threshold selection or old-label access. New observed identifier evidence changes the next qualification action, not success criteria for functional/RSI claims.

Chemistry translation and MULTIseq feature→cell-line/flask/time provenance remain separate hard conditions. Generic names such as barcode1 cannot authenticate culture assignments. Prefix overlap cannot certify independent cultures or causal/function measurements. Full records or matrices require a later justified contract.
