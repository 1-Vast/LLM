Materials and Methods Inference. We first describe how to infer the generative model from data. The LCD model distinguishes diffusion (biological) from measurement (technical) noise by modeling discrete observations  p ( y )  as noisy samples from the stationary diffusion densities  p ( x ) , governed by the likelihood  p ( y ∣ x ;   π ) . To achieve this separation in the generative model, we perform inference in two consecutive steps ( Fig. 1 A ). Suppose we observe data  Y q = y ( n )  for a control condition  q 0  and  k  perturbations  q 1 , ⋯ , q k . Inference of the model then proceeds as follows: Learn state densities  p q ( x )  and likelihood parameters  π  that maximize evidence of the observed  Y q . Input:  data  Y q  for each condition  q Output:  samples  X q ∼ p q ( x )  and  π Learn drift  f  and embeddings  e q  that jointly fit  p q ( x ) . Input:  states  X q  for each condition  q Output: f  and embeddings  e q After both inference steps, we have learned the stationary diffusion drift  f , perturbation embeddings  e q , and measurement noise parameters  π . These specify the full generative model and enable data generation under unseen embeddings  e q ′ . The samples  X q  are only used for fitting the drift and discarded afterward. We now describe each step in more detail. Inference stage 1: Measurement model. Inference of the state density  p ( x )  corresponds to learning the  prior  that generates the data distribution  p ( y ) , an approach called empirical Bayes ( 65 ). Our goal is not posterior inference of  p ( x ∣ y ) , since we do not require the state that generated a specific datum  y . Our approach to this inference problem is to model the prior  p ( x )  as an implicit distribution that is easy to sample from and differentiate ( 66 ). Specifically, we model prior samples  x ∼ p ( x ;   ϕ )  as  x = g ( ϵ , ϕ ) , where  ϵ  is random noise and  g  a differentiable function with respect to parameters  ϕ . This choice enables a flexible distributional family for  p ( x )  to avoid biasing the drift trained on the inferred priors in the second inference step. Implicitly modeling the prior is possible, because both of our inference steps only require samples  x ∼ p ( x ;   ϕ )  or differentiating them with respect to  ϕ . We infer the prior  p ( x ;   ϕ q )  of a condition  q  by maximizing the evidence of the observed readouts  Y q . We use separate parameters  ϕ q  for each condition  q  but share the likelihood parameters  π  across conditions, as  π  is used for test-time generation. The evidence  log p ( Y q ;   ϕ q , π )  is given by [9] log p ( Y q ;   ϕ q , π ) = ∑ n log ∫ p ( x ;   ϕ q ) p ( y ( n ) ∣ x ;   π ) d x ≈ ∑ n L S E m = 1 M log p ( y ( n ) ∣ x ( m ) ;   π ) − log M , where we approximate the integral with  M  samples  x ( m ) ∼ p ( x ;   ϕ q ) , written with the log-sum-exp operator  L S E m ( z ( m ) ) : = log Σ m exp ( z ( m ) ) , which has a numerically stable implementation. The ZIP likelihood factors as  p ( y g ∣ x g ; π g ) = π g ∥ ( y g = 0 ) + ( 1 − π g ) Pois ( y g ; μ g ( x g ) ) , where  ∥ ( y g = 0 ) = 1  iff  y g = 0  and  π g = sigmoid ( π ¯ g )  with learned logit  π ¯ g ∈ R  (Eq.  2 ). To account for scale differences across genes, we used the rate function  μ g ( x g ) = η g log ( 1 + e x g ) , where  η g  is a fixed gene scaling computed from control samples ( Training Details ). Optimization of the evidence is nontrivial, since the estimator (Eq.  9 ) is biased and high-variance. Expanding the joint likelihood  log p ( y ∣ x ;   π ) = ∑ g = 1 d log p ( y g ∣ x g ;   π g )  shows that the LSE term scales linearly with  d . Due to the exponential, maximizing the log-sum-exp term requires learning to generate samples with high likelihood across all  d  dimensions jointly, which becomes exponentially less efficient with  d . We tackle this by using large  M  and introducing a scaling  τ − 1  of  log p ( y ∣ x ;   π )  in the loss:  [10] log p τ ( Y q , ϕ q , π ) : = ∑ n τ LSE m = 1 M ( τ − 1 log p ( y ( n ) ∣ x ( m ) ;   π ) ) . The temperature  τ  interpolates between fitting the full joint distribution including higher-order dependencies ( τ = 1 , higher variance) and fitting the marginal distributions only (high  τ , lower variance). As  τ → ∞ , the log-sum-exp operator converges to the arithmetic mean, effectively swapping logarithm and summation like a Jensen’s lower bound, and treating the  d  dimensions in the joint likelihood as (unconditionally) independent, thus alleviating the variance caused by the exponential. Our final training objective  L IP  for learning the implicit prior is to minimize the combined loss [11] L IP ( Y q , ϕ q , π ) = − log p 1 ( Y q , ϕ q , π ) − log p τ ( Y q , ϕ q , π ) tuned over  τ ∈ 5 , 20 , 100 .  L IP  is fully differentiable with respect to  ϕ  and  π  by propagating gradients through the implicit samples  x = g ( ϵ , ϕ ) . In  SI Appendix , Fig. S8 , we ablate the temperature scaling in  L IP . Inference stage 2: Stationary diffusion. Inferring the drift  f  and perturbation embeddings  e q  requires learning a stationary diffusion model that jointly fits the densities  p q ( x )  obtained in inference stage 1. Any learning approach may in principle be used for this. In our experiments on SDEs with constant  σ  (Eq.  1 ), score matching was computationally efficient and achieved good fit and generalization. In this setting, a drift can be inferred by denoising smoothed data  x ~ ∼ N ( x ~ ;   x , α 2 I ) , where  x ∼ p ( x ) . The drift  f  that minimizes the squared loss  | | f ( x ~ ) + ( x ~ − x ) / α 2 | | 2 2  in expectation satisfies  f ( x ~ ) = ∇ log p ( x ~ ;   α )  under weak regularity conditions, which implies the SDE has stationary density  p ( x ~ ;   α )  for  σ = 2  ( 67 ). The difference between  ∇ log p ( x ~ ;   α )  and  ∇ log p ( x )  becomes negligible as  α → 0 . Following Song and Ermon ( 68 ), we thus infer  f  by learning to denoise different smoothing levels  α , conditioning the drift on  α . The loss for drift  f ( x ;   θ , e q , α )  is then [12] L D ( X q , θ , e q , α ) = ∑ n | | α ( n ) f ( x ~ ( n ) ;   θ , e q , α ( n ) ) + ϵ ( n ) | | 2 2 , where  x ~ ( n ) = x ( n ) + α ( n ) ϵ ( n ) ,  ϵ ( n ) ∼ N ( 0 , I d ) , and the scales  α ( n )  are drawn from the geometric sequence  α = [ 0.01 , ⋯ , 10 ] ∈ R 30 . In Eq.  12 , we scaled the norm by  α 2  to ensure that loss terms have comparable magnitudes. Training on multiple and large smoothing levels  α  avoided fitting all perturbed densities  p q ( x )  unconditionally like a mixture distribution of all conditions, ignoring the embeddings  e q . Avoiding this also required careful sampling based on  α  ( Sampling ). For CLIPR, we condition  f  on the smallest  α 1 = 0.01  and thus least smoothing error ( CLIPR ). We fixed the diffusion scale  σ  (Eq.  1 ) to  σ = 2  throughout all experiments. This is a time-scale convention, not a model parameter, as score matching ties drift and diffusion terms together when fitting  p ( x ) . Rescaling both only rescales time, and our choice selects the parameterization in which  f  equals the score. We shared  θ  across conditions  q , modeling the gene regulatory mechanisms and enabling test-time generation for unseen  e q . Score matching fits the drift  f ( x ;   θ , e q )  to a gradient field, abstracting away the fact that  θ  is fit to multiple densities and coupled through  e q . While this would imply that steady-state dynamics have zero curl ( ∂ [ f q ] a / ∂ x b = ∂ [ f q ] b / ∂ x a ), the perturbation behavior modeled by LCDs is not symmetric. Because perturbations modify the hidden state of a nonlinear drift ( Fig. 1 B ), perturbing gene  a  may not have the same effect on gene  b  as perturbing gene  b  has on gene  a . CLIPR reveals that LCD perturbations indeed exhibit asymmetry ( Figs. 3 C  and  4 B ). To learn stationary densities with nonzero curl and enable modeling, for example, negative feedback loops of three repressors ( 23 ,  36 ), future work could leverage more general learning objectives not based on the gradient field assumption ( 31 ), which would also allow learning state-dependent diffusions  σ ( x ) , where  σ  carries biological meaning rather than serving as a time-scale convention. Sampling. To generate data  y ∼ p q ( y )  for a test perturbation  e q , we conditioned  f  on the test embedding  e q  and simulated the diffusion to obtain samples  x ∼ p q ( x )  from the stationary density. For a perturbation combination of  q a  and  q b , the embedding is  e q a + e q b  ( Neural Network Architectures ). We generated diffusion samples by annealing the Euler–Maruyama method according to the trained smoothing levels  α  ( 68 ). The sample path approximation at step  l  is ( 69 ) [13] x ( l + 1 ) = x ( l ) + f ( x ( l ) ;   θ , e q , α ( l ) ) ( α ( l ) ) 2 Δ t + ξ ( l ) α ( l ) 2 Δ t for noise  ξ ( l ) ∼ N ( 0 , I d ) , step size  Δ t , and smoothing level  α ( l ) . In our experiments, we used  Δ t = 10 − 4 , initialized at  x ( 0 ) ∼ N ( 0 , I d ) , and computed 500 Euler–Maruyama steps per annealing scale in  α , starting with  α 30 = 10.0  and ending at  α 1 = 0.01 . The last state  x ( l )  corresponds to the sample from  p q ( x )  after inverting the shift and scale standardization performed on the training data ( Training Details ). For each  x ∼ p q ( x ) , we generated one observation  y ∼ p ( y ∣ x ;   π )  (Eq.  2 ) as the final sample from the LCD.  SI Appendix  summarizes the full LCD workflow. Neural Network Architectures. For our experiments, we parameterized the drift and the implicit priors using multilayer perceptrons (MLPs). The implicit prior network  g ( ϵ , ϕ )  transformed noise  ϵ ∼ N ( ϵ ; 0 , I 64 ) ∈ R 64  into samples  x = g ( ϵ , ϕ ) ∈ R d . After an initial linear layer mapping  ϵ  to 64 dimensions, the network consisted of a sequence of residual MLP blocks with 64 hidden dimensions (4 blocks), followed by a linear layer mapping to  d  dimensions, and additional residual MLP layers with 256 hidden dimensions (2 blocks). Residual MLP blocks computed output  z ′  from input  z  as  z ′ : = z + Linear ( SiLU ( Linear ( z ) ) ) , where  SiLU ( z ) : = z · sigmoid ( z )  elementwise and  Linear ( z ) : = W z + b  with independent parameters  W , b  and corresponding dimensions per layer. Residual layers stabilized training and the variance of  p ( x ;   ϕ ) , and the low dimensionality reduced memory, enabling larger Monte Carlo sample sizes  M  during training. The drift  f ( x ;   θ , e q , α )  was parameterized by a fixed  α -dependent scaling to adjust for changing state and gradient magnitudes across the different smoothing scales  α  ( 70 ). Specifically, we modeled  f  as [14] f ( x ;   θ , e q , α ) = 1 α h ( x 1 + α 2 ;   θ , e q , α ) , where  h  is the main neural network parameterized by  θ , taking state  x , perturbation embedding  e q , and smoothing scale  α  as input.  h  is an MLP with two hidden layers,  tanh  nonlinearities, and  d f ∈ 1 , 024 , 2 , 048  dimensions ( Fig. 1 B ). Representations  e q  have 1,024 dimensions and are jointly learned with  θ . They are added to both hidden states of the MLP before the nonlinearity following separate learned linear transformations, similar to conditioning techniques in vision models ( 71 ). We model combinations of perturbations  q a  and  q b  by adding embeddings as  e q a , q b = e q a + e q b  and represent the control condition  q 0  by the zero vector  e q 0 = 0 . Last,  h  models the effect of  α  by encoding the index of  α  in the sequence  α  as a sinusoidal position embedding ( 72 ), then mapping to  d f  dimensions with a linear layer,  tanh  nonlinearity, and a second linear layer, and finally adding the  α  representation to the first hidden state of  h .  SI Appendix , Fig. S8  provides ablations of these modeling choices. Training Details. As described in  Inference , we observe data  Y q  for a control condition  q 0  and  k  perturbations  q 1 , ⋯ , q k . Training then proceeds in two consecutive steps. We used the same training hyperparameters devised during development of the method across all experiments unless we note they are tuned otherwise ( Baselines and Hyperparameters ). We learned the priors by minimizing  L IP  (Eq.  11 ) with gradient descent for 100,000 steps (Wessels et al.,  k ≈ 100 ) or 250,000 steps (Norman et al. and Replogle et al.,  k > 200 ). We used the Adam optimizer ( 73 ) ( β 1 = 0 ,  β 2 = 0.99 ) with learning rate  0.0003 , warmed up for 5,000 steps and cosine-decayed to zero. Each step randomly sampled a perturbation  q  and then updated parameters  ϕ q  and  π  based on  Y q . The loss  L IP  was computed using a batch size of  64  and  M = 20 , 000  Monte Carlo samples. Gradients were clipped at  ℓ 2 -norm  1.0 . We used the link function  μ g ( x g ) = η g log ( 1 + exp ( x g ) )  to map states  x g  to Poisson rates, where  η g  are gene-specific scalings (Eq.  2 ). We fixed these scalings to  η g = y ¯ g + s ¯ g 2 / y ¯ g − 1 , lower bounded by  1 , where  y ¯ g  and  s ¯ g 2  are sample means and variances of  y g  in the control data  Y q 0 . This is the method-of-moments estimator for the Poisson mean under a ZIP model of  y g  ( 74 ) and thus calibrated  μ g ( x g )  to the expected scale of  y g  (see  SI Appendix , Fig. S8  for an ablation of this scaling). After optimization, we generated  N = 10 , 000  state samples  X q = x ( n ) n = 1 N ∼ p ( x ;   ϕ q )  for training the diffusion. We trained the drift  f  and perturbation embeddings  e q  by minimizing  L D  (Eq.  12 ) with gradient descent for 50,000 steps. We used the Adam optimizer ( β 1 = 0.9 ,  β 2 = 0.999 ) with learning rate 0.001, cosine-decayed to zero, and weight decay tuned over  0.03 , 0.1 , 0.3 , 1.0 , 3.0 . Weight decay was most effective at controlling over- and underfitting and tuning predictive performance of LCDs. Each update step randomly selected one condition  q , one smoothing level  α ( n )  for each  x ( n ) , and then updated parameters  θ  and  e q , using a batch size of 8,192 to compute  L D . We standardized the training data to facilitate gradient-based optimization by subtracting the control means of  X q 0  and dividing by the SDs across all training samples  X q 0 , ⋯ , X q k . We numerically approximated the fixed point defining the perturbation response  ℓ f q  by integrating the flow of  f  conditioned on  e q  as [15] ℓ f q ≈ lim t → ∞ x ¯ ( t ) , where  d x ¯ ( t ) / d t = f ( x ¯ ( t ) ;   θ , e q , α )  and  x ¯ ( 0 ) = 0  ( Fig. 1 C ). For integration, we used the same annealing scheme for  α  as used for sampling but dropped the diffusion term ( Sampling ). Integration starting from the control vector  0  resolves the ambiguity that  f q  may admit multiple fixed points. We assume throughout that this limit exists, which held true in all experiments. To compute CLIPR, we assembled the  V  and  L  matrices ( Theorem  1 ) by conditioning the drift  f  separately on each perturbation embedding  e q  learned during training. For the linear systems in  Fig. 3 , we used a regularization strength of  λ = 1 / ( 10 d )  for systems of  d  variables, specifically  λ = 10 − 3 , 3 · 10 − 4 , 10 − 4  for  d = 100 , 300 , 1 , 000 . These values were selected by cross-validation on held-out linear systems. For real-world datasets, cross-validation is not possible, because the true causal effects are unknown. Moreover, values calibrated on linear systems are likely overly conservative under the model mismatch introduced by nonlinear perturbation responses. We therefore selected  λ  by plotting the norm of  A ^ λ  against its approximation error and identified the  λ  value beyond which changes to the CLIPR matrix diminish with further regularization. For our analysis in  Fig. 4 , this yielded  λ = 10 − 2 .  SI Appendix  and  SI Appendix , Fig. S11  provide additional details. We standardize the states  p ( x )  before learning  f , so  f  operates in different unit scales than the original  p ( x )  ( Training Details ). However, we still want to interpret the causal effects of the drift in the original units when applying CLIPR to  f  learned in standardized units. That is, we seek the CLIPR linearization of the drift we  would have learned  had the data not been standardized. For this, we can provide the original drift  f x  as an explicit function of the data transformation and learned drift  f s  assuming the diffusion scale  σ  is fixed. If densities  p ( x )  are transformed as  x = m + T s , where  m ∈ R d  and  T ∈ R d × d  positive definite, the perturbation responses of  f x ( x )  (Eqs.  5  and  6 ) are given in terms of  f s ( s )  as [16] v f x = T − 1 f s ( − T − 1 m ) , ℓ f x = m + T ℓ f s . We always applied Eq.  16  before computing CLIPR to account for data standardization before training. Datasets and Preprocessing. We performed experiments on Perturb-seq data by Norman et al. ( 5 ) and Wessels et al. ( 6 ) ( Fig. 2 ) and by Replogle et al. ( 1 ) ( Fig. 4 ). All datasets were prepared with standard preprocessing steps. Initial quality control filtered genes expressed in less than 20 cells, cells measuring less than 200 genes, and perturbations with less than 100 cells, as well as outliers based on dataset-specific cutoffs for high mitochondrial RNA counts and total cell and gene counts. For benchmarking, we split the double-gene perturbations into a validation set of 20 perturbations for hyperparameter tuning and a test set used for benchmarking, which was split further into 10 folds. For a given test fold, methods were trained on control, single-gene, and double-gene perturbations of the remaining test folds. Combining all experiments, we obtained test-time predictions for all double-gene perturbations ( SI Appendix , Fig. S2 ).  SI Appendix , Table S1  lists summary statistics for the perturbations available in each dataset. For all datasets, we modeled 1,000 highly variable genes based on Seurat-dispersions ( 75 ) of the control and single-gene perturbation data (always in training split), normalized to median control library sizes and  log 1 p  transformed. Gene selection prioritized perturbed genes and top 20 marker genes of the perturbations. Norman et al. recorded the single-gene perturbations underlying most double-gene perturbations, which enabled us to classify gene pairs into GI categories by comparing the single and double postperturbation means ( SI Appendix ). GI metrics computed on the 1,000 selected genes correlated with those computed on the full gene set ( SI Appendix , Fig. S3 ). We therefore determined thresholds for GI types based on the classifications of the original study ( SI Appendix , Fig. S4 ). We also performed experiments on perturbation data generated by linear systems ( Fig. 3 ). Here, we observed samples  x ∼ p ( x )  directly rather than first inferring  p ( x )  from counts  y ∼ p ( y ∣ x ;   π )  (Eq.  2 ). For each evaluation setting, we randomly generated ten linear systems (Eq.  3 ) with different parameters  A , b  and then sampled single-gene perturbation data from the systems’ stationary distributions using one-sparse shift vectors  c q . Specifically, we sampled  A ∼ Unif ± ( 1 , 3 )  and  b ∼ Unif ( − 3 , 3 ) , where  Unif ±  denotes a uniform distribution with random signs, masked  A  by random Erdős-Rényi and power-law sparsity structures, and then shifted the masked  A  by a constant diagonal to ensure stability with a maximum eigenvalue of  − 0.5 ( 31 ). Erdős-Rényi structures contained independently sampled nonzero entries (10 per gene in expectation) ( 76 ), and power-law structures were randomly generated with few regulator genes and many downstream genes (Barabási-Albert preferential attachment with strength 2 and 10 links per gene, orientation flipped with probability 0.1 to create feedback loops) ( 77 ). Each perturbation  c q  targeted a unique gene  g  with on-target shift  [ c q ] g ∼ Unif ± ( 5 , 15 )  and zero entries otherwise. The simulated datasets contained 200 samples per perturbation. Metrics. For benchmarking, each method generated  1 , 000  samples per test perturbation  Fig. 2 . We computed MMD using a squared exponential kernel  k ( y , y ′ ) =   exp ( − | | y − y ′ | | 2 2 / 2 d γ 2 ) , averaged over 10 length scales  γ ∈ [ 0.01 , 10 ]  in geometric progression ( 20 ). We also calculated RMSE and Pearson correlation between the predicted and observed means. For Pearson correlation ( Δ ), we subtracted the perturbed centroid (average of all observed perturbation means) from both the predicted and observed means ( 52 ), rather than the control centroid ( 19 ,  21 ), to adjust for systematic variation. We identified the top 20 differentially expressed (marker) genes relative to control using Mann–Whitney  U  tests with BH correction. Metrics were computed on normalized counts (library size  10 4 ,  log 1 p  transformed). An explicit definition of the empirical MMD is given in  SI Appendix . For evaluating CLIPR, we computed the accuracy of  A ^ λ  relative to the ground-truth  A  by classifying the predicted effects into positive, negative, and absent using the thresholds  ± 0.5 Fig. 3 . We reported one-vs.-one AUROC scores averaged over the three class pairs, using predicted effect strength as confidences, which is insensitive to class imbalance ( 78 ). We calculated the F1 score for the three-class setting by averaging the scores predicted for each label. All metrics excluded the diagonals of the causal effect matrix (self-links).
