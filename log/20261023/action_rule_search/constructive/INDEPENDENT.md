## Specific operation examined

Application: transfer a drug decision across molecular contexts when inhibiting target activity is a different operation from lowering the target's RNA. A transcript-edit world may predict the wrong drug action even if its transcript dynamics are accurate. The single candidate I can specify is **shared-target, action-only functional calibration**. It freezes the learned cell dynamics and observation/readout maps during sparse drug feedback, updating only an independently anchored actuation vector, then reuses the same target calibration across new chemical implementations.

Let the dynamics be dx/dt = f_theta(x) + B_theta(x) a_d(c; kappa), where a represents measured fractional target activity changes, not target RNA. Let P_j(kappa) be the later functional prediction for an already revealed support condition j. For drug d, define a_dk(c) = -q_dk c/(K_dk+c) for an inhibitory target k; K is a drug-specific engagement scale, q is the context-dependent inhibited fraction. Do not infer inhibition direction, intracellular concentration or complete target coverage merely from a target annotation. The proposed update holds theta fixed and estimates a small target calibration xi from support activity and function:

xi_new = argmin_xi sum_j [y_j-P_j(xi)]^2 / sigma_j^2 + sum_m ||a_observed,m-a_model,m(xi)||^2_W + lambda ||xi-xi_source||^2.

The restriction is genuinely different from unconstrained whole-world retraining: the source-shared cell law is frozen, only specified action coordinates can move, and target engagement anchors their scale. This is a possible beneficial biological prior and finite-feedback estimator. It is **not rejected merely because a local solver is Gauss–Newton or the loss has a standard regularizer**. A faithful ordinary comparator must obey the same source/feedback permissions and receive the same activity measurements. Whole-world refit need not produce the same finite-budget predictions.

Nevertheless I cannot nominate the present specification as a distinct research core. The saturating action parameterization is conventional pharmacodynamics/input calibration. There is no new transport rule for xi, no demonstrated repeated error attributable to actuation in our strong functional controls, and no authenticated input that would justify sharing q across contexts/compounds. Saying a target is shared does not establish identical fractional inhibition, off-targets, or downstream target-to-function gain. A new restriction might eventually supply novelty; this one merely states known action semantics plus sparse parameter fitting. Searching lambda, action ranks, dose families or nonlinear heads on stopped outcomes is not an admissible repair.
