## Exact faithful ordinary comparator

For scalar p,r and tau>0, min_delta (r-p delta)^2 + tau delta^2 subject to -b<=delta<=b has unconstrained optimum p r/(p^2+tau) and constrained optimum clip of that quantity. The Hessian is 2(p^2+tau)>0. Thus the API's exact finite operation is a standard box-constrained scalar ridge/linearized least-squares solve. This comparator is specified independently from its proposed joint E,h union-refit loss; it does not copy the candidate and merely give it another name. It also freezes E,h and is a legitimate same-information direct calibration baseline.

Frozen state, one scalar and an externally justified bound could still be a useful biological restriction or efficient estimator. Ordinary GN/ridge ancestry does not itself disprove biological usefulness or every possible algorithmic contribution. The API presently supplies no distinct biological rationale for its particular bound and no measured recurring error. Its joint-refit straw alternative is not an exhaustive strong direct/refit comparator: a direct model can retain frozen RNA state and refit only its scalar/functional head.

## Bound and inheritance issues before numerical result access

With sigma in functional-output units, p and r scale together under output conversion by c. tau=sigma^2/n scales as c^2, so unconstrained p r/(p^2+tau) is invariant. b=sqrt(2 sigma^2 log(1/epsilon)/n) instead scales as |c| although delta is an action coefficient. The clipping can therefore change the action when only output units change. This does not deny that unit-dependent numerical recipes can empirically work; it defeats an intrinsic dimensionless action-confidence interpretation without a reference scale.

At fixed nonzero physical correction and finite fixed sigma, b tends to zero with n. The literal one-shot correction centered on alpha=1 thus tends to zero even with perfect convergence of measured residual to a nonzero signal. A confidence radius around a progressively estimated mean would behave differently, but is absent. Sequential accumulated steps, adaptive rescaling or a fixed physical bound would be different candidate specifications, not a retroactive reading of this formula.

The claimed inherited prior N(delta_i,s_i^2+kappa) does not enter the next-task update. For linear Gaussian support mean with variance v=sigma_j^2/n_j and prior N(m,v0), posterior mode before box restriction is (p_j r_j/v + m/v0)/(p_j^2/v+1/v0), expressed in matching residual coordinates. The API formula lacks m and v0, so different inherited means yield the same update at identical support. Merely storing or sampling a prior does not show that the specified estimator uses it. The s_i formula is not justified as a coherent posterior for the stated ridge prior either; avoid inventing an unstated Bayesian model to repair it.

## State/action semantics

It says alpha multiplies known outgoing receptor activity influences in a GRN, yet x1=x0 exactly. If those influences belong to the generator producing RNA state, this is not a self-consistent resimulation of that state. It could instead be a separate functional branch conditioned on a frozen observed state; that is coherent as conditional prediction, but must be declared. Calling that branch an action intervention does not authenticate receptor activity or drug effect. Identical recorded RNA after update is guaranteed by freezing and is not independent evidence of biological state preservation.

The simple a=1,E=.9,y=1.2 example silently uses zero/no effective regularization and inactive bound to assert delta=.333. Positive sigma and finite n need not yield that number. A chosen whole-world refit moving E is only one possible solution, not proof that every ordinary direct method corrupts state.

## Function, transfer and RSI

The proposed Norman growth endpoint is explicitly HYPOTHESIS in the API. Existing actual functional target names and normalization must be verified before relabeling any function as growth/fitness. A scalar per single perturbation also supplies no specified rule for composing calibrations into unseen double perturbations. No new labels should open under this unsupported pilot contract.

E0/E1 x updater-on/off may separate predictor changes and a fixed-updater interaction if task splits/budgets are honest. It is **not** an improved-improver test: it does not compare old/new proposal strategies generating descendants from the same initial updater at equal historical and total costs. Literal copying of delta across a changed E also changes p and units of effect; transfer is a hypothesis, not established.

Initial decision: STOP literal bound/inheritance specification as a new core, subject to saved-result arithmetic confirmation. Do not reject all structured action-only updates. A corrected ordinary estimator remains a possible baseline, not evidence this actual API candidate passed. No biological fit, source expansion or editor follows merely from synthetic consistency.
