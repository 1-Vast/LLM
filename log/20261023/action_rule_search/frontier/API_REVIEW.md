# Independent post-seal API review

Read api/PROPOSAL.md only after frontier INDEPENDENT_SEAL.json existed. Review is analytic, no new numerical run.

The API's specific operation has a concrete ordinary competitor without changing molecular state: fit a one-coefficient functional calibration on fixed source features. For scalar sensitivity p and residual r, minimize (r−pδ)²+τδ² over −b≤δ≤b. If p²+τ>0, completing the square gives unconstrained optimum pr/(p²+τ); Euclidean projection onto the scalar interval yields exactly its clip. This is ordinary bounded ridge, not an invented all-weights union-refit comparator or a universal claim about arbitrary algorithms. Such a comparator has the same single coefficient, observations and cost scale, and also freezes E/state. A whole-world refit is an additional comparator, not the only direct competitor.

Other testable issues:

- Dimensional consistency: δ is dimensionless, r and σ have functional output units, p has output per δ. Numerator/denominator in ridge fraction scale consistently when r,p,σ all rescale, but proposed b has output units and scales with output normalization. Thus clipping is not output-unit invariant without a separately justified conversion. A trust-region radius need not be invariant if consciously defined in calibrated physical units, but that calibration is absent.
- For fixed σ>0,epsilon in(0,1), b→0 as n→infinity; therefore every update δ→0 even with fixed nonzero true correction. This radius treats shrinking estimation uncertainty as shrinking effect size. This is a defect for estimating nonzero fixed action correction, not a proof every small-step online procedure is inconsistent: repeated accumulation or reference recentering could change the procedure, but neither is stated.
- If state E(i) and h are literally fixed and alpha has no separate path, derivative p is0. A separate functional actuation path can make p nonzero while reported RNA remains fixed; then the claimed GRN-actuation semantics and unchanged state need an explicit architecture. Do not declare p universally0; the API's notation is under-specified.
- Prior inheritance is declared N(delta_i,s_i²+kappa), but its mean/variance do not enter the stated new-task numerator/denominator. Reusing a prior only in prose does not create operational inherited updates. A correct ordinary Bayesian/MAP calibration would explicitly add prior precision and prior-mean terms.
- Its .9,.3 toy gives correction1/3 only when ridge penalty is0 and bound nonbinding. The proposed generic formula has positive tau if sigma>0,n finite; the stated exact result is not a generic consequence.
- Pair/holdout folds in one K562 setting are not independent later tasks for inherited improvement; perturbation fitness labels and single-to-double alpha transport are not authenticated by the API's HYPOTHESIS. No biology label access is warranted to repair these missing specifications.

Decision: no qualified new core from current formula; root's frozen scalar tests can check the two unit/asymptotic issues. This critique does not show every actuation-only biologically constrained update is equivalent at finite budget or cannot improve a drug decision.
