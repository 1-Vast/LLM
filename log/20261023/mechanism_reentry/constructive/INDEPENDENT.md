## scBalFlow rules out one tempting repackaging

Its input is drug fingerprint + dose + matched-control mean expression. Stage1 predicts condition-level Rsim2 between mean control and perturbed profiles using a residual MLP and imbalance-adjusted GAI loss. Stage2 routes strong-response conditions into a Gaussian-noise-to-expression flow model and weak ones into sampling matched controls. **Training uses the real response-similarity target for routing; inference uses its predicted value.** The two stages do not share encoder parameters. This is an explicit ordinary response-mixture comparator for any claim that selectively invoking the virtual cell only on important perturbations is new. It is not a sequential functional-feedback update procedure or measured update-utility supervision.

Actual named resources are SciPlex3, McFarland and ComboSciPlex; paper code link is https://github.com/hanwenlv-cmd/scBalFlow. No release/partition/functional-count join was authenticated here. RNA distribution/mean accuracy is its stated output, not demonstrated live-cell benefit. Adding an RSI wrapper to this route does not supply a new update law.

## ARTEMIS: an operationally different feedback object worth examining, but not promoting

The original has a real mass-changing mechanism beyond ordinary expression regression: encode timepoint expression with a VAE; fit forward/backward stochastic bridges; add birth/death jumps to a cemetery state; match observed marginal distributions and timepoint population changes; jointly train latent dynamics/reconstruction with Wasserstein losses. The output includes expression trajectories and modeled cell-status variables. Forward/backward marginal matching is IPF, explicitly identified as a dynamic Sinkhorn procedure. It is not recursive self-improvement of the research program.

Crucial primary Methods2.3 text: the paper assumes collected cell number nt represents relative cell population and sequencing-related incomplete sampling is negligible. Its prior kill rate is the fraction of features deviating by more than two standard deviations from the next measured timepoint's mean; below20% deviating features it is set to zero. Thus its population target and state-death prior are **observational construction assumptions**, not independent measured cell viability. This is a concrete reason not to cite inferred live/dead trajectories as verified functional feedback.

Notation requires care. Equation7 writes the posterior as k(z,t)Kω(t); Equation11 writes Kω,t(z). The article therefore does not unambiguously establish whether the implemented correction is time-only or state-dependent. I did not download implementation files beyond README and cannot claim that state-specific corrections are structurally impossible in their code. Even with a state-dependent multiplier, aggregate counts constrain an integral of survival, not a unique state-specific killing field without additional state-resolved observations/restrictions. This is a precise identifiability issue, not a blanket impossibility claim about learned priors.

Bridge boundary distributions include the measured final state. Improving an unmeasured intermediate snapshot between supplied endpoints is interpolation; it cannot be sold as forecasting an unseen drug endpoint unless the endpoint is removed from the conditioning/training contract. Relabeling chronological timepoints as consecutive integers, described in Methods2.6, also requires scrutiny if claiming time/dose generalization.

## One considered operation and why it does not receive GO

Considered operation only, **not a nominated new core**: freeze a source-trained state-transport model and update only an intervention-conditioned state-survival field using paid, orthogonal state-resolved live counts under a new drug. Propagate the surviving state measure to future time/dose/combination queries. Inputs would be baseline state distribution, named intervention/time, fixed transport and a whole-assay package of matched untreated/treated state-resolved live counts; output an updated finite live-state measure and future functional predictions. Inherited object would be the restricted update rule/representation, not one task's updated parameters.

Drug application would be predicting persister-subpopulation burden after anti-cancer exposure and nominating exposures that suppress surviving states. It might outperform a direct scalar endpoint predictor if independently validated transport and stable state-specific survival constraints enable useful sharing across sparse times/interventions. That is a conditional hypothesis, not evidence the factorization is true or that expression motion determines survival.

Why no executable candidate: the authenticated ARTEMIS resources are pancreatic differentiation GSE114412, zebrafish developmental data (article/README inconsistently print SCP126 versus linked SCP162), and A549 TGFB1 EMT GSE147405 / https://github.com/dpcook/emt_dynamics. They authenticate transcriptomic chronology at source level, not matched orthogonal state-resolved live counts under a multi-drug prospective assay. scBalFlow resources supply drug-perturbed expression, without a newly authenticated state/count/independent-task join in this pass. Prior AML identity remains localSTOP; no source is silently reused to fill this gap. I cannot currently name a verified available feedback package that tests the proposed survival-restriction law.

Moreover replacing sampled nt with true live counts is improved measurement, not automatically a new updater. With fixed transport and a constrained survival field, common multiplicative density reweighting, constrained likelihood, reaction-transport inference or unbalanced transport can implement the same operation. If inputs, constraints, objective and solver match pointwise, that is operational equivalence: no separate updater advantage can be claimed. A valuable new, empirically supported biological restriction could still count, but none has been established here. Hence do not nominate a renamed survival gate or ordinary mass correction.
