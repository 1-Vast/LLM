## What the original method actually learns

MLExpert groups all model decisions between successive experiment results into a window. Its reward combines submission tier/error status with local trend T in {-0.2,0,0.2} relative to the previous valid submission. All main-model tokens in the window receive this common weight, not group-relative normalization. It records rollout token log probabilities and corrects stale-policy probabilities with q=exp(logp_old-logp_roll), retaining only a fixed ratio interval; the token correction is not a full-trajectory importance ratio. A PPO-style objective, per-window token normalization, fixed-reference KL and entropy regularization train the agent. It learns long-horizon experimentation policy, not simply predictor weights.

Consequently “train the research agent from intermediate experiment outcomes,” “put credit at experiment boundaries,” or “inherit how to optimize” already have a precise direct precedent. A cell-specific task name or swapping medal score for AUC does not distinguish an operation. WIRL's previous-submission trend is nevertheless not an identical same-snapshot causal edit comparison; the proposal below differs in that narrow construction, while ordinary paired policy gradient remains an exact counterpart.

## Precise attempted procedure

Let p be an executable update program U_p mapping current predictor/fast optimizer state plus a newly acquired intervention/function feedback record to the next predictor/state. A program edit must change how later observations are processed; adding a frozen residual head or retaining its coefficients does not qualify. Let G_psi(e|p,H) be a trainable editor policy over permitted finite AST rewrites of U, with a bounded emitted-program/runtime budget. Such an editor could be a small categorical rewrite policy; no inaccessible fine-tuning of a proprietary API is assumed. The details of a scientifically useful edit grammar have not been discovered here; unrestricted code generation is not a substitute for them.

For each lawful source training episode, freeze base model theta, optimizer fast state, p, past history H, support observations S and future query Q before proposing an edit. Sample e from G_psi and generate p_e. Both p and p_e start from the same theta/fast state and consume exactly the same revealed S in the same actual sequence. Score their resulting predictors on the same actual held-out functional Q; neither sees Q as update input. The two arms share random draws where this is semantically valid. Define loss lower-is-better and a fixed total execution-cost accounting:

    Delta(e)=L_Q(U_p(theta,S))-L_Q(U_(p_e)(theta,S))
             -lambda_cost*(cost(p_e)-cost(p)).
    psi_new=psi+eta*Delta(e)*grad_psi log G_psi(e|p,H).

No threshold or score-scale is selected from the current episode. An invalid edit receives a predeclared failure score with actual consumed cost retained. Shared query labels are charged computational uses of released source assays, not free new wet experiments. All two-branch evaluation and generation cost must be charged; one cannot claim a doubled simulator evaluation is equivalent to one run merely because it uses the same purchased assays. Evaluation at an independent later episode freezes psi before its outcome.

This differs from the particular WIRL local reward: high absolute performance of an unchanged updater gives zero Delta, and unedited baseline performance is computed from the *same* snapshot/support rather than the immediately preceding run with potentially different model/data. This is a precise difference, not a claim that WIRL cannot be adapted to it.

## Exact ordinary counterpart and finite-cost hypothesis

For fixed p,H,S,Q the baseline arm does not depend on sampled e. Therefore the expected gradient of its reward term is zero:

    E_e[B*grad log G(e)]=B*grad sum_e G(e)=0.

The estimator is **exactly REINFORCE with an action-independent baseline/control variate**. An ordinary paired optimizer-program search policy with the same edit grammar, starting policy, observations and evaluations executes every step identically. Subtracting unedited validation loss, common random numbers, evolutionary paired comparisons, and retaining successful edits do not supply a separate algorithm invention. This is a constructive same-operation equivalence, not a claim that any member of meta-learning/search is prohibited.

A potential finite-resource benefit relative to *unpaired* absolute-return credit is reduced nuisance variability. If candidate and reference losses have variances v_e,v_0 and covariance c, paired-difference variance is v_e+v_0-2c. It helps only with adequate positive covariance and after charging the reference evaluation. Negative covariance, evaluation overhead or deterministic cheap objectives may remove any benefit. An ordinary same-paired policy-gradient/search control gets exactly that advantage too.
