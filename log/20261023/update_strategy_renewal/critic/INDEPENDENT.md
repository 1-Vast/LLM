## Concrete candidate and purpose

Candidate: improve how updater-program search avoids paying repeatedly to evaluate operationally duplicate candidates. Fix common predictor theta0, dynamics/noise prior, feedback history H, candidate grammar and candidate proposal stream. A program U changes the predictor after H; expensive fitness is its subsequent actual functional error. A cheap semantic witness is a fully specified algorithm input (theta,H,query), used only to test U's computation. Synthetic witnesses are software tests, never real-cell feedback or evidence of biological utility.

G_D computes sigma_D(U), the vector of post-update query predictions on a small retained witness suite D. It sends one representative of each proven equivalent behavior class to the full functional evaluator and reuses that result for duplicates. New counterexamples distinguishing formerly colliding programs refine D. For a restricted algebraic grammar, two signatures can carry an exact coefficient/equivalence certificate; for unrestricted neural/code programs, a finite test suite is not a proof and collision alone must not discard a candidate as universally duplicate. A separately specified risk/cost argument would be required for approximate pruning.

The potentially useful restriction is operational semantics of updating under *different histories*, rather than source-code strings, fitted model weights or current zero-shot predictions. It could reduce redundant ordinary optimization before any new biological assay is purchased. It is not an assertion that current MAESTRO proposals have sufficient duplicate cost or that this abstraction alone is novel.

## Genuine improvement-strategy test, not memory/prior relabeling

U is the update program. D is inherited test experience; storing D alone is experience reuse, not proof that the improver improved. To test changed improvement strategy G, learn a test/probe-selection or equivalence-check ordering policy pi from earlier source program-search episodes, then compare G_pi1 with original pi0 from the same starting U, theta0, prior, D/history, candidate stream and total cost on later tasks. Both receive the same experience. Measure validated future functional improvement versus total search/evaluation cost, with false-prune/lost-best-program rates. Policy learning, failed proposals, certificate tests, full validations and LLM calls all count. A changed suite without a changed strategy does not establish Level3.

Strong ordinary opponents: source-trained direct episodic prediction and joint/refit updaters under the same acquired history; naive program search with exact source/AST memoization; algebraic/e-graph canonicalization; differential-testing/CEGIS with fixed or greedy informative witness selection; randomized retained tests; Bayesian optimization or ordinary learned proposal/ranking policy; equal-total-budget program search with the same inherited archive and feedback. In particular, do not deny the conventional search access to D or charge full true evaluation to an exact duplicate it could canonically identify. Generic CEGIS or learned evaluation scheduling may implement the whole operation; family membership alone is not the objection—the exact arithmetic counterpart already does.

Source-only mathematical tests can begin without a complete RSI dataset. A first necessary test would use a frozen non-biological updater grammar and explicit subsequent-history semantic counterexamples, measuring true-equivalence pruning and total compute versus ordinary canonicalization/CEGIS. Only if that mechanism has a distinct measured resource advantage is a real functional-research search justified. No such advantage is established here. No existing stopped biological panel becomes a fresh later task through a new seed or chronology label.

## Biological/world-agent contribution remains separate

Eventual application is cheaper search for update procedures that improve later measured intervention responses. Full fitness must be actual lawful functional query outcomes, not world-generated scores, passed only at permitted stages. A world-model program and direct predictor program may both be searched; the semantic deduplication mechanism itself supplies no reason the world is necessary. Agent utility would be the search/evaluation decision rule's incremental functional efficiency; updater inheritance would compare changed U on later tasks; improved-improver would additionally compare pi1/pi0under the common-start controls above. These require separate evidence and cannot be inferred from software test savings.
