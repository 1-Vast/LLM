# 决策：停止固定合并事件更新配置

2026-10-23。目标仍为 ACTIVE / NOT_ACHIEVED。本轮完成一次冻结后的真实数据数值实验，不重复拟合或挽救已失败配置。

应用：在重复 TRAIL 与 TRAIL/TBQ 交替处理下，用已测早期染色面积密度预测后续群体端点。数据为 Peyre et al. (2025), DOI 10.1038/s44320-025-00150-0，固定仓库提交及两个原始文件见 PROTOCOL.md/FREEZE.json。不同时间牺牲不同培养皿，不是同皿轨迹；文件编号不保证独立培养。测量不是细胞计数、死亡概率或 CTG。

两方向来源文件全曲线与目标文件 0/24/48h 前缀用于预测 72/96h，九种固定普通方法均获得相同合法信息。所有预测先保存封存再评分。但两文件互为来源，全部数值已物化，因此只是相关开发交叉验证，不是安全盲测或新任务库。

| 方法 | 总体 MSE | 总体 MAE |
|---|---:|---:|
| 持平 | 10.43389725 | 2.533 |
| 最近区间外推 | 8.137049875 | 2.324125 |
| 来源残差趋势 | 7.760021507 | 2.584875 |
| 来源事件均值 | 196.869091622 | 13.155479167 |
| 合并事件重拟合 | 340.509243562 | 17.412611111 |

预设门槛要求合并重拟合在每个目标文件×处理组均严格胜过来源事件模型与持平。四组全部失败，八个合并预测均为负而真值为正。决定 STOP_THIS_FIXED_POOLED_EVENT_UPDATE_CONFIGURATION。保留负预测和原损失，不截断、不删首区间、不调整权重、不增加阶段或潜状态挽救。

合并事件模型在结果前已被证明严格等于来源事件预测与目标前缀事件预测的 2/3、1/3 固定混合；即便有效，也不构成新的更新算子。大幅首轮下降混入固定加性事件效应，与后续小幅变化不适配；这说明该统计限制失败，不能识别细胞耐受、密度效应或测量因素。两个处理组的前两项原始 token 完全相同，不能凭此推断同皿或独立反馈数。

普通方法有有限效用，但没有一致赢家。残差趋势平均 MSE 最低，MAE 却劣于持平，在两方向交替组也均劣于持平。互换方向的来源曲线、偏移和残差趋势误差具有反号代数对称，相同 MSE 不是独立重复验证。此数据上选出的最小平均值不能升级为稳定可复用规律。

独立来源审计直接读取 raw OOXML、以 Decimal 重建九种方法：418 项数值核对通过，最大差约 6e-13；批判审计从合法存储对象核对 378 项，最大差约 5.68e-14。双方封存后实际互读并回应了分组反例、MAE 反例、重复首轮 token、代数对称和机制不可辨识问题。报告与交叉质疑见 source/RESULT_AUDIT.md、source/RESULT_CROSS.md、critic/RESULT_REVIEW.md、critic/RESULT_CROSS.md。它们是互补审计，不是第二次生物实验。

主实验 Python 3.11.16，记录墙钟 0.0383214 秒、退出码 0、stderr 空；CPU 时间未单列。隔离合成测试两项通过。本阶段没有新网络 GET、DeepSeek API、GPU 或湿实验；代理底层身份、token 和货币成本不可得，不估造。代码及测试仅在 research/，本阶段记录仅在 log/。

当前世界模型贡献、智能体贡献、更新器继承收益、联合收益、改进策略使后续改进更有效，均 NOT_ESTABLISHED。本阶段不是这些完整主张的公平验证，不能拿普通九方法比较替代它们。

对用户外部建议的核对：先寻找可复用、改善功能或决策的更新规律，而非增加编辑器层级，这一判断成立。但其中 CDK 尚未数值测试的时态已过期；已有 Middle 组成和匹配功能测试未建立稳定联合收益，不能无新证据重新启动同一配置。共享测量误差是合理常规诊断，不是已经发现的新机制；缺少计数或重复时不得臆定噪声协方差。

下一研究入口应先取得能区分适应、密度和测量因素且含独立后续功能响应的证据，再预注册更新规律与强直接预测、普通重拟合等比较。仅修改本已暴露面板的尺度、窗口或阶段划分不足以构成新入口。保留 organoid 数据资产资格核查等未完成线索，不声称已取得可用独立任务。
