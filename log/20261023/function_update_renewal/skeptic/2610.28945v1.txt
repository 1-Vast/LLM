 Self-Improving Agents with World Model Predictive Paths

 Abstract 
    
 Large language model (LLM) agents are increasingly expected to interact with environments and improve their decisions during deployment.
However, how anticipating future outcomes and drawing on accumulated interaction experience can jointly support decision-making remains underexplored.
We propose a test-time framework, inspired by Model Predictive Path Integral (MPPI) control, that combines multi-branch predictive analysis with experience-based adaptation.
At each step, the agent proposes multiple candidate actions and imagines their outcomes with a world model, so that alternatives can be compared without being executed in the environment.
Since language environments provide neither explicit dynamics nor costs, the predicted outcomes are evaluated for task progress and risk, and MPPI-style weights over the resulting costs guide the final decision.
A dual-branch experience memory enables self-improvement: the planner branch refines candidate generation and action selection, while the world model branch improves next-observation prediction.
Experiments on ALFWorld and ScienceWorld across three backbones demonstrate the strong overall performance of our method and the effectiveness of experience-guided predictive control. Our code will be made publicly available. 
  
 
 
 
 
 
 1  Introduction 

 
 Large language model (LLM) agents interact with environments by interpreting observations and taking actions to accomplish tasks.
Long-horizon tasks require them to sustain progress under incomplete observations, where poor decisions can lead to repeated failures or wasted interactions.
Building agents that make reliable decisions over extended interactions therefore remains a central challenge. 
 
 
 Prior work improves interactive decision making in several complementary ways.
ReAct interleaves reasoning with environment feedback  ( Yao et al., 2023b ) , but commits to a single proposed action at each step, which may miss useful alternatives.
Search-based methods instead explore multiple reasoning or action paths at inference time  ( Yao et al., 2023a ;  Zhou et al., 2024 ;  Hao et al., 2023 ;  Liu et al., 2026 ) , but their cost grows with the breadth and depth of the search.
A separate line improves agents through retrieved reflections and trajectory-derived action advantages  ( Shinn et al., 2023 ;  Li et al., 2026a ) .
These directions motivate exploring a few alternatives before acting, without executing them, together with experience gathered through interaction.
This also resembles how people mentally simulate a few alternatives before choosing  ( Gilbert and Wilson, 2007 ;  Vul et al., 2014 ) : the agent imagines the outcomes of several candidate actions  ( Hafner et al., 2020 ;  Gu et al., 2025 ) , which avoids the interaction steps and potential irreversible consequences of trying them in the environment.
Model Predictive Path Integral (MPPI) control offers a concrete recipe for this pattern: it samples a finite batch of candidate trajectories, weights them by predicted costs with exponential (Gibbs) weights, executes only the next action, and replans  ( Williams et al., 2015 ;  Williams et al., 2017 ) . 
 
 
 Language environments, however, provide neither explicit dynamics nor costs.
A language world model can supply the missing dynamics by predicting the outcome of each candidate action  ( Hao et al., 2023 ;  Liu et al., 2026 ;  Zhang et al., 2026 ) , but better next-observation prediction does not necessarily yield higher task success  ( Zhang et al., 2026 ) .
We therefore couple prediction directly with decision making: the agent predicts the outcomes of several candidate actions, an evaluator assigns costs for task progress and risk, and MPPI-style weights summarize these costs for a final controller that selects or synthesizes the action to execute. 
 
 
 To make both the candidates and their predictions more reliable over time, we further introduce a dual-branch experience memory for self-improvement.
The planner branch uses accumulated experience to improve candidate generation and action selection, while the world model branch improves next-observation prediction, so that a single stream of interaction experience improves both what is proposed and what is predicted.
Both branches operate through retrieved textual context, with policy and world model parameters frozen.
Our analysis bounds the agent’s per-step regret in terms of three error sources, namely limited candidate coverage, errors in action selection, and inaccurate next-observation predictions, which motivates the two branches. 
 
 
 Experiments on ALFWorld  ( Shridhar et al., 2021 )  and ScienceWorld  ( Wang et al., 2022 )  demonstrate the strongest overall success-rate performance among the evaluated methods across three backbones.
Our main contributions are: 
 
 •  
 
 We propose a test-time, MPPI-inspired framework that improves a bounded predict–select–replan decision loop with experience: a world model predicts the outcomes of a few candidate actions, and a dual-branch memory improves both candidate generation and selection and next-observation prediction. 
 
 •  
 
 We provide a theoretical analysis showing that the weighting rule is optimal under a KL-regularized objective, and that the per-step regret is bounded in terms of candidate coverage, action selection, and next-observation prediction errors, which motivates the two memory branches. 
 
 •  
 
 Experiments on ALFWorld and ScienceWorld across three backbones demonstrate the strongest overall success rate performance among baselines. We also provide ablation studies and a computational cost analysis. 
 
 
 
 
 
 2  Related Work 

 
 LLM agents. 

 
 LLM agents choose actions from textual or visual observations  ( Wu et al., 2025a ;  Wu et al., 2025b )  in a loop.
ReAct  ( Yao et al., 2023b )  and SayCan  ( Ahn et al., 2022 )  ground actions in environmental feedback or available skills, ADaPT  ( Prasad et al., 2024 )  decomposes tasks, and further methods support lookahead through branching or retrieved information  ( Yao et al., 2023a ;  Zhou et al., 2024 ;  Koh et al., 2024 ;  Holt et al., 2026 ) .
In traditional control, a related perspective also uses lookahead: model-predictive control  ( Camacho and Bordons, 2007 )  plans over a finite horizon, executes only the first action, and replans from the new observation.
MPPI further weights sampled trajectories by their predicted costs  ( Williams et al., 2015 ;  Williams et al., 2017 ) .
We adapt MPPI’s strategy of predicting and weighting multiple candidates to language agents through world model prediction, replacing its continuous control update with a discrete action update driven by language models, and thus call our framework MPPI-inspired. 
 
 
 
 World models for agent planning. 

 
 World models can estimate how actions change an environment before they are executed.
Dynalang  ( Lin et al., 2024 ) , RAP  ( Hao et al., 2023 ) , WebDreamer  ( Gu et al., 2025 ) , and IMPLEMENT  ( Song et al., 2026 )  simulate action outcomes with language-based or lightweight world models; while ITP  ( Liu et al., 2026 ) , WKM  ( Qiao et al., 2024 ) , and WorldEvolver  ( Zhang et al., 2026 )  add adaptive lookahead, structured knowledge, or retrieved experience.
Qian et al.  ( Qian et al., 2026 )  and Li et al.  ( Li et al., 2026b )  study how well agents use forecasts and whether LLMs can serve as text-based world models.
More recently, MemWM  ( Wang et al., 2026 )  trains a world model with offline-built memory to evaluate the candidates.
Unlike them, we keep all models frozen and use experience gathered during interaction in two branches that improve next-observation prediction and candidate generation and selection. 
 
 
 
 Self-improving agents. 

 
 Experience-based methods improve later decisions by retaining information from prior interactions, building on memory systems  ( Park et al., 2023 ;  Packer et al., 2023 ;  Chhikara et al., 2025 ;  Xu et al., 2025 ;  Sumers et al., 2024 ;  Hu et al., 2025 ;  Gao et al., 2025 ;  Liu et al., 2023 ;  Liu et al., 2024 ;  Lu et al., 2026 ) .
Reflexion  ( Shinn et al., 2023 ) , ExpeL  ( Zhao et al., 2024 ) , ERL  ( Allard et al., 2026 ) , and ReasoningBank  ( Ouyang et al., 2026 )  distill feedback or trajectories into experience, Voyager  ( Wang et al., 2024 )  and AWM  ( Wang et al., 2025 )  retain skills or task procedures, AdaPlanner  ( Sun et al., 2023 )  and JitRL  ( Li et al., 2026a )  revise plans or action preferences from retrieved experience, and Memento  ( Zhou et al., 2025 ) , ACE  ( Zhang et al., 2025 ) , and Dynamic Cheatsheet  ( Suzgun et al., 2026 )  adapt through episodic memory or evolving contexts instead of fine-tuning  ( Wu et al., 2026 ) .
These methods improve what the agent proposes; our dual-branch memory also improves what it predicts, so a single stream of interaction experience sharpens both the candidates and the forecasts used to choose among them.

 3  Problem Formulation 

 
 We consider a language agent solving a long-horizon interactive task with goal  g g  and an interaction budget of  T T  steps.
At step  t t , the agent receives an observation  o t o_{t}  and has interaction history  h t = ( o 1 , a 1 , … , o t − 1 , a t − 1 ) h_{t}=(o_{1},a_{1},\ldots,o_{t-1},a_{t-1}) .
It acts from context  x t = ( g , h t , o t ) x_{t}=(g,h_{t},o_{t}) . Its policy  π ( ⋅ ∣ x t ) \pi(\cdot\mid x_{t})  defines a distribution over language actions, and the action at step  t t  is generated according to: 
 

 
 
 a t ∼ π ( ⋅ ∣ x t ) , a t ∈ 𝒜 . a_{t}\sim\pi(\cdot\mid x_{t}),\qquad a_{t}\in\mathcal{A}. 
 
 (1) 
 
 
 
 After  a t a_{t}  is applied, the environment generates the next observation according to: 
 

 
 
 o t + 1 ∼ P env ​ ( o ′ ∣ h t , o t , a t ) . o_{t+1}\sim P_{\mathrm{env}}(o^{\prime}\mid h_{t},o_{t},a_{t}). 
 
 (2) 
 
 
 
 Our objective is to maximize the probability of completing the task within the interaction budget: 
 

 
 
 π ⋆ = arg ⁡ max π ⁡ Pr ⁡ ( success by  ​ T ∣ g , π ) . \pi^{\star}=\arg\max_{\pi}\Pr(\text{success by }T\mid g,\pi). 
 
 (3) 
 
 
 
 In control, Model-Predictive Control (MPC) plans over a finite horizon  H H  by selecting the candidate action sequence  𝐚 = ( a t , … , a t + H − 1 ) \mathbf{a}=(a_{t},\ldots,a_{t+H-1})  with the lowest expected predicted cost: 
 

 
 
 𝐚 ⋆ = arg ⁡ min 𝐚 ​ J ¯ t ​ ( 𝐚 ) , \mathbf{a}^{\star}=\arg\min_{\mathbf{a}}\bar{J}_{t}(\mathbf{a}), 
 
 (4) 
 
 where  J ¯ t \bar{J}_{t}  is the expected cost of the model-predicted trajectory  ( Camacho and Bordons, 2007 ;  Rawlings et al., 2017 ;  Li et al., 2019 ;  Li et al., 2020 ;  Zhang et al., 2021 ;  Li et al., 2021 ) .
MPC executes only the first action and replans after the next observation.
Model Predictive Path Integral (MPPI)  ( Williams et al., 2015 ;  Williams et al., 2017 )  approximates this search by sampling candidate trajectories and favoring those with lower predicted costs with Gibbs weights.
This predict-and-replan cycle suits our agent tasks, where each action shapes later decisions.
Inspired by MPPI, we develop a test-time framework for language agents that uses a world model to evaluate multiple candidate actions and guide decision-making.
The next section presents our method in detail. 
 
 
 
 4  Method 

 
 We first describe the test-time loop: a world model predicts outcomes for up to  K K  proposed actions, and MPPI-inspired weighting of task-conditioned costs guides a final controller to select or synthesize an action before replanning from the new observation.
We then describe how dual-branch experience memory improves planning and grounds future forecasts. 
 
 
 4.1  MPPI-Inspired Decision Loop 

 
 At time step  t t , the agent receives the goal, interaction history, current observation, and action protocol.
Let  M t P M_{t}^{\mathrm{P}}  denote the planner experiences retrieved for this decision, which will be introduced in Sec.  4.2  in detail.
The proposal module first reasons over the context, and then emits up to  K K  atomic candidate actions.
The resulting candidate set is represented as: 
 
 
 
 
 𝒜 t \displaystyle\mathcal{A}_{t} 
 = { a t ( k ) } k = 1 N t , \displaystyle=\{a_{t}^{(k)}\}_{k=1}^{N_{t}}, 
 1 ≤ N t ≤ K , \displaystyle 1\leq N_{t}\leq K, 
 
 (5) 
 
 
 a t ( k ) \displaystyle a_{t}^{(k)} 
 ∼ q π ​ ( a ∣ x t , M t P ) , \displaystyle\sim q_{\pi}(a\mid x_{t},M_{t}^{\mathrm{P}}), 
 k = 1 , … , N t . \displaystyle k=1,\ldots,N_{t}. 
 
 
 
 
 Here  q π q_{\pi}  denotes the proposal policy,  K K  is the maximum number of candidates, and  N t N_{t}  is the number generated at step  t t .
This adapts MPPI’s candidate sampling to language actions: instead of adding perturbations to a continuous control sequence, the proposal policy generates candidate actions that could advance the task, gather information, or recover from failures. 
 
 
 Next, for each proposal, the world model receives the goal, current observation, candidate action, and retrieved world model memory  M t world M_{t}^{\mathrm{world}} . 
 
 
 It predicts a one-step textual observation of the action’s immediate consequence: 
 

 
 
 o ^ t + 1 ( k ) ∼ P ^ ​ ( o ′ ∣ g , o t , a t ( k ) , M t world ) . \hat{o}_{t+1}^{(k)}\sim\hat{P}(o^{\prime}\mid g,o_{t},a_{t}^{(k)},M_{t}^{\mathrm{world}}). 
 
 (6) 
 
 We use one-step prediction rather than multi-step rollouts to simplify the architecture and control computational cost.
We denote the resulting candidate-specific imagined transition by 
 

 
 
 τ ^ t ( k ) = ( g , h t , o t , a t ( k ) , o ^ t + 1 ( k ) ) , \hat{\tau}_{t}^{(k)}=(g,h_{t},o_{t},a_{t}^{(k)},\hat{o}_{t+1}^{(k)}),

 which bundles the task context, proposed action, and predicted outcome used to evaluate that candidate.
In classical MPPI, candidate trajectories are evaluated by a numerical cost function.
For language agents, we instantiate this cost-evaluation stage through textual outcome prediction and evaluation of task progress and risk.
A language evaluator maps each imagined transition to a bounded predictive cost: 
 

 
 
 C t ( k ) = C ψ ​ ( g , h t , o t , a t ( k ) , o ^ t + 1 ( k ) ) ∈ [ 0,100 ] , C_{t}^{(k)}=C_{\psi}(g,h_{t},o_{t},a_{t}^{(k)},\hat{o}_{t+1}^{(k)})\in[0,100],

 4.2  Dual-Branch Experience Memory 

 
 The weighting in Proposition  1  depends on both the proposed actions and the accuracy of their predicted costs.
It cannot assign weight to a useful action absent from the candidate set, and inaccurate forecasts can favor unsuitable candidates.
Moreover, optimal candidate weights do not guarantee an optimal final action, since action selection is performed by a separate controller.
Our dual-branch memory aligns with these limitations: the planner branch targets candidate coverage and final action selection, while the world model branch adapts forecasts to environment-specific dynamics.

Reference costs represent an ideal assessment of actual action consequences, which are not available to the agent.
Taking  a ∘ a^{\circ}  to be a reference-optimal action makes the left-hand side of Eq. ( 18 ) a per-step regret and  Δ t cov ≥ 0 \Delta_{t}^{\mathrm{cov}}\geq 0 . Eq. ( 18 ) separates the limitations above: the coverage gap is positive only when a better action than every candidate exists, and shrinks as better candidates are proposed, while  ϵ \epsilon  decreases with more accurate forecasts and cost assessments.
The selection gap compares the controller’s choice with the weighted candidates: it is negative when the controller corrects inaccurate weights or generates a better action, and positive when it disregards reliable guidance.
This decomposition guides our memory design.
Candidate-generation memories target  Δ t cov \Delta_{t}^{\mathrm{cov}} , final-planner memories target  δ t sel \delta_{t}^{\mathrm{sel}} , and world model memories target  ϵ \epsilon .
Both memory branches update textual memories while keeping the model parameters frozen.

 World model branch. 

 
 For the world model branch, we adopt the episodic and semantic memory design of WorldEvolver  ( Zhang et al., 2026 ) , which we use to reduce the predictive cost error  ϵ \epsilon  in Proposition  2 .
To support prediction for multiple candidate actions, we retrieve relevant transitions separately for each candidate and use them with shared environment rules to predict next observations.
Memory is updated only after real interaction, storing observed transitions and extracting rules from prediction errors.
The implementation details are provided in Appendix  A . 
 
 
 
 
 
 5  Experiments 

 
 5.1  Experimental Setup 

 
 Benchmarks. 

 
 We evaluate our method on ALFWorld  ( Shridhar et al., 2021 )  and ScienceWorld  ( Wang et al., 2022 )  provided by AgentBoard  ( Ma et al., 2024 ) .
Our evaluation includes 134 ALFWorld tasks and 90 ScienceWorld tasks, with each trial limited to 30 environment steps.
ALFWorld is a text-based household benchmark of tasks such as picking up, cleaning, heating, and moving objects, while ScienceWorld is a text-based science benchmark where agents manipulate objects and carry out simple experiments.
Our primary metrics are SR@1, the fraction of tasks solved in a single trial, and SR@5, the fraction solved in at least one of five trials. 
 
 
 
 Baselines. 

 
 We compare our method with multiple baselines.
ReAct  ( Yao et al., 2023b )  interleaves reasoning and action, using environment observations to guide subsequent decisions.
ITP-I, the training-free variant of Imagine-then-Plan  ( Liu et al., 2026 ) , uses adaptive lookahead to imagine future outcomes and guide action selection.
WorldEvolver  ( Zhang et al., 2026 )  represents an evolving language world model pipeline that uses episodic and semantic experience.
All baselines use the same task files and backbone. 
 
 
 
 Implementation details. 

 
 At each step, the agent generates up to  K = 8 K=8  candidate actions and applies MPPI-style weighting with  λ = 10 \lambda=10  to their predicted costs.
Candidate generation and final planning read from the corresponding planner memory bank with capacity  C = 24 C=24  and retrieval count  R = 4 R=4 .
The policy and world model parameters remain frozen during deployment. Following WorldEvolver  ( Zhang et al., 2026 ) , we do not reset memory within each evaluation setting.
World model memory hyperparameters and prompt templates are in Appendices  A  and  D .
We also vary the backbone, evaluating Gemma-4-26B-A4B  ( Gemma Team, 2026 ) , Qwen3.5-9B  ( Qwen Team, 2026 ) , and GPT-5.4-mini  ( OpenAI, 2026 ) , to test generalization across models.
In all tables,  bold  and  underlined  numbers mark the best and second-best results per column, shaded rows are the default setting, and Avg. is the mean over ALFWorld and ScienceWorld. 
 
 
 
 
 5.2  Results 

 
 Results on ALFWorld and ScienceWorld. 

 
 Table  1  compares our method with ReAct, ITP-I, and WorldEvolver on ALFWorld and ScienceWorld across three backbones.
With Gemma-4-26B-A4B, Ours leads on both benchmarks, scoring 65.7/84.3 on ALFWorld and 46.7/60.0 on ScienceWorld, and improves over the strongest baseline, ITP-I, by 32.9/29.8 and 10.0/10.0 points, respectively.
With Qwen3.5-9B and GPT-5.4-mini, Ours achieves the best ALFWorld results and remains competitive on ScienceWorld: it ranks second behind ReAct on Qwen3.5-9B, and leads in SR@1 but ranks second in SR@5 on GPT-5.4-mini.
Across the three backbones, Ours achieves the strongest overall performance, ranking first in nine comparisons and second in the remaining three.
Per-task ALFWorld results are reported in Appendix  C .

 Action selection analysis. 

 
 Figure  2  shows that the controller selects a highest-weight candidate in 77.8–83.8% of decisions across both benchmarks and trial settings.
Second-ranked candidates account for 10.4–12.2%, while actions outside the proposal set account for 1.6–6.0%.
The controller therefore usually follows the highest-weight candidate, while retaining the flexibility to choose other candidates or generate new actions. 
 
 
 Figure 3:  An example of how retrieved experience and predictive evaluation guide action selection. Our agent completes the focus subgoal before pickup and succeeds, while ReAct skips this subgoal and fails. 
 
 
 
 Illustrative example. 

 
 Figure  3  shows how retrieved experience and predictive scoring guide a ScienceWorld trajectory.
At Step 4, retrieved experience identifies focusing on the target as a prerequisite for pickup, and the controller selects the lower-cost focus action over immediate pickup.
After this subgoal is completed, the predicted cost of pickup falls from 40 to 10, making it the preferred action at Step 5 and leading to environment-verified success with a score of 100.
In contrast, ReAct skips the focus subgoal and repeatedly declares completion despite ending with failure.

 6  Conclusion 

 
 We presented a self-improving, test-time MPPI-inspired framework for language agents performing long-horizon tasks.
The framework predicts the outcomes of several candidate actions with a world model before acting, and uses MPPI-style weights to summarize their costs for the final decision.
A dual-branch experience memory enables self-improvement: planner memory refines candidate generation and selection, and world model memory improves next-observation prediction.
Experiments on ALFWorld and ScienceWorld demonstrate the strongest overall performance across three backbones, with measured computational costs remaining practical for the evaluated tasks. 
 
 
 
 7  Limitations 

 
 First, world model accuracy is important because predicted outcomes determine candidate costs and can change the controller’s action preference.
Our current dual-branch adaptation relies on retrieved textual experience while keeping model parameters frozen. More capable mechanisms for improving world model accuracy and adapting to changing dynamics remain an important direction for future work.
Second, evaluating multiple candidates requires additional world model and evaluator calls at test time.
This increases inference latency and cost as the candidate set grows, motivating more computationally efficient ways to obtain useful candidate comparisons. 
 
 
 Ethical considerations.  Our experiments are conducted entirely in text-based simulated environments and involve no human subjects or personal data. If such an agent were deployed in real environments, inaccurate world model predictions could lead to unsafe actions, so human oversight would be needed.

 Appendix A  World Model Memory Implementation Details 

 
 Our implementation adopts WorldEvolver’s episodic and semantic memory design  ( Zhang et al., 2026 )  as auxiliary prediction context.
For each real transition, the episodic bank stores the current observation, executed action, and observation returned by the environment.
For a candidate action  a a , we tokenize it and each stored action  a ′ a^{\prime}  into token sets and score them by Jaccard similarity: 
 

 
 
 s ⁡ ( a , a ′ ) = | 𝒯 ⁡ ( a ) ∩ 𝒯 ⁡ ( a ′ ) | | 𝒯 ⁡ ( a ) ∪ 𝒯 ⁡ ( a ′ ) | . s(a,a^{\prime})=\frac{|\mathcal{T}(a)\cap\mathcal{T}(a^{\prime})|}{|\mathcal{T}(a)\cup\mathcal{T}(a^{\prime})|}. 
 
 
 We retrieve up to the five highest-scoring transitions.
Each retrieved record is presented as a state–action–next-state example.
The predictor prompt also includes the task goal and current observation. 
 
 
 The semantic memory bank stores reusable rules about environment changes and persistence.
For each prediction–observation mismatch, the language model extracts at most one rule.
Up to eight recent rules guide subsequent predictions. 
 
 
 For both benchmarks, the episodic memory bank stores up to 100 transitions and retrieves up to 5 per candidate, while the semantic memory bank stores up to 128 rules and supplies up to 8 per prediction.
Memory is retained across trajectories within each environment, allowing later interactions to reuse accumulated experience.
