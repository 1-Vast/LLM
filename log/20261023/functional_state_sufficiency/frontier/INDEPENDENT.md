## Exact operation, including what the interface already solves

The benchmark explicitly constructs paired real Android branches with identical current WM-visible observation **after the exact input transformation** and identical next action, but different validated semantic future. Four families are artifact existence/location, clipboard payload, ordered collection and timer deadline. State labels come from read-only environment evidence, not from the current screenshot. The author reports800 strict pairs across25 templates. AppendixC.8 correctly states that one distinct realized outcome does not alone prove different stochastic transition laws; its authors additionally replay one pair per template, three times per branch. These are author evidence/claims, not ours, and are not biological replicate counts.

The method trains family-specific history-to-structured-state teachers, then a unified history/schema-to-JSON student. Its loss is family-weighted conventional token CE plus temperature/topK teacher distillation (lambda.25, temperature2, topK64). The frozen world model receives a deterministic interface Gamma(recovered_state,next_action,task_context). Canonical state is defined by controlled next-observation equivalence; the implementation explicitly says its annotated structured state need not equal that canonical sufficient state. The theorem/one-step definition does not establish a recursively closed multi-step Markov state.

Crucially, Gamma is more than serialization of a latent state. AppendixE computes **action-resolved consequences** and imposes next-surface constraints:

- Clipboard PASTE must display the recovered payload in the post-action editor.
- Timer active/remaining time plus action duration determines none/running/fired and remaining countdown.
- Artifact existence plus candidate folder/search action determines visible row versus explicit absent state.
- Ordered collections are rendered with the supplied exact item count/order.

The Full request calls these authoritative, non-negotiable post-action constraints. This is not evidence of information leakage by itself: the consequences are deterministically derived from supplied recovered state/action. It is, however, substantive engineered dynamics/readout knowledge and computation. Any interpretation of the gain must account for that rule contribution; calling the entire pipeline merely “a better learned state” omits an implemented operation.

## Difference from ordinary alternatives and why no new cell core follows

The source is more concrete than adding an abstract value-relevant loss: it provides a strict paired diagnostic, typed hidden-state supervision, history recovery, and an engineered state-to-frozen-WM interface. It does not discover a new abstraction split from sparse counterexamples, learn which state dimension to add, update its own update rule, or obtain unknown dynamics from auxiliary function labels. CE/KD across schemas is an ordinary supervised/distilled state estimator. Controlled predictive equivalence is a sufficiency definition, not an executable new estimator by itself. These observations do not dismiss the paper's benchmark/engineering contribution or imply equal empirical performance for arbitrary alternatives.

For “similar post-intervention RNA yet different function,” the honest diagnostic analogue is a prespecified readout summary/metric/tolerance, shared action scope, genuinely measured functional difference beyond assay noise, and an allowed extra history/state channel that predicts that difference on independent units. Visually/arithmetically similar high-dimensional readouts need not be identical biological states. A noisy single functional discrepancy is not proof of a new hidden state, and current molecular proximity cannot be selected after seeing a large function residual.

The source's Android latent labels and known deterministic transition rules have no automatically available cell counterpart. A proposed Gamma(cell_state,drug) that simply supplies the desired response would pre-solve the unknown pharmacology. In cells the mapping from a recovered state to future function must be learned/validated from legal source feedback, shared with direct controls and charged. A deterministic assay-derived function score cannot replace an independent functional assay when the claim is cross-readout repair.

Minimum alternatives for a later qualified candidate would include same-history/action functional supervision directly, ordinary multitask state+function training, supervised history-state recovery+functional head, value/predictive-sufficiency representation, bisimulation/conditional state splitting where applicable, and contextual direct/neural-process prediction. If hand-specified Gamma rules are used, provide them identically to direct predictors and compare Gamma's semantic output without the world renderer. A fixed frozen-WM wrapper cannot demonstrate world-model necessity when the decisive functional answer is already encoded in the wrapper.

No biological source was qualified or downloaded here. Existing exposed Norman/BeatAML/rechallenge assets remain under their scoped stops; none is relabelled a new strict-pair corpus. The paper establishes a useful experimental template, not permission to reopen them or invent true cell-state annotations. Actual independent functional/state assays and lawful group identities must be authenticated before any matching or fit.

## Decision

**NONE_NEW_CELL_CORE / NO_FIT_GO.** Retain the original as a strong direct precedent and a sharper diagnostic/control requirement. Do not promote “functional counterexamples add a recoverable typed state and feed a frozen world model” as our new mechanism. This source already implements much of that pipeline, while its supervised state targets and consequence rules are currently unsupported cell assumptions. No new concrete cell-specific split/update estimator or justified sample/resource advantage beyond the above alternatives was derived here.

A next proposal may still use familiar components: it needs an independently justified cell error/measurement contract, a specific new restriction or demonstrable finite-cost advantage and a minimal falsifier. It need not invent a new mathematical primitive. A small lawful sufficiency diagnostic is permissible before a new algorithm exists, but is not authorized by this source review alone. Failure to beat same-information direct/history/multitask/rule-only controls would stop that instantiated mechanism, not all state learning. No world, agent, inherited-updater, joint or improved-improver benefit is established.
