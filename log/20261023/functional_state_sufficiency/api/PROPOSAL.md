## 一个值得实验的updater规则：**药身份条件化的低秩反馈残差（per-drug diagonal + shared rank-1）**

### 为什么它不是旧实例的改名

已排除的实例是：标量残差校准、同基混合、全局梯度组合、后验高斯条件更新。它们的共同点是**在固定Jacobian上做全局标量/同基修正**。BeatAML已确认的硬事实是：固定药身份后反馈Jacobian是常量——这意味着**任何只依赖已测AUC、不依赖药身份结构的全局标量更新，都已被普通方法精确匹配**。真正未被覆盖的自由度是：**常量Jacobian本身可以随药身份变化**，而在8个已测AUC的有限反馈下，唯一可辨识的受限结构是"药特异对角+跨药共享低秩"。

这不是新基础算子，是一个**秩约束**：把"每药一个自由反馈增益"压成`diag + rank-1`。最接近的普通实现是**per-drug独立线性refit**（每药8点拟合斜率+截距，共2×药数参数）和**conditional EB**（把每药斜率向全局均值收缩）。挑战点很明确：8点/药下独立refit方差大，conditional EB已能做收缩；本规则的可证伪差异只在于**rank-1共享项是否比"向全局标量收缩"多解释反馈**。如果conditional EB的收缩已经吃掉这部分，规则失败，应如实报告。

### 公式

设药\(d\)、已测反馈点\(i=1..n_d\)（BeatAML中\(n_d=8\)），basal特征\(x_i\)，已测功能\(y_i\)（AUC），静态预测\(\hat y_i^0=f_0(x_i,d)\)，残差\(r_i=y_i-\hat y_i^0\)。

更新规则（源期学\(\{a_d\}_{d\in\mathcal D_{\text{src}}}\)与共享\(u,v\)，目标期只更新共享项）：

\[
\hat y^{\text{upd}}(x,d)=\hat y^0(x,d)+\underbrace{a_d\,\bar r_d}_{\text{per-drug diag}}+\underbrace{u_d\,(v^\top \phi(x))\,\bar r_{\text{pool}}}_{\text{shared rank-1}}
\]

其中\(\bar r_d=\frac1{n_d}\sum_i r_i\)为药内反馈均值，\(\bar r_{\text{pool}}\)为跨已测药池化残差均值，\(\phi(x)\)为**固定、源期预注册**的少量basal特征（例如2–3个已知与药敏相关的表达轴，具体选哪些必须在看目标反馈前锁定并记录），\(u_d\)为药身份在rank-1上的载荷（源期学，目标期冻结或只允许标量缩放），\(v\)为共享方向（源期学）。

**伪代码：**

```
源期（BeatAML训练药，可有反馈回放）:
  for each drug d in D_src:
     用 n_d 个反馈点拟合 a_d（1参数/药，岭约束向0）
  固定 phi(x)（预注册，不看目标）
  拟合共享 (u_d, v) 使 sum_d ||r_d - a_d*mean(r_d) - u_d*(v^T phi)*mean(r_pool)||^2 最小
  记录 a_d 的跨药分布、u_d 分布、v

目标期（新药/新分层，合法信息 = 该药自己的 n_d 个已测AUC + basal x + 药身份）:
  计算 r_i = y_i - f_0(x_i,d)
  a_d^tgt = shrink( fit on n_d points, prior = 源期 a 分布 )   # 只此一参数自由
  u_d^tgt = 源期 u 的最近邻或冻结
  y_upd = y0 + a_d^tgt*mean(r_d) + u_d^tgt*(v^T phi)*mean(r_pool)
```

### 源期可学习对象 vs 目标期合法信息

- **源期学**：\(\{a_d\}\)、共享\((u,v)\)、\(\phi\)的**选择规则**（预注册，不在目标反馈上搜索）。
- **目标期合法**：该药自己的8个已测AUC、basal表达、药身份。**不合法**：其他药的目标期功能、目标期跨药池化若含未测药的真值、任何CellHealth预测health、PRISM rank对齐当绝对剂量。

### 核心生物/信息限制

限制是**低秩可迁移性假设**：药特异反馈增益的主变异方向（rank-1）在源期药之间共享，目标新药只在该方向上取一个载荷。若真实反馈增益在药间近乎独立（rank接近满），rank-1共享项不增益，只剩per-drug diag，退化为"8点独立refit+收缩"，与conditional EB无差别——这是可证伪的失败模式。

### 有限样本/计算优势的可检验理由

- 计算：目标期只拟合1个标量\(a_d\)+冻结载荷，比per-drug 2参数refit少一半自由度，比全多任务refit少几个数量级。
- 有限样本：8点下per-drug斜率估计方差\(\propto 1/8\)；rank-1把跨药信息注入\(u_d\)，若\(u_d\)在源期可估（药数≫1），目标期\(u_d\)无需从8点估。**可检验预测**：在新药留出回放上，本规则相对conditional EB的MSE改善应集中出现在"源期\(u_d\)分布集中"的药子集；若\(u_d\)分散，改善消失。这个子集分层是预注册的证伪条件。

### 标准方法如何用完全相同信息挑战

1. **per-drug独立线性refit**（8点拟合斜率+截距）：自由度更多，但8点下方差大；本规则若赢，必须赢在方差而非偏差。
2. **conditional EB**：把每药斜率向全局均值收缩，已利用跨药信息；本规则的唯一增量是**rank-1方向而非标量均值**。若conditional EB的全局均值收缩已匹配，rank-1多余。
3. **标准直接多任务模型**（共享底层+药特异头，用8点微调）：表达力覆盖本规则；挑战是它能否在8点下稳定微调——若能，本规则无优势。
4. **混合专家**：药身份作gate，8点更新专家权重；表达力覆盖，但8点下gate估计不稳。

关键：**这些方法都能表示本规则**，这不自动否决本规则。可证伪点在于**8点预算下的样本效率**是否真的由"diag+rank-1"这个具体秩约束带来，而不是任何收缩带来的。实验必须把conditional EB作为主基线，并预注册"rank-1增益在\(u_d\)集中子集出现"的分层检验。

### 坦白：现在证据够不够

**不够支撑"形态相同、功能不同"的新发现**——CellHealth数值未下载，无实测。**不够支撑多背景RSI**——BeatAML是单背景静态basal+单药。**够支撑的**只是：在BeatAML回放上检验上述updater组件相对conditional EB的增量。若连这个都不过，rank-1假设应放弃，不换标记救分（沿用你CD14分层的停止纪律）。

## 世界模型和智能体的实质作用

**当前仅够检验updater组件。** 世界模型（干预状态→功能的预测器）在本证据下只有"固定药身份后常量Jacobian"这一条被核实；智能体（反馈→更新的决策规则）只有上述updater可在BeatAML回放上被证伪。**不能证明整个框架**：没有独立任务、没有产后代效用、没有多背景RSI证据。世界模型若只是\(f_0\)+常量Jacobian，它在信息上等价于静态条件预测器加一个已知增益，不构成"模型"意义上的新对象；智能体若只是"读8点→套公式"，它是updater而非agent。两者作为框架组件的实质作用**尚未被任何已核实数据区分于普通条件预测+校准**。

RSI升级必须走：后续独立任务、共同起点\(U_1/U_0\)、等经验等预算\(G_1/G_0\)、产后代效用比较。**不能靠保存一次更好预测器升级**——一次回放MSE更低不构成RSI证据，因为普通refit在同一信息下也可能更低。

## 最小真实数据证伪（非toy、非新目录、不发明标注）

**数据**：BeatAML已有静态basal RNA+单药功能反馈回放（你已核实可用、MSE降23.49%的那套）。**操作**：在**新药留出**设定下（药身份在源期未出现），对每个留出药用其8个已测AUC做反馈，比较：

- **H0（主基线）**：conditional EB——每药斜率向源期全局均值收缩；
- **H1（本规则）**：diag + rank-1共享项，目标期只拟合\(a_d\)；
- **H2（上界参考，非真值）**：per-drug独立2参数refit。

**预注册证伪条件**（看目标反馈前锁定）：

1. H1相对H0的留出回放MSE改善中位数**不显著**（按药配对检验，预注册阈值，例如中位改善≤0或置信区间跨0）→ rank-1假设失败，停止，不换\(\phi\)救分。
2. H1改善**不集中**在源期\(u_d\)分布集中的药子集 → 增益不来自rank-1结构，归因失败。
3. H1在8点下劣于H0但优于H2 → 只说明收缩有用，不说明本规则，记为阴性。

**若source不支持**：新药留出若在BeatAML现有划分下不可构造（例如药数不足以留出且源期\(u_d\)不可估），**直接说明不可做，不发明新划分**。CellHealth不能作此检验——它是静态遗传干预条件预测，不是动态反馈，且health是预测非真值，PRISM剂量只rank对齐，均不作反馈回放的真标签。**药物部分的预测health一律不作真值。**

**这个证伪的边界**：即使H1赢，也只证明"8点反馈下diag+rank-1比conditional EB样本效率高"，**不证明**世界模型、智能体框架或RSI成立。框架主张需另设独立任务与\(G_1/G_0\)产后代效用检验，当前证据不支撑。
