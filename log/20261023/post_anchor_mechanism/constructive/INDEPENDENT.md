## Exact task distinction and ordinary operation

The scientific application would be predicting which cell states have **drug-specific relative outgrowth suppression**, after a small amount of real feedback, rather than merely predicting which clones grow well in any condition. For matched baseline/control/treated counts, a possible carefully qualified endpoint is

    R_i(d,t) = log[N_i,d(t)/N_i,d(0)] - log[N_i,control(t)/N_i,control(0)].

This formula is illustrative, not a claim about either author's actual estimator. Zeros, detection/lineage dropout, differing expansion history, bottlenecks, unequal sampling, absolute versus relative counts and pseudocount effects require an actual authenticated contract. Control-adjusted log relative abundance can cancel shared growth/normalization terms only under explicit matching assumptions; it is not automatically an individual causal effect. Randomized split cultures can support population/clone conditional contrasts, not counterfactual outcomes of the same physically destroyed single cell.

A reusable rule might try to update only the treatment-interaction part of a lineage state model while preserving the baseline growth component. But with a source fit

    log N_i,d(t) = b_i(t,z_i) + h_d(t,z_i),

and matched untreated feedback, conventional joint likelihood/mixed effects or direct treatment-interaction regression already performs that separation. Residualizing against an untreated model, constraining a baseline nuisance subspace, or using an orthogonal treatment-effect score are ordinary informed alternatives. I do not supply an additional invariant cell-state transition, exclusion restriction, finite-sample guarantee or computational property that would distinguish a new updater from them. The new design lead must not be used to resurrect the stopped nuisance-projection/MAP methods under “fitness correction” terminology.

The source1 author abstract additionally warns that a convincing new method can appear strong while learning only baseline growth. The correct response is a stronger untreated/clone-size comparator and a drug-specific endpoint, not an immediate new architecture. A complex model cannot obtain the missing causal separation merely by adding hereditary latent states.

## Strong same-information controls if the source is qualified later

Every method must receive identical baseline RNA, source controls, clone/founder history, acquired treated feedback, cell-count support and assay times. Include a clone-size/count/untreated-fitness-only predictor; raw baseline-state direct predictor; direct treatment-interaction model with the same control data; hierarchical lineage random effects/EB; ordinary same-forward joint refit; a source-episodic meta-initialization adapted only on paid feedback; source-selected simple mixture. Cell-cycle/growth scores are substantive controls, not nuisance covariates denied to the candidate. All tree/state features must be constructible without new-task query outcomes.

For a world-model claim, the mechanism must predict treatment-conditioned transitions or functional contrasts that improve decisions beyond those controls. It need not output explicit RNA, but measured future RNA or an endpoint tree cannot stand in for a forecast. Agent selection must operate on feasible culture/time/assay packages, with fixed and ordinary optimal-design controls. Inheritance needs source->later independent histories; improvement-of-improvement needs a changed proposer/evaluator outperforming its frozen predecessor from the same base/history/total cost. Neither paper design automatically supplies those extra episodes.

## One minimal real falsifier, before any architecture

If an independent source qualification authenticates clone-level baseline/control/treated joins and lawful independent culture groups, prefreeze a **fitness-adjusted state information diagnostic** on that new lineage asset. Predict matched treatment-minus-untreated clone outgrowth from pretreatment RNA, comparing a strong untreated-fitness/count/history-only model with a same-information direct model additionally using RNA. Entire founders/related clones/cultures must follow the prespecified grouping, and a held-out culture cannot contribute its future untreated or treated counts except the explicitly purchased support packages. Test drug-specific residual gain and a prespecified actual functional ranking endpoint, not only AUROC on raw survival or pooled-cell random splits.

The most important falsifier is that pretreatment RNA's gain on raw treated survival disappears after the matched untreated growth/count comparator. That would stop a state-as-drug-specific-updater premise for that fixed source contract while preserving useful general fitness prediction. A positive would justify looking for a specific repeatable residual/state transition restriction, not establish a mechanism or RSI. Same-drug/same-ancestor results would be exploratory and would require an independently qualified transfer source before inheritance claims. No numerical gate is improvised from the author's abstract AUROC or the old5% screen.

This is a proposed source-qualified real falsification, **not an authorization to open labels now**. It is more discriminating than repeating another dose toy or expanding Emerald's failed anchor menu, because it changes the outcome/measurement structure and directly tests the treatment-specific meaning of a state signal. But no source qualification may be used to postpone a negative decision indefinitely; if usable matched control/fate arrays cannot be authenticated by a bounded metadata audit, this particular prospective task is not executable and another structure must be sought.
