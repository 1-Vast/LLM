## Why “ordinary family” is not a valid novelty veto

Two procedures may have the same expressive family but different finite-sample estimation error, intervention constraints, computation or acquisition requirements. A new biologically justified restriction can be a research contribution even if its optimizer is MAP, ridge or dynamic programming. Exact pointwise prediction/update/cost equivalence **under the same inputs and assumptions** rules out that instantiated operational distinction; it does not prove all restrictions in the family are uninteresting. A nonlinear posterior is a relevant informed control, not a free omniscient solver that every method must outperform.

For example, a validated target-specific invariance can reduce the number of parameters that new feedback must identify. The new contribution could be that invariance and its finite-task value, while conventional inference implements it. The appropriate comparison must isolate the law's value and then any inference advantage; gifting the law only to our model and claiming updater novelty is unfair, whereas requiring the candidate to beat its literally identical same-law solver is impossible. The missing element now is an empirically justified new law and lawful source/query evidence, not a demand for an unprecedented mathematical primitive.

## Actual recent original: RM-WAM

**RM-WAM: Reliable Memory-Augmented World Action Models for Long-Horizon Robot Manipulation**, arXiv2610.15305v2, https://arxiv.org/html/2610.15305v2. New original body214421bytes; SHA and timing in rmwam.receipt.json. Read SectionIII-C Counterfactual Memory, III-E Training Objective, IV-A implementation details, with the relevant complete paragraphs saved in rmwam.text.txt. Author performance was not reproduced, code was not run and this is not comprehensive novelty clearance.

Concrete mechanism: keep current observation/instruction/proprioception/target fixed, vary history access among aligned, temporally stale, stage-shifted and cross-episode histories. Separate short visual and event memories are injected through two learned utility gates, trained along with future-state/action losses. The same sample-level soft target supervises both gates using BCE.

**Critical method detail actually read:** the text explicitly calls its q_v a proxy for expected relative reliability, *not a direct measurement of causal performance gain*. The implementation assigns q_v=1 to aligned reference and0.01to each perturbed-history class. Thus “counterfactual memory utility” here does not mean author ran common-parent update/no-update descendants and measured paired downstream query loss. This is a disclosed methodological choice, not misconduct or evidence that the approach cannot work. Its benefits may come from regularization and a good history-alignment prior.

This is substantive overlap for a cellular proposal that stores previous feedback, classifies it as stale or related, and injects it through context gates. That recipe is already concrete prior art, not our independent core. Conversely a cellular method based on *measured intervention-conditional update utility* would have a different supervision object. It still needs separation from ordinary learned error correction and existing paired-utility optimization; changing the object name or adding a functional head does not establish a new algorithm.

## A precise falsifier for a reliability-prior transfer claim

Let c denote a lawfully available cellular context and S a historical functional feedback package. Let f0 and fS be forecasts from the same base with/without that update, and define actual task utility

    Delta(c,S,Q) = L_Q(f0) - L_Q(fS).

Historical similarity, chronology, matched target annotation or source class may predict Delta, but none is its definition. A claim that source-correct/aligned feedback must help is falsified by a domain in which S is accurate for the support intervention, but query interventions use a different context-specific dependence. Correct source information can induce negative transfer; conversely cross-context history can be more useful than a stale same-context history. This is an assumption challenge, not a newly executed toy or a universal information impossibility result. Direct state/functional context may legally distinguish the regimes; a candidate should say what observation does so.

Important fair control: use the same frozen base/updater/history and compare a construction-prior gate with a source-episodic direct predictor of **paired Delta**, plus a fixed strategy, ordinary nested model selection and an always-ignore option. Give all methods the same real support packages and source query labels, and charge fitting plus counterfactual evaluations. Paired common-parent credit alone is already known from previous original-method reviews (e.g. HarnessTTT); do not repackage it as a fresh novelty claim. An ordinary learned conditional covariance only predicts linear transfer; include nonlinear conditional estimation when Delta depends on support magnitude or active regimes.

If a new restricted operator is proposed later, its strongest test is whether it predicts *which unseen query effects change* under a specified lawful update more accurately/sample-efficiently than those controls. A gate that only predicts parent score, memory similarity or source correctness does not test that question.
