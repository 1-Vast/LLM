Abstract
World Action Models (WAMs) improve robotic manipulation by jointly predicting future visual states and actions, yet most existing methods make decisions primarily from the current observation. This limits their reliability in long-horizon tasks, where visually similar states may correspond to different interaction histories and task stages. Moreover, directly incorporating historical observations can introduce stale, stage-mismatched, or error-contaminated information, leading to inaccurate world prediction and accumulated closed-loop errors. We propose RM-WAM, a reliable memory-augmented World Action Model that treats memory as a context-dependent predictive resource rather than universally useful historical context. RM-WAM represents history using complementary short-term visual state memory and latent event memory, which respectively capture recent interaction dynamics and longer-term state transitions. A counterfactual memory learning scheme varies the accessible history while keeping the current inputs and prediction targets fixed, enabling the model to learn a context-dependent utility estimate for historical memory. Based on this estimate, a utility-aware gating mechanism adaptively controls memory injection into the world–action backbone. Experiments demonstrate that RM-WAM highlights the importance of reliable and selective memory utilization in long-horizon tasks.
I INTRODUCTION
By further training pretrained vision-language models on embodied data, Vision-Language-Action models (VLAs) are becoming an important foundation model paradigm for robotics and show strong abilities in task understanding and generalization [1, 2, 3, 4]. However, existing VLAs focus on predicting the next action from the current observation directly. This local decision-making paradigm has clear limitations in long-horizon tasks, because each action not only determines the immediate behavior but also affects subsequent environment states and task progress. World Action Models (WAMs) are designed to bridge this gap [5, 6, 7, 8, 9]. By modeling action-conditioned state transitions and future observations, WAMs predict both what action the robot should take and how the world changes after the action is executed. However, reliable prediction of world evolution depends not only on the current observation, but also on a continuous understanding of past interactions. This makes historical context particularly important for WAMs in complex long-horizon manipulation, where visually similar observations may correspond to different interaction states and require different future evolutions.

Motivation of RM-WAM. (a) Existing memory-augmented VLAs use memory for action prediction, but retrieved memory is not always useful and they do not model future world prediction. (b) RM-WAM evaluates memory utility and incorporates reliable memory into a WAM for both world prediction and action generation.
Recent studies use memory mechanisms to improve policy performance in long-horizon manipulation tasks. For example, MemoryVLA [10], MEM [11], and other memory-augmented methods [12, 13, 14] build perceptual, semantic, or multi-scale memories to provide additional history for long-horizon action generation. However, directly extending these memory mechanisms to WAMs presents two fundamental limitations, as illustrated in Fig. 1. First, existing memory-augmented VLAs are primarily designed to support action prediction, whereas WAMs additionally model action-conditioned world evolution through future visual-state prediction. Memory in a WAM therefore needs to support not only action generation but also world-state modeling, where inappropriate historical information can directly distort the predicted future. Second, retrieving task-relevant history does not necessarily mean that the retrieved memory is useful for the current world-action prediction. Existing memory mechanisms typically retrieve historical information according to relevance or similarity and then use the retrieved memory as additional context. However, even highly relevant memory may be stale, inconsistent with the current task stage, or contaminated by previous rollout errors. Therefore, WAMs require an additional mechanism to explicitly assess the utility of retrieved memory before incorporating it into the prediction process.
This view is also consistent with cognitive science, where memory is not treated as a passive replay buffer but as an active and context-dependent source of control [15]. Humans selectively retrieve and reorganize past experience when it supports the current goal, while suppressing or weakening memories that interfere with ongoing behavior. Similarly, historical information in WAMs should not be assumed to be beneficial simply because it is relevant to the task. Its usefulness depends on the current observation, task stage, and prediction objective. We therefore argue that the key challenge in memory-augmented WAMs is not only which memory to retrieve, but also whether the retrieved memory should be used. This motivates explicitly modeling memory utility for reliable world-action prediction.
To address this challenge, we propose Reliable Memory-augmented World Action Model (RM-WAM), a utility-aware memory framework for long-horizon robot manipulation. We first model history as short-term visual memory and latent event memory according to their different roles in world-state prediction. Short-term visual memory describes local visual changes, providing interaction states that are difficult to infer from current observation. Latent event memory encodes historical transitions in the shared latent space and captures history that is relevant to future world evolution. We then introduce a counterfactual memory learning scheme for WAMs. By keeping the current observation and task instruction fixed while changing the accessible history, the model learns how different memory conditions affect future prediction and action generation, thereby obtaining a context-dependent utility estimate for historical memory under the current state. Based on the learned utility, the model adaptively controls memory injection before WAM backbone, so that it preserves history that helps the current prediction while suppressing stale, stage-misaligned, or error-contaminated memory. In this way, memory is no longer treated as extra context that is useful by default, but as a selective historical intervention in world evolution.
Our contributions are summarized as follows:
•
We extend memory augmentation to the World Action Models, and show that the key challenge in memory-augmented WAMs is not only storing or retrieving history, but also determining whether memory is consistent with the current world-evolution prediction and whether it has positive utility for future state estimation and closed-loop decision making.
•
We propose Reliable Memory-augmented WAM, a utility-aware memory framework for long-horizon robotic manipulation. The proposed method models history at different scales through short-term visual memory and latent event memory, and combines counterfactual memory learning with utility-aware memory adapters to selectively preserve helpful history while suppressing stale, stage-misaligned, or error-contaminated memory.
•
We evaluate RM-WAM on both simulation benchmarks including LIBERO [16], memory-dependent RMBench [17] and challenging long-horizon real-world task. Compared with representative non-memory and memory-augmented baselines, RM-WAM consistently achieves strong performance, demonstrating the benefit of reliable memory utilization for World Action Models.
II Related Works
II-A Vision-Language-Action Models
Vision-Language-Action models (VLAs) integrate visual observations, language instructions, and robot actions into end-to-end policies [18, 19, 20]. Many recent VLAs build on pretrained vision-language models (VLMs) and are further trained on large-scale robot demonstrations, improving generalization across tasks, environments, and robot embodiments [21, 22]. Early works such as RT-1 [23] and RT-2 [24] show the scalability of Transformer-based policies. Open X-Embodiment [25], Octo [2], and OpenVLA [1] further push multi-embodiment training and efficient downstream adaptation. The π\pi family [26, 3] further uses diffusion or flow matching to generate continuous action chunks. However, existing VLA methods mainly learn a direct mapping from current observations and language instructions to action sequences, while overlooking how the environment evolves under robot actions.
II-B World Action Models
World models learn environment dynamics by predicting future observations or latent states, providing predictive representations for planning and policy learning [27, 28, 29]. The Dreamer series [30, 31] optimizes policies in a learned latent world and shows the value of imagined trajectories. UniPi [32] and Video Language Planning [33] use future videos for planning and convert visual predictions into robot actions through inverse dynamics or goal-conditioned policies. Recent world action models jointly model future visual states and actions in a unified architecture [7, 8]. However, existing WAMs mainly rely on the current observation and lack effective modeling of historical state. This limits history-dependent prediction in long-horizon tasks with partial observability and stage-dependent behavior.
II-C Memory-Augmented Robotic Manipulation
Memory is important for handling long-horizon task dependencies in robotic manipulation. Early approaches mainly use recurrent states or temporal attention to aggregate history [34]. Recent studies use updatable memory bank to extend the temporal context of robot policies [35, 11]. However, directly applying memory-augmented mechanisms to WAMs does not ensure that the retrieved history remains consistent with the current world prediction. Although recent studies improve policy performance by introducing hierarchical, persistent, or higher-capacity memory mechanisms [36, 37], they primarily focus on organizing and extending historical context, while the context-dependent utility of retrieved memory for current world-action prediction remains less explicitly modeled. Historical information may be stale, stage-mismatched, or corrupted by closed-loop errors. Our RM-WAM therefore treats visual memory as a predictive resource with context-dependent utility rather than uniformly useful historical context.

III-B Framework Overview
The overall framework of RM-WAM is illustrated in Fig. 2. Given the current and historical observations, language instruction, and proprioceptive state, RM-WAM first constructs a dual-scale memory from visual latent tokens. A temporal encoder aggregates recent latent states to form short-term memory tokens, while an event encoder represents historical state transitions as event-memory tokens. These memory representations are selectively injected into the video branch through gated adapters, where the gating functions are learned with counterfactual memory supervision to estimate the utility of memory. The video branch adopts Wan2.2-TI2V-5B [38] as the backbone, including its VAE encoder-decoder and Video DiT, while the action branch employs an Expert DiT for action prediction. The two branches interact through a Mixture-of-Transformers (MoT) and are conditioned on language and proprioceptive information through the state/text encoder, enabling memory-enhanced joint prediction of future visual states and action chunks.
III-C Counterfactual Memory
To estimate the utility of historical memory under the current context, we construct counterfactual memory conditions by varying only the accessible history while keeping the current observation, task instruction, proprioceptive state and prediction target unchanged. This design isolates the influence of memory from changes in the current inputs and supervision targets. Specifically, ℳtref\mathcal{M}_{t}^{\mathrm{ref}} is constructed from the causally aligned history preceding the current timestep within the same episode and serves as the reference memory condition, ℳtstale\mathcal{M}_{t}^{\mathrm{stale}} is sampled from temporally distant history, representing information that is valid within the episode but less relevant to the current state, ℳtstage\mathcal{M}_{t}^{\mathrm{stage}} is constructed by temporally shifting the historical sampling positions within the same episode, producing history that is causally valid but misaligned with the current decision point. This condition simulates temporally mismatched context without requiring explicit stage annotations, ℳtcross\mathcal{M}_{t}^{\mathrm{cross}} is drawn from another episode of the same task, preserving task-level semantics while breaking the correspondence with the current trajectory. These counterfactual conditions expose the model to historical contexts with different expected levels of predictive reliability. Each condition is associated with a soft utility target qv∈[0,1]q_{v}\in[0,1], which serves as a supervision proxy for the relative reliability of memory under the current prediction context, rather than a direct measurement of causal performance gain.
III-D Dual Memory Representation
III-D1 Short Visual Memory
Short memory provides recent visual for WAM and supplements local interaction states that are difficult to infer from a single current frame, such as manipulator occlusion, small object displacement, and short-term motion trends. Directly concatenating all historical tokens increases sequence length and introduces repeated background information. RM-WAM therefore compresses recent visual history before it enters the WAM backbone.

RM-WAM is trained with joint world-action modeling, future-transition supervision for latent event memory, and memory-utility supervision. The overall objective is
ℒ=ℒact+λv​ℒvid+λe​ℒevt+λu​ℒutility,\mathcal{L}=\mathcal{L}_{\mathrm{act}}+\lambda_{v}\mathcal{L}_{\mathrm{vid}}+\lambda_{e}\mathcal{L}_{\mathrm{evt}}+\lambda_{u}\mathcal{L}_{\mathrm{utility}},

where ℒact\mathcal{L}_{\mathrm{act}} and ℒvid\mathcal{L}_{\mathrm{vid}} are the flow-matching losses for action generation and future visual dynamics, ℒevt\mathcal{L}_{\mathrm{evt}} encourages latent event memory to retain historical transitions related to future world evolution, and ℒutility\mathcal{L}_{\mathrm{utility}} provides memory-utility supervision from counterfactual memory conditions. During inference, RM-WAM maintains a causal visual history buffer for each episode. After the robot executes an action chunk and receives a new observation, the observation is appended to the buffer in temporal order, and memory is sampled with the same temporal offsets as in training at the next decision step. When valid history is insufficient at the beginning of an episode, missing positions are masked instead of being filled by copying the current frame. Since causal attention masks already prevent the action branch from accessing future visual information during training, future video generation can be omitted during inference without affecting action prediction.
IV Experiments
IV-A Experimental Setup
IV-A1 Model architecture
RM-WAM adopts a dual-branch architecture for joint modeling of future visual and robot actions. The video branch uses Wan2.2-TI2V-5B [38] as the backbone for world prediction, while the action branch employs a 30-layer Diffusion Transformer (DiT) [39] to generate continuous action chunks. The two branches interact through a Mixture-of-Transformers (MoT). In addition, a one-layer temporal Transformer encodes recent visual latent tokens to construct short-term visual memory, while another one-layer Transformer encodes historical latent transitions to form latent event memory. For the two memory types, lightweight two-layer MLP gating modules are employed to control memory injection, with their strengths learned through counterfactual memory supervision.
IV-A2 Benchmarks
We evaluate RM-WAM on two simulated benchmarks, LIBERO [16] and RMBench [17]. LIBERO evaluates language-conditioned manipulation across four suites: LIBERO-Spatial, LIBERO-Object, LIBERO-Goal, and LIBERO-Long, covering spatial, object-centric, goal-conditioned, and long-horizon tasks. RMBench focuses on memory-dependent manipulation under partial observability, where reliable execution requires the model to retain and utilize historical visual states and interaction events over extended temporal horizons. Together, the two benchmarks assess both the general manipulation capability of RM-WAM and its effectiveness in long-horizon tasks.
IV-A3 Baselines
We compare RM-WAM with four representative methods. Diffusion Policy (DP)[40] is included as an action-generation baseline without world modeling. π0.5\pi_{0.5} [3] represents a strong vision-language-action policy for continuous robot control. FastWAM [9] serves as a world–action modeling baseline that jointly learns visual and robot actions. HiMem-WAM [36] is the most closely related memory-augmented world-action model and introduces hierarchical memory gating for long-horizon manipulation. All methods are evaluated using the same data and evaluation protocol.
IV-A4 Implementation Details
Short-term memory encodes the four most recent frames, while event memory samples visual latents every 16 timesteps to construct four transition-level candidates. Counterfactual supervision is implemented by modifying the historical sampling pools of short and event memory while keeping their memory lengths fixed. The reference, stale, stage, and cross-episode conditions are assigned soft utility targets of 1.01.0, 0.010.01, 0.010.01, and 0.010.01, respectively. These values are used as soft supervision priors to distinguish causally aligned history from deliberately perturbed memory conditions, and counterfactual memory samples account for 50% of the training data.
Multi-view observations are concatenated into a single image before being fed into the model. Robot actions are represented in 7-DoF, with an action horizon of 32. Models are trained for 10 epochs with a batch size of 16 and gradient accumulation of 1, using AdamW with an initial learning rate of 1×10−41\times 10^{-4} and a weight decay of 1×10−21\times 10^{-2}. During training, gradients from the action branch to the video branch are stopped. At inference, RM-WAM maintains a causal history buffer that is updated with incoming observations, and unavailable historical states at the beginning of an episode are masked out. For action generation, we use classifier-free guidance (CFG) [41] with a guidance scale of 1.0.

IV-C Real World
IV-C1 Task
We further evaluate RM-WAM on a real-world dual-arm robotic platform consisting of two AGILEX PIPER manipulators, an Intel RealSense D435i
RGB-D camera. We design a long-horizon Organize Table task that requires the robot to complete a sequence of object manipulation steps within a single episode. As shown in Fig. 3, the task consists of multiple temporally dependent stages and therefore requires the policy to maintain and utilize historical information throughout execution. We collect 500 expert demonstrations for training, each covering the complete task trajectory from the initial scene to the final organized state. During evaluation, the initial object configurations are randomized, and the robot is required to complete the entire multi-stage task. For real-world inference, the policy predicts an action chunk of 32 and replans every 8 control steps at a control frequency of 30 Hz. To further evaluate robustness and generalization in real-world settings, we consider three testing settings: Standard evaluates the complete task under normal initial configurations. Disturbance introduces external interventions during execution, such as manually removing an object that has already been placed at its target location. Unseen introduces objects that are absent from the training data. We conduct 30 rollouts for each setting and report the overall average success rate.
Fig. 3: Real-world long-horizon tabletop organization task. The task consists of three sequential manipulation subtasks, denoted by ①–③, requiring the robot to complete multiple object organization steps over an extended temporal horizon.
IV-C2 Evaluation Results
We compare RM-WAM with FastWAM, which follows a similar world-action modeling paradigm, to examine the effectiveness of the proposed reliable memory mechanism in physical environments. As shown in Table III, RM-WAM consistently outperforms FastWAM across all three settings. Under Standard, RM-WAM achieves a success rate of 90.0%, improving over FastWAM by 10 percentage points, indicating more stable execution in long-horizon multi-stage tasks. Under Disturbance, RM-WAM reaches 83.3%, compared with 70.0% for FastWAM. This suggests that when external interventions alter task progress, relying mainly on the current observation can lead to incorrect stage estimation, whereas RM-WAM can leverage historical interactions to better reassess the current task state and recover from disturbances. Under Unseen, RM-WAM achieves 86.7%, compared with 76.7% for FastWAM, showing that reliable historical context remains beneficial when generalizing to unseen objects.

IV-D1 Short-Term Visual Memory
To understand the effectiveness of the short-term memory in RM-WAM, we visualize its spatial attention and the corresponding utility coefficient on the Blocks Ranking Try task in RMBench. As shown in Fig. 4, at the current timestep tt, the robot has just completed placing the pink block and should subsequently interact with the green block. The short-term memory mainly attends to manipulation-relevant regions, including the gripper, the previously manipulated pink block, and the green block corresponding to the next interaction, providing historical cues for identifying the subsequent manipulation target. We further visualize the short-memory utility coefficient learned through counterfactual memory supervision. As the task transitions from placing the pink block to manipulating the green block, the utility increases toward the current decision and reaches its highest value at t−1t-1. This indicates that RM-WAM does not uniformly fuse recent observations, but instead adaptively evaluates the utility of short-term history according to the current task state.

To analyze how RM-WAM utilizes latent event memory during long-horizon manipulation, we visualize the memory attention over time on the Put Back Block task in RMBench. The result provides qualitative evidence that latent event memory captures meaningful interaction events and supports history-dependent decision making in long-horizon tasks.

IV-E Ablation Studies
We conduct an ablation study on LIBERO to analyze the short-term memory and latent event memory across tasks. As shown in Table IV, w/o short-mem. and w/o event-mem. denote removing the short-term memory and latent event memory, respectively. Removing short-term memory decreases the success rate on LIBERO-Spatial from 98.8% to 97.8%, indicating that recent visual history is important for preserving local spatial information. On LIBERO-Goal and LIBERO-Long, removing event memory leads to larger performance drops, with success rates decreasing to 96.8% and 95.0%, respectively. This is consistent with the stronger dependence of these tasks on task progress and longer-range state transitions, for which latent event memory provides more persistent historical context. Overall, RM-WAM achieves the highest average success rate, validating the complementary roles of the two memory components.

V Conclusion
In this paper, we propose RM-WAM, a reliable memory-augmented World Action Model for long-horizon robot manipulation. Different from existing memory augmentation methods that treat historical information as universally useful context, RM-WAM considers memory as a context-dependent predictive resource and models history through complementary short-term visual memory and latent event memory to capture local interactions and long-term state transitions. Furthermore, counterfactual memory learning is introduced to learn a context-dependent utility estimate for historical information under the current task state, enabling adaptive memory utilization for world prediction and action generation. Experiments demonstrate that RM-WAM effectively exploits reliable historical information and improves long-horizon task performance through more accurate world evolution modeling and closed-loop decision making.
