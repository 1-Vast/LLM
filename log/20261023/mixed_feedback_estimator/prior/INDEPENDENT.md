## Actual operator, derivation and executed check

Let x_ab be a fixed intervention-anchored combination feature, s_ab = W^T x_ab a named-state response, and f_ab = beta^T s_ab a fixed known linear readout. State feedback observes I W^T x; functional feedback observes beta^T W^T x. For any observation row h:

    h W^T x = (h tensor x)^T vec_F(W).

Consequently, a shared low-rank W estimated from those mixed channels is exactly ordinary low-rank matrix sensing with known measurement operators. Missing full-state rows do not by themselves create a new learning rule. This is an exact parameterization identity, **not** a proof that all regularizers, algorithms or nonlinear circuit models are equivalent, or that conventional structure cannot give finite-sample gains.

With fully observed orthonormal-design state targets T, a particularly direct readout-aware rank-r estimator minimizes

    ||W-T||_F^2 + lambda ||(W-T) beta||_2^2,  rank(W)<=r.

Set Q=I+lambda beta beta^T. Its global optimum is rank_r(T Q^(1/2)) Q^(-1/2), because multiplication by invertible Q^(1/2) preserves rank. It is ordinary transformed-output reduced-rank regression. This derivation requires the stated complete/orthonormal design; it is not claimed as a closed-form solution for arbitrary missing-state feedback.

Executed check.py on a fixed T=diag(20,.2,0,0), beta=e2, rank 1, and the declared lambda menu [0,100,10000,20000]. RNA-only rank 1 has function squared error .04. Readout-aware rank 1 at lambda=20000 has function error 7.7037e-34, while state squared error grows from .04 to 400. This shows a real capacity tradeoff, not free joint improvement. The original and transformed objective differ by at most 1.7764e-15. The direction and large weight were chosen analytically to illustrate the phenomenon; this is not an empirical hyperparameter selection result.
