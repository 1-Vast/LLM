# Independent metadata support review

2026-10-23. Role: mixed-state support. Peer reports not read. Full objective read; update_law_search and numerical-qualification decisions read. Scope is source identity support, not new state/function observations, predictor fitting or novelty approval.

## Executed facts

`metadata_support.py` reads only split membership, canonical panel identities and raw cell identity metadata. It does not open the RNA matrix, any functional outcomes, filtered identities, development/protected coverage, or peer reports. Identity QC is number_of_cells == 1 and good_coverage == true. Perturbation label aliases follow the existing author-supported map; expression features are not renamed. Controls are the existing three declared control-target identities, not a newly response-selected set. Barcode suffix supplies gemgroup, and is checked against the recorded gemgroup.

Of the 3,160 existing source eligible unordered pairs, 73 have identity-QC double-state cells: 20,395 cells total, 49–969 cells per represented pair. All 73 occur in all eight gemgroups. Every observed pair/gemgroup has both constituent single-target identities and allowed controls in that gemgroup. No allowed-cell barcode/gemgroup mismatch was found. There are 72 pairs with one exact guide-identity string and one pair, IGDCC3|TGFBR2, with two exact identity strings (120 and 142 cells); these strings are not independent unordered pair tasks.

The full pair-level list is SOURCE_PAIR_METADATA.csv; exact guide strings and cell counts are SOURCE_GUIDE_LINKS.json. Missing source pair state metadata is explicit, not numerical zero RNA. Summary is METADATA_REPORT.json with input hashes. The report's all_source_pair_gemgroup_counts intentionally includes 3,087 unsupported pairs. A pre-report naming ambiguity (calling this all-pair histogram supported-only) was corrected before sealing; no data selection or identity changed.

RNA UMI >= 2,000 has NOT been checked for doubles, and no numerical double expression is read. Previous single/control QC pass does not prove double retention. The prior raw-schema audit reports complete barcode joins; this step does not reread 5.9M barcode rows. Gemgroups are experimental batch strata, not eight independent biological contexts. State/function pairing is by unordered target identity; RNA is a measured transcriptome and growth is a separate assay. No cell-level joint growth/RNA outcome exists here. Target-combination discovery remains a proxy, not drug efficacy.

## One minimal admissible data structure

If the candidate estimator survives a separate mathematical/novelty gate, a bounded local capability experiment could expose a frozen subset of these 73 source pairs as mixed feedback. For each selected unordered pair store: both single profiles, pair profile, corresponding guide identities, per-gemgroup cell counts and shared control definition; also the already-authorized source pair function label and the same-information single growth priors. Pair state residual in one fixed coordinate system is r_ab = mu_ab - mu_a - mu_b + mu_control. This is a contrast definition, not a biological mechanistic update or an identified force/Jacobian.

The simplest identifiable restriction to test is a shared low-dimensional mixed-response map from a *prospectively fixed, intervention-anchored pair design* to RNA residual and function residual. Mixed observations can identify its coefficients only on the observed design span; there is no data support for unrestricted 103-target quadratic interactions, arbitrary off-span transfer, unique circuit edits or dynamics. Freeze dimension/regularization/feedback schedule before opening any pair expression. Training-only representation fitting and nested leave-pair-out use of the 73 are needed; many cells cannot replace 73 pair units. Previous source outcomes are historically exposed, so a held-out source capability result is internally cross-fitted support, never fresh independent validation or RSI inheritance.

Give the strongest direct control the entire same pair-state payload, pair identities, single features, function priors, feedback labels and schedule. At minimum compare ordinary joint multi-output regression/union refit with identical design and regularization opportunities, and a direct function regressor allowed supervised or unsupervised state representation learning. A shared residual map alone is ordinary multi-task regression, not yet a new algorithm. The proposed estimator must name an additional useful restriction or update objective and face this direct control; merely inserting a latent state between pair and growth is insufficient. Charge state-query costs equally, even if source growth labels were already available; do not describe previously exposed function labels as newly discovered experimental feedback.

## Decision

GO only for a prospective source-only mixed-feedback numerical qualification after a distinct estimator/ablation protocol is accepted. Metadata support is real but small and selected; 73 is not validation of performance, inheritance, drug application or an agent's necessity. STOP any plan to estimate an unrestricted mixed tensor from this panel, claim gemgroups as independent subsequent tasks, open development/protected state coverage now, or turn the presence of pair RNA into an innovation claim. No strong baseline performance has been measured in this phase.

Unresolved: after prospective double-RNA QC, are the chosen anchored design and readout restrictions simple, identifiable and useful on untouched source folds beyond ordinary same-information union refit? This requires actual measurements and a candidate-specific minimal falsifier; metadata cannot answer it.
