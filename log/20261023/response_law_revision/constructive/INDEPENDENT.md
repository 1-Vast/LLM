This changes the predictor's cross-intervention sharing rather than only its numerical posterior on a fixed covariance.

Attempted executable rule (conditional on declared compatible representations):

    2. For each G, choose its compact generator set and impose the associated commutation constraints on W.

In the noiseless dynamic setting with the source's separation assumptions, steps1–5 are already the published adaptive-symmetry operator. Reusing it is not a new contribution. We have not supplied an independently justified noisy selection/update criterion, a cheaper generator algorithm than the source, a new sharing restriction or a later-task bound. Calling step5 an inherited updater does not establish any of these differences.

The finite-computation prospect remains legitimate: updating constraints through compact generators can be cheaper than enumerating every transform. ## Real observation contract and nontrivial failure boundary

Existing finite-pool AUC feedback can reveal drug sensitivities, but distinct inhibitors are not authenticated exact symmetry-related interventions. Shared nominal target or chemical class does not imply equal potency/exposure/off-target actions. Swapping the order in a data structure representing an unordered pair is an encoding invariance, not a learned response law. Swapping actual timed drug administrations is a biological schedule claim and can change outcome; the sparse FAC/OLA development tables do not authenticate a group action or independent symmetry-learning tasks. Monotone dose effects are not a finite invertible group. Gene renaming is not a physical intervention equivalence unless the matching transformation of measured context and intervention mechanism is specified.

One scalar assay at each of two purported interchangeable drugs may reject equality in a particular context; it does not supply the full-state/feature representation, trajectory excitation or noise separation used by the source theorem. Known assay noise needs a noisy statistical protocol, not treating unequal noisy numbers as an exact symmetry break. For static noisy data it is possible to perform a modest ordinary shared-versus-unshared fit, but this does not inherit the trajectory theorem or automatically learn a reusable biological update rule. No current documented source supports the required exact action transformation in our functional task. This is a specific missing semantic restriction, not a claim that all cell invariances or all useful few-shot sharing are impossible.

The robotics source illustrates a separate supervision gap: terminal ATP/AUC is not a measured instantaneous residual force with known input balance. We cannot manufacture its residual-equation target by naming a hidden cell state or using a model-generated derivative. A measured effective response basis might still be useful, but currently no new basis-construction/update operation is supplied beyond sparse regression plus coefficient adaptation.
