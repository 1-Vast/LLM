## 最小统计

先固定一个状态变量和阈值规则，并认证其在功能测量前可用。可用单一明确命名的basal marker或预声明signature；不要从Y择优挑基因/signature/阈值。源表达主成分也可作描述性分组，但若原语义不足，不能将PC1叫作细胞状态或药理机制。

按患者hash分discovery与replication，所有同患者RNA样本留在一半。每个drug pair需在每个状态组拥有成对完整功能记录；缺失ness与覆盖数先报告。为了最低复杂度，可按患者对同一配对样本的值先聚合，再计算组内中心化Pearson r之差，而不直接比较原尺度协方差。具体“成对完整”聚合应使用同一患者、同一RNA样本同时有两药的记录，不能把不同时间样本的两药拼成一个患者的伪配对。

discovery可筛所有预先合格drug pairs，但必须把唯一候选或有限候选集、方向及效应阈值冻结后才读replication结果。复现报告相同方向的效应及患者bootstrap区间；若多个候选需统一多重比较约束，不挑最有利复现。样本极少/方差近零者不可硬算相关；最低覆盖与方差规则必须在Y前固定。不能把两半叫新临床队列或跨背景外部确认。

若关心支持药物对query的条件预测，简单交互检验更直接：Yq = b0 + b1 Ys + b2 state + b3 Ys×state。组截距必须保留，不能把均值差误报成共享斜率变化。发现方向和drug-pair身份在discovery冻结后，在replication用同一公式检验b3方向；这一诊断使用相同已观测drug pair，没有声称能预测未见药物或自适应挑实验。反转不是必须：稳定的有用斜率差也可反驳特定全局共享限制。

相关差与交互斜率差回答不同问题：相关差会受组内量程限制、噪声方差与共同敏感度影响，斜率差也会受误差变量衰减影响。二者不能互相替代后择优宣布成功。可选一个作主终点、另一个预声明描述性诊断，或只执行一个。

## 最强替代解释及结论边界

- 不同药物/组的缺失性、筛选paper_inclusion与完整案例构成可产生条件关联变化；成对样本覆盖不平衡需展示。
- 全局“易杀伤”敏感度、blast purity与细胞组成、RNA/功能测量批次或wave，都能制造marker条件下的关联异质性。没有认证metadata不能装作已控制它们。
- 原尺度协方差变化可能仅是尺度变化或异方差；Pearson差也不能认证药物作用机制改变。
- 同患者时间点与标本来源差异、支持药物测量误差可使跨样本聚合产生偏差；患者划分仅修复部分依赖，不能认证同培养物。
- discovery全pair挑最强是选择成本；不报告全部筛选规模或在replication继续改分组会摧毁最初独立检验。

诊断若复现，只说明在该合法源人群、已测单药面板中，固定全局共享可能丢失一个可见条件。普通条件协方差、heteroscedastic regression、交互回归和非线性集合预测器仍是最强解释/对照；**不证明新结构修订优于它们，更不证明世界模型、智能体、继承或RSI**。诊断若不复现，停止这一预固定marker与筛选规则，不在同一复现半换marker救援。
