## A concrete limitation of the strongest local positive comparator

For fixed purchased drug identities S, the implemented covariance predictor is

`yhat_Q = mu_Q + D_Q C_QS (C_SS + I)^(-1) D_S^(-1) (y_S - mu_S)`.

Here C is the source covariance in standardized response coordinates, D contains source scales and the exact code solves an 8-by-8 system. Consequently its derivative with respect to purchased response values,

`d yhat_Q / d y_S = D_Q C_QS (C_SS + I)^(-1) D_S^(-1)`,

is constant for a fixed S. It cannot make the local direction of feedback transport depend on a newly observed cellular context or on the response values themselves. This follows from the inspected operation; no new toy or biological values are required. Differing S can change this matrix, and missingness can affect which S is bought; neither should be silently held fixed in an empirical comparison.

**Potential error contract:** the same support-drug perturbation could imply opposite query-drug sensitivity changes in two independently observed cellular contexts, while a pooled affine response transport uses one direction. That is a specific failure of this comparator, rather than the vague statement that biology is nonlinear. However, the inspected evidence has not established such a repeatable conditional sign reversal, its magnitude, or that it harms drug ranking. The FAC/OLA outcomes alone cannot establish it: support/query action distribution, assay channel, density and ordinary misspecification remain alternatives. Do not assert this failure exists because it is mathematically possible.

## Why this is not yet the requested mechanism

A context-interaction regression, context-dependent GP/kernel, mixture of regressions with a learned gate, or full-history auxiliary conditional predictor can all represent changing feedback directions. The closest explicitly inspected primary-method counterpart is Mani/Vondrick/Zemel2026, arXiv2602.12112v1, retained in `functional_rule_discovery`: its function posterior consumes action, function and high-dimensional auxiliary context. That original is already in the project evidence; I did not independently retrieve or fully reread it this turn. No fresh literature novelty clearance is claimed.

Estimating a support-dependent covariance, gating response experts, or fine-tuning a nonlinear response head therefore does not by itself supply a distinct update mechanism. Conversely, that observation does not prove these conventional models have equal finite-data or finite-compute performance. A new structural restriction could be useful, but it must state which response interactions are shared, why source evidence supports that restriction and what resource/error advantage is expected over a competent matched direct implementation. None is supplied by the current inspected evidence. I do not propose another generic gate or add a latent state merely to fill this gap.

## What a minimum discriminating test would need

The application would be selecting drugs after a small ex-vivo feedback panel for a new cellular background. The legal support bundle is fixed before outcomes: baseline context, the purchased intervention identities, their measured function and, **only if actually available**, their measured post-intervention state. Queries are unpurchased measured functional responses. Held patients/backgrounds are tasks; support partitions, seeds and wells are not extra independent tasks. BeatAML is an available functional/basal-context route, but the just-inspected pilot did not use basal RNA and did not authenticate matched post-intervention RNA. It can test nonlinear functional conditioning, not the stronger transition-repair claim. I am not claiming another paired corpus exists.

Before a new method fit, specify one source-supported, prespecified context variable and query drug family and establish whether affine transport has a repeatable clinically relevant directional/ranking error in a lawful untouched evaluation. The condition must be fixed using source information, not selected from exposed errors. Basal molecular state can motivate predictive stratification; it does not establish that a treatment changed that state. This report does not authorize protected holds or a return to the stopped BeatAML consistency setup.

If a new operation becomes justified, the essential comparison is:

1. Pooled covariance versus nonlinear same-history direct/auxiliary prediction and ordinary context-interaction refit. A win here establishes a predictive restriction/resource advantage, not automatically a world model.
2. Frozen transition model plus head adaptation versus the proposed transition update; and a same-capacity same-step joint refit, all receiving exactly the purchased channels. A head-only win alone is insufficient.
3. Functional query benefit **and**, for a claim of molecular transition repair, an independently withheld molecular response. State forecasts cannot be evaluated on the same measured states used to construct the update. Independent state accuracy still does not prove the gain requires the proposed architecture; the same-information direct competitor remains essential.

Controls have identical source tasks, observable support bundles, query action lists, hyperparameter-selection access, update/replay/auxiliary costs and total search budget. No new modality is free. If acquiring molecular state is more costly, match total assay cost as well as count and provide the functional-only alternative. Ordinary continual learning, active selection, simple mixtures and equal-budget program search become necessary before agent/inheritance/RSI claims; this diagnostic is not a substitute for them.

**Stop before candidate expansion** if conditional reversal is not reproducible, depends on outcome-selected contexts, loses its ranking relevance, or is explained equally well at matched cost by ordinary conditional prediction. Stop the molecular-repair interpretation if no paired intervention-state/readout contract exists, even if ordinary functional forecasting remains permissible. Do not require true latent-state identification for a modest predictive claim; do require evidence appropriate to any causal transition claim. There is presently no warranted threshold numerical study because no actual new operation has survived this gate.
