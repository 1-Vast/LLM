Abstract
Traditional system identification typically involves two steps: initially, training data is processed to estimate a model of the system of interest; then, the model is used to predict outputs for new input queries.
In contrast, recent in-context learning approaches learn a meta model that maps directly from training data and query inputs to outputs in a zero-shot fashion, bypassing explicit model estimation. This approach leverages a meta model trained offline, on large sets of synthetically generated data, to emulate the behavior of a system identification algorithm. In this work, we advance this meta-learning framework for system identification in three directions. First, we develop a unified probabilistic meta-identification architecture that combines a Transformer-based encoder–decoder with tailored mechanisms for handling long training sequences, enabling calibrated predictions over long horizons. Second, we show how a pre-trained meta model can act as an uncertainty-aware synthetic data generator for classical system identification, providing task-specific data that regularize parametric models when real data are scarce. Third, we systematically evaluate the framework on standard nonlinear system identification benchmarks and on a challenging out-of-distribution scenario, demonstrating competitive accuracy with state-of-the-art methods and strong generalization, including cases where input-only adaptation is sufficient to handle significant distribution shifts.

Introduction
1.1
System identification and meta learning
System identification (SYSID) provides data-driven methods to construct mathematical models of dynamical systems from measured input–output data. Given a dataset, the goal is to estimate a model that captures the underlying behavior with sufficient accuracy for tasks such as simulation, prediction, and control design. Over the past decades, a broad range of identification techniques has been developed, ranging from prediction-error and subspace methods for linear to deep-learning-based approaches for nonlinear model learning; see, e.g.,
Forgione and Piga (2021a)
;
Zhou et al. (2022)
;
Beintema et al. (2021)
;
Masti and Bemporad (2021)
;
Schoukens et al. (2014)
;
Paduart et al. (2010)
.
In the classical setting, each identification task is posed for a single system, and a model is fitted using exclusively the data available for that system.
Traditional identification limitations
In standard practice, the estimation pipeline relies heavily on expert intervention. The practitioner must select a suitable model structure (e.g., linear
vs
nonlinear, time-invariant
vs
time-varying, state-space
vs
input/output representation, etc.), choose an identification approach (e.g., prediction error methods, subspace methods, kernel-based approaches, etc.), and tune hyper-parameters in the numerical optimization routines used to solve the identification problem (e.g., learning rate in gradient-based methods, regularization weights, stopping criteria to prevent overfitting, etc.). These design and tuning choices are typically repeated from scratch for each new system of interest.
In many applications, however, the goal is not to model a single isolated plant, but to repeatedly identify
related systems (for example, members of a given benchmark family or class of processes). In such settings, traditional pipelines treat each system independently: for every new dataset, the modeling and tuning steps described above are repeated, and a separate model is estimated from scratch. This per-system workflow does not exploit information gained from previously identified systems and can be computationally demanding when many systems must be modeled. Moreover, classical approaches typically yield a different model for each system, which complicates downstream tasks such as deploying a shared controller across a fleet of systems or transferring prior knowledge to new tasks. While uncertainty-aware identification methods and advanced long-sequence models exist, they are not generally designed to provide class-level, zero-shot predictions for new systems from a short context trajectory.
Proposed meta-learning approach
To address these challenges, we adopt a meta-learning viewpoint in which the basic object of interest is a
class
of dynamical systems rather than a single plant. Building on the in-context system identification paradigm introduced in
Forgione et al. (2023)
, this paper presents a
novel
SYSID paradigm inspired by meta learning techniques
Hospedales et al. (2021)
. We consider a meta model that is trained once, offline, on a large synthetic corpus generated from a distribution over systems. At inference time, this pre-trained meta model receives a context input–output sequence from a new system and a query input, and directly predicts the corresponding output in a zero-shot fashion eliminating the need to implement any system identification algorithm and avoiding the selection of model structure and hyper-parameters.
This class-level meta-modeling addresses the limitations discussed above in the following ways:
•
Reuse of knowledge across systems:
a single meta model is shared by all systems in the class, so information gained during offline training is amortized across tasks instead of being discarded after each identification.
•
Reduced per-system design effort:
architecture and training hyper-parameters are chosen once at the class level. For a new system, the meta model is applied without revisiting model-structure selection or hyper-parameter tuning for each trajectory.
•
Zero-shot prediction from short contexts:
given a limited context from a new system, the meta model can produce output predictions for new inputs without any task-specific gradient-based adaptation, in contrast to classical pipelines that require solving a new optimization problem per system.
This enables knowledge reuse across systems and reduces the need to repeatedly perform full identification procedures—including structure and hyper-parameter selection—for every new trajectory.
We emphasize that addressing the above limitations comes at its own cost.
In particular, the proposed meta-learning paradigm relies on a substantial offline pre-training phase on synthetic data, and a performance gap with carefully tuned classical system identification methods may still appear when abundant task-specific data are available or when strict requirements on parsimonious models for control design are imposed.
These trade-offs, and the regimes in which the meta-modeling approach is most advantageous, are examined in detail in the subsequent sections.
The proposed meta learning approach is analogous to
Large Language Models
(LLMs) like GPT-4, LLaMA, Gemini, and DeepSeek, which are pre-trained on vast text corpora to understand and generate text. Similarly, our meta learning approach enables users to generate output predictions by providing context and a related query, leveraging knowledge acquired in pre-training to efficiently handle various system identification tasks.
1.2
Related Literature
Meta learning, also referred to as learning to learn, is a branch of machine learning introduced in the late 1980s
Schmidhuber (1987)
that has gained significant momentum in recent years. In a broad sense, the goal of meta learning is to enhance model and algorithm efficiency by leveraging experience from multiple related tasks. While standard machine learning trains models for a single task, meta learning approaches aim to capture common patterns and similarities across tasks, enabling rapid adaptation to new ones with minimal data and computational resources.
One of the most popular meta learning algorithms is
Model-Agnostic Meta Learning
(MAML)
Finn et al. (2017)
, which aims to find model parameters that can quickly adapt to new tasks. MAML has proven particularly effective in few-shot learning scenarios across various domains and applications, including computer vision for few-shot image classification tasks
Antoniou et al. (2019)
, reinforcement learning to accelerate policy learning in new environments
Finn et al. (2017)
, materials science for predicting material properties and accelerating materials discovery
Zuo and others (2021)
, as well as in system identification, optimization and control
Kaushik et al. (2020)
;
Chakrabarty et al. (2023)
;
Richards et al. (2021)
;
Chakrabarty et al. (2025)
.
Another instance of meta learning is represented by in-context learning, where large models
are trained on diverse and extensive datasets, enabling them to process a context–a demonstration of the task at hand–along with a query input, and directly predict the corresponding output without further training
Kirsch et al. (2022)
;
Dong et al. (2024)
. In this framework, zero-shot prediction emerges as a powerful feature of in-context learning, where models leverage their extensive pre-training on diverse datasets to adapt to new tasks without requiring additional fine-tuning or retraining. Typical application of in-context learning include Natural Language Processing
Zhu et al. (2023)
, vision
Zhou et al. (2024)
, speech recognition
Chen et al. (2024)
, and robotics
Zhu et al. (2024)
, just to cite a few. In the field of system identification, in-context learning has recently demonstrated promising results for zero-shot prediction, leveraging knowledge gained from estimating the behavior of systems similar to the target one
Forgione et al. (2023)
;
Rufolo et al. (2025a)
;
Du et al. (2023)
.
1.3
Paper Contribution
This paper builds upon the preliminary work on in-context learning for system identification introduced in
Forgione et al. (2023)
and further developed in
Piga et al. (2024b)
;
Rufolo et al. (2025b)
.
The aim is to provide a unified framework that integrates and extends these previous contributions, establishing a comprehensive and probabilistic formulation of in-context learning for system identification.
Within this unified setting, the present work introduces the following technical contributions:
•
Extended methods for long-context processing:
A novel ensemble-based strategy with probabilistic weighting is proposed to efficiently handle long input–output context sequences.
Compared with the patching approach of
Rufolo et al. (2025b)
, the new method achieves higher in-distribution accuracy and reduced meta-training time, at the cost of a slight increase in meta-inference time.
•
Probabilistic synthetic data generation:
The data generation strategy of
Piga et al. (2024b)
is reformulated within the probabilistic framework, enabling the production of uncertainty-aware synthetic datasets for training classical system identification algorithms.
•
Benchmark validation:
Where
Forgione et al. (2023)
;
Rufolo et al. (2025b)
focused mainly on simulated scenarios, we systematically evaluate the full proposed architecture on multiple nonlinear system identification benchmarks from the nonlinear benchmark initiative
[
27
]
, demonstrating robustness and generalization on real experimental data.
•
Model adaptation study:
We assess the framework in an out-of-distribution (OOD) scenario in which both the dynamical systems and the input signals differ from those used during meta model training. We show that fine-tuning by matching only the inputs, while keeping the family of training systems fixed, achieves performance comparable to full adaptation. This result is practically relevant for scenarios where the system dynamics are uncertain but the excitation signals, chosen by the user, are known in advance.
Taken together, these contributions go beyond our previous works
Forgione et al. (2023)
;
Piga et al. (2024b)
;
Rufolo et al. (2025b)
in several ways. First, the probabilistic formulation of synthetic data generation yields uncertainty-aware synthetic datasets and a principled mechanism to down-weight unreliable synthetic samples, addressing the growing need for more reliable synthetic data in machine learning. Second, the adaptation study shows that fine-tuning only the input side of the meta model can already recover most of the benefits of full adaptation, which is particularly relevant in applications where excitation signals can be designed but the system dynamics remain uncertain. Finally, by combining these elements with long-context processing in a single architecture and by carrying out a systematic evaluation on standard nonlinear benchmarks, including systems that differ from the WH training class, the paper validates the sim-to-real capabilities of the in-context approach and provides some of the first concrete tools for using meta-learning in system identification, considering the emerging interested in this research direction.
The rest of the paper is organized as follows. In Section
3
, we review the meta modeling framework originally introduced in
Forgione et al. (2023)
. We first formulate a point estimation problem of system outputs as in
Forgione et al. (2023)
, and then extend this formulation to the more general case of probabilistic predictions. Model architectures and training algorithms are discussed in Section
4
, followed by novel approaches to manage long context sequences. The first one is based on sequence patching and inspired by the Vision Transformer
Dosovitskiy et al. (2020)
for image classification. The second one relies on an ensembling of the meta model predictions associated with different (short) context sequences. Section
5
details how the pre-trained meta model can generate synthetic data useful for classical system identification to estimate a parametric model of a dynamical system of interest when the training data are scarce or insufficiently informative. Examples showcasing the effectiveness of the meta learning paradigm are reported in Section
6
, including benchmark performance and model adaptation analyses. Concluding remarks are drawn in Section
7
, along with directions for future research.

6.2.2
Benchmarks
The pre-trained meta model

\mathcal{M}_{\phi}

The adopted benchmarks consist of

Notably, these datasets are used solely for testing, with no additional training performed on the benchmark-specific training data. The available training datasets serve only as context for the pre-trained meta model
ℳ

The benchmark systems are chosen to span a spectrum of structural proximity to the synthetic training distribution, in order to stress-test the framework under varying degrees of distribution shift:
•
Wiener–Hammerstein (WH) benchmark.
This is an
in-distribution
test: the synthetic pre-training data are WH systems, so performance here validates that the framework correctly exploits the pre-training prior on systems drawn from the same class but generated in an experimental setup.
•
Coupled Electric Drives (CED).
The CED system is structurally close to a WH model: it consists of a linear dynamical core followed by a static nonlinearity, which matches the WH cascade structure.
Good zero-shot performance on CED therefore confirms that the learned prior transfers to near-distribution systems with similar compositional structure.
•
Cascaded tanks with overflow.
This system exhibits a piecewise-linear overflow nonlinearity embedded in a nonlinear state-space model that does not factorize as a WH cascade, making it a genuinely out-of-distribution test for the meta model.
The cascaded tanks benchmark is also characterized by a particularly small real training dataset, a regime where classical identification methods are prone to overfitting and struggle to generalize.
In this setting, the inductive bias acquired during WH meta-training acts as a strong regularizer, enabling the framework to achieve competitive, and in some cases state-of-the-art, performance despite the distributional mismatch.
These observations highlight a regime where the proposed meta-modeling framework is particularly effective: when real training data per system are limited, the class-level prior learned from WH-based synthetic data provides a strong regularization effect and improves generalization. Conversely, on benchmarks with abundant task-specific data (e.g., systems with very long and informative training records), carefully tuned classical identification methods can still achieve higher asymptotic accuracy, whereas the meta model primarily offers the advantage of zero-shot prediction with modest performance gaps.

7
Conclusions
In this paper, we presented novel developments on in-context learning for system identification, which enables zero-shot prediction of a system of interest without the need to estimate a model for that specific system. This approach eliminates the necessity to implement traditional system identification algorithms, thereby bypassing the need to select hyper-parameters typically chosen by system identification experts, such as model type, model order, training algorithm, etc. Indeed, the meta model is trained offline using a large set of synthetic data and has the capability to directly infer the behavior of the system of interest based on the available context (namely, available training data) and then predict the system’s output for any query input.
New developments based on sequence patching and ensembling also allow us to process long context sequences, circumventing the quadratic complexity of the attention mechanism of Transformers. Moreover, the meta model can generate synthetic data that can be used for data augmentation in classic system identification. This synthetic data allows to leverage information from systems in the class, as well as efficient processing of training data, implicitly learned by the encoder during the pre-training of the meta model.
Numerical results demonstrate how training a meta model with simulated data allows it to generalize well to real data or systems from a different class, potentially with quick adaptation.
Current research activities are focused on two distinct and seemingly opposite directions. On one hand, we aim at scaling to very large-scale meta models, characterized by billions of parameters. These models are expected to describe very broad classes of dynamic systems, pushing the boundaries of what dynamics meta models can comprehend and predict. On the other hand, research is also focusing on creating distilled architectures. These lighter models aims to enhance computational efficiency and accessibility, making advanced meta models techniques more feasible for real-time applications and edge devices with limited processing capabilities.
Limitations
The estimated meta model
ℳ
ϕ
\mathcal{M}_{\phi}
is able to predict, in a zero-shot learning fashion, the output of a given system of interest based on its context input/output sequence and for any possible query input. However, this predictive meta model also comes with limitations. First, meta training requires a substantial offline computational effort on a large synthetic corpus, which is not needed by classical system identification tools when they are applied to a single system with an ad hoc model structure
Pillonetto et al. (2023)
. Second, the meta model is relatively heavy at inference time, making it less suitable for embedded or resource-constrained implementations compared to parsimonious parametric models. Third, while the meta model achieves competitive accuracy in regimes where per-system data are scarce or weakly informative, classical identification methods trained directly on abundant, high-quality data for a specific system can still reach higher asymptotic accuracy. Finally, the meta model provides predictions rather than an immediately interpretable parametric representation, which can be a drawback when frequency-response analysis, sensitivity studies, or control design require a compact and structured model of the system of interest, although recent works on transformer-based model predictive control
Chen and Cannon (2026)
indicate that such applications are possible but currently more specialized and computationally demanding.
Further developments in the field are expected to draw inspiration from advancements in Natural Language Generation algorithms, exploring the use of alternative architectures beyond Transformers, like Structured State Space and diffusion models. Additionally, there is potential to leverage open models like LLaMA or DeepSeek, applying low-rank adaptations to their weights to tailor them for the specific meta modeling challenges of dynamical systems.
