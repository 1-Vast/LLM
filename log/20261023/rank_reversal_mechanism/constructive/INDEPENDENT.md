## Precise question and the indispensable missing restriction

Application: nominate context-specific double-KO combinations by more-negative published GI. Legal new target feedback could change rankings that source scores predict incorrectly. Positive scalar calibration from the stopped diagnostic does not do this: critic established identical full query ordering in20/20 saved cases. The endpoint recipe remains stopped; a new rank objective does not reactivate it.

A rank-revising update must carry target-feedback information to unobserved pair contrasts. Without a restriction on that transport, two target laws can agree on every source score and legal target support value while giving two unobserved candidate pairs opposite target ordering. The observations and resulting updater state are identical in both worlds; an algorithm must make the same choice and be wrong in one. This elementary indistinguishability argument is not a new theorem or research contribution. It states the exact missing object: a falsifiable restriction linking observed target pair changes to unobserved target contrasts, plus a cost contract. Neither rank loss, agent reflection nor a learned update function supplies that restriction automatically.

Reward R(a,x) is invariant; contexts X are sampled after an arm choice from source distribution PS, whereas performance is evaluated under PT. The bounded, smooth density-ratio family g(alpha,x)=dPT/dPS is assumed to contain truth; known target moments Ml=E_PT[m_l(X)] constrain alpha. TACTIC keeps both an arm set A_t and density-ratio parameter set R_t. Each phase obtains reward samples and additional context samples, estimates weighted arm means and moment violations, removes arms only when suboptimal for every still-plausible alpha, and removes alpha values inconsistent with target moments. The density-ratio uncertainty can change the action ranking: it is not fixed scalar rank calibration. Its stated finite-information contribution is joint adaptive allocation between nuisance-distribution resolution and arm resolution, compared with a naive two-stage fixed half-budget weighting-then-identification procedure. TACTIC+ discretizes the parameter search with epsilon nets; sample-count claims must not be confused with free computation as dimension/resolution grows.

This is a legitimate scientific/algorithmic contribution within a familiar weighting/elimination family. It must not be rejected merely because it uses importance weights. However, it handles covariate shift with fixed conditional R(a,x), not a context-specific change in the conditional intervention law. We do not have authenticated target mixture moments, density-ratio realizability or random post-action cellular-context samples under this GI archive contract. Treating cell line as both conditioning response and a nuisance distribution would conflate conditional shift with mixture shift. TACTIC is a relevant ordinary control if a later application actually supplies those assumptions; it is not evidence that weighting learns cell interaction changes. It also has no improved-improver experiment.

## New primary2: do not resolve rankings irrelevant to a representative decision

Read official original HTML https://arxiv.org/html/2610.16840v1 (626187bytes; SHA2562030fc1d61add83441a07c080ab1f123d4a929d0c415ea7a366e6888434c6a0d). Inspected section2 feedback/decision definition, section3 GFM/AFM elimination and instance-gap statements, section4 lower-bound definition, appendixC oracle-based Track-and-Stop scope and computational discussion; no full proof or implementation reproduction.

One arm pull returns an entire M-objective noisy reward vector. The target is a small L-arm representative set minimizing worst weighted degradation from objective-wise ideal values, not identifying every objective's best arm or recovering the full ordering. GFM-Elim maintains objective benchmark candidates and known-group representative candidates; it samples the union of still-relevant base arms, using one observed vector in every unresolved role. Confidence intervals prune objective benchmarks and representatives separately. The effective per-arm gap tracks its last unresolved role, giving a stated finite-time sample bound proportional to a sum of inverse squared effective gaps. AFM-Elim extends elimination to size-L candidate sets. This can avoid resolving tiny objective-wise differences irrelevant to the representative decision without requiring low-rank rewards.

The main distinction is a genuine decision-identification problem and shared vector-feedback operation, not merely changing a prediction loss. Nevertheless it is published already, and the purported sample benefit relies on receiving all objectives from each paid pull. Here one target-score reveal does not buy all target contexts and repeated independent noise samples; the archived source screens and author normalization bundle have already been measured. Reusing five exposed columns as fresh full-vector pulls would invent a different cost oracle. Also nominating a small covering set across multiple backgrounds changes our target; no user/application evidence makes that replacement preferable to context-specific functional prediction or drug selection. AFM candidate families are combinatorial. Its asymptotic Track-and-Stop statement explicitly uses exact optimization oracles and is not the paper's practical evaluated routine; a polynomial bicriteria alternative trades a larger output-set budget for computation. No free global solution or improved-improver gain follows.

## Distinctions required before any new core

Low-rank/context-factor models already permit rank reversals through changing latent context coordinates; a new cell restriction would need prospective evidence that its contrast transport is more identifiable/sample-efficient at matched information and cost. Conditional ridge, joint source-plus-gene models and ordinary context mixtures are likewise genuine rank-changing controls when feedback changes their coefficients/mixture weights. Their familiarity does not disqualify a biological contribution; we simply have no new restriction here that they cannot represent or exploit as efficiently. The stopped endpoint result cannot supply it by relabeling the same residuals.

GP active learning or ordinary bandit elimination can already acquire feedback where competing nominations remain uncertain. TACTIC and few-for-many supply particularly concrete examples of nuisance-aware and decision-equivalence-aware finite-information allocation. A proposed 'ask only about uncertain reversal' operation is therefore insufficient unless it yields a new valid observation/transport restriction, new guarantee or measured cost advantage against those ordinary procedures. Decision-oriented training may improve top-k utility but is not by itself a reusable update mechanism. Extra task/source fitting and all policy-search evaluations belong in the budget.

MeRLOT/SIB already demonstrate support-driven learned functional/gradient updates optimized with held-query losses; another query-conditioned rank updater does not establish objective novelty. The prior decision-proxy joint-law counterexample already showed why preserving decision-relevant joint information can matter without explicit nuisance identification; renaming that principle 'reversal memory' adds nothing. The AZ effect-coordinate direct-model defeat, Norman/endpoint diagnostic limits, monotone-threshold ranking preservation and stopped bare J/teacher/resolvent families remain binding negatives. This report introduces no nonlinear rescue, untested teacher or latent-dimension expansion.
