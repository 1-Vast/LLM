## Four actual prediction operations and information parity

For each pair p=(a,b), x_p is its four-source-score vector and m_p its source mean. Source-vector scaling is fit without target query outcomes. The target residual for support is r_p=y_p−m_p.

1. Source mean: predict m_p without target labels. Its zero-update status and lower label use are disclosed.
2. Affine source-vector ridge: yhat=intercept+beta'x, selected using only permitted support/source tasks. This checks source offset/scale/reweighting.
3. Strong nonlinear direct: a small fixed kernel or tree menu using x and the same gene/pair-identity information granted to the additive correction. A useful compact comparator is kernel ridge with K=RBF(x,x')+gamma z_p'z_p', where z is the gene-incidence vector. This joint nonlinear-plus-endpoint model permits both source-response nonlinearity and additive endpoint structure. A bare four-input nonlinear model alone must not be described as having the same information as a gene-identity updater. Keep menu/cost finite and frozen; no giant unplanned search.
4. Ordinary endpoint-additive residual update: yhat_p=m_p+alpha+delta_a+delta_b, with shrinkage on deltas estimated from S only. It is a conventional incidence-design ridge/mixed-effect model. Nodes absent from support retain the declared prior correction (usually0), never a target-wide estimate. The model tests endpoint-associated transport error, not true pairwise mixed interaction revision.

For cleaner attribution the additive residual can be anchored on a selected affine source predictor instead of m, but then also retain the pure affine arm and explicitly separate source reweighting from endpoint correction. Choose the anchor before target values; never switch after a disappointing result. Nonlinear direct receives this same skip/identity information. Hyperparameter evaluation counts, source fitting, target fitting and wall/memory costs are recorded; equal config count is not equal CPU.

The author has anchor/query scoring roles. Symmetric biology does not imply identical measurement processing. Preserve metadata roles through grouping and, if they can be authenticated without outcome selection, include a predeclared role-aware additive nuisance comparator alpha_anchor(a)+beta_query(b), or at minimum report role confounding as an unresolved explanation. It must not be introduced only after a symmetric correction wins. Mirrored measurements cannot be split across support/query to give an apparent identity-transfer benefit.

## What to measure, without mining another restriction

Primary evidence should be common-Q MAE/MSE gain versus the best validation-selected ordinary comparator and the actual 128→512 error reduction. Report each context/mask, pooled equal-context summaries and support/query counts. For decision relevance, predeclare a fixed finite top-k fraction/count and compute nominated-score regret or achieved true published score relative to a query-only oracle using the correct sign. The oracle uses query labels only after predictions freeze. No FDR threshold or clinical efficacy claim. Choose k and a useful gain margin prospectively; do not infer them from observed histograms.

Save predictions and residuals by grouped pair before aggregating. Evaluate endpoint-associated error using support-trained corrections on query, not averages fitted from query residuals. Report support coverage of query endpoints and pair incidence; this separates observed-endpoint interpolation from unseen-gene transfer. Compare correction predictions across the three fixed support packages on their common Q to assess repeatability, while recognizing all three share query truth. Reproducible means consistent error direction and held-query improvement, not only a large coefficient in one support fit.

A bounded descriptive per-gene query-residual plot can locate remaining errors after all model scoring freezes, but cannot be promoted as a discovered predictor or tune a mask in this run. It may formulate one later independently evaluated restriction. No multiple-testing causal claim is warranted, and pair bootstrap intervals do not create new biological backgrounds. A five-context leave-one-out table plus repeated-mask spread is more honest than treating thousands of pair rows as independent evidence for transport to arbitrary contexts.

## Normalization structure versus biological law

Per-anchor expectation fitting, residual centering/scaling, mirrored-direction aggregation and final pair-panel standardization can induce role/endpoint-associated constraints and dependence. An additive correction can exploit those patterns even if cellular interactions have not changed. Its gain on published GI therefore establishes at most predictable score-construction/context error under this release contract. It cannot identify whether a coefficient represents growth biology, library effects or normalization. Source-vector affine/nonlinear controls are necessary because global centering/scale or nonlinear transport may explain the entire apparent signal.

Do not standardize the target query panel anew to “remove normalization”; that uses its outcomes. Source-only/support-only affine recalibration is legal and is the relevant ordinary control. Raw/control-referenced fitness would be a separate observation contract, not another sensitivity computed from unauthenticated counts. No new counts acquisition is needed for this score diagnostic.

## Decision gate: which outcomes justify later work

If source mean is already strong and all target adaptation gains are inconsistent or vanish against the joint nonlinear/endpoint control, record no usable recurring-error lead at these budgets and stop this diagnostic. Do not lower margins, add latent teachers or tune on lung outcomes.

If only affine/vector reweighting works, retain ordinary calibration/transport utility; this does not motivate a new interaction law. If endpoint correction yields repeated common-Q gains across masks and several backgrounds, persists at512support, and improves the predeclared decision endpoint beyond affine/nonlinear controls, it supplies a concrete error pattern worth a subsequent restriction hypothesis. It is still ordinary endpoint adaptation and could reflect author normalization. If the joint nonlinear-plus-endpoint arm matches it, the simplest interpretation is ordinary conditional structure, not an updater discovery.

A source-only result is valuable even with no new primitive. A distinct later mechanism would need a prospectively specified cross-context structure on these predictable errors and evidence on a newly assigned audit role; do not consume lung values merely because the development pattern looks interesting. A549/A427 remain untouched until a separate reviewed protocol. No result from five masking replays counts as inherited-U, world/agent value or improved-improver benefit.
