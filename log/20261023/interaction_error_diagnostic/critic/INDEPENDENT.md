## Same-information estimators and selection

Source mean/zero-target-fit is a meaningful frozen reference. Affine ridge uses the four source values with an intercept, source/support-only scaling, and penalties selected entirely inside the paid target support. A single source-vector mean offset is another useful low-complexity reference. The strong nonlinear direct predictor must receive the same source vector and gene IDs as any additive method claiming an information-matched comparison, or be complemented by a direct method that does. Comparing gene-additive residuals to a nonlinear model denied gene identity only estimates the added input package, not a superior update rule.

An endpoint-additive residual model can use y_hat=base(x)+alpha_gene_a+alpha_gene_b with ridge shrinkage on target-support residuals, zero/prior fallback for unseen genes, and an intercept treated explicitly. It is ordinary two-way/random-effect adaptation. Freeze whether the base is source mean or selected affine; if both are tested, retain both with their separate search costs. A frozen-base additive update isolates residual structure; jointly refitting base plus endpoints is a different legitimate model. Label either honestly.

Use the same target-support folds for affine/nonlinear/additive selection. Four folds yield32/128 validation observations at the two budgets; three/five folds are also legal if fixed. All transformations and base fits affecting inner predictions must be trained on each inner training fold. Do not prefit an affine base on all support then evaluate additive residual hyperparameters on residuals from that base in held-out support folds: inner heldout labels would already affect the base. Refit the selected full pipeline on all support only after inner selection. Source-derived auxiliary training is permissible if specified and charged equally; it must not include the pseudo-target query values via other tasks' cached artifacts.

Identical candidate counts do not mean equal CPU. Freeze small sensible menus; log all fits, feature dimensions, tuning wall time and source/preprocessing time per arm. Report measured time rather than asserting the nonlinear baseline is strong just because its name is nonlinear. No requirement to train a giant world model for this diagnostic. If the strongest direct model wins, retain its error pattern rather than adding an editor to force a mechanistic story.

## Minimal falsification and decision gate

Primary metric: per-context heldout MSE in the published GI coordinate, with relative improvement against the prespecified selected ordinary baseline; aggregate contexts equally, not by rows. MAE and negative-GI top-k selection are useful secondary metrics only if fixed before labels. A rank metric requires confirming the endpoint sign convention before it is called utility; otherwise call it score ranking. Never invent clinical value from standardized GI.

One executable conservative advancement gate is >=5% equal-context MSE reduction at512 support versus the strongest preregistered ordinary non-endpoint baseline, improvement in>=4/5 contexts, with the128-support direction and same fixed query set reported. This is a pragmatic development screen, not a biological significance theorem; root may choose a different justified margin before values. A paired pair-resample interval can describe conditional prediction uncertainty, but cannot turn thousands of shared-gene pairs into independent cell contexts. No need to require every exploratory error summary to clear this gate.

If endpoint-additive residuals fail that gate, stop the claim that endpoint sharing offers a promising reusable error law on this configuration; do not tune gene groups/interactions or reopen lung values to rescue it. If affine/nonlinear ordinary transfer clears the gate versus source mean and endpoint terms do not add value, report useful ordinary calibration and stop a mechanism claim. If none improves source mean reliably, stop expanding this exact transfer recipe. If a structured residual survives, nominate a specific next hypothesis and opposing review; do not automatically call it novel or open lung outcomes. A diagnostic can end with a well-characterized negative result and still meet its purpose.

Stop execution rather than silently repair if lung values are decoded, pair grouping fails, query-derived preprocessing/inner-CV leakage occurs, query eligibility differs across methods, or an unregistered outcome-dependent exclusion is needed. Preserve the failed attempt, correct in a new sealed protocol and disclose any development exposure. Reversible synthetic poison/mirror/target-scaler checks are appropriate before new values; no repeat of old biology/toys is needed.
