## Decision before attachment/schema inspection

CONDITIONAL_GO_METADATA_ONLY. A static HCC functional-response catalog can support a small, useful test of transferable finite-feedback updating. It cannot by itself establish a dynamic virtual-cell model, a scientifically autonomous agent, or RSI. Ten screened tumor donors neither establish nor refute power for a still unspecified effect. The independent units and attainable effect precision must be assessed after lawful schema qualification and a separately frozen numerical protocol. No novelty or performance claim is currently supported.

The application is selecting promising drugs for a new patient-derived HCC organoid after paying for a small subset of drug assays. This is an ex vivo prioritization component, not demonstrated patient treatment benefit. Unless matched normal labels are verified for the same donor, utility must concern tumor response, not therapeutic selectivity. Baseline RNA/WES/CNV is optional authenticated pre-intervention information; do not infer perturbed trajectories.

## Minimum lawful task

1. Authenticate attachment membership, donor/model IDs, drug identities, units, direction of response, assay duration, dose or curve-summary semantics, repeat structure, preprocessing and missing/censored labels before fitting. Confirm whether the alleged 100-drug menu is common across qualified donors. Do not turn an IC50 reported outside assay range into an exact continuous label.
2. Group all tumor/normal, 2D/3D, passage and repeat records from one patient in one outer split. Never let a paired monolayer response for a held-out patient become a free source feature. Technical repeats affect assay precision, not independent donor count. If independent nonpatient cell lines are included, their source/test status is declared in advance; they do not inflate HCC patient replication.
3. Begin with a fixed, source-only chosen support menu and one small support budget, then predict all eligible unqueried drugs. Fix drug ranking direction, utility, missing-data policy and tie handling before held-out values. Repeated support draws quantify support sensitivity but are not independent donors. The replay labels are originally measured outcomes; the selection policy was not run by the authors and must be called offline replay.
4. A source task can produce an actual updater history by fitting a declared model before/after its allowed source support and recording query increments. Culture-format response differences are not algorithm update histories. The candidate transferable law must be specified before its evaluation; a learned low-rank covariance is a legitimate component but initially an ordinary empirical-Bayes/meta-learning baseline, not a novel law.
5. Source-only development and donor-disjoint final evaluation are required. With limited donors, a fully nested leave-one-donor-out estimate is possible for a fixed procedure, but it does not create a chronologically untouched cohort after repeated researcher inspection. Reserve untouched final donors if their number and schema permit; otherwise report cross-validated component evidence and selection uncertainty honestly. Do not select a favorable donor order after seeing outcomes.

## Mandatory simple comparisons for the first component test

All methods receive the same source donors, pre-assay features and paid target labels, with the same response transforms and source-only tuning opportunities.

- No-update drug mean/source-only direct predictor; target intercept or affine calibration when lawful for the response scale.
- Ordinary retraining/union refit, and regularized residual ridge or kernel completion using the same observed target drug responses. Baseline rank and regularization are source-selected.
- Low-rank matrix completion or empirical-Bayes covariance conditioning, including signed variation; this addresses prior API failure where a signed mean erased a shared axis.
- A learned target updater versus its frozen initialization and a fixed ordinary updater. If inherited model state and inherited updater are separate claims, test them separately; do not compare an informed updater only with an uninformed model.
- A simple mixture of candidate and conventional predictions, fitted only on source tasks. If a selected procedure is claimed, compare source-only fixed procedure selection and equal-total-cost random/finite procedure search.

The first test need not add an active acquisition policy or full world model merely to satisfy a diagram. If later claiming agent selection benefit, hold updater fixed and compare random, fixed drug panel, standard uncertainty/diversity/acquisition rules under the same number of assays and source-search cost. If later claiming WM value, add a matched-information direct predictor and static structured model so a mechanistic or dynamic interpretation has an actual competing explanation.

Count source fitting, source-search evaluations, hyperparameter trials, model calls, target fitting, and target assay queries separately and in total. An inherited updater's offline cost cannot disappear from an equal-budget comparison.

## Outcomes and boundaries

Primary utility should reflect the declared drug shortlist (for example, mean withheld response of a fixed-size selected set or regret relative to the eligible measured menu). The exact endpoint and shortlist size require schema qualification and source-only design. Include predictive error and rank quality as secondary diagnostics. Report paired donor differences and individual donor results; use donor-level intervals or an exact donor-level test where its assumptions hold. Drug rows and repeat draws must not be treated as independent patients. No arbitrary numerical success margin or power claim is registered before measurement-scale qualification.

Pre-register a practically useful margin and an uncertainty rule in the subsequent numeric protocol, rather than equating a positive point estimate with success. A small exploratory result can justify an external test; it cannot establish generality. A static catalog can demonstrate updater transfer but does not contain a changed improvement strategy merely because procedures are refit on more rows.

Level3 requires separately recorded old and updated improvers, the same starting updater and same held-out improvement tasks for descendants, equal search/evaluation budgets, and an improvement-efficiency endpoint. An E0/E1 predictor comparison or inheritance of weights alone is not that test. This data might provide component tasks, but adequacy for multiple disjoint generations is unknown.

## Stop / revise conditions

- STOP current dataset-task pairing if table identity, response semantics, patient grouping or usable shared drug labels cannot be authenticated. A missing attachment only stops that requested oracle, not the entire project.
- REVISE to a narrower documented component if only aggregate curve summaries or only subset coverage exist. Do not invent timecourses, assay noise or counterfactual secondary labels.
- STOP candidate promotion if its apparent benefit is explained by intercept/affine adjustment, covariance conditioning, ordinary refit, simple mixture or the same-cost procedure search; preserve any useful conventional result without calling it a new core mechanism.
- STOP any selectivity claim lacking patient-matched normal outcomes; do not silently replace selectivity with tumor-only efficacy.
- STOP current improvement-law claim if it only works for a retrospectively selected split/support set, changes after protected outcomes, or fails the predeclared utility/uncertainty rule. Do not repeatedly mine the same held-out donors.
- Missing dynamics, few donors or absence of a novel foundational operator alone are not reasons to reject a bounded component experiment. Conversely, a successful static component does not complete the full objective or justify a WM/RSI label.
