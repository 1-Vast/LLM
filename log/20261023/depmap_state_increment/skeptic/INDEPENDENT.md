## Strongest objection: perturbation information versus modeling capacity

The intended positive claim must be precise. The full menu contains a nonlinear relative-state RBF; the nonperturbation menu contains only QC-linear and same-target panel-context linear. A full-menu victory can therefore reflect nonlinear context modeling rather than information particular to the target's perturbation state. The protocol can measure this exact menu contrast, but cannot infer that target-specific perturbation state was necessary. Add a same-target panel-context RBF, with the same lengthscale convention, regularization grid and nested selection. If QC is an important nuisance explanation, give QC a same-budget RBF as well, or explicitly restrict any positive interpretation to the declared linear-QC competitor. This is a simplicity control, not a demand to fit an unbounded model zoo. The same-target restriction also limits context transfer: a context-only global kernel should be considered if making broad 'all nonperturbation information' claims; otherwise call the comparison the fixed restricted menu. A constant-context or nonlinear-nuisance explanation is unresolved without those controls.

The panel mean contains every paid query RNA vector including its own target; relative state uses that same panel. This is lawful given the explicit transductive information contract, and it is not untreated basal RNA. Avoid claiming a clean causal decomposition of basal versus perturbation-specific information. Per-target contribution to the mean, selected-panel composition and recovery changes can enter both context and residual. No free-expression-predictor or hypothetical world model is being evaluated.

## Source gene priors, residual construction and exact nesting

Source gene mean uses the training labels of the same gene; this is a strong appropriate ordinary prior for known targets in a new line. Residualizing each source y against its source gene mean is not hidden-query leakage, although each training observation contributes to its own baseline mean. It is a two-stage plug-in estimator, not cross-fitted biological residual or independent history. Because every method shares this construction, it does not by itself invalidate the component comparison. Do not describe it as learned reusable update law. Gene imbalance and absent-source fallbacks must be reported.

The draft says source-only inner tuning, but implement the stronger explicit invariant: for every inner validation fold, recompute gene means, residuals, transcript centering, kernel centering, kernel scale, distance median and any mixture component tuning using only that inner training subset. Reusing outer-source residuals leaks each inner validation label into the target mean. Reusing outer-source medians is weaker unsupervised transduction, still inconsistent with the declared source-only fit contract. Inner validation label must only enter its loss. Full-menu selection must use genuine heldout inner predictions; C/E separately tuned on the same validation losses and then reporting their mixture is a declared two-hyperparameter search advantage, not five equivalent tries. Count/report this opportunity and total fit cost.

Clarify same-target context kernel algebra and centering order before fitting. Centering context vectors before multiplying by delta(target_i,target_j) differs from centering the full product-feature kernel; source conditional-on-target centering is a third operation. RBF kernel centering is feature-space centering, not simply centering input vectors. Specify formulas for K_train, K_query and source normalization, including degenerate zero-scale/zero-distance behavior. A zero correction should reduce to the prior rather than produce NaN. These are implementation ambiguities capable of changing results, not grounds to reject KRR.

## Independent units and claimed transport

Leave-one-line-out evaluates contexts but does not make 1,593 pair outcomes independent. Selected genes recur, lineages may recur, and shared experimental batches can generate strong batch signatures. Batch-heldout is therefore valuable; verify aliases and number of unique actual groups before calling it independently supported sensitivity. Within a heldout batch, aggregate line losses equally, and state whether the overall summary weights lines or batches. Do not interpret the 12/16 sign rule as 16 independent Bernoulli trials. No p-value or clinical transport claim is appropriate. A source gene association may reflect selected essentiality design and survivor-state expression, not target inhibition potency or causal functional dynamics.

## Decision metric and margin

Top-10 genetic-dependency ranking regret is a meaningful bounded panel diagnostic. It is not drug-ranking benefit, selectivity, therapeutic window, intervention-cost savings or real discovery, especially when exact same-pair public Chronos values are already available. Define handling if a line has fewer than 10 finite scores, confirm negative means stronger dependency, and preserve deterministic target-name tie handling. Since all target RNA is already measured, ranking does not demonstrate economical experiment selection.

The 5% MSE improvement cutoff is acceptable as a prospectively chosen research-screen margin. It has no verified connection to Chronos noise, assay reproducibility or economic value. It must never become a biological minimum effect or statistical significance threshold. Strict positive direction in batch sensitivity and no top-10 deterioration are useful safeguards, but can be fragile with few groups; report actual per-line/per-batch differences and absolute regret as well as pass/fail. A gate failure stops this exact frozen menu/preprocessing, not all possible functional RNA research. A pass permits only a new independently testable residual hypothesis; it does not justify retrospectively optimizing these endpoints or building an editor/RSI stack.
