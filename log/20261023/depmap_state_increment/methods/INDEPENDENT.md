## Decision

REVISE_TO_FREEZE, with small specification changes; no demand for a world model or RSI before this useful limited component experiment. Static, already measured RNA can validly test conditional function reconstruction when its acquisition and availability are stated. Successful reconstruction cannot establish an intervention world model, prospective unknown-function value, drug response, adaptive experiments or inherited improvement. The draft already observes these limits. A weak or negative result would stop this menu, not all possible function-bearing state mechanisms.

## Necessary pre-freeze clarifications

1. In every inner fold recompute source gene means, global fallback mean, feature means, kernel scale, RBF lengthscale and training residuals using that inner training partition. The outer-source gene mean must not be reused to construct inner residuals or inner predictions. Recompute final outer fits on all outer-source rows after choosing the program and lambda. This is the most consequential implementation leakage test.
2. Specify kernel C exactly. A target-gated context feature map, centered globally after target gating, does not retain zero cross-target covariance; centering introduces cross-target terms. One valid simple definition is k(i,j)=1[g_i=g_j] * <c_i-mu_g,c_j-mu_g>, with each mu_g estimated on source rows for that target and a source-only global context mean fallback. Divide by one source mean diagonal. This remains PSD and preserves the advertised gate. Alternatively change the advertised restriction and explicitly implement centered gated feature maps. Do not silently switch meanings.
3. Clarify whether F uses raw RBF Gram matrices or source-RKHS-centered RBF Gram matrices. Centering logRNA features before an RBF is a translation and does not center the RKHS kernel. Either is a conventional valid predictor, but only the chosen operation may be frozen and implemented. Define the source cross-Gram centering if used, and define the all-identical source-feature fallback for a zero median distance and zero norm.
4. Batch splitting must use the metadata's actual experiment-batch column, preserve every alias of a line within one group, and freeze the alias-to-batch map before labels. Inner loss is equal-line MSE, even for batch folds; outer batch sensitivity likewise equal-line. Report number and sizes of groups, label missingness and every fallback occurrence. If metadata has only one batch, no valid batch validation exists; do not invent a split. If batch folds leave fewer than two source batches, preregister a fixed regularization fallback rather than consulting heldout labels.
5. A/B/C versus A-G program selection must use the same inner folds, preprocessing and stored out-of-inner predictions. Lambda selection and program selection may reuse the source validation folds: outer predictions remain honest, although inner minimum scores are optimistic and cannot themselves prove improvement. Do not select a globally best program after seeing all outer results.

These are explicit implementation choices, not requests for more rounds of unfalsifiable review. Parent can resolve and freeze them now without response-value inspection.

## Strength and necessity of controls

Gene mean is an important selected-target prior, and C is an informed same-information context baseline: it gets the query line's full paid measured-state panel. C is not a no-RNA baseline and should never be called that. B is QC-only, C excludes target-specific differential states; the full-versus-restricted menu contrast is thus the increment of target-specific RNA over gene/QC/panel context, not all RNA versus no RNA.

D/E/F are themselves strong ordinary direct models and G tests simple fusion; this is adequate to screen this narrowly stated conventional component without learned editors. A score-only low-rank matrix completion baseline cannot infer a wholly unseen line with zero functional support without introducing an information source. Such a baseline is not a mandatory artificial competitor here. Context-conditioned hierarchical or low-rank regression could be useful later, but is not grounds to delay this finite screen or to infer novelty from its absence. If a mechanism is nominated after a positive screen, strong conditional hierarchical/empirical-Bayes and same-information direct alternatives then become required competitors before mechanism promotion.

Full state panel availability is a real cost: it is retrospective/transductive and includes RNA from all ranked interventions, including query-target RNA. State-shuffle controls would be optional exploratory attribution, not needed to establish observed prediction increment and not a license to claim causality. Perturbation-specific state may encode proliferation/depletion downstream of dependency, guide efficacy or selection; this still predicts a hidden score but does not identify the causal intermediate.

## Statistics and stop rule

Sixteen lines with shared targets and batches are not sixteen independent identically distributed biological tasks. Equal-line aggregate and batch sensitivity are appropriate descriptive checks. The 5% / 12-of-16 gate is a finite research screen, not a significance or general efficacy statement; the draft says this correctly. Top-10 regret should use finite available target scores in each line with all counts reported. If fewer than ten are available, preparation should stop rather than silently change the action count. For exactly equal predictions, lexical target ordering is deterministic but can drive A ties; report the number of ties at the cutoff without using alternative tie breaks after results.

Strictly improved line counts and nonworsening regret are meaningful only for the source-selected full and restricted procedures, not best observed menu members. Report each fixed method descriptively, including deterioration; do not salvage a failed predeclared aggregate by highlighting a winner line or method. Failure of this gate supports STOP_FIXED_COMPONENT_MENU, not a universal no-function or no-world-model theorem.

## Minimal verification

Meaningful synthetic leakage test: construct inner/outer grouped toy data and mutate only the outer query labels. Assert all program/lambda choices and predictions unchanged; separately mutate inner-validation labels and assert no inner-training feature statistics or gene means change. Check inner gene-mean reconstruction directly. No-signal check should use truly zero centered features, not arbitrary unrelated random features whose finite-sample fit can be nonzero. Affine translation invariance applies to the declared centered linear models with nondegenerate source norms. Test gated kernel off-target entries and PSD numerically on a small toy. For independent audit, independently reconstruct a representative normalization/gene mean and one selected outer prediction without importing the fitter, with fixed source/query identities and numerical tolerance.

## Unresolved evidence and novelty

There is no new algorithm proposed here, and therefore no affirmative novelty assessment. No biological value or performance is established yet. Useful positive data evidence would be a reproducible target-specific measured-state increment beyond the source-selected informed restricted menu and batch robustness. That would motivate a new, explicit update-rule hypothesis on new isolated data; it must not retroactively turn this static reconstruction into RSI evidence. The actual broad objective remains active and unachieved.
