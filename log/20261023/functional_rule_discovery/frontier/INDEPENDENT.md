### Mani, Vondrick, Zemel, Few-Shot Design Optimization by Exploiting Auxiliary Information

arXiv2602.12112v1,12February2026. Actual scope: abstract/introduction, setting, §§4.1–4.3 including both algorithms, architecture, task setup. No whole-paper result reproduction; source full HTML includes author results but their numbers are not ours.

Original bottleneck: expensive action/design evaluation yields a scalar objective f(a) **and** rich auxiliary h(a), e.g. tactile trajectories or learning curves. A history of related tasks exists. Ordinary scalar BO discards this information; blindly reconstructing all auxiliary outputs may spend capacity on irrelevant features.

Exact operation: source-train a neural predictive posterior P_theta(f_Q | {(a_s,f_s,h_s)}, a_Q) using disjoint context/query functional NLL. Do **not** require reconstruction of query h_Q. Context tokens encode action,function,auxiliary; target tokens contain only action and attend to context. Their temporal auxiliary encoder has an extra(action,function)token, so function can select which auxiliary trajectory features matter. Model parameters are frozen within a new BO task; newly evaluated bundles enter context; conventional PI or another acquisition chooses the next action. Their default query distribution factorizes across target actions.

This is a specific existing operation, not merely a generic claim all models can be written as regression: it already learns from real task feedback what parts of rich observations help predict a different action's future functional result, without needing the full auxiliary forward model. Therefore replacing tactile observations with cell RNA/proteins and objective with survival is **direct application**, not automatically an algorithmic advance. A biological restriction or finite-data/cost advantage could still be valuable, but must be specified separately. It also weakens any claim that a detailed molecular forward reconstruction is universally necessary for useful decisions: a competent functional-query-trained auxiliary model is a strong matched-input opponent.

## At most one candidate considered

**Functional-query-conditioned molecular residual transport.** Current functional prediction mu(a) and predicted molecular response m(a) are frozen during each new functional support purchase. For observed support a_s, create innovations e_s=y_s−mu(a_s) and molecular discrepancies d_s=m_measured(a_s)−m(a_s). Source-learn a small posterior transport U_phi:

mu_new(q)=mu(q)+U_phi(q,m(q),{a_s,e_s,d_s}),

by heldout **functional** query loss across legal source episodes. Preserve molecular predictions for all targets during this correction, so functional feedback cannot falsely claim to have fixed RNA. Inheritance stores phi as the update procedure and resets support context at a new task; predictor-only source weights and support cache are separate objects.

The desired specific hypothesis would be that the *joint pattern* of molecular discrepancy and functional residual identifies when a functional feedback should reverse, rather than merely rescale, another action's prediction. A small source-trained conditional updater might exploit this more efficiently than whole-model fine-tuning at sparse feedback. This is a plausible predictive hypothesis, not a proven mechanistic activity inference and not necessarily new: the exact few-shot auxiliary posterior in2602.12112 already consumes equivalent inputs (subtracting fixed source means is invertible), and ordinary residual neural processes/deep-kernel conditional prediction can implement this operation with the same source functional targets. The current statement supplies **no additional biologically justified transport restriction**, architecture property, statistical benefit or measured recurring error beyond that prior. Consequently I do not recommend fitting it to look for a lucky increment and then declaring novelty.

Ordinary counterpart is concrete and costable, not selfcopy universalization: train the published context/query functional-posterior architecture on the same (action,source prediction,observed auxiliary,function) tuples with equal encoder width, source episodes/functional labels and deployment budget. Include fixed source covariance conditioning and nonlinear deep-kernel conditional regression. A residual mean may be better calibrated than an absolute mean, but that parameterization difference must be isolated; it is not a feedback monopoly.
