## 候选一：干预方向残差符号受限的“幅度保持更新器”

**1. 应用与观测。** 用于同一细胞背景下，已有若干干预（如CDK抑制剂、CXCL9刺激）的真实功能反馈后，预测**尚未测量干预**的响应幅度与排序。需要：干预标签与剂量、同批细胞状态基线（至少可观测的转录/蛋白基线）、功能读数（分泌量、活力或组合响应）。公开入口可考虑Norman组合扰动、TG-GATES重复剂量；具体字段与许可**待查**。

**2. 更新公式。** 设直接条件预测器给出 \(\hat y_0(i,s)\)，普通残差更新为 \(\hat y=\hat y_0+r_\phi(i,s)\)。候选限制为：只用源任务学到的**符号-幅度分离器**，
\[
\hat y(i,s)=\hat y_0(i,s)+\alpha\, \sigma_\theta(i,s)\,|\hat y_0(i,s)-\bar y_s|
\]
其中 \(\sigma_\theta\in\{-1,0,+1\}\) 由源任务反馈学习，\(\alpha\) 为有限幅度系数，\(\bar y_s\) 为同状态均值。可继承对象是 \(\sigma_\theta\) 与 \(\alpha\)，不是任务特定残差。细胞观测结构支持的理由：真实反馈常给出方向（升高/降低）比精确幅度更稳定；metaDRP中“残差符号相同期间丢幅度”正说明符号与幅度应分开继承。

**3. 何时胜过强对手。** 可观察重复错误：直接条件预测在**同符号、跨剂量/近邻干预**上系统性压缩幅度，而联合重训练因样本少把幅度拉回均值。若候选在留出干预上保持符号且恢复幅度，则可胜过普通残差更新与简单混合。最强反对：它可能严格等价于“带符号约束的岭回归残差更新”，或仅等价于对 \(\hat y_0\) 做方差校准；若源任务符号不可迁移，则失败。全历史序列直接预测若已隐式学到剂量-幅度关系，本候选无优势。

**4. 小型真实实验。** 独立单位：留出干预或留出剂量层，而非随机细胞。源/支持/查询：源任务学 \(\sigma_\theta,\alpha\)；支持集只含少量同符号反馈；查询为未测干预。强对手：同信息全历史序列直接预测、联合重训练、普通残差更新、简单混合、等预算主动学习。预注册成功：查询集上幅度误差显著低于全部强对手且排序不降；停止：若与符号约束岭回归差异不显著，或跨源任务 \(\sigma_\theta\) 一致性低于预设阈值，停止。

**5. 未证明部分。** 世界模型：未证明细胞状态转移可分解为可继承符号场。智能体：未证明主动选点优于固定分层。继承：未证明符号跨细胞背景稳定。RSI：无任务证据，仅为假设。

## 候选二：源任务“可更新性分层”选择器

**1. 应用与观测。** 用于决定**哪些源任务反馈值得继承**到新药物响应任务，减少后来任务的反馈量。需要：多个源干预的真实功能反馈、每任务的小支持集、统一查询功能读数。数据入口同候选一，**待查**。

**2. 更新伪代码。**
```
for 源任务 t:
  用支持集算普通更新后的查询改进 Δ_t
  记录可继承特征 x_t（基线离散度、反馈符号一致性、剂量覆盖）
学 p(Δ_t>0 | x_t)   # 仅用源任务交叉验证
新任务: 选 p 最高的源更新器做初始化，
       仅当新支持集反馈与源符号一致时启用，否则回退直接预测
```
可继承对象是**选择器**与源更新器参数，不是全历史。细胞结构支持：反馈可用性在干预类型间高度不均，盲目继承会负迁移；先选“可更新源”比改更新公式更基本。

**3. 何时胜过强对手。** 可观察错误：普通联合重训练在低反馈源上被高反馈源淹没；等预算主动学习选点但未选源。若候选在新任务少反馈下优于全历史直接预测与普通元学习，则成立。最强反对：它可能严格等价于按源任务验证误差加权，或只是普通元学习中的任务采样；若源任务数少，选择器过拟合，失败。

**4. 实验。** 独立单位：源任务与查询任务按干预族分层。源/支持/查询合法分离。强对手：全历史序列直接预测、普通联合重训练、普通元学习、等预算随机源选择。成功：新任务反馈预算减半时查询误差不高于全预算直接预测；停止：若与验证误差加权无显著差异，停止。

**5. 未证明部分。** 世界模型：未证明源可更新性由细胞状态结构决定。智能体：未证明选择器可在线改进。继承：未证明选择规律跨数据集迁移。RSI：仅为假设。

**最强反对解释：** 两个候选都可能退化为已知正则化或任务加权；若全历史直接预测已含足够信息，则“继承更新器”无独立价值。最值得寻找的观测关系是：**真实反馈的符号一致性是否跨近邻干预稳定，而幅度是否可由源任务校准**——这决定候选一是否值得做。
