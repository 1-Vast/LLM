## Concrete application, observations and proposed transferable restriction

Application: triage screening compounds whose apparent transient growth inhibition may fail to persist because extracellular drug activity decreases. The action in the proposed retrospective benchmark is purchasing an additional matched functional-activity assay for a selected compound/context; it is not choosing a new resistance intervention. Observation includes an already purchased full drug-exposure growth curve, concentration labels and controls; the expensive additional label measures residual functional drug activity through a separate reporter assay. Later queries are disjoint compounds whose functional labels remain hidden. This is proximal activity-persistence screening, not mammalian virtual-cell repair, clinical efficacy or safe treatment selection.

The source gives a concrete law worth testing rather than a generic model interface: at comparable overall growth inhibition, delayed recovery dominated by lag extension is associated with loss of drug activity, whereas drug target class alone is insufficient. Authors tested38compounds in one E.coli background and report an ROC AUC0.83 for a lag-directed threshold using their functional annotations. That is a same-study fitted association, not our held-compound prediction, external validation or updater result. The source explicitly identifies exceptions and acknowledges that delayed cellular adaptation/subpopulations can yield similar shapes.

Let phi_i be a declared low-dimensional shape representation extracted only from compound i's purchased growth curves using source-fixed scaling. Let q_i be a measured residual-activity outcome (or the source's limited binary functional annotation if continuous activity is not recoverable). Candidate operation: retain a shared prior lag-to-activity mapping m(phi), then update a low-dimensional calibration from a small legally acquired functional support set S:

    P_S = P_0 + sum_(i in S) w_i b(phi_i)b(phi_i)^T,
    h_S = h_0 + sum_(i in S) w_i b(phi_i) q_i,
    theta_S = P_S^(-1) h_S,
    qhat_j = b(phi_j)^T theta_S.

Here b is a small prespecified basis containing the lag direction and, only if justified from source training, growth-rate/capacity covariates. For a binary label, replace the Gaussian update by regularized logistic calibration and state that change before fitting. The proposed restriction is a stable shared shape-to-functional-activity law with a small context calibration, so feedback about a few compounds transfers to other compounds. This is ordinary Bayesian linear/logistic calibration, not a new mathematical operator. Its practical value would have to come from the justified response-law restriction and assay-budget efficiency, not a renamed inverse-Gram update.

This is more modest than reconstructing intracellular dynamics: it predicts a separately measured functional consequence from observed response shape. No unseen compound receives its own functional label for free, and full growth-curve/dose/control cost is charged. A full-curve feature is not a legal early-prefix signal; this candidate makes no early warning claim. Source-wide AUC50 interpolation and barycentric min/max require care: held functional labels may remain hidden, but any adaptation of feature scales using target curves must be declared equally available to every method. If a prospective low-curve-budget claim is desired later, the source's complete curve features do not supply it for free.

## Strongest ordinary opponent and actual potential distinction

The update above is exactly ordinary regularized regression on the same basis. Ordinary same-basis refitting is therefore an equality control, not merely a weaker baseline. No claim is made that a world model is necessary. The only scientifically worthwhile question is whether a source-fixed shape restriction gives more useful new-compound activity predictions per functional assay than strong same-information unconstrained alternatives, and whether its calibration transfers across independent assay contexts.

Include source-only mapping/lag threshold, ordinary ridge/logistic on the identical shape basis, nonlinear same-feature kernel prediction, full-growth-curve conditional direct prediction with the same purchased labels, drug identity/class/descriptor predictors, ordinary source-plus-support retraining, head/residual calibration and fixed source/calibrated mixtures. If actively choosing functional assays, compare random, ordinary uncertainty and equal-cost decision-directed selection, charging curve fitting, all source labels and search. Equal-budget selection over basis/rank/calibration rules is mandatory; calling a selected basis inherited knowledge does not remove its search cost.

An updater can only claim finite-budget usefulness over a fixed predictor if source-selected calibration improves held-compound functional utility at equal total information/cost. It cannot claim originality over identical ordinary refitting. Any genuinely distinct later mechanism would need a testable cell/assay restriction beyond this low-dimensional calibration—for example independently stable calibration shared across new assay contexts—and evidence that ordinary equally constrained prediction does not already realize the same result.

## Independent tasks and the present specific missing restriction

Thirty-eight compounds are potential disjoint query units within one panel, not38independent environments for inherited-updater training. Same-plate triplicates are not automatically independent runs. The published strain comparisons were selected mechanistic controls, not an authenticated broad distribution of later contexts. README's 'all drugs and all strains' describes stored data scope, not a cross-product or independence guarantee. File metadata must first establish compound/context IDs, pairing of functional assays to curve features, replicate/run grouping, missingness and whether functional labels are selected versus exhaustive. No MAT headers or values have been examined here.

The exact missing mechanism premise is: does a low-dimensional shape-to-functional-activity calibration learned on some compounds remain stable across genuinely independent later assay contexts, rather than merely fitting the original lag/classification association? The current source supports within-panel association and a functional readout, but not this across-context stationarity. Without that premise, feedback can support ordinary held-compound prediction but not inheritable update-rule evaluation. A sparse collection of hand-picked context pairs cannot be multiplied into independent task generations by support resampling.
