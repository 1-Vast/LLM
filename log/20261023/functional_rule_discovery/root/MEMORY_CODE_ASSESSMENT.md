## Actual inspected operation

`tta_library/metanet/TTT.py` defines TTTMGG and its TTTLinear sequence block. In the linear block, a minibatch computes reconstruction_target=XV_mini_batch-XK_mini_batch; ln_fused_l2_bwd forms the analytic gradient of a layer-normalized squared reconstruction objective. Causal/primal/dual branches maintain fast W1/b1 states and gradient accumulators; eta determines writes, then query-projected hidden states are emitted. TTTMGG delegates to this block, detaches the returned last_minibatch state dictionary and returns tanh(hidden_states). These are specific learned write/read operations with nonlinear normalization/activation, not an exact fixed linear MetaSGD diagonal multiplier.

The active application wrapper previously downloaded by critic computes current gradients via backward, maintains first/second exponential gradient moments, concatenates normalized momentum/current gradient and calls mgg under torch.no_grad; it then writes generated norm-parameter updates into the optimizee. The source class docstring claiming 'forward only' must not override the literal backward call and parameter replacement. no_grad around the generator does not prevent its explicitly computed fast-state writes, nor imply the entire adaptation has no gradient computation.

## Candidate and strongest simpler controls

The proposed assay adaptation computes all per-support gradients at a common predictor start, runs canonical and reversed fast-memory passes from reset and averages the resulting updates with a source-only consistency penalty. That differs from sequential gradient evaluation at moving model parameters and from the specific prior BeatAML updater, so the old negative experiment is not an operation-level proof against it. However the assay's unordered rows already admit exact DeepSets/batch-sum pooling, and two orders are only approximate symmetry. Nonlinear fixed-start memory is not necessary merely to express an exchangeable support set. Same-history neural-process/set prediction, batch-gradient/meta-learned pooling, same-moment feedforward/LSTM and replay are concrete controls with the same lawful observations and all-in costs.

The known BeatAML study already tested a source-trained order/batch consistency restriction on true functional feedback and found reduced sensitivity without useful predictive gain. This current candidate must explain a new measurable error and a distinct resource advantage rather than reuse exchangeability as new biological evidence. A fixed-point gradient history can reduce repeated optimizee computations but costs storing/computing Jacobians, source unroll training and two memory passes. Small support panels may make exact pooling/replay cheaper. No source here shows that these costs favor the candidate on drug-response tasks, and no cell state-transition supervision is supplied by GDSC functional endpoints.

Disposition: retain a concrete generated-update baseline and its actual fast/slow-state distinctions, but no current biological prototype GO. Do not claim all memory is ordinary diagonal scaling, that all ordered models are invalid, or that prior failure universally refutes this rule. Need a specified finite-resource transfer hypothesis not already achieved by simpler exact set operations, plus qualified data and a frozen functional utility test. No new synthetic order counterexample or old outcome rerun is needed to state this gap.
