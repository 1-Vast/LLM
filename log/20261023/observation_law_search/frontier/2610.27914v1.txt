Real-world observations are noisy and often contain excessive task-irrelevant information. Effective world modeling and planning need to abstract observations into world state representations while filtering out irrelevant information.
However, encoders in existing world models are typically non-adaptive, leading to state representations that are easily distracted by task-irrelevant information. As a result, the model may not selectively filter observations to cater to different task demands.
To address this problem, we introduce ConfigWM, which realizes configurable perception through task-conditioned state extraction. Given a language description of the task at hand, ConfigWM uses it as a configuration signal to steer how visual embeddings are mapped into a task-specific state space, selectively preserving information relevant to the current task while suppressing task-irrelevant variations. Action-conditioned dynamics are then learned in this task-specific state space for planning.
We evaluate ConfigWM in environments with increasing levels of distraction. While existing methods exhibit substantial declines in planning success rate as the environments become increasingly noisy, ConfigWM remains comparatively stable and outperforms the strongest competing method by

1  Introduction
Real-world environments contain far more information and dynamics than are needed for any single task
(
Chen et al., 2025b
;
Bharadhwaj et al., 2022
;
Toso et al., 2026
)
. However, what constitutes a sufficient state depends on the task: different tasks may require different information from the same observation. This challenge becomes particularly pronounced in dynamic environments, where multiple objects or agents may coexist and evolve simultaneously
(
Wu et al., 2026
;
Wang et al., 2026b
)
.
In such settings, only some of these dynamics may be relevant to the current task. If task-irrelevant dynamics are retained in the state, the world model must account for transitions that do not contribute to the current objective, making prediction and planning inevitably difficult.
Existing world models do not explicitly resolve this challenge.
In particular, feature-based world models construct states from task-agnostic representations
(
Zhou et al., 2024
;
Assran et al., 2025
;
Baldassarre et al., 2025
)
.
However, a desirable state should act as an information bottleneck, retaining only the information sufficient for current task while suppressing the task-irrelevant information
(
Pacelli and Majumdar, 2019
;
Eftekhar et al., 2024
;
Cui et al., 2026
)
.
This is difficult to achieve with task-agnostic methods, since the relevance of an object can change with the task: the same object may be the target under one instruction but a distractor under another.
The same observation can therefore require different representations under different task queries, whereas task-agnostic state representations remain unchanged.
Figure 1:
ConfigWM Architecture.
In the literature, it has also be noted that task-agnostic approaches may retain both target and distractor dynamics in the state
(
Nikulin et al., 2026
)
.
These limitations motivate adapting representations to better preserve task-relevant information. A more direct alternative is to introduce task conditioning directly into perception. This motivates
configurable perception
(
LeCun and others, 2022
;
Shi et al., 2023
;
Marza et al., 2024
)
, where the current task configures visual encoding to construct a task-relevant state.
In this work, we introduce
configurable perception
into world modeling and propose
Config World Model (ConfigWM)
, an action-conditioned world model built on the task-relevant state abstractions, as illustrated in Fig.
1
.
Inspired by VL-JEPA
(
Chen et al., 2025a
)
, we build ConfigWM on a configurable encoder that steers visual prediction with a task query and is therefore naturally suited to realizing
configurable perception
.
The resulting query-conditioned representations define the task-relevant state space, over which ConfigWM learns action-conditioned dynamics for planning.
To evaluate whether
configurable perception
improves world modeling under dynamic distraction, we augment Two-Room, Push-T, and OGBench-Cube
(
Maes et al., 2026a
)
with increasing numbers of dynamic, target-like distractors and conduct controlled comparisons across different training and testing conditions. Baseline methods degrade substantially when trained on clean observations and evaluated under distraction. More importantly, simply exposing them to distractors during training does not solve the problem and can even further impair planning performance. In contrast, ConfigWM remains consistently robust as distraction increases, with an average planning improvement of 22.3%. These results show that robustness does not arise merely from exposure to distractors during training. Rather, conditioning perception on the task allows the world model to selectively preserve task-relevant dynamics while suppressing irrelevant motion, thereby supporting reliable prediction and planning in dynamically distracting environments.
Apart from planning success, we further characterize the quality of the learned states from two complementary perspectives. Physical-quantity probing
(
Maes et al., 2026b
;
Alain and Bengio, 2016
)
measures how well the representations preserve task-relevant physical information, while distracted-to-clean retrieval
(
Garrido et al., 2024
)
evaluates their robustness to dynamic distractors.
Across both analyses, baseline representations are increasingly affected as distractors are introduced, whereas ConfigWM remains substantially more stable. These results indicate that ConfigWM better preserves task-relevant information while suppressing noise.
In summary, the contributions of this paper are as follows:
•
We propose ConfigWM, which realizes
configurable perception
by using task instructions to construct task-relevant latent states and learn action-conditioned dynamics over them.
•
We augment Two-Room, Push-T, and OGBench-Cube with progressively increasing dynamic, target-like distractors, establishing a controlled evaluation setting for world models in noisy environments.
•
We show that ConfigWM maintains stable planning under dynamic distractors and achieves consistent gains in physical-quantity probing and distracted-to-clean retrieval, indicating better preservation of task-relevant information.
2  Related Works
World State Representations.
Recent world models have explored several ways to obtain latent states suitable for prediction and planning, from directly reusing pretrained visual features to jointly learning or further adapting the state representation.
A common approach is to build predictive dynamics directly over pretrained or frozen visual features, using these representations as the state space for world modeling and planning
(
Zhou et al., 2024
;
Assran et al., 2025
)
.
Rather than fixing this state space, other approaches further shape the representation for downstream control. Some jointly learn the latent state with dynamics, reward prediction, and value-learning objectives, allowing task returns to directly influence the learned representation
(
Hansen et al., 2022
)
, others improve predictive state learning through latent regularization
(
Maes et al., 2026b
;
Zhao et al., 2026
;
Terver et al., 2026
)
, explicitly ground the latent space in physical state and motion
(
Yan et al., 2026
)
, or map generic visual features into more compact and control-relevant representations
(
Wang et al., 2026a
;
Fu et al., 2026a
;
Toso et al., 2026
)
. Compact latent representations have also been explored to improve the efficiency of predictive planning
(
Yao et al., 2026
)
.
Despite these advances, task relevance is typically introduced by shaping the learned state, rather than by allowing the current task to determine what visual information is encoded in the first place.
Figure 2:
Constructing noisy worlds.
Columns show observations with an increasing number of dynamic, target-like distractors. Rows show Two-Room, Push-T, and OGBench-Cube. Across all settings, the underlying task, action sequence, goal, and target trajectory remain unchanged.
Steerable Representations.
Recent work has explored visual representations that can be steered by task or language signals, allowing the same observation to produce different representations depending on the current query. Some methods condition the visual encoder directly, enabling its features to emphasize queried objects, regions, or attributes
(
Ruthardt et al., 2026
;
Mao et al., 2026
)
, while others introduce textual conditioning into predictive representation learning, where the query guides the features being predicted
(
Huang et al., 2026
;
Chen et al., 2025a
)
.
However, these methods primarily focus on learning task-conditioned visual representations, leaving open whether the resulting representations can support better action-conditioned world modeling and therefore improve downstream planning.
Language has also been used to condition future prediction and action generation
(
Cheang et al., 2024
;
Brohan et al., 2023
)
. ConfigWM differs by applying language at the state construction stage to obtain the task-relevant states for planning, extending the steerable representations to action-conditioned world modeling.
3  Constructing Noisy Worlds
To evaluate world models under dynamic distraction, we construct
controlled noisy variants
of three widely used visual control environments: Two-Room
(
Sobal et al., 2025
)
, Push-T
(
Chi et al., 2025
)
, and OGBench-Cube
(
Park et al., 2025
)
. Together, they span 2D navigation, planar object manipulation, and 3D robotic manipulation, covering representative goal-conditioned planning settings studied in recent latent world models
(
Zhou et al., 2024
;
Wang et al., 2026a
;
Maes et al., 2026b
)
.
Unlike existing noisy settings that primarily modify background appearance or introduce static clutter
(
Pumacay et al., 2024
;
Rasouli et al., 2025
)
, we introduce multiple
dynamic, target-like distractors
that move independently and compete with the real target, while preserving the original task and target motion. By progressively increasing the number of such distractors, we create nine difficulty levels for each environment, allowing us to systematically vary dynamic distraction without changing the underlying control problem. The resulting matched clean and noisy observations are also used as training pairs for
configurable perception
in our model
. We next describe the distractor construction (§
3.1
) and its instantiation in the three environments (§
3.2
).
3.1  Dynamic Distractor Construction
We construct the dynamic distractors directly in the observation space, without modifying the underlying simulator state or task dynamics. We first use SAM 3
(
Carion et al., 2025
)
to segment and track the target-like objects from valid task rollouts. The extracted object masks are recolored and composited onto another rollout while preserving their original trajectories, producing visually similar objects whose motion remains consistent with the environment but is unrelated to the current task. Since this procedure operates only on the visual observations, it can also be adapted to other environments without modifying their underlying simulators.
As illustrated in Fig.

This matched construction provides both a controlled difficulty axis for studying world models under increasing distraction and the noisy–clean pairs used to train the configurable encoder in Sec.

.
3.2  Environment Instantiations
Two-Room
(
Sobal et al., 2025
)
.
A continuous 2D navigation task in which an agent must move through two connected rooms to reach a target location. We introduce additional agents with similar appearance, creating competing object motion around the query-specified agent.
Push-T
(
Chi et al., 2025
)
.
A planar object-pushing task in which a circular pusher moves a T-shaped block to a target pose. We introduce additional recolored T-shaped blocks, requiring the model to distinguish and track the query-specified block among visually similar moving objects.
OGBench-Cube
(
Park et al., 2025
)
.
A 3D robotic manipulation task in which a robotic arm moves a designated cube to a target location. We recolor the robot arms in complete manipulation scenes and combine these scenes into a tiled observation. This creates multiple simultaneous arm–cube interactions, while the task query identifies the scene relevant for prediction and planning.

We aim to learn a world model with adaptive state abstractions so as to support planning in noisy environments, where multiple dynamic, realistic, and target-like distractors coexist with the main target. Following the configurator view of autonomous intelligence
(
LeCun and others, 2022
)
, ConfigWM uses language to

Below, we first introduce a configurable encoder for configurable perception (§

), then describe how ConfigWM learns action-conditioned dynamics over the resulting predictive states (§
4.2
), and finally present latent-space planning with the learned world model (§
4.3
).

5  Experiments
5.1  Experimental Setup
We compare ConfigWM with LeWM
(
Maes et al., 2026b
)
, TC-LeWM
(
Liu et al., 2026
)
, Sub-JEPA
(
Zhao et al., 2026
)
, and EB-JEPA
(
Terver et al., 2026
)
, with EB-JEPA evaluated only on Two-Room following its official implementation. These methods retain their original state-learning objectives and regularization strategies. To ensure a fair comparison and isolate the role of configurable encoder, ConfigWM uses the frozen configurable encoder to construct query-conditioned predictive states while adopting the LeWM-style action-conditioned causal Transformer as its dynamics model. A trainable state projector maps the spatial encoder features into the 192-dimensional global state required by the dynamics model.
We additionally construct DINOv2-WM as a controlled encoder baseline. It replaces configurable encoder with a frozen DINOv2 encoder while retaining an identical projector architecture, dynamics model, training objective, and planning protocol. Therefore, the comparison between DINOv2-WM and ConfigWM changes only how the visual predictive state is constructed.
We also report Unified ConfigWM, which uses a single configurable encoder jointly trained on pooled data from all environments and distractor levels.
With this encoder frozen, separate world models are trained under the same per-environment training and evaluation protocol as the standard comparisons.
All methods are trained on the same transition data and evaluated under the same planning protocol. Further optimization and evaluation details are provided in Appx.
B
.

5.5  Does the Query Configure the Predictive State?

Since the decoder has no direct access to the query, these differences provide qualitative evidence that the query configures which visual content is retained in the predictive state.

6  Scaling the configurable encoder with real-world data
We explore a scalable training route that converts existing egocentric
(
Grauman et al., 2022
;
Damen et al., 2022
)
, robot manipulation
(
Khazatsky et al., 2024
;
O’Neill et al., 2024
)
and internet instructional video
(
Tang et al., 2019
;
Chen et al., 2026
)
data into supervision for
configurable perception
. Given a clean observation and its task description, a VLM generates editing prompts specifying reasonable but task-irrelevant objects, which are inserted into the observation using an image-editing model. The task-relevant scene content and task description remain unchanged, and the original observation serves as the clean target. The configurable encoder is then trained to predict the representation of the clean target from the noisy observation conditioned on the task description.
Fig.
10
shows held-out PCA visualizations across DINOv2, DINOv3, V-JEPA 2.1, and LingBot-Vision. Complementary patch-level linear probing for distractor and task-relevant region prediction shows that the configurable encoder reduces distractor average precision (AP) by an average of 17.9 percentage points relative to the frozen backbones, while task-core AP remains nearly unchanged, indicating weaker responses to task-irrelevant objects while preserving task-relevant states. Full quantitative results and the evaluation protocol are provided in Appendix
D
. These results suggest that our encoder can benefit different visual backbones, providing a practical route for scaling
configurable perception
to large real-world video datasets, without requiring manual annotation.
7  Conclusion
We introduced ConfigWM, an action-conditioned world model that brings
configurable perception
into state construction. Rather than modeling dynamics over a fixed task-agnostic representation, ConfigWM uses the task query to construct a task-relevant state and learns action-conditioned dynamics over it.
Across three environments with increasing dynamic, target-like distractors, ConfigWM maintains stronger planning performance than the baselines, while representation analyses show that its states preserve task-relevant physical information and remain more consistent with their clean counterparts as distraction increases.
We further examine whether the query actually configures the learned state, finding that decoding the states under different queries reveals different task-relevant state representations, while replacing the correct query with a mismatched one leads to a substantial drop in planning success.
Beyond these controlled environments, results on real-world data suggest a promising path to scaling the configurable encoder across different visual backbones.

This section details the construction of our noisy-world datasets. We first describe the shared distractor-generation pipeline in Sec.

A.1  Dynamic Distractor Generation
Object Extraction.
For each environment, we begin with the official clean rollouts and use SAM3
[
Carion et al., 2025
]
to identify the task-relevant target object. Specifically, SAM3 segments the object and tracks its mask consistently across frames, producing a sequence of per-frame masks and image-space trajectories. These masks and tracks provide the spatial extent and motion information required to replay the extracted objects as distractors in other rollouts.
We then reconstruct each extracted object to match the native appearance of the corresponding environment. This reconstruction preserves its characteristic geometry, boundary profile, and shading while allowing controlled recoloring. Finally, the reconstructed object is composited into a recipient rollout by replaying its tracked donor trajectory frame by frame. Consequently, each distractor follows motion observed in a valid rollout rather than being independently repositioned in every frame, resulting in temporally stable and visually plausible distractors.
Progressive noise levels.
We construct the noise levels cumulatively. The
d
0
d_{0}
condition contains only the recolored task-relevant objects and no additional distractors. For each trajectory, we sample eight donor trajectories and keep their identities and tracks fixed throughout the construction. Starting from
d
0
d_{0}
, we add one additional donor trajectory at each noise level.
This progressive construction enables controlled comparisons while keeping all previously introduced distractors unchanged.
Color-balanced and query-conditioned targets.
In this work, we use object color as a concrete and easily controlled visual configuration attribute, although the formulation itself is not inherently restricted to color. For example, the Two-Room environment uses nine semantically named colors: red, blue, green, orange, purple, cyan, yellow, pink, and brown. To prevent the clean target from being associated with a fixed appearance inherited from the original dataset, such as the red ball in Two-Room, we recolor the task-relevant core object and balance the nine colors across trajectories. At every noise level
d
ℓ
d_{\ell}
, the core object and its
ℓ
\ell
distractors are assigned mutually distinct colors.
In addition to the standard source-to-clean pairs derived from the official datasets, we construct a same-source multi-query dataset from
d
8
d_{8}
, which contains the complete set of one core object and eight distractors. At a temporal stride of five, the same noisy observation is paired with nine color queries and nine corresponding query-selected clean targets. This construction provides a direct realization of
configurable perception
, changing only the language query changes the desired target while keeping the source pixels fixed. Each target retains only the object or manipulation scene specified by the query (task-relevant) and removes the non-queried (task-irrelevant) distractors, while preserving task-relevant contextual elements (e.g., goals and interaction objects).
A.2  Environment-Specific Construction
Two-Room.
The task-relevant object is the moving ball. SAM3 is used to extract and track balls from donor trajectories. Their soft, Gaussian-like appearance is reconstructed with the native style of the environment, recolored, and replayed along the extracted trajectories. The room walls, and other static geometry are preserved during compositing. Queries follow the template {color} ball, and the corresponding target contains only the queried ball in the matched clean room observation.
Push-T.
The task-relevant object is the movable T-shaped block, while the green T-shaped region and blue pusher provide task context. Additional T-block trajectories are extracted from valid donor rollouts. We reconstruct each donor with the geometry and edge appearance of the original T-block, recolor it, and replay it along its donor trajectory. Only the donor T-block is transferred, while the green goal and blue pusher are retained from the recipient observation. Natural occlusions between the pusher, selected T-block, distractors, and goal are preserved during compositing. Queries follow the template {color} T block.
OGBench-Cube.
Each donor corresponds to a complete arm–cube manipulation trajectory, identified by the color of its robot arm. SAM3 is used to extract and track the relevant manipulation content, after which the robot arm is reconstructed with an environment-matched appearance and recolored. The associated cube and interaction context are retained so that each donor remains a coherent manipulation scene.

The target encoder receives only the corresponding clean target image and does not take the task query as input. B.4  Planning and Evaluation Protocol
We evaluate all world models using the same CEM-based model predictive control protocol, following LeWM
[
Maes et al., 2026b
]
. At each replanning step, the current and goal observations are encoded using the corresponding representation model. CEM optimizes candidate action sequences by rolling them out through the learned dynamics model and minimizing the distance between the terminal predicted state and the encoded goal state. A prefix of the optimized action sequence is executed before replanning from the updated observation. The same planner configuration is used across methods within each environment. All reported results are averaged over evaluation seeds 40, 42, and 45.

We draw candidate cases from task-annotated clips in public datasets spanning three domains: egocentric video (e.g., Ego4D

Identify all visible task-critical entities, including the target, destination, tool, acting hand or robot, directly involved container, contact region, action path, and support surfaces needed to understand the task. All identified entities must be protected.
3.
Select task-irrelevant distractors.
Every distractor must be unrelated to the task. Never add another instance, substitute, semantic alternative, or look-alike of a task entity. Prefer an ordinary, scene-plausible object whose category, shape, color role, and function are visibly distinct from all salient original objects. Use one distractor in dense scenes or when only one isolated empty region exists. Use two only when the visible support contains two clearly separated empty regions.
4.
Determine safe placements.
Place additions on visible existing support surfaces in genuinely empty regions. They must not overlap, touch, cover, replace, move, recolor, resize, or merge with any original entity. Never place an addition inside the task area, between an actor and its target, or along the task motion path.
5.
Construct the editing instruction.
The edit_prompt must contain exactly three concise sentences:
(a)
Start with “Add only these new task-irrelevant objects:” and specify the appearance and realistic size of each object.
(b)
Start with “Place them separately” and specify the existing support surface and an unambiguous empty relative location for each object. Explicitly forbid touching or overlapping any original object.
(c)
Start with “Preserve the input image exactly” and require every original pixel and object to remain unchanged in identity, count, color, pose, position, scale, contact, shadow, geometry, exposure, camera view, framing, and spatial relationship.
6.
Construct the negative prompt.
The negative_prompt must forbid cropping, zooming, recentering, restaging, reconstruction, deletion, replacement, relocation, recoloring, duplicate additions, unrequested objects, occlusion, overlap, floating objects, altered support surfaces, altered hands or robots, and changed task relationships.
