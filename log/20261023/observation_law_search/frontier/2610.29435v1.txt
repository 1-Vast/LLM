Abstract
World models are increasingly used for planning, where a planner ranks candidate actions by returns imagined by the model. However, these models are judged mainly by how well they render frames, even though a visually faithful rollout can still assign the wrong return. To identify where this mismatch arises, we introduce a transition-level diagnostic that replaces imagined transitions with real ones and measures the reduction in return error against a budget-matched random control. Our analysis yields two findings. (1) Event transitions, the few steps where a reward is earned or an episode ends, are rendered as well as other steps (median pixel-error ratio 0.85), yet restoring them removes a median of 70% of the return error. In contrast, restoring transitions with the largest MSE, SSIM or LPIPS error removes less than a random choice. Across the 44 Atari-100k model–collection pairs that pass our reliability checks, including three released families, event patches outperform random patches in 39 (sign test

(2) The remaining error is structured: a complementary patch separates errors at true events from those elsewhere, while an eight-step timing tolerance recovers few events missed by our deterministic models. This structure also guides repair: a rule recorded before four repair outcomes were known predicts when a diffusion model repairs these failures. Event patches improve plan ranking, and the same concentration appears on control tasks with rare reward events.

To answer this question, we introduce a transition-level substitution diagnostic
(Fig.
1
). Each imagined rollout is paired with a real rollout that starts from
the same context and follows the same recorded actions, so the two differ only in who drew the
frames. A frozen, memoryless detector, trained once per game, reads reward and termination from
each pair of consecutive frames; replacing one imagined pair with the real one therefore changes
the return only at that step. We patch the pairs at true events, the same number of random pairs,
all non-event pairs, or every pair. These four patches isolate the targeting effect, its
budget-matched control, the error away from events, and an all-real reference.
Our analysis yields two findings.
First, return error concentrates at events that do not
look wrong.
In Fig.
1
D, restoring three transitions around a Seaquest reward
removes almost all return error; three random ones remove little. Across 44 reliable
Atari model–collection pairs, event patches beat random patches in 39 by a median of
+44 points, and the advantage appears within a few patches (Fig.
2
).
Event frames are rendered as well as others (median pixel-error ratio 0.85), yet
restoring them removes a median of 70% of the return error; the same pattern holds on
eighteen games added after our predictions were recorded.
Second, the remaining error
is structured rather than merely mistimed.
Complementary patches separate errors at true events
from errors elsewhere, and timing-tolerant recall shows that temporal offset explains little
of the events our deterministic models miss. This structure also predicts where a diffusion
model helps; event patches improve plan ranking and carry over to control tasks with rare reward events.
We summarise our contributions as follows:
•
We introduce a per-transition substitution diagnostic with a budget-matched random control.
It treats the world model as a black box, and we apply it to three released model families on all 26 Atari-100k games.
•
We show, for the first time on released pixel world models, that return error concentrates
at reward and termination transitions, also under each model’s own reward head and without the
score display, and that a complementary patch separates errors at true events from other errors.
•
We show that a temporal offset explains little of the events missed by deterministic
models, predict all four repair outcomes with a rule recorded in advance, and show that event
patches improve plan ranking in every counted pair and carry over to control tasks with rare reward events.

5.1
Absent or Mistimed Events
A detector can miss an event in imagined frames for two reasons: the model draws it at a
neighbouring step, or it does not draw it in a form the detector reads. The two predict different
curves. If events are only mistimed, recall should rise with the alignment tolerance faster than
for a displaced-prediction null; if they are not drawn readably, recall should stay low at every
tolerance.

A Rule Recorded Before the Outcomes
If events are not drawn readably, a model that draws them should reduce the return error, most

A sampled future can differ from the realised one, so we evaluate event recall, return error, and
plan ranking.

τ
=

\tau=0
below
0.50

Ablation on Sampling.
A natural question is whether the gain comes from sampling.
To isolate it, we train the same diffusion network with a deterministic squared-error objective
(same data, 8k updates and seeds). It still has lower error than our MSE baseline on all five
games and keeps Freeway’s events (recall 0.95 against 0.94); its
seed-mean error is lower than with sampling on Freeway (0.096 against
0.171) and within the larger seed span on the other four, while sampling recalls more
events on Pong (0.80 against 0.69; supplement). The repair thus comes from the
diffusion network, not from sampling or the training loss.
6.5
A4: Event Transitions Drive Plan Selection
Finally, if events decide the imagined return, restoring them should also improve plan choice
beyond a matched random patch. To test this, we rank eight plans from each of 150 emulator states,
as a sampling-based planner does
[
11
,
20
]
, and score pairwise accuracy
and normalised top-1 regret; 7 of the twelve pairs, including the diffusion model, pass
the reliability rules (supplement), and Fig.
7
shows one. The event patch
improves pairwise accuracy in all 7 pairs, whereas a random patch changes it by a
median of +0.019, and median top-1 regret falls from 0.565 to
0.141. Under pre-specified rules, 15
further games add 8 pairs from Freeway, CrazyClimber and Gopher, whose detectors also pass on
plan states, and the event patch improves all 8 of them (median +0.156, random

0.5000 to 0.6110 (random-weighted control 0.5007). The transitions carrying the return error thus also
decide plan selection.

8
Conclusion
In this paper, we introduce a per-transition substitution diagnostic that locates where the
imagined return of a world model goes wrong. In 39 of 44 reliably measured
model–collection pairs on
Atari-100k
, the return error concentrates at reward and termination transitions that pixel metrics do not single out:
world models get the return wrong at events, in frames that look no worse than the rest.
A rule recorded in advance predicts where a diffusion model class helps, and event patches improve
plan ranking in every counted pair; the same concentration appears on control tasks
with rare reward events. These results suggest evaluating world models for planning by where their return error
occurs, in addition to how well they render frames.
