## One minimal candidate assessed

Application: choose a second intervention that suppresses resistant-cell outgrowth, using paid molecular and abundance feedback from an initial intervention. The candidate replaces a normalized survivor distribution with an unnormalized population measure and explicitly models capture:

`d mu_u(x,t)/dt = -div(v_u(x,t) mu_u(x,t)) + g_u(x,t) mu_u(x,t)`;

`P(observed x | u,t) = c_u(x,t) mu_u(x,t) / integral(c_u mu_u)`.

The reusable update rule would use calibrated counts to update growth/selection `g`, paired state trajectories to update transport `v`, and only authenticated capture calibration to update `c`. It must not interpret a normalized expression shift automatically as cellular transport. In finite states, the exact simplest comparator is an ordinary action-conditioned multitype branching/transition model with joint count likelihood and union refitting. Given known capture probabilities, composition correction is ordinary inverse-probability reweighting. Given unknown capture, an added flexible capture network does not identify the answer.

This is a scientifically meaningful representation change, **not presently a novel algorithm**. It does not yet explain an observed repeated error of the strongest project models. It has no instantiated distinctive restriction or estimator beyond standard reaction-transport/branching inference. Therefore I do not nominate it for a biological fit or an RSI expansion.
