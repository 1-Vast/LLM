    Delta_ab = c_a(rho_a,rho_b) Delta_a + c_b(rho_a,rho_b) Delta_b + s(rho_a,rho_b).

## Candidate: a repeated over-counting error, precisely restricted

Application: target-combination screening. A strong additive/state-to-state predictor can count an already maximally engaged transcriptional program twice when both single perturbations drive the same named readout in the same direction. Hypothesis: within the fixed source representation and this candidate's scope, the reusable error is a bounded overlap deficit, not a product of amplitudes. This has a plausible finite-capacity rationale for shared-program engagement, but no proof that broad transcript readouts obey it; the restriction is deliberately strong and should be cheaply falsified first. It is not inferred from a newly inspected favorable source subset.

Let s_a,k and s_b,k be independently acquired, control-centered single effects in the existing103named readouts; let y_ab,k be the separately acquired double effect. Fix

    h_ab,k = -1[s_a,k*s_b,k > 0] sign(s_a,k) min(|s_a,k|, |s_b,k|).
    yhat_ab,k = s_a,k + s_b,k + theta*h_ab,k,       0 <= theta <= 1.

Private readouts (one parent zero) and opposite-sign readouts are untouched. Shared same-sign effects range from additive at theta0 to the more extreme parent at theta1. A larger single cannot make overlap correction larger than the weaker single. This bounded degree-one overlap geometry differs from the stopped theta_k*s_a,k*s_b,k law: it has one shared parameter, sign-aware support and degree-one/min saturation, not a coordinatewise bilinear product. It cannot produce amplification, cancellation on opposite-sign parents, or off-support/neomorphic shifts.

Feedback is a real observed double-state package in development; it updates a shared overlap coefficient that is then used on other pairs, rather than editing the observed pair only. For observed residual r_i=y_i-s_ai-s_bi and weights w_i fixed before labels, a simple exact update is

    A_next = A + sum_i w_i*h_i^2,
    B_next = B + sum_i w_i*h_i*r_i,
    theta_next = clip_[0,1](B_next / (lambda + A_next)).

Initialize A=B=0; lambda is fixed by the exploratory contract, not tuned on stopped source outputs. This is exactly constrained one-parameter ridge/reaction-error estimation. **No separate optimizer novelty is claimed.** Its possible contribution is the overlap law's out-of-pair finite-feedback value. Give an ordinary solver the exact law; it must produce the same update. Sequential sufficient statistics equal batch fitting at identical weights: this candidate cannot claim recursion/ordering advantages from retaining A/B.

## Strongest counterexample, and why this is still testable rather than already refuted

SHERLOCK's off-span/neomorphic mechanism is a direct counter-regime: if two parents change only readout1 but their pair changes readout2, h_2=0 and this candidate cannot update it. Opposite-sign suppression and same-sign synergy also violate the law. These phenomena being possible does not prove the stated overlap restriction has no finite-source value; it does forbid presenting it as universal. A measured recurrent orthogonal/neomorphic residual or systematic wrong sign in the predefined domain should stop it rather than lead to a class gate, new residual head or selected responsive subgroup. No phenotype-class gate is added.

Strong direct full-q ridge already wins on the old product-diagonal precursor. Its capacity can express saturation approximately from source data; a fixed overlap restriction could only help via sample efficiency or robustness when feedback is small. It is not generally more expressive or more informative. SHERLOCK-style residual composition, ordinary additive+min-feature regression, a same-law constrained solver and simple fitted parent scaling are required direct competitors. The min-feature regression with the same scalar constraint is an operational identity, not a baseline to beat by renaming.
