## What shared control noise does and does not imply

Input and target gems are disjoint; claiming literal reuse of the same random control measurement across the two sides would be wrong. Within each input gem, however, both centered singles use one control, so even under a null effect a control error e yields a=b=-e and h=e. Within a target gem, double-single-single+control includes its **separate** control error. If those errors are independent centered symmetric fluctuations, the null expected h*r is0: within-gem common centering alone does not establish the observed cross-gem association.

True single/double/baseline values are identical, so biology is additive/null. Independently collected but systematically biased controls yield input a=b=-c, h=c and target r=c.
