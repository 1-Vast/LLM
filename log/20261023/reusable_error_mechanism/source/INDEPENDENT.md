## One precise candidate examined

**Realized action-strength correction rather than mixed-response curvature.** A concrete possible error of a nominal-action cell model is that the same named CRISPRa target is not activated to the same extent in a single versus double perturbation. Co-delivery, CRISPRa machinery competition and intervention-specific transcriptional feedback can change realized action strength. A model that treats the named target as a fixed action could misattribute reduced activation to biological antagonism. This differs mathematically from the stopped shared coordinatewise product law; it concerns the **action input**, not a learned diagonal output interaction coefficient.

An explicit falsifiable restriction would be: conditional on realizing target-a activation magnitude eta_a and target-b magnitude eta_b, a fixed gene-specific response direction from single perturbations remains locally valid for other readouts and future function. For response state s in an appropriately fixed expression scale,

    s_ab ≈ eta_a(ab) s_a + eta_b(ab) s_b + r_ab,

where eta_a(ab) is obtained from the target-a coordinate's double-versus-single deviation from control (and similarly b), not fitted to the query fitness or allquery residuals. The reusable quantity would be an action-calibration map that links an on-target response assay to effective intervention strength; inherited updates would revise that map rather than freely revising every functional output. Nonlinear biological interaction remains r_ab; this restriction must not assume away real synergy.

**Decision: NONE as a currently qualified new core or authorized numerical test.** I do not nominate the above as validated biology. It is the strongest specific scientific-error hypothesis I can formulate from the existing source without searching new datasets, but the following observations prevent an honest immediate GO. At most this is a reviewable future exploratory hypothesis, not a rescue experiment.

## Why an informed ordinary predictor might be inefficient — and why that is unproven

If the realized-strength invariance were true, learning two calibrated gains could share more efficiently across target pairs than unconstrained fullstate refitting. Its exact informed counterpart is an ordinary action-calibrated regression/state-space model with the same eta prior, same feedback and same reuse rule.
