# Conditional dependence, not a universal covariance requirement

2026-10-23. This addendum preserves API_ROOT_REVIEW.md and the original API answer. Constructive review identified a further limitation of the API wording. Nonzero conditional covariance is not necessary for useful nonlinear feedback prediction.

Hand calculation, not another executed experiment: let R be uniform on {-1,0,1} and Q=R²-2/3. Both means and Cov(R,Q) are zero. The linear covariance update predicts zero, with risk E[Q²]=2/9; an ordinary nonlinear conditional predictor knows Q exactly from R and has zero risk. No new biological values, algorithm or novelty evidence follows from this example.

The missing scientific relation is a learnable conditional functional-support/query law under lawful observations. A proposed restriction must have a concrete finite-data, robustness or computational advantage against informed realizable controls. Neither a covariance formula nor the unattainable true Bayes predictor should be treated as proof that all nonlinear methods are equivalent or useless.
