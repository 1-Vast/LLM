# Pre-outcome exploratory count forecast protocol

Question: does freeing only the published common half-range dose midpoint produce a repeatable future-count advantage beyond ordinary same-information fits? This is a model-restriction diagnostic, not a new algorithm claim. World/agent/inheritance/joint/RSI remain unestablished. Previous sealed independent reviews and all historical STOPs stand.

Primary endpoint: squared error at actual120h against the actual exported count divided by observed6hcount. Average equally over6doses, then curves (equal19percell unless prefix exclusions). Report per-cell and overall means, group paired differences and wins. Secondary: average squared error over actual75..120h, actual120h MAE, and reconstructed raw-count MSE. No MAPE/pseudotruth/fittedsurface target. This forecasts observed later counts, not latent biological truth, birth/death or ATP. No uncertainty interval is authenticated without independent repetitions; do not treat456wells or16times as independent biological n.

Methods (all use same6..72hobservations):

1. VUScope6 functional form: two logistic asymptotes, beta(t)=kbeta*abs(alpha−delta), gamma constant. Reimplement from saved source; bounded numerical approximation to published family, not published pipeline replication. kα,kδ in[0,2], log(aα,aδ) in[log1e−6,log1e6], kbeta in[0,1000], gamma in observed log10dose range. Positive a prevents t0singularity; a<1 permits decreases. Nine fixed starts: ka1,aα100,kδ.5,aδ10; beta.1/1/10 × gamma minimum/median/maximum. Minimize unweighted count-ratio SSE; select by training SSE. Each start scipy least_squares max_nfev400, standard tolerance.
2. Moving-midpoint7: identical bounds/starts/loss/optimizer except gamma(t)=gamma0+v*t/2.75days, v in±observed logdose range, initialized0. Nine starts, same nfev limit each. This changes gamma only; beta restriction remains. Improvement cannot identify delayed-death causality or establish that the full surface family is generally wrong. Identical starts/nfev are not identical FLOPs; report function/Jacobian counts and runtime.
3. Ordinary independent-dose logistic: fit same positive logistic family separately per dose (12parameters/curve); k/loga same bounds,3fixed starts(1,100),(.5,10),(1,.5); SSE, max_nfev400 per start. Strong conventional relaxation of jointdose restrictions, not new dynamics.
4. Direct selected temporal predictor: eight fixed configurations, shared configuration selected per curve across its6doses using only prefix6..48h fit and51..72hvalidation SSE. Six per-dose count polynomial fits degree1/2 ×ridge1e−6/.01/.1 (intercept unpenalized; time=(actualh−6)/72); two local linear log1p(count-ratio) predictors using last24/48hof available input. Select minimum validationSSE, ties first, refit on entire prefix. Clip negative forecasts to0 for physical counts. Pseudoval horizon24h differs from final48h; it is a fixed ordinary baseline, not proof of optimal direct modeling. Nine nonlinear starts versus eight direct configurations are disclosed search opportunities, not claimed equal search cost.
5. Persistence at actual72h, inexpensive sentinel.

No extra starts, hyperparameters, subgroups, outcomes, datasets or rescues after release. Retain fitstatus for every start; use finite best trainingSSE even if nfevlimit (not a convergence claim). Any uncaught fit/nonfiniteprediction aborts, preserving partial files; no implicit substitution. Record actual cost; no API/GPU/wet experiment. A fixed seed is unnecessary because all operations/starts are deterministic. Freeze sourcebytes/protocol/schedule/code/environment before run.

Execution separation: fit every method for all eligible curves using prefixonly; persist all parameters, validationchoices and predictions; hash/seal predictions BEFORE parsing any late response. Then load actual75..120hcounts and score. A late outcome failure does not authorize changed configuration. Exact source/model-boundary and prefix-read-isolation synthetic tests precede freeze; they validate implementation, not biology.

Decision: retain the moving-midpoint hypothesis for a separately reviewed follow-up only if it improves primary and secondary meanMSE versus VUScope6 in at least3/4cells, improves primaryMSE in more than half eligible curves, and beats both ordinary independent-logistic and direct-selected controls on both overallMSE endpoints. Otherwise STOP expansion of this particular moving-midpoint configuration. These are finite-panel directional diagnostic conditions, not statistical significance or a clinically meaningful threshold. Even success cannot support an application/innovation GO without measurement repeatability, independent tasks, stronger direct/source-learning controls and an explicit new update operation. If ordinary direct/refit already explains gains, preserve useful forecast evidence but no new-core promotion. Do not impose completeRSIassets as prerequisite for this bounded source test, or use this test as substitute for the full goal.
