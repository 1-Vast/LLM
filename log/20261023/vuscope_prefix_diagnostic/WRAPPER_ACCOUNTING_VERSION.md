# Accounting-only wrapper version

run_frozen.py is retained byte-for-byte as reviewed. run_accounted.py executes the identical reviewed pilot once, first checking explicit final reviewer hashes, and freezes the final code reviews plus exposure-scope/accounting addenda. It changes no model/dataflow/endpoint/budget. This avoids modifying the already reviewer-bound wrapper merely to extend its evidence list. The two final scientific reviews approve the current pilot; the initial critic text describes pre-repair issues while its late-captured seal binds the repaired bytes (read/hash timing race). Preserve the original review/seal and use the final reread as the approval, not an assertion that the initial review was a pass. This is documentary timing disclosure, not a biological positive.
