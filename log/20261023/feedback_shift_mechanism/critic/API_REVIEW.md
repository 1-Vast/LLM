## Decision: reject as stated; ordinary corrected variant not globally forbidden

The proposal combines query-local weights, recency weights, weighted ridge/NN, an additive generation-mean correction, and a significance-triggered correction gate. These operations can be useful ordinary components. In particular beta!=0 gives predictions different from bare beta=0 weighted refit; it would be incorrect to claim the two are always numerically equivalent. Nevertheless the whole stated algorithm is exactly reproducible by the ordinary control performing the same kernel/recency-weighted refit, lagged intercept/drift correction and same gate. This is an operational comparator, not the invalid argument that every argmin is the same method. No biological restriction, estimator efficiency result or source-learned transferable update strategy distinguishes the proposed combination from that comparator.

## Lawful feedback and scientific meaning

H_g is described as generations before g, while the correction uses bar_y_g-bar_y_(g-1) to predict generation g. Under that forecast convention bar_y_g contains current target outcomes and is unavailable. This is label leakage as written. If g instead denotes the last observed generation and prediction concerns g+1, or the correction uses g-1/g-2, the information defect can be repaired. It then becomes lawful lagged intercept/drift extrapolation, which may help but requires its own ordinary comparator and independent evaluation. Corrected indices do not establish novelty.

Generation response means mix response-law change, observation/normalization change AND the action distribution chosen in each batch. Equal means do not imply stable conditional biology, and unequal means do not identify a measurement offset. A control-adjusted or common-design statistic could narrow interpretation under assumptions, but no such new measurements or invariance are supplied. Our prior untreated-control affine counterexample still applies; conversely it does not invalidate every legal drift predictor.

The proposed post hoc FAC/OLA registration is not prospective confirmation: these59response means and winner patterns are already exposed, and the fixed configuration was stopped. Reversing the OLA error or choosing FAC/OLA-specific switches here would be development-set optimization. Those campaigns may motivate a hypothesis; they cannot become new independent inherited-U tasks by labeling generations as descendants.

## Specific implementation and arithmetic gaps

1. rho cannot be identified as forgetting from G0-only LOO: all genuine G0 generation indices are equal, so rho^(g-g0) is a common multiplicative factor. With normalized weights it cancels. With sum-loss ridge and fixed penalty it changes effective regularization only, not relative ages. Inventing pseudo-generations from G0 order creates an arbitrary resampling design, not actual temporal response evidence. Such meta-training is allowed as a hypothesis, but cannot be asserted to recover real generation drift or independent task inheritance.

2. beta update, rho update and the significance gate lack executable estimation/test definitions. G0 pseudo-generation CV does not authenticate actual batch offsets, and the threshold's error model/replication unit is unspecified. A fixed practical threshold could be a lawful ordinary control; absent biological replicate IDs, a nominal p-value cannot manufacture independent batches.

3. The hand example has G0mean1, G1mean10 and equal-data mean5.5. For delta=9, 5.5+beta*9 equals10 only for beta=.5. beta=1 gives14.5; if “beta estimated+9” is literal it gives86.5. If the intent is a correction of+9 rather than coefficient9, it still gives14.5. Query-local/recency fitting may change5.5, but then the example must specify its weights and beta. This is a fixable arithmetic/underspecification issue, not a general impossibility result.

4. “Duration-normalized dose exposure” is not established by anonymous raw time codes. seq Jaccard needs a specified representation: as drug sets, all permutations of the same drugs have identical Jaccard similarity; as singleton opaque categories, it is merely a mismatch indicator. The scalar abs(t1-t0) loses information about schedules with identical imbalance and different durations/order. A different distance can be valid but must be defined before outcomes and given identically to ordinary controls. Do not infer hidden physical semantics or repair distances after seeing OLA errors.

5. Hyperparameter search over lambda/rho/beta and gate thresholds consumes budget even if G0-only. Equal-budget controls must receive the same tuning opportunity, query design and history. A single API request's token count does not account for subsequent selection/assay cost. “Inherited U vs restart from G0” deliberately withholds lawful feedback from the restart and therefore tests feedback availability, not inherited updater quality at equal history. A same-history ordinary refit with the identical retained parameters is required. Random gating versus a selected gate alone is not proof that G1 improves future improvement strategies.
