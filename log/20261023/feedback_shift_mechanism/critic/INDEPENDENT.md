## Precise operation-equivalence objection

Consider the promising-sounding candidate “first explain feedback by measurement/context nuisance, then update the response law only in the nuisance-orthogonal direction.” Its simplest executable version is

    minimize_theta,gamma ||y - X theta - Z gamma||² + lambda ||theta-theta0||²,

where X is the response design and Z the declared measurement/context nuisance design. Assume full-column-rank Z and lambda>0. Profiling out gamma gives M=I-Z(Z'Z)^(-1)Z' and exactly

    theta_new = (X'MX+lambda I)^(-1) (X'My+lambda theta0).

This is ordinary partial regression/profiled ridge with known nuisance covariates, i.e. the Frisch–Waugh–Lovell residualization operation with a quadratic prior. It is not a new response updater. The exact same-history direct predictor using X and Z, with the same penalty, returns the same response coefficient and forecasts. An unpenalized intercept can be included in Z. If a candidate penalizes nuisance, changes constraints or chooses a different loss, its comparator must change accordingly; the equality is not a claim that every nonlinear conditional model equals this formula.

Separately residualizing y alone while leaving X unprojected is generally NOT this joint optimizer. Calling that discrepancy a new update mechanism would require a justified differing restriction and direct comparison, not credit for a two-stage name. Likewise a gate based on nuisance residual size followed by a convex update is ordinarily model selection/shrinkage unless it contributes a precise independently testable constraint.

If X lies in span(Z), then MX=0 and theta_new=theta0: projection has removed all response information. This is an explicit overcorrection failure mode, not an empirical statement about FAC/OLA. A learned batch embedding can suffer a corresponding identifiability issue, but this linear equality alone does not prove a deep model's performance failure.

Fixed witness research/feedback_shift_mechanism_20261023/critic/equivalence_witness.py solved a6-row two-feature/two-batch joint system and the profiled system. Maximum coefficient discrepancy1.3322676295501878e-15. A fully confounded example returns its prior to numerical precision. No random operations, hyperparameter search or bio-data fit occurred. The underlying equivalence is known mathematics, not a new theorem or research success claim.

## Identifiability counterexample: one control does not separate gain from response

Let source response at untreated/treatment actions be f=[1,2], source measurement identity. Target observed responses are [1,3]. Two worlds produce identical target endpoints, including an unchanged untreated control:

- Measurement world: biology remains f=[1,2], but measurement is m(s)=2s−1.
- Biology world: measurement remains identity, biology becomes f_target=[1,3].

Thus an unchanged single control and all these action endpoints cannot distinguish a changed shared affine measurement channel from a biological treatment-response change. The measurement world has positive gain and all values are positive; this is not a construction relying on an invalid negative viability. Any update chooser receiving only these observations must make the same choice in both worlds. This is a restricted full-observation equivalence, not proof that all informative metadata, extra controls, raw channels or arbitrary experiments fail.

Two distinct, KNOWN invariant reference values can identify one shared affine measurement channel: solve [s_i,1](gain,offset)=observed_i. The fixed witness recovers gain2,offset−1. But reference invariance and applicability of a shared channel to drug-treated specimens are substantive assumptions. A live/dead stain can change with treatment chemistry or cell permeability; “untreated control exists” does not authenticate a treatment-independent calibration law. A molecular distribution or multiple raw channels may also break this toy ambiguity. Conversely an action-dependent measurement channel can defeat two scalar references. Do not reinterpret this as a universal two-anchor assay prescription.

This identifies a useful experiment-design question, not an estimator innovation. Ordinary affine calibration, matched controls, bridge samples and conditional regression must remain named as such. No need for a full virtual-cell trajectory bank before testing one documented reference assumption, but no new wet dataset or additional calibration asset is asserted acquired here.
