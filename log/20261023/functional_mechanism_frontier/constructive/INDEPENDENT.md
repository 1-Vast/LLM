## Concrete original operation and scientific corrections

Let W be the edited linear map, K0the retained-key matrix, K1new edit keys with target values V1, and Kpkeys from previously applied edits. Original§3defines P=U0U0^T from the null eigenspace of K0K0^T. Its sequential objective is

    min_D ||(W+DP)K1−V1||_F² + ||DP||_F² + ||DP Kp||_F².

The applied edit is

    E = R K1^T P (Kp Kp^T P + K1 K1^T P + I)^−1,
    R = V1−WK1;  W_next=W+E.

Thus feedback changes weights while projecting away protected-key directions; a previous-edits penalty amortizes interference. It is a closed-form actual update, not merely a claim to be safe. The paper explicitly relates it to prior Adam-NSCL/least-squares methods and provides the code link https://github.com/jianghoucheng/AlphaEdit; no code download or implementation claim here.

Three distinctions directly change admissible future actions:

* Exact P K0=0guarantees only that this fixed linear map's outputs at fixed K0remain unchanged. It is not a guarantee of correct biological function, invariant upstream features or the whole drug-decision process. The2026replication explicitly highlights model/locate assumptions and finite fixed-key snapshot scope; its author stress results are not universal disproof or our experiment.
* Original§3.2footnote says practical eigenvalues above10^−2are removed, retaining small nonzero eigenvalues. Approximate null is not exact null. A retained one-dimensional covariance eigenvalue epsilon>0gives ||E K0|| proportional to sqrt(epsilon), generally nonzero. One must report this tolerance/leakage rather than cite an exact theorem for a thresholded projector.
* Kp is protected by a finite quadratic penalty, not the same hard null constraint as K0. Even in a one-dimensional free direction with Wk_p=v_p, one new contradictory target and positive finite regularization produce a nonzero edit and hence alter the old value. Do not claim all previous feedback is exactly preserved by Eq12/14. This does not mean the stated tradeoff is useless; it defines the actual competing operation.

Potential drug application: after a real viability/response feedback package in one patient or cell context, correct the drug-response model while preserving a prospectively specified set of already validated responses or treatment rankings. This port's exact ordinary counterpart is equality-constrained least squares / nullspace projected updating with identical features, calibration and penalties. The operation is already present in AlphaEdit, so a different label or adding a virtual-cell encoder establishes no new U.

This family could still have a valuable new biological restriction or finite-cost property; being conventional is not a veto. But two concrete counterexamples block the generic safety claim:

1. **Full protection can forbid all correction.** If legal protected feature columns span R^d, then P=0and no feedback edit is possible. More locally, if the new drug's feature lies in the protected span but its earlier prediction is wrong, every permitted update keeps the error. This is an explicit conflict between correction and preservation, not a nonlinear impossibility theorem. A source-ranked “safe” set chosen from currently confident predictions can therefore lock in confidently wrong pharmacology.
2. **Local key preservation need not preserve a decision under feature change.** For W=(0,1), old protected key e1and edit E=(0,c), exact E e1=0. If the upstream representation later changes that physical query to e1+epsilon e2, the output changes byc epsilon. With an arbitrarily close competing drug score, the ranking can flip. A meaningful safe-ranking claim needs a measured margin and control of representation drift, not just layerwise nullspace.

Preserving predictions is also not preserving true response: unmeasured assays have no known correct V0, repeat assays have noise, and legitimate new biology may invalidate past mappings. Replacing values with a protected ranking cone would weaken the constraint but is ordinary constrained prediction; it still needs a lawful uncertainty/margin contract and no new restriction is established here.
