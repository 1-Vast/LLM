# Independent dose-update critic: retain question, no core GO

2026-10-23. Independent read-only assessment; no peer opinion in this new phase read. No API, HTTP, biological labels, fitting or executed synthetic test. Prior full goal and functional-update decisions remain the scientific boundary. This report is not a universal impossibility result for dose-response transfer.

## Current verdict

**REVISE / NO_NEW_CORE_GO.** A shared drug-module potency/efficacy model could yield finite-sample improvements after functional feedback. That is a legitimate empirical hypothesis. As currently described it supplies a model class, not a distinctive update restriction: fitting a few shared parameters and propagating posterior changes to other drugs is exactly what a hierarchical nonlinear mixed-effects model or same-forward structured posterior already does. A new component should specify which cross-drug parameter changes are ruled out and why, then derive a falsifiable sample, robustness or computation advantage against those informed ordinary controls. No need to demand complete physical occupancy identification for every predictive use.

The core application should be named tightly: for example, ranking the next compounds to validate by expected viability reduction or selective tumor-vs-normal effect at accessible concentrations, after a fixed bundle of anchor assays. Curve interpolation alone is not drug discovery utility. Measured target RNA/protein states are purchased information; same-information direct competitors must get them and costs must count. Predictive latent potency is not automatically biochemical affinity, intracellular occupancy, target dependence or clinical efficacy.

## Strongest ordinary controls

- **Same-forward nonlinear hierarchical posterior/MAP:** exactly the proposed dose-response observation equation, same shared-module structure, prior source contexts, potency/efficacy parameters, nuisance terms and support assays. Permit joint updates and uncertainty over correlated parameters; do not force the ordinary opponent into a Gaussian tangent if the candidate uses finite nonlinear switching. This is the primary operation-level comparator. A named model family does not prove equivalence of all future inference restrictions; the actual likelihood, constraints, priors and budget must match.
- **Flexible direct prediction:** source-trained regularized dose/context/action predictors, multitask nonlinear Gaussian process or kernel model and a direct episodic support-set predictor. Give them the same drug descriptors, target/module annotations, state measurements, dose history, normal controls and feedback. Include single-curve interpolation/spline/Hill, source curve libraries and source-selected mixtures. No hidden privilege from author-fitted whole-curve IC50/Emax labels or future-dose missingness.
- **Empirical Bayes:** learn context/drug/module distributions of log-potency, efficacy and slope, including covariance and heterogeneous assay noise. Ordinary posterior shrinkage can inherit source tasks and avoid negative transfer by broad or multimodal priors. Gaussian residual conditioning is a useful cheap baseline, not the strongest possible EB family. Include a same-forward non-Gaussian posterior where multiple parameter regimes yield the same support data.
- **Meta/continued adaptation:** a source-episodic model trained on support-to-query functional loss, with learned initialization or updater, compared with same-history union refit/continual update. Source-trial/search cost and acquired states must be charged, and query outcomes cannot supervise new-task selection. The old direct RNA menu was not a functional-support transfer experiment and cannot be asserted to have defeated these methods.
- **Active decisions:** fixed concentration grids, random selection, uncertainty sampling, expected information gain, model-disagreement/model-discrimination design, and decision-targeted expected value of information/knowledge gradient. Include BATCHIE/PDBAL or an honest task-adapted approximation for batch assay selection; charge whole feasible plates/curves/replicates/control packages, not fractional isolated wells. Comparing a model-based agent only with random selection does not prove agent necessity. An optimal Bayesian oracle is an information bound, not a computationally free benchmark every finite-budget method must surpass.

Ordinary direct models may beat restricted mechanistic models on prediction but lose on sample efficiency or calibrated extrapolation; either result is possible. These are required controls, not predetermined winners. The hypothesis needs a finite useful margin in the concrete task, not automatic inheritance of the old 5% menu screen.

## Identifiability concerns, without another repeated toy

One or a few dose observations generally constrain combinations of potency, efficacy and slope, not each parameter separately. That ambiguity has already been exposed by the historical dose-shift checks; no duplicate single-point falsification was executed or promoted as new progress. Near-flat or saturated response regions are especially poor places to learn potency. Even a complete measured support-drug curve need not identify whether a change is drug uptake, target occupancy, downstream sensitivity, growth normalization or shared module dependence. A new drug may use the same annotated target but a different unmeasured action mixture.

The relevant counterexample family is therefore **support agreement, query action disagreement**: two parameter regimes produce the same lawful support state/control/curve but differ in an unmeasured drug's action-to-module map or in a query-critical module not challenged by the support drug. Exact support fitting and preserved control then do not identify the cross-drug correction. This only refutes a universal transfer guarantee absent an additional tested restriction. It does not refute empirical predictive sharing where source tasks and legal state distinguish the regimes. A useful proposal must say which pre-feedback observable excludes the alternative, or represent the ambiguity and buy a distinguishing assay. Do not require complete global biology when only scoped query prediction is claimed.

If potency/efficacy changes are assumed common across a target module, that assumption must be independently tested on drugs that separate shared target action from chemical/off-target changes. A drug-wide latent shift versus cell-wide sensitivity can be predictive but observationally confounded; call it predictive calibration unless physical interpretation is supported. Differences in growth-rate correction, exposure duration, curve normalization and AUC integration can masquerade as efficacy changes. An AUC-only table cannot supply an identified potency curve or a dose-query oracle.

## Decision gate and records

Before data acquisition/fitting, require one exact forward/update restriction, an authenticated curve/state/function timing contract, independent drug+context units and the same-forward posterior comparator. Source feasibility of a genuinely different constraint may be tested before full later-task RSI assets exist; it must be labeled exploratory and cannot reopen old endpoints as fresh confirmation. Stop the *specified restriction* if the requisite shared parameter law cannot predict independent query drugs, if same-forward ordinary inference matches the operation without a demonstrable resource property, or if decision benefit is below the prespecified useful margin. Wide intervals are inconclusive, not a universal null.

World-model necessity requires predicted intervention state to beat same-information direct alternatives in decisions; measured RNA benefit is not enough. Agent benefit requires improved assay choice over fixed/OED controls. Inherited updater benefit requires common-start later-task adaptation; Level3 requires a changed improvement strategy to improve subsequent descendant discovery yield under identical history and total budget. None is established by an ordinary posterior dose fit.
