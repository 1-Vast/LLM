## Biological meaning and prior STOP boundaries

The protocol correctly treats a fixed digital package of previously measured drug/AUC records as records, not physically simultaneous assays or a sequence of real exposures. Column serialization contains no claimed exposure chronology. Missing same-checkpoint/aliquot authentication therefore does not veto this numerical test. It does prevent interpreting any result as invariance of living-cell treatment order. If genuine history were present, retaining it would remain mandatory.

The endpoint is retrospective ex-vivo dose-response AUC completion for the historically exposed panel, not viable-cell kinetics, target engagement, drug-intensity correction, clinical outcome, or cross-drug clinical potency. The implemented secondary regret selects three **unpurchased finite query drugs** per sample; it is not top-three utility over all original panel entries, since purchased support is excluded. Concentration-range and assay conventions constrain comparisons between drug columns. The protocol's patient-cluster averaging appropriately avoids treating multiple patient samples as independent patients.

The E*tanh(h) model is an ordinary low-dimensional drug-panel response predictor/meta-updater. It supplies no baseline cell state, intervention mechanistic representation, or autonomous policy. Testing its digital-order behavior addresses a different component question from the stopped low-rank cell-state branch, but cannot reopen that branch's claim or establish world-model utility. Historical fold0 remains inspected development information; new random seeds/partitions do not provide independent biological confirmation. No agent, updater inheritance, joint contribution, or RSI claim follows even if the directional gate passes.

## Information and implementation contract

Code reads only the four specified NPZ members Y/groups/contexts/items; hashing the cache bytes does not decode expression features. No expression, event, G, or protected pool is used. Patient-group salted folds are assigned before fitting. Retained drugs depend only on source-fold outcome availability; mean/SD normalization and empirical covariance use source folds1–4. Eligibility uses finite-value availability, not favorable outcomes, and that information is shared. Means/covariance may use source rows ineligible for support episodes, which is allowed by the written source-fold contract and does not weaken that sentinel.

Development support uses an outcome-independent sample/drug hash and exactly eight measured finite outcomes. All remaining finite outcomes are query-only for scoring. The source tensor contains the entire exposed cache after decoding, but episode indexing selects only source train_rows for model losses. Query labels do not enter embeddings, steps, scaling, or covariance fitting. Train/test patient groups do not cross by the defined salt.

Fast-state gradients are computed separately per batch row; summing package loss without dividing by batch does not mix rows because h has a distinct row per context. Fixed/augmented/consistent share initialization, RNG episodes, support size and total five package-gradient evaluations per episode, with three source query views. Consistent differs by the stated penalty, not extra query-label access. DeepSets sees the same complete support; fixed support cardinality makes sum/8 an ordinary exact-invariance alternative. Its larger parameter count and different work must be reported, as the protocol requires; equality of 120 outer steps alone is not equal total FLOPs.

Evaluation uses AB for every trained updater and saves BA/union separately. The zero-update identity solution is not accepted on consistency alone. Raw predictions, masks, supports, source scales and model states are written for audit. Patient-cluster means, rather than per-sample means, define the primary/secondary aggregate. No implementation change is requested before this bounded run.

## Necessary interpretation of outcomes

The frozen all-three-seed/directional gate is a screening rule, not an assay-derived minimum important effect or a statistical significance claim. Three seeds are robustness runs on the same source. If consistent fails either functional metric against augmented or the ordinary sentinels, execute the stated stop without tuning gamma, width, seed selection, subgroups, or the support menu. A lower consistency discrepancy with worse functional prediction is a failure for this goal.

A pass can only nominate a later comparison. This limited pilot omits full fair-budget refitting, continual learning, active selection, mixtures, meta-learning alternatives, and equal-budget search; no claim of superiority to all these opponents is supported. Ordinary randomized-order training, full covariance and invariant set conditioning are particularly pertinent alternative explanations already included. Actual walltime/work and all source-query evaluations should accompany any result.

The protocol's append-only failure/correction handling, initiation guard and pre-run freeze are appropriate. This review does not authorize additional labels, data acquisition, a restarted low-rank mechanism claim, or reinterpretation of digital shuffles as real feedback episodes.
