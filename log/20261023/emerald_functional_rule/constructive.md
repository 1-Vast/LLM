# Independent combination-function update assessment

2026-10-23. Read identity-only public menu and the previously authenticated official Rhaister/relative-phenotype contracts; no new functional values, expression payload, peer opinion from this phase, HTTP, API, biological fit or toy execution. The prior complete objective and stopped dose/update mechanisms remain binding. Native model identity/usage is not attested.

## Decision

**NONE as a qualified new reusable update mechanism.** There is a concrete, finite, function-only information question worth considering on the newly authenticated combination menu: whether one measured combination anchor improves predictions of chemically distinct combinations in the same context beyond all available single-drug function. That question is materially different from the closed measured-RNA menu. It is not yet a new algorithm, biological sharing law, prospective assay-saving task or RSI demonstration. A narrow exploratory replay can measure whether an opportunity exists; it must not be relabeled a core GO.

## The closest substantive restriction, and its current gap

KRAS blockade can induce compensatory signaling, and a second pathway inhibitor may remove that compensation. A legitimate biological hypothesis would be that the *context-specific interaction between two pathway perturbations* transfers across selective chemical implementations after their single-drug effects are accounted for. This would go beyond a common horizontal potency shift: the update changes a joint conditional functional response rather than moving both single curves along dose.

However, shared module labels do not imply equal compensation, occupancy, off-targets or feedback timing. The exact public menu includes Adagrasib/Sotorasib combinations with Galunisertib/LY3200882/PF-06952229, but neither selective equivalent target activity nor sufficient single-agent curves is authenticated from those condition strings. Prior action-substitution/Kinobeads tests were already stopped; rebranding same-target substitution as combination-module transport is not an acceptable new mechanism.

For an explicit ordinary reference, let g_c(a,b) be a released response for a specified dose-pair, and define a raw contrast where all four conditions actually exist:

    I_c(a,b) = g_c(a,b) - g_c(a,0) - g_c(0,b) + g_c(0,0).

These are contrasts in the released field, not automatically Bliss/Loewe synergy, additive growth rates or log survival. The growth transformation is not authenticated. Imposing

    I_c(a,b) = phi_a * phi_b * theta_c,modulepair

and updating theta from an anchor is a precise low-rank module-interaction model. It differs from a dose shift or an output offset. But its direct ordinary competitor is the same interaction model with source-learned prior and conventional mixed-effects/MAP/posterior inference. A direct ridge on product interaction features can also implement its linear version. I have no additional measured biological constraint, identifiable restriction, robustness result or finite-budget property that separates a new updater from that informed implementation. This is not rejected merely for using old mathematics; the particular proposed restriction currently has an exact ordinary construction and no demonstrated new law.

An invariant raw interaction could become a scientific discovery if established on independent selective implementations/contexts with the right activity/function measurements, but the current menu alone does not establish it. Do not manufacture missing singles, fit target equivalence from query outcomes or call drug identity annotation an action measurement. The present report does not nominate this model as a new core.

## A finite real-data diagnostic that could change the next decision

Application: retrospective prediction/ranking of released within-pool five-day relative phenotypes for unobserved combinations in a partially observed cancer context. It is not absolute killing, tumor selectivity or a clinical efficacy test. The source/context units are cell lines conditional on this measured pool; they are not 52 independent new experiments.

Use a fixed metadata-selected anchor, present in the actual public identity menu:

    Adagrasib 0.005 uM + Galunisertib 0.1 uM.

For a held-out context, predict these three chemically transferred query conditions, also present with exact matching single-agent doses:

1. Sotorasib 0.005 uM + Galunisertib 0.1 uM;
2. Sotorasib 0.005 uM + Galunisertib 0.5 uM;
3. Sotorasib 0.005 uM + LY3200882 0.5 uM.

These fixed identities are chosen from the proposed compensatory-pathway structure before response access, not because of favorable values. They test replacement of the primary inhibitor and, for the third query, secondary chemistry as well. They are three correlated queries per context, not three independent mechanistic replications. Higher Sotorasib 0.01-uM combinations exist but matching single-agent 0.01-uM function is absent from this public single menu; do not silently interpolate it or add those queries after results. PF-06952229 lacks single conditions and is likewise not used for an exact four-arm primary contrast.

For each context expose only its complete authenticated single-agent panel, permitted controls and the fixed one-combination anchor. Source contexts supply the same panels and candidate combinations. The baseline question is **incremental value of the combination anchor conditional on the singles**, including exact known single-drug Sotorasib/Galunisertib/LY3200882 values. Otherwise transfer can be explained by ordinary main-effect sensitivity. All methods receive the same source histories, controls, function measurements and metadata; no RNA is needed for this first diagnostic.

Before any numerical opening, canonicalize combination tuple order with exact doses/units. The public menu includes reordered compound strings; chemical-equivalent conditions cannot cross support/query/train splits as if different interventions. Do not equate different doses under canonicalization. All repetitions of a canonical condition stay grouped and retain their unresolved replicate provenance. The chosen anchor and three queries are not reordered aliases of each other, but the complete source panel still needs this check.

Ordinary competitors should include: source query mean; additive cell/condition model; function-only Rhaister support ridge; joint direct ridge/nonlinear predictor on the exact single panel plus anchor; source-trained conditional EB/non-Gaussian episode predictor; raw-contrast interaction mixed effects; and tuned simple mixtures. A no-anchor counterpart from the same start/source-selection budget measures information value, not algorithm novelty. Within each outer context split, select hyperparameters/support-to-query maps only by source-context folds. Whole context/batch grouping must reflect available provenance; do not assert independent biological uncertainty from cells or pooled rows.

The primary prediction endpoint can be equal-context MSE across these fixed query conditions. A secondary decision endpoint is regret of selecting the lowest released phenotype among those three, relative to a source-only and single-panel direct predictor. This is a narrow relative ranking, not an assay-saving claim. Predeclare response direction, handling of missing/nonfinite labels, complete denominator, useful margin and stopping rule in a separate actual execution protocol after source package semantics are resolved and before labels. The old5% RNA threshold is not inherited. A conventional positive would justify studying a residual sharing law, not immediately building an agent/editor. No model choice is allowed after seeing which of the three query identities benefits.

## The pooled-assay obstacle that must accompany that diagnostic

The assay measures many lines in one pool under each condition. Revealing one context's functional anchor while revealing another context's query is an artificial information projection unless actual assay packages permit those separations. A held-out cell-line query may have been measured in the very same physical package already used for source-cell query labels. It is therefore a matrix-entry reconstruction benchmark, not automatically prospective independent feedback acquisition. A candidate cannot claim the experiment buys only one cheap line-specific anchor and avoids the query assay if that assay was already performed for the pool.

For real acquisition utility, support/query actions and cost must be defined as whole physically purchasable packages: treatment/sample/pool, controls and repeats. Extra source information from the query treatment in other lines is an explicitly retrospective/transductive assumption. Without independent pools/runs or a scientifically defensible future-context contract, this source cannot alone confirm across-run biological transfer or cost-saving research-agent behavior. This limitation does not invalidate a clearly named released-phenotype reconstruction diagnostic.

Same-endpoint relative phenotype and RNA are not independent functional evidence. This first diagnostic deliberately avoids RNA, not because measured RNA is prohibited, but because the unresolved core question is whether actual combination-function feedback carries transferable interaction information beyond singles. If there is no such conventional incremental signal, adding RNA/agents would obscure the simpler negative. If it exists, a new distinct restriction must still be specified and challenged on fresh isolation; these exposed query values cannot become a confirmation set for a newly invented gate.

## What success or failure would decide

Failure of a prespecified useful anchor increment against the strongest no-anchor ordinary model ends this exact anchor/query diagnostic. It does not refute all combination feedback or every module interaction. Success over no-anchor indicates information value; a joint ordinary direct/EB model matching the proposed interaction rule explains the gain and prevents a new-updater claim. A genuine core GO would require a new tested biological law or inference property with its corresponding informed controls; neither is supplied now.

No full virtual-cell contribution, agent contribution, inherited updater, joint benefit or improved-improver evidence is obtainable merely by this ordinary static replay. It is a finite opportunity screen, not a narrowed substitute for the original objective. The next action is to decide whether this consciously limited information question warrants a frozen experiment, or whether to move to a different structural opportunity; it is not to rename low-rank module fitting as RSI.
