## The central physical-cost trap

Each pooled drug-condition assay may reveal relative abundance for **all52lines together**. Hiding a line's labels in a matrix does not make that line's function a separately purchasable experiment. In this retrospective diagnostic the source already contains the same drug-condition assays in other lines, so the physical experiments generating target-query proportions may already have been conducted. Charge the actual condition/pool/control/replicate packages and disclose source assays as sunk acquisition; do not claim prospective savings from masking table entries.

Count support dose conditions, source data acquisition, all folds/trials/failed fits, preprocessing and wall compute separately.
