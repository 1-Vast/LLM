## A concrete grouping defect

Official retained metadata maps reagent BRAF1-1, symbol BRAF1, and BRAF-2, symbol BRAF, to the same target ID ENSG00000157764. ES2platemap likewise has distinct gene_name strings and distinct broad_sample IDs. A split using author gene_name or parsing a reagent name would separate one target. Therefore do not freeze a purported59-gene holdout from59 distinct strings. This is direct evidence that apparent name counts are not validated target counts; the corrected count remains to be established.

The same retained metadata supplies missing target IDs for ATP50-1/2 and XBP-1/2; ES2platemap has missing broad_sample entries for them. Do not silently correct ATP50 to a guessed modern symbol or XBP to a particular paralog. A string resembling a known gene does not authenticate the actual reagent target. No sequence-based remapping is proposed in this metadata-only task.

## Minimum corrected grouping procedure

Build an auditable non-sequence reagent→official-target table before any outcomes. Preserve plate/well/reagent/line/name/source-ID provenance and missing/conflicting states. Use the official same-reagent correspondence across plates/lines, not row-order joins. Format harmonization for well labels, plate timestamps and ID versions must be explicit and preserve original keys. Reject unexpected many-to-many plate/well mappings rather than selecting the first match.

Create conservative connected components for split assignment: (a) all rows sharing a nonempty authenticated target ID; (b) all occurrences of the same authenticated reagent across lines; (c) documented alias relations already established by those official IDs. BRAF1 and BRAF must consequently remain in one component. An equal literal author gene_name across distinct known target IDs can be conservatively unioned for splitting only, with a recorded ambiguity flag; this is a dependence safeguard, not a claim that the IDs denote the same gene. Conflicting reagent→ID records must be quarantined/resolved before defining the primary eligible set.

Primary supervised training, inner tuning and held-target evaluation use only components whose target assignment is qualified. Missing-ID reagents stay out of both primary training and test until an authoritative non-sequence mapping is established. Keeping all unknown reagents in one extra group is insufficient to claim strict target holdout: one might secretly target a known group present in training. Unknown rows can remain as separately described exploratory observations; they cannot contribute primary prediction metrics or be silently assigned by name. Ordinary assay controls used for declared unsupervised normalization are a separate role, not target examples.

All guides/lines/wells belonging to a qualified component remain together in each outer and inner split. Group-level loss/uncertainty uses the corrected target component as the cluster; fold counts and nominal59 names are not biological sample sizes. Publish eligible component count, exclusions, alias unions and line coverage before decoding endpoints. Small eligibility or inadequate locked-test uncertainty can stop the proposed diagnostic without changing the endpoint or splitting disputed target names apart. This repairs the local split contract; it does not authenticate every historical project dataset.

## Endpoint and normalization: what is required versus optional

Retained feature mapping identifies vb_percent_dead as '% All Dead (DRAQ7+)', description 'Fraction of DRAQ7 positive cells', with gating required. This supports the selected semantic endpoint; exact denominator and sampling/gating exclusions still need confirmation from metadata/methods. It does not license vb_percent_dead_only substitution.

Raw fractions are **not a mathematical prerequisite** to a narrowly declared retrospective normalized-target summary-insufficiency comparison. Both arms may predict exactly the same released normalized/MODZ condition target, provided that target is declared as such and all-target plate normalization/selection is disclosed. Such a result concerns relative normalized assay phenotype under this released processing protocol; its MSE is not percentage-point death error. It cannot demonstrate prospective assay savings, raw-fraction calibration, sparse feedback or clinical utility.

For the intended interpretable death-fraction diagnostic, prefer independently processed raw vb_percent_dead in authenticated units, equal declared health-replicate aggregation and no all-query-label target transform. This avoids plate-wide target statistics defining the outcome scale and multivariate MODZ replicate weights making one endpoint depend on other health channels. It is a **changed target-processing contract**, to freeze explicitly before numerical values, not a retrospective repair after poor normalized results. Compare morphology arms under one target contract only; do not choose raw versus normalized by whichever wins. Global target standardization for fitting, if needed, must use source-training labels only and predictions converted back for scoring.

Raw processing must also account for the author viability×cycle inner join: use a declared membership rule and disclose whether viability-only reprocessing differs from released merged membership. For the minimal first test, an interpretable raw fraction is recommended only after denominator/membership qualification; otherwise retain the explicitly normalized retrospective question or stop. Either choice must precede outcomes. No paired-cell or matched-well health interpretation follows.
