## Judgment

**REVISE -> GO for bounded metadata/schema qualification; conditional GO for one predeclared diagnostic.** A new, narrow question is justified: whether cell-level heterogeneity discarded by the published well-median summary adds out-of-gene predictive information about a separately assayed death phenotype, beyond competent models of the same medians. This does not need matched individual cells across assays. It does require authenticated condition and replicate provenance, single-cell morphology access, an identified target column, and lawful normalization. Neither performance nor new algorithm novelty is established.

This question differs from simply rerunning the author's median-feature elastic nets or original line holdout. Nevertheless standard distribution summaries may answer it. If they do, the result is information gain from measurement representation, not a new world model, functional update law, agent contribution, inheritance or RSI.

## Endpoint before looking at values

Prefer **percentage of dead cells defined by DRAQ7** as the sole primary endpoint, subject to identifying the exact released column and its numerator/denominator in schema/documentation. Primary Methods separate dead/live cells using max DRAQ7 intensity. Their separate acquisition is sufficient for the weak condition-level target. Avoid raw live/dead counts as primary: cell yield, field coverage and proliferation are substantial competing signals. Avoid DPC shape, Hoechst-derived cell-cycle fractions and an aggregate score of all70 as the first functional demonstration. Shape may share direct measurement content; Hoechst is also present in Cell Painting;70 targets introduce selection opportunity and correlated comparisons.

Percentage dead is still an assay-defined marker proportion, not a complete measure of viability, clonogenic survival or clinical drug benefit. Its total-cell denominator and gating exclusions must be documented. Dead/detached cells can be absent from fixed Cell Painting or pass segmentation differently. A failure could reflect differential population sampling rather than a deficient learned state. A success cannot identify the individual cells destined to die, given unmatched parallel assays. The primary paper already calls percent dead highly predictable; a small headroom is a legitimate limitation, not a reason to change endpoint after observing results. If exact endpoint cannot be authenticated, STOP this instantiated test rather than silently substitute an easier phenotype.

## Minimal lawful experiment if qualification succeeds

1. Unit: guide x line condition, aggregating its independent morphology wells and separate health wells. No same-well or cell join. Keep all guides of each gene together across all three lines for primary outer holdout. Shared controls are references, not independent target genes or extra test samples. All assay replicates of a heldout gene remain outside supervised training. Predeclare deterministic outer gene blocks; inner tuning is also gene grouped. A descriptive heldout-line analysis can be secondary, but only three line backgrounds exist and the author already did that analysis. Do not count folds as independent contexts.
2. Reconstruct common morphology features from the same single-cell tables, common segmentation/QC and common control reference. Base representation is per-well median followed by the same declared replicate aggregator. Augmented representation adds fixed per-feature q10/q90 and IQR summaries, aggregated with equal well weight. This tests **marginal heterogeneity summaries**, not a full joint distribution or copula. If only pooled cells are used, differing cell/well counts can dominate: do not weight high-cell-count wells as extra biological evidence.
3. Baselines: ordinary median-only elastic net and a competent nonlinear median-only direct model, plus median+cell-count/QC controls. Compare augmented summaries with the same predictor families and matched tuning opportunities; a stronger dimensionality penalty or source-only dimension reduction may be needed with ~357 conditions. Also include median+mean if feasible to distinguish tail/spread information from simply replacing a median with a mean. No need introduce an agent or generative model for this diagnostic. All methods get the same observed postintervention imaging information and paid replicates.
4. Target is a **retrospective normalized condition phenotype** if using author released normalized/MODZ labels. This explicitly allows the author target transform's use of whole-plate target readouts and cannot support sparse prospective assay savings. For a future sparse-feedback task, establish raw target units and a fixed/reference-only transform first. The primary Methods say target normalization subtracts plate median and divides SD, whereas input normalization uses EMPTY controls and median/MAD. These are distinct. A target plate transform computed from hidden query labels must never be described as free deployment preprocessing.
5. Use paired outer predictions and gene-cluster uncertainty for normalized squared-error difference, with line-specific results and simple mean/line baseline disclosed. Compare against the strongest predeclared median-only direct comparator, not merely author elastic net. A reasonable prospective resource gate is >=5% reduction in pooled error and a positive one-sided95% gene-cluster bootstrap lower bound for improvement; root must freeze any chosen threshold before payload. The inference is conditional on these selected59 genes and three lines, with few gene clusters and correlated model training; it is no broad drug/general-cell guarantee.
6. Prespecify missing-target and QC rules before values; no selecting only reproducible guides using heldout labels, no choosing the best endpoint/quantile set/line after results, no target normalizer fitted from training+test as if inductive. If augmented features do not clear the frozen practical/statistical gate, stop this representation rationale without endpoint or cutoff rescue. If they do, independently verify whether count, infection efficiency, batch, field coverage or standard nonlinear median prediction explains the increment before considering a learning-rule candidate.

## Costs and evidence interpretation

The CP assay has already been performed after perturbation. A method that requires it cannot claim pretreatment drug prediction or avoiding those experiments. Single-cell processing increases memory/storage and fitting cost even if extra staining cost is zero; all raw images/cells/wells, assays and repeats belong in the information/cost ledger. Health panels return multiple channels together; pretending each chosen endpoint is a separately purchased independent assay understates cost. In silico train/test labels are existing measured data, not new wet feedback. Library-wide drug70 outputs remain model predictions, outside this qualified primary task.

The source supports existence of Figshare single-cell SQLite and separately normalized/consensus health locations, not yet verified accessible sizes, tables or matching keys. A bounded next metadata step should authenticate exact target definition, plate/line/guide/gene map, CP well objects, object joins and replicate identities, plus immutable source versions/size. No numeric label peeking is needed for that step. If distribution inputs are not available, the proposed diagnostic is not executable on public aggregated medians; that is an instantiated data limitation, not an impossibility theorem about distribution-to-function modeling.

## Boundaries that must survive a positive result

Even a clean distribution-summary gain only establishes that these summaries retain useful condition-level predictive information. It does not establish sufficient hidden state, joint-gene interactions, causal pharmacology, reconstructible lost populations, transferable functional correction, autonomous experiment selection or recursive improvement. A subsequent updater would require its own paid-support/query contract, evidence of a reproducible error it repairs, ordinary same-information refit/conditioning/direct controls, and independent later tasks. No generic novelty veto is warranted now; no new core is yet specified either.
