# Independent statistical review

Scope: source inspection of `research/certified_discovery_gates_20261023/` and its existing protocol. No response arrays, protected/reserve outcomes, new datasets, or fitted results were opened. No implementation was changed and no experiment was run for this review. The points below concern the current contract, not an observed FDR failure.

## Decision

Retain the small evidence-portfolio experiment as a development diagnostic. Do not describe its real-data output as mathematically certified, or a Gate 1 pass as establishing FDR control. Predictable portfolio weights preserve a valid base process; they cannot repair an invalid or unproved base process. The present source provides useful software checks and model diagnostics, with important missing mathematical and empirical conditions.

## 1. What predictable mixing actually guarantees

Let F_t contain every observation available to the allocator, including other units and plates. For each null unit u and expert j, require a nonnegative multiplier L_u,t,j satisfying E[L_u,t,j | F_(t-1)] <= 1 whenever that read is selected. A convex mixture with F_(t-1)-measurable weights then satisfies the same inequality. Its product is a test supermartingale; finite stopping preserves an e-value. Allocation and stopping must also be predictable in this filtration.

The portfolio in `replay.gate1_run` uses round-1 observations to select round-2 weights and a learned bet. This direction of use is appropriate. Scoring a newly fitted expert on round 1 to choose its future weight does not by itself reuse its round-1 score as evidence. It can overfit the credit assignment, so it does not establish that credit improves future learning. Require a later-round or later-task gain against fixed weights, fixed experts, and equal-budget ordinary expert selection. The current two-round experiment cannot demonstrate improvement of the improvement strategy itself.

Global predictability alone is insufficient. Shared plate shocks can make a future read's null law depend on previously observed other units. e-BH permits arbitrary dependence among valid terminal e-values; that theorem does not supply conditional validity of the multipliers under an adaptive allocation policy. Distinct barcodes for a unit's reads remove one duplication issue and do not establish the needed global conditional noise model.

## 2. Model-based Student-t evidence needs a narrower claim

- `gate1.world_fit` fits sigma and nu using all real evidence reads, and then `Bets` reuses those estimates to evaluate the same reads. The density-ratio identity holds for the specified true null density, not automatically for its plug-in estimate. Location-invariant fitting removes the effect parameter from the fitting objective; it does not make the fitted nuisance independent of the scored evidence. Semi-synthetic reads subsequently drawn from the fitted density have a different, explicitly model-conditional status.
- `composite_null_check` evaluates finitely many mu/sigma values in [-5, 0] and finitely many bets. Numerical agreement is not a proof over every mu <= 0, the tails, or nuisance uncertainty. Rename its output to a grid diagnostic. Either prove a one-sided bound for the exact t construction used, with stated assumptions, or replace it with a multiplier whose composite-null bound is established. A certified supremum/normalizer over the declared null family is another possible construction, if computationally feasible and justified.
- P1 pair differences are effect-cancelling under repeated-read assumptions. However, (T1-T2)/sqrt(2) for independent t draws is generally not a single t draw with the original scale and degrees of freedom. The P1 simulation correctly reproduces this transform but scores it with the original single-read LR. Matching that simulation is a diagnostic of the transformed pipeline, not proof that its multipliers have expectation <= 1.
- P2 mirroring is not an authenticated all-null intervention set. Inactive single agents can have synergistic or antagonistic combinations. Mirroring positive synergy is conservative only under an additional appropriate validity/dominance argument; antagonistic effects become positive. Moreover, the Student-t shift LR is not monotone in x: its log derivative is (nu+1)[x/(nu*sigma^2+x^2) - (x-m)/(nu*sigma^2+(x-m)^2)], which changes sign in the tails. Therefore the protocol's literal statement that true synergy can only lower mirrored e-values has no general pointwise justification.

Minimum next step: separate simulator-conditional evidence, real-data diagnostics, and any prospective certification path in outputs. For prospective certification, freeze nuisance parameters using independent calibration data and justify the conditional family, or use a construction that explicitly handles nuisance uncertainty. Independence alone does not correct model misspecification. Fit-on-all-data replay can remain a labelled development analysis.

## 3. Plate ranks are a diagnostic until exchangeability is justified

Hashing read order randomizes replay reveal order; it does not randomize treatment placement on original plates. Gate 1b Type N is correctly described as a symmetry/code check: randomly choosing a control and ranking it among the others produces a uniform rank even with fixed positional variation. Type L asks a useful different question, but inactivity selected on other plates does not make the current treatment well exchangeable with NC-1 wells. Residual drug effects, dose/solvent differences, edge effects and layout roles remain possible explanations.

Record plate/position strata and the physical assignment design. Use within-stratum random assignment or a defensible exchangeability argument before treating rank bets as design-based evidence. A Type L pass is evidence against some gross discrepancy in that selected sample, not a proof for combination wells or future layouts. Its failure would not by itself identify positional bias rather than biological/assay differences.

## 4. Calibration and stopping claims

- A capped mean close to a fitted-model simulation does not establish E[e] <= 1. Capping removes precisely the tail that can dominate expectation; simulation agreement can share the same misspecification. Keep capped comparisons, tail frequencies and uncapped means as diagnostics. Do not change the certifier or choose a calibration factor after inspecting the same evidence without a valid construction and a new evaluation contract.
- `read_calibration` labels reads independent, while multiple reads belong to units and many units share plates. Unit-only bootstraps also ignore shared plates. Use plate/batch-aware uncertainty where identifiable; otherwise report sensitivity and conditional replay variability rather than biological-population confidence. Two hundred permutations of the same observations are not two hundred independent experimental screens. The FWER Monte Carlo threshold describes the declared replay distribution only, not unconditional real-world FDR.
- Terminal e-BH is correct if each null terminal e-value has expectation <= 1 for the declared family. Its per-null inequality follows directly from I{u rejected}/max(R,1) <= alpha*e_u/K. No independence among terminal e-values is needed. Repeatedly reporting e-BH sets and keeping their union requires a separate valid procedure; the ordinary terminal theorem does not certify that union. The present final set should be the final e-BH set only.

## 5. Highest-priority code changes and meaningful tests

| Priority | Change | Verification |
|---|---|---|
| P0 | Add explicit result fields for `software_checked`, `model_diagnostic`, and `guarantee_status`; default real-data certification to unestablished until its assumptions are met. | A fitted-model grid pass must never toggle the real-data mathematical guarantee to established. |
| P0 | Make required-pool completeness part of Gate 1. The current main label can pass while an undersized P2 pool is skipped via `not_testable`. | Remove one required pool; expect an incomplete/not-established decision, never `GATE1_PASS`. |
| P0 | Separate independent calibration from scored evidence when a formal path is requested; reject full-evidence plug-in use in that mode. | Mutating hidden future reads must not change frozen nuisance parameters, round-1 decisions, round-2 bets, or earlier multipliers. A calibration/evidence overlap fixture must fail. |
| P0 | Do not call the finite grid a composite-null certificate. Require a declared proven construction/assumption contract. | Include nuisance scale error, plate shocks, heteroscedasticity, nonzero null effects beyond the grid, and transformed pair noise as adversarial diagnostics. Their pass/fail is empirical sensitivity, not a theorem. |
| P1 | Make `clip_bets` handle no valid bets and requested bets below the minimum explicitly. It currently indexes an empty grid or clips upward despite a downward-clipping docstring. | Empty valid set fails closed or returns the no-bet multiplier 1; below-minimum requests follow the declared rule; nonfinite inputs fail explicitly. |
| P1 | Preserve future-only credit and add a truly later evaluation of its utility. | Changing unrevealed round-2 values must not change round-2 weights; a clairvoyant credit variant must fail this noninterference test. Compare equal-weight, fixed-bet and equal-cost selection controls on later data. |
| P1 | Keep only the terminal e-BH rejection set unless a separate repeated-reporting rule is implemented. | A unit that crossed a first-round threshold but falls below the final threshold is absent from the final reported discoveries. |
| P1 | Separate plate-aware diagnostics from formal randomization claims. | A synthetic positional gradient must leave Type N near its rank-symmetry benchmark; Type L can detect a layout discrepancy. Neither fixture should mark exchangeability proven. |

The independent density-ratio recomputation, brute-force allocation comparison and e-BH sorting check are appropriate software verification already present. They should be retained with the narrower interpretation above. The oracle/A1 comparison can assess simulator-specific headroom; it is not a universal upper bound on every policy, a demonstrated achievable improvement, or evidence that a world model or RSI mechanism supplies that improvement.
