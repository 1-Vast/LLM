The primary reviewer explicitly confirms that e-PS/proxy-e controls become necessary for a later certification or novel allocator claim. They are not prerequisites to this small descriptive test. ## Unresolved scientific questions

2. How much outcome dependence remains through plate normalization, common cell stock or fitted single-agent terms? Global split and cluster summaries limit a few failure modes but do not settle this biology.
3. Could a trained direct predictor, static transfer prior or dynamic world add value beyond ordinary scout sorting at the same total cost? The reduced diagnostic does not test these alternatives.
4. Can globally valid conditional evidence be constructed for these assay observations at practical replication cost? The existing source audit and primary literature do not provide that construction.
5. Can an inherited strategy improve later improvements from common starts and equal all-in budgets? No later-task/editor experiment is specified here.

No disagreement remains between the three reviewers about the limited justification for the reduced diagnostic. Agreement is design input, not independent empirical support.

## Actual pre-freeze challenge: the originally supported comparison cannot win

After reading the new `study.py`, this reviewer challenged a structural error that all earlier prose reviews had missed. Scout finals are drawn from original top S, while the original-only direct arm acquires the same final observation for every unit in original top S+F. Direct's final-positive count is therefore at least the feedback count on every possible outcome vector. The proposed pass was impossible before any data were needed. Root accepted the challenge and confirmed that no freeze or response conversion had occurred. Both other reviewers were sent this exact set-inclusion argument.

The proposed minimal correction is a distinct repeat-positive acquisition task: count units positive on both purchased scout/final observations. Compare the adaptive S scouts/F finals policy with a fixed repeated comparator buying both role observations for original top D = floor((S+F)/2), charging the odd leftover scout. This task has nonzero structural headroom and uses the same two-role measured observations without a noise model. It requires a new explicit endpoint and pre-freeze revision record; it is not evidence that the original final-count claim succeeded. Missing either selected observation means no repeat, with both planned observations charged. The final-only original arm, if retained, is descriptive and its set dominance remains disclosed.

This reviewer supports that limited pre-outcome correction and will check the revised implementation rather than executing the discarded design. Prior agreement above is superseded on the final-count primary endpoint, while the storage, protected-source, missingness, independence and contribution limits remain unchanged.

The revised source was inspected before freeze: `direct` now buys pairs for floor((S+F)/2), the choices ledger identifies scouts separately for each arm (including an odd leftover direct scout), and the primary boolean requires both role observations to exceed the threshold. Three generated-data integration tests passed; [test receipt](STUDY_CONTRACT_TESTS.md) and [initial fixture failure](TEST_STUDY_INITIAL_FAILURE.md) are retained. These tests cover metadata-only eligibility, persisted nominations before final conversion, future-value noninterference and charged missing reads. They establish no biological result. The implementation is ready for the one frozen development run within these stated limits, pending the root's other reviews/checks.
