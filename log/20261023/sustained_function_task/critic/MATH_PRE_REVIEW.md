# Independent pre-execution review: delayed target death after effector death

## Valid outcome and time definitions

Let K_t count observed target deaths, not lethal hits. A single effector dies at t=1 with K_1=0. The assay endpoint is T=2, not t=1. Let B be equally likely 0 or 1. For B=1 a target was triggered before effector death and its observed death occurs at t=2; for B=0 no target dies by T. Thus additional observed deaths Y=K_2-K_1=B. The old unconditional effector-death terminal rule predicts Y=0 in either case. A deterministic delay in this mathematical construction is sufficient to falsify that terminal rule; no biological rate or prevalence is inferred.

## Essential fair-information correction

Root initially suggested an ordinary same-history supervised predictor yielding separate exact predictions 1 and 0. This requires that B or another perfectly identifying observation is in the legal input history. A latent lethal-hit distinction does not itself grant either predictor access to it. If the two legal observed histories are identical, ordinary p=B would be an oracle and is not a fair control.

Primary minimal version, requiring no observed trigger: both receive the identical legal H_1 consisting of the stipulated common observations (effector dead, no observed target death, and identical other observable past). B remains hidden. The true conditional Y distribution is Bernoulli(1/2). The original terminal p=0 has mean binary Brier E[(p-Y)^2]=1/2. The ordinary same-information Bayes predictor p=1/2 has mean Brier 1/4. This strict gap alone establishes invalid absorption with completely matched inputs. The Bayes predictor is an analytic population comparator, not an empirically learned model or finite-sample training claim.

Optional separate fully observed branch: explicitly stipulate that a binary trigger marker B is legally observed at t=0 and give the identical B-containing H_1 to both methods. Ordinary p=B then has Brier 0 while the old terminal p=0 still has 1/2. This is a hypothetical observation contract, not a claim the biological sources contain such a marker. If this extra branch adds no necessary information, omit it for simplicity.

## Tower-property scope

Correct endpoint prediction has F_1(z)=E[z^Y|H_1]=(1+z)/2 in the hidden-B version, or z^B with observed B. Both differ from the absorbing value 1 whenever future observed target deaths remain possible. At the actual endpoint remaining deaths are zero and the generating function for the remaining increment is 1. Propagating the observed final interval to that true endpoint recovers the tower identity. Tracking censoring is not such an endpoint. This demonstrates only that effector death cannot be assumed terminal for this outcome; it does not prove every nonabsorbing approximation or every TD implementation is correct.
