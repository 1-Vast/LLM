## A lawful control-only endpoint exists without requiring author GI

If matching construct identities, a declared start reference and valid terminal columns are available, define a fixed endpoint for construct g in context c/replicate r:

    ell_gcr = log2(N_g,end+alpha) - log2(N_g,start+alpha)
    z_gcr = ell_gcr - median_{h in predefined reference controls}(ell_hcr).

Use a frozen positive pseudocount, reference identities and missingness/baseline-abundance rule. This normalization reads only paid construct/reference payloads, not all-target sums, target-score standard deviations or adaptive author essentiality screening. Fixed guide weights can aggregate z to each action. A pair-contrast is then the difference between two fixed action aggregates. The shared per-sample scalar control center cancels in that contrast when weights sum equally; arbitrary action/anchor-specific scaling does not. Reference controls must be measured controls, not assumed known invariant standards. This endpoint measures reference-relative construct depletion, not synthetic lethality or absolute growth/death.

The start may legitimately be a shared plasmid reference if that is what is measured, with the induced dependence disclosed. One must not relabel it matched biological T0. Shared guide/plasmid noise can inflate apparent repeat agreement. With fixed identical linear guide weights, difference-of-contrasts across contexts sharing the same plasmid denominator cancels that denominator algebraically; differences of separately aggregated medians do not in general admit that cancellation. No cross-context subtraction is required merely to measure whether the same fixed action ordering recurs in each context/replicate. A control-only alternative is mathematically legitimate without latent mechanism truth, but changing from author GI to depletion changes the endpoint and cannot silently validate previous GI rankings.

A separate preregistered author-style per-sample residual diagnostic could also be legitimate with full-screen costs disclosed and residuals rebuilt before pooling. It answers reproducibility of a processed interaction coordinate; it cannot claim control-only access or physical sparse sampling. Both options require freezing endpoint, exact sample/guide/orientation aggregation and contrasts before the new endpoint values are examined. Do not try both and choose the favorable one after results.

## Finite evidence and stop boundaries

Two screen replicates do not provide dozens of independent biological samples by expanding9guide pairs or mirrored constructs. Fixed guide contrasts give descriptive measurement agreement conditional on this library; biological-culture independence must be authenticated separately if claimed. Reuse of the same guides, common plasmid denominator and context samples needs dependence disclosure. Discovery-selected contrasts must be frozen before confirmation-replicate access; split by experimental repeat, not randomly by guides while sharing the same terminal culture. Selecting a GI-tail contrast with prior pooled GI already viewed can remain an exposed-data diagnostic but is not a fresh independent replication. No broad generalization or precise uncertainty from n2alone is warranted.

Success for this source phase is exact asset/code/metadata authentication and a clear permitted endpoint, not a new model gate.
