# Independent review of the actual API proposal

2026-10-23. Read only the received `api/PROPOSAL.md` for this assignment, plus already reviewed historical/peer evidence. No new API request, fit, outcome inspection or literature download. This supplements the sealed independent report and actual cross debate; it does not rewrite them.

**Accept the proposal's NONE recommendation for the supplied candidate; reject its universal refit-equivalence claim.** A valid narrow conclusion cannot be extended by introducing an unspecified regularizer or a generic argmin.

## Claims accepted

The displayed rank-one inverse update is exactly Sherman–Morrison when its denominator is nonzero. The equilibrium sensitivity is ordinary implicit differentiation under the usual smoothness and nonsingularity assumptions. Neither formula alone is a new update estimator; finite nonlinear edits also change equilibria/Jacobians and are not captured merely by an inverse identity.

One scalar local observation constrains only one linear functional of an unrestricted edit, so its nullspace is nonidentifiable. Multiple independent feedbacks or independently justified restrictions can resolve some/all of that ambiguity. The axis/mixed witness supports only the stated single-axis information limit; it does not stop learning from the 3,160 existing source pair functional outcomes.

The data/exposure limits are appropriate: source-only Norman is exploratory, previously exposed dev must not be called untouched, unacquired paired RNA is unavailable, and SCHEMATIC full-panel residualized scores are not automatically legal sparse-query feedback. Source OOF folds are not subsequent biological RSI tasks.

An underdefined binary feedback-sign threshold is not presently a new algorithm. No estimate, threshold selection rule, independently justified edge constraint or finite-budget mechanism has been supplied. Recommending no new core from that omission is warranted.

## Claims rejected or narrowed

1. **“Any proposed constrained feedback update can be written as this same-information refit” is unproved and overbroad.** The specified model `M_Theta + beta^T z` does not exhibit a construction reproducing an arbitrary history-dependent update program. Even if an objective can be invented whose minimizer encodes an arbitrary output, that restates the answer; it does not exhibit a computable solver using the same information/search/cost or establish pathwise equality. Learned step/history policies, early stopping and optimization geometry may matter at finite budget. Ordinary union refit is a necessary strong comparator, not a universal mathematical dominator.

2. **A candidate graph or L0 support class describes an admissible set, not the learning/selection operation.** Giving refit/direct the same graph and all RNA/features is required for fairness. It does not imply the optimizer selects the same edges, pays the same search cost or has the same risk at finite sample size. If a particular binary rule is completely specified and an ordinary implementation reproduces it, that particular equality can be tested. No such rule or reproduction is given here. Biological priors can produce real sample-efficiency gains even within a known regularization family; novelty then depends on the specific constraint/estimator and evidence.

3. **“Same single-axis Jacobian” needs an explicit location.** The witness shares the control Jacobian, not all response operators in perturbed backgrounds. At `(u1,0)`, `J12=c*u1`; at `(0,u2)`, `J11=-1+c*u2`. Transverse probes already provide mixed-support information. For its known function readout, one pair value recovers `c=(y-2)/(y-1)`. Consequently the witness cannot rule out a pair-feedback shared update.

4. **No genuinely untouched source confirmation is authenticated by a new partition name.** A source-pair split can prospectively hide individual labels from a new fit, but prior source-derived results already influenced research choices. The honest result would be exploratory source feasibility under a frozen new candidate protocol, followed by independent later-task evaluation where required. Merely calling pairs “unexposed” does not repair researcher-level adaptivity.

## What the actual proposed test could establish

A prospectively specified constrained edge estimator could be compared against same-graph ordinary constrained union refit, strong same-information direct prediction, residual covariance/context inference and fixed/equal-budget selection. Match feedback and total costs including graph/selection learning, and measure function/ranking utility. Failure against these controls supports stopping that instantiated estimator; success may support a finite-sample/compute contribution even when it belongs to constrained regression. Neither outcome alone establishes world-model necessity, agent necessity, inheritance, synergy or Level-3 improved-improver behavior.

**Final recommendation: keep API's NONE, discard the purported universal reduction as evidence.** The defensible stop rests on the absence of an additional concrete estimator and the exact IFT/Sherman–Morrison identity for the supplied operation. No new core has emerged; no class-wide impossibility has been proved.
