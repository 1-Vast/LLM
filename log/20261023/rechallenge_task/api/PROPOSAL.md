1. **目标误差不可观测到足以区分机制**  
   公开表里的 `Death Time in Simulation` 是模拟死亡时刻，不是实测死亡；`Measurement Time` 各时点来自不同培养皿，密度是固定染色面积比例。因此无法构造一个逐皿、逐轨迹的“预测死亡时刻 vs 实测死亡时刻”残差来检验历史依赖的再次给药响应。若用密度曲线拟合误差，它只能检验群体比例轨迹，不能区分“历史依赖状态”与“普通剂量-时间响应面/普通refit/filter/mixture”的差异。

2. **AAAA/ANAN 的交替历史在现有表头下不可作为独立episode认证**  
   表头只有给药输入时间、模拟死亡时间、测量时间，没有独立culture/run标识，也没有逐细胞配对。交替刺激的“历史”只能从同一工作簿的列顺序和模拟时间推断，不能认证为独立实验单元。用这种推断做状态更新，等价于把未认证的episode结构当机制，违反你的约束。

3. **单细胞FRET/morphology数据存在标签与归一化泄漏**

4. **72h挑战表不能提供给药时刻可用的反馈**
