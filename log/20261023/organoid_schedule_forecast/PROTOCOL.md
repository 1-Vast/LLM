For each campaign and g=1..maxgen: predict the complete batch g. Frozen models use G0 labels only; cumulative models use exactly gen<g. Same model specification, fixed hyperparameters, G0 preprocessing and query actions. This intentionally compares different labelled-feedback amounts and design coverage, not same-history updater quality. g1 is an algebraic identity check for all three pairs, excluded from improvement summaries. No arbitrary action oracle, optimizer replay or whole-space policy-value claim.

Six fixed ordinary predictions, no tuning or search:

1. frozen_mean / cumulative_mean: arithmetic training-label mean.
2. frozen_ridge / cumulative_ridge: identical ridge below.
3. frozen_nn / cumulative_nn: identical nearest-neighbor below.

G0 mean and population standard deviation define z_j=(t_j-mu_j)/sd_j; exactly zero sd replaced by1. This scaler remains fixed for every later batch and every model. Ridge feature vector is [z0,z1,onehot(seq),onehot(seq)*z0,onehot(seq)*z1], full fixed category domain. Fit an unpenalized intercept by centering X and y on the actual lawful training set; coefficients solve (Xc^T Xc + I) beta = Xc^T yc (sum squared loss, alpha=1). Query prediction mean(y)+(Xq-mean(X))beta. No hyperparameter learning, standardization of interaction columns or future centering. Unseen-in-history valid categories remain lawful fixed onehot features, with zero learned category-specific coefficients; shared duration features/intercept still predict.

Nearest-neighbor distance is squared Euclidean distance between G0-scaled durations plus2 if categories differ. Average labels of every training row at exactly the minimum computed distance. No epsilon radius, bandwidth or outcome-based tie handling. This supplies a simple local full-regimen control; tiny G0 data do not justify unrestricted model search. These six controls do not establish superiority over all possible direct models or meet the full-goal control suite.

Isolation: predictor accepts G0 training records, cumulative lawful history, and query actions/IDs with no cv field. Predictors never receive current/future labels. Main process necessarily has access to downloaded CSV bytes; no secure blinding is claimed. Future labels are legal historical feedback for later batches. No outcome-dependent rerun, re-encoding or configuration changes. Synthetic tests will check target-label exclusion, earlier-prediction invariance to future-response changes, and g1 equality using synthetic inputs only.
