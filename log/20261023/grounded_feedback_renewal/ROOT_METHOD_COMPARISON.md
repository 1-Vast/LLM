## U-Pert: state plus recovered abundance already exists

Original preprint: *Unbalanced Perturbation Dynamics For Cell Fate Design*, DOI10.64898/2026.06.30.735555v1. Actual full HTML is root/upd_method.body. Root read Abstract/Results, conditional WFR/semi-coupling and field-training Methods, architecture, inverse-design Methods, evaluation/data/code statements and limitations. The paragraph extraction retains prose but formula images appear as Embedded Image; root does not claim a complete equation-level proof audit or exact numerical reproduction.

The actual mechanism constructs stratum-specific WFR semi-couplings between observed control and treated snapshots, then learns condition/context-dependent velocity and scalar mass-growth fields via conditional unbalanced flow matching. A100-dimensional PCA state and FiLM conditional networks are specified. At inference, a learned operator predicts terminal states and particle masses. The inverse-design step holds model parameters fixed, optimizes a continuous condition embedding, retrieves actual compounds and re-ranks them by the same model's forward target score. Even that final re-ranking is model inference, not independent experimental feedback.

This is direct prior art against calling joint state/mass fields or differentiable virtual-cell inverse screening our mechanism. It does not establish a learned feedback updater or RSI. The authors explicitly acknowledge sampling/capture/batch effects in recovered counts, plausible transport paths rather than observed lineages, and the need for experimental validation of inverse designs. Those caveats are preserved, not attributed as oversights. Known public sciPlex/Perturb-seq/PBMC sources are listed; their availability is not a new prospective functional-feedback task here. The inspected version advertises code and simulated datasets upon manuscript acceptance; no author implementation was independently authenticated in this phase.

## SP-ICL: informative physical-time windows, not free data acquisition

Constructive inspected *Adaptive Control with Sparse Identification of Nonlinear Dynamics*, arXiv2604.06338v1. Its report documents physical-time integral regressors, sparse differential-inclusion adaptation, finite-excitation memory and tracking-bound assumptions. Root relies on that attributed original-method reading; no complete proof audit or author result reproduction is claimed.

The useful mechanism is retention/reuse of informative trajectory windows after finite excitation, avoiding explicit state differentiation. The technical contribution is not interchangeable with a static predictor merely because both fit parameters. However, the normalized window Gram H and right-hand side h are sufficient statistics for the same sparse regression objective .5theta^T H theta-theta^T h+lambda||theta||1. A comparator given identical windows can compute those statistics and solve that objective too. If one removes the tracking term/controller and simply solves this objective, that **specific stripped operation** is ordinary windowed sparse regression; this does not prove equivalence of the complete SP-ICL feedback dynamics/stability argument.

Putting unknown actuation coefficients into the regression dictionary can be a legitimate controlled-system identification formulation: concatenate integrated drift features and integrated state-by-known-input features into one regressor. That elementary modification does not authenticate known actuation, inherit the full-row-rank controller theorem or create an original cell update operator. Full-rank-known g assumptions limit the cited guarantee, not every empirical trajectory forecast. Likewise lack of a closed cellular Markov state blocks a mechanistic identification claim, not all useful observed-state prediction.

Selecting which already measured windows to retain is not selecting which wet intervention to perform. Retaining parameters/history is model/knowledge adaptation. A fixed memory replacement rule reused forever is not an improved strategy for producing future updaters. Cross-task retention of constant-theta statistics is not justified automatically under resistance or context-dependent parameter change.

## New T-cell atlas: functional validation exists, its feedback update does not

Critic inspected iScience DOI10.1016/j.isci.2026.117527 and a matching author entrypoint. Its literal input is measured post-metabolite expression, mapped to RNA-derived scores/state labels and embedding-distance ranking. Four selected compounds then have a separate downstream animal functional study. It is incorrect to turn this into pretreatment state+unseen compound→future state prediction, or a complete functional oracle for all364screened compounds. Four selected functional follow-ups cannot be imputed as an unbiased multi-task update panel. Functional benefit does not alone identify mediation through the proposed molecular transition.

If functional feedback is claimed to repair a reusable transition, compare identical support feedback under frozen-world/head-only calibration, same-capacity functional residual correction, same-parameter/optimizer/step joint retraining and same-information direct prediction. An independently held molecular readout tests that specific repair claim; it is not a universal requirement for ordinary functional prediction. Stronger claims of inherited updater or improved-improver require separate later-task, common-start, equal-history and equal-total-cost comparisons.

## Adjudicated link, not a proposed innovation

U-Pert's snapshot interpolation field cannot simply be supplied as SP-ICL's observed physical-time trajectory. Its mass output is not automatically live growth; its optimized embedding is not a purchased feedback observation. SRS provides a real-clock channel but the required public trajectory/experiment/input-history contract is not authenticated. T-cell follow-up supplies real functional validation but not repeated function-to-transition updates. Concatenating their labels does not construct a dataset containing their combined observations.

The independently justified bottleneck is **whether legal physical-time input/state observations contain enough information for an update to improve predictions on unobserved intervention schedules**, beyond same-window ordinary estimation. It is a useful prospective research question, not an algorithm nominated by this evidence. None of the inspected sources supplies the distinctive cell-specific response restriction and fair executable comparison needed to promote a new core now. No fit, toy result or RSI capability is invented to fill that gap.
