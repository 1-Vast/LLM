## A narrowly implementable difference to test, rather than claim

If a new authenticated source supplies paired pre/postRNA plus independently measured function across multiple compounds and independent experimental groups, define a transition Ftheta(x0,a), fixed molecular readoutH and functional headg. A lawful feedback update can use purchased supportfunction y and change theta through the composed loss sum(g(Ftheta(x0,a))-y)^2 while preserving a declared molecular likelihood on sourceRNA. Carry exactly the same updated transition to heldout compounds and TWO outputs: functional outcome and independently measured molecular readout not used in that support update. This can test whether functional feedback repairs a reusable transition, instead of only calibrating a score. It is a specific intervention on shared parameters with observable outputs. It is NOT yet a novel operator; no unsupported extra editor or agent module is needed.

Strongest simple control is head-only regularized functional calibration with identical frozen transition/RNA features, same supportfunction and same source data. Second, SAME PARAMETER COUNT unrestricted residual correction to function; third, ordinary joint molecular+function retraining with the identical optimizer/step budget and shared trainabletheta; fourth, direct predictor receiving identical x0,compoundfeatures,measuredsupportRNA/function. An inherited update rule can be challenged by fixed-step gradient/refit and equal-budget search over step sizes/loss weights on the SAME previous tasks. Compare actual outcomes on later tasks with common starts, support acquisitions, parameter writes, compute and all search/failures counted. A direct model is not denied a purchased RNA channel. Head-only success with no molecular advantage would defeat the need to call the update a repaired cell transition.

Falsifier: preregister a novel update operation only when its exact parameter changes differ from these controls; require same-feedback functional risk/decisiongain AND independently heldout molecular consistency across whole donor/experiment and compound groups. Require transfer of learned U versus reset/fixedU. A Level3RSI claim additionally needs evolved improverG producing better future U descendants from the SAME starts/history/cost than oldG. Merely retaining theta or using mouse validation once does not test it. Stop if only head calibration matches performance, molecular forecasts worsen, improvement vanishes under same-information controls, or available functionalgroups cannot support the declared evaluation. No source here warrants fitting before those prerequisites are met.
