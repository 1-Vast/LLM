**结论：NONE（本阶段不提出新核心/RSI机制）。** 严肃推导后，现有认证资产不足以识别“ψ1 比 ψ0 更会改进”：缺少同一独立未来机会上的共同起点比较；候选操作均可由 same-information direct、ordinary refit/CL、AL、mixture 或 equal-budget program search 精确复现，或已被历史 STOP。缺的不是模型结构，而是**独立干预单元＋早期状态→后期药物功能配对**。

**(1) 真实应用与最小数据。** 仅可作 exposed development：Pseudomonas 同细胞 step-response MAT（g/m3×36×213，t3×213），只能 within-run；WM1366 Fig4B（15 wells，每臂3技术孔，0–48h/3h，24h前洗换）只能 well-readout；AP-1 Fig4e 47 个 start-cell→final-colony reporter 配对无共同 later drug challenge。三者均不能作药物 RSI 独立验证。下一步不设计新 wetlab 空候选，先审计已有资产是否含至少两个独立 run/background 的 early-prefix→later growth/death 功能配对。

**(2) 最小操作/可证伪主张。** 不提出新公式；只做资格审计：固定源与键→保留完整 early→later 键→按 run/well 分组→屏蔽 later 功能→拟合 same-information direct/refit→在独立 run 留出上比较 direct 与常数/重复测量噪声基线→记录缺失/死亡 censoring→若独立单元不足或 direct 无预注册可检测 headroom 则 STOP。可证伪主张：该源不存在可测 headroom；若 direct 在独立留出上不能优于常数/噪声基线，则停止。10行内可完成。普通 direct/refit 可逐项精确复现该审计。

**(3) 与最接近普通方法差异。** 无差异；审计本身是普通预测/资格检查，不冒充新算子。未提出 world/agent 机制，故无待归约的新操作。

**(4) 最便宜 realdata gate。** 用上述 Pseudomonas within-run 资产先做键完整性与 run/well 独立性审计，不解释响应值、不称药效。失败：独立单元<2、只有技术孔/同 run、simple baseline 饱和、缺失/死亡 mass 不可保守界定。

**(5) 公平控制。** 未来任何候选须同信息、同总成本运行：same-information direct；ordinary refit/CL；AL（同真实 assay 菜单）；mixture；equal-budget program search。当前只运行 direct/refit 作为资格基线，避免把搜索换名。

**(6) 五类证据。** World、Agent、weight/procedure inheritance、joint、ψ1 胜 ψ0：全部 **NOT_TESTED**；本阶段无性能或独立验证证据。

**(7) 成功/停止。** 成功＝资格审计发现至少一个合格独立未来机会，且 simple baseline 有由重复测量噪声界定的预注册 headroom；之后才冻结 ψ0/ψ1、共同起点、总预算和后续改进质量/成本指标。停止＝只有技术 well/同 run、baseline 饱和、缺失/死亡不可保守界定，或候选被上述普通控制精确复现；不得把 exposed development gate 冒充独立验证。
