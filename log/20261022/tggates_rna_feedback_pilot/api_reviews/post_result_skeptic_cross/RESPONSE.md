**反对对方一处**：对方称"历史Middle-copy 0.02335714已独立迫使候选<0.00335714才可能过绝对门槛"。此推论方向正确，但须补上参照对象：该约束是相对`prior_middle_copy`的绝对门，而冻结门槛的参照是**最强非同构普通基线refit（0.0189510）**，要求候选<−0.0010490，即候选须优于refit。两个约束并存，不能只报Middle-copy那条。我首轮"LDH仅低0.0011867未达门槛"表述正确，未犯此误。

**真实未决**：route增量（route_11=rho_0同值0.0273153，route_01=0.0273589）是否具实际价值；mixture限制的解释边界。二者均为描述性，非显著，非因果。

**最小验证**：冻结门槛下连续报告candidate-vs-direct、noRNA、routes、mixture对比；不换端点、不删样本、不放宽门槛、不开保留集；agent/继承/RSI另立预注册。
