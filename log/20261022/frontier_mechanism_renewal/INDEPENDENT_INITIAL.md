## Error feedback versus operator failure

Let the current predictor be linear, f_theta(X)=X theta. Define query residual r_Q=y_Q-X_Q theta and an arbitrary parameter edit delta produced from the available support S. Under half-squared query loss, the exact improvement is

G_Q(delta) = r_Q^T X_Q delta - 1/2 ||X_Q delta||^2.

The first term asks whether the edit transports toward the unobserved query residual. A large support error, or even perfectly removing it, does not determine that term. The exact two-world example in check_update_identifiability.py has identical support x=1,y=1, theta=0, residual +1 and edit delta=+1. A query with y=+1 gains 1/2; a query with y=-1 loses 3/2. Both edits fit the support perfectly. The script verifies the formula and the opposite gain signs using rational arithmetic. These are synthetic mathematical values, not biological fits or experimental evidence.

This example refutes a universal identification claim from residual-only feedback. It does not establish that response residuals are empirically uninformative, deny correlation learned from a valid task distribution, or exclude a latent regime identifiable from multiple interventions. If the support and query share a qualified biological structure, residuals can be informative through that structure. The question is what that extra structure is and whether it transfers.

For a small gradient update delta=-eta*g_S, first-order query gain is eta*g_Q^T*g_S. The exact linear quadratic case subtracts the nonnegative curvature term. Learning how to weight support observations using this gain is already validation-gradient reweighting; learning a stateful function of gradients/residual histories is learned optimization. If no query outcomes or trusted external evaluator are observed, a model-generated estimate of g_Q adds assumptions, not new evidence. If actual query outcomes are revealed, their assay cost and later evaluation exclusion must be charged.

## One minimal hypothesis considered and rejected as a new core

HYPOTHESIS: In drug-induced cardiotoxicity screening, the direction and cross-endpoint structure of a control panel's response errors predict which update program improves decisions for later, unmeasured compounds at a new site. A gain predictor could choose between keeping the source model, a regularized update, a robust update, and a mixture, then inherit experience about update failures to a subsequent site.

Concrete available asset: the qualified CiPA 28-drug, multi-site functional recordings and the source/development partitions recorded in the prior DECISION. Real functional outcomes, explicit validity masks and disjoint control/target compounds exist. The application would be safer prioritization of compound follow-up under a fixed assay budget, not a reduction in expression loss.

This is a **conventional hypothesis**, not the promoted candidate. Its mathematical core is a contextual algorithm selector trained on held-out update gains. The prior project already tested related update-value selection and common-start program search, with scoped negative decisions. The current data has only five source physical sites; splitting drugs or endpoint columns does not manufacture independent site-learning trajectories. A four-arm portfolio is finite program search, not open-ended evolution. A learned selector is Level 2 procedure improvement at most; it does not demonstrate Level 3 improvement of the improver.

The world model is currently an interchangeable conditional response predictor; a same-input direct gain predictor or simple algorithm selector can make the same decisions. The learned agent has no demonstrated indispensable scientific action, and no newly identified pharmacological mechanism follows. Therefore this construction fails the updated goal's new capability, world necessity and independent algorithmic contribution requirements before any biological run. Renaming its gain predictor an error-to-repair world or nesting a second selector would repeat a stopped family.

If an independently qualified task later makes this useful as an ordinary test, minimum success would require a preregistered useful **decision** gain against the best same-information direct/refit/continual-learning/active-learning/fixed-mixture/equal-budget search controls, stable held-out group behavior, and a later common-start old/new improver swap with matched data and compute. The useful margin must be determined from that application's cost and consequence, not invented here. Failure against these controls, inability to measure independent future gain, or absent headroom stops the exact configuration. No such test is authorized or proposed by this review.
