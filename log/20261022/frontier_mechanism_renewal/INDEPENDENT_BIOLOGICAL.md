## 1. Strongest objection to a premature negative

Identical observed support errors under two incompatible target mechanisms establish nonidentification from that support alone. They do **not** establish that a learned updater cannot improve average future intervention decisions under a stable population of tasks. A learner can use measured state, intervention identity, exposure time, assay status and earlier tasks to learn a conditional distribution over those mechanisms. Its unavoidable error can still be smaller than that of a constant update. Learning a useful population regularity is a legitimate goal; point identification of every individual mechanism is not a necessary condition.

A fully explicit algebraic counterexample makes the scope clear. Let independent task types Z be equally likely +1/-1. A noisy measured state S equals Z with probability .8. Every task has the same support residual e=1, while the unobserved target residual is Z. A no-update prediction 0 has population squared error 1; unconditional +1 updating has error 2; an inherited population rule m(S)=.6S has error .64. For two interventions with outcomes Z and -Z, choosing by S is correct with probability .8 versus .5 for either constant choice. The identical support residual has not disappeared: S and the population law supply the additional information. If S is independent of Z, the gain disappears. These numbers are an exact stipulated distribution, **not a fit or biological experiment**.

This also gives the strongest ordinary explanation: the same effect is achieved by conditional regression/Bayes prediction. It defeats a general impossibility claim and proves neither algorithmic novelty, causal interpretation, recursive improvement nor a need for an agent. A candidate must earn those additional claims separately.

## 3. The most defensible biological question, and where it still reduces

The useful question is: **can an early, intervention-dependent state distinguish when a feedback residual should modify a transferable drug-effect rule, when it should modify only current population state, and when it should modify an assay observation model?** Those edits have different consequences for unmeasured interventions. A blanket same-sign correction can be biologically wrong even when it fits the observed condition. Cell loss, growth arrest, clearance of dead cells and measurement suppression are a concrete example of different causes producing similar net readouts.

A minimal possible operation is one state-conditioned update map

`theta_next = theta + U_eta(state, action, time, observation_status, residual)`

trained only by later measured intervention-decision utility on source tasks. A learned small operator may outperform refitting in a low-feedback regime because its population bias is better, even if a large ordinary model can represent the same mapping. This is a **testable hypothesis**, not a cleared innovative algorithm. As specified, it remains learned optimization/meta-learning. Making it a three-way router, adding a graph, or naming its components biology does not remove that reduction. The required extra technical content would be a precisely stated constraint or estimation operation that uses actual biological structure and yields a demonstrable advantage over an equally informed learned optimizer and ordinary state/observation-model inference. I cannot supply that missing operation from the current sources without inventing it.

Two tempting variants should not be advanced now. A history-triggered state split is already the stopped predictive-state/MDL candidate; no new distinct operation has been supplied. A policy that admits or rejects residual updates from support agreement alone fails the two-mechanism construction unless some additional state or population supervision distinguishes them. Cross-fitting prevents some ancestry leakage but does not supply that information.

## 5. A gate that permits success instead of defining it away

If a newly qualified asset supplies many independent tasks, preserve it for one small experiment. Freeze legal interventions, early observations, later measured function, task dependence groups, a useful decision margin and a common-budget comparator. Start with a very small state-conditioned updater and ordinary hierarchical/refit/direct-state competitors. Compare equal-information policies before closed-loop acquisition, so a better observation set cannot masquerade as a better update rule.

Population-learning gate: on later independent tasks, does the inherited updater improve the registered decision beyond the strongest source-selected ordinary rule? Include state masking, state permutation within design strata, no update, refit, empirical-Bayes conditional update, a conventional learned optimizer, fixed search and equal-budget program search. Permutation must preserve assay/batch structure and not fabricate impossible states. Exact same-information equivalence is a disqualification of a novelty assertion, not a logical reason to refuse every finite-sample performance test.

Improver gate: save eta_old and eta_new; reset the underlying world to the **same** start, give both the same later task stream and update opportunities, and measure useful future improvements per observation/compute budget. Improvement in theta alone is Level 1; a learned better research/update procedure can support Level 2; Level 3 requires that actual eta change to improve subsequent improvement efficiency over equal-budget fixed/meta-learning/search controls. Finite-menu specialization is not open-ended evolution. A new update program must introduce a validated new competence, and archive diversity or nonwinner ancestry alone does not prove that.

No margin or sample size is invented here because no new numerical protocol is authorized by this source review. A positive ordinary-control diagnostic would be valuable motivation but is not approval to call a conventional calibration layer the requested innovation.

## 6. Independent verdict and questions for cross-debate

**No candidate is currently ready for a new biological fit or a novelty claim.** This conclusion follows from missing specific operation/asset qualification and strong ordinary reductions, not a theorem that learned updating is impossible. Continue the overall research objective; preserve the separate CiPA ordinary diagnostic and all existing STOP boundaries. Do not add another architecture to compensate for this gap.

The primary must answer: (1) which measured variable distinguishes competing update consequences, or which stable population law learns that distinction; (2) what exactly is changed in the updater beyond conditional regression/online EM/learned optimization; (3) which real independent source units train and test it; (4) which later intervention decision improves at equal cost; and (5) which same-start experiment isolates improved improvement capacity. A blanket impossibility response to question (1) is too strong; an appeal to a newly named memory/module for question (2) is too weak.
