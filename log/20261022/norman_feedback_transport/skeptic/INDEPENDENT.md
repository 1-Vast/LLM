## Small common-start experiment

Use the actual qualified 103-target Norman K562 assets, existing single-only RNA representation, single-growth priors, qualified source-pair IDs, and already exposed development set. Do not create a new biological measurement or require a new operator. Keep protected pairs sealed. One deterministic ID hash partition of the 3160 source pairs supplies A=128 initial pairs, E=512 earlier feedback pairs and L=512 later feedback pairs; remaining source labels are unavailable to these fits. Existing 1051 development pairs are Q. Commit IDs/order, code, candidate menus and selection rule before fitting. Q is development, not an independent untouched audit; previous development-based method selection must be disclosed.

Fit one common quadratic baseline on A and one common fixed-RNA predictor on A. Within E, use a fixed 256/256 ID split: each candidate updates the A predictor from the first half and is scored on the second. This learns candidate choice using earlier feedback alone. Use the established symmetric pair features and ordinary PSD kernel mixture K_eta=(1-eta)K_RNA+eta K_identity, with each component normalization fixed without response labels. Identity means gene-identity pair-feature kernel, not a diagonal kernel on pairs. Mixture learning is ordinary supervised kernel/metric learning. Candidate eta={0,0.5,1} and the prior ridge penalty menu {.1,10,1000} give nine candidates. Never describe this grid as exhaustive or an optimized strongest baseline.

Construct q_E once using A+E, fixed RNA geometry and a declared penalty selected using E alone; then freeze and copy its exact predictions to every later-only arm. q_E must not depend on which geometry is later compared. In the narrow contrast, every arm predicts

q_new(Q)=q_E(Q)+K(Q,L)[K(L,L)+lambda I]^-1 [y_L-q_E(L)].

This is a valid common-start comparison: only the residual-update estimator changes; all arms receive identical L outcomes. Its estimator is conventional kernel ridge on later residuals. Earlier labels influence q_E equally, while only the selected geometry/penalty differs. The residual convention is intentional: it is not mathematically equivalent to a joint A+E+L refit, which must be compared separately. No claim of a new update primitive follows.

The central pair is the E-selected mixture update versus E-selected fixed-RNA update using the same three penalties, starting at exactly q_E. Also retain q_E without L, and identity-only updater as descriptive controls. Report absolute Q MSE, MSE change from q_E, and paired squared-error differences on identical Q IDs. Because q_E is common, the difference in gains equals the final loss difference; report both without treating them as two independent findings.

## Necessary ordinary competitors and finite stopping rule

In the same run fit ordinary all-feedback ridge on A+E+L, using the same pair features and the nine mixture candidates; calibrate its candidate choice using only an internal E split and an explicitly replayed training schedule, never Q. Also fit the established identity+RNA direct ridge and source-inspired RNA nuclear completion on A+E+L under their existing three-penalty menus. All receive identical raw legal inputs and labels. Earlier labels used to choose the updater still count as paid information, and competitors can use them directly. A fresh E-independent Q score is not available from this protocol.

For a sharper geometry attribution, freeze one penalty in advance for a subsidiary eta-only contrast (e.g. the middle existing penalty), or explicitly report that the main selected-method contrast combines geometry and regularization selection. Equal candidate counts do not make distinct grids equal compute or equivalent search opportunities. Fixed-RNA nine penalties versus mixture three-by-three can be reported as a budgeted menu comparison, but retain the matched three-penalty fixed-RNA subset; do not claim geometry caused a difference against only the nine-penalty menu.

Stop after this single registered run: if the mixture later-update arm does not improve Q MSE over both the matched fixed-RNA update and the best registered same-information ordinary refit, stop this calibration route at these budgets and menus. If it does, retain a bounded ordinary adaptation signal and freeze a subsequent protected comparison separately; do not spend the protected outcomes here or tune the split/grid to rescue an unfavorable result. Since Q has been exposed historically, this is a capability screen, not confirmatory evidence or a universal rejection. Report complete candidate scores and costs even for losers/nonconverged fits. No statistical or practical-effect threshold is invented from unavailable noise evidence.

Candidate calibration for the joint refit needs an explicit schedule: train pseudo-joint models on A plus E_train, validate on E_valid, choose candidate, then fit on A+E+L. This ordinary selection schedule is intentionally different from selecting a later-only residual updater, because the target estimators differ. A stronger competitor can additionally select refit penalties by the same pseudo-later residual validation schedule, at recorded added cost. Neither may select using Q; the candidate envelope on Q is only a labeled descriptive oracle.

## What would a positive establish?

At most: within this selected seen-gene K562 map and these finite menus, earlier feedback chose an ordinary estimator whose use on later feedback improves conditional pair prediction, with some gain surviving the registered joint-refit comparators. If it beats fixed RNA but loses to ordinary joint refit, useful geometry adaptation may exist but there is no evidence for a superior sequential updater. If same-information direct ridge wins, do not credit the transport formulation.

Task-level learning of U is not identifiable from one graph. E and L are disjoint edge sets, not independent tasks; shared target genes and a shared functional surface couple them. A learned metric can encode the graph's ordinary response function, noise, baseline errors or geometry mismatch. Those explanations can agree on observed predictions. Multiple masks/seeds do not create independent cell contexts or establish inherited improver efficiency. A positive neither identifies biologically reliable RNA directions nor proves cross-context updater inheritance, novelty, RSI, agent necessity, drug response utility or virtual-cell capability. Testing those claims would require separately defined independent contexts/tasks and a fixed transfer contract, not relabeling these subsets as generations.

The earlier stopped categorical search grammar remains stopped; no temperature, program search, active acquisition, editor or agent wrapper is introduced. The present empirical question is permitted precisely as ordinary supervised adaptation, with the original Figure 6 precedent retained.
