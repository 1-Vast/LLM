## The one apparent gap and why it does not qualify

The apparent gap is that NAIAD predicts a scalar phenotype rather than an intervention-induced expression distribution. The primary paper explicitly states this limitation in section 6, but also states that a projected single-cell phenotype can be predicted with its existing scalar formulation. Its equation (1) combines known single-gene phenotype effects with learned gene identity embeddings; adaptive capacity and sequential acquisition are already part of the published method. Absence of an expression output is therefore an output-contract difference, not evidence of a functional prediction error requiring a virtual cell.

For the current fixed-context, seen-gene pair-to-growth task, a state predictor followed by a growth decoder is itself a function of the same intervention inputs. A direct model can represent that composite function in principle. This observation does not establish equal finite-sample or computational efficiency, and does not rule out useful state supervision. It does rule out inferring state necessity from an expressive output alone. RNA-side residual completion's previously reported positive development signal establishes useful side information for an ordinary scalar learner; it does not identify a missing intervention-state mechanism. The feedback-transport DECISION further shows that the particular restricted updater lost to ordinary union refitting.

The paper's other explicit limitation, unseen genes lacking single-gene phenotype measurements, also supplies no qualifying error here: the current local contract supplies seen IDs and single-growth priors. Pretrained features or amortized single-effect prediction would address a changed generalization contract and have ordinary representation/multitask learning controls. They would not by themselves establish state prediction necessity. Making acquisition learnable likewise falls within active learning, as the paper itself discusses. Learning feedback-dependent RNA geometry is metric learning unless a distinct operation and advantage are independently demonstrated.

## Concrete next diagnostic

Before proposing another mechanism, run one frozen **source-only reliability and residual-structure diagnostic** on the already authorized scalar endpoint, without selecting models on development or opening protected outcomes. Use the existing source-inner train/validation split; obtain cross-fitted residuals of the strongest already frozen same-information direct predictor, then ask whether their magnitude and shared-gene structure exceed a measurement-reliability reference available from authenticated guide/replicate measurements of the same endpoint. Register the aggregation, uncertainty unit, and test before converting any new values. If the accessible processed endpoint has no valid replicate/guide reliability reference, record that limitation rather than treating residuals as biological mechanism.

This diagnostic is deliberately not another architecture search. Its falsifier is that remaining residuals have no reproducible structure distinguishable from the available reliability reference; in that case there is no supported intervention-state error to explain. A reproducible structured remainder would justify a subsequent narrowly specified state-versus-direct experiment, but would still not prove state necessity. Residual structure alone can be exploited by a direct functional learner. No new primitive, agent/editor, or RSI layer is a prerequisite for this check, and it is not authorized or executed by this report.
