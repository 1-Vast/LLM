# NAIAD Tutorial

In this tutorial, we'll walk through the core steps for training NAIAD models on genetic perturbation data and evaluating their performance. We will cover:

1. **NAIAD model and workflow**: How to train a model using genetic perturbation data and predict novel perturbations.  
2. **Model performance evaluation**: How NAIAD’s predictive accuracy changes when we start from small number of training data (including replicates).

We'll use the [Norman2019](https://www.science.org/doi/10.1126/science.aax4438) dataset as our primary example. This dataset provides cell viability measurements for pairwise CRISPRa perturbations across approximately 120 genes.

For further exploration, we can also apply the same workflow to the [Simpson2023](https://www.biorxiv.org/content/10.1101/2023.08.19.553986v1) and [Horlbeck2018](https://www.cell.com/cell/fulltext/S0092-8674(18)30735-9) datasets, both located in the `./data` subfolder of this `tutorials` directory.

## NAIAD model and workflow

In this example, we used 500 gene pairs for training, 1,000 for validation, and 1,000 for testing. Alternatively, you can specify fractions for the training, validation, and test sets, and the `NAIAD` function will automatically handle the data splitting.

Once your preprocessed table data is ready, create a NAIAD object using the `NAIAD` function. This function automatically shuffles the data, splits it into training, validation, and test sets, and generates the corresponding dataloaders. We can then access these data splits through `naiad_model.data`, preserving the same ordering used by the dataloaders. To learn more about the `NAIAD` class, refer to `help(NAIAD)`.

# load data
processed_data = load_naiad_data(data_file)
processed_data.head()

# create the NAIAD object
naiad_model = NAIAD(processed_data, n_train=n_train, n_val=n_val, n_test=n_test)
naiad_model.set_seed(seed=seed)
naiad_model.prepare_data()

print(naiad_model.data.keys())
naiad_model.data['train'].head()

naiad_model.dataloaders   

To initialize the model parameters, we can call `naiad_model.initialize_model`. We can explore the available parameter options by using `help(naiad.models.NAIADEmbedPheno)`. Customize model parameters by providing a dictionary to the `model_args` argument, and configure the optimizer and loss function with `naiad_model.setup_trainer`. Finally, we can train the model using `naiad_model.train_model`.

# initialize model and prepare trainer
naiad_model.initialize_model(device=device)
naiad_model.setup_trainer(n_epoch=n_epoch)

# run model training
naiad_model.train_model()

After training the model, we use the model to generate the prediction for training, validation and test data by running `generate_preds()`. We can use the best model based on the validation loss or use the model from the last epoch. The default setting is to use last epoch.

## Evaluate performance of NAIAD model with increasing training data
Here, we demonstrate the process of training the model using replicates and evaluating how the size of the training data impacts the model's performance.

from naiad.utils import RunModelsReplicates

def run_model_replicates(n_ensemble,  model_type, n_train_set = range(100, 3000, 300),  n_val = 1000,  n_test = 1000, n_epoch = 200):
    
    loss_metric = pd.DataFrame(columns=['val_loss_mean', 'test_loss_mean', 'val_loss_std', 'test_loss_std'], index=n_train_set, dtype=float)    
    for n_train in tqdm.tqdm(n_train_set):
        naiad_model = NAIAD(processed_data, n_train=n_train, n_val=n_val, n_test=n_test)
        _, rep_loss = RunModelsReplicates(model=naiad_model, n_ensemble=n_ensemble, n_epoch = n_epoch, device=device, model_args={'model_type': model_type})

        # get the index of the best model based on the validation loss
        rep_loss_index = list()
        for loss_i in rep_loss:
            rep_loss_index.append(np.argmin(loss_i['val_loss']))

        rep_val_loss = np.array([rep_loss[i]['val_loss'][rep_loss_index[i]] for i in range(len(rep_loss))])
        rep_test_loss = np.array([rep_loss[i]['test_loss'][rep_loss_index[i]] for i in range(len(rep_loss))])
        
        loss_metric.loc[n_train] = [np.mean(rep_val_loss), np.mean(rep_test_loss),\
                                    np.std(rep_val_loss),  np.std(rep_test_loss)]
    return loss_metric


n_rep = 4
loss_pheno = run_model_replicates(n_ensemble=n_rep, model_type='pheno')      # 'pheno' means only using single-perturbation phenotype values in the overparameterized linear model 
loss_embed = run_model_replicates(n_ensemble=n_rep, model_type='embed')      # 'embed' means only using perturbation embeddings to predict the combintaorial effect
loss_naiad  = run_model_replicates(n_ensemble=n_rep, model_type='both')      # 'both' means using the full NAIAD model with both phenotype values and perturbation embeddings    

## log transformation of mean and std
loss_pheno['test_loss_mean_log'] = np.log(loss_pheno['test_loss_mean'])
loss_pheno['test_loss_std_log'] = np.sqrt(np.log(1 + (loss_pheno['test_loss_std']/loss_pheno['test_loss_mean']) **2))

loss_embed['test_loss_mean_log'] = np.log(loss_embed['test_loss_mean'])
loss_embed['test_loss_std_log'] = np.sqrt(np.log(1 + (loss_embed['test_loss_std']/ loss_embed['test_loss_mean']) **2))

loss_naiad['test_loss_mean_log'] = np.log(loss_naiad['test_loss_mean'])
loss_naiad['test_loss_std_log'] = np.sqrt(np.log(1 + (loss_naiad['test_loss_std']/ loss_naiad['test_loss_mean']) **2))

n_train_set = range(100, 3000, 300)
plt.figure(figsize=(10, 6))
plt.errorbar(n_train_set, loss_pheno['test_loss_mean_log'], yerr=loss_pheno['test_loss_std_log'] / np.sqrt(n_rep) , 
             label='Pheno Loss', marker='o', capsize=5)
plt.errorbar(n_train_set, loss_embed['test_loss_mean_log'], yerr=loss_embed['test_loss_std_log'] /  np.sqrt(n_rep), 
             label='Embed Loss', marker='s', capsize=5)
plt.errorbar(n_train_set, loss_naiad['test_loss_mean_log'], yerr=loss_naiad['test_loss_std_log'] /  np.sqrt(n_rep), 
             label='NAIAD Loss', marker='^', capsize=5)

# Titles and labels
plt.title('Test Loss Comparison Across Models', fontsize=16)
plt.xlabel('Training Set Size', fontsize=14)
plt.ylabel('Loss', fontsize=14)

# Legend and grid
plt.legend(fontsize=12)
plt.grid(True, linestyle='--', alpha=0.6)
