## Necessary components and simplicity

The prior B1 Gaussian is the essential strong baseline, and preserving its exact numerical conventions avoids redefining success against a weaker baseline. F-direct additionally controls chemistry plus high functional response. Mask-direct is necessary to distinguish processed-row availability from numerical values; value/both-direct test the value block. RBF offers a fixed nonlinear direct comparator; joint-PC supplies a small source-only dimensionality reduction control; cross-fitted residual correction and equal mixing test ordinary combination. These are enough to examine the single question without new agent machinery.

Nine programs are a finite broad baseline panel, not nine mechanisms or independent confirmations. No module is necessary to call the primary conditional-information test mathematically meaningful, but the panel is justified by the user's demand for strong conventional explanations. Preserve all predictions and do not grow the panel after results. Seven molecular families versus two functional families create unequal search opportunities; the explicit disclosure is adequate for this exploratory information-allocation gate, but cannot establish equal-budget search/agent superiority or confirmatory statistical significance.

M-joint-PC lacks chemistry, unlike most direct comparators. That is an intentionally restricted representation baseline, not a like-information comparison to declare PCA mechanistically superior or inferior. The molecular portfolio contains direct alternatives with chemistry, so this restriction does not invalidate the primary portfolio test. M-residual's fixed Gaussian lambda .1 makes its gain inseparable from this base choice; its proposed explicit label and comparison with its fixed base should remain visible. Neither is a new world model.

## Main clarification: values versus availability

The gate currently permits **a value-containing direct program** to beat M-mask-direct. This is underspecified for value attribution. M-value omits the mask and has a different representation; M-RBF changes nonlinearity as well as adding values. A positive result from any of several candidates could therefore reflect representation/capacity/selection changes, not a clean addition of values to an existing availability model.

The simplest pre-value clarification is to nominate **M-both-direct versus M-mask-direct**, using each program's declared source-only nested tuning, as the positive-mean check. They share chemistry, high functional support, mask kernel, search grid and query contract; the additional block is the value kernel. No extra model or stronger statistical threshold is required. Report value-only/RBF contrasts as ordinary descriptive evidence. Even this contrast establishes usefulness of exported numerical values *conditional on their masks and processing*, not independent measured proteomic causality or selected-dose detection.

Separately tuned regularization means the contrast tests the two complete ordinary procedures, not an isolated biochemical causal effect. Equal fixed block weights can also change effective regularization after a block is added; this is permitted by the finite protocol but must not be described as uniquely identified biological mechanism. Do not add a post-result block-weight search to fix a negative result.

## Information boundary and processing

The source-only eligibility, imputation, standardization and grouping rules correctly limit target leakage. Global identifier storage must not leak target-only membership into retained features. Explicit masks describe presence/finite validity in the published ALL files. They are **not** independently authenticated detection masks for only the 10000 nM assay. ALL inclusion and upstream normalization may depend on other doses, so neither mask nor values establish a verified local molecular acquisition budget. The protocol correctly treats the input as a published processed vector and excludes fit/RF/whole-curve columns. This permits a legitimate finite published-data task without certifying all upstream provenance.

Method [56] describes relative intensities computed against average DMSO then fitted; that does not authenticate every exported Normalized_Intensity scale or full ALL row selection. The stated log2(1+x) operation is a frozen mathematical input transform, not a biological claim that this scale is calibrated across proteins/drugs. Negative finite values stopping preparation for review is sensible under that transform; it must not silently select favorable drugs after viewing outcomes.

Clarify the degenerate implementation conventions before freezing: if a source fold has no eligible value or mask features, its corresponding linear kernel is zero rather than dividing by zero. If all PCA directions have zero eigenvalue, the joint-PC predictor reduces to its functional-support-only linear form. An RBF with no positive pair distance uses the already specified constant kernel and should not create NaNs. These are deterministic completions of the existing programs, not new menu options.

## Success, stops and allowed conclusions

The primary gate is appropriately tied to the prespecified molecular-versus-functional portfolio MSE gain, adjusted for no extra budget opportunity here because there is one declared primary test; dose direction and individual influential-drug deletions prevent a narrow single-task story. The additional overall F-Gaussian comparison prevents promotion based only on finite portfolio-selection failure. Preserve the B1 Gaussian reference and recheck it against prior saved predictions rather than claiming an independent repeat experiment.

The fixed-OOF group bootstrap remains exploratory and excludes selection/retraining/measurement uncertainty. Previous development responses are already exposed and the new analysis has been motivated by them; a passing gate licenses focused hypotheses and reserved-task plans, not external confirmation. Missing functional repeats and uncertain local processing limit claim strength, not permission to analyze published endpoints.

A gate failure stops this exact single-high-dose expansion into WM/agent/RSI. It does not show all proteomics useless or permit rescue by opening the other 96 drugs, changing endpoints, adding lower molecular doses, or enlarging the grid. A pass establishes at most a conventional conditional-information candidate. New mechanism proposals must explain a repeatable residual beyond these same-information ordinary models and undergo opposing review; no gate result establishes agent, inheritance, recursive improvement or clinical drug-decision utility.
