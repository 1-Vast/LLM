## Core nested information audit

**No obvious nested-label leakage was found in the audited implementation.** Outer training excludes all members of its scaffold group, inner source excludes all members of its inner group, and risk averages individual drug losses. Targets enter molecular prediction via their molecular vector and high functional entry only. Query function labels are used as training outcomes for source drugs and validation losses for validation drugs, not as query features for that fold.

Eligibility, means, observed variances, masks, high-functional standardization, RBF bandwidth and PCs all depend on the current explicit `train` indices. Although `fold` constructs transforms and kernel rows for every drug, only source rows determine these statistics. Target-target kernel entries do not enter the source fit or selection. Source-absent identifiers have zero count/variance and cannot be eligible. Global storage of those identifiers does not by itself leak response information.

`M-residual` calls `residuals(train)` for the exact current source list. That routine removes each residual target's entire group before base Gaussian prediction, so inner residual construction is rebuilt within inner source rather than reusing outer-source residual targets. Its cache key is the exact ordered training tuple. This addresses the concrete residual-leakage concern from cross-review. Query labels for a validation group do not appear in the base fits generating current-source residual targets.

Kernel/eigendecomposition caches use exact ordered train and method; residual cache uses exact train. They are instance-local, so the future 47 refit must create a fresh Engine, not reuse a 48 Engine while merely hiding a prediction row. Negative finite intensities and duplicate rows belong to preparation audit, not verified by this evaluator inspection.

## Numerical conventions and reference fidelity

- F-Gaussian calls the actual previous predictor with budget1 and target high entry, preserving N-1 five-dose covariance, trace/5 ridge scale and high support convention. Its independent tuning iterates the same source group folds/grid. Exact-reference comparison is saved but not asserted in this snapshot; any material discrepancy must block interpretation and be resolved rather than only printed.
- F-direct uses the same chemical plus source-standardized high-functional kernel, source kernel centering, output source mean and N*lambda ridge as the prior. It solves through an eigendecomposition with tiny negative eigenvalues clipped to zero, while the prior uses a direct solve. This is algebraically faithful for a PSD kernel but not necessarily bitwise identical; reference verification must use a declared numerical tolerance and report actual discrepancy.
- Value transform, observed-only mean/std, imputation to standardized zero, >=.8 source presence and variance>1e-12 agree with std>1e-6. Value/mask kernels divide by max(1,dimension), so zero-dimensional blocks give zero without division failure. Mask means and scales are source-only.
- Combined molecular Gram has implicit source centering because the value/mask feature blocks are source centered. PCs come from its source eigendecomposition, then source score standardization and 1/sqrt(rank). Zero rank leaves high-functional features only. The code uses tolerance max(1e-12,max_eigenvalue*1e-10).
- RBF uses exp(-distance/(2*bandwidth)); bandwidth is median source distances **above1e-12**, not literally every positive floating distance; fallback is an all-one kernel, later centered. These exact conventions need the before-value amendment, not after-result reinterpretation.
- M-joint-PC uses K+N*lambda I, corresponding to feature covariance normalized by **N**, not N-1. Its primal/dual check must use that same normalization. The current draft's feature-covariance description alone does not fix N versus N-1.
- M-mix shares the same lambda across the two specified component fits. M-residual consistently uses fixed Gaussian .1 for source residuals and base prediction. Value attribution is implemented as M-both versus M-mask mean gain, as requested.
