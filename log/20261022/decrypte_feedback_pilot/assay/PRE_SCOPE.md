# Source-only assay followup preregistered scope

2026-10-22. Before new HTTP requests, this followup is limited to author-linked Shiny/ProteomicsDB public landing-page metadata, public code repository metadata/code, and method documentation. It may archive landing HTML and metadata response bytes without reading embedded biological numerical payloads. No new functional matrix, assay-result API, raw well results, workbook numeric cells or protected reserve will be requested or decoded. Existing supplement is not downloaded again.

Questions: whether dose-indexed Raw/Relative columns are measurement-derived or all-dose fitted; normalization and confluency correction; cytotoxicity endpoint time/aggregation; whether independent functional controls/repeats are publicly available by documented identities. Every request attempted gets a body/archive hash or explicit failure receipt. Search metadata may identify a relevant repository but does not establish implementation correspondence to the study without provenance.

Missing well-level data will limit precision/noise/paired-state claims, not automatically veto a declared published-endpoint prediction task. No numerical effect gate or model architecture is introduced. No functional values will be opened for root.
