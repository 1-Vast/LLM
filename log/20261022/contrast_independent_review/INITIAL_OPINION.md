## A: exact operation and information content

Write the class-restricted kernel weights as w_i >= 0, W = sum_i w_i, and m = sum_i(w_i/W)y_i. Whenever W > 0, **sum_i(w_i/W) = 1**. Consequently the proposed support condition is always true for tau_s <= 1 and always false for tau_s > 1. It cannot measure support density, distance, number of independent observations or reliability. If there is no class-matched observation, W = 0 and both m and the written gate are undefined. Numerical kernel underflow is a separate implementation failure, not evidence of absent biological support.

An exact example is one same-class observation with y_1 = 0. For any finite embedding distance and positive bandwidth, normalized weight is 1. Predictions f = 0 give residual 0 and pass both tests for tau_s <= 1 and tau_r >= 0, however far away the query is. Thus the written gate cannot deliver its stated absence-of-support safeguard. Replacing normalized mass by raw mass, nearest distance or effective sample size would change the proposed operation; each is also a conventional support statistic requiring training-only calibration and independent-unit weighting. None is a demonstrated innovation.

The residual r = f - m is ordinary disagreement with a Nadaraya–Watson functional estimator. It is a scalar, not an identified nuisance direction. No counterfactual intervention, paired potential outcome, nuisance-invariance condition or causal identification assumption is specified. Calling its threshold an intervention-support test does not establish those properties. Same perturbation class alone cannot establish comparable target engagement, exposure, timing or effect mechanism. A true, useful novel response can disagree with historical neighbours and be rejected; a wrong prediction can agree with wrong neighbours and pass. These are limitations of the information supplied, not a theorem that selective prediction cannot help.

The proposed falsifiers do not establish novelty or redundancy. Computing r requires observed functional y_i; metadata and embeddings alone do not suffice unless those labels are explicitly authorized support data. Predictability of sign(r) from uncertainty does not make |r| redundant: residuals 0.1 and 10 can share a sign while crossing the same abstention threshold. Conversely, disagreeing with an uncertainty ranking does not make a rule novel. A conventional predictor supplied with (f, m, support features) and the same calibrated decision rule reproduces this gate exactly, without a special virtual-cell or agent module.

## B: a legitimate constraint, incompletely specified

Isotonic projection is a well-defined classical estimator once the order, weights, response direction and loss are fixed. The proposed "envelope" does not specify these, uncertainty treatment, a projection metric or a complete decision threshold. For nonincreasing viability, only lower-dose observations impose an upper bound on a higher-dose target; they do not generally identify a two-sided interval. With bounded noiseless viability, the resulting interval can be merely [0, min(lower-dose responses)]. A noisy observation is not a hard biological bound without an explicit noise model.

Dose and time need separate biological justification. Time is not automatically an ordered surrogate for exposure: recovery, proliferation and adaptive responses can alter the direction. Metadata can authenticate a schedule and assay but cannot establish response monotonicity. Inspecting terminal response values to choose the monotone region would contaminate evaluation; any empirical restriction must use designated training data and be frozen before testing.

The response's sign-change falsifier is incorrect for triage. Projecting viability from 0.7 to 0.5 preserves its positive sign but crosses an advance threshold of viability <= 0.6, and can change ranking and fixed-budget selection. The proper question is whether projection changes the prespecified decision or calibrated risk and improves held-out functional utility against a matched shape-constrained baseline. A useful constrained estimator could survive this test; the present evidence supplies no reason to call it a new core.

## Fair comparison, missing evidence and next boundary

An ungated baseline is insufficient. Every strong direct predictor needs the same functional-support labels, embedding access, support retrieval, calibration opportunities and abstention/selection budget. Compare matched coverage or a fixed number of advanced candidates, with explicit replacement rules and assay/compute costs. Include kernel/isotonic methods, local refits, ordinary ensembles/mixtures, acquisition rules and equal-budget program search. The response interprets "CL" as contrastive/self-supervised learning; the goal also requires **standard continual learning**. Local refit is parameter adaptation, and a fixed gate is a fixed policy. Neither supplies inherited improvement of an improvement process.

All named resources and join fields remain unverified. An expression atlas plus a sensitivity table does not authenticate matched dose/time/run-level functional labels. Require actual perturbation identity, dose units, exposure/order, endpoint definition, missingness, run/batch/donor/line identity and usable support/terminal separation. A cell-line x drug x dose x time key is a condition, not automatically an independent replicate; shared runs, lines and drugs determine grouping and the generalization claim. Missing function cannot become zero truth. Embeddings trained using terminal functional labels would invalidate a purported support-only test.
