## Main correction and decision

The author README explicitly identifies maxide.py as a Numpy implementation of constrained matrix completion. Exact finite optimization/tuning/masking details still require the named prediction notebook and Maxide implementation; the primary plus README already suffices to rule out claiming the **general task or RNA-guided matrix-completion idea** as new.

## Independent assay and selection are now grounded

The primary explicitly describes K562 SunTag CRISPRa, two sgRNAs per gene and a growth-screen comparison of sgRNA-pair abundance at screen start versus ten days later. Fitness GI is deviation of observed double-overexpression fitness from expected single-gene effects. These are independent bulk-growth assays, not Perturb-seq capture-count-derived viability. Exact score normalization, guide/replicate aggregation and published-null fitting remain to be traced before a numerical contract.

The112 initial genes were hits whose activation changed growth. The132 RNA-profiled pairs were selected from the existing fitness GI map within/between interaction-profile blocks; the primary explicitly uses low-rank structure to justify this selection. Thus the RNA pair panel is outcome-informed. It supports conditional quantitative analysis, not blind representative all-pair discovery. The paper profiles singles as well as chosen doubles, so single-state side information is a genuinely distinct lower-acquisition-cost prediction setting.

The population source gives concrete lineage: processed_emap is loaded from filter15 gene GI; processed_fitnesses is derived from replicateAverage/ABBA-averaged phenotype matrices followed by gene averaging. A different perturbseq fitness path refers to the specific guides selected for RNA, as the notebook comments that RNA uses one guide per gene versus two in the growth map. Aliases include RHOXF2→RHOXF2B and other historical annotation changes. Single-state construction excludes BAK1/BCL2L11 explicitly because toxicity caused dropout. Preserve all of these distinctions rather than assuming all named fitness files or gene symbols are interchangeable.

The source reads an unfiltered_single_phen variable and perturbseq_phen_matrix without defining them in the extracted source sequence. A notebook's existence is therefore not proof it is executable standalone or that every export can already be reconstructed. This does not invalidate its clear external-fitness versus RNA-count lineage. Do not run the old notebook or infer missing intermediate semantics from result values.

## Impact on minimum comparison and novelty

For a single-RNA experiment the original RNA-constrained matrix-completion method/faithful finite implementation is a direct mandatory comparator when feasible, along with unconstrained completion and same-information direct symmetric single-feature predictors. Removing its label/RNA information or using copied weak code as a stand-in would not establish novelty. Fair finite budgets, masks, side-information provenance and tuning are necessary; a primary's objective identity alone does not establish identical finite training or equal cost for another implementation.

If main evaluation uses the RNA-selected pair panel, explicitly state that it was chosen using the full historical GI map. If testing all eligible held-out edges with available single RNA instead, freeze that actual eligible matrix and correctly distinguish this from the132 measured-double panel. Hold each unordered gene pair's orientations/guides/replicates together. Fit no model on the held-out reciprocal matrix entry. A pair-completion split among known genes is legitimate and does not become novel-gene transfer.

One defensible next question is whether a transparent, calibrated state-informed direct/low-rank baseline retains a useful independent-function increment under fixed pair-group evaluation and equal information. Another later question is whether a proposed update procedure improves that capability efficiently across genuinely fresh tasks. Neither currently demonstrates a new world-model mechanism, and one fixed K562 graph is not by itself a bank of independent biological contexts or inherited RSI generations. Do not manufacture task independence by relabeling folds while retaining held-out target feedback.

The original primary author result is motivation and a possible calibration target, not our reproduced positive result. No new fit/performance, prediction success, world-model necessity, agent contribution, inheritance or improved-improver benefit has yet been established.
