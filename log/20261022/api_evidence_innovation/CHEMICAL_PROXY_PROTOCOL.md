# TG-GATEs chemical-dependence proxy audit, before API requests

Purpose: determine whether47currently authenticated compound labels can support a chemically blocked exploratory test, rather than equating names/doses with independent tasks. Input is the unchanged renewal/data/TGGATES_THREE_DOSE_IDENTITY.json results.both.accepted_identity_only. No biological outcomes, gene expression, future labels or old reserves may be read. This is a chemical identity/structure API test, not a model result.

Retrieve each exact released name through the primary PubChem PUG REST compound/name property endpoint, asking for CanonicalSMILES/InChIKey/MolecularFormula. Save response bytes, URL, status, timestamps and hashes even on failure. Sequential requests with0.5seconds spacing, request timeout25seconds; one initial request per name in this pass, no automatic name substitutions. Nofirst-CID picking: require one returned property record with one parsable structure; otherwise unresolved. Parent simplification uses RDKit FragmentParent followed by Uncharger and nonisomeric canonical SMILES. Murcko scaffolds are nonchiral; blank scaffold means 'acyclic:' plus that parent, never one shared empty group. Disclose version and all discarded fragments/changes.

These are **name-resolved proxy structures**. PubChem's preferred exact-name match and one returned CID do not independently authenticate actual TG material, salt/dose equivalence, mixture composition or stereochemistry. Non-small-molecule/mixture/ambiguous names and non-carbon entries remain visible; no source-material certainty is inferred. Report unresolved rather than silently substituting another chemical. A more exact sourceCAS/structure mapping can supersede this before confirmation, preserving current exposure. The dependency grouping is a conservative development blocking variable, not evidence of donor/culture independence.

Join labels with identical neutral parent OR identical nonempty Murcko scaffold into connected components. Acyclic parent-specific keys prevent the vacuous empty-scaffold giant group. Record parent-only and scaffold-linked component counts and sizes, but do not assign source/dev/test until resulting group size/precision is reviewed. No outcome-dependent split. If every name is unresolved, this exact API identity route fails; it does not prove the source globally unusable. An incomplete proxy must not be called a completed chemical qualification or used to open unexplored final labels. No universal minimum-group gate is invented here; the next precision/design decision uses these metadata counts and explicit utility requirements.
