## 候选与范围

建议只保留一个可实测机会：**在未见化学实体的条件级毒性确认中，联合预测的两个功能通道是否出现“可校准且决定后续反馈价值”的分歧；继承一种从分歧形态选择反馈/更新的策略，是否比常规不确定性或单纯剂量邻近更有效。** 这里的分歧需在source内用assay各自尺度、噪声和剂量效应校准，不能把DNA%−LDH%直接称同一生物量差值。这不是已识别的死亡/停滞机制，也不以query-by-committee的新名称申报算法首创。

具体药物发现用途是：TG-GATEs已预筛、持续暴露的人肝细胞目录中，已有新化合物的少量低/中剂量观测后，预测其未查询高剂量24h relative survival，辅助优先安排后续毒性确认。不作临床安全性或疗效结论，不外推未测剂量。主要功能预先固定DNA relative survival；LDH relative survival是完整次要结果和学习辅助，绝不把LDH%解读为原始泄漏。若实际应用更需要LDH主终点，必须在新数值protocol开值前改变并说明，不能看结果择优。

**可证伪主张**：source上能学习一种早期干预状态条件下的跨assay预测分歧，使其能预测“买哪一份低/中剂量bundle后，高剂量功能误差将下降更多”。该关联在未来化学实体上应超过仅剂量、化学相似性、整体uncertainty、功能offset及ordinary multi-output learner给出的查询/更新价值。若普通多输出active learning和等预算程序选择完全解释，则该经验机会可以有应用价值，但不能声称新的核心改进机制。

它区别于上轮RNA residual-kernel：上轮假设干预后RNA响应几何决定功能残差向未查询条件的传播；这里测试的是**两个功能通道预测间的校准分歧能否指出何种观测/更新最值钱**。分歧只是候选可观测诊断，仍可能退化成普通模型误差/噪声，现有证据不证明独到性。

4. 记录每个source伪episode中买Low或Middle完整bundle后的真实高剂量误差下降。
5. 比较分歧条件价值与dose/uncertainty/chemical/simple multi-output标准价值预测。
6. 开始新药时，各arm从共同source模型与空新药history出发，最多买一份Low或Middle。
7. 查询策略由冻结分歧价值或普通对照给出；完整bundle揭示后执行预定更新。
