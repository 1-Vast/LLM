## What the direct API test actually established

The provider selected Watermelon and proposed asymmetric RNA/history channel allocation. I reject that proposal as written:

1. It invents early quantitative H2B-mCherry history and day0→3→7 division increments. The authenticated released PC9 metadata header is exactly `nGene,nUMI,orig.ident,percent.mito,sample_id,time_point,sample_name,sample_type,full_cell_barcode,lineage_barcode,clone_size`. No early fluorescence/division-history field is authenticated. H2B-mCherry is measured for terminal sorting in the original experiment; that does not make its per-cell early continuous values released inputs. RNA cell-cycle scores must not replace the independent reporter silently.
2. Its primary binary cycling/noncycling labels make cycling-vs-rest and noncycling-vs-rest complements. A separately interpreted asymmetric pair is therefore unsupported; any regularization difference needs an explicit computation, not two biological names.
3. It acknowledges whole assay bundles but then charges individual barcode label reveals. Those are a computational label oracle only. They cannot validate an experimentally efficient agent or physical query strategy.
4. It permits equal-budget program search directly on final test outcomes and calls source→dev→test lineages later research tasks. This is not a valid held-out evaluation or broad C4. A support/evaluation partition could repair a computational search comparison, but not produce more independent cultures/drugs.
5. Two cultures cannot support a meaningful culture-cluster bootstrap or broad culture-generalization interval. Resampling lineages is conditional clone uncertainty, not a new culture sample. There is also no reason to rescope an independent reporter outcome to an RNA cell-cycle proxy merely because the gate is fluorescence-defined; day14 gate definition is already known from the paper.
6. The response contradicts its own permutation criterion: operations require loss of the edge, escalation later says it should survive. Permuting history within the outcome gate preserves label-specific marginal signals and is not a clean global-history null. No such test should be copied into a frozen protocol.

These are substantive failures of this exact API candidate, not evidence that cell worlds or state/function factorization are impossible. No generated procedure is promoted.

## Strongest positive repaired candidate

I recommend a **narrow empirical claim about a terminal functional decoder**, rather than a new optimizer: under fixed PC9/osimertinib sorting/capture design, a day14 RNA-state→captured-proliferation-gate relationship can transfer across the two cultures better than a direct day3RNA→gate relationship, and forecasting the late-state distribution using source lineage supervision preserves enough of that decoder's advantage to improve day3 prediction for held-out lineages.

The biological question is whether early RNA is weak because the relevant functional state is only expressed later, while a learned forward state bottleneck can still anticipate the later mixture. The original paper already reports lineage reproducibility, late NRF2/FAO programs and only weak early clone-size associations. Reproducing those associations is not new. The possibly useful result is a strict out-of-lineage, cross-culture finite-sample state-supervision advantage over strong same-information direct/multi-instance learning. This is a hypothesis with low operator novelty and unverified literature originality. A positive needs opposing review and independent data before framework promotion.

The input is the distribution of day3 RNA cells in each single-call lineage in culture2. Output is the three-way day14 **captured-gate distribution** in culture2, conditioned on single-call recovery and future capture. It is not natural cycling probability, survival, clone abundance, treatment efficacy or selection/transition causality. Day14 RNA and gate are future targets for held-out lineages. The 482-support hash partition source309/dev84/test89 remains fixed; its future capture eligibility is disclosed. Use all three gates; do not choose a binary exclusion after opening labels. The >=2-cell 134/35/37 subset is a fixed sensitivity, not a new test.

For the initial culture-transfer test, source lineages in culture1 supply day3/14 state and day14 gate supervision; development lineages in culture1 tune preprocessing/hyperparameters. Evaluate once on held-out test lineages in culture2. Expression features/normalization/clustering must be fitted without test RNA, including test-culture future expression. If source-culture2 labels are opened for calibration, report a distinct target-calibrated task rather than claiming culture2 is unseen. Individual cells are repeated samples; lineages are the conditional predictive units; two cultures are the only biological replicate contexts. The original raw matrix-column join still needs authentication before conversion.

Minimal computation, at most twelve lines:

1. Authenticate matrix columns against unique rownames; freeze permitted rows and feature definitions.
2. Fit a small late-RNA state dictionary on source-culture1 expression only.
3. Fit terminal state→three-gate decoder on source-culture1 late cells.
4. Fit early lineage RNA-bag→late-state-mixture predictor using source-culture1 lineages.
5. Compose predicted late-state mixture with the frozen decoder.
6. Tune the small menu once on culture1 development lineages.
7. Evaluate frozen models on test-culture2 day3 inputs and late gate targets.
8. In the same evaluation, score the source terminal decoder on actual late test RNA as an explicitly paid/oracle state diagnostic, never the main prediction input.
9. Compare early direct and source-supervised direct/multi-instance models with all identical allowed labels.
10. Permute source lineage early↔late pairing within predeclared capture-depth strata and refit.
11. Report full three-gate losses and fixed >=2-cell sensitivity; no later model rescue.

No world operator is novel here. A linear factorization is algebraically a direct matrix product; its identical direct form is one method, not a baseline to defeat. A multihead auxiliary-state predictor with the same decoder/computation may be the same method too. The relevant comparison is whether this structural supervision produces a practical finite-sample benefit over equally informed direct models with ordinary auxiliary late-state losses, hierarchical/multi-instance pooling, low-rank shrinkage, mixtures and matched capacity/search. If that ordinary auxiliary learner matches it, keep the empirical state-supervision result if real but withdraw an independent new-world-operator claim. An empirical representation effect is not guaranteed merely by a nonzero oracle advantage.

The 0.02 value is an engineering minimum, not calibrated reporter noise or screening utility. Parent must freeze or replace it before labels open. Passing this check is target repeatability, not state headroom or world/agent benefit. It selects the next experiment without any new RNA conversion.

Before the numerical world test, additionally freeze a useful utility and precision target from source/dev only. A defensible provisional primary is mean lineage three-gate cross-entropy, requiring >=0.03 nats reduction versus the strongest separately selected same-information baseline and a conditional uncertainty interval excluding zero, with direction retained on the >=2-cell sensitivity. A practical triage endpoint must be specified before claiming drug-discovery usefulness; this captured-gate study by itself has no validated intervention-choice utility. If no source/dev predictive margin or oracle-to-forecast recoverable headroom remains, stop before test opening. These values are suggestions, not claims of known power, assay tolerance or actual success.

## Full-goal contrasts and stopping boundary

This first task has no legitimate per-lineage wet-query menu. The paid unit is culture/time+sorting/capture/library bundle. Existing data support a retrospective, fixed-bundle world test. Adding a label-selection agent would test only an explicitly named computational oracle, and I recommend not doing so here. Query-cost or drug-intervention discovery claims need a later dataset with an actual menu of perturbation bundles and functional outcomes.

| Requirement | Concrete contrast / honest current status |
|---|---|
| World | Same allowed source late-state/gate labels; compare composed forecast with strong direct auxiliary-state/multi-instance, ordinary refit/shrinkage/mixture models. Actual late RNA is a paid/oracle diagnostic only. No identical computation appears as a competing method. |
| Agent | Future bundle-choice agent vs fixed menu, random, uncertainty/information-gain and standard active learning at the same physical bundle budget. Not identifiable from a menu of clone labels here. |
| Parameters/continual learning | Later task common-start predictor, with ordinary accumulated-data retraining, replay and continual learning. Model inheritance is distinct from program inheritance. No broad later-task set currently qualified in Watermelon. |
| Program inheritance | Carry only a frozen source-learned decoder/update rule into truly held-out perturbation/cell-model tasks; compare fixed rule, fresh search and raw-history retrieval at equal data/search budgets. Remaining lineages are evaluation units, not new drug-discovery tasks. |
| Joint | Factorial world on/off × agent on/off × inherited-rule on/off under the same scored utility and total cost; report each contribution and total, without requiring superadditivity. Not yet run. |
| RSI/C4 | Save explicit old/new improvers, reset a common later solver and initial history, give identical later tasks/information/permissions/search budget, and compare improvement efficiency against fixed improver, ordinary meta/AL and equal-budget program search. Stronger inherited predictors alone are not C4. Two cultures cannot establish this. |

Stop this core if terminal decoder is not portable, its oracle benefit is absent, forecast loses all useful benefit, source pairing permutation preserves the alleged state contribution, or a same-information ordinary direct/auxiliary learner explains the entire effect. Keep any genuine narrower supervised-state result, without expanding to a new agent/RSI mechanism. Escalate only if this state/function transfer effect survives the frozen strong comparisons and utility threshold. This is a positive falsifiable research direction, not a qualified new framework core.
