Abstract
World models, which simulate an environment and predict how it changes under actions, are increasingly used in real-world applications such as robotics. Complex systems call for the same tool because the effect of an action is not immediate. Seeding nodes for a campaign, or immunizing nodes against an epidemic, changes little on its own; what matters is the outcome that unfolds over the steps that follow. Designing an algorithm that selects such actions to maximize expected performance on a task is inherently iterative, and every candidate must be scored by the outcome it produces. Obtaining that outcome has relied on simulation, whose cost becomes a bottleneck when candidates are evaluated over many sampled trajectories. We propose an action-conditioned Network World Model that learns a network’s diffusion dynamics under interventions over time, applies each action to the network, and predicts the outcome that follows. It serves as a fast evaluator inside an algorithm design loop in which a coding agent designs and refines executable algorithms using feedback from full rollouts, action-level credit, and counterfactual probes over alternative interventions. Across eight network tasks and five diffusion models, the designed algorithms match or exceed the strongest reported baseline in 138 of 141 settings while enabling up to 14.5 times faster rollouts than Monte Carlo simulation. Introduction
Complex systems such as social, contact and information networks are dynamic in two ways: their state evolves on its own, and it also changes under actions taken on the system
(
Pastor-Satorras et al., 2015
)
. Choosing which actions to take to maximize task performance is a combinatorial problem that appears across domains, from selecting the users who will carry adoption farthest
(
Kempe et al., 2003
)
to choosing who to vaccinate before an outbreak spreads
(
Pastor-Satorras and Vespignani, 2002
;
Cohen et al., 2003
)
or seeding a correction ahead of a rumor
(
Budak et al., 2011
)
. One of the major roadblocks in designing algorithms for these choices lies in evaluation: how do we know what an action will lead to before taking it? Classically, the answer is simulation, called inside the search once per candidate
(
Kempe et al., 2003
;
Tang et al., 2014
;
Han et al., 2018
)
, since computing the expected outcome is #P-hard
(
Chen et al., 2010a
)
. Learning-based methods handle this problem by fitting a mapping from a network and a chosen set to the quantity of interest
(
Xia et al., 2021
;
Ko et al., 2020
)
, or by predicting the solution itself
(
Fan et al., 2020
;
Ling et al., 2023
)
, but each is fit to a particular task and objective. This creates a trade-off between generality and cost: simulation supports arbitrary candidate interventions but requires repeated process execution, whereas learned mappings are inexpensive but typically specialized to a particular task and objective.
Designing effective algorithms for these problems often requires substantial heuristic design and empirical tuning. LLM-based program search can automate part of this process by generating, evaluating, and refining algorithmic code
(
Romera-Paredes et al., 2024
;
Mankowitz et al., 2023
;
Novikov et al., 2025
;
Liu et al., 2024
;
Ye et al., 2024
;
Van Stein and Bäck, 2024
;
Zheng et al., 2025
)
. Such a search process needs an environment in which the consequences of candidate actions can be evaluated. In other domains, world models serve this role by learning environment dynamics in which an agent can act
(
Ha and Schmidhuber, 2018
;
Hafner et al., 2025
;
Schrittwieser et al., 2020
;
Bruce et al., 2024
)
. Existing world models largely operate on images, video, point clouds, or low-dimensional control states. Yet network systems require modeling both the relational structure through which interactions propagate and how interventions modify the system and its subsequent dynamics. This raises the central question of this work: can we learn such an action-conditioned world model and use it as a reliable and efficient environment for algorithm design?
Complex systems pose three challenges for world modeling and algorithm design. First, actions may modify node states, edges, or contact weights, changing both the immediate system configuration and the subsequent diffusion dynamics. Conventional world models evolve states within fixed observation spaces
(
Hafner et al., 2025
;
Schrittwieser et al., 2020
)
, while learned diffusion surrogates often fix the intervention type, such as a seed set, and predict a specific objective
(
Xia et al., 2021
;
Ko et al., 2020
;
Ling et al., 2023
)
. Second, long-horizon evaluation introduces compounding transition error, so accurate next-state prediction does not necessarily preserve the relative performance of candidate algorithms over repeated rollouts. Third, evaluating candidate algorithms with Monte Carlo simulation is costly, while aggregate task scores provide limited guidance for revision, and evaluating alternatives, such as swapping a seed or blocking a different edge, incurs simulation cost.
To address these challenges, we propose a Network World Model and an LLM-based algorithm design framework (Figure
1
). The model is a graph neural simulator that applies interventions exactly to node states, edges, and contact weights, then predicts subsequent diffusion through a transition head constrained by the process’s known rules. We develop a coding agent search loop that uses fast model rollouts to score candidate algorithms, estimate the contribution of individual actions through ablation, and evaluate alternatives such as node swaps, providing targeted feedback for algorithm revision. We further provide a theoretical analysis that bounds algorithm selection regret in terms of transition error, rollout horizon, and search suboptimality, and shows how exact intervention handling tightens this bound. Across eight tasks and five diffusion models, the framework matches or exceeds the strongest reported baseline in 138 of 141 settings while enabling up to 14.5
×
\times
faster rollouts than Monte Carlo simulation.
Our main contributions are:
(1)
an action-conditioned Network World Model for complex network dynamics;
(2)
an LLM-based framework for network algorithm design using the learned model; and
(3)
theoretical guarantees for world-model-based algorithm selection, together with extensive evaluation across eight tasks and five diffusion models.

Related Work
Algorithms for complex network dynamics.
Classical methods for influence, containment, and inverse diffusion problems typically rely on repeated simulation or task specific structural objectives
(
Kempe et al., 2003
;
Pastor-Satorras and Vespignani, 2002
;
Budak et al., 2011
;
Shah and Zaman, 2011
)
. Learned alternatives reduce this cost by approximating the forward process, directly predicting solutions, or learning generative priors over diffusion trajectories, but are generally specialized to a particular task, objective, or intervention form
(
Xia et al., 2021
;
Fan et al., 2020
;
Ling et al., 2022
;
Yan et al., 2023
;
Memon et al., 2025
)
.
World models.
World models learn a transition function and plan or learn a policy against it in place of the environment
(
Ha and Schmidhuber, 2018
)
, either by compressing observations and rolling them forward in a latent space
(
Hafner et al., 2019b
;
Hafner et al., 2019a
)
or by training the model to support search
(
Schrittwieser et al., 2020
)
. Predominantly, they are learned over video frames or low-dimensional control states, where the observation keeps a fixed shape, however the agent acts. On graphs, the pieces exist separately: learned solvers predict the next state by message passing but take no action
(
Battaglia et al., 2016
;
Sanchez-Gonzalez et al., 2020
;
Pfaff et al., 2020
)
; the estimators above take an action but return only a final number; and graph world models act on multimodal agent states, where an action names a task and not a change to the network
(
Feng et al., 2025
)
. A complex system requires both a latent representation structured by the graph and dynamics that respond to an action which changes that structure
(
Memon et al., 2026
)
.
Algorithm discovery with language models.
Language models can write a program, score it, and revise it, and this work has converged on an evolutionary loop over a population of candidates. FunSearch pairs a model with a program database and selects on the exact objective
(
Romera-Paredes et al., 2024
)
; EoH, ReEvo, LLaMEA and MCTS-AHD organize the same loop as an evolution over heuristics, adding reflection, tree search, or mutation operators
(
Liu et al., 2024
;
Ye et al., 2024
;
Van Stein and Bäck, 2024
;
Zheng et al., 2025
)
; AlphaEvolve scales it to whole programs
(
Novikov et al., 2025
)
. Reinforcement learning is the other learned route on graphs, training a policy that emits a solution instead of a procedure that produces one
(
Khalil et al., 2017
;
Manchanda et al., 2020
)
. Across these systems, the evaluator is taken as given, since the objective is cheap and the loop’s cost is the model’s. Graph diffusion breaks that assumption: scoring one candidate means thousands of simulations. We supply the evaluator and make it return diagnostics and counterfactual answers.

3.3.2
Rollout Feedback from the Network World Model
The task score states how well a candidate performs but not how to revise it, and a revision to a plan can take three forms: retiming its actions, removing or keeping actions in the plan, and adding or swapping in actions outside it. The Network World Model returns one view for each: rollout diagnostics describe how the process evolved under the plan, action-level credit measures what each action contributed, and counterfactual probes evaluate actions the plan did not take. Diagnostics and credit are computed after every evaluation from the rollouts that produce the score, and the agent poses probes before writing the next candidate, targeting the actions the other two single out.
Rollout diagnostics.
The coding agent is given a trace of how the actions produced by the candidate algorithm unfold over the sampled trajectories. For spreading tasks, these diagnostics include the estimated task score and its standard error, the cumulative number of nodes reached after each step, the number reached during that step, and the step at which the process stops spreading. Task-specific diagnostics are used for the inverse and forecasting tasks (Appendix
E.1
). These diagnostics come from the same rollouts used to evaluate the actions produced by the candidate algorithm and therefore incur no additional rollout cost. They provide intermediate information about how the network state evolves under those actions, as revealed by the rollout trajectories.

5
Conclusion
We introduce a Network World Model as an environment for algorithm design on complex networks, together with an LLM-based search framework that uses model rollouts and targeted feedback to refine executable algorithms. Across eight tasks and five diffusion models, the designed algorithms match or exceed the strongest reported baseline in 138 of 141 settings, transfer across networks with little performance loss, and can be evaluated faster than with Monte Carlo simulation. Overall, the results show that learned network dynamics can support reliable algorithm selection and extend beyond prediction to the iterative design and evaluation of algorithms for complex networks across a range of tasks.
AI use statement
We used generative AI tools to edit the writing, including grammar checking and polishing the text for readability. In addition, large language models are part of the proposed method: the coding agent in the algorithm design loop is an LLM (GPT-5.6 Sol, Terra, or Luna) that writes and revises candidate algorithms. In the paper, we have reviewed all AI-assisted work. We read every suggested edit and accepted or rejected it by hand, and no edit changed the paper’s technical content, claims, or results. Ethics statement
Our work does not raise ethical concerns beyond those in the established network diffusion literature it builds on. It involves no human subjects and no new data collection: all networks and cascade corpora are public, all datasets and baseline methods are used under their original terms, and we use their structure and adoption times, never personal attributes or content. All interventions are evaluated in simulation, and none is deployed on a real platform or population.
Reproducibility statement
All datasets we evaluate are public, and we describe their sources in the appendix. The appendix specifies the tasks, baselines, evaluators, and experimental protocol; the world model setup; and the design loop, including its operators, probes, and implementation details. It also includes the complete prompts given to the coding agent. The coding agent itself uses closed-source LLMs accessed through an API, which we chose because they are the current state of the art. We provide examples of some of the best-performing designed algorithms with their source code in the appendix.

When a candidate loses the paired comparison, the three sampled trajectories on which it lost by the most are described and appended to its diagnostics, so that they reach the agent as feedback and travel with the record whenever the candidate is later shown as a parent or an inspiration. Operator instructions.
REFINE: make a SMALL, targeted improvement to the PARENT: adjust one term, fix one weakness the diagnostics expose, keep its overall approach.
PARAMETERS: change ONLY numeric constants of the PARENT (weights, thresholds, sample counts, radii). No structural change: same functions, same control flow, different numbers, chosen from what the diagnostics say.
