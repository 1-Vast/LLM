# DeepSeek 两个具体构造的独立反方评审

2026-10-22。评审角色：scientific_skeptic。**结论：两个构造均不保留为新的核心机制；可分别作为普通成本敏感查询、在线分段预测的基线组件。** 本稿独立阅读 `DEEPSEEK_PROPOSAL.md`、其原始提示和调用协议后撰写，初稿未读支持方新稿。没有 HTTP、响应矩阵读取、拟合或数值实验；下述是定义级归约与识别问题，不是生物学阴性结果，也不是穷尽性文献查新。

本稿只评审提案中的操作。`INDEPENDENT_TASK_REVIEW.md` 的信息/持久性门槛是资源分配和验证设计，不是另一种新算法。

## 候选 1：查询成本状态

提案状态包含实际转移浓度、可见生长孔、最近 IC50 向量和已查询集合 Q；成本定义为 c(s,a)=1[a∉Q]，另学习 IC50，并最大化预测改善减 λ 倍预测成本。这里先把 `a` 明确为 challenge assay choice；原文用 `d` 同时接近 dose、drug 和决策索引，不能据符号混用产生额外因果动作。

### 精确归约 1：成本不需要世界模型预测

Q 已包含在可见状态，a 是决策者自己指定的查询，故

`E[c | s,a] = 1[a∉Q]`，且 `Var(c | s,a)=0`。

这个等式不要求 Q 与实际浓度独立；也不要求 c 是常数。即使前面的实验动作影响后来 Q，它仍然是当前状态和当前动作的已知确定函数。学习 c 只是在近似一项程序本来可以准确计算的集合成员关系。

因此提案的“成本预测 AUC>0.6”不是 world-model 的可证伪生物预测。存在正负样本时，精确 membership 规则会无须训练得到完美排序；如果全部候选都是未查询项，c 全为 1，ROC AUC 无定义。学习器 AUC≤0.5 可说明该实现、索引或编码有问题，不能杀死或支持一个关于细胞状态的假设。成本识别正确也不支持性能、新颖性或 RSI。

### 精确归约 2：普通成本敏感信息获取

把可获得的生物观测历史记为 H，普通直接模型产生对未查询响应 Y_a 的条件分布 `p(Y_a | H)`。用完全相同的模型、Q、收益函数 G 和成本，普通一步查询规则为

`a* = argmax_a E[G(Y_a,H) | H] - λ·1[a∉Q]`。

这与提案的选择式逐项相同。实际转移浓度和可见生长孔只是 H 中的上下文；普通主动学习/实验设计并不被定义为禁止这些协变量或禁止动作相关成本。把一个未包含成本的特定 AL 实现作为对照，不能据此主张 AL 本身不含该能力。

若加入多步信息价值，令 b 为给定 H 的潜在生物状态后验，则 `(b,Q,剩余预算)` 是普通信念状态。观测新 assay 后用相同似然更新 b，用 `Q←Q∪{a}` 更新账本，Bellman 目标扣除同一已知成本。该增广信念 MDP/POMDP 逐步实现同一策略。提案没有给出超出这个表达的新状态辨识条件、更新操作、近似误差保证或样本优势。

还有一个更小的退化：若每步只能选尚未查询的新 assay，所有可行动作 c=1，固定步数预算下 `−λ` 是同一常数，不改变当步 argmax。若把已查询项也列为零成本动作，其真实信息增益应为零；把同一响应重新当新反馈会重复计数，甚至形成“免费重复查询”的虚假收益。

### 需要先修复的对象身份与动作语义

若 Q 只存 drug 名称，某药 day2 测过就会使 day4/day6/day8 的同药测量免费。生物状态已变化，这不是同一已知响应。合理的 query key 至少包含独立 lineage/population、采样时间、challenge drug 和 assay 类型；独立重复测量还需 replicate 标识。修复 key 后，每个尚未知的新 assay 一般仍然有一次成本。

主实验中的 challenge 是对取出/培养的样本做药敏测量。改变“查哪项 IC50”改变智能体信息；它并未被证明改变仍在原选择药下的母谱系未来生物状态。若 a 改指实际施加的选择药，则需要同一当前状态下不同选择药的后继转移结果，不能把测量不同 challenge drug 的响应行当成这种转移。若 a 改指实际 daily dose，则原实验的 dose 由先前生长决定；当前来源没有认证自由剂量策略的完整反事实菜单。三个动作不能互换。

原实验未必有一个供算法参与的真实选择性查询顺序。可在档案上预登记 mask/揭示顺序并评估模拟信息获取，但应如实称为 retrospective query replay，不能称为已运行的实验反馈闭环。作者当时测量顺序也不会自动成为最优实验分配的行为策略。

### 可挽救边界

保留为简洁的已知 assay 成本账本和成本敏感 AL 基线，是合理的工程选择。若真实成本来自未知的培养失败、达到阈值所需重复次数、反馈时延或 assay feasibility，成本可能需要估计；但这要求相应 attempt/失败/时间记录，而不是重新定义 membership。即便这些记录存在，也首先归入普通随机成本/受约束实验设计；尚需指出一个具体且不能被同信息普通方法逐步实现的新操作，才形成新候选。

**最省资源的杀死方式：以上确定性代入与策略逐项归约已足以停止它作为新机制。** 无须先拟合 c，亦不应为其 AUC 下载响应。未来真实预算下命中数更好，最多证明这个基线组件有用，不能撤销其算法等价性。

## 候选 2：挑战前置条件、转折点与切换日

提案定义 `g_k = IC50_DOX(k)-IC50_DOX(k−1)`，拟合分段线性函数与翻转点 h，选择 DOX 挑战时间，并把规则迁移到新 population。这里 g 是目标响应的有限差分，尚不是独立的挑战前置条件或生物状态变量。

### 目标式本身未定义一个有效的断点估计

原式为 `argmin_h Σ_{k≤h}(IC50_k−f(k;θ))²`。它让不同 h 使用不同数目的观测，却未给出 θ 如何共同优化、最小段长、复杂度惩罚和真正可见的决策 cut。非负残差和会直接偏向少量前缀；很短的前缀还可被直线精确插值。更关键的是：若 h 同时是拟议断点而拟合仅用 k≤h，数据没有断点右侧，第二段斜率无法由该目标辨识。

这不是只需要更强优化器的问题。它也不是因为“分段方法能力弱”。需要先把所解问题写对。

### 修正式精确归约：普通分段回归/在线结构变化检测

给定固定的已观测 cut T，标准连续分段直线可写成

`f(k)=α+βk+γ(k−τ)_+`，

并在同一观测集合 `k≤T` 上联合拟合 τ、α、β、γ（含预先固定的正则化、最小段长/候选断点规则）。这正是提案“时间+一次斜率改变”的函数族。顺序读取新观测并重拟合，就是普通在线分段回归；给断点和参数后验、随新观测更新，就是普通在线结构变化推断。出现 g 符号翻转并不会改变这个归约。原提案只写“无翻转时退化”过于弱：**有翻转时也仍是同一个分段回归操作。**

“原作 dMDP 假设未来 profiles 已知，而这里仅用过去”确实改变可用信息和预测问题，值得设为公平对照条件；但不构成新的学习方法。应把不享受未来信息的直接历史预测、普通分段重拟合、平滑非线性曲线和简单持久性同时纳入，不能只胜过有不同任务设定的 dMDP 就宣布新颖。

### 预见未来翻转的识别边界

如果所有可见时点都在真实断点之前，那么对任何 `τ>T`，上述 hinge 项在全部训练时点均为零。训练似然与未来 τ、γ 无关。相同前缀可以接上继续上升、稍后下降或更晚下降的轨迹；仅从无约束前缀无法辨识下一天会否翻转。

若有跨 development populations 学到的断点/斜率分布，或已认证的独立前驱状态变量，可以得到一个有条件的预测。但前者是普通分层/共享先验预测，后者需要额外数据与可验证的观测模型；两个都不是当前公式自动拥有的能力。若已看见断点后的若干观测，h 可更容易回溯估计，但不能把回溯定位包装成在 h 之前已成功预警。

`g_k` 还会放大测量噪声。即使原始误差彼此独立且同方差 σ²，相邻差分的噪声协方差也是 `−σ²`，因它们共享一项且符号相反。因而直接计数逐日差分符号变化不能证明存在稳定生物转折。应在观测误差/技术重复下比较预测和决策效用，而非仅要求“存在一个非端点 bootstrap CI”。即使曲线平滑弯曲或短暂抖动产生符号翻转，也不特指分段机制。

### 真实应用范围与效用判断

20-population CRO→DOX 实验实测的是持续 CRO 演化轨迹上每日样本的 24h DOX 挑战。它可支持固定菜单中的未来 DOX 响应预测及单次挑战时点选择。它尚未支持 DOX 分支继续演化、来回换药或长期疗效。因此“时序反事实”最多是这个菜单中的受限回顾性选择，不能由标签提升为一般治疗反事实。

比较固定日程时，应允许固定日程使用 development populations 的均值曲线，以及论文已公开 days8–13 窗口的设计暴露信息；该窗口不是本候选新发现。对留出 population 用其完整未来轨迹选最优 h 后再报告低 IC50，是后见选择。合法策略只能用其 cut 前实际取得且计费的观测；尚未发生日的 DOX 结果不能免费成为 g 的输入。

个体未来预测可以有用，但它需要改善实际的时点/确认分配而非只拟合一个转折。如果早期 prefix 不胜过 last-response 或 calendar mean，复杂的切换规则没有已展示的作用空间。这个验证是 task gate，不是本候选的算法贡献。

### 可挽救边界

将式子修复为固定 prefix 的普通分段基线，测试 population-specific timing 是否有可预测信息，是值得保留的窄应用。均值转折/个体差异能否预测、是否胜过简单曲线仍然未知。新机制则需要另一个具体贡献，例如可检验的前驱观测关系或有识别条件的更新约束；当前提案未提供，不能靠增加 latent state 或多层 agent 自动补齐。

**停止其新核心身份不要求先证明 g 从不翻转。** 即便许多群体有真实、可预测的翻转，该公式的修正版也仍属普通分段回归；若得到样本外收益，应如实报告普通模型的应用收益。

## 两个候选的继承和 RSI 归因均不成立

把已知成本规则写入下一个程序，或者把拟合的 h/先验迁移到另一 population，分别是规则复用、参数或模型迁移。它们可以和 restart/pooled/simple mixture 对照评估，但“m1 少查几次/选日更准”只测后继策略性能。

RSI 的目标对象是 improvement procedure I 本身。需明确 I 如何从程序、训练/开发证据和有限预算产生后继程序；明确被编辑的 I0→I1；然后冻结二者，给它们等资源、相同起始条件和独立的后续改进机会，测后续改进增益、可靠性或达到同等效用的成本。当前两个提案均未定义这个对象和更新，故它们的所谓“improver m1胜m0”不是 improver 测试。

世界模型、agent、继承和联合收益也必须分别归因：已知 membership 准确率不是 world-model 贡献；更换 λ 或回归曲线不是自动成为研究 agent；同一轨迹数据增加不是独立任务继承；加入两个普通组件的总性能提升不是自动的联合协同。此处没有这些贡献的阳性或阴性数值证据。

## 评审决定与交叉质疑问题

**候选 1：STOP_AS_NOVEL_CORE，保留已知成本 AL 基线。候选 2：STOP_AS_NOVEL_CORE，保留修正后的在线分段预测基线。新核心候选数量：none。** 这不否定该来源存在有用的 phenotype forecasting 或实验分配应用；数据身份资格与先前单独提出的最小任务门槛照常评估。

拟向支持方交叉质疑：

1. 在 s 已知 Q、a 由算法指定时，能否给出 c 不是精确 membership 的任何情形，同时仍保留原提案定义？若不能，哪一步无法由同信息成本敏感 AL/信念 MDP 原样执行？
2. 对候选 2，用固定观测 prefix 修复目标后，能否给出不同于 hinge 分段回归的实际更新？在断点全在未来的两条同前缀轨迹之间，什么已认证观测打破不可辨识？
3. 哪个具体 improvement procedure 被继承性地编辑了？能否指出后续改进机会和等预算比较，而不把更好的预测/查询策略本身称为更好的 improver？

支持方若能指出明确不同的操作、已认证额外观测或识别条件，应将其作为新版本重新审查，不用本稿对原公式的否决替代对新构造的判断。
