## 实际问题与答复

1. **反方问：** s 包含 Q 且 a 由算法指定时，`E[c|s,a]=1[a∉Q]`、条件方差为零。原定义内哪项成本仍未知，哪一步不能由同信息 cost-sensitive AL / belief MDP 实现？

   **支持方答：** 原定义就是 deterministic membership，没有额外未知成本或新更新；归约无须 Q 与 dose 独立。普通 cost-aware AL / belief MDP 逐步覆盖。若只记录 drug 还会使未来 timepoint 错误免费。反方接受。

2. **反方问：** 原 `Σ_{k≤h}` 改变拟合样本数、断点右段无观测；固定 prefix 修正后等价普通 hinge 分段回归。`τ>T` 时全部未来断点在前缀上同似然，哪项已认证观测能预见翻转？

   **支持方答：** 承认短前缀偏差、固定 prefix 后的普通 segmented regression 归约，以及当前没有已认证额外前驱观测可打破未来 τ/γ 不可辨识。反方接受；补充相邻差分噪声的负相关使“检测到符号翻转”更不能单独建立可预见机制。

3. **反方问：** 哪个 improvement procedure I0→I1 被编辑，在什么独立后续机会中检验它更会改进？

   **支持方答：** 提案没有定义该对象、编辑或后续 improvement opportunity；m1 更省 query / IC50 更低只是最终 policy 更好。反方接受。

## 支持方反向质疑与反方澄清

- **支持方问：** 没有作者历史 query 顺序，是否仍能预冻 archive query replay？

  **反方确认可以。** 实际可用的完整菜单、合法 assay bundle、身份与计费认证后，可以预登记 masking / reveal 顺序；Q 由算法自身已揭示历史生成。无须先恢复作者原查询顺序。限制是不能称为作者实际选择、真实湿实验反馈闭环或已经省下真实实验。本点原反方稿已允许，双方无分歧。

- **支持方问：** 是否错误要求 DOX 挑战后继续演化，才允许 timing 应用？

  **反方确认不要求。** 单次 24h DOX 挑战的定时/确认分配应用可直接研究。只有更长期治疗控制、返回 CRO 或多轮切换主张才需要对应 continuation 结局。本点原反方稿已区分，双方无分歧。
