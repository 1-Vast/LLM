## Agreement with the endpoint contract

The binary exported-row EAD fraction, exported continuous-availability fraction, and available-mean ddFPDc match the contract. EAD is not inferred from event-type strings; no missing H is assigned pathology or zero. The continuous score is conditional on observed numeric availability with coverage reported, rather than an unobserved latent ground truth. The expression `p²−2py+y` is the equal-row expected Bernoulli Brier score within a bundle; it is a valid proper score for the row-event probability and differs from `(p−y)²` by a target-only constant. Paired model comparisons on the same endpoint population are therefore unaffected by that constant. Equal-bundle averaging and fixed populations are important.

Source-only IQR/SD scaling, zero-correction fallback, source prediction fallbacks, and masking only the continuous endpoint are consistent with the contract. All three source-predicted heads may be features; actual terminal EAD, H, valid counts, missingness masks, or event strings may not. The source-derived observation head is an ordinary derived prediction, not access to the unpaid condition's observed mask.

## Prefreeze issues to resolve explicitly

1. **Program-selection folds:** hashing eight acquired IDs into four bins can produce an empty bin. Specify balanced deterministic assignment (e.g. order by hash+ID, assign positions modulo4) or an explicit empty-bin rule. Prefer pooling held-out predictions across all eight controls before computing the three endpoint scores. A held-out fold can have no available H even if the full control set has some H; skipping that fold/head separately can change the meaning/weighting of a combined score. If the full acquired set has no H, use one declared reduced-head score for every program and record that fact. Never let a method omit a hard head because its prediction failed; invalid predictions must stop/fail under a common rule.
2. **LOSO features:** recompute source lookup means, global means, scale, source-vector features, between-context uncertainty, and all selected hyperparameters within each physical-source-site fold using only its training sites. In particular, do not reuse all-source vector columns in a held-out-site augmented direct model. The held-out source site is pseudo-target feedback only at its declared eight controls. No other held-out numeric value may influence acquisition or fits. The training predictor may use its own training labels normally; the target feature summaries must exclude that target site.
3. **Select source-only comparator before development:** the success text's phrase “improves mean source-only combined loss at development6/7” should unambiguously mean the development combined loss of the source-CV-selected source-only predictor, scored on the same terminal bundles, not a comparison to a source-CV loss on another population. Freeze a primary candidate (the source-CV-selected updater) and primary fixed query set. Other family/policy screens remain explicitly multiple descriptive comparisons; do not promote whichever happens to win development.
4. **Context versus site budget:** the new protocol uses eight queries per context, whereas earlier task wording used eight per new physical site. This is an explicit task revision, not an endpoint-contract violation. Report every physical site's total context count and total paid bundle cost and do not later describe16queries across two contexts as an eight-query site calibration. Group source-CV loss by physical site as written, rather than allowing multisystem sites extra weight merely through context count. If development happens to have one context per site, the revision does not alter their primary cost, but the convention must remain explicit for later tasks.
5. **Missing-source uncertainty:** define the source-only variance estimate/fallback for a head with fewer than two valid source-context values and for any missing source H lookup. Do not let an unpaid target count decide that fallback. Stable-ID ties make the fully defined metadata policy reproducible.
6. **Probability and numerical safeguards:** source-only scale must be finite positive after the declared fallback, predicted arrays must be finite, and clipped probability predictions must be used consistently in CV, program search and terminal scoring. Null continuous truth is a mask; a null/nonfinite continuous prediction for an available truth is not an allowed selective abstention. No silent sample drop should improve a method's score.

Items1–3 are the most consequential prefreeze checks. They were sent directly to root and the model implementer rather than held until a later review.

## Fairness and limits already handled

The direct drug×dose ridge/tree, source-vector-augmented direct model, ordinary refits with target weighting, identity-penalized calibration, source lookup strata, fixed mixture, source-best family, standard uncertainty/design acquisition and paid-label-only program selection cover strong ordinary explanations. The protocol accurately calls the design policy non-outcome-adaptive and the portfolio search equal-assay-budget rather than equal-compute. Extra fitting/search cost is to be measured. A random policy's seeds do not create additional independent biology.

The primary fixed controls are published-pharmacology choices, not blind discoveries. Their transfer to the24other drugs is a concrete falsifiable calibration operation. A loss to direct/source/refit baselines would stop the corresponding configuration; a gain would still be ordinary adaptation evidence. Source line/platform confounding remains, and no causal site/platform mechanism is established. Known drug categories and categorical dose curves are permissible in this interpolation task; no unseen-drug claim follows.

The primary screen includes all three pooled component nonworsening checks plus combined improvement over the frozen source-only comparator. That is stricter than merely improving a convenient scalar. With only two development sites, report both site differences and avoid population claims. A candidate can pass an opportunity gate yet lose to a stronger conventional refit; such a result provides no basis for promoting it as a world/agent contribution. Later sites8–9 remain protected by identity-only handling and need another frozen future protocol.
