Source bundle means are equally weighted by context, not exported row count. For each drug/dose/head predict (a)all-source-context mean, (b)same-cell mean, (c)same-cell/platform mean; fall back c→b→a→head's source-global mean if needed. These are strong known-drug direct lookup baselines. Default source functional vector is b=(E,M,H/source_scale).

At the fixed eight paid control bundles compare three ordinary updates of b: independent residual offset; independent affine correction; and multivariate affine correction using all three source-predicted heads. Fit each head on available paid labels only, penalize departures from the source identity prediction with ridge strength kappa in {1,8,32}. Features for residual models: offset[1], affine[1,b_head], multivariate[1,b_E,b_M,b_H]. All coefficients, including residual intercept, are penalized; prediction=source prediction+fitted residual. No valid paid labels for a head means no correction. These are standard shrinkage/calibration models, not new worlds.

## Freezing, execution and interpretation

Prefit clarifications, recorded before any predictive fit: all source summaries, scales, variances and lookups are recomputed using only training-source sites inside each LOSO fold. For augmented direct ridge, source-training rows receive source vectors computed leaving their entire physical training site out; target-acquired rows use only the fold's source sites. This prevents encoding a source row's own outcome in its derived feature. Metadata one-hot categories may be known globally, but no numerical label summary is global across a held-out site.

Portfolio four-fold assignment uses SHA256(bundle_id) ordering followed by round-robin, giving exactly2querybundles per fold. If a validation fold has no finite continuous response, average only the available endpoint losses for that fold, with identical validity masks for all candidates, then average the four fold losses equally. No per-model outcome filtering. This also specifies how the generic combined loss handles a genuinely absent head; E/M remain available. Query counts are8percontext, so a dual-context source site receives16total while each single-context development site receives8. This is an explicit equal-context-bundle benchmark rather than equal physical-site cost. The improvement comparator is the source-CV-preselected source-only model's **development evaluation score**, never its source-CV score compared across populations.
