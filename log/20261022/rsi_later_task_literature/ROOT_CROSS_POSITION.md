# Root questions and resulting scope clarifications

2026-10-22. These questions were actually sent after the independent drafts, and the skeptical reviewer actually accepted the first three in CROSS.md. They do not change the running frozen AZ experiment.

1. A static action-conditioned functional-response model can be a legitimate world-model component. Neither molecular state nor a time sequence is a universal prerequisite. Actual molecular/dynamical claims require matching evidence; static/RNA/morphology tasks retain their scoped scientific value. Strong same-information direct comparisons determine whether explicit world structure contributes.
2. The user's current RSI requirement is a better improver making subsequent improvements more effective from a common start and budget (C4). Unbounded acceleration or repeated growth of this gain (C5) is a stronger optional claim. Code rewriting is neither necessary nor sufficient. A learned statistic or small policy can be an improver, but ordinary bandit/meta-learning remains a strong explanation and baseline.
3. Joint product gain does not require superadditivity. Positive world×policy interaction is required only for a synergy claim. A failed isolated policy swap does not refute useful total inheritance; report both and distinguish their interpretations.
4. Common start includes the model/program/data/allowed history/budget, rather than merely the same starting score. Subsequent histories may diverge because policies choose different observations. A summary need not reconstruct raw history to be a fair representation; match original information, learning permissions, inheritance payload and costs.
5. The two-paid-AC/BD contract does not permit eight rounds of hidden-AB feedback. Repeated model fits on the same paid information are computations, not new experiments. A source-trained update policy can act on paid inputs and receive one terminal AB audit after sealing. A genuinely interactive future experiment would need a separately registered, charged feedback menu and protected remaining audit targets. Public static response tables can support explicitly retrospective query-oracle tasks where actual measured actions are available; public pre-existing adaptive trajectories are not a universal requirement. No new such protocol or reserve opening is authorized by this literature note itself.
6. An ordinary controller succeeding only with a validated biological representation can support a real representation/transport/sample-efficiency contribution. It does not establish that the representation adds raw information, that all direct models are incapable, or that the controller is a new RSI operator. Concrete prior biological/meta-learning work still needs review.

All three independent reviewers agree that generic memory, diagnostic routing, local patching, shared-program inheritance, editable meta agents, learned update selection and common-start evaluation already have close precedents. No new core is cleared. A narrowly specified later-task capability remains scientifically testable if its data/feedback contract, actual use threshold and strong ordinary baselines are qualified before numerical execution. The illustrative numbers in the advocate draft are not preregistration, sample-size qualification or a reason to reopen a stopped AZ configuration.
