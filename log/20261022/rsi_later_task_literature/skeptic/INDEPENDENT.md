## 逐篇反方核查

**Hyperagents。** 正文 `S5.SS2.p4.1–p5.1` 明说迁移整个实现，包括 task agent 与 meta agent；五个 transfer agents 的初始得分同为约 0，但参数、程序、解析与失败模式仍可不同。报道 transfer 固定 meta 的 imp@50 中位数 .630，并不单独隔离“meta 更新”而排除初始任务程序差异。`S5.SS1.p2.1` 初始程序在 paper review 因缺解析/后处理得 0；这说明格式修复可以是巨大且真实的程序收益，但不能自动等同于更强科研改进能力。`S5.SS1.p6.1` 对 DGM-custom 的优势不显著；`S5.SS3.p1.1` 200 步迁移 .640 对 .610 的差异也不显著，不能转述成已证递归加速。ProofAutoGrader 起点的改善是强产物证据，但缺少“同一 ProofAutoGrader + 原 meta”这一配对对照，仍不自动完成严格 improver swap。外层 parent selection 和评估固定（`S7.p2.1`）；可编辑不等于所有层都学习。

预算附录 `A4.SS2.p1.1` 报自修改约 33M tokens、评估 .506M×100，却给总量 88.6M；按列示数相加是 83.6M。可能存在未列费用或文字误差；本稿不自行修正作者真实 ledger。对本项目的启示是使用实际每次调用与评估总账，不能只拿迭代数或叙述总量称等预算。

**SpecRSI。** `A4.SS1.p1.1` 区分 reset、carry 与同 released-artifact fork；`A4.SS1.p3.1` 原/新 improver 的 gain 为 5.7/6.9pp，报告成本指标 54.2/50.8。这是值得正面承认的严格近邻，不能再把“保留模型不变，只换改进器再做后续任务”称首次。`A6.SS5...Px4.p1.1` 将独立完整搜索而非共享树叶作为 group；`...Px7.p2.3` 指出训练后 actor 改变 continuation law，旧 scorer 不是自动精确新 policy value，并明确有限 rounds 不推出无限加速。这些都直接约束本项目。

局限也须精确：`S4.SS4.p3.1`、Table2、FigureS7 明说部分 joint/shared-backbone 条件训练费用不等；不能把 joint 更高全部归给模块协同或更好策略。成本指数不是统一真实湿实验成本。该工作研究的是一般程序/验证搜索，不证明细胞世界模型或生物功能响应必要。它已有成本/资源分配先例，本项目若只是将 scorer 输入换成细胞残差，仍可能只是领域条件化的普通策略学习。

**Learned optimizer。** `S3.SS1...Px2.p1.1` 配对共享初始化、数据顺序、随机流、训练预算；四个小分类元训练任务、160 步轨迹，部署未见语言/视觉/图任务，实质说明“改进方法以学习参数继承”不需要源代码重写。`A1.SS3.SSS1.p1.1` 基线 Adam 固定 lr1e-3、SGD/SGDM 固定 .01，零 weight decay、无分域 sweep；这是作者声明的 off-the-shelf 问题，不能拿来声称击败充分调参最强优化器。

Table7 的全参数 learned 路由在 BERT 为3.889对 Adam3.815，GPT为4.299对4.268；主语言结果更强的是与 Adam 分区混合路由。故“全部参数普遍更优”不成立，也说明简单混合是必要对照。`S3.SS4...p1.1–p2.1` 报语言单步实际时间最高2.336×与显著历史状态内存；同更新步数不等同时间/内存预算。它证明一个固定元训练好的更新法可迁移，不证明元优化器自身跨轮变得更有效。

**Recursia。** `S1.p4.1`、`S2.SS3.p3.1`、`S2.SS4.p3.2` 已覆盖失败类型归因、共享工具/契约/交接/验证器修复、策略随迭代变化和 top1→topn beam；仅把这些词搬到细胞领域不新。`S3.SS4` 的案例区分操作完成与后继可执行条件：stove-on 从0/10→10/10但组合仍0/10，修复显著局部机制不等于真实终点收益。这对单细胞状态预测与功能终点之间的关系尤其重要。

作者自己在 `A3.SS3.p3.1` 区分 acceptance evidence 与独立 audit；`A3.SS4.p3.1` 说明 frozen execution 不证明目标未被开发观察，并披露 evaluation rows reuse/Scene5 历史暴露。`A4.SS2.p1.1` scaling 每点单次 evaluation run，不能称独立完整循环反复成功。`S5.p1.1` 源端 simulator ground truth 和可反复同态 reset 是实质优势，湿细胞通常做不到廉价克隆；本项目必须给现实可获得观测和成本，不能从冻结库读取未来功能真值却称可执行反馈。本文未隔离新/旧策略在同一共享栈上的后续效率，因此更新策略增益仍需额外测试。

**Épi。** `S3.SS2` 已含实验历史、死路、层级记忆、分支和独立模型评审；`S2.SS2.p2.1` 模型权重固定，通过程序、记忆、检索与反馈适应是其机制。若本项目只增加这些模块，创新主张不足。数学 construction/certificate 是强真实产物证据；没有必要因缺 improver swap 而否定这些产物。

Épi-turbo `S6.SS1...Px6.p1.1` 关闭 review/额外验证；`S6.SS2.p2.1` 30任务每系统一次、不报显著性；不能据此证明每个架构模块必要。Table3 的53.96对51.21总分优势主要来自速度项（`S6.SS3.p4.1`）；平均 quality1.030对1.032，119可比实例中更好目标值18对61、40 ties，不能转述成所有意义的解质量更强。持久科研过程确实可出更好算法，但这仍不同于“改进策略本身被学习得更强”。

**实证审计。** Table2 明确区分 C1产物、C2累积、C3整循环重复性、C4共同起点 improver gain、C5反复swap的compounding。90篇中60%报告 selection-independent evaluation、22% audited loop reruns；26篇better-improver中4篇同artifact+matchedbudget。该比例是冻结 search frame 下的报告编码，不是未报告即无能力，也不是复制失败率。`S5.SS3.p9.1`、`S6.SS2.p3.1` 明确严格规则把 Hyperagents 的task+meta共同迁移重新归为非同起点；这与我直接读原论文得出的混淆点一致，但不替代原文核查。Proposition3 的关键不是“更多run一定没用”，而是旧/新 improver 与 solver状态完全绑定时，对未观测的交叉组合没有识别信息。`S9` 承认 frame、筛选与部分编码可靠性限制，因此本项目不能把审计比例当作领域普遍定理。

## 普通方法已能给出哪些证据

| 观测/设计 | 足以由普通方法产生 | 尚不能因此推出 |
| --- | --- | --- |
| 多搜几次后 best score 上升 | best-of-N、固定程序搜索、噪声选择 | 更新规则被学会、更有效的后续改进 |
| 相同状态/预算下 context-conditioned arm选择胜随机 | contextual bandit、Bayesian optimization、learned scheduler | 新型 RSI、世界模型必要 |
| 共享初始模型上 learned optimizer 提高单位预算收益 | 普通 learning-to-learn、超参数/梯度更新元学习 | 改进策略的更新法也已跨轮进步，或新技术贡献 |
| 后续任务因保留样例、memory、技能/权重而变好 | replay、持续学习、检索、迁移学习、程序库 | 科研程序/模型更新法已改进；也可能只是更强起点 |
| 同artifact原/新improver，等预算，审计后继 | 真正的 improver gain；普通元学习也完全能做到 | 新机制首创、无限自加速、世界模型贡献 |
| 功能失败引起共享可执行程序修复并冻结继承 | Recursia 类程序修复/共享技能，领域外已示范 | 细胞 latent dynamics 必要、因果可识别或湿实验有效 |

“代码自改”既不是必要条件，也不是充分条件。一个小网络、统计量或固定表内 learned routing 可以是 improver；如果恰好化简为 ordinary bandit/posterior count，应按其本名比较，不因 agent 封装而升级新颖性。保留一个更好产物与学到更好改进程序是两个不同对象；同时可以有真实收益，必须分开测。

## 最小仍可证伪的问题，而非现成创新声明

我支持的最小研究问题 H 是：**真实可得的干预功能反馈，能否让系统学到“什么状态/失败下应采用什么模型或表示更新”，并使该更新规则在后续未见任务上，从同一初始模型出发，以同样实验和计算预算得到更高功能收益？**

H 的普通解释非常强：它可能只是 contextual bandit over update programs、普通元学习或更好数据摘要。不能把H成立直接叫新核心。更有技术辨识度的候选只有在补足生物结构后才值得深入，例如：相似表达状态在干预后具有不同功能响应，功能反馈触发可预测、可迁移的干预状态划分修订；该修订改变后续可执行实验/更新程序，并在未见干预序列上改善模型更新效率。这里“状态划分修订”仍可能化简成普通 mixture-of-experts/representation learning；必须让同信息、同参数/搜索预算的基线实际竞争，且需要可获得的纵向/序列干预功能数据。当前尚未指定满足合同的数据，不应伪装成已可执行方法。

世界模型必要性的最短证伪链是：去掉 action-conditioned state/transition prediction、改为同信息强直接预测器后，程序选择和后续收益是否仍相同；将功能反馈打乱到不匹配的cell/intervention但保留边际分布后，是否仍得到相同收益。若是，世界模型语义或功能归因没有得到支持。不能因维度缩减、名字或把状态接口叫world而认定贡献。静态剂量表面的普通机会门即使通过，也不自动提供这些纵向机制证据。

## 后续实验必须最少分开的比较

1. **世界模型收益**：同观察/训练/参数与搜索预算下，action-conditioned模型对强直接预测、普通重训练、replay/持续学习；用未来功能响应、序列/域外干预及终点决策评分，不能仅看表达重建。
2. **智能体收益**：模型和初始数据固定，学得的实验/程序选择对固定研究流程、随机分配、主动学习/BO、同预算有限程序搜索。搜索失败、验证、API、测量、超参数和策略训练成本都入账；同迭代数不够。
3. **继承收益**：同后续任务/初始模型分开继承原始历史、提炼memory、模型/技能、更新器。全部给基线同样可用的源信息；另外报告包含源阶段费用的总成本和摊销条件，不能免费把已有搜索结果送给新方法。
4. **联合收益**：做 world×learned-research-policy 的配对factorial；联合产品增益与交互项分开。大于两个单独增益之和的“协同”需要实际交互估计和不确定性，不能靠各自显著拼出。
5. **RSI 的后续效率**：在每个预定checkpoint，将同一个未见任务的同一模型/代码/允许历史/预算复制为共同起点，分别运行初始和当前 improver，审计后继。重复独立完整改进循环；若还声称策略收益继续加速，须反复swap并预定要增长的是单位成本gain、成功概率或time-to-threshold，不能只画bestscore曲线。相同初分、较强carry模型、同一树的多个叶、单个最终agent的多seed，都不能替代该对照。

这些是要辨别的效应，不是要求现在一次堆五层模块。先找一个数据合同合格的功能任务，把最小可学习更新规则与普通解释比较；若不赢，停止该候选，不添加抽象名词救结果。

## 成功与停止的预定边界

只有在任务/真实可得反馈确定、实用阈值按该source预定、普通方法充分调参且包括等预算搜索后，才能锁定具体数值成功门。不得把其它assay的.02阈值直接继承到新功能任务。H失败（未来任务共同起点无单位预算收益）、world消融无损、功能反馈置换不损或同信息bandit/简单混合复现全部优势，都关闭相应新机制主张；可以保留普通工程收益。数据若只有静态释放表、无法合法提供序列或实验反馈，就停止动力学/真实研究闭环的该解释，而非用oracle字段补未来信息。

即使H成功，六篇先例仍使新颖性 NOT_ESTABLISHED。需写清最小差异与模块必要性，再由不同立场实际交叉审查；本独立稿不宣布世界模型、智能体、继承、联合或RSI任何一项已成立，也不把有限文献审查当成全领域新颖性证明。
