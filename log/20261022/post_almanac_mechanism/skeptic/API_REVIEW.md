# Independent API CCI review

2026-10-22. Read api/RESPONSE.md before reading biology/root API-specific opinions. This is a static mathematical/methodological review, no numeric experiment or reserve access. Existing independent original remains sealed. Verdict: NO_PROMOTION of this literal specification; do not revive ALMANAC anchor/residual novelty route through a2x2name. Not a general prohibition on standard mathematical primitives: a genuinely different composition could be innovative, but this proposal has not specified one.

## Strongest version and faithful counterpart

The useful primitive is a factorial interaction contrast b=y11−y10−y01+y00 under one legal common context, actual matched interventions and compatible measurement scale. It cancels arbitrary additive main effects. This is not an order-exchange/noncommuting intervention contrast unless an explicit temporal protocol says so; two-drug endpoint factorials alone do not supply sequence dynamics. Dose rectangles are legitimate but their interaction depends on dose coordinates and response scale. A general cell world model is not required merely to predict this scalar.

The proposal's strongest ordinary counterpart is not just a soft auxiliary-loss neural network or RBF with extra features. It is the EXACT SAME low-dimensional rule family, same prior r0, same observed factorial contrasts, same epsilon and metric, constrained least-squares or standard projection onto their intersection, followed by the SAME cost-sensitive coverage/contextual-bandit acquisition and rollback. Give it identical source traces and stored constraints. This uses standard operations but precisely matches the proposed executable mechanism; no information or optimization advantage has been specified between them. If nonlinear, use the same nonlinear constraint solver and count search/verification costs; do not award candidate a better solver for free.

For a linear contrast prediction a^T r+d, projection onto one slab is explicitly r'=r0−a*(v−clip(v,−epsilon,+epsilon))/||a||², v=a^Tr0+d−b, when a is nonzero. Multiple slabs give an ordinary convex quadratic program when the rule is linear. A hard feasible constraint need not match a finite fixed penalty loss, so I do NOT claim equivalence to every ordinary MSE auxiliary-loss baseline. The precise faithful constrained counterpart is enough to defeat the proposal's stated distinction. For nonlinear rules low dimension does not itself guarantee cheap/global feasible projection.

## Certificates and missing observations

The written C_t definition is ambiguous: if it contains only currently satisfied |b−bhat_r|≤epsilon entries, excluding violations would produce a selectively self-confirming certificate rather than fixing conflicts. Read charitably as all legally observed constraints with their tolerated discrepancies; then ordinary version-space projection already implements it. The r versus r0 time indexing also needs precision: projecting to an original rule each iteration and projecting from the last rule are different procedures. No currently defined choice yields a unique innovation.

All four outcomes are needed for an identified empirical interaction contrast unless additional measured/structural assumptions substitute missing cells. At least one intervention difference is not enough; missing factorial cells cannot be replaced by the world model and then called an external certificate. Four outcomes make one contrast, but do not make it one assay cost; charge the union of drug/control/replicate bundles. Difference variance involves all four variances and covariances. A numerical epsilon fit to noisy observed labels is not a statistical guarantee of biological rule validity or future utility. Relaxing epsilon on infeasibility must be predeclared or independently calibrated, otherwise it can preserve any rule by weakening its own certificate.

The retrospective ALMANAC high-high feedback contract and its passed pilot cannot be silently replaced by a fully observed factorial certificate and different heldout drugpairs. Existing STOP and reserves remain. API's Jurkat/ALMANAC availability statements are explicitly uncertain; they are not metadata qualification. No new source hunt or outcome read is justified while the operation itself is unchanged from the faithful ordinary method.

## Inheritance and RSI are different objects

Transferring a feasible rule or constraint set may be knowledge/procedure inheritance. A coverage table can be a useful active-learning memory. Neither alone demonstrates improved improvement strategy. In particular 'round2 reaches the same violation rate with fewer feedbacks because tableM contains prior covered patterns' can result from having already acquired more relevant observations or from an easier remaining curriculum. Starting from a better feasible rule also trivially reduces work; that is not an improved improver from a common downstream start.

A fair Level3test freezes old/new search/update policies and compares them on independent later contexts from the SAME initial downstream rule and initial target observations, with the same allowed source history for ordinary learned policies. If M is claimed to encode a learned strategy, test a changed conditional rule for choosing/validating updates beyond a fixed coverage policy receiving the same table/history. Compare standard contextual bandit/information-gain acquisition with that same knowledge, not a memoryless uniform picker. Charge source learning and later feedback. Saving a pattern bit is not denied useful transfer, but currently it is evidence reuse, not a distinct improved mechanism for producing new improvements.

A decline in certificate violations can coexist with worse drug ranking or heldout MSE. A correlation test between violation and MSE benefit is neither necessary nor sufficient for useful operation: constraints could act by another relation, and selecting already-satisfied/noisy-easy constraints can correlate spuriously. A predeclared functional utility gain against the exact constrained counterpart and common-start policy-efficiency comparison are the material falsifiers; zero-feedback invariance is only a sanity test.

## Decision

STOP literalCCI novel-core/RSI promotion. The factorial contrast can be scientifically useful, and hard constraints differ from a fixed soft penalty, but the proposed minimal projection plus coverage bandit is already exactly available to an equally informed ordinary constrained estimator and active learner. No unique rule-transfer assumption or new feasible-budget operation was given. No new mathematical primitive is required in principle; a distinctive, testable constraint-selection/transfer principle could change this judgment, but it must be specified independently rather than added after seeing an unfavorable comparison. Preserve the API response and this negative review; no datasetfit or new corrector follows.
