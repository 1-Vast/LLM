**机制：2×2干预交换证书的规则继承（CCI）**  
只继承“可证书化”的低维更新规则，不继承模型参数/提示词。

**输入/反馈合同**：每个反馈记为 \( (s,g,h;y(s),y(sg),y(sh),y(sgh)) \) 或可识别子集；\(s\)为细胞/背景，\(g,h\)为剂量/药物干预。允许缺格，但必须保留同一\(s\)下至少一个干预差分；不同study/剂量映射不得混格。反馈只来自目标任务，源任务知识对baseline同样开放。

**更新/伪代码**  
1. 当前WM与规则\(r\)预测四格，构造经验/预测交互项  
\(b=y(sgh)-y(sg)-y(sh)+y(s)\)，\(\hat b_r\)同理。  
2. 约束集 \(C_t=\{|b-\hat b_r|\le\epsilon\}\)。  
3. 规则更新为最小改动投影：  
\(r'=\arg\min\|r-r_0\|^2\ \text{s.t.}\ |\hat b_r(c)-b(c)|\le\epsilon,\ c\in C_t\)。  
4. 若不可行：不继承或放宽\(\epsilon\)，记录失败证书。  
5. 维护模式覆盖表\(M\)（剂量加性、药对交互、细胞条件），新任务用bandit只选“未覆盖/高冲突”模式的反馈格，以最小期望违规降低/成本搜索规则。

**不同点**：普通做法把反馈当标签最小化MSE或加交互辅助loss；CCI把反馈变成**组合差分约束**，只审核/投影规则，并继承“通过证书的模式”。规则搜索由约束覆盖驱动，非梯度重训/archive prompt。

**有限数据/计算优势**：差分消主效应，四格共用一约束；投影低维规则，避免全模型重训；选点针对未覆盖约束。可能改善小反馈下的规则迁移，但不保证最终药对排序。

**最强faithful conventional counterpart**：同预训练WM、同反馈预算的多任务元学习（共享低秩适配）＋同交互残差辅助损失＋同样主动选点/验证；或直接RBF加交互项特征。必须同源知识。

**真实数据可获得性**：ALMANAC是否在887药对/10新细胞中保留同细胞、同药、单药与组合的同剂量2×2格，未知；Jurkat 48开发药反馈能否形成同背景剂量阶梯，未知。需查数据字典确认，不能假定。

**最小可执行证伪**：在可构造的ALMANAC 2×2子集上，留出药对/细胞，用目标反馈预算比较CCI与上述强counterpart。若CCI的证书违规率与held-out MSE收益无正相关（Spearman≤0），或同预算下不优于强counterpart，则否。数学边界：若只有边际反馈、无同\(s\)组合格，交互项不可识别，CCI退化为普通差分，无优势——此时应明确NO_CANDIDATE并先补组合格。

**边界**：WM只验证交互项/组合差分；agent只验证选格与拒绝继承日志；inheritance验证跨任务证书违规率与零反馈不更新；improved-improver验证第二轮达到同违规率所需反馈数下降，且改进来自覆盖表而非调参。不得用未给baseline的源反馈制造优势。
