## Marked turnover: defend the information result, stop the algorithm claim

The exact identity J = delta N_H - B_H + D_H is supported by integer event bookkeeping. The supplied pairs keep start/end populations and aggregate turnover fixed while changing J. Hidden reciprocal cycles also give the same J with different gross crossing. Thus J identifies net crossing, not a transition history, total switching, same-cell reversion, or a unique molecular adaptation mechanism.

The revision to account for residence times addresses a real counterexample: fixed shared rates already give currents (2,-2,0), so opposite pulse/washout signs alone cannot identify drug-dependent adaptation. The fixed-design witness W = 2J1 + 2J2 - 3J3 rejects the constructed varying-rate expected-flow vector, giving -2. This is a valid algebraic compatibility check under its declared deterministic expected-flow assumptions.

Its decisive competitor is already present. W is exactly -3 times the residual from fitting two ordinary rates to the first two equations and checking the third. Current recovery is conservation with constant arithmetic cost. Two-bin minimum gross flow is |J|. The recorded 729 residual comparisons corroborate this identity; the algebra itself establishes why equality is structural, rather than a weak-baseline or low-power accident. The full feasible null is a nonnegative-rate cone, not just W=0: the negative-rate example passes W while requiring (-1/5,-1/5). A practical conventional feasibility test must include rate nonnegativity and measurement uncertainty.

Remaining biological/statistical gaps are substantive. Marked deaths require live pre-event state; division contributions need a consistent mother/daughter convention; immigration, loss from view, and state classification must be bounded. Occupancy is endogenous. Weights obtained from the same future noisy occupancy cannot be granted an iid conditional test by inspection. Marker drift, hidden state, and memory can reject the two-state null without establishing the desired biological explanation. The code checks constructed occupancies algebraically; it does not validate a realizable assay or calibrated stochastic coverage. No source meeting these requirements is authenticated here.

Cost cannot be inferred from the number of summary statistics. Measuring event state and integrated occupancy may require much of the imaging/tracking effort that the summary avoids storing. Comparing cheap arithmetic to an expensive bridge solver would therefore miss both the optimized computational baseline and the physical acquisition cost. The transfer from observer-aware killed-particle models is conceptually relevant, but neither that inspiration nor Branching Flows' split/delete operators supplies a non-equivalent algorithm. No claim of literature-wide absence is justified by these inputs.

## Continuation: a real delayed-credit witness with a sufficient simpler program

The code genuinely computes source empirical immediate and suffix values and freezes a checkpoint before later evaluation. It selects the initially neutral edit when a calibrated second edit completes it. That is a legitimate operational witness of delayed credit. The mean myopic error 9/128 versus zero continuation error is appropriately diagnostic.

It cannot support the proposed central contribution. Contextual complete sequences, the beta success portfolio and exhaustive finite-horizon rollout match it. The unconditional source-best complete program (1,1) also solves all later tasks; the postrun audit confirms it is source-best even though it is a literal in the frozen implementation. The fixed ratio extrapolator solves the same family with four direct later fits and no need for learning an improvement policy. In this fully observed two-step deterministic menu, maximization over first and second edits is equivalent to maximizing over complete sequences. More elaborate policy machinery is unnecessary.

The four later tasks change amplitude while preserving both underlying laws. Because the error is normalized by amplitude and context rho<1 is recoverable from y1/y0, this is particularly limited transfer: amplitude novelty does not challenge the improvement rule. Supplying rho through the executor is not extra hidden information in this toy, but the interface is not an independently tested data-access boundary. No fresh biological decision, noisy assay, sparse trace coverage, or cost-constrained adaptive experiment is demonstrated.

The cost addendum is necessary and credible: 12 unique source readouts differ from 48 source feedback-score arithmetic evaluations and 16 duplicate final-loss calculations; six search arms incur 48 later edit/score computations in total. All are logical synthetic observations, not independent assays. Equal resource caps allow direct or source-best controls to spend less. Source costs cannot disappear through unquantified amortization, and no runtime advantage was measured.

Ordinary empirical RL fills a gap relative to the proposal's account of AGAR's textual continuation estimates, but that does not establish a new RL mechanism. An altered proposal law alone also falls short of the user's Level-3 requirement: it must improve subsequent improvement efficiency over fixed search and equal-budget ordinary metaoptimization. This result instead shows those controls already suffice.

The methods authenticate continuous exposure versus a fixed interruption/rechallenge schedule. GEO authenticates two FM07 endpoint libraries. FM06 has untreated samples but is not authenticated as a pre-decision FM07 sibling. FM07 lanes are sequencing subdivisions. The inspected processed-gDNA inventory contains FM02/FM03 branches and no FM07 branch; this is absence from this inventory, not proof no other FM07 record exists. A general spike-in calibration procedure cannot calibrate the FM07 endpoint state libraries by association with the paper. Nor can a late state measurement become day-9 information. Thousands of clone rows do not create thousands of independent pool-level schedule choices.

The positive scope is meaningful: FM02 has several real initial action arms and candidate gDNA-to-state mapping files. Shared barcodes can support prediction of captured sibling fate or calibrated net outgrowth across those initial treatments. Unique selection-versus-adaptation identification is not necessary for an honest prediction comparison. However, retained barcode/state data are capture-conditional; name-level mappings are not yet a validated numerical join; held-out clones only assess within-family generalization. Any apparent gain would still need direct action/history predictors, clone and abundance controls, and ordinary transition/net-growth models with the same observations. Current records prove none of their performances.
