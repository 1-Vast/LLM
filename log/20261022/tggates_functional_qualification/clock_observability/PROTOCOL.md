# 开值前代数资格：clock observability

2026-10-22。本协议先于脚本执行登记；不使用任何 TG-GATEs DNA/LDH/CEL 响应，不训练或选择模型。目的仅为检查支持方 `T'(t)=T(exp(eta)t)` 的一般可识别性主张，不能据此否定固定参数模型在真实heldout任务中的预测价值。

预定检查：

1. 线性轨迹 `z(t)=z0+v*t`：时间放缩与相对于z0的幅度放缩完全等价。
2. 幂律轨迹 `y(t)=b+a*t^p`：时间放缩等于幅度放缩 `a'=a*exp(p*eta)`。计算clock/amplitude切向量的矩阵秩；双输出不同p在单一共同amplitude下可分，若给各输出amplitude则clock又在其span内。不要把其中一种限制当普遍等价。
3. 固定2/8/24h切面不足确定时间导数：给平滑曲线加在三个切面为零的多项式，检查观测值相同但导数不同。
4. 更强反例：基线 `fA(t)=t/24`；`fB(t)=fA(t)+0.02*q(t)/q(12)`，`q(t)=(t-2)(t-8)(t-24)(t-4)`。两曲线在2/8/24h完全相同；预定warp=1/2，8h paid support对应4h，两曲线亦相同；24h withheld forecast对应12h则差0.02。用导数的精确临界点检查两曲线在[2,24]都单调，避免仅由剧烈非物理振荡构造反例。支持值、warp和曲线在执行前固定，不搜索有利例子。

预定结果身份：达到解析预期说明未经参数族限制的“由三切面/单支持识别应修clock而非amplitude/head”不成立。任何数值不符合解析预期先判实现错误，不修改预期追结果。全部算术是构造例子，无药物性能/生物复现/世界模型/Agent/RSI成功证据。

最小测试只覆盖独立数学不变量：任意eta的解析等价、秩嵌套关系、切面相同与导数不同、同paid support/不同withheld预测、全区间单调性。输出含源代码/协议hash、明确计数和观测值，拒绝覆盖。代码和测试仅 `research/tggates_clock_observability_20261022/`；日志和pytest cache仅本目录。
