## Application and falsifiable claim

Application: early fixed-dose drug-response triage in deposited STACK screens. Predict exported live-reporter density at72 nominal acquisition hours from observations at0,4,8,12,16,20,24h. Three contexts: T98G+DMSO, T98G+400micromolarTMZ, U2OS, each library compound5micromolar. U2OS2h frames are downsampled to the same seven4h prefix times; no finer unused frames enter features. The reporter is literally NLS in the T98G+DMSO file and mKate2+ in the others, with the previously documented source-supported mapping. SG+ is dead-object density, not cumulative death events. Units objects/mm². Main target y=log2(L72+1); all supervised models predict y−log2(L24+1) and restore that actual anchor.

Main claim: a complete early SG history improves future live-reporter forecasting beyond identical live history/time/background under matched strong-direct model selection. It is an empirical information claim, not a new algorithm or identification of death/turnover. A dynamic-history claim additionally must beat D0-only, D24-only and joint D0+D24 arms. No future D, LF/AUC, QC membership, LED fit or result-ranked side table is opened in this gate. No controls inferred from87#N/A identities or library plate assignment. The pooled three-screen result is within these deposited screens, not independent-run or new-cell-line generalization.

## Exact feature coordinates and matched direct budget

Let s_i=log2(L_i+1), z_i=log2(D_i+1), i at0:4:24. Every arm gets exactly: all seven absolute s_i; the first six s_i−s_24 (omit redundant last zero); OLS s slopes on0:12,12:24,0:24; three screen one-hots in fixed source-file order. No names, group hash, row coordinate, library structure/target/plate or future controls are model inputs. Equal per-screen data count need not be assumed after missingness: sample weights normalized so each screen has equal total fit weight. StandardScaler is train-only (no weighting required for its feature moments); selected refit uses train+validation only.

Five arms: live_only adds nothing; dead_initial adds only z0; dead_snapshot adds only z24; dead_endpoints adds z0,z24 jointly; dead_history adds all seven z_i. No D/L ratios or D slopes. Full history explicitly contains all snapshot/endpoint information. Feature dimensions19,20,20,21,26 respectively. Test feature construction cannot depend on target values or eligibility-by-target. This deliberately simple coordinate choice varies only dead-channel coordinates, avoiding extra nonlinear live transformations introduced by D/L ratios. It still measures finite-forecaster predictive value, not a proof of conditional mutual information or causal D→L effect.

Each arm has the same14configs: Ridge alpha .01,.1,1,10,100,1000 with StandardScaler; HistGradientBoosting max_iter300,learning_rate.05,max_leaf_nodes7/15,l2_regularization0/10,min_samples_leaf10; ExtraTrees300trees,max_depth8/None,min_samples_leaf2/5,n_jobs1. random_state20261022 everywhere applicable. Same labels, fit weights and validation metric. For each arm fit14ontrain; choose lowest validation macro MAE, tie lexicographic config name, then refit exactly that config on train+validation. No adaptive features/model configs. Record all trial validation scores, fit/predict runtime and exact selected config. Fourteen trials plus one refit each,70trial+5refit total. Equal trials/trees are not equal wallclock; report actual runtime, do not claim identical FLOPs.

Two fixed live-only anchors, no validation selection: persistence L72forecast=L24 in log space and OLS log-growth anchored atL24 using all seven s_i. These are diagnostic baselines and cannot replace any failed primary comparison. This gate intentionally precedes expensive latent-model fitting; ordinary world/refit/mix/search/agent/CL/AL/inheritance/RSI contributions are NOT_TESTED here.

## Scoring, usefulness and stopping

Primary metric: screen-macro MAE, averaging absolute log2 errors within each screen then equally across the three. Report each screen's MAE and every test key/prediction/target. Primary gain=live_onlyMAE−dead_historyMAE. Useful information requires gain>=.05log2 units AND>=10% oflive_onlyMAE AND positive gain separately in all three screens. .05is a pragmatic~3.5% factor in(density+1), not a measured noise floor or clinical effect. A dynamic-history claim also requires >=.05 AND>=10% against EACH of dead_initial, dead_snapshot and dead_endpoints plus positive per-screen gains against all three. Do not select the best D arm on test or change thresholds. Beating the two single snapshots alone does not establish value in the intermediate samples; the joint-endpoint control addresses that simpler explanation under the registered predictors.

Report paired group-bootstrap sensitivity10,000draws,seed20261022, resampling role groups with all their entries/screens together and recomputing the screen-macro difference; percentile95%interval. This describes finite recorded-entry sampling within these screens, not biological-run uncertainty. Threshold decision uses the preregistered point/per-screen criteria; intervals are supporting qualification and cannot be called independent replicated significance.

If domain/coverage fails, classify qualification failure, not channel negative. If primary useful information fails on a qualified panel, stop expanding this exact fixed-dose24→72h application into an agent/RSI framework under these registered predictors. Do not prove universal absence of D information. If primary passes but history vs snapshots fails, retain static/additional-channel value only. If dynamic history passes, qualify the effect as within-source exploratory evidence needing world-model baselines, observation calibration and other legitimate tasks before promotion. There is no algorithmic novelty claim from these standard models. Preserve all failures/contradictions; one measured run. Only explicit implementation failure permits a documented correction, never model/endpoint tuning after numerical exposure.

Before measured run, tests must cover exact-cell whitelist future/QC isolation (including malformed closed values), group/test-label authorization, conflicting metadata grouping, equal feature availability and test-target independence, feature dimensions, sample-weight/macro arithmetic and model-budget equality. Independent reviewers must assess whether the operational question is meaningful, comparisons fair and stop boundaries scientifically scoped. No new primary retrieval or provider call is required to execute this bounded gate; latest closest-method evidence remains in preceding logged reviews.
