2026-10-22。仅阅读本阶段 `PROTOCOL.md`；未读 peer 新稿、raw/XLSX/response、assay 数值，未联网或拟合。此稿先于交叉质询。

## 独立裁决

**对该狭窄、普通模型的条件预测信息门检验给予 CONDITIONAL_GO；没有发现需要改变科学终点、预算或阈值的实质阻塞。** 条件是数值前冻结准确实现、源和角色映射，完成协议要求的权限/特征/权重/预算测试，并将下面的解释边界保留在结果中。本门检验只决定是否值得把早期 SG 通道进一步带入后续研究，不能直接产生新世界模型、智能体、继承或 RSI 贡献。

## 应用价值与可证伪性

具体问题是：对这三个已存固定剂量筛选背景中未见过的记录条目，由 0–24h 的导出活标记密度预测名义采集时间 72h 的同类密度。该问题可作为早期固定剂量反应筛查的必要预测子问题，潜在价值在于判断额外死亡通道是否值得用于长时响应预测。它不直接证明药物效力排序、选择性、安全性、患者疗效或真实 viability；也尚未证明前瞻省时、省成像或决策收益。相同 5µM 不是剂量反应，三个背景也不是独立重复实验。

主要主张有明确失败条件：full D history 必须在合格的共同面板上相对 L-only 强直接模型同时达到绝对 .05 log2、相对 10% 和三个 screen 均正的增益。若失败，停止在此精确应用/预测器配置上扩展到大框架，不能改为挑某个 D arm、单背景或另一个 endpoint 来称成功。该门槛可证伪且保守，.05 的意义已准确限定为实用阈值，并非实验噪声下限或临床效应。

即便通过，“条件信息”仍应读作**在预定特征、模型族与选择预算下可获得的额外预测价值**；不是估计了条件互信息，不是任意最优预测器的信息定理。增加维度及参数化会改变有限样本归纳偏置。应报告每个 arm 的配置与验证分数，而非据测试表现讲模型机制。

## 为什么两种快照比较必要

L-only 获得全部七个绝对 L 值、相对坐标、斜率和 screen 信息；没有通过特征缺省人为削弱它。D0 能揭示基线库存/采集校准，D24 能揭示与预测锚点同时刻的累计库存或状态。因此 full D 仅胜 L-only 时，不能说 0–24h 动态历史必要；它可能只是在补一个静态代理。

full D 明确包含 D0 与 D24 的信息，且只有同时胜两种单快照的相同实用门槛、每 screen 正增益时才保留 history claim，这是必要且较强的设计。即便全部通过，也只说明早期多个 SG 观测对该导出 L 目标的联合预测价值，不证明死亡事件、clearance 或 turnover 机制，也不证明全七点各自必要。没有必要在此先增加 latent 模块。

## 强直接比较与预算公平性

三种标准强模型族、固定 14 configurations、同一标签/训练行/验证指标、各 arm 一次选择与 refit，足以作为一个有竞争力的固定直接预测基准；不能称为对所有可能强直接模型的最优性证明。live-only 的两种固定锚点可帮助诊断任务难度，但不能替代主比较。

共同 L 特征的维度为 7+6+3+3=19；D0/D24 各 21，full D 为 34，数值自洽。共同 prefix eligibility 避免各臂在不同井上打分，screen 归一 fit weight 与 screen-macro metric 方向一致。需在实现中确认：每次 train fit 及 train+validation refit 都由各自拟合集重新计算 screen 权重；验证与测试评分使用共同目标有效行；所有 arm 的 paired comparisons 使用完全相同 test keys。StandardScaler 只用合法拟合集，不能让 validation/test 参与。

14 trials+1 refit/arm 是相同选择机会，不是同等计算量；不同维度及 selected family 影响运行成本，协议已要求报告 runtime。该不等价不构成此信息问题的实质障碍，但不得把本试验称为等 FLOPs 的程序搜索或 RSI 基线实验。

## complete-case 的实质限制

这次将完整观测条件写在任何 assay 数值前，并保留固定命名条目面板，不是在目标问题后换规则救 HCT116。>=95% 的每 role×screen coverage 和跨三背景组数阈值，使失败资产有明确资格出口。它允许小量源报告缺失，但禁止插补、裁剪和后验选强反应。

然而 valid target 是未来结果相关的条件：若负值/缺失集中在极强反应区域，合格完整面板仍可能不代表无条件应用，即使总体覆盖超过 95%。阈值限制规模，不能消除这种选择偏差。需把 prefix coverage、额外 target failure、共同 complete coverage 分开列出，至少按既定 role×screen 报告，不能仅报最终总 coverage；不得因 test target 无效将预先保存的 forecast/abstention 删除或改写。此协议已要求这些基本产物，无需另加模型或后验筛选。

若 coverage 不通过，仅作 DATA_QUALIFICATION_INSUFFICIENT，不得把拟合成功或某些可算分数升级成 useful-gain 结论。这个条件分析不证明全部 1,833 条目有实际可用预测服务，更不证明未识别 87 行或完整生物体的功能。

## 身份、测试与外推边界

按记录 library-entry 跨 screen 共角色，且将已知 exact-SMILES 冲突对保守同组，是合理的最低防泄漏。它不认证化学别名，也不解决未知其他同化合物条目，因此未见 recorded entries 的说法准确，不能换称新化学结构/靶点或新 scaffold。三个 screen 与同条目一同 bootstrap，能够描述记录条目抽样敏感性，不能创造 biological-run 重复。点阈值与 bootstrap 支持性区间已分开，避免用后验置信区间调规则。

测试权限顺序合理：prefix 全部合法后仅开启 train/validation L72；所有 test predictions/abstentions 保存后才开 test L72。XML 已在盘这一事实与“未授权字段不参与解析”不矛盾，但不能称密码学封存。最关键测试是目标授权、闭合字段中的恶意/畸形值不影响合法读取、test target 与特征/预测无关、同组不跨角色、共同面板、weight/macro 算术及 56+4 fit 预算。若代码与文字冲突，应数值前纠正并附原因，不能执行后重解释。

世界模型相对 direct、普通重训/持续学习/主动学习、简单混合、等预算程序搜索、智能体、继承、联合收益及 improvement-of-improver 均为 NOT_TESTED。此门若通过，只支持下一步另立世界模型/机制问题；若失败，只停止精确配置，不宣布普遍无 D 信息。普通多通道模型获得增益本身没有算法新颖性。保持这一级别，才是该前置实验的价值。

## 独立自查补记：双端联合仍未比较

此补记在收到反方实答前已向 root 与反方发送。full D 同时胜 D0-only、D24-only，仍可能仅需 D0+D24 联合，而非五个中间时点有用。因此前文“较强设计”只指排除任意单快照足够，不足以推出完整轨迹或中间点必要。主比较没有因此失效。最小改动是将 history claim 明确收窄为“超越任一单快照的多时点 SG 预测价值”；无需为该狭窄门检验强加第五 arm。只有若未来要检验中间轨迹必要性，才应在接触该任务响应前另立联合端点比较。已向 root 说明，不据后验结果新增它。
