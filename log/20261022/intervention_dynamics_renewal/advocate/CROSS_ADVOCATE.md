## 反方对我的实际挑战与回应

**1. reset 是否辨识了动力学？**

反方：crossed prepared histories 的随机化只辨识指定实验条件的 endpoint effects。r/e 有 gauge，不能唯一识别 tumor transition 或 NK competence dynamics。具体反例：固定终点 T，Model A 的 h_ij(t)=r_i e_j/T；Model B 前 T/2 为 2r_i e_j/T，后半为 0。四格积分完全相同，但中途撤药、reset 或新时长预测不同。更一般，加入积分为零、足够小的交互时间项也可隐藏瞬时 interaction。

回应：接受。该分析反例不取任何真实响应；已写入倡议稿。分离即使通过也只支持固定条件下的 endpoint response constraint，不能上提动态世界模型、内在 epigenetic memory 或 transition operator 继承。

**2. 三格预测第四格的 kill test 是否有效？**

反方：这是有效的过识别约束，但一个 2×2 成功不证明迁移。±0.05 等价性判断须传播前三格、共同 control、H00 分母和 held-out 生物噪声；不能只估第四格 SE。V>1／接近1不能看完结果再排除；growth control 不会自动把读数变为死亡 hazard。

回应：接受。把预测区间、锁定定量域和失败处理写明。±0.05 是未来可预登记的实用候选界限，正式做前需独立 assay calibration；本轮未执行或根据响应调参。

**3. 是否因已有组件而过早否决？**

反方：同 rank-one predictor、相同 posterior/acquisition/update 的逐项归约成立，算法 NONE 不过早；不否定该生物组合可能有经验价值。

回应：同意。归约范围是本稿给出的完整 operation，不是所有 controlled dynamics 或 future combinations。实测 separability、新 history 的可靠预测以及实验节省仍可成为具体经验贡献；当前均未成立，也未查明 first-of-kind。

**4. 当前是否值得启动进一步实验？**

反方：原文没有 aged-NK factorial，不能声称当前有离线 kill data。先资格已有公开 crossed-history functional asset；若未来本来有可做的独立实验条件，2×2 + independent batch 才有可证伪价值，不需 LLM/RSI。

回应：接受。当前不启动训练、架构、wetlab或性能实验，只保留资产资格入口。没有真实交叉数据则暂停本线。

## 我对反方 AP-1 问题的实际挑战与回应

**1. unpaired state/function 能否支持更新？**

我问：若 Fig3/5 状态和 Fig2 colony function 没有同 run 联结，是否存在相同 aggregate 但相反条件功能预测？

反方答：存在。X、Y 均为各半的 0/1，M+ 令 Y=X，M− 令 Y=1−X；所有边际相同而条件预测相反。一般同边际的 copula 也一样。当前只能 manifest qualification／mechanism stress suite，不能硬 join 训练 U。

我接受。此为定义级解析 witness，不是来源数据或估计结果；不否认有资格的实际 sample linkage 日后可能解除该歧义。

**2. 药理时间分支是否唯一指定 write/maintain 边？**

我问：JNK／CBP-p300 多效性、state-specific toxicity、短暂响应与 survivor selection 是否已由同 run 控制排除？

反方答：已有 naive JNK growth、T5224、两个 p300 domain 抑制剂等 orthogonal 支持，但不足唯一排除这些解释；尚无已认证同 run 控制可唯一指定边。

我接受。不能把作者已发表的 phase-specific findings 自动变成新模型可识别的独立 latent edge。

**3. 更新 latent initial state、θ 与 ψ 能否区分？**

我问：盲测功能改善如何区别三者，避免把参数修正上提为 improver？

反方答：当前 source 不能仅凭 blind function 唯一区分初态与 θ，它们有状态参数化等价；必须固定 model state／likelihood／初始观测，再比较 state-only 与 θ-update 在多个 held-out starting states/schedules 的预测。这只是相对预测证据。ψ 则必须有明确编辑，冻结 I0/I1 后在独立后续更新机会中给相同数据成本比较。AP-1 尚未认证足够任务。

我接受。AP-1 memory 不等于跨任务 improver memory；U 问题还不是新算法。

**4. n=1 erase 的合理用途？**

我问：是否可作为单 task 的候选反例，但不能合并其他图 n7/n6 补继承统计？

反方答：是；可作为已发表的单 task counterexample（withdrawal 不等于 restoration，erase-washout 不等于简单可逆），不能借其他图补继承统计，也不能单凭它唯一指定生物机制。

我接受。反方已承诺在其记录中明确此边界。
