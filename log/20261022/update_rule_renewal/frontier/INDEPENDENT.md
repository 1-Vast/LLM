## Fresh primary operation, not a paper-name analogy

**DeltaTTT: Layerwise Optimization for Nonlinear Recurrent Memory**, Li, Han, Fu and Huang, arXiv2610.08553v1, 2026-10-06. The source reports that serial nonlinear TTT can lose to a fixed-base parallel write despite its ability to depend on earlier updates. Its diagnosis is limited inner optimization: a linear memory fits fixed K/V better in one epoch, while a nonlinear memory benefits from more passes. It then uses two matrices A and B with local losses ||Ak-v||²/2 and ||B h-v||²/2, h=SiLU(Ak), rather than joint optimization of ||B SiLU(Ak)-v||²/2. Each layer has an affine delta recurrence. Pre/post variants differ in whether h uses old or updated A; the default is pre, enabling concurrency. This is an actual write-rule change, not ordinary SGD renamed.

The biological mismatch is precise: v is a high-dimensional language value representation generated by a trainable outer model. If one literally substitutes a scalar measured functional assay y for v while preserving the paper's equal hidden/value width, A has one row and B is scalar. The nonlinear predictor depends on only one learned action-feature projection. That is an unnecessarily severe representation restriction for context-dependent drug response. Simply adding width does not provide the missing local targets. Conversely this is not a theorem that scalar supervision cannot train a rich model: ordinary end-to-end multilayer learning clearly can. It is a limitation of this literal layerwise target prescription.

**Double-Take: Improving Capacity, Binding, and Selectivity In Long-Context Within Bidirectional Memory**, arXiv2610.13073v2. The source makes multiple partial Muon-normalized memory writes without per-step row renormalization; local cross-position convolution changes the associations being written; bidirectional context differences make the write target sensitive to changes. Its cross-position binding and two-sided context are meaningful for genomic sequence, not automatically legal for a forward experimental campaign with future outcomes unopened. The source processes sequences with large context compression and memory capacity pressure. Current sparse assay panels do not inherit that bottleneck merely because their observations are called memory. I do not propose a second construction from this source or transplant its genomic sequence results into pharmacological feedback evidence.

## One concrete attempted biological learning rule

Task target: source-learn a rule that updates a small intervention-response model after observing one functional result, then improves prediction/ranking of distinct unmeasured interventions in the same new biological context. Future decisions must depend on those updated unmeasured predictions; measured-hit reuse alone does not count as update value. This is a possible target-prioritization/response-adaptation operation, not a demonstrated virtual-cell mechanism.

Let k be a fixed source-trained embedding of intervention plus legal cellular context, A in R^(p x d), b in R^p, u=A k, h=tanh(u), yhat=b^T h, e=y-yhat. All quantities below use the pre-update state. Define a narrow learned teaching network

    r_phi(k,u,b) = tanh(P_phi [k;u;b]),
    u_target = stop_gradient(u + r_phi(k,u,b)*e),
    A_new = A + eta_A (u_target-u) k^T,
    b_new = b + eta_b e h.

The local A objective is ||A k-u_target||²/2 with target held fixed during its local step. P_phi and A0,b0,eta_A,eta_b are meta-trained only on source task episodes: after support updates, minimize fixed held-out functional query squared loss plus the same predeclared pairwise ranking surrogate for every learned-rule control. For definiteness the latter can be softplus(-sign(y_i-y_j)*(yhat_i-yhat_j)), excluding true ties. Its coefficient must be fixed on source before target outcomes, not adapted to failed CDK data. Outer differentiation is through the support-update recurrence; the stop-gradient defines only the local teaching operation, so the explicit r_phi update remains differentiable with respect to phi in the outer objective.

This construction permits p>1 from scalar y and bypasses the saturating tanh Jacobian in the hidden update. Unlike DeltaTTT, its first-layer target is a learned error-dependent direction conditioned on the current hidden state, not the same observed value vector as the readout target. Unlike simply refitting b, it can modify the hidden representation. Unlike CCI, it does not enforce a constraint set; unlike DR/reward shaping it is a state update rather than an evaluator. Thus the operation is specific enough to implement and falsify.

However the strongest direct counterpart uses the *same P_phi* to predict a local synthetic gradient

    g_u = -r_phi(k,u,b)*e,
    A_new = A - eta_A g_u k^T,

with exactly the same b step and outer loss. These updates are identical term by term, at every source and target step, for all states. local_rule.py implements the target and synthetic-gradient forms explicitly. No trained comparison is claimed: the equality is inspectable in these implementations and equations. The counterpart does not need an arbitrary universal network, additional labels or search; it uses the same finite network and arithmetic, avoiding the target vector subtraction if desired. Calling the first form a biological teaching target or inherited update program adds no independent operation. The wider direct-DeltaTTT comparison would be informative about this conventional alternative, but could not establish novelty against the faithful synthetic-gradient comparator.

The original synthetic-gradient literature cited by DeltaTTT is a relevant precedent, but I have not newly retrieved or claimed that its published training loss is identical to the external-query meta-objective here. The exact no-difference conclusion concerns the explicitly specified same-outer-loss comparator, not a sweeping claim that all learned local losses or learned optimizers have already been solved. A genuinely different target construction could still be substantive even within this family.

## Data contract and minimum falsifier

Source tasks would require intervention identity, matched cellular context and measured functional outcomes on disjoint support/query intervention sets, with independent study or biological-family partitions and honest outer validation. A static completed functional-screen table can support replay; it does not manufacture fresh experiments or dynamic state trajectories. An actual sequential treatment that changes a culture would require new state/branch evidence and cannot reuse a static row as a temporal counterfactual.

AssayLoop's already authenticated public code/README documents completed historical CRISPR screens and loaders. That is a realistic source route for genetic target prioritization, not an authenticated drug-response temporal corpus. Continuous y is optional here; y may be a measured binary functional hit. No data have been downloaded, and actual source independence, phenotype utility, label quality and split identities remain unqualified. Existing stopped CDK/ALMANAC labels will not be used to choose this rule or tune its target map.

The minimal comparison, if the rule were studied as a conventional capability experiment, is the same small two-layer predictor with end-to-end one-step SGD/Adam and compute-matched multi-step refit, literal scalar DeltaTTT, a fixed or learned expanded-label DeltaTTT control, frozen-A head adaptation, and the exact same-network synthetic-gradient control. Same source episodes, representations, legal feedback, source training/tuning and deployment compute are required. Count the teacher network's outer training; no free meta-training or imaginary assay returns. A gain over scalar DeltaTTT alone could reflect lifting an avoidable bottleneck. An advantage over the exact synthetic-gradient form would indicate inconsistent implementation/budget, not scientific discovery.

The decisive falsifier for the purported *extra mechanism* is already algebraic: identical hidden/readout states and costs under the same P_phi/initialization/episode. Therefore do not launch a biological pilot just to rediscover that equality. This does not imply the common rule is incapable of outperforming SGD; such a result could support useful learned-optimizer capability while leaving the new-method claim unresolved. Nor does it justify repeating the old gradient-recombination experiment: this is a local hidden-state teacher, with a different source and different direct comparator, and its own literal equality is what stops promotion.

## Remaining concrete gap

The promising unfilled technical problem is to construct a high-dimensional local teaching target from sparse functional outcomes that improves *unmeasured* intervention decisions within a demonstrable limited-update regime, without merely reparameterizing a learned local gradient, introducing unobserved molecular targets or limiting the baseline to scalar hidden width. Such a construction needs an additional identifiable structural relationship, a specific computational advantage, or an empirically justified regularization property beyond the equation above. I have not supplied it. The two papers' language/genomic capacity constraints do not establish that relationship for current drug-discovery assets.

This is a concrete failed novelty attempt, not a blacklist of meta-learning. No new inference is drawn about all world models, all Middle information or all biological feedback. World/agent/RSI necessity remains untested.
