**机制：反例编译的改进策略（CCIP）**。psi 不学新参数，而把“世界模型高置信错误”编译成可跨任务复用的“算子–区域禁用证书”，使后续改进跳过已被证伪的搜索/标注区域。

**(1) 应用与最小数据**  
用已认证 STACK 三屏（T98G+DMSO、T98G+TMZ、U2OS）的 0–24h live/SG 前缀预测 72h 导出 marker 变化。不碰已暴露主 test，不救 STACK 已停配置；只在 train/validation 内按药物组构造 20 个小任务流。每任务：共同 θ 起点；动作=选一个改进算子（局部重训/加特征/查询一个历史标签）；反馈=该药物组已存在标签；后续任务=同屏未用药物组。核验缺口：STACK 无独立 run/well/replicate，marker 非真 viability，标签已在先前阶段数值暴露；因此只能作有限范围经验 gate，不是药物效果或独立生物泛化。新 wetlab/独立 screen 未核验。

**(2) 伪码（≤10行）**  
```text
输入 θ0, 世界模型 fθ, 算子库 O, 任务流 T
对每个反馈反例 r=(x,y):
  e=|y-fθ(x)|; σ=fθ预测SD
  if e≤τσ: 交回普通重训θ; continue          # 低置信错误不写入psi
  R=TopK遮挡特征集,使遮挡后e下降最大
  o*=argmin_o 在R上改进后的验证误差
  C[R,o*]←Beta(a+1,b)                       # 失败证书
对下一任务候选(o,R):
  若E[C失败后验]>0.5: 跳过o在该R的搜索/标注
  否则预算 b(o,R)∝E[gain]/(cost·(1+失败后验))
若新反例在C区域被o成功修正: 删除/降权该证书
```
技术实质：psi 更新发生在离散“算子–区域”证书层，而非梯度/样本权重；只有高置信错误进入 psi，低置信交回 θ；证书跨任务保留并减少后续搜索/标注。

**(3) 归约与差异**  
最接近：version-space/约束获取 + 失败样本重加权 + 元学习 + 主动学习 + bandit 预算分配。若 R 取全特征、证书用普通 boosting 实现，则约化为“失败重加权+搜索剪枝”，无新数学。差异主张仅在：高置信门控的责任区域 + 算子–区域证书跨任务复用，能否在同信息同反馈同预算下产生可测预算节省。若普通约束学习/程序搜索可逐步复现相同证书与相同跳过顺序，则承认等价并停止。

**(4) 最便宜决定性实验与门槛**  
纯计算重放，不新 wetlab：20 任务×5 反馈轮，psi0=普通失败重加权/元学习，psi1=CCIP，共同 θ 起点、同反馈机会、同拟合/标注总预算。预注册：高置信反例 top20% 区域须覆盖≥50%错误（前提失败则停）；psi1 达到同等验证 MAE 的累计拟合/标注预算比 psi0 少≥20%，且最终 MAE 不劣于 +0.005；至少 2 个留出任务复现；打乱 R 与 o* 对应后增益<5%。任一失败即停，不转救暴露 test。

**(5) 公平比较**  
同信息：同一反例序列、候选算子库、特征与标签；同反馈：每轮可查同样数量标签/拟合；同预算：总拟合次数、标注数、墙钟上限相同。强 direct 不更新；普通重训每轮全量；CL 用普通 replay/正则；AL 用方差/熵选标签；simplemix 固定平均算子；等预算程序搜索随机/枚举算子序列。psi1 只改算子选择，不额外给数据。

**(6) 可证伪预测**  
- world：高置信错误的区域集中度≥0.5；否则 world 对 psi 无贡献。  
- agent：psi1 比固定/AL 少≥20%预算；若同预算同结果则否定。  
- 继承：证书跨任务复用使新任务冷启动预算下降；随机区域任务无下降。  
- 联合：world+psi 超过单独；随机化世界模型后优势消失。  
- psi1>psi0：共同 θ 起点、同后续反馈下，psi1 达到目标误差所需反馈更少；若只使 θ 更好而改进效率不变，则不算 RSI，停止。
