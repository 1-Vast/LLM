# Two-bundle monotherapy-reference design gate

2026-10-22, after target-blind census, before this graph scan. Read only DESIGN_MATRICES.jsonl, never the response ZIP. This gate asks whether two OTHER measured drug-pair bundles could supply the exact dose coordinates of both drugs of an unpurchased target pair, without reading the target bundle's attached monotherapy values. It does not test response availability, fit provenance, effect-space support, efficacy, state dynamics, a new algorithm or RSI.

For each matrix with target drug IDs A,B, find one other matrix containing A at all target A concentrations and another containing B at all target B concentrations. Exclude every matrix of the unordered A,B pair, including its repeats: buying a repeat is not independent reference-only evidence for a hidden AB combination. Use exact finite Decimal micromolar equality from the design fields, no interpolation/extrapolation. A–C plus B–D is sufficient even when C and D differ; a triangle A–C/B–C/A–B is only a special example and is not required. Requiring one witness per entire axis is a sufficient two-bundle design, not a proof no partial-curve multi-bundle design could work.

Compute two explicitly separate scopes: same member/PROJECT_ID/MASTER_CELL_ID/CELL_ID/BARCODE, and same member/PROJECT_ID/MASTER_CELL_ID/CELL_ID across plates. The first avoids assuming cross-plate monotherapy transport; the second describes a conditional menu only. Stock/plate/layout units are not independent later tasks. Keep drug IDs as source IDs, do not merge the46IDs into37chemical entities without an authenticated dictionary.

Choose lexically first compatible witness per axis to make deterministic metadata-only certificates. Record each target/witness key and aggregate eligibility by member, pair and source cell model, plus incomplete axes. Do not create a final experimental panel from these descriptive counts. Pair-cell coverage in this source is68816, matching the reported count; this still does not identify why3246nominal pair-cell combinations were absent.

Four pre-scan synthetic checks: a nontriangle A–C/B–D cover is accepted; missing a required concentration is rejected; wrong-stock references are rejected; AB repeats cannot be their own reference probes. No new HTTP/API requests, no biological response use, no model fitting. If neither scope provides viable designs, stop this exact two-bundle proposal, preserving alternatives without target-based rescue. If designs exist, require a separate development-response protocol and matched baselines before making a scientific claim.
