## 唯一候选：可继承的干预误差定位修复程序

具体应用：在已测功能反馈菜单上，少量反馈后改进未查询药物/剂量的功能确认；重点不是再预测一份转录谱，而是降低真实功能预测/确认的剩余遗憾。世界模型将干预对状态与功能的映射分成可编辑模块；程序根据已购反馈定位应修改的模块与下一次鉴别测量，继承这个定位/修复程序到后续任务。

最小操作，不超过10行：

1. 固定细胞状态/干预→后续功能模型 `F_theta`、模块分区、合法查询菜单和总预算。
2. 从同一起点获得一组真实功能反馈 `D`，保留全部失败与成本。
3. 由当前残差和已有状态构成诊断 `r(D,theta)`，不访问未购结果。
4. 程序 `psi` 返回模块掩码 `m`、一个合法查询 `q` 和一个固定候选更新算子 `U`。
5. 获取 `y(q)`，用 `theta'=U(theta,D∪{q,y(q)};m)` 更新世界模型。
6. 用同一剩余动作菜单评估后续功能确认，记录净收益和全过程成本。
7. 在开发任务中仅用后续收益更新/编辑 `psi`，不把 theta 精度当 meta 标签。
8. 冻结 psi1，后续未触及任务从相同 theta0 与付费历史比较 psi1/psi0 的后续改进曲线。
9. 继承参数、继承程序、二者联合分别开关，与普通重训/CL/AL/混合/等预算搜索比较。

这九行给出了真实可编码的行为接口，**没有给出新颖性**。

## 最近普通方法能怎样精确归约

若模块与更新算子是有限菜单，则把 `(m,q,U)` 作为一个复合 arm，任务历史为 context，reward 为付费后续功能收益；这就是 contextual meta-active learning/策略选择。所谓“错误定位”若只用于挑 arm，并没有改变这个归约。单个 m 中的参数更新也不新：在线性例子中

`theta' = theta - eta P_m X^T(X theta-y)`

就是投影/块坐标梯度；若用 posterior/正则 refit，则是普通条件更新或模型平均。跨任务学习 m 的规律属于模块化/因果元迁移问题，必须另有真实干预可识别性质才有新的结构结论。这里给的是操作级替代，不是用“通用 NN 可表达一切”否定结构偏置。

若允许 psi 重写自己的诊断、proposal 或更新代码，有限菜单变成程序生成，但“editable task agent+editable meta-agent+archive+validation”已有直接一手先例。新读取的 Hyperagents 原文明确：meta-agent 本身可改；其 improvement@k 从初始 task agent 出发，固定被比较的 meta-agent，在 k 次改进后按 validation 选择并测 test。AIDE² 已直接报告研究 agent 自身的连续代码改写与跨任务转移。因此 `psi1>psi0`、继承失败记录、critic、更好的搜索本身均不是未被提出的操作。生物功能有效性尚未被这些论文解决，但“尚未用于这里”也不能自动证明本候选独到。

要保留一个新的核心，至少须给出：**某个具体、可用干预区分的模块错误，具有普通同信息全 refit/直接预测/标准元主动学习未利用的可验证结构限制，并在新任务上带来足够大的功能决策收益。** 当前候选没有说明是哪一个模块、哪一条实验能区分，或何种可检验结构能阻止上述精确替代。不能用抽象“因果模块”填空。

## 真实应用与可得数据：可做普通基线，不伪装完整资格

可复用的真实功能来源是已完成身份审计的 TG-GATEs 人源体外菜单：8→24h 有385个身份可用条件/152个药名标签，2→24h 有156条件/52药；功能为源定义的 relative survival（LDH% 不能改称原始泄漏量），早期 CEL 状态与 sample 身份可连接。可操作问题是在持续暴露、已预筛剂量菜单内，买少量后期功能反馈后改善未查询条件确认。数据和方法身份均在 `../tggates_functional_qualification/DECISION.md`，本稿没有打开数值。

但这还不是一个完全可执行的 RSI 任务集：存在非control dose='0'、非标准单位及化学别名问题，sample→lot/同培养关系未认证，高剂量本来就按相对存活预筛；385身份条件不是385认证动作，也不是152独立 biological runs。药内三剂量/时间点不能膨胀成后续科研任务。需要先冻结实际合法子菜单、化学组和任务/反馈/测试角色，才能授权一个普通模型 pilot。这不是重开已停止的单eta时钟核心。

不推荐拿旧 ALMANAC cache 冒充新确认：data/INVENTORY 明示其曾使用、源目录空、原访问路径受保护。WM1366 顺序实验只有一 vessel/15技术井，足以做很窄的源内问题，不足以训练并独立确认 psi；原论文已有顺序反应，本稿不再把它重新命名作新机制。STACK 开值测试继续停止，不降低其门槛或换指标。

## 最便宜的失败实验与可执行下一步

**零生物开值的第一门：做复合 arm 替代。** 要求任何候选提交其 m、q、U 的确切代码/方程和 psi 输入输出，构造普通控制器直接选择同一 `(m,q,U)`。如果候选所述步骤和控制器逐步产生相同查询、更新与成本，则“新操作”主张关闭；不需要训练细胞模型证明它是普通选择器。以上线性掩码更新已经给出一个构造归约。若候选实际有该替代做不到的结构性质，必须指出具体哪一步和可证伪条件；不能拿一个无掩码 refit 充当最强普通比较。

**随后的唯一数值下一步应是机会检验，不是加框架：** 在功能任务代理给出真实 action/function/task manifest 后，另立前响应 pilot，给固定普通更新器相同付费反馈，先测其任务间相对收益是否具有可重复、可预测的异质性。若不同更新规则的赢家仅是反馈噪声，或一个全 refit/固定 AL 占优，就没有学习定位程序的可靠机会，停止 psi 搜索。若存在稳定异质性，再允许最简单 contextual selector，只有它的可迁移收益无法由普通模型选择解释且存在独特科学结构时才推进核心。先验证 opportunity 是研究报告中 EG-RPT reliability gate 的合理延续，不声称它本身是新算法。

这个下一步可执行的前提与停止很具体：先提交旧功能源的合法动作/身份 manifest；无合格任务划分则停止该源。再冻结普通候选、配对反馈、重复/独立评价单位、label/program/计算预算和最小净收益；无稳定 policy 差异则停止。当前阶段不应直接开数值，因为行动与独立任务角色尚未完成且 parent 明确禁止。本稿不指定未经噪声/功效论证的任意样本量或临床阈值。

## 五类贡献与 psi1>psi0 的独立证据要求

| 主张 | 真正需要的证据 | 不能替代的东西 |
| --- | --- | --- |
| world | 同信息、同反馈、计费的真实干预功能测试中胜强 direct 和常规动力学；移除 transition/rollout 路径损失收益 | 固定增长锚点很差、latent 命名、转录预测单独变好 |
| agent | 真实合法查询/研究决策的净效用胜固定计划、标准 AL 和等预算搜索 | 测量本身有用、更多标签、人工挑高收益策略 |
| inheritance | 后续合法任务 common-start 下，继承程序/参数分别胜 fresh start、pooling、普通 CL、history retrieval | 同一测试上重复 fit、多个技术井、只省代码输入 |
| joint | 同历史/预算的 world×agent×inheritance crossed ablations，分别测主效应及联合净收益 | 将各自不同任务的正结果拼接 |
| psi1>psi0 | 冻结两个 improver，从相同 theta0/付费历史在新任务给相同 k/label/计算预算，比较其产生的后续改进质量/成本 | psi1 直接预测更准、历史 archive 变大、task-agent 继承更强起点 |

这些要求只是可证伪合同，不是已取得的证据。Hyperagents 的 imp@k 已是最近普通比较，不能省略它或将该评价定义称为原创。
