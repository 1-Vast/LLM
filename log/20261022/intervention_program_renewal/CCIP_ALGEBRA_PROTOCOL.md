# Pre-audit protocol: counterexample-to-improver certificates

Prepared after retaining improver/RESPONSE.md(SHA256a08eb9dc18c02bb7bec1fca214389e11315f742197f5c7fe5fa9b903a8c24cff), before executing this audit. No real biological response, feature array or prior STACK train/validation label is accessed. This rejects the suggestion to construct another20-task empirical gate on the previously stopped exposed STACK task.

Candidate: high-confidence errors choose a feature region R and the operator o* with smallest validation loss, then increment that operator-region's Beta failure posterior, prune posterior failure mean>0.5, and allocate remaining budget by gain/[cost*(1+failure_mean)]. Cross-task tables are inherited, and a successful future correction may delete/downweight a certificate. It proposes this certificate layer as the technical distinction from ordinary failure memory, contextual bandits and budgeted program search.

Decisive checks, deterministic and hand-written rather than running model-generated code:

1. Literal sign consistency. Construct two explicit operators whose evaluated validation losses are0.01and0.25, with the first genuinely successful under a declared0.05success cutoff. The source selects the best operator but increments its *failure* count. Starting Beta(1,1), verify that this immediately bans the actually successful operator, worsening the identical next task's available minimum loss. This is a counterexample to the literal rule, not a theorem that no revised certificate method can work.
2. Charitable repair. If instead updating the failure count from observed operator success/failure, compare the proposal's operator-region Beta table and pruning/budget ordering with standard Bernoulli Beta posteriors for each observed context(region)×arm(operator), using identical gate/events/gain/cost and lexicographic ties. Record all states and chosen operators. Exact stepwise reproduction by this ordinary masked contextual-arm statistic stops the certificate representation alone as a new learning operation. It does not imply all search procedures are empirically equally efficient.
3. Transfer requires an assumption. Give two task-specific operator-loss vectors in the same R where the good/bad order switches. Inherit a hard ban from task1; verify that task2's best operator can then be skipped. This demonstrates absence of universal validity without invariant context/explicit exploration; it does not refute a separately specified statistical transfer assumption.
4. Disabled operators cannot supply their own successful correction under the written exclusive skip rule if there is no other action/override that tries them. Record this as an executable reachability fact for the specified tiny example, not a general prohibition of certificate revision.

No neural world model, biological efficacy, acquisition head-to-head, inheritance utility or improvement-of-improver score is produced. The audit must preserve the distinction between an operator-selection policy learning ordinary statistics, a revised policy-update rule, and the user's stronger RSI effectiveness requirement. Independent reviewers must challenge both the literal interpretation and the charitable reduction before deciding whether any core warrants further research.
