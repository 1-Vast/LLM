## Proposed operation and scientific use

A research program p has measured diagnostic state s(p): e.g. held-out functional residuals, calibration error and measured transition-model consistency. An edit is an actual change to its model-update or experiment-selection procedure, not a drug intervention. Candidate inheritance stores the effects T_i of these edits and their noncommutativity; an updated improvement policy would choose edit order for a later program from its fresh diagnostic state. The intended useful capability is reusing paid source edit experiments to choose unseen later compositions with fewer evaluator calls than whole-program search. This is a coherent improvement-policy target. It is not automatically a virtual-cell world model: that separately must learn cellular interventions and supply decision-relevant diagnostics validated against functional assays.

The precise favorable structural hypothesis is a common affine edit law T_i(s)=A_i s+b_i across programs/tasks, up to a known coordinate interface. One could estimate each map from d+1 affinely independent diagnostic states, inherit it, and calculate the order effect

T_j(T_i(s))−T_i(T_j(s))=(A_j A_i−A_i A_j)s+A_j b_i+b_j−A_i b_j−b_i.

This is an exact positive compositional statement **conditional on that common law**. The primary papers do not establish it. Learned biological features or cross-fitted residuals alone do not prove that all edits share it across new drugs/lines. Shared diagnostics also need adequate state, legal timing and stable edit semantics; those are empirical assumptions rather than universal demands for unique biological causal identification.

## Strong equal-information simplification

Write H_i=[[A_i,b_i],[0,1]]. A candidate's inherited algebra computes compositions H_j H_i, commutators and scores from the source-estimated H_i. An ordinary structured model-based optimizer stores exactly the same H_i and runs the same matrix calculations and order-selection procedure. Every input, prediction, selected edit, posterior over unknown matrices, feedback query and downstream initialization can be coupled pointwise. Its source fit is the same fit; its planning overhead can copy the same cache. Thus the literal operation introduces no additional information or specified new planning algorithm. This is a constructive simulation of **this proposal**, not a theorem ruling out every possible faster algebraic optimizer. If a new non-equivalent optimizer were later specified, its computational tradeoff would require its own analysis.

Consequently neither gains over an unstructured portfolio nor old/new policy gains alone would demonstrate the needed novelty. The equally informed affine transition/response-surface optimizer is mandatory. No enlarged edit grammar, forbidden compound program or weak myopic control is used to obtain an advantage here. There is no positive algorithmic increment to promote.

## Exact falsifier when shared affine closure is unverified

The operation-equivalence above does not prove that source data identify the common law. New exact script check_edit_algebra.py tests two edit systems:

A(x)=x+1; B_lambda(x)=2x+lambda*x*(x−1)*(x−2), with lambda∈{0,−1/9}.

For fresh source starts0and1, execute **all four two-edit programs** AA,AB,BA,BB. Both laws produce identical full intermediate and terminal traces. Every exposed input to an edit lies in{0,1,2}. This includes observed AB−BA order effects of+1 at both source starts. There are8 source trajectories,6 unique(edit,input) pairs; verification replayed both laws,32 exact source edit calculations.

At the fresh later start3, the sign of the AB-vs-BA terminal ordering reverses: lambda0 gives8vs7, difference+1; lambda−1/9 gives16/3vs19/3, difference−1. Hence the source traces, even including complete local programs and their observed order effects, do not identify the later ordering without a structural restriction. No comparator is charged a mandatory mistake; both face the same ambiguity. This is a deterministic identifiability counterexample, not a worst-case claim against population-prior average transfer or an empirical performance result. Only these two orderings are compared; no claim that either is globally optimal among every possible program. All programs remain legal to a comparator.

Result: FALSIFIER_RESULT.json. Deterministic rational arithmetic; no random seeds, training, biological responses or protected data. Later calculation costs8 edit evaluations across4 trajectories. No meaningful runtime benchmark and no assay-cost interpretation.
