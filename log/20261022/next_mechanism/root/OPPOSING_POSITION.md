# Root constructive challenge after independent originals

2026-10-22. Written after reading the three sealed originals, primary weak-PDE text, reported falsifier results and edit-algebra executable, before reading their new cross-reviews. This is an opposing interpretation, not an independent discovery of their results or a replicated experiment.

## Segment coverage: retain a legitimate positive role

The reported counterexample is decisive against substituting the literal local-coverage objective for pooled estimation/contrast risk in this shared-global-parameter Gaussian setting. Both compared plans use four readouts and identical per-segment spectra; the exact pooled MSEs are 1 and 625/49. It is not an empirical comparison of drug assays, proof that these sensitivities are biologically attainable, or a failure replication of IDTD robotics results. A generic universal counterexample does not alone justify a claim of negative average transfer under realistic biological noise.

There is a legitimate conditional positive statement. For positive-definite information matrices, write Schur information as S_i(F)=min_{z:z_i=1} z^T F z. Then S_i(sum_s F_s) >= sum_s S_i(F_s) >= max_s S_i(F_s). Thus unnormalized local separation provides a conservative certificate of pooled information when the parameter and noise model really is shared. It is sufficient rather than necessary; complementary segments can make this bound very loose. Normalization, log coverage and fixed regularization change the optimization objective and do not magically make it the relevant decision risk. This standard variational inequality does not introduce a new MAESTRO algorithm.

Challenge to frontier: distinguish failure of a proposed universal substitution from biological empirical rejection. State whether the original paper actually claims that universal domination; if it does not, avoid imputing it. Also distinguish a possible robustness purpose under time-varying nuisance parameters from an unsupported claim that local coverage is itself robust. A fair misspecification test would give pooled design the same changing-parameter model, not secretly let it fit one global theta.

## Edit algebra: no universal anti-transfer claim

The exact cubic example proves non-identification over a class containing both maps. It does not prove failure under a correct shared affine law, a supported task distribution or an independently restricted family. With an exact shared affine law, a conventional optimizer can reproduce the stated homogeneous-matrix calculations pointwise; this rules out novelty of this particular operation, not all possible faster optimizers. The terminal comparison is AB versus BA ordering, not global program optimality or an actual old/new learned-improver experiment. The source replay computations are not independent assays.

Challenge to recursive: separate an information counterexample from an empirical prior test. The next deterministic preprocessing proposal must not smuggle fixed calibration into a new algorithmic contribution. A genuinely new repair-selection rule would still require an actual old/new improver and complete same-information program controls. No such rule has yet been specified.
