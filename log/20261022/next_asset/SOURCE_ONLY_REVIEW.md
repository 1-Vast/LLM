## Application and permissible virtual-cell scope

Concrete application: select a small, finite set of assay measurements when transferring a hiPSC-cardiomyocyte safety screen to a new laboratory, then predict unmeasured drug-condition **electrophysiological response and event status** at that laboratory. A static intervention-conditioned functional world is permissible here: state can consist of repolarization response and a categorical event distribution rather than RNA. A dynamic biological simulator is not authenticated by these tabular exports.

The most defensible first task is **new-physical-site calibration for already named drugs**, not simultaneous new-drug generalization. All contexts from one physical site remain in the same split. Future new-drug work requires a separate drug-held-out design, authenticated chemistry/dose descriptors and a separate claim. The current data do not establish any ability to predict an unseen human donor, optimize actual treatment of a patient, or infer causal ion-channel mechanisms from this table alone.

Source-visible limitations: clinical risk labels and event-category vocabulary were seen as OOXML shared strings and author text. These are not unseen labels. The numeric EAD and ddFPDc columns were not converted. An experimental trainer should exclude `risk` as an input and may target measured assay responses rather than use an already visible clinical label as a purportedly blind discovery endpoint. `ddFPDc` is a common export field; the author also combines optical APD and MEA FPD measures. Their equivalence is a source modeling choice, not a demonstrated new invariant.

## What should be proposed, and what should be rejected

No novelty claim is cleared. Simple multi-site calibration, ordinary mixed effects, ion-channel or calcium mechanistic models, positive-control correction and generic mechanism-discrepancy updates already have close prior explanations. The source explicitly mandates positive controls, discusses serum/site differences, balanced multi-channel effects, and quiescence's limitations. Merely naming these a world model or inheritance does not create a technical contribution.

A small **observation-model test**, suggested during independent exchange with the mechanism skeptic, is legitimate: distinguish an observed event/measurement status from a conditional repolarization value and test whether joint handling improves transferable predictions. A hurdle/two-head formulation is ordinary statistics and must be benchmarked against an equally informed direct two-head model. No ddFPDc blank may be assigned an EAD/quiescence cause without inspecting the exact missingness pattern and author rules: technical failure is another possible cause. Missingness, masking and event labels themselves can be informative outcomes.

An actual future candidate would need a more specific operation that beats those ordinary baselines, e.g. an update strategy that chooses which known-drug assay bundle to measure at a new site and then changes its next-update strategy using evidence. At present this is a falsifiable research question, **not a distinct innovation**. The model must predict effects under an explicit drug/context intervention; a lookup table plus site offset remains a strong competitor.

## Cheapest discriminating next experiment

Before numerical learning, qualify the physical dose code mapping, event semantics, outcome availability and missingness, and freeze a physical-site split and legal acquisition bundles. Retain all rows belonging to one site/line/drug/dose-code bundle together; never acquire one arbitrary row and treat the other measurements of that same condition as independent unseen validation. Include both cell-line contexts from a held-out site together. Do not infer operating cost from row counts: absent authentic costs, use an explicitly declared equal-bundle budget, not a claim of actual wet-lab cost savings.

Then compare one frozen ordinary functional world/update against: (1) a strong direct drug/context predictor with identical acquired information; (2) a direct two-head event/conditional-response model; (3) mixed-effects or hierarchical response curves with ordinary refit; (4) fixed shrinkage/mixture transfer; (5) continual-update, random acquisition and standard uncertainty/expected-improvement acquisition; and (6) equal-budget search over the same legal update programs. Primary evaluation should use proper event scoring and conditional-response error separately, with an explicitly defined combined decision score only if its utility is justified. No prediction for a missing continuous measurement should be silently scored as if a latent ground truth was supplied.

The initial necessary gate is predictive/decision headroom at fixed few-bundle budget on development physical sites. Freeze a useful margin tied to an actual assay decision and uncertainty at site/drug level **before** numerical targets are opened; this reviewer does not invent a numerical threshold without scale or application cost. If the ordinary direct/refit controls absorb the candidate's effect, stop that candidate before agents/RSI. Small positive aggregate error changes that do not change the registered decision are insufficient.

Only after that gate, a later preregistration can separate world benefit, agent benefit, inherited model/program benefit, and joint benefit. Joint benefit need not be superadditive. C4 RSI requires the **same starting learner/state, same tasks/data budget, and old versus new checkpoints of the same improvement strategy**. Comparing a new world solver to an old direct solver is not C4. The 10 physical sites limit precision of site-generalization and meta-improvement claims; 8,859 rows do not multiply the independent site population. A same-budget offline feedback replay is possible; claims must remain retrospective, finite-menu and assay-specific.

Stop this asset path if dose/event semantics or acquisition grouping cannot be authenticated, if later-site budgets cannot be evaluated without opening their unqueried outcomes, or if the registered direct/refit/search tests remove useful improvement. Do not fix a failure by selecting a more convenient site, replacing the target after seeing values or reopening historical reserves.
