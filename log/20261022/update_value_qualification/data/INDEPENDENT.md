# Independent source qualification — 2026-10-22

First draft saved before reading the new advocate or skeptic drafts. This is a metadata/source audit, not a new numerical experiment or novelty endorsement. Scope: two available functional-response directories only, PRISM 19Q4 and Jaaks 2022. No source response values have been converted, no fit/provider call made, no AZ reserve opened.

## Judgment

**CONDITIONAL GO for an exposed-development, released-repeat-profile diagnostic of ordinary update value.** PRISM supplies genuine released X1/X2/X3 profile identifiers, making a real repeated-profile question possible without injecting synthetic noise. It does not supply authenticated independent culture starts or independently normalized audit measurements. Shared ComBat/control processing limits the claim; it does not make every static catalog/replay task illegal.

**NOT QUALIFIED** for fresh biological confirmation, independent raw-assay reproducibility, clinical efficacy, a world-model benefit, agent benefit, inheritance benefit or RSI novelty. A new split of historically exposed numerical sources remains development. Metadata does not establish sufficient ordinary-update headroom, usable finite coverage or statistical power. Do not open numerical targets until a concrete bounded protocol specifies those checks.

**Measurement:** release log2 fold change is relative to DMSO and corrected for experimental confounders. README specifies low-control-separation/outlier filtering, division by shared control barcodes, same detection-plate negative controls, then **ComBat per compound_plate/well across pool-replicate batches**, before median collapse. X1/X2/X3 are actual released repeat profiles; they are conditionally dependent through processing and possibly stock/culture. Viability proxy is neither direct death nor target engagement/clinical benefit.

## Minimal executable task contract (proposal, no fit authorized here)

1. Freeze a metadata-only eligible catalog: HTS002 exact2.5, experimental, identical full Broad ID/compound_plate/well across parsedX1/X2/X3, all three headers present; STR-qualified matrix/pool join; resolve or exclude ambiguous structures. Group parent aliases and exact scaffolds before any source/feedback/audit allocation. Never select by response strength, QC values or apparent update success.
2. Choose source chemical groups and later target groups by a fixed hash of metadata identifiers. From one declared source dataset train **one common starting artifact**, freeze it and all permitted history. For each target episode, allocate disjoint feedback and audit chemical groups by metadata hash. All ordinary updates start from this same artifact and history.
3. Paid feedback uses named **X1 whole released profile columns** for selected feedback compounds. The basic physical acquisition block is a `(pool_id,compound_plate,well,replicate)` pool-profile bundle; charging a full selected column conservatively charges its20 eligible pool bundles. Every method receives the same permitted union when compared for update-only value. No free target-cell scalar queries. Controls/all-attempt real wet costs are not reconstructed, so report catalog-field/pool-bundle costs separately from wet-lab spending.
4. AuditA usesX2 and AuditB usesX3 on the **same disjoint audit compounds and context population**, evaluator-only. Each is separately charged and excluded from fitting/selection. Same contexts/chemicals make this a released-repeat-profile ranking diagnostic conditional on shared preprocessing. If instead split audit compounds into two halves, the result is chemical-panel transport and **not measurement replicate reliability**. Shared compound/dose/controls/plate/pool dependence must remain in the estimand and uncertainty blocks.
5. Ordinary menu: frozen/no update; scalar residual recalibration; L2-regularized linear residual update on fixed source-trained chemistry/context features. Any penalty/rank choice is fixed using source-only data. Training budget and common artifact/history are identical. A diagnostic oracle uses evaluator-only audit solely as an upper bound, never deployed selection. First establish nontrivial, reproducible differences among ordinary actions; a world/agent module has no justified opportunity if updates are tied or rank-discordant within uncertainty.
6. Primary quantities: per-audit-partition paired loss difference for each update from frozen; best-fixed-action value; episode oracle-versus-best-fixed gap; cross-audit policy-ranking/selected-action regret. Exact metric, practical floor and blocked power decision must be registered before values are opened; metadata cannot justify one universal numerical floor. Stop if usable coverage fails, action rankings fail transport at the declared resolution, or oracle headroom is too small relative to costs/uncertainty.
7. Only after opportunity passes, compare any proposed selector to strong direct prediction, ordinary retraining/CL/AL, simple mixtures and equal-total-budget program search. Shared source labels, paid union, representation inputs, hyperparameter/search budget, seeds and evaluation access must be matched or explicitly priced. Repeated fits consume computation, not new biological feedback.
8. World contribution: hold selector/planner fixed and compare grounded action-conditioned prediction to equally strong direct predictors and ordinary residual/retraining models. Agent contribution: common model and budget, compare selection with fixed/random/active-learning and program-search controls. Inheritance: later tasks with common starts/history and equal cost, world-only/procedure-only/both/neither 2×2; report separate and joint benefit without requiring superadditivity. **C4:** old/new improver applied to the same later starting solver and feedback history under equal later improvement budget; faster/better improvement by the changed strategy is required. A growing checkpoint or repeated ordinary fitting alone is not C4.

## Assumptions and unresolved gates

The contract is deliberately a conventional opportunity diagnostic, not a candidate innovation. Prior EG-RPT is an unexecuted historical draft and already proposed update-policy ranking; renaming it does not create new evidence or novelty. Basal expression could supply measured cell context, but no matched molecular trajectory/action-conditioned latent world has been qualified here. A static action-conditioned world remains legal if it earns value experimentally.

Remote exact release provenance, HTS002 authenticated duration/culture/stock independence, actual finite response coverage, controls/all-attempt wet costs, dependence-aware power, useful action headroom and world-specific information value remain open. None is silently assumed true. Failure of raw biological independence limits a biological replication claim; it does not alone stop a properly labeled exposed static/repeat-profile diagnostic or a computational C4 test.
