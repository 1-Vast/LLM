# Provisional operation for independent review; no advancement

2026-10-22. This is an explicit hypothesis, not an established new method.

Application, if a suitable asset qualifies: select measured serial-antibiotic
experiments that reduce later microcolony growth in a fixed public menu. The
world-model state is an early morphological/growth observation plus whatever
past intervention history has proven necessary for predicting future response.
This is a bacterial population phenotype application; no human or clinical claim.

Proposed operation: use paid action/response observations to detect pairs of
histories mapped to the same current state but with different subsequent response
to the same action. Add the smallest historical feature/state distinction that
resolves those counterexamples; inherit the distinction to later tasks. A
research procedure chooses experiments for testing unresolved state aliasing.
Its possible meta-level revision changes which counterexample/feature tests to
try first, and must make later tests more effective from a common starting state.

The hard novelty question is whether anything here differs from controlled
predictive-state/causal-state reconstruction, counterexample-guided automata
learning, ordinary recurrent representation/structure search, active system
identification and meta-active learning. Naming or combining these operations
is not sufficient. The supporters must identify a precise extra operation or
concede that this is only a baseline. A same-information direct history predictor
may remove any world-model advantage.

Necessary tests before any scientific advancement:

1. Demonstrate repeatable, action-conditioned predictive insufficiency of a
   current-state baseline beyond run/context and size+slope. Do not use a chosen
   encoder's information loss as proof that biology has hidden memory.
2. Compare minimal state refinement with direct models given the same full
   history, RNN/state-space dynamics, ordinary feature/structure search, refit,
   continual learning and identical future auxiliary supervision.
3. Isolate experiment selection versus fixed/random/active-learning and matched
   search; separate state/procedure inheritance from weights, retrieval and
   distillation. Count all observations and formation/search costs.
4. Freeze model/program/history and fork old/new improvement strategies with
   equal proposal/evaluation budgets on later held-out tasks; an improved initial
   representation alone is not RSI.

Stop this core if the operation has no defensible difference from established
methods, if same-information history predictors explain its gains, if useful
improvement is absent at the declared practical margin, or if the qualified
asset cannot supply real histories/actions/responses. A toy counterexample can
test logic but cannot establish bacterial efficacy or RSI. No numerical efficacy
margin is invented before a functional outcome and acquisition unit qualify.

Independent advocate and skeptic reviews were requested before cross-debate.
Their initial positions should remain separate, followed by explicit responses
to each other's strongest objections. Root will retain unresolved disagreements
and decide whether any deeper mechanism experiment is warranted.
