# 生物／应用立场：实际交叉审查与代数反证后的修正

原独立稿与原 seal 保持不变。本稿在封存后实际阅读 frontier/PROPOSAL.md、recursive/PROPOSAL.md、api/RESPONSE.md、API_FALSIFIER_RESULT.json 和 ROOT_MATH_RESULT.json。已向两位独立代理发送具体问题，收到明确回答，并回应他们对本稿的五项质疑。没有新增公共下载、生物补表、保留数值读取或分类器运行。

## 1. 对 root 最强反证的回答：接受，当前独特机制停止晋升

**完全接受同信息等价性。** 在实际观测蛋白集合 O 上，记 r=r_z,O，j=j_O，A=A_O，W=W_O，普通目标为

\[
 \min_{\delta,\gamma}\ \|r+j\delta-A\gamma\|_W^2+\lambda\delta^2.
\]

令 P=I-A(AᵀWA)^†AᵀW，消去未加惩罚的 nuisance γ，得到

\[
 \hat\delta=-\frac{j^\top WP r}{j^\top WPj+\lambda}.
\]

这正是 X=[-j,A]、仅 δ 有高斯 prior／ridge λ 的 joint WLS/MAP。nuisance 若也受惩罚，等价对象需包含同一个惩罚；不能一边改变普通方法再说不等价。root 按事前 ROOT_MATH_PROTOCOL.md 做了 5 seeds × λ∈{0,.25} 的 10 cases，profile 与 joint MAP 的最大绝对差为 **2.220446049250313e-16**。我实际读取了 ROOT_MATH_RESULT.json，接受这个结果；它不是弱近似对照，而是本估计器的精确普通实现。

**P1 原表述过强。** 若无噪声 r=-jδ₀+Aγ，令 I_obs=jᵀWPj，则

\[
 \hat\delta=\frac{I_\mathrm{obs}}{I_\mathrm{obs}+\lambda}\delta_0.
\]

因此 λ>0 仍有 shrinkage bias。root 的精确例为真 δ=1、I_obs=1、λ=1，估计=1/2。只有 λ=0、局部模型正确、I_obs>0 时才能说无噪声精确恢复；非线性 F 的一阶近似还另有误差。原稿的“无噪声应恢复”不能作为无条件定理继续使用。

**可识别性须以实际观测坐标判断。** 全坐标 j 不在 span(A) 不能保证缺失后的 j_O 不在 span(A_O)。root 的五个混淆检查 I≈0 符合这一点。应按预定数值容差与 assay 噪声拒绝不可识别更新；浮点约 1e-14 的正负数不是可识别证据。这是普通线性估计的必要条件，不是新算子。

**P2 不能保证有噪声时必然拒绝。** root 给 S=0、A=.1、噪声界 .1、观测 .05，两个候选都兼容。若剩余离散剂量上没有足够预测间隔，最大分歧仍可能为零或在噪声内。此时结果必须为“不辨别／不支持共享位移”，不能把未拒绝当 H 成立；应不执行有鉴别意义的行动主张，或退回明确的普通功能校准。对于有界同宽噪声，至少须有大于 2ε 的候选均值间隔，才有不重叠区间式的确定性识别；随机噪声还需预定概率错误率与重复成本。大的分子 I 不保证功能曲线可辨别，尤其在平坦／饱和段。

**还剩什么独特性质？当前没有已成立的一项。** “先保存 q2 预测，再用独立第二反馈反驳耦合”是值得保留的科学程序，但普通 model discrimination／OED + 同一 WLS/MAP 也能逐步执行。它不能单独支撑创新。固定两次反馈下更好的真实功能风险／成本是可验证的潜在贡献，目前没有结果，不能拿它绕过等价性检查。

决定：**STOP_CURRENT_DISTINCT_CORE**。当前最多保留为“普通 dose-shift joint MAP 与模型辨别”的可解释基线。不开新生物值，不扩补表，不启动多代搜索。这个结论针对本运算；并未检验所有剂量结构、所有预算优势或所有潜在新估计器。

## 2. 对 recursive 的具体质疑与双方回应

recursive 提出五点，我全部接受并具体收窄：

1. **数据可获得性不等于完整 join 已验证。** decryptE 正文认证 144 药×五剂量的实验设计及并行功能测量，公开声明 MassIVE／曲线资源。未下载补表就不能认证完整逐 drug-dose×assay 文件、每孔重复数、缺失模式或全部功能原始值均已可下载并正确配对。原稿的可用资产表述只能指实验设计与公开位置，不能升级为已认证完整功能矩阵。当前不为补这一点扩下载。
2. **S 子群不能作主结果。** 全部预定药物任务的未查询剂量风险、拒绝率、拒绝任务风险与所有查询成本才是主评价；被 S 选择的子群仅作次级机制诊断。不要排除弱响应／拒绝任务再计算优势。原稿 P3 的子群描述按这个边界解释。
3. **两点裸拟合四参数 Hill 是弱对照。** 普通 Hill／多输出 nonlinear least squares／GP 必须得到与候选相同的源先验与反馈。source-prior MAP／联合条件化才是本候选真正应击败的对象。增加蛋白维度不赋予候选独占先验的权利。
4. **q2 缺乏可辨别间隔时不算通过。** 该边界已在上节落实。
5. **没有新 RSI 运算。** gate／拒绝／继承权重或 updater 的变化不等于 improver 变强。当前同意先以普通 dose-shift MAP 命名，未证明同信息统计／计算优势就不晋升。

我向 recursive 反问了其 8 对 16 标签效率主张的稀有阳性与成本条件。已知 HCT116 的 34/600 仅作说明：iid 示意下 8 次功能支持全 N 的概率约 (566/600)^8≈.63，真实 grouped 固定序列概率不能用这个近似替代。对方接受报告全 N 支持频率，不补采阳性；保持预定平均 BCE 主终点，并分解正／负类风险、全 query risk、相对 source-prior／EB 的差与 AP／发现率，以免截距改善被误当药物能力。

对方还接受当前不超过三个保留背景不足以支撑有力二倍效率／源训练费用摊销结论，限定为可能功效不足的 pilot。break-even 需源成本差／每任务净节省与实际可用任务数上界；净节省≤0 就不能摊销。标签数、CPU 和 API 分别计账，不能编造 assay 美元成本或用无限未来任务抵消开销。认可这是一套诚实的普通更新基线计划，尚非新机制或 RSI 结果。

## 4. 对 API 原稿与已执行反证的实际审查

API 的 WGRP 使用化学组内秩 z 和 z³ 校正固定分数，pairwise loss 只对同组异标签对提供数据项。root 的 API_FALSIFIER_RESULT.json 已在原有暴露数据上给出：600 条件、596 化学组，其中 592 singleton、4 个 size2，**同组异标签对为零**。四个重复组的基础分数与标签相同。

因此该提案指定的 pair loss 没有数据项；正 L2 下 a=b=0 为唯一解，候选无任何可学习的组内信号。singleton 的秩定义也不提供有效组内排序。不能为了挽救方法改成新的药理分组或另开保留标签；那已是新的假设／协议，而本候选按原任务应停。

即便有组内对，s'=s+λaz+λbz³ 可由普通固定 s 系数为 1 的多项式特征读出精确表达。root 已记录 11 个精确特征等式。它没有动态／干预状态模型；原稿把基础 predictor 的微调当 G，而不是对改进器本身的修改，不能构成 RSI。它自己未核验文献，不能把未经检索的近邻列表当新颖性审查完成。**接受 STOP_WGRP_ON_THIS_GROUPING**；不需重训来确认空数据项。

## 5. 支持、反对与未决事项

支持证据：三方都给了具体更新对象，承认强普通实现；root 实际数学反证确认 profile 等价、正则偏差和噪声下不可保证拒绝；API 实际任务分组证据直接否定其训练信号。生物侧明确了“蛋白响应≠功能”与 assay 合同边界，没有用未知 S8 时序补叙事。

反对意见：目前 biology 候选为普通 MAP+实验辨别，frontier／recursive 为普通 learned optimizer／EB 类对象，API 候选在给定组上数据项为空。没有一个已建立独特的世界模型更新性质、真实有限预算优势或改进器的后续效率收益。

未决分歧不是“这些普通方法有没有用”，而是有没有额外的可验证结构或总成本优势。当前双方没有给出已通过最小反证的额外核心。后续若有实质新估计器或清楚的误差／样本复杂度／成本主张，再先提出其普通精确实现与反例；如果只是本运算换数据，报告普通应用基线。当前不因此打开任何保留集。

本轮判断：接受 root 的数学结果，停止本具体对象的独特核心主张；保留公开生物设计与普通模型作为未来可审查的参照。完整研究目标仍未达成，世界模型、智能体、继承与 RSI 都没有被本轮证明。
