 Abstract 
    
 We investigate Optimization under Input Uncertainty (OIU), in which the input to the objective function, rather than the objective function itself, is subject to uncertainty.
OIU appears in manufacturing processes with production tolerance, control of physical systems with actuation noise, Mixture of Experts, and Reinforcement Learning (RL).
Most of the existing approaches solve OIU by using the value of the objective function but discard the information of the realized input, even though the realized input is observable in various applications.
The question here is whether the discarded information of the realized input is useful to accelerate the optimization process.
We affirmatively answer this question for Evolutionary Strategy (ES) by theoretically showing that the information of the realized input can reduce the variance of the gradient estimator via Rao-Blackwellization.
Using the Rao-Blackwellized gradient estimator, we propose Phenotype-Accelerated Evolutionary Strategy (PAES), which is a refinement of ES for OIU.
Numerical experiments show that PAES converges faster than the usual ES from simple continuous optimization problems to RL benchmarks.

 1  Introduction 

 
 In this paper, we investigate a class of stochastic optimization problems in which the input to the objective function, rather than to the objective function itself, is subject to uncertainty.
Concretely, we specify an input distribution  p θ ​ ( x ) p_{\theta}(x)  of the input  x x  parameterized by  θ \theta  and then observe the realization  x x  of the input and its evaluation  f ⁡ ( x ) f(x) .
Our aim is to find the optimal parameter  θ \theta  of the input distribution that maximizes 
 

 
 
 F ⁡ ( θ ) := 𝔼 p θ ​ ( x ) ​ [ f ⁡ ( x ) ] , \displaystyle F(\theta):=\mathbb{E}_{p_{\theta}(x)}\left[{f(x)}\right], 
 
 (1.1) 
 
 the expected value of the evaluation.
We call this problem  Optimization under Input Uncertainty  (OIU) (Figure  1.1 ). 
 
 
 Figure 1.1:  Schematic illustration of Optimization under Input Uncertainty (OIU) and its biological analogy. The parameter  θ \theta  (genotype) stochastically determines the input  x x  (phenotype) via  p θ ​ ( x ) p_{\theta}(x) , which is then evaluated by  f f  (individual fitness). The objective  F ⁡ ( θ ) = 𝔼 p θ ​ ( x ) ​ [ f ⁡ ( x ) ] F(\theta)=\mathbb{E}_{p_{\theta}(x)}\left[{f(x)}\right]  corresponds to the population fitness with genotype  θ \theta . 
 
 
 The uncertainty of input in optimization problems can be found in various contexts  [ 4 ;  22 ] , such as the manufacturing process with production tolerance  [ 4 ;  49 ;  8 ] , the control of robots and spacecraft with actuation noise  [ 12 ;  37 ] , and performative prediction in machine learning, where the distribution of data depends on the model parameters  [ 38 ] .
While these examples regard randomness in  x x  as an externally imposed nuisance, the same setup also appears when an algorithm designer intentionally introduces randomness.
In addition, we sometimes employ a distribution  p θ ​ ( x ) p_{\theta}(x)  when  x x  is discrete to make  𝔼 p θ ​ ( x ) ​ [ f ​ ( x ) ] \mathbb{E}_{p_{\theta}(x)}\left[{f(x)}\right]  differentiable with respect to  θ \theta .
Mixture of Experts (MoE)  [ 23 ]  and classification problems are representative examples.
Another important class of problems is Reinforcement Learning (RL)  [ 48 ] , where we introduce stochasticity to a policy to encourage exploration for finding better actions.
We also note that a similar structure appears in prompt engineering, since the outputs of Large Language Models (LLMs) are stochastic. 
 
 
 Since a variety of important real-world problems are categorized into this class of problems, several algorithms have been proposed to deal with the uncertainty of the input.
An approach is gradient-based algorithms, which minimize the worst-case objective value by assuming boundedness of uncertainty  [ 3 ;  21 ;  20 ] .
The second class is Bayesian optimization  [ 12 ;  36 ] , which constructs a prior distribution of the objective function by incorporating the uncertainty of the input and then updates the distribution by observing the realized input and its evaluation.
Yet another approach, which we focus mainly on in this paper, is population-based optimization  [ 5 ] , such as Evolutionary Strategy (ES)  [ 41 ]  and genetic algorithms  [ 51 ] .
ES has demonstrated its efficiency and superiority in RL  [ 44 ;  30 ]  in terms of scalability and robustness to local optima compared to single-agent RL algorithms  [ 27 ;  9 ]  (See Appendix  A  for more detail). 
 
 
 While these algorithms search for an optimal  θ \theta  using  f ⁡ ( x ) f(x)  of the realized input  x x  as a feedback signal, they do not utilize the information of the realized input  x x  itself.
Since the realized input  x x  is observable in many applications, the information it carries could be used to further improve the efficiency of the algorithms.
In the manufacturing process, for example, the production tolerance prevents us from completely controlling the resulting product  x x , but the manufactured product  x x  can be measured and therefore observable.
Likewise, in the control of physical systems, actuation noise hinders us from completely controlling the trajectory of the system, but we can measure the trajectory afterwards.
In particular, ES applied to RL  [ 44 ]  uses only the reward of the episode without tapping into the trajectory of states and actions. 
 
 
 These examples raise a question:  is the observation of the input useful for accelerating the optimization? 
Motivated by the analogy with evolutionary biology, we introduce the  Phenotype-Accelerated Evolutionary Strategy (PAES)  which achieves the acceleration of ES.
In the context of evolutionary biology, the function  f ⁡ ( x ) f(x)  is fitness, which is determined by the phenotypic state  x x  of an individual (Figure  1.1 ).
The phenotype  x x  is stochastically determined by the genotype  θ \theta  as  p θ ​ ( x ) p_{\theta}(x) . Thus, the objective function  F ⁡ ( θ ) F(\theta)  is the fitness of a population with genotype  θ \theta . Following the idea of accelerating evolution by learning at the phenotypic level  [ 32 ;  34 ] , PAES takes advantage of the phenotypic information to design a population-based efficient gradient estimator.
Furthermore, we affirmatively and theoretically answer the question by showing that this acceleration is Rao-Blackwellization  [ 40 ;  6 ;  28 ] .
Rao-Blackwellization is a technique to reduce the variance of estimation in which we eliminate the randomness from irrelevant random variables by taking a conditional expectation (See Appendix  A ).
PAES replaces the gradient estimation of ES for OIU with its Rao-Blackwellization. 
 
 
 The contribution of this paper is summarized as follows: 
 
 •  
 
 We introduce a general framework for optimization under input uncertainty (OIU). 
 
 •  
 
 We show theoretically that observing the realized input can accelerate ES for OIU through Rao–Blackwellization, and we call the resulting accelerated method PAES. 
 
 •  
 
 For a class of problems, we derive the Rao–Blackwellized gradient estimator analytically and provide a reparameterization-trick approximation to it  [ 25 ;  42 ] . 
 
 •  
 
 We demonstrate numerically that PAES converges faster than ES across benchmarks, from simple optimization problems to more complex RL tasks. 
 
 
 
 
 We note that a Rao-Blackwellization of a gradient estimator is employed in   [ 26 ] . Yet, this work differs from ours in that they take a conditional expectation of the latent variable with respect to the activation of hidden layer whereas we take a conditional expectation of parameters with respect to the realized input.

 2  Preliminaries 

 
 Before introducing PAES, we clarify the notation to be used and outline the basis of ES and its variants. 
 
 
 2.1  Notation 

 
 For a positive integer  n n , let  [ n ] = { 1 , 2 , … , n } [n]=\{1,2,\ldots,n\} .
For simplicity, we sometimes denote summation  ∑ i = 1 N f ⁡ ( x i ) \sum_{i=1}^{N}f(x_{i})  as  ∫ f ⁡ ( x ) ​ 𝑑 x \int f(x)\mathrm{d}x .
We denote the Kronecker delta function as  δ x , x ′ \delta_{x,x^{\prime}} .
For a vector  𝒙 = ( x 1 , x 2 , … , x n ) \bm{x}=(x_{1},x_{2},\ldots,x_{n}) , its diagonalization  diag ⁡ ( 𝒙 ) \mathrm{diag}(\bm{x})  is defined as the diagonal matrix with  x 1 , x 2 , … , x n x_{1},x_{2},\ldots,x_{n}  on its diagonal. 
 
 
 
 2.2  Random Variables and Probability Distributions 

 
 When a random variable  x x  follows a certain distribution whose probability density function is  p ⁡ ( x ) p(x) , we write  x ∼ p ⁡ ( x ) x\sim p(x) .  𝔼 p ⁡ ( x ) ​ [ f ​ ( x ) ] \mathbb{E}_{p(x)}\left[{f(x)}\right]  denotes the expectation of  f ⁡ ( x ) f(x)  with respect to  p ⁡ ( x ) p(x) .
For a random vector  v ∼ p ⁡ ( v ) v\sim p(v) , we define the variance of  v v  as  𝕍 p ⁡ ( v ) ​ [ v ] = 𝔼 p ⁡ ( v ) ​ [ ‖ v ‖ 2 ] \mathbb{V}_{p(v)}\left[v\right]=\mathbb{E}_{p(v)}\left[{\|v\|^{2}}\right] . 
 
 
 For a  n n -dimensional normal distribution, we denote its probability density function by  N ⁡ ( x ∣ μ , Σ ) N\left({x}\mid{\mu},{\Sigma}\right) , where  x ∈ ℝ n x\in\mathbb{R}^{n}  is a random variable,  μ ∈ ℝ n \mu\in\mathbb{R}^{n}  is the mean vector, and  Σ ∈ ℝ n × n \Sigma\in\mathbb{R}^{n\times n}  is the covariance matrix.
Similarly, for a Dirichlet distribution, we denote its probability density function by  Dir ⁡ ( π ∣ α ) \mathrm{Dir}(\pi\mid\alpha) : 
 

 
 
 Dir ⁡ ( π ∣ α ) \displaystyle\mathrm{Dir}(\pi\mid\alpha) 
 : = 1 ℬ ⁡ ( α ) ​ ∏ i ∈ [ n ] π i α i − 1 , \displaystyle:=\frac{1}{\mathcal{B}(\alpha)}\prod_{i\in[n]}\pi_{i}^{\alpha_{i}-1}, 
 
 (2.1) 
 
 where  π \pi  is a probability distribution on  [ n ] [n]  and and  α ∈ ℝ > 0 n \alpha\in\mathbb{R}^{n}_{>0}  is the parameter.
Here,  ℬ ⁡ ( α ) \mathcal{B}(\alpha)  is the extended Beta function defined by 
 

 
 
 ℬ ⁡ ( α ) := ∏ i ∈ [ n ] Γ ⁡ ( α i ) Γ ⁡ ( ∑ i ∈ [ n ] α i ) , \displaystyle\mathcal{B}(\alpha):=\frac{\prod_{i\in[n]}\Gamma(\alpha_{i})}{\Gamma\left(\sum_{i\in[n]}\alpha_{i}\right)}, 
 
 (2.2) 
 
 where  Γ ⁡ ( x ) \Gamma(x)  is the Gamma function. 
 
 
 
 2.3  Evolutionary Strategy 

 
 Given an unconstrained maximization problem of an objective function  F : Θ → ℝ F\colon\Theta\to\mathbb{R} , where  Θ ⊆ ℝ n \Theta\subseteq\mathbb{R}^{n}  is a search space and its element is typically represented by  θ \theta , ES solves the problem by introducing a population, which is written as a distribution  q ψ q_{\psi}  on  Θ \Theta  parameterized by  ψ \psi .
Instead of directly optimizing  F ⁡ ( θ ) F(\theta) , ES seeks a parameter  ψ \psi  that maximizes the expected value of  F ⁡ ( θ ) F(\theta)  with respect to  q ψ ​ ( θ ) q_{\psi}(\theta)   [ 41 ] : 
 

 
 
 ℱ ⁡ ( ψ ) := 𝔼 q ψ ​ ( θ ) ​ [ F ⁡ ( θ ) ] . \displaystyle\mathcal{F}(\psi):=\mathbb{E}_{q_{\psi}(\theta)}\left[{F(\theta)}\right]. 
 
 (2.3) 
 
 This expected value is maximized by a stochastic gradient ascent method: 
 

 
 
 ψ t + 1 = ψ t + η ​ ∂ ℱ ∂ ψ ¯ , \displaystyle\psi_{t+1}=\psi_{t}+\eta\overline{\frac{\partial\mathcal{F}}{\partial\psi}}, 
 
 (2.4) 
 
 where  ∂ ℱ ∂ ψ ¯ \overline{\frac{\partial\mathcal{F}}{\partial\psi}}  is an estimator of  ∂ ℱ ∂ ψ \frac{\partial\mathcal{F}}{\partial\psi}  and  η \eta  is a learning rate.
By applying the log-derivative trick, the gradient is calculated without computing  ∂ F ⁡ ( θ ) / ∂ θ \partial F(\theta)/\partial\theta  as follows 
 

 
 
 ∂ ℱ ∂ ψ = 𝔼 q ψ ​ ( θ ) ​ [ F ⁡ ( θ ) ​ ∂ log ⁡ q ψ ​ ( θ ) ∂ ψ ] . \displaystyle\frac{\partial\mathcal{F}}{\partial\psi}=\mathbb{E}_{q_{\psi}(\theta)}\left[{F(\theta)\frac{\partial\log q_{\psi}(\theta)}{\partial\psi}}\right]. 
 
 (2.5) 
 
 From this equation, we can estimate the gradient using samples  θ i ∼ q ψ \theta_{i}\sim q_{\psi}  for  i ∈ [ N ] i\in[N] : 
 

 
 
 ∂ ℱ ∂ ψ ≈ 1 N ​ ∑ i = 1 N F ⁡ ( θ i ) ​ ∂ log ⁡ q ψ ​ ( θ i ) ∂ ψ = : ∂ ℱ ∂ ψ ¯ . \displaystyle\frac{\partial\mathcal{F}}{\partial\psi}\approx\frac{1}{N}\sum_{i=1}^{N}{F(\theta_{i})}\frac{\partial\log q_{\psi}(\theta_{i})}{\partial\psi}=:\overline{\frac{\partial\mathcal{F}}{\partial\psi}}. 
 
 (2.6) 
 
 
 
 
 2.4  Modifications and Refinements of ES 

 
 The gradient estimator of ES ( 2.5 ) is sensitive to the scale of the objective function  F ⁡ ( θ ) F(\theta) , which may worsen the performance of ES in some cases.
To address this issue, we can introduce a transformation function  W { F ⁡ ( θ i ) } i : ℝ → ℝ W_{\{F(\theta_{i})\}_{i}}:\mathbb{R}\to\mathbb{R} , which can depend on a set of evaluations  { F ⁡ ( θ i ) } i \{F(\theta_{i})\}_{i}  over the populations.
We define a transformed objective function by 
 

 
 
 ℱ W ​ ( ψ ) := 𝔼 q ψ ​ ( θ ) ​ [ W ⁡ ( F ⁡ ( θ ) ) ] , \displaystyle\mathcal{F}_{W}(\psi):=\mathbb{E}_{q_{\psi}(\theta)}\left[{W(F(\theta))}\right], 
 
 (2.7) 
 
 and the associated gradient estimator from samples  [ 37 ] ; 
 

 
 
 ∂ ℱ W ∂ ψ ≈ 1 N ​ ∑ i = 1 N W ⁡ ( F ⁡ ( θ i ) ) ​ ∂ log ⁡ q ψ ​ ( θ i ) ∂ ψ , \displaystyle\frac{\partial\mathcal{F}_{W}}{\partial\psi}\approx\frac{1}{N}\sum_{i=1}^{N}{W(F(\theta_{i}))}\frac{\partial\log q_{\psi}(\theta_{i})}{\partial\psi}, 
 
 (2.8) 
 
 where we omit the subscript of  W { F ⁡ ( θ i ) } i W_{\{F(\theta_{i})\}_{i}}  for notational simplicity.
We can further improve the performance of ES by introducing a natural gradient estimator.
Using the Fisher information matrix 
 

 
 
 ℐ ⁡ [ q ψ ​ ( θ ) ] := 𝔼 q ψ ​ ( θ ) ​ [ ∂ log ⁡ q ψ ​ ( θ ) ∂ ψ ​ ∂ log ⁡ q ψ ​ ( θ ) ∂ ψ ⊤ ] , \displaystyle\mathcal{I}\left[{q_{\psi}(\theta)}\right]:=\mathbb{E}_{q_{\psi}(\theta)}\left[{\frac{\partial\log q_{\psi}(\theta)}{\partial\psi}\frac{\partial\log q_{\psi}(\theta)}{\partial\psi}^{\top}}\right], 
 
 (2.9) 
 
 the natural gradient is obtained; 
 

 
 
 ∇ ℱ W ​ ( ψ ) = ℐ ​ [ q ψ ​ ( θ ) ] − 1 ​ 𝔼 q ψ ​ ( θ ) ​ [ W ⁡ ( F ⁡ ( θ ) ) ​ ∂ log ⁡ q ψ ​ ( θ ) ∂ ψ ] , \displaystyle\nabla\mathcal{F}_{W}(\psi)=\mathcal{I}\left[{q_{\psi}(\theta)}\right]^{-1}\mathbb{E}_{q_{\psi}(\theta)}\left[{W(F(\theta))\frac{\partial\log q_{\psi}(\theta)}{\partial\psi}}\right], 
 
 (2.10) 
 
 where and hereafter  ∇ \nabla  instead of  ∂ / ∂ ϕ \partial/\partial\phi  is used to indicate the natural gradient.
We can approximate the natural gradient by samples in a similar way to ( 2.8 ).
This method is known as Information Geometric Optimization  [ 37 ] .
The algorithm with transformation function  W W  is summarized in Algorithm  1 .

 There exist other finer modifications of the gradient estimator ( 2.8 ).
The two-point gradient estimator  [ 47 ;  11 ;  35 ;  10 ]  is a major example, and its theoretical analysis shows the superiority of the two-point estimator over the one-point gradient estimator ( 2.8 ).
The two-point gradient estimator for general ES is defined as follows: 
 

 
 
 ∂ ℱ W ∂ ψ ¯ := 1 N ​ ∑ i = 1 N [ W ⁡ ( F ⁡ ( θ 1 i ) ) − W ⁡ ( F ⁡ ( θ 2 i ) ) 2 ​ σ ] ​ [ ∂ log ⁡ q ψ ​ ( θ 1 i ) ∂ ψ − ∂ log ⁡ q ψ ​ ( θ 2 i ) ∂ ψ ] . \displaystyle\overline{\frac{\partial\mathcal{F}_{W}}{\partial\psi}}:=\frac{1}{N}\sum_{i=1}^{N}\left[\frac{W(F(\theta^{i}_{1}))-W(F(\theta^{i}_{2}))}{2\sigma}\right]\left[\frac{\partial\log q_{\psi}(\theta^{i}_{1})}{\partial\psi}-\frac{\partial\log q_{\psi}(\theta^{i}_{2})}{\partial\psi}\right]. 
 
 (2.11) 
 
 
 
 
 2.5  Zeroth-Order Optimization: an instance of ES 

 
 One of the most popular versions of ES is the case in which the population  q ψ ​ ( θ ) q_{\psi}(\theta)  is a Gaussian distribution  N ⁡ ( θ ∣ θ ¯ , σ 2 ​ 𝐈 ) N\left({\theta}\mid{\bar{\theta}},{\sigma^{2}\mathbf{I}}\right)  with  σ \sigma  as a hyperparameter.
In this case, the gradient of  ℱ W \mathcal{F}_{W}  in ( 2.8 ) is reduced to the following form: 
 

 
 
 ∂ ℱ W ∂ ψ ≈ 1 N ​ σ ​ ∑ i = 1 N W ⁡ ( F ⁡ ( θ i ) ) ​ ϵ i , \displaystyle\frac{\partial\mathcal{F}_{W}}{\partial\psi}\approx\frac{1}{N\sigma}\sum_{i=1}^{N}{W(F(\theta_{i}))}\epsilon_{i}, 
 
 (2.12) 
 
 where  ϵ i = ( θ i − θ ¯ ) / σ \epsilon_{i}=(\theta_{i}-\bar{\theta})/\sigma .
This method is called Zeroth-Order Optimization (ZOO).
The two-point gradient estimator for ZOO becomes 
 

 
 
 ∂ ℱ W ∂ ψ ¯ = 1 N ​ σ ​ ∑ i = 1 N [ W ⁡ ( F ⁡ ( θ 1 i ) ) − W ⁡ ( F ⁡ ( θ 2 i ) ) 2 ​ σ ] ​ ϵ i . \displaystyle\overline{\frac{\partial\mathcal{F}_{W}}{\partial\psi}}=\frac{1}{N\sigma}\sum_{i=1}^{N}\left[\frac{W(F(\theta^{i}_{1}))-W(F(\theta^{i}_{2}))}{2\sigma}\right]\epsilon_{i}. 
 
 (2.13) 
 
 
 
 
 
 3  Formalization of Optimization under Input Uncertainty (OIU) 

 
 In this section, we formalize OIU.
Let  𝒳 ⊂ ℝ n \mathcal{X}\subset\mathbb{R}^{n}  be an input space (possibly a discrete space), and  f : 𝒳 → ℝ f\colon\mathcal{X}\to\mathbb{R}  be an objective function over the input space.
Let  Θ ⊆ ℝ m \Theta\subseteq\mathbb{R}^{m}  and assume that, for each  θ ∈ Θ \theta\in\Theta , a probability distribution  p θ p_{\theta}  on  𝒳 \mathcal{X}  is associated.
Our aim is to maximize the following objective function over the search space  Θ \Theta : 
 

 
 
 F ⁡ ( θ ) := 𝔼 p θ ​ ( x ) ​ [ f ⁡ ( x ) ] . \displaystyle F(\theta):=\mathbb{E}_{p_{\theta}(x)}\left[{f(x)}\right]. 
 
 (3.1) 
 
 In the following, we call  p θ p_{\theta}  the  input distribution . 
 
 
 3.1  Examples of OIU 

 
 3.1.1  Continuous Optimization with Input Noise 

 
 Let us consider the case where we optimize an objective function  f : ℝ n → ℝ f\colon\mathbb{R}^{n}\to\mathbb{R} , but the input  x x  is perturbed by an input noise.
Specifically, in each trial, we choose an intended input  θ i ∈ ℝ n \theta_{i}\in\mathbb{R}^{n} .
Then, we observe a realized input  x i x_{i} , which is perturbed by the input noise as  x i = θ i + ϵ i x_{i}=\theta_{i}+\epsilon_{i} , where  ϵ i \epsilon_{i}  is the input noise that follows some distribution  h ⁡ ( ϵ i ∣ θ i ) h(\epsilon_{i}\mid\theta_{i}) .
We then observe the feedback  f ⁡ ( x i ) f(x_{i}) .
In this situation, our objective is to maximize the expected value of  𝔼 ϵ i ​ [ f ⁡ ( θ i + ϵ i ) ] \mathbb{E}_{\epsilon_{i}}\left[{f(\theta_{i}+\epsilon_{i})}\right] .
By setting  p θ i ​ ( x ) = h ⁡ ( x − θ i ∣ θ i ) p_{\theta_{i}}(x)=h(x-\theta_{i}\mid\theta_{i}) , this problem is formulated within the framework of ( 3.1 ). 
 
 
 
 3.1.2  Reinforcement Learning 

 
 In RL, our objective is to find a policy  π θ ​ ( a ∣ s ) \pi_{\theta}(a\mid s) , where  a a  is an action and  s s  is a state, which maximizes the expected cumulative reward.
The expected cumulative reward is given by 
 

 
 
 F ⁡ ( θ ) = 𝔼 ℙ F θ ​ [ ∑ t = 0 ∞ γ t ​ r ​ ( s t , a t ) ] , \displaystyle F(\theta)=\mathbb{E}_{\mathbb{P}_{\mathrm{F}}^{\theta}}\left[{\sum_{t=0}^{\infty}\gamma^{t}r(s_{t},a_{t})}\right], 
 
 (3.2) 
 
 where  r ⁡ ( s , a ) r(s,a)  is a reward function and  γ ∈ [ 0 , 1 ) \gamma\in[0,1)  is a discount factor.
Here, we define  ℙ F θ \mathbb{P}_{\mathrm{F}}^{\theta}  as the law of the trajectory of states and actions produced by a policy  π θ ​ ( a ∣ s ) \pi_{\theta}(a\mid s)  and a given transition matrix  𝐓 ⁡ ( s ′ ∣ s , a ) \mathbf{T}(s^{\prime}\mid s,a) .
The explicit form of  ℙ F θ \mathbb{P}_{\mathrm{F}}^{\theta}  is 
 

 
 
 ℙ F θ ​ ( a 0 , s 1 , a 1 , s 2 , … ∣ s 0 ) = ∏ t = 0 ∞ π θ ​ ( a t ∣ s t ) ​ 𝐓 ​ ( s t + 1 ∣ s t , a t ) . \displaystyle\mathbb{P}_{\mathrm{F}}^{\theta}(a_{0},s_{1},a_{1},s_{2},\dots\mid s_{0})=\prod_{t=0}^{\infty}\pi_{\theta}(a_{t}\mid s_{t})\mathbf{T}(s_{t+1}\mid s_{t},a_{t}). 
 
 (3.3) 
 
 By setting sample  x = ( a 0 , s 1 , a 1 , s 2 , … ) x=(a_{0},s_{1},a_{1},s_{2},\dots)  and  p θ = ℙ F θ p_{\theta}=\mathbb{P}_{\mathrm{F}}^{\theta} , we see that this problem is in the framework of ( 3.1 ). 
 
 
 
 
 3.2  Extension of OIU 

 
 We may extend OIU to Contextual Optimization under Input Uncertainty (COIU) where  f ⁡ ( x ) f(x)  and  p θ ​ ( x ) p_{\theta}(x)  are also dependent on a context  c c  as in  f ⁡ ( x , c ) f(x,c)  and  p θ ​ ( x | c ) p_{\theta}(x|c) .
This extension covers a wider range of applications such as mixture of experts and classification with bandit feedback.
To keep the main body of the text simple, we discuss this extension in Appendix  B . 
 
 
 
 
 4  Phenotype-Accelerated Evolutionary Strategy (PAES) for OIU 

 
 In this section, we introduce PAES and its core component, the phenotype gradient estimator. As PAES is an extension of ES for OIU, we first illustrate how ES is adopted to solve OIU and how its gradient estimator can be improved by exploiting the realized input  x x . 
 
 
 4.1  Evolutionary Strategy for OIU and Genotype Gradient Estimator 

 
 Give the objective function  F ⁡ ( θ ) F(\theta)  of OIU, its smoothed version by a distribution  q ψ ​ ( θ ) q_{\psi}(\theta)  is obtained as 
 

 
 
 ℱ ⁡ ( ψ ) := 𝔼 q ψ ​ ( θ ) ​ [ F ⁡ ( θ ) ] = 𝔼 q ψ ​ ( θ ) ​ [ 𝔼 p θ ​ ( x ) ​ [ f ⁡ ( x ) ] ] . \displaystyle\mathcal{F}(\psi):=\mathbb{E}_{q_{\psi}(\theta)}\left[{F(\theta)}\right]=\mathbb{E}_{q_{\psi}(\theta)}\left[{\mathbb{E}_{p_{\theta}(x)}\left[{f(x)}\right]}\right]. 
 
 (4.1) 
 
 where  q ψ ​ ( θ ) q_{\psi}(\theta)  is interpreted as the diversity of genotypes (Figure  4.1 ).
We can also define a transformed objective function: 
 

 
 
 ℱ W ​ ( ψ ) := 𝔼 q ψ ​ ( θ ) ​ [ 𝔼 p θ ​ ( x ) ​ [ W ⁡ ( f ⁡ ( x ) ) ] ] . \displaystyle\mathcal{F}_{W}(\psi):=\mathbb{E}_{q_{\psi}(\theta)}\left[{\mathbb{E}_{p_{\theta}(x)}\left[{W(f(x))}\right]}\right]. 
 
 (4.2) 
 
 The gradient is calculated via ( 2.5 ): 
 

 
 
 ∂ ℱ W ∂ ψ = 𝔼 q ψ ​ ( θ ) ​ [ 𝔼 p θ ​ ( x ) ​ [ W ⁡ ( f ⁡ ( x ) ) ] ​ ∂ log ⁡ q ψ ​ ( θ ) ∂ ψ ] . \displaystyle\frac{\partial\mathcal{F}_{W}}{\partial\psi}=\mathbb{E}_{q_{\psi}(\theta)}\left[{\mathbb{E}_{p_{\theta}(x)}\left[{W(f(x))}\right]\frac{\partial\log q_{\psi}(\theta)}{\partial\psi}}\right]. 
 
 (4.3) 
 
 Then, we obtain an estimate of this expression by sampling: 
 
 
 Definition 1   (Genotype gradient estimator) . 
 
 

 
 
 ∂ ∂ ψ ¯ g ​ ℱ W := 1 N ​ ∑ i = 1 N W ⁡ ( f ⁡ ( x i ) ) ​ ∂ log ⁡ q ψ ​ ( θ i ) ∂ ψ . \displaystyle\overline{\frac{\partial}{\partial\psi}}^{\mathrm{g}}\mathcal{F}_{W}:=\frac{1}{N}\sum_{i=1}^{N}{W(f(x_{i}))\frac{\partial\log q_{\psi}(\theta_{i})}{\partial\psi}}. 
 
 (4.4) 
 
 Since this estimator is obtained by applying ES to the objective function  F ⁡ ( θ ) F(\theta)  with respect to  θ \theta , i.e., genotype information, we call it the genotype gradient estimator. 
 
 
 
 We can also apply ZOO ( 2.12 ) to continuous optimization with input noise (Section  3.1.1 ), for which the genotype gradient estimator is given by 
 

 
 
 ∂ ℱ W ∂ ψ ≈ 1 N ​ σ ​ ∑ i = 1 N W ⁡ ( f ⁡ ( x i ) ) ​ ϵ i , \displaystyle\frac{\partial\mathcal{F}_{W}}{\partial\psi}\approx\frac{1}{N\sigma}\sum_{i=1}^{N}{W(f(x_{i}))}\epsilon_{i}, 
 
 (4.5) 
 
 where  ϵ i = ( θ i − θ ¯ ) / σ \epsilon_{i}=(\theta_{i}-\bar{\theta})/\sigma . 
 
 
 
 4.2  Intuition behind Improvement of Gradient by Phenotypic Information 

 
 One potential problem of the genotype gradient estimator ( 4.5 ) is that it utilizes only the evaluation  f ⁡ ( x i ) f(x_{i})  and the intended input  θ i \theta_{i} , i.e., the fitness value and the gennotype information.
The information of realized input  x i x_{i} , i.e., the phenotypic information, is discarded.
Let us illustrate that the realized input  x i x_{i}  has richer information than  f ⁡ ( x i ) f(x_{i})  and  θ i \theta_{i}  for gradient estimation by the following example. 
 
 
 We consider an extreme example under the problem setting in Section  3.1.1 , where the population distribution is singular.
Concretely, we assume that  h ⁡ ( ϵ i ∣ θ i ) = N ⁡ ( ϵ i ∣ 𝟎 , 𝐈 ) h(\epsilon_{i}\mid\theta_{i})=N\left({\epsilon_{i}}\mid{\bm{0}},{\mathbf{I}}\right) , where  ϵ i = ( x i − θ i ) / σ \epsilon_{i}=(x_{i}-\theta_{i})/\sigma .
We also assume that  ψ = θ \psi=\theta  and  q ψ q_{\psi}  is a delta distribution  δ θ \delta_{\theta} .
We further assume that  W ⁡ ( f ⁡ ( x ) ) = f ⁡ ( x ) W(f(x))=f(x) .
As a consequence, the genotype gradient estimator ( 4.5 ) becomes meaningless since we can no longer define  ∂ log ⁡ q ψ ​ ( θ ) ∂ ψ \frac{\partial\log q_{\psi}(\theta)}{\partial\psi} .
This is because, while the estimator ( 4.5 ) uses the diversity of  θ \theta  for the estimation of the gradient, there is no diversity of  θ \theta  in this case.
However, by following a similar argument to the usual ES, we can estimate the gradient even in this case by using the realized input.
As shown in the next section (see Theorem  3 ), we have 
 

 
 
 ∂ ℱ W ∂ ψ = 1 σ ​ 𝔼 p θ ​ ( x ) ​ [ f ⁡ ( x ) ​ ϵ ] = 1 σ 2 ​ 𝔼 p θ ​ ( x ) ​ [ f ⁡ ( x ) ​ ( x − θ ) ] , \displaystyle\frac{\partial\mathcal{F}_{W}}{\partial\psi}=\frac{1}{\sigma}\mathbb{E}_{p_{\theta}(x)}\left[{f(x)\epsilon}\right]=\frac{1}{\sigma^{2}}\mathbb{E}_{p_{\theta}(x)}\left[{f(x)(x-\theta)}\right], 
 
 (4.6) 
 
 where  ϵ = ( x − θ ) / σ \epsilon=(x-\theta)/\sigma .
From this equation, we can estimate the gradient as follows: 
 

 
 
 ∂ ℱ W ∂ θ ≈ 1 N ​ σ 2 ​ ∑ i = 1 N f ⁡ ( x i ) ​ ( x i − θ ) . \displaystyle\frac{\partial\mathcal{F}_{W}}{\partial\theta}\approx\frac{1}{N\sigma^{2}}\sum_{i=1}^{N}{f(x_{i})(x_{i}-\theta)}. 
 
 (4.7) 
 
 
 
 This example illuminates that the realized input  x i x_{i}  is useful for estimating gradient, and we can construct a new gradient estimator ( 4.6 ). 
 
 
 
 4.3  Phenotype gradient estimator and PAES 

 
 By generalizing the procedure in the example above, we define another gradient estimator: 
 
 
 Definition 2   (Phenotype gradient estimator) . 
 
 For a joint distribution  ℙ F ​ ( x , θ ) = p θ ​ ( x ) ​ q ψ ​ ( θ ) \mathbb{P}_{\mathrm{F}}(x,\theta)=p_{\theta}(x)q_{\psi}(\theta)  and its marginal distribution  ℙ F ​ ( x ) = ∫ ℙ F ​ ( x , θ ) ​ 𝑑 θ \mathbb{P}_{\mathrm{F}}(x)=\int\mathbb{P}_{\mathrm{F}}(x,\theta)\mathrm{d}\theta , a gradient estimator is defined as follows: 
 

 
 
 ∂ ∂ ψ ¯ p ​ ℱ W := 1 N ​ ∑ i = 1 N W ⁡ ( f ⁡ ( x i ) ) ​ ∂ log ⁡ ℙ F ​ ( x i ) ∂ ψ . \displaystyle\overline{\frac{\partial}{\partial\psi}}^{\mathrm{p}}\mathcal{F}_{W}:=\frac{1}{N}\sum_{i=1}^{N}{W(f(x_{i}))\frac{\partial\log\mathbb{P}_{\mathrm{F}}(x_{i})}{\partial\psi}}. 
 
 (4.8) 
 
 We call this estimator  phenotype gradient estimator  since it utilizes the diversity of both genotype  θ \theta  and phenotype  x x . 
 
 
 
 The relationship between the genotype gradient estimator and the phenotype gradient estimator is illustrated in Figure  4.1 . 
 
 
 Figure 4.1:  Schematic illustration of the application of ES to OIU and its refinement, phenotype-accelerated evolutionary strategy (PAES). We introduce  q ψ ​ ( θ ) q_{\psi}(\theta)  as the population of ES, which we regard as the diversity of genotypes in the context of evolutionary biology.
We can estimate the gradient by using only the genotypic information  θ i \theta_{i}  and the evaluation  f ⁡ ( x i ) f(x_{i}) , which is called the genotype gradient estimator. However, we can also utilize the phenotypic information  x i x_{i}  to improve the estimator, which we call the phenotype gradient estimator.
 
 
 
 Theorem 3 . 
 
 The phenotype gradient estimator is an unbiased estimator as the genotype gradient estimator is: 
 

 
 
 ∂ ℱ W ∂ ψ = 𝔼 ℙ F ​ ( x ) ​ [ W ⁡ ( f ⁡ ( x ) ) ​ ∂ log ⁡ ℙ F ​ ( x ) ∂ ψ ] . \displaystyle\frac{\partial\mathcal{F}_{W}}{\partial\psi}=\mathbb{E}_{\mathbb{P}_{\mathrm{F}}(x)}\left[{W(f(x))\frac{\partial\log\mathbb{P}_{\mathrm{F}}(x)}{\partial\psi}}\right]. 
 
 (4.9) 
 
 In addition, the phenotype gradient estimator is superior to the genotype gradient estimator in that it has smaller variance than the genotype gradient estimator: 
 

 
 
 𝕍 ℙ F ​ [ ∂ ∂ ψ ¯ p ​ ℱ W ] ≤ 𝕍 ℙ F ​ [ ∂ ∂ ψ ¯ g ​ ℱ W ] . \displaystyle\mathbb{V}_{\mathbb{P}_{\mathrm{F}}}\left[\overline{\frac{\partial}{\partial\psi}}^{\mathrm{p}}\mathcal{F}_{W}\right]\leq\mathbb{V}_{\mathbb{P}_{\mathrm{F}}}\left[\overline{\frac{\partial}{\partial\psi}}^{\mathrm{g}}\mathcal{F}_{W}\right]. 
 
 (4.10)

 We have

 (4.11)

 (4.12)

 (4.13) 
 
 
 
 = 𝔼 ℙ F ​ ( x ) ​ [ W ⁡ ( f ⁡ ( x ) ) ​ ∂ log ⁡ ℙ F ​ ( x ) ∂ ψ ] . \displaystyle=\mathbb{E}_{\mathbb{P}_{\mathrm{F}}(x)}\left[{W(f(x))\frac{\partial\log\mathbb{P}_{\mathrm{F}}(x)}{\partial\psi}}\right].

 4.4  Phenotype Gradient Estimator as the Rao-Blackwellized Estimator 

 
 To systematically extend generalized genotype gradient estimators (e.g., the two-point estimator ( 2.11 )) to their phenotype counterparts, it is crucial to first generalize Theorem  3 .
Here, we clarify that this generalization is achieved by an argument similar to the Rao-Blackwell theorem. 
 
 
 Recall that, at each generation  t t , we sample  ( θ i ( t ) , x i ( t ) ) ({\theta_{i}}^{(t)},{x_{i}}^{(t)})  from  ℙ F ​ ( x , θ ) \mathbb{P}_{\mathrm{F}}(x,\theta)  independently for  i ∈ [ N ] i\in[N] .
Let us assume that we have some unbiased estimator  U ⁡ ( { θ i ( t ) , x i ( t ) } i ∈ [ N ] ) U\left({\{{\theta_{i}}^{(t)},{x_{i}}^{(t)}\}_{i\in[N]}}\right)  of the gradient for these samples  i ∈ [ N ] i\in[N] . 
 
 
 Definition 4   (Rao-Blackwellized estimator) . 
 
 Given an estimator  U ⁡ ( { θ i ( t ) , x i ( t ) } i ∈ [ N ] ) U\left({\{{\theta_{i}}^{(t)},{x_{i}}^{(t)}\}_{i\in[N]}}\right) , a Rao-Blackwellized estimator  RB ⁡ [ U ] \mathrm{RB}\left[{U}\right]  is defined by 
 

 
 
 RB ⁡ [ U ] ​ ( { x i ( t ) } i ∈ [ N ] ) := 𝔼 ℙ F ​ [ { θ i ( t ) } i ∈ [ N ] ∣ { x i ( t ) } i ∈ [ N ] ] ​ [ U ⁡ ( { θ i ( t ) , x i ( t ) } i ∈ [ N ] ) ] , \displaystyle\mathrm{RB}\left[{U}\right]\left({\{{x_{i}}^{(t)}\}_{i\in[N]}}\right):=\mathbb{E}_{\mathbb{P}_{\mathrm{F}}[\{{\theta_{i}}^{(t)}\}_{i\in[N]}\mid\{{x_{i}}^{(t)}\}_{i\in[N]}]}\left[{U\left({\{{\theta_{i}}^{(t)},{x_{i}}^{(t)}\}_{i\in[N]}}\right)}\right], 
 
 (4.15) 
 
 where the expectation is taken over  ℙ F ​ ( θ ∣ x ) \mathbb{P}_{\mathrm{F}}(\theta\mid x)  for all pairs of  ( θ i ( t ) , x i ( t ) ) ({\theta_{i}}^{(t)},{x_{i}}^{(t)})  independently.
Here,  ℙ F ​ ( θ ∣ x ) \mathbb{P}_{\mathrm{F}}(\theta\mid x)  is the conditional distribution defined by  ℙ F ​ ( x , θ ) / ℙ F ​ ( x ) \mathbb{P}_{\mathrm{F}}(x,\theta)/\mathbb{P}_{\mathrm{F}}(x) . 
 
 
 
 For this Rao-Blackwellized estimator, we can prove a generalization of Theorem  3  . 
 
 
 Theorem 5   (Generalization of Theorem  3 ) . 
 
 The Rao-blackwellized estimator is unbiased. 
 

 
 
 𝔼 ℙ F ​ [ RB ⁡ [ U ] ​ ( { x i ( t ) } i ∈ [ N ] ) ] = 𝔼 ℙ F ​ [ U ⁡ ( { θ i ( t ) , x i ( t ) } i ∈ [ N ] ) ] . \displaystyle\mathbb{E}_{\mathbb{P}_{\mathrm{F}}}\left[{\mathrm{RB}\left[{U}\right]\left({\{{x_{i}}^{(t)}\}_{i\in[N]}}\right)}\right]=\mathbb{E}_{\mathbb{P}_{\mathrm{F}}}\left[{U\left({\{{\theta_{i}}^{(t)},{x_{i}}^{(t)}\}_{i\in[N]}}\right)}\right]. 
 
 (4.16) 
 
 In addition, the Rao-blackwellized estimator has smaller variance than the original estimator: 
 

 
 
 𝕍 ℙ F ​ [ RB ⁡ [ U ] ​ ( { x i ( t ) } i ∈ [ N ] ) ] ≤ 𝕍 ℙ F ​ [ U ⁡ ( { θ i ( t ) , x i ( t ) } i ∈ [ N ] ) ] . \displaystyle\mathbb{V}_{\mathbb{P}_{\mathrm{F}}}\left[\mathrm{RB}\left[{U}\right]\left({{\{{x_{i}}^{(t)}\}_{i\in[N]}}}\right)\right]\leq\mathbb{V}_{\mathbb{P}_{\mathrm{F}}}\left[U\left({\{{\theta_{i}}^{(t)},{x_{i}}^{(t)}\}_{i\in[N]}}\right)\right]. 
 
 (4.17) 
 
 
 
 
 The proofs are given in Section  C.1 .
We can check that Theorem  3  is a special case of Rao-Blackwellization by using the following proposition: 
 
 
 Proposition 6   (Phenotype gradient estimator is a Rao-Blackwellized estimator) . 
 
 

 
 
 RB ⁡ [ ∂ ∂ ψ ¯ g ​ ℱ W ] = ∂ ∂ ψ ¯ p ​ ℱ W . \displaystyle\mathrm{RB}\left[{\overline{\frac{\partial}{\partial\psi}}^{\mathrm{g}}\mathcal{F}_{W}}\right]=\overline{\frac{\partial}{\partial\psi}}^{\mathrm{p}}\mathcal{F}_{W}. 
 
 (4.18) 
 
 
 
 
 The proof is given in Section  C.1 . 
 
 
 
 4.5  Analytical Form of Phenotype Gradient Estimator 

 
 The phenotype gradient estimator requires the computation of  ∂ log ⁡ ℙ F ​ ( x ) ∂ ψ \frac{\partial\log\mathbb{P}_{\mathrm{F}}(x)}{\partial\psi} .
This can be analytically achieved when the input distribution  p θ p_{\theta}  belongs to an exponential family and  q ψ q_{\psi}  belongs to its conjugate family. 
 
 
 Suppose that  x ∈ 𝒳 ⊆ ℝ k x\in\mathcal{X}\subseteq\mathbb{R}^{k}  and 
 

 
 
 p θ ​ ( x ) = h ⁡ ( x ) ​ exp ⁡ ( θ ⋅ u ⁡ ( x ) − A ⁡ ( θ ) ) , \displaystyle p_{\theta}(x)=h(x)\exp\left(\theta\cdot u(x)-A(\theta)\right), 
 
 (4.19) 
 
 where  u ⁡ ( x ) : 𝒳 → ℝ n u(x)\colon\mathcal{X}\to\mathbb{R}^{n}  and  h : 𝒳 → ℝ h\colon\mathcal{X}\to\mathbb{R}  , and  A ⁡ ( θ ) A(\theta)  is a logarithm of the normalization constant defined by 
 

 
 
 A ( θ ) = log ∫ h ( x ) exp ( θ ⋅ u ( x ) ) d x . \displaystyle A(\theta)=\log\int h(x)\exp\left(\theta\cdot u(x)\right)\mathrm{d}x. 
 
 (4.20) 
 
 We also assume that  q ψ q_{\psi}  belongs to the conjugate family of  p θ p_{\theta} : 
 

 
 
 q ψ ​ ( θ ) = exp ⁡ ( ν ​ ϕ ⋅ θ − ν ​ A ​ ( θ ) − B ⁡ ( ϕ , ν ) ) , \displaystyle q_{\psi}(\theta)=\exp\left(\nu\phi\cdot\theta-\nu A(\theta)-B(\phi,\nu)\right), 
 
 (4.21) 
 
 where  ν ∈ ℝ \nu\in\mathbb{R} ,  ψ = ( ϕ , ν ) ∈ ℝ k × ℝ \psi=(\phi,\nu)\in\mathbb{R}^{k}\times\mathbb{R} , and  B ⁡ ( ϕ , ν ) B(\phi,\nu)  is the logarithm of the normalization constant defined by 
 

 
 
 B ( ϕ , ν ) = log ∫ exp ( ν ϕ ⋅ θ − ν A ( θ ) ) d θ . \displaystyle B(\phi,\nu)=\log\int\exp\left(\nu\phi\cdot\theta-\nu A(\theta)\right)\mathrm{d}\theta. 
 
 (4.22) 
 
 
 
 Proposition 7 . 
 
 For the exponential family and its conjugate,  ∂ log ⁡ ℙ F ​ ( x ) ∂ ψ \frac{\partial\log\mathbb{P}_{\mathrm{F}}(x)}{\partial\psi}  is analytically represented as 
 

 
 
 
 ∂ log ⁡ ℙ F ​ ( x ) ∂ ϕ = 𝔼 q ψ ′ ​ ( θ ) ​ [ ν ′ ​ θ ] − 𝔼 q ψ ​ ( θ ) ​ [ ν ​ θ ] , \displaystyle\frac{\partial\log\mathbb{P}_{\mathrm{F}}(x)}{\partial\phi}=\mathbb{E}_{q_{\psi^{\prime}}(\theta)}\left[{\nu^{\prime}\theta}\right]-\mathbb{E}_{q_{\psi}(\theta)}\left[{\nu\theta}\right], 
 
 (4.23) 
 
 
 
 ∂ log ⁡ ℙ F ​ ( x ) ∂ ν = 𝔼 q ψ ′ ​ ( θ ) ​ [ ϕ ′ ⋅ θ − A ⁡ ( θ ) ] − 𝔼 q ψ ​ ( θ ) ​ [ ϕ ⋅ θ − A ⁡ ( θ ) ] . \displaystyle\frac{\partial\log\mathbb{P}_{\mathrm{F}}(x)}{\partial\nu}=\mathbb{E}_{q_{\psi^{\prime}}(\theta)}\left[{\phi^{\prime}\cdot\theta-A(\theta)}\right]-\mathbb{E}_{q_{\psi}(\theta)}\left[{\phi\cdot\theta-A(\theta)}\right]. 
 
 (4.24) 
 
 where  ψ ′ = ( ϕ ′ , ν ′ ) \psi^{\prime}=(\phi^{\prime},\nu^{\prime})  and 
 

 
 
 
 ϕ ′ = ν ​ ϕ + u ⁡ ( x ) ν + 1 , \displaystyle\phi^{\prime}=\frac{\nu\phi+u(x)}{\nu+1}, 
 
 (4.25) 
 
 
 
 ν ′ = ν + 1 . \displaystyle\nu^{\prime}=\nu+1. 
 
 (4.26) 
 
 Moreover, if we parameterize  q ψ q_{\psi}  by the expectation parameter, 
 

 
 
 η ⁡ ( ψ ) = ( 𝔼 q ψ ​ ( θ ) ​ [ ν ​ θ ] , 𝔼 q ψ ​ ( θ ) ​ [ ϕ ⋅ θ − A ⁡ ( θ ) ] ) ⊤ , \displaystyle\eta(\psi)=(\mathbb{E}_{q_{\psi}(\theta)}\left[{\nu\theta}\right],\mathbb{E}_{q_{\psi}(\theta)}\left[{\phi\cdot\theta-A(\theta)}\right])^{\top}, 
 
 (4.27) 
 
 the natural gradient is calculated as follows  [ 37 ] : 
 

 
 
 
 ∇ η ϕ ​ log ​ ℙ F ​ ( x ) = 𝔼 q ψ ′ ​ ( θ ) ​ [ ν ′ ​ θ ] − 𝔼 q ψ ​ ( θ ) ​ [ ν ​ θ ] , \displaystyle\nabla_{\eta_{\phi}}\log\mathbb{P}_{\mathrm{F}}(x)=\mathbb{E}_{q_{\psi^{\prime}}(\theta)}\left[{\nu^{\prime}\theta}\right]-\mathbb{E}_{q_{\psi}(\theta)}\left[{\nu\theta}\right], 
 
 (4.28) 
 
 
 
 ∇ η ν ​ log ​ ℙ F ​ ( x ) = 𝔼 q ψ ′ ​ ( θ ) ​ [ ϕ ′ ⋅ θ − A ⁡ ( θ ) ] − 𝔼 q ψ ​ ( θ ) ​ [ ϕ ⋅ θ − A ⁡ ( θ ) ] . \displaystyle\nabla_{\eta_{\nu}}\log\mathbb{P}_{\mathrm{F}}(x)=\mathbb{E}_{q_{\psi^{\prime}}(\theta)}\left[{\phi^{\prime}\cdot\theta-A(\theta)}\right]-\mathbb{E}_{q_{\psi}(\theta)}\left[{\phi\cdot\theta-A(\theta)}\right]. 
 
 (4.29) 
 
 The proof is given in Section  C.2 . 
 
 
 
 
 4.6  Remark on the Space Where Fisher Information Matrix Is Defined 

 
 In equations ( 4.28 ), the Fisher information matrix is defined by ( 2.9 ).
However, we have another choice of the Fisher information matrix based on  ℙ F \mathbb{P}_{\mathrm{F}} : 
 

 
 
 ℐ ⁡ [ ℙ F ​ ( x ) ] = 𝔼 ℙ F ​ ( x ) ​ [ ∂ log ⁡ ℙ F ​ ( x ) ∂ ψ ​ ∂ log ⁡ ℙ F ​ ( x ) ∂ ψ ⊤ ] . \displaystyle\mathcal{I}\left[{\mathbb{P}_{\mathrm{F}}(x)}\right]=\mathbb{E}_{\mathbb{P}_{\mathrm{F}}(x)}\left[{\frac{\partial\log\mathbb{P}_{\mathrm{F}}(x)}{\partial\psi}\frac{\partial\log\mathbb{P}_{\mathrm{F}}(x)}{\partial\psi}^{\top}}\right]. 
 
 (4.30) 
 
 For some cases (e.g. Section  5.1 ), this Fisher information matrix leads to an easier update rule.
Let us compare these two definitions of the natural gradient. As discussed in  [ 2 ] , the natural gradient is characterized by the following variational problem.
For any distribution  p p , we have 
 

 
 
 ℐ ​ [ p ] − 1 ​ ∂ ℱ W ∂ ψ = lim ϵ → 0 argmax δ ​ p [ ℱ W ​ ( ψ + δ ​ p ) ] , \displaystyle\mathcal{I}\left[{p}\right]^{-1}\frac{\partial\mathcal{F}_{W}}{\partial\psi}=\lim_{\epsilon\to 0}\operatornamewithlimits{argmax}_{\delta p}\left[\mathcal{F}_{W}(\psi+\delta p)\right], 
 
 (4.31) 
 
 where  δ ​ p \delta p  satisfies  𝒟 KL ​ ( p ∣ p + δ ​ p ) = ϵ \mathcal{D}_{\mathrm{KL}}(p\mid p+\delta p)=\epsilon .
Thus, the natural gradient is the direction where the objective function increases the most when we measure the "distance" by the KL divergence.
Under this interpretation, the natural gradient with  ℐ ​ [ q ψ ​ ( θ ) ] \mathcal{I}\left[{q_{\psi}(\theta)}\right]  is the direction to which the objective function increases the most when the distance is measured by  𝒟 KL ​ ( q ψ ​ ( θ ) ∣ q ψ + δ ​ ψ ​ ( θ ) ) \mathcal{D}_{\mathrm{KL}}(q_{\psi}(\theta)\mid q_{\psi+\delta\psi}(\theta)) .
On the other hand, the natural gradient with  ℐ ​ [ ℙ F ​ ( x ) ] \mathcal{I}\left[{\mathbb{P}_{\mathrm{F}}(x)}\right]  is the direction to which the objective function increases the most when the distance is measured by  𝒟 KL ​ ( ℙ F ​ ( x ∣ ψ ) ∣ ℙ F ​ ( x ∣ ψ + δ ​ ψ ) ) \mathcal{D}_{\mathrm{KL}}(\mathbb{P}_{\mathrm{F}}(x\mid\psi)\mid\mathbb{P}_{\mathrm{F}}(x\mid\psi+\delta\psi)) .
We also note that the Fisher information matrix of  ℙ F ​ ( x , θ ) \mathbb{P}_{\mathrm{F}}(x,\theta)  is the same as that of  q ψ ​ ( θ ) q_{\psi}(\theta) : 
 

 
 
 ℐ ⁡ [ ℙ F ​ ( x , θ ) ] = 𝔼 ℙ F ​ ( x , θ ) ​ [ ∂ log ⁡ ℙ F ​ ( x , θ ) ∂ ψ ​ ∂ log ⁡ ℙ F ​ ( x , θ ) ∂ ψ ⊤ ] = ℐ ⁡ [ q ψ ​ ( θ ) ] . \displaystyle\mathcal{I}\left[{\mathbb{P}_{\mathrm{F}}(x,\theta)}\right]=\mathbb{E}_{\mathbb{P}_{\mathrm{F}}(x,\theta)}\left[{\frac{\partial\log\mathbb{P}_{\mathrm{F}}(x,\theta)}{\partial\psi}\frac{\partial\log\mathbb{P}_{\mathrm{F}}(x,\theta)}{\partial\psi}^{\top}}\right]=\mathcal{I}\left[{q_{\psi}(\theta)}\right]. 
 
 (4.32) 
 
 Therefore, we have two options for the distance measure of probability distributions and the corresponding Fisher metric, and we should choose the one that is best suited to the problem under consideration. 
 
 
 
 4.7  Approximation of Phenotype Gradient Estimator via Reparameterization Trick 

 
 Most OIU problems may not fall within the case of Section  4.5 .
To cover a wider range of problems, approximation methods to calculate the phenotype gradient estimator are crucial.
We derive it by the application of the reparameterization trick. 
 
 
 Let us assume that  θ \theta  is decided deterministically from some noise:  θ = β ψ ​ ( ξ ) \theta=\beta_{\psi}(\xi) , where  ξ \xi  follows a distribution  q ⁡ ( ξ ) q(\xi)  and  β ψ ​ ( ⋅ ) \beta_{\psi}(\cdot)  is a deterministic function.
A typical example is Gaussian input noise:  ξ ∼ N ⁡ ( ξ ∣ 𝟎 , 𝐈 ) \xi\sim N\left({\xi}\mid{\bm{0}},{\mathbf{I}}\right)  and  β ψ ​ ( ξ ) = θ ¯ + σ ​ ξ \beta_{\psi}(\xi)=\bar{\theta}+\sigma\xi , where  ψ = ( θ ¯ , σ ) \psi=(\bar{\theta},\sigma) .
In this setting, the expectation  ℱ W \mathcal{F}_{W}  of the objective function becomes 
 

 
 
 ℱ ⁡ ( ψ ) = 𝔼 q ⁡ ( ξ ) ​ [ 𝔼 p β ψ ​ ( ξ ) ​ ( x ) ​ [ W ⁡ ( f ⁡ ( x ) ) ] ] . \displaystyle\mathcal{F}(\psi)=\mathbb{E}_{q(\xi)}\left[{\mathbb{E}_{p_{\beta_{\psi}(\xi)}(x)}\left[{W(f(x))}\right]}\right]. 
 
 (4.33) 
 
 Then, we can calculate the gradient as 
 

 
 
 ∂ ℱ W ∂ ψ = 𝔼 q ⁡ ( ξ ) ​ [ ∂ β ψ ​ ( ξ ) ∂ ψ ​ [ ∂ ∂ θ ​ 𝔼 p θ ​ ( x ) ​ [ W ⁡ ( f ⁡ ( x ) ) ] ] θ = β ψ ​ ( ξ ) ] . \displaystyle\frac{\partial\mathcal{F}_{W}}{\partial\psi}=\mathbb{E}_{q(\xi)}\left[{\frac{\partial\beta_{\psi}(\xi)}{\partial\psi}\left[\frac{\partial}{\partial\theta}\mathbb{E}_{p_{\theta}(x)}\left[{W(f(x))}\right]\right]_{\theta=\beta_{\psi}(\xi)}}\right]. 
 
 (4.34) 
 
 By applying the log-derivative trick to the inner expectation, we have 
 

 
 
 ∂ ℱ W ∂ ψ = 𝔼 q ⁡ ( ξ ) ​ [ ∂ β ψ ​ ( ξ ) ∂ ψ ​ 𝔼 p θ ​ ( x ) ​ [ W ⁡ ( f ⁡ ( x ) ) ​ [ ∂ log ⁡ p θ ​ ( x ) ∂ θ ] θ = β ψ ​ ( ξ ) ] ] . \displaystyle\frac{\partial\mathcal{F}_{W}}{\partial\psi}=\mathbb{E}_{q(\xi)}\left[{\frac{\partial\beta_{\psi}(\xi)}{\partial\psi}\mathbb{E}_{p_{\theta}(x)}\left[{W(f(x))\left[\frac{\partial\log p_{\theta}(x)}{\partial\theta}\right]_{\theta=\beta_{\psi}(\xi)}}\right]}\right]. 
 
 (4.35) 
 
 By approximating the right hand side by samples, we have the following gradient estimator: 
 

 
 
 ∂ ∂ ψ ¯ r ​ ℱ W = 1 N ​ ∑ i = 1 N ∂ β ψ ​ ( ξ i ) ∂ ψ ​ W ​ ( f ⁡ ( x i ) ) ​ [ ∂ log ⁡ p θ ​ ( x i ) ∂ θ ] θ = β ψ ​ ( ξ i ) . \displaystyle\overline{\frac{\partial}{\partial\psi}}^{\mathrm{r}}\mathcal{F}_{W}=\frac{1}{N}\sum_{i=1}^{N}\frac{\partial\beta_{\psi}(\xi_{i})}{\partial\psi}W(f(x_{i}))\left[\frac{\partial\log p_{\theta}(x_{i})}{\partial\theta}\right]_{\theta=\beta_{\psi}(\xi_{i})}. 
 
 (4.36) 
 
 This estimator is not Rao-Blackwellized since it contains irrelevant random variables  ξ i \xi_{i}  on the right hand side, which are not deterministically decided by  ψ \psi  and  x x .
However, the dependency on  ξ \xi  is very weak in some cases.
We will see an example in Section  5.3 .

 6.2.2  Performance evaluation 

 
 Since the performance of ES and PAES may depend on the hyperparameters  σ \sigma  and  S = ∑ a ∈ 𝒜 α a , s S=\sum_{a\in\mathcal{A}}\alpha_{a,s}  respectively, we ran each algorithm with different random seeds and hyperparameters.
We measure the performance of the algorithm at each step by the cumulative reward of the updated policy, which is obtained by normalizing the parameters  α s \alpha_{s}  of the Dirichlet distribution for PAES and directly from the Q-table for ES.
This evaluation of the reward is different from the evaluation of the cumulative rewards in the population in that we make the policy deterministic by taking the action with highest probability for each state.
Figure  6.3  (a) shows the learning curves of each algorithm for the best hyperparameter setting, where the vertical axis shows the cumulative reward of the updated policy.
Here, we choose the best hyperparameter setting for each algorithm by the speed of convergence of the cumulative reward and stability of the learning curve (see Appendix  E.1  for details).
Although we run the experiment until  500 500  generations, we show only the first  250 250  generations for better visibility.
PAES converges to a high cumulative reward of the updated policy faster than ES.
Figure  6.3  (b,c) shows the sensitivity of the cumulative reward of the updated policy at the last  50 50  generations to the hyperparameters.
We observe that the performance of ES is better when the  σ \sigma  is no less than  0.1 0.1 , which means that the variance of the population is large.
On the other hand, the performance of PAES is better when  S S  is smaller than  1 1 , which means that the variance of the population is large like ES.
The comparison of computation time is provided in Appendix  E.2 , where PAES converges faster than ES in terms of wall-clock time as well.

 6.3  Reinforcement Learning (Reparameterization Trick Approximation) 

 
 We evaluate the performance of PAES for more complex RL tasks by applying the reparameterization trick approximation of the phenotype gradient estimator ( 5.14 ).
In the following, we present learning curves in terms of generations.
The comparison of computation time is provided in Appendix  E.2 , where the learning curves are similar to those in the main text. 
 
 
 6.3.1  CartPole 

 
 We apply the approximated PAES with reparameterization trick to the CartPole-v1 environment  [ 50 ] .
We note that the PAES with the exact Rao-Blackwellization  ( 5.9 ) is not applicable to this environment because the state space is continuous.
The maximum step for each episode is set to  500 500 , which is equal to the maximum reward for each episode.
We introduce early stopping when the mean reward of the population reaches  475 475 .
The policy is represented by a three-layer neural network with  32 32  hidden units with the  t ​ a ​ n ​ h tanh  activation function.
The final layer outputs the action probabilities by applying the softmax function.
The policy is initialized by the Xavier initialization  [ 14 ] .
We add Gaussian noise with standard deviation  σ = 0.1 \sigma=0.1  to the policy parameters.
The population size is set to  100 100 .
We optimize the policy by Adam with learning rate  0.001 0.001 ,  β 1 = 0.9 \beta_{1}=0.9 ,  β 2 = 0.999 \beta_{2}=0.999  for both ES and PAES.
We define the weighting function  W W  by using the cumulative reward  r i r_{i}  of each policy in the population as follows: 
 

 
 
 W ⁡ ( r i ) = rank ⁡ ( r i ) N − 1 − 1 2 , \displaystyle W(r_{i})=\frac{\mathrm{rank}(r_{i})}{N-1}-\frac{1}{2}, 
 
 (6.5) 
 
 where  rank ⁡ ( r i ) ∈ { 0 , 1 , … , N − 1 } \mathrm{rank}(r_{i})\in\{0,1,\ldots,N{-}1\}  is the zero-indexed rank of  r i r_{i}  among  { r 1 , … , r N } \{r_{1},\ldots,r_{N}\} .

For ES, we use antithetic sampling, which is a common variance reduction technique for ES  [ 44 ] .
To apply the update rule of PAES ( 5.14 ), we collect the empirical count  j ⁡ ( a , s ) j(a,s)  of each policy in the population and then compute the gradient of the original policy by back-propagating the gradient  ( 5.14 ) to the network.

 6.3.2  Pendulum 

 
 Next, we evaluate the performance of PAES for the Pendulum-v1 environment  [ 50 ] , where both state and action spaces are continuous.
The policy is represented by a three-layer MLP with  64 64  hidden units with the  t ​ a ​ n ​ h tanh  activation function, which directly outputs the continuous action.
When we generate a population in both ES and PAES, the policy parameters  θ \theta  are perturbed by Gaussian noise with standard deviation  σ \sigma .
Here, the value of  σ \sigma  starts from  0.05 0.05  and linearly decays to  0.01 0.01  over  3000 3000  generations.
In addition, for PAES, we add Gaussian noise with standard deviation  σ \sigma  to the action output of the policy.
This noise corresponds to the phenotypic noise in PAES and accelerates exploration in the action space.
For ES, we found that adding noise to the action worsens the performance (results not shown), and thus we show the result without adding noise to actions.
We set the threshold for early stopping to  − 200 -200 .
The other settings are the same as those in CartPole-v1. 
 
 
 Figure  6.4  (b) shows the learning curves of ES and PAES.
The vertical axis shows the deterministic reward of the updated policy, which is evaluated by not adding the action noise to the policy.
The result shows that PAES converges faster than ES in terms of generations. 
 
 
 
 6.3.3  Swimmer 

 
 Finally, we evaluate the performance of PAES in the Swimmer-v5 environment  [ 50 ] , which is a more complex continuous control environment.
The setting is the same as those in Pendulum-v1, except for the following points.
The standard deviation  σ \sigma  of the noise added to policies  t ​ h ​ e ​ t ​ a theta  and actions starts from  0.2 0.2  and linearly decays to  0.05 0.05  over  5000 5000  generations.
We added larger noise because, with smaller noise starting from  σ = 0.05 \sigma=0.05 , both ES and PAES failed to find a successful policy within  5000 5000  generations for about half of the seeds.
This is reasonable because the Swimmer environment is known to have many local minima, and thus exploration is necessary to find the successful policy.
We balance exploration and stability after convergence by tuning the standard deviation  σ \sigma  of the noise. 
 
 
 Figure  6.4  (c) shows the learning curves of ES and PAES for Swimmer-v5.
PAES converges faster than ES in terms of generations, demonstrating that phenotypic information can also accelerate learning in complex continuous control environments.

 7  Conclusion 

 
 In this paper, we have investigated the question of whether the realization of the input is useful to accelerate the ES in OIU problems.
We showed that the acceleration of the ES is achieved by PAES in which the phenotype gradient estimator utilizes the information of input realization, i.e., phenotype information.
Then, we generalized this result by clarifying that the acceleration is achieved by Rao-Blackwellization, which reduces the variance of the gradient estimation by utilizing the realization of the input.
We also provide both analytical forms and an approximation of the phenotype gradient estimator in PAES to cover a variety of problems.
Numerical experiments demonstrated the superiority of PAES, which is consistent with our theoretical results.
PAES achieves faster convergence than ES from simple optimization to more complex RL benchmarks.
We found that the computation time of PAES is comparable to that of ES, which means that PAES is more efficient than ES even in terms of wall-clock time.
Furthermore, to obtain finer gradient estimators, PAES could be combined with several other techniques for RL, such as the baseline control  [ 15 ] . 
 
 
 A limitation of PAES is that it requires the input distribution to be in some well-behaved class to calculate the phenotype gradient analytically.
To apply PAES to a broader class of problems, we need to develop an approximation method for the phenotype gradient estimator.
A possible approach is to use the phenotypic information to imitate the input  x x  with a higher objective value in the population.
Indeed, the phenotype gradient estimator for the Gaussian OIU problem ( 5.4 ) can be interpreted as imitating the input  x x  with a higher objective value in the population.
In addition, the reparameterization trick ( 5.14 ) employed for RL can be regarded as imitating the action of agents with a higher reward in the population.
These results indicate that imitation of the ancestors with a higher objective value in the population can accelerate the ES, even though it may not necessarily be represented as Rao-Blackwellization. 
 
 
 The application of OIU has been expanding from classical examples of manufacturing to robotics and RL.
Another application of OIU would be Large Language Models, in which the stochastic output is guided by optimizing prompts and context information fed to LLM.
This expansion indicates possible broad applications of this paper.
Moreover, there are several solutions to OIU: ES, gradient-based methods, and Bayesian optimization.
Although we focused only on ES and its extension PAES, a similar idea may be applicable to other solutions.
For such directions, the observation that Rao-Blackwellization via the realization of the input resembles imitation learning might be useful to construct improved algorithms.

 Appendix A  Related Work to OIU and PAES 

 
 ES  [ 41 ]  is applied to a broad class of problems, especially when the gradient of the objective function is not available.
ES represents the population as a probability distribution and aims to maximize the expected value of the objective function over population.
The expected value is maximized via the stochastic gradient ascent, where the gradient is estimated by using the samples of objective values in the population.
Variants of ES, such as CMA-ES  [ 19 ;  18 ] , Natural Evolution Strategy (NES)  [ 52 ] , and Information Geometric Optimization (IGO)  [ 37 ]  are widely applied to various problems and have high performance on benchmark functions  [ 17 ;  43 ] .
In the context of black-box optimization, ES is also called zeroth-order optimization (ZOO), and its properties such as convergence rate and sample complexity have been studied  [ 35 ;  11 ;  47 ;  10 ;  55 ] .
In this paper, we improve ES for OIU by tapping into the information of realized input  x x . 
 
 
 Variance reduction techniques for gradient estimation have been studied in various contexts of machine learning.
One technique is Rao-Blackwellization, in which we can reduce the variance of estimator by taking conditional expectation with respect to irrelevant variable.
Rao-Blackwellization is applied to variational inference  [ 45 ;  39 ;  26 ] , the estimation of the gradient of discrete variables  [ 56 ;  29 ] , and the construction of action-dependent baselines for policy gradient methods  [ 53 ] .
Another technique is the reparameterization trick (also known as stochastic backpropagation  [ 42 ] ), which, for a compositional objective function, computes some part of the objective function analytically and then estimates the gradient of the other part by sampling.
The reparameterization trick is empirically shown to have a smaller variance  [ 46 ;  31 ]  and
theoretical analysis is provided for some idealized cases  [ 54 ] .
The reparameterization trick is also applied to the variational auto encoder  [ 25 ] , and variational inference  [ 26 ] . 
 
 
 
 Appendix B  Contextual Optimization under Input Uncertainty (COIU) 

 
 As an extension of OIU, we also define a  Contextual Optimization under Input Uncertainty  (COIU).
At each trial, we are given a context  c ∈ 𝒞 c\in\mathcal{C}  which is drawn from some distribution  ν ⁡ ( c ) \nu(c) .
For each  θ ∈ Θ \theta\in\Theta , we define a conditional probability distribution  p θ ​ ( x ∣ c ) p_{\theta}(x\mid c)  on  𝒳 \mathcal{X} .
For a function  f : 𝒳 × 𝒞 → ℝ f\colon\mathcal{X}\times\mathcal{C}\to\mathbb{R} , the objective function is given by 
 

 
 
 F ⁡ ( θ ) := 𝔼 ν ⁡ ( c ) ​ [ 𝔼 p θ ​ ( x ∣ c ) ​ [ f ⁡ ( x , c ) ] ] . \displaystyle F(\theta):=\mathbb{E}_{\nu(c)}\left[{\mathbb{E}_{p_{\theta}(x\mid c)}\left[{f(x,c)}\right]}\right]. 
 
 (B.1) 
 
 
 
 B.1  Examples of the Problem 

 
 B.1.1  Mixture of Experts 

 
 Let us consider a classification problem.
We are given a context  c c  that follows a distribution  ν ⁡ ( c ) \nu(c) , and we need to output the corresponding label in a discrete set  𝒳 \mathcal{X} .
The loss function is  f ⁡ ( c , x ) f(c,x) .
One solution to this classification problem is MoE.
Assume that we have a set of experts  ϕ = { ϕ i } i = 1 k \phi=\{\phi_{i}\}_{i=1}^{k} , each of which defines a distribution  π ϕ i ​ ( x ∣ c ) \pi_{\phi_{i}}(x\mid c)  over the output labels.
In MoE, we first choose an expert  i i  with probability  α ⁡ ( i ∣ c , ρ ) \alpha(i\mid c,\rho) , where  ρ \rho  is a parameter.
Then, the chosen expert outputs a label with probability  π ϕ i ​ ( x ∣ c ) \pi_{\phi_{i}}(x\mid c) .
Our aim is to optimize each experts  ϕ \phi  and the choice rule  ρ \rho  of experts to minimize the expected loss.
The expected loss when we choose the  i i -th expert is given by 
 

 
 
 F ⁡ ( i ) = 𝔼 ν ⁡ ( c ) ​ [ 𝔼 π θ i ​ ( x ∣ c ) ​ [ f ⁡ ( c , x ) ] ] . \displaystyle F(i)=\mathbb{E}_{\nu(c)}\left[{\mathbb{E}_{\pi_{\theta_{i}}(x\mid c)}\left[{f(c,x)}\right]}\right]. 
 
 (B.2) 
 
 Therefore, the optimization of  ϕ i \phi_{i}  is formulated in the framework of ( B.1 ).
The expected loss when we choose exert stochastically from  α ⁡ ( i ∣ c , ρ ) \alpha(i\mid c,\rho)  is 
 

 
 
 F ⁡ ( ϕ , ρ ) = 𝔼 ν ⁡ ( c ) ​ [ 𝔼 π θ i ​ ( x ∣ c ) ​ α ​ ( i ∣ c , ρ ) ​ [ f ⁡ ( c , x ) ] ] . \displaystyle F(\phi,\rho)=\mathbb{E}_{\nu(c)}\left[{\mathbb{E}_{\pi_{\theta_{i}}(x\mid c)\alpha(i\mid c,\rho)}\left[{f(c,x)}\right]}\right]. 
 
 (B.3) 
 
 In Section  B.2.1 , we will solve MoE by ES and see that  α ⁡ ( i ∣ c , ρ ) \alpha(i\mid c,\rho)  corresponds to a population distribution of ES and the expected loss to  ℱ \mathcal{F}  in ( 2.3 ). 
 
 
 
 B.1.2  Classification with Bandit Feedback 

 
 We consider a classification problem with bandit feedback  [ 24 ] .
The classification problem is the same setting as the previous subsection.
We note that this setting is different from the usual classification problems in that we do not know the correct class for  c c .
Suppose that we have a stochastic classification algorithm  π θ ​ ( x ∣ c ) \pi_{\theta}(x\mid c) , which is a conditional probability distribution on  𝒳 \mathcal{X}  given  c c .
The expected loss is given by 
 

 
 
 F ⁡ ( θ ) = 𝔼 ν ⁡ ( c ) ​ [ 𝔼 π θ ​ ( x ∣ c ) ​ [ f ⁡ ( c , x ) ] ] . \displaystyle F(\theta)=\mathbb{E}_{\nu(c)}\left[{\mathbb{E}_{\pi_{\theta}(x\mid c)}\left[{f(c,x)}\right]}\right]. 
 
 (B.4) 
 
 By setting 
 

 
 
 p θ ​ ( x ) = π θ ​ ( x ∣ c ) , \displaystyle p_{\theta}(x)=\pi_{\theta}(x\mid c), 
 
 (B.5) 
 
 the expected value of the feedback is formulated in the framework of COIU ( B.1 ).

 Appendix E  Additional Details of Reinforcement Learning Experiments 

 
 E.1  Hyperparameter Sensitivity for FrozenLake-v1 

 
 We provide the sensitivity of learning curve of FrozenLake-v1 to the hyperparameters  σ \sigma  for ES and  S = ∑ a ∈ 𝒜 α a , s S=\sum_{a\in\mathcal{A}}\alpha_{a,s}  for PAES.
We observe that the speed of convergence of ES is faster when  σ \sigma  is no less than  0.1 0.1  (Figure  E.1  (a)).
The speed of convergence of PAES is faster when  S S  is smaller than  1 1 , but the final reward decreases when  S S  is too small (Figure  E.1  (b)).
Also, the learning curve fluculates after reaching high cumulative reward ( ≈ 0.8 \approx 0.8 ) when  S S  is too small ( S < 1 S<1 ) (Figure  E.1  (b)). 
 
 
 We note that the Fisher information matrix for the Dirichlet distribution depends on  S S  even though the ratio of  α a , s \alpha_{a,s}  is fixed.
It means that we need to change the learning rate depending on  S S  or use natural gradient to compare the speed of convergence for different  S S  more accurately.
However, changing the learning rate and using natural gradient obscure the effect of  S S  on the learning curve.
In this paper, we focus on the effect of the hyperparameter  S S  on the learning curve, and we do not change the learning rate dependending on  S S .
