# Independent original: audit-corrected trace credit for a search-policy improver

2026-10-22. No current peer proposals read. This is one mechanism candidate and at most one substantive repair, not a new architecture. Historical literal gradient recombination is excluded. Source, biological outcomes and paper performance are not assumed.

## Intended drug-discovery operation
A distribution q_psi over improvement policies is inherited. Each sampled policy theta starts from the same base intervention model, chooses a bounded sequence of model/agent edits and actual assay requests, and obtains terminal functional improvement R. Its full logged trace H includes requested actions, returned intervention-response measurements, rejected candidates, and final selected program; Z is a cheaper compression of H. Update psi, not the final world's parameters, from these feedback traces. Later tests reset every arm to the same fresh world/agent start and compare how efficiently old/new q find a successful new edit under all training, assay, proposal and inference costs.

New primary source: Nakashima and Kobayashi, PAES, arXiv2608.02073v1 (2026-08-03), authenticated API metadata and complete HTML. Section4.4 conditions ES score on realized input; Section5.2 gives exact action-count posterior for Dirichlet policies; AppendixB includes context and bandit feedback. Main technical source is actually read, not inferred from title. It directly motivates replacing noisy policy-genotype credit R*s(theta) by R*E[s(theta)|H]. This is a strong nearest baseline, not a claimed MAESTRO invention.

## Biological obstacle and first proposed operation
Destructive molecular assays on parallel wells reveal a partial response Z, not the complete functional realization. Function need not be measurable from RNA/marker Z; toxicity, cell contact or rare resistant subpopulations may remain hidden. A cheap world posterior m(Z)=E[s(theta)|Z] gives g0=R*m(Z). Merely observing a real molecular trace does NOT guarantee this is an unbiased search-gradient estimator. Exact bias is -E[Cov(R,s(theta)|Z)]. Test this before any learning.

The substantive repair considered once is randomized full-trace credit audit. For each trace, compute cheap g0. Independently audit its expensive full posterior credit gH with probability a(Z,R)>0, chosen before that audit. Return gA=g0+A/a*(gH-g0). Its conditional mean equals gH, hence retains the complete-trace estimator's validity. Learn a from previous source feedback residual squares to minimize variance for a fixed expected posterior-inference budget; no new wet assay is implied by an inference audit. Full trajectories must actually be retained. Missing physical measurements cannot be created by replay. If required observations were never acquired, they must be separately paid and logged, and the present computation-only formula does not apply.

Minimal cost allocation with exact residual second moment d2(x) is a(x)=min(1,sqrt(d2(x)/(lambda*c_exact(x)))); positive support is retained unless zero residual is independently certified. This is the mathematical operation under test, and parameterizing a changes evaluation of future improver updates. The causal world need not be exactly true, but using a misspecified full posterior can still bias gH. A simulator's likelihood is not automatically the biological likelihood.

## Faithful conventional comparators and novelty criterion
(1) genotype ES R*s(theta); (2) exact PAES/conditional Monte Carlo gH; (3) cheap trace substitution g0; (4) ordinary randomized two-level/control-variate estimator using the SAME g0, gH and a. Candidate4 is the strongest obvious reduction: if it matches the repair pointwise, this repair has no distinct operation relative to that conventional estimator. A finite advantage versus ES or full PAES may still be a useful computational tradeoff, and generic standard-primitive membership does not itself decide novelty. We require an actual differing useful estimator/objective/computational rule beyond the ordinary two-level implementation before promoting a new algorithm.

Known-policy action-history likelihoods can cancel environmental transitions even under partial observation, provided policies use the recorded history and do not alter physical measurement laws except through logged actions. In that case a world-model posterior may be unnecessary. A changed world only used as an internal planner does not make unknown physical transition likelihoods necessary. Conversely coarsening actions or outputs can break that cancellation. This distinction is a mechanistic test, not universal world-model nonnecessity.

## Frozen smallest falsifier
Exact Fraction enumeration, no stochastic sampling, no biological data. Sample theta in{0,1} at p=.5. Let z in{-1,+1}, w in{-1,0,+1}, P0(z,w)=.5*(.025,.95,.025). Set P(H|theta)=P0(H)*(1+(2theta-1)*(z/5+w/10)). Feedback R=1+w/2. All laws normalize and are positive. q-score s=+2/-2. Use full conditional score, z-only conditional score, audit a=1/10, and a cheap feedback-dependent audit (a=1/2 if R!=1 else1/100). Enumerate exact means and variances, pointwise candidate/conventional equality, and same-start one-step downstream expected utility. No synthetic result is empirical biological transfer. The synthetic law deliberately has missing function in the coarse trace. No superiority is inferred from arbitrary charged costs; all likelihood-posterior arithmetic and feedback support are reported.

Stop literal novelty if the candidate matches ordinary two-level correction and no different finite rule remains. Stop naive partial-trace update if its mean differs from exact derivative. Retain useful scoped computational possibilities without repeating old biological pilots. No protected reserve decoding or model fitting. No source self-edit requirement. Exact observation-law knowledge in this test is a convenience and not a proposed real-assay assumption.
