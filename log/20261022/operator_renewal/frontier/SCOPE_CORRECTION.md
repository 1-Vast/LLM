# Cross-bundle control scope correction

The sealed original allows R_q to include within-bundle shared controls, and the synthetic main audit uses .25 I + .1 11^T for each two-readout bundle. **Across those bundles the errors/controls are independent.** The ordinary batch reference explicitly builds a block-diagonal noise matrix. This limits the original exactness statement: per-bundle R_q alone is insufficient when distinct acquisitions reuse the same physical control. Both independent reviewers raised this legitimate boundary question.

For theta~N(0,1), y_i=theta+e_control+e_i with all three error variables independent N(0,1), and observed y1=y2=1, correct joint conditioning gives posterior mean 2/5, variance 3/5. Treating the reused control as fresh noise gives mean1/2, variance1/2, exaggerating the evidence. `check_shared_control.py` verifies the exact rational values in three assertions and preserves SHARED_CONTROL_RESULT.json. These are synthetic calculations, not assay measurements.

An exact implementation must group all correlated readouts into a joint likelihood, retain the reused control error in the compressed latent state, or equivalently use conditional future noise/cross-covariances given the acquired observations. If the actual control reuse pattern is unqualified, a biological exactness claim is not permitted. This correction narrows the stated tested domain and does not add a second candidate revision. The ordinary cached joint Gaussian/GP already supplies the same correct operation and dimension. NO_PROMOTION of the candidate is unchanged.
