## Functional contrast/assay closure

The operation is mathematically coherent for a fixed jointly Gaussian world and finite linear assay menu, and unlike a transcription-persistence projection it explicitly preserves function-informative noisy directions and correlated reporters. No universal cell-state identification or same-cell longitudinal assay is necessary to justify such a finite statistical posterior. Genetic sensitization remains an appropriate narrow application; it does not by itself establish small-molecule benefit or independent later patients. Cell/guide counts and effector ratios are not independent tasks.

The strongest concrete biological/statistical concern is **shared-control noise across successive paid bundles**. The original says R_q contains within-bundle covariance, including shared controls; that does not cover the covariance between q1 and q2 when both subtract or divide by the same physical control sample. For example, y1=theta+eta_c+eta1 and y2=theta+eta_c+eta2 have nonzero Cov(epsilon1,epsilon2)=Var(eta_c). Sequential marginal-noise Gaussian updates with R1,R2 separately can count the control information twice. Keeping every legal H row in Z closes latent linear signals but does not automatically keep the random control errors. Either the legal menu must bundle all measurements sharing controls, the control noise must be part of the retained joint state, or the second update must use correctly conditioned cross-noise. Each can be conventional and exact; the current declaration does not determine which applies.

This is not a demand that all screens be independent. It is a necessary condition for the claimed exact online reduction on real shared-control assays. One minimal falsifier is the above scalar shared-control example: compare full joint Gaussian posterior to the specified sequential compressed update. Explicitly charge the union of control samples and show whether the corrected optimized ordinary implementation has the same dimensions/update cost. If all contrasts/assay rows number almost p or dense cross-covariance storage dominates, nominal projection does not establish compute reduction.

A fixed menu can be a useful world/decision object even if cached Gaussian conditioning implements it exactly. Since the original already identifies that precise conventional competitor, I support its bounded algebra/cost audit and do not support biological/core promotion without an additional finite difference. Source-fitted covariance, calibration, legally purchasable molecular/functional bundles and withheld utility labels are still required. No negative conclusion about nonlinear functional worlds follows if this Gaussian specification ties.

## Audit-corrected trace credit

The original correctly separates destructive partial observations from complete functional realization. Randomized inference auditing can correct a cheap posterior-credit approximation when the complete-trace credit is itself valid and computable, with positive audit support and preaudit randomization. Reusing an already stored complete trace is computational work; collecting a missing cell response is a new physical experiment. The role explicitly preserves that distinction.

The main biological relevance gap is not the two-level estimator's algebra. It is the existence of an **expensive exact full-trace posterior credit that needs a cell world**. If all policy actions/histories and terminal R are retained and policies affect the environment only through logged actions, the policy-history likelihood can cancel the unknown environment, as the original itself states. Then gH may be computed without a virtual-cell likelihood. If molecular measurements were coarsened or missing and the world is used to integrate them out, the full biological observation law is generally unknown; a simulator posterior is not an unbiased biological credit oracle. More compute cannot fix missing functional measurements or model misspecification. R must be measurable in the conditioning trace (or explicitly appended), or Rao-Blackwell conditioning can still leave reward-score covariance.

The strongest question is therefore to identify one actual admissible trace/assay setting where H contains the required terminal function, exact gH is expensive but available, and the cell-world component is indispensable to that inference rather than an optional planner. The current finite toy can demonstrate bias repair and cost-sensitive variance reduction, not that empirical contract. If no such setting is qualified, retain a useful computation-only estimator with world/agent/RSI claims unestablished. Inherited audit allocation is an improvement-policy object in principle, but must improve later policy learning from the same fresh starts at equal source/later costs; merely decreasing the variance of a deliberately known toy score does not establish recursive discovery benefit.

The strongest ordinary same-information reduction is exactly the randomized two-level/control-variate correction already named. Pointwise equality would settle this literal operation's novelty without denying its utility. I support one exact audit and an honest scoped decision, not another biological pilot or a second rescue mechanism.

## Common task/cost boundary

The accessible Frangieh pooled screen can support retrospective within-model gene/family prediction. It does not presently qualify per-gene physical purchase, independent patient campaigns, fresh eight-round feedback, or absolute immune-killing rates. Separately published gene-level and guide-level contrasts from the same counts do not create extra measurements. Molecular feature access, guide grouping, control normalization and source-fit/calibration labels must be identical across candidate and optimized conventional counterparts.
