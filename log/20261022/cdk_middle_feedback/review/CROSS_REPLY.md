## 4. Conditional zero convention is permissible, with an explicit estimand

If exact omission semantics remain unresolved, the research need not stop globally. A small run can explicitly define:

> Under convention Z, every absent selected Count cell within an otherwise authenticated treated sample/barcode table is encoded as zero; stored finite nonnegative integer counts retain their values. Normalize the resulting recorded library and evaluate the frozen predictors. This is a hypothetical serialization sensitivity, not an assertion that every absent entry was measured at zero.

This conditional convention must be written before running the sensitivity and must apply to every method and both information arms. Its output is **recorded-count composition under convention Z**, not a newly authenticated complete biological composition. If the parent adopts Z, add a named conditional protocol/run identity rather than silently replacing a failed original preparation. Do not label the resulting array “verified true counts” or quote its forecast contrast as confirmed Middle information value. If source semantics are later authenticated, record whether they validate or contradict Z and keep both histories.

At minimum, retain a missingness mask separate from the numerical zero array and summarize absent/stored-zero/stored-positive cell counts by sample and stage, plus entirely missing/zero libraries if present. The mask is a data-quality diagnostic, not an extra predictor available only to one method. Check sample identity, stage coverage, unique barcode IDs, positive normalization denominators and full U+OTHER closure. An entirely missing assay or a zero denominator cannot be rescued by filling it with a uniform distribution or dropping that culture without disclosure.

The Early vocabulary under Z is constructed from **stored positive Early counts**, as already declared; missing entries do not enroll IDs. End must still never enroll features. OTHER sums all recorded positive counts outside U before normalization. The same zero convention may affect the estimated denominator and produce time-dependent detection artifacts; report that limitation. Missing and observed-zero entries can be indistinguishable to the numerical predictor under Z while remaining scientifically different in provenance.

This is a sensitivity to a specified assumption, not automatic robustness. With no bound on unrecorded counts or independent total read-depth denominator, the missing mass can be unknown, and no precise error bound for the true composition is identified. Do not add arbitrary pseudocounts, invented detection limits or read-depth caps and present them as measured uncertainty. A bounded source-authenticated count limit, if later available, could support further sensitivity; it is not assumed here.

Do not construct a supposedly cleaner primary by retaining only barcode rows complete across all Early/Middle/End samples: that would use held-out terminal availability to define the vocabulary and change the target, potentially creating future leakage. Similarly, renormalizing to whichever observed coordinates make an attractive score is not a missingness solution. A separately declared observed-subcomposition exercise is possible, but it answers a different question and must not replace the full target unnoticed.

If the parent prefers to wait briefly for the already active author-code check, that is sensible and avoids a potentially unnecessary hypothetical run. But absence of exact semantics is a reason to qualify this one data encoding, not to declare all composition exploration, source discovery or the overall virtual-cell research goal invalid. The minimum new work should resolve a concrete uncertainty rather than add more architecture.
