# Offline genomic-figure source check

2026-10-22. The public article explicitly reports genomic observations in
Fig5c and Extended Data Fig5; absence of a matching workbook sheet is not proof
that only FASTQ can supply state observations. Root registers an offline check
of these two original figure objects from the already retained official ZIP.

Project `graphic` references only for JATS ids Fig5 and Fig11 (the latter is
Extended Data Fig5), match their exact reference stems to ZIP basenames, and
inventory candidate image dimensions/hashes without interpreting measurements.
Extract at most one largest-pixel JPEG/PNG representation per target, retaining
original bytes under `log/20261022/chemical_genetics_qualification/graphics/`.
No network, other figures, supplementary PDF, model API or response workbook.
Use maestro `-B`; all source-check code stays in `research/`.

Root may then visually inspect each selected complete figure to determine
whether gene/allele and marginal frequency information is publicly legible.
All visible source outcomes and numbers become **published/designer-exposed**;
no claim of a sealed validation on these figures is permitted. No numerical
arrays are digitised, no state is imputed and no model is trained in this step.
Success is either a concrete lower-cost genomic source candidate or an exact
legibility/provenance limit. Image presence alone does not establish culture
joins, phased haplotypes, arbitrary action coverage or method utility.
