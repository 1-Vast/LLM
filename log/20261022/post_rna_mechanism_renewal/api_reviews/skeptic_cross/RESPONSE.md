## 一、先修正我自己的错误

我作为 skeptic 的首评有若干实质错误，必须收回或改写：

1. **CST 中“共享运输 T 耦合 counts 与定位”公式不成立。** 在 \(n=N r,\ \sum r=1\) 下，\(\sum n=N\) 与 \(T\) 无关。即使共享嵌入会带来统计耦合，也不能由该式推出“运输介导总 counts 变化”。我原先把“定位改变”误写成“丰度—定位联合机制”。修复若要做，必须让总丰度成为基因特异/目的地特异的运输或非平衡质量项的函数；否则只能称空间重分布模型。
2. **标量源汇在 softmax 中会抵消。** 我原文的 \(s_i=Se_p+Uz_i\) 若被解释为每个目的地同一标量，确实会消掉；只有向量或基因特异 logits 才可能保留。审计已明确这一条件，我接受。
3. **置换控制的失败逻辑写反了。** 真实生物信号在扰动标签置换后应当消失或显著下降；“置换后增益消失”是预期对照，不是泄漏证据。正确写法是：若置换后仍保留同等增益，才提示 nuisance/泄漏/正则化；且空间标签置换要尽量保持边际，否则会制造不合法分布。
4. **counts+localization 不是 world+agent 联合收益。** CST 是模型/世界结构，不是主动 agent。C4 中“同一 start 的 old/new improver”与“继承 vs 重启”也是两个不同实验；我原先把它们混在一起。
5. **真正未见扰动的 \(E[p]\) 不能靠一张表预测。** 若无化学/靶点描述符，留出扰动只能来自已见组件组合；否则应明确为不可识别。修复后的 CST 很可能落回 shared-embedding / unbalanced-OT 多任务预测，必须检索精确前驱，不能因公式更“机制化”就称新。

## 二、对三项提案的交叉判断

**CAF 提案。** 生物问题最有药物发现相关性：联合免疫治疗的顺序可能比终浓度重要。但我接受 root 的数学批评：\(\lambda=0\) 是一阶松弛，不是瞬时响应；审计数值显示 \(s_0=0/1\) 在 \(t=1\) 后仍差 \(e^{-1}\)。\(\lambda>0\) 也不保证双稳：\(\kappa=1,\lambda=1\) 严格递减，\(\lambda=5\) 才有三个平衡点。因而原模型不能把“λ 后验压到 0”直接当成机制无效；它只说明有限样本下不支持额外非线性。统计 CI 排除 0 也不是应用有用增益，必须绑定决策 regret、实验成本或固定验证预算。

CAF 的最强反对不是“生物学不可能”，而是**可辨识性和数据 join 同时缺失**：没有同供体预处理—洗脱—同一终刺激—功能重复，就无法把慢松弛、真平衡滞回、细胞因子 carryover、供体差异和细胞组成漂移分开。Lorch 等已占住通用学习型动态耦合的先验位置；其 stationarity/线性化假设不证明 CAF 有无滞回，但显著提高了“仅凭单时间点 RNA 推状态历史”的门槛。

**空间提案。** 我修正后认为：它可作为“定位重分布 + 丰度头”的常规多任务基线，但当前公式不能支持运输导致总 counts 变化的机制。若让总质量随运输改变，需要明确非平衡 OT 或基因特异质量生成；若坚持 row-stochastic 运输，只能预测定位。未见扰动的 \(E[p]\) 还要求描述符或组合留出设计。CST 的模型贡献与主动查询 agent 贡献必须分开测；不能用 count 与 localization 同时改善冒充 user-level world+agent 联合收益。

**决策翻转提案。** 审计反例成立：正 flip 概率可以有负净价值；flip 排序还可把低价值查询排在前面。\(p_{\text{noise}}\) 只处理零效应附近，不能修复效应量、处理—对照异方差和成本。把它改为 EVSI/knowledge gradient 是正确修复，但也是标准贝叶斯设计；对比低秩程序分解又接近监督分解/PLS。凸包内插也不保证功能可外推，除非显式假设响应线性。NCI-ALMANAC 可支持静态 action-conditioned viability 世界，不能因缺 RNA 就排除；但它不能替代 CAF 的细胞状态机制。

## 三、唯一优先项：CAF 只做 source qualification，不做实现

三选一，我保留 **CAF 假说作为唯一主候选**，但优先级严格限定为 **数据资格审计与可辨识性重述**，不进行数学拟合、不生成湿实验、不声称滞回。原因：它是三者中唯一直接对应“治疗顺序”药物决策的问题；但当前没有经认证的同供体历史/洗脱功能菜单，且 root 已证明原模型表述需改。继续写实现会把不可识别参数包装成机制。

- **支持证据**：CAF 有真实功能 coculture、细胞因子扰动和患者来源小样本；药物顺序问题明确。
- **最强反对**：缺同供体预处理—洗脱—同一终刺激—功能重复；n=3/4；单时间点快照不能区分松弛、双稳与混杂。Lorch 是通用动态耦合的近距离先验，未证明 CAF 滞回，但压缩了“只换模型名”的空间。
- **与 constructive 的分歧**：我同意其把假说标为可证伪结构；不同意在无配对数据时把 \(\lambda=0\) 称普通瞬时模型，也不同意仅靠后验 λ 或统计 CI 判成功/失败。必须先有能估计 \(\kappa,\lambda\) 的设计。
- **必要模块**：同供体配对历史、洗脱时长、同一终刺激、迁移/激活功能重复；细胞因子残留与组成标志物作为混杂测量；留出供体预测；以决策 regret 或固定验证预算定义有用增益。
- **缺失 join**：作者补充表与 HRA011931/HRA008021 元数据中是否有 donor_id、预处理剂量/时长、washout_time、terminal_stim、功能读出、技术重复和匹配 vehicle；目前未核实。

**下一判别行动（唯一）**：只读审计 CAF 作者 XML 引用的补充表和 HRA 元数据字段，逐项核对上述 join。若核心字段缺失，则 CAF 只保留为生物假说，不作为可检验世界模型；若存在配对历史/洗脱/功能数据，再冻结一个仅回顾性的嵌套模型比较，先检验 \(\kappa\) 与额外阈值项是否可辨识，而不是先做主动实验。

若该审计失败，备选只能是明确标注为**常规基线**的 NCI-ALMANAC 静态 action-conditioned 功能 pilot，用真实成本检验 EVSI 相对 flip 启发式；它不检验 CAF 世界机制，也不因“无 RNA”被排除或升级为生物贡献。
