## 一、我自己的错误修正

1. **λ=0 不是“普通瞬时剂量—响应”**。我原文的嵌套说法错了。λ=0 时  
\[
\dot s=\kappa[u(c)-s]
\]
是有限记忆的一阶松弛；\(\kappa=1,u=.5,t=1\) 从 \(s_0=0/1\) 得 \(0.316/0.684\)，历史差 \(e^{-1}\)。真正的瞬时嵌套应是 \(\kappa\to\infty\) 或 \(s=u(c)\)，不是 λ=0。

2. **λ>0 不保证双稳**。对 \(\theta=.5\)，  
\[
f'(s)=-\kappa+\lambda(-3s^2+3s-.5),
\]
在 \([0,1]\) 最大为 \(-\kappa+\lambda/4\)。\(\kappa=1,\lambda=1\) 严格递减、唯一平衡；\(\lambda=5\) 才有三平衡 \(0.276,0.5,0.724\)，外稳中不稳。故“后验 λ 压到 0 即失败”也不充分；必须比较 \(\kappa\)、真实平衡滞回、细胞因子 carryover、供体随机效应和细胞组成漂移。统计显著或 CI 也不是应用有用增益。

3. 我原来说“λ=0 自动退回静态模型”是错的；正确说法是“λ=0 仍有慢松弛记忆”，只有 \(\kappa\) 大或显式代数模型才接近瞬时。数学修复本身不构成 novelty，尤其 Lorch 等已覆盖通用 latent causal/dynamical coupling；我的差异只能是 CAF 状态变量与 T 细胞功能端点，而不是通用动力学。

## 二、对另外两位的具体质疑

**对 skeptic 的 CST**：我同意 root 的审计。其公式在 \(r=\mathrm{softmax}(\log\pi+s)\)、\(n=N r\) 下，\(\sum_b n_b=N\) 与运输 \(T\) 无关；共享嵌入会造成统计耦合，但“运输介导总 counts 改变”没有被公式建立。基因索引与质量方向也未定。标量目的地常数会从 softmax 消掉，向量 logits 才可能保留条件；这需要明确写成 gene-specific/unbalanced transport，而不是含糊的 \(Tq\)。更关键的是其失败逻辑反了：真实生物信号在标签/空间置换下**应当**消失；若增益仍存在，才提示泄漏或正则化。置换消失是必要对照，不是充分证明。有效对照应保留分层/边际结构、重跑完整预处理、给出置换零分布，并加已知注入信号的正对照；同时把“共享嵌入分离头”和“直接多任务”作为同信息对照。CST 目前更像标准 shared-embedding/unbalanced-OT 多任务预测，未给出精确最近前驱；counts+localization 也不是用户要的 world+agent 联合收益。C4 的 old/new improver 从同一 start 比较“继承后继续改进”，与 transfer vs restart 的“继承参数后重启”不是同一测试，不能混称。

**对 application 的 EACT-DQ**：root 的有限状态反例已证明 \( (p_{\rm flip}-p_{\rm noise})/\mathrm{cost}\) 不是决策最优或成本 worth 的保证：正翻转可负净值，更高翻转可把低价值查询排前。p_noise 只校准翻转率，不补 effect magnitude，也不处理处理组—对照组的异方差。若改成 EVSI/KG，那是标准贝叶斯设计；要成为贡献，必须有实测效用模型、真实 assay 成本和同预算随机/通用 AL 对照。低秩端点对齐与监督因子分解/PLS 很近；凸包成员也不保证功能可运输，除非加上响应假设。其“vehicle 噪声/CI 排除 0”只认证预测噪声，不认证应用价值。另需修正：NCI-ALMANAC 可支持静态 action-conditioned 功能世界模型，缺 RNA 不自动排除；但不能编造未释放的 queryable bundle。

## 三、选择的唯一优先级

**优先级：CAF 候选降级为“source qualification only”，不做数学/生物实现拟合。** 理由不是 CAF 生物学不可能，而是当前配置没有可认证的同供体“预处理—洗脱—再刺激—功能”配对菜单；n=3/4、RNA 与功能 coculture 不能静默拼接，且 carryover、供体差异、组成漂移与慢松弛会混淆。没有 wet-lab 访问时，继续修方程只会得到标准动力学模型，不能产生新证据。

- **支持性证据**：作者 XML 有患者来源 apCAF/mCAF、IFNγ/TGFβ、T 细胞迁移/激活 coculture；root 审计确认 λ=0 有限记忆、λ=5 可三平衡，说明数学上可区分，但不是生物证据。
- **最强反对**：没有已认证的历史/洗脱配对功能表；小样本；Lorch 先验覆盖通用动力学；即使找到数据，也可能只支持慢松弛而非平衡滞回。
- **分歧**：我不接受 CST 现在作为主候选；也不接受 decision-flip 作为决策最优规则。二者均可保留为 conventional baseline，但需精确前驱与同预算对照。
- **必要模块**：同供体配对历史、洗脱时长、同一终刺激、功能读出（迁移/激活）、vehicle/技术重复、供体/板/批次、细胞因子时间序列、apCAF/mCAF 组成；模型侧必须同时含 \(\kappa\) 有限松弛、λ 非线性、carryover、供体随机效应和组成协变量。
- **缺失 join**：HRA011931/HRA008021 与功能表、供体 ID、处理顺序、洗脱、终刺激、T 细胞读出之间的映射；补充表是否含这些字段未核实。
- **下一个判别行动**：只做**源数据/schema 审计**：核对上述数据库与补充表是否至少有一个数据集具有“同一供体≥2 种预处理历史→洗脱→同一终刺激→功能读出+vehicle/技术重复”。若有，冻结回顾性 leave-one-donor-out 比较：瞬时代数模型 vs 有限松弛 λ=0 vs 非线性 λ>0，并显式建模 carryover/组成；若无，停止 CAF 拟合，明确记为 source-qualification failure，不用更大模型掩盖。此行动可检查、无需新生物实验；未核实前不声称数据存在。
