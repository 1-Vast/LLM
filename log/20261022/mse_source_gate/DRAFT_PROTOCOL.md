# Source-only numerical task gate — pre-outcome draft

2026-10-22. This is a new phase after the sealed contrast scout, not reopening any stopped CiPA/TG/AZ configuration. No endpoint/composition scalar has yet been decoded. Root assumption: a narrow **ex vivo candidate nomination** task is scientifically useful if patient-specific paired raw count/fraction depletion has measurable decision headroom. This cannot establish healthy-cell preservation, clinical response, dynamic state transitions or RSI.

1. Bind metadata-only135samples/95patients/common65 and deterministic SHA256 patient55source/20development/20later partition. Repeated samples always travel together; order is an arbitrary experimental task order, not clinical chronology. No clinical features enter this first task. Keep all early STP outcomes and other drugs unopened.
2. Fix eight probes by an independent drug-name SHA256 order before observing any target composition or response. Each probe costs one drug-condition bundle revealing paired raw RCN/RCF. A parallel24hDMSO composition bundle costs one additional bundle. At this common information checkpoint nominate five disjoint drugs from57terminal actions. This is information replay of already measured assays, not wet-lab cost/turnaround savings. The fixed hash batch is a diagnostic reference, not a proposed optimal acquisition policy.
3. Only designated source patients' common65 raw RCN/RCF and13raw composition fields may be numerically decoded. Scaled response/control tables are forbidden. Raw assay workbook/worksheet identities and exact named fields must be bound before decode. Source truth is never imputed, clipped or repaired; negative raw responses are legal. Non-source numeric XML text must not be accessed or scalar-converted, though acquired XML bytes/parser buffers necessarily include the full published worksheet.
4. Candidate literal validity contract: every source response is numeric, finite and <=1+1e-10, as required by a nonnegative count/fraction ratio. There is no artificial negative lower bound. Every source composition field must be finite and match the primary fraction/conditional-subtype interpretation (range0..1 with1e-10tolerance). Parent/subtype axes are overlapping; no sum-to-one over all13axes. Any missing/invalid required field stops this exact complete-menu configuration; no row removal. Raw control denominators and retained-well QC counts are absent: output is conditional on published derived endpoints/QC and cannot independently authenticate these denominators or replicate precision.
5. Proposed utility, without data calibration: joint hit iff **RCN>=0.50 and RCF>=0.20**. These mean50%count and20%fraction depletion of classifier-retained malignant cells relative to controls. They are research screening levels, not clinical efficacy or significance. No source quantile tuning or post-result threshold replacement.
6. Source headroom: success fraction of each five-drug shortlist; average samples within patient then equally average55patients. For each held-out source patient, ordinary global baseline takes the five terminal drugs with highest mean joint-hit rate over the other54patient groups (ties alphabetical). Oracle takes five true successful terminal actions per sample where available. Report oracle-minus-global mean and per-patient distribution. Gate requires margin>=0.10 and at least10source patient groups having a sample with both hits and failures in57terminal actions. These are diagnostic prerequisites, not a held-out model test, power guarantee or evidence of achievable feedback gains. LOPO aggregation is reported separately from predictive fits.
7. If any declared gate fails: STOP this exact menu/utility/budget/split configuration, retain actual negatives, do not move thresholds/splits/probes. If it passes: only a separately frozen strong ordinary fixed-probe information comparison is authorized as a next research gate. No architecture or new algorithm promotion follows. Before later decode freeze all models/calibrations/metrics and compare direct scalar and bivariate prediction, ordinary conditional/refit, hierarchical/lowrank completion, no-feedback, composition-only/probe-only, simple mixtures, and equal budgets. Agent policy comparisons and inheritance/Level3 need their own independent evidence.

Independent biological and audit positions are pending. This draft may change only before any scalar decode; amendments must retain the draft and be explicit in the final protocol. Tests of source-only access denial must pass on synthetic workbooks before execution. All code under research/mse_source_gate_20261022; all outputs and failures under this log directory.
