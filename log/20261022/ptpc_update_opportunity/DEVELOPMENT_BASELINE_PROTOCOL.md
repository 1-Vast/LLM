# HCT116 development-only function-annotation opportunity

Pre-abundance exploratory baseline protocol, not an innovation test or confirmation set. HCT116 labels have been qualified (602 noncontrol annotations,34Y); source gate exposure is acknowledged. All other new backgrounds remain unexamined for labels and abundance. No oldfinal repackaged as new.

Application: predict author's PTPC Y/N Efficacy annotation for HCT116 drug conditions using chemical structure, measured6h protein state, or both. It is not authenticated fixed-dose viability, prospective6h decision timing, or virtual-state prediction. The measured6h-state comparator is intentionally strong and gets the same actual observation if a future world-model agent uses it. No world/agent/inheritance/RSI gain follows from a positive baseline.

Eligible conditions: all HCT116 noncontrols with complete consistent annotation and at least one6h measurement, as established by metadata. Do not require24h state, filter by abundance quality, or select on class/score. Decode only those eligible HCT1166h protein rows, no24h abundance or other backgrounds' rows. Use authenticated metadata↔matrix row correspondence, not a Sample_ID many-to-many merge. Explicit matrix blanks/NA/N/A/NaN are missing, not0; stored finite0 remains observed. If observed negative/nonfinite values occur, stop and document scale rather than silently invent transform. Predeclare log1p nonnegative observed intensity, with unknown original normalization still a limit. Technical rows of a Sample_ID median first, then biological/sampleIDs at samecondition/time median; all repeat rows stay together. No sample observation count changes outcome independence.

Drug chemistry: only source B_drug_info Pert_ID,Compound_name,SMILES. RDKit canonical isomeric SMILES and radius2 Morgan2048; do not remove salts/charge or infer targets. Identical canonical SMILES form one indivisible split group, even with multiplePertIDs. Invalid/missingSMILES get zero fingerprint plus missing flag; group by normalized declared compound name, orPertID if name absent. Do not exclude failures after viewing outcome. Chemical identities across conditions do not make them independent drugs; retain percondition metrics and report alias grouping. Chemical2D descriptors beyond Morgan not used in this minimal finite run.

Five outer folds assigned to chemical-identity groups by sha256('PTPC_HCT116_DEV_V1|'+key) modulo5, without stratification or label-based repair. Each fold's inner selection uses three analogous source-only grouped hash folds (saltINNER); no heldout label enters fitting/transforms/selection. Empty or one-class fold metrics are reported unavailable; never choose an alternative partition for balance. This is within-one-background chemical-group extrapolation exploration, not cell-background transfer or blinded confirmation.

Pre-fixed families: source prevalence constant; class-balanced L2 logistic regression with chemistry only, proteins only, jointchemistry+proteins. Same C grid0.01,0.1,1, selected by mean source-fold averageprecision (ties grid order). Protein median imputation and variance scaling fitted on training data only; all-missing train proteins dropped. Chemical bits unchanged. After scaling, each feature block divided by sqrt(number of its columns), so jointdimensionality does not silently dominate by count. Joint has exact same chemical/protein observations as its component comparators. Fixed seed0,max_iter1000,liblinear; report warnings rather than silently accept nonconvergence. No post-result tuning expansion.

Primary metric pooled out-of-fold averageprecision, with fold AP and prevalence, AUROC,Brier andprecision@5 annotation retrieval secondary; macrofold reporting only where defined and tied scores use deterministicPertID ordering for retrieval. All comparison curves are exploratory; a majority accuracy is not adequate. The balanced models are not presumed calibrated, hence prevalence/Brier comparator retained. No arbitrary clinical margin inferred from AP. Report wall time, model settings, split membership and prediction rows. HCT116 is a single development background, no inferential barcode/drug row p-values or inheritance claim.
