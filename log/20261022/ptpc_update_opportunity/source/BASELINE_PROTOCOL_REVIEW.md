Verdict: the limited author-annotation exploration is scientifically permissible. Three same-budget direct logistic families, the three-value C grid, and an outer-training-prevalence predictor are an appropriate minimal baseline set. No original assay cutoff, dose or prospective timing contract is required to explore this explicitly limited released-annotation target. Unknown original normalization limits biological interpretation but does not by itself prohibit a prespecified representation and honest development analysis. No result will establish novelty, world-model contribution, agent contribution, inheritance, RSI or confirmed performance.

Two execution details need an explicit frozen clarification before abundance access. These are avoidable specification gaps, not evidence that the actual unseen data are defective.

1. **Chemical aliases spanning valid and missing/invalid SMILES.** Canonical-SMILES grouping handles exact valid-structure aliases, and normalized-name grouping handles invalid records among themselves. As written, a missing-SMILES record and a valid-SMILES record with the same declared compound name can still get separate keys. Detect such cross-representation aliases and union their split groups, or stop on their occurrence before fitting. A simple deterministic connected-component rule over equal canonical SMILES or equal normalized nonempty declared names is conservative and adequate; record the normalization rule and the resulting membership. Do not use labels to repair or split components. Keep per-Pert_ID outcomes separate even if a chemical split component contains several annotations. This issue is blocking if a cross-key alias is observed and left across folds; its presence has not been established by this review.

2. **Aggregation and log order.** Technical-repeat median and sample median are sound, but log1p and an even-count median do not generally commute. Freeze missing-aware technical median within authenticated `(Cell_line, Pert_ID, time, Sample_ID)`, then missing-aware median across distinct Sample_IDs in the same condition/time, then log1p of the aggregated nonnegative observed intensities. Keep an all-missing aggregate missing until source-training-only imputation; never use zero as a missing placeholder. This order is a recommendation, not a claim that the alternative would be invalid; one deterministic order must be specified before values. This matters because the already-open identity metadata includes technical duplicate pairs.

The remaining requested checks pass at protocol level, with the following execution assertions:

- **Matrix row mapping:** authenticate the complete matrix first-column Sample_ID sequence against the metadata sequence, not merely a set or the selected rows. Then select eligible workbook row offsets and decode only their abundance cells. Assert that every technical duplicate being aggregated has the same line, Pert_ID and molecular time. A Sample_ID lookup or many-to-many merge is not sufficient. This uses identities from other backgrounds without resolving their outcomes or protein values.
- **6h-only admission:** use all consistent-label HCT116 drug conditions with at least one 6h row; do not require a 24h abundance or discard a condition for protein quality. The prior label gate implies 601 eligible noncontrol conditions, with 34 Y annotations, whereas the both-time population has 600 conditions. Assert the metadata-defined eligible count before abundance, and do not silently replace it with the 600 paired-time cohort. The 24h-only condition is ineligible for this stated application. Cross-time label consistency already checked in the label gate does not require reading any 24h state.
- **Hash folds:** deterministic group hashes without label-based repair preserve the intended exploratory audit. Freeze exact key serialization, UTF-8 encoding, outer/inner salts and modulus in code before predictions. An empty or one-class validation fold must not trigger a new seed or altered grouping. If a source-training partition itself has one class, or a protein family loses every train feature, record that family/fold as unfit under the protocol; do not silently substitute or tune another model. If no inner AP is defined, predeclare the first-grid C or mark selection unavailable. These are deterministic edge-case rules, not a reason to redesign the split based on observed labels.
- **Missing and scale:** the distinction between finite stored zero and absent/NA/N/A/NaN is correct. Negative or observed nonfinite intensities should stop the run as proposed. Parse the declared missing tokens before deciding that a numeric NaN is an unrecognized nonfinite intensity, so equivalent missing serialization has one explicit policy. Training-only median imputation, feature dropping and scaling avoid heldout transform leakage. Report dropped-feature counts and missingness; do not exclude condition rows after inspection.
- **Replicate and unit accounting:** one chemical group stays in one fold; all condition timepoints and technical/biological measurements stay bound to it. A sample median does not authenticate independent functional replicates. Report both percondition counts and chemical-component counts. Neither the 601 condition annotations nor the repeated state measurements are independent cell-background tasks.
- **Comparators and claims:** source prevalence must be computed separately on each outer-training set and predicted on that outer test fold. Chemistry, measured-protein and joint families receive the same admitted conditions and the same train/test membership, with feature-family-specific missing representations. The source-prior comparison is essential given the 34-positive minority. Pooled OOF AP can describe this development exercise; pooled Brier highlights the effect of class balancing. No cell-background transfer, calibrated therapy utility or new mechanism can be inferred from these scores.

Recommendation: freeze the two clarifications and deterministic edge-case behavior, then run the finite HCT116 baseline. Preserve A375 as selection-unopened and NCI-H1975/NCI-H2170/Panc1005 as final-unopened. An unexpectedly strong ordinary predictor should strengthen the direct baseline, not be rebranded as evidence for the world-model or RSI proposal.
