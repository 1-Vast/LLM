# PTPC 可继承更新：独立反方机制审查

2026-10-22。角色：recursive_distinct，独立怀疑者／替代机制审查。本文先于阅读另一份本轮机制草稿封存；没有读取本轮任何 Efficacy 数值、蛋白丰度、标签门结果或其他评审草稿，没有拟合模型或调用 API。这里的否定针对尚未证明的新颖机制，不是否定新数据或一切可能的世界模型。

**判断：目前没有一个可据此直接宣称新颖、值得扩大 RSI 搜索的更新操作。** 可做一个很小的跨药物信息检验，但应先把它命名为支持集条件化／更新规则迁移研究。蛋白残差传输、低秩背景适配、混合损失权重调整都已有直接普通等价或最近同源工作，不能只因放入智能体循环就成为递归创新。当前五个新背景可以检验有限的继承效应，不能支撑多代改进策略越来越善于改进的确认。

## 1. 可执行的最小主张，而不是任意更新菜单

应用限定为：在一个新背景中购买少量支持药物的 6/24h 蛋白测量，改善**其他未查询药物**的作者 Efficacy 注释预测／排序。预测每个药物自己的已观测蛋白对应标签是另一个有效问题，但不能当成跨药物实验节约。没有认证 0h，不把时间匹配 control 叫做处理前同一细胞状态；也不把作者标签解释为已认证固定剂量、24h 存活或临床药效。

可检验对象应具体到一个更新器，而不只是“模型能更新”：从允许的旧背景获得基础模型 W0，并在源背景支持／查询分离的 episode 上学习 U_phi。部署时固定支持药物集合 S，输入其药物描述、6/24h 蛋白残差及缺失掩码；U_phi 生成本背景的状态修正或参数增量。该任务增量每背景重置，继承的是 phi／规则代码。目标药物 T 的自身蛋白和标签完全不输入。支持集是否包含标签须单独列为信息条件；不能同时声称是只买蛋白、又偷偷用其 Efficacy 梯度。

**最小可证伪主张：**在同一 W0、同一支持信息、同一预算、同一目标集上，冻结继承的 U_phi 相对于无反馈预测，以及同信息的普通重训、核残差适配、联合直接预测，降低预固定功能损失；优势应来自支持集对未查询药物的可迁移信息，而不是查询药物自身标签、条件重复、增加训练量或目标背景预处理。若不存在这一增量，停止新机制扩张。若仅优于无反馈而不优于强普通条件化，记录信息有效，不声称更新器贡献。

这不是提交一个新候选算法。它是任何候选必须具体实现的最小科研对象。当前我不推荐额外发明一个损失权重／路由／搜索模块来填补它。

## 2. 最强普通等价：什么机制可能已经解释全部收益

设支持蛋白残差 r_S 来自观察值减去基础预测。常见修正为

`delta z_T = K_TS (K_SS + lambda I)^(-1) r_S`。

K 可以来自化学指纹、药物作用靶点或源学习蛋白潜空间。此操作是普通条件高斯／核残差回归。若功能读出在工作区间是线性的，则把此分子修正送入功能头，等价于一个使用诱导交叉协方差的功能核修正。非线性读出可能增加表达能力，但仍须实测其有别于同容量联合预测器的效益。把 K 叫作“世界模型动力学”不会自动改变这个事实。

更普遍地，固定步数的确定性更新后预测可以写成直接函数：

`yhat_T = g(drug_T, {drug_s, time_s, protein_s, mask_s, optional_label_s}, context)`。

这不是证明更新器永远无用：分解结构可能改善有限样本效率、计算或可迁移性。但它反驳“有更新步骤所以普通预测无法实现”的主张。必须给这个集合条件化的直接预测器同样的源 episode、输入和调参机会，不能只比较忽略支持蛋白的弱直接头。

一个无需动力学的正例反解释为 `protein_cd = a_c + b_d + noise`、`Pr(y_cd) = f(a_c, drug_d)`。支持药物蛋白估计背景偏移 a_c，然后所有药物预测改善。一个低秩背景编码器／ridge 条件化就能实现；6/24 两时点即使有帮助，也未必因识别了干预下的状态转移。

反向可证伪例：在给定药物描述和背景后，各药物蛋白残差相互独立，或某支持药物残差主要是该药物特有毒性。此时支持残差没有目标信息；未经检验的“继承”会负迁移。模型不能凭更复杂的智能体产生不存在的跨药物关联。支持反馈打乱药物对应、跨背景交换残差、用相同均值／时间信息替代等负对照，应只检验具体候选的必要信息，避免事后选择哪一个看起来好。

## 4. 数据合同决定该检验有没有意义

身份审查确认 S8 的 2,217 个元数据行与蛋白矩阵第一列按行精确对应，但 Sample_ID 有重复，不能 many-to-many 合并。必须把同背景×同药物所有 6/24h、techrep、biorep、plate 放在同一支持／查询侧。进一步核查 Pert_ID 的同名／同 SMILES／同 CAS 别名；同一化合物不同 ID 不能跨支持和目标。没有剂量字段时，不从缺失剂量想象独立条件。

条件 Efficacy 冲突、混合缺失、缺失标签等按结果前规则处理。一次条件查询不是每个蛋白、每时点、每技术重复各一个研究任务；6h 与24h蛋白是否算两次实验资源须明确。蛋白和功能标签是不同反馈通道，购买和成本分别记账。目标药物自己的已观测状态不混入跨药物任务。

蛋白映射、归一化、缺失处理与潜空间默认从允许源侧拟合。若允许新背景的所有无标签目标蛋白参与 PCA／归一化，这已经提供了原本“未查询”的测量，须改名为转导任务，向所有基线提供同样信息并计成本。时间匹配 control 是一种实测输入资源，也必须共享。

HCT116 的条件多于其他背景，不能把其多数药物当成数百个独立新环境来训练并确认 RSI。HCT116 开发、A375 单次方法选择、另三线冻结评估有清晰用途，但 A375 只有一个独立选择背景，不支持用无限 API 搜索吃掉其标签后仍称泛化确认。其余三线也不能边评估边再修改；若执行过，只能如实转为开发史。不能以随机种子、support 重采样或不同药物划分制造新的独立背景代数。

## 5. 如何拆开四种收益以及 RSI

世界模型贡献：同一支持信息下，状态约束的预测／更新是否胜过强联合直接预测；若只因额外蛋白输入获益，不能单独归因动力学。智能体贡献：固定候选空间和反馈预算，对比预固定常规调参、随机／简单程序搜索、主动学习与相同预算搜索；LLM 只能改变提案质量，不能享受更多反馈。继承收益：把 U0 与源上改进后的 U1 分别移植到**相同 W0、相同任务支持集**，并同算学习 U1 的源期成本。继承一个更强 W1 与继承一个更强更新器要分开。

联合收益需在共同测试记录中同时报告模型、智能体、继承各因素及联合，不把三个各自较弱的对照拼成联合优势。共享训练算力、源标签与蛋白预算、内层选择次数及真实 API token／时间；没有价格时报告实物数量，不捏造湿实验或 token 费用。

进一步的 improved-improver 必须检验：改进策略 E1 相较 E0，在同一初始 U、同一新改进反馈和预算下，产生了更好的下一更新器，而不只是 E1 本身当前得分高。还要有未参与 E1 选择的新环境确认。五背景不足以在开发、选择、确认后再提供多代独立验证；当前合理最高主张是有限的一阶更新器继承试点。改进策略自称写过更好的 prompt、保留最佳 checkpoint、重新拟合参数，均不构成这个检验。

## 6. 深入与停止判断

先等待独立标签合法性门，不据此偷偷挑类别或药物。若任务合法，只有在倡议方提出一个不被上述普通等价完全吞没的具体新操作、解释跨药物信息路径，并承诺同信息强对照后，才值得做小规模信息／更新器检验。第一次可以只回答支持蛋白是否比普通背景条件化多带来未查询药物的信息，不能先搭建大型多代理系统。

若支持蛋白无稳定增量，停止该跨药物反馈方向；若普通联合预测／核适配解释全部增量，保留常规应用结果，停止世界模型新机制／RSI扩张；若新操作有超出普通方法的稳定增量，封存小试点后再讨论三线一次性确认。若当前只有“重建更好所以药效更好”“更新权重可继承”“让智能体搜索更新方式”三种叙述，**我的结论是没有合格的新候选**。

依据 CDK 已有结果，强条件均值和同类直接 ridge 已能解释大部分预测，小的反馈信号也可能真实存在。该阴性经验支持把“信息有效”与“独到更新机制有效”分开，既不复活旧 RSI 扩张，也不把小信号说成绝对无信息。
