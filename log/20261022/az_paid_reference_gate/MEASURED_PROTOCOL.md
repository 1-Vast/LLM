## Models and equal bounded search

The shared-structure candidate is **effect**: `Yhat=B(u,v)+h_pair(u,v)`, `B=u+v−uv`. Shared means across training cell contexts; no cell identity is a feature. This tests a simple functional-state compression bias. It does not forceh(u,0)=0: zero measured mono effect is not zero dose. Finite out-of-range values are not clipped.

For **effect** and same-capacity **dose**, h is pair-specific ridge on26fixed Gaussian features (5×5centres at0,.25,.5,.75,1 plus intercept). Effect uses(u,v); dose uses normalizedlog10µM coordinates, with each source drug's own min/max range from all already available GDSC007 design metadata and strictly positive concentrations; a constant range maps to zero. Both predict the same residualY−B(u,v), then restoreB. Same12configs: widths{.1,.25,.5}×alpha{.01,.1,1,10}; intercept penalized too. Unknown training pair has residual0 and is reported. No learnt temporal/molecular dynamics or new operator is claimed.

Two strong direct arms predictY: **direct** uses full features, **combo_direct** uses without_mono. Each gets the same12config grid: ExtraTrees200trees, minleaf{5,20,50}×maxfeatures{.5,1}; or HistGradientBoosting150iterations, learningrate{.05,.1}×maxleaf{15,31,63}, L2=1, no early stopping. Seed20261022, ExtraTreesn_jobs2. No fits run concurrently to hide compute. Each episode's finite training rows have total weight1, normalized to mean sampleweight1 within a fit. Row-weighting is not an independence claim.

Train each config on train only and retain all validation predictions. Four arms×12=48selection pipeline fits. Select configuration separately for MAE and recommendation utility within each of seven fitted variants (effect,dose,direct,combo_direct,effect_offset,dose_offset,direct_offset), jointly with eta where relevant. Choose the first candidate on exact tie. Thus these are two separately optimized policies from a family; success is not a single same-parameter model winning both endpoints. Refit each unique selected (base arm,configuration) on train+validation once, caching exact duplicates across endpoints/offset variants: at most14final pipeline fits, at most62total. Mixture/enumerator reuse these fits. Record actual per-pair ridge solves, tree/boosting fits, timings, prediction cost and failures; “same12configs”does not mean equal CPU. Episode weighting is not cell-balanced training. No fit/config retry or extra family after outcome reading except a documented implementation correction reviewed before test opening. A failed numerical run is not silently discarded.

Cheap ordinary comparators: **Bliss**; **historical pair-dose** mean target inhibition from training, with nearest normalized dose coordinate/lex tie when exact coordinate absent, global trainingmean if unseen pair. The latter is refit on train+validation for test and uses no new targetdata. **Local offset/refit** compares the same three base arms(effect,dose,direct), using only the two paid witnesses: calculate each witness's mean observed `Y−B(own observed mono)`; subtract its querypair's historical mean residual, estimated from unique paid training matrices with each matrix equal weight. Average the two resulting residual deviations, then addeta×offset to baseprediction. Eta∈{0,.25,.5,.75,1}is jointly selected with the base configuration separately on validation MAE and meanU; final querypair means use train+validation paid records. Missing historical querypair mean defaults0and is reported. This is ordinary source-context calibration, not instrument-cause identification or independent per-drug parameter identification.

**Mixture/search**: choosew∈{0,.25,.5,.75,1}separately on validation MAE and meanU forw×effect+(1−w)×direct_with_offset, using the corresponding endpoint's selected component policies. Freezewbefore test. It includes familiar components and can reproduce effect exactly; a match is not a new algorithm win. A validation enumerator over all registered ordinary/candidate prediction arms is the finite equal-menu program-search reference, with all component costs included. This gate does not claim to beat arbitrary larger program search; expensive CL/AL/RSI are not run before structural opportunity.

The local offset is constant within an episode. For a fixed base configuration it cannot alter its five-action ranking, and the offset part of a mixture likewise only adds a constant. It is a forecast-calibration control, not evidence of decision adaptation or an intelligent updater. Utility configuration ties use the declared stable order; floating-point perturbations of exact action-score ties are implementation arithmetic, not biological improvement.

## Metrics, utility and gates

Keep all nominal episodes/rows and all assigned MASTERs in coverage denominators. Common input coverage must be≥95%in each role. Forecast uses common valid-input finite targetrows; an episode needs≥5such rows. Forecast scorable episode and valid finite targetrow coverage must each be≥95%in each role. Recommendation uses only common episodes with valid input AND every nominal targetrow finite; this intersection must cover≥95%of all nominal episodes in each role. For EACH endpoint, EVERY preassigned MASTER must contribute at least one scorable episode; otherwise qualification stops rather than silently shrinking the macro estimand/bootstrap population. Report missingness by role, cell, pair and input/target reason. Complete-case coverage does not establish ignorable missingness. A failed coverage gate stops this exact configuration, without candidate ranking or a new panel. Valid targetmissingness is reported after sealing, never used to retarget prediction. All finite targetvalues are scored as released, no clipping.

Primary forecast MAE: mean absolute error per episode across its finite doses, then mean across episodes in each MASTER, then equal mean across MASTERs. Model selection uses this same macro unit. Test uncertainty: paired10000bootstrap resamples of test MASTERs, seed20261022, percentile95%interval. Conditional source-model resampling is not a confidence interval for biological source independence. Use all preassigned testcontexts, no cancer-type cherry-picking.

Functional recommendation utility is **purchased-reference excess** `U=Y−max(u,v)`, not source HSA or mechanistic/clinical synergy. Each method selects the5nominal targetdose points with greatest`Yhat−max(u,v)`, stable global-row-order tie, using predictions and paidu/v ONLY. Save the five global row indices per policy/episode together with predictions BEFORE testtarget conversion and hash-seal both. Invalid-input episodes explicitly abstain. Never reselect an action from a target-finite menu. Evaluate those preselected actions on the common complete-target-matrix panel defined above. Regret is that episode's top5observedUmean minus selectedmean, a noisy source-data oracle diagnostic rather than true noiseless drug benefit. Aggregate episode→MASTER→macro as above. This avoids treating largestdose inhibition alone as discovery. No clinical dose constraint is claimed; all choices remain within the released design. Historicalpairdose is a registered five-action anchor; a one-point maximumdose corner is not presented as a comparable top5policy.

Select the strongest registered **ordinary** comparator for forecast by validation MAE among Bliss,historicalpairdose,dose,combo_direct,direct,dose_with_offset,direct_with_offset; select its recommendation comparator separately by validation meanU. Mixture/enumerator and effect_with_offset remain additional fully reported comparisons rather than concealing a matching ordinary reduction. Primary effect candidate must improve forecast MAE by≥.02absolute AND≥10%relative to its selected ordinary comparator, paired95%lower bound ofgain>0. For recommendation require≥.02absolute U gain AND≥10%reduction of baseline regret, paired95%lower bound ofUgain>0. If baseline regret≤.02, this exact task has insufficient registered useful decision headroom; stop recommendation expansion. Both co-primary gates must pass to justify a later decision-oriented structural investigation; requiring both does not create an uncorrected either-endpoint success rule. These2percentage-point margins are predeclared source-unit practical proxies, not measured assay noise or clinical thresholds.
