## Actual opposing discussion with scientific_skeptic

1. **Action locking and missing target values.** Accept fixed nominal top-five indices sealed before hidden targets, a common full-finite target-matrix episode panel, and the predeclared 95% role coverage threshold. Coverage denominator must remain every metadata-eligible nominal episode; paid-input abstentions and target missingness cannot silently disappear. I questioned whether full-matrix finiteness is mathematically necessary for fixed selected-top-five mean utility. Skeptic agreed it is not; its purpose here is a simple sufficient common panel supporting both fixed-policy utility and full-grid oracle/regret. Both reviewers accept the root's simpler full-case choice, without adding another gate. A 95% completeness rate does not establish ignorable missingness. Report missingness by role/cell/pair and interpret results as conditional on complete cases.

2. **Fair validation selection.** Accept using all already-paid 48 selection fits' predictions for endpoint-specific configuration selection, including the candidate. Ordinary local offset must choose base configuration and eta jointly within the registered menu; mixture components and weight must follow the same endpoint-specific rule. Cache identical `(arm, parameter)` final refits, report actual maximum and used counts, and include all component/validation/search costs. Merely choosing U's strongest arm after every arm was tuned only for MAE would not be an equally optimized recommendation comparison.

3. **What endpoint-specific success means.** MAE-optimal and utility-optimal effect configurations can establish that the same model family has useful structure for two tasks. They cannot establish that one fixed parameter model simultaneously wins both, nor a unified agent or joint benefit. A later single-model claim requires one predeclared configuration or multi-objective selection rule on unexposed tasks.

4. **Ordinary reductions.** Effect/dose ridge, Bliss, offset calibration, mixtures, and validation enumeration are ordinary methods. Mixture endpoints can reproduce effect exactly. Matching such an endpoint does not erase a structural empirical observation, but cannot be described as beating equal-menu search or inventing an improvement operator. All are to be reported; a favorable comparison only to a weaker subset is insufficient for a new-core claim.

5. **Training versus scoring unit.** Equal finite-row mass per episode, rescaled to mean row weight one, is not equal cell mass when cells have different episode counts. It is a shared predetermined fitting convention; validation and test use equal cell macro aggregation. This objective mismatch does not block this bounded ordinary pilot, but it must be stated and not called cell-balanced training.
