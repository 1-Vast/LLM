# Watermelon source and header-only qualification

This extension is frozen before metadata-asset retrieval. It permits author README and Git-LFS pointer blobs, official GEO directory listing, the two explicitly named metadata assets, and sample design records. It does not permit downloading response/count/expression matrices or LFS large RDS objects. Root will keep every HTTP body and hash receipt; HTTP failure and partial contact remain charged.

For metadata assets, phase 1 decompresses only the first line for field names/orientation. It does not parse subsequent fields or report numeric outcomes, signature scores, published fate, clone sizes or group frequencies. Byte contact with full compressed assets is disclosed; downloading metadata is not biological confirmation. Before subsequent row parsing root must freeze an explicit allowed-column list. If transposed, stop and specify a row-name-only operation. Only time, physical sample/library/culture identifiers, barcode/lineage identifiers, drug, model and raw sort-gate labels are eligible for design parsing. Published future-derived fate, clone size, survival and expression scores remain prohibited. Raw sort labels and design counts may later authenticate a conditional retrospective task; they do not identify absolute survival or biological independence.

The narrow application is prediction of cycling propensity among captured survivors, if supportable. It is not absolute reservoir mass or causal intervention efficacy. A score conditional on sort capture must either account for documented sampling weights or explicitly target that sampling distribution. Shared-founder cross-culture transfer is not unseen-lineage transfer. A full culture/time assay is the feedback unit, not an individually purchasable clone label. Source feasibility and an executable structural counterexample will precede biological fits; no current novel core has cleared.
