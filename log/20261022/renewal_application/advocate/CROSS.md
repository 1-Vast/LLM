## root 来源位置与 proposal 的实际质疑

根通知独立稿已经保存，才读取其 ROOT_INDEPENDENT_POSITION、DeepSeek RESPONSE 和保存的 Watermelon 官方 NCBI BioC 原文相关 methods/figure captions、GEO元数据与作者 repo tree。本代理未新增GET/下载/拟合。原文记载 H2B-mCherry dilution 是实际 proliferative-history reporter，不能贬成 scRNA captured-count viability；也不能用该事实跳过 sampling 与标签结构。

已实际向 root 发送以下最强问题：

1. day14 按 mCherry 三 gate 分样、每 sample 约9000 capture；若无 gate 分母/捕获及 barcode-recovery 权重，不能把 scRNA clone counts 当绝对 growth/depletion 或 rare prevalence。可保留 gate-conditional prediction，缺权重不是所有 static world 的禁令。
2. 原文 Fig2 caption 明言 majority fate 来自 combined replicates。如果进行跨 culture 测试，必须逐 culture 重建目标 fate，不能以合并 fate 标签引入 target-culture outcome；early model 仅可用其冻结时点信息，published 按未来 clone size 选的 genes 不得当未见标签选择。
3. 同 barcode 跨时点不是同细胞；缺 barcode 不能当死亡。同 barcode train/test 须写成共同 founder 下跨培养预测，不能称未见 lineage 泛化。
4. GEO描述七模型，原文 pooled methods 列八个（含 MMACSF）；PC9 day14 与 pooled day10 不可当同一协议，需要实际 manifest 核对，不能以论文模型数量当 later-task 数。
5. clone标签不是实际可买 experiment query；action/cost须按culture或真实assay bundle。两 parallel cultures 不能膨胀 C4；其局部复现仍有描述价值。
6. DeepSeek 的符号/排序 K 可由普通 sign/ranking constrained learning 明确实现；改变 candidate 本身不是新操作。同 target 剩余 pairs 不自动是后续独立 research tasks。joint benefit 不普遍要求超过各 single；只有更强主张才需该额外门。

root 对这些问题尚未回复；不把发问写成来源资格已经失败或已经解决。当前建议是 Watermelon 值得有界 metadata/任务审查，因为 actual reporter/lineage 是不同应用的正证据；没有新 core 清关，也不直接授权数值。
