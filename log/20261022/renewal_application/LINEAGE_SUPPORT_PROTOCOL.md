# PC9 lineage-join mask audit, before reading any lineage values

The root has read only the frozen design columns and metadata headers. No lineage-barcode values, RNA response arrays, clone_size, published majority fate or signatures were parsed. Design confirms shared day0, paired day3/day7 and three day14 raw gates for each replicate. This audit now permits only exact lineage identifier, full cell identifier, sample_name/time_point/sample_id. It asks whether early-state to later sampled-gate tasks have enough observable connections to merit a numerical source pilot. It does not select genes, estimate growth/death, read gate composition as a target, or test biological performance.

Map sample identities exactly to the11 already authenticated names. Reject any other name or inconsistent time/sample ID. Missing lineage strings are '',NA,NaN,nan,None,null. Disclose all nonmissing formats and duplicates by structural format, without exporting raw identifier strings. Within each culture, pool day14 low/med/high presence into a boolean endpoint mask. Do not count lineage membership by individual gate, calculate majority fate or clone size. Count unique barcodes at each time/culture, intersection with earlier time and cross-culture support. Missing endpoint barcode means 'not captured', never death. All counts are sampling-support counts.

Freeze unseen-lineage partitions via sha256('watermelon-support-v1|' + lineage), first8hex modulo10:0..5source,6..7development,8..9test. For each split, report the minimum of early/endpoint captured multiplicities across both cultures, at thresholds1,2,3,5 cells per early and endpoint sample. This is a fixed descriptive feasibility curve, no adaptive best threshold. Hash namespace and split are not tuned after observation. Day0 is shared context and cannot be called an independent culture.

Admission decisions fixed in advance: a split with zero eligible lineages cannot support that exact prospective holdout; fewer than30test lineages at the minimal1cell threshold means no confirmatory performance claim, although a debugging pilot remains allowed. Thirty is a minimal screen for a scoped pilot, not a power guarantee; a positive performance claim needs a separately justified precision/power contract and independent culture limitations. At most2cultures here; regardless of barcode count this source alone does not qualify broad later-research-task RSI. No new-core claim can pass by coverage alone. If numerical pilot is deferred, keep expression and per-gate lineage targets unopened.

Each original metadata download is one computational source acquisition, not a wet assay. Repeated local audits add computation, not biological samples. Real feedback cost remains whole culture/time + sorting/capture/barcode libraries.
