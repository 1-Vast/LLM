## 问题、应用与历史约束

目标应用是药物发现中的体外肝细胞功能复核优先级，而非临床安全或药效推荐。OASIS 为一个五供体混池、44 h 同时形态／代谢 MT／LDH 读出。供体数、剂量数、图像数和孔数不能充当独立生物背景数。

已核查的历史阴性要求先证明增量信息：PTV 同配置混合选择世界模型权重为零；普通 offset、ridge/kernel 更新、简单混合、固定设计和蒸馏已经解释过多项所谓改进。保留所有既有停止结论；不把 PTV 不同药池的数字拼接归因，也不重复旧报告中“分子更新结构上不影响功能头”的已更正说法。

本轮最强候选是“真实测量过程干预约束应更新细胞响应模型、观测模型或两者，并继承诊断程序”。独立评审发现两项未过关：OASIS 无认证的相应干预菜单；候选还未提出超出固定 counter-screen SOP、贝叶斯模型鉴别和等预算程序搜索的独有操作。正常无细胞 blank/spike 也不能自动排除依赖细胞存在或状态的干扰。故该机制保持 **NOT_IDENTIFIED / NOVELTY_NOT_ESTABLISHED**，未实现为新架构。

## 为什么低秩相关不能扩大为“没有有用信号”

独立审计复算 MT Pearson 为 0.95337，而幅度最极端 5% 动作贡献约 92.0% 的 pooled 平方变差。这说明幅度指标可被少量强信号／极端点主导，同时多数接近 DMSO 的动作排序仍不稳定；两者不矛盾。LDH Pearson 约 0.221，未显示相同幅度一致性。

上述尾部分析是看见主结果后的解释诊断，既不证实真实损伤，也不翻转预设失败。全菜单 Spearman 并非所有稀疏决策或 MSE 增量的必要条件；因而本轮不能用它否定未测的 G0b 信息主张。我们停止当前配置，保留这个评价门与实际用途可能不匹配的未决问题。

三方讨论过一次固定预算的尾部复核 pilot，但未执行：它只确认第一板已经测过的动作；端点选择还存在 MT／LDH／双端点分歧，也没有独立功能裁决。继续挑指标不足改变世界模型或 RSI 的研究方向。这个不执行决定不是因为缺 API 配额。
