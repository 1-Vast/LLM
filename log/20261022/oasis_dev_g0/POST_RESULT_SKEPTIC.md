# G0a 失败后的独立反方判断

2026-10-22，Asia/Shanghai。仅依据 PROTOCOL.md 与 DEV_QC.json 汇总，不读取原始响应、逐孔/逐药导出、count、CNN 或未开放分区。此前预审指出的首两板选择与退化输出问题，根代理报告已在 freeze 前修复并通过 6 项测试；本记录不把该报告当作独立重跑验证。

## 当前裁决

**原定 G0a 必须 STOP，G0b/CNN/模型/Agent/继承/RSI 均不得因本结果启动。** dev 641 标签/400 化学组的 10256 孔中，9708 孔合格（94.66%），548 孔缺失 count；预定 5128 个配对动作中 547 对失败，4581 对完整。覆盖与组数门通过，但两个排序可靠性门清楚失败：

| 端点 | Spearman | chemical-group 95% 区间 | 差异平方/合并方差 |
|---|---:|---:|---:|
| MT | 0.3243 | [0.2585, 0.3972] | 0.0940 |
| LDH | 0.1709 | [0.1329, 0.2172] | 1.5706 |

预定相关门为 >=0.60 且下界>0.50；这里连上界都低于 0.50。区间明确条件于本 screen 的已观测板和控制，不能推广到新培养背景。失败不是“没有拿到足够组/孔”这类单纯样本覆盖解释。

## 能支持与不能支持的结论

支持的是：该预设变换、配对和菜单下，全域跨药物剂量排序不足以进入原连续信息资格方案。不支持的是：所有测量无效、所有形态无信息、没有稀疏尾部决策空间、没有世界模型价值或 RSI 不可能。后几项根本未测。

MT 的低 rank 相关与 0.094 的小二阶差异并不矛盾。大多数近基线点可有不稳定名次，同时少数高幅度点支配总方差并在重复中一致；少数异常点也可能制造类似现象。若重复均值/尺度接近，该差异比对应很高的线性一致性，但摘要没有提供实测 Pearson，不能把推算当测量。当前只足以保留“可能有少量可重复强幅度信号”的解释，不能把它认证成真实损伤或实际决策 headroom。

LDH 的较大差异比表明全域二阶一致性也较弱，但并不能单凭该平均量证明尾部完全无效。两个端点不是互为生物真值，也没有独立损伤 adjudication。

## 尾部 pilot 的赞成、反对与未决

根代理提出的未执行方案是：仅 dev 暴露技术重复，首两板互作 prediction/evaluation，k=20 个不同化学组的 compound-dose；分别用首板 MT/LDH 提名，对比最高剂量、同时间 paid count、hash-random；次板使用预定 MT ratio<=0.5、LDH 超过控制尺度的 flag；每端点每 orientation 均需超过最强基线 0.10 precision@20。它没有登记或执行。

反方赞成其作为**一次廉价的阴性解释诊断**具有有限信息价值，不认为描述性技术复现必须先有外部培养数据。理由是它能区分“全域 rank 失败但强尾部稳定”和“连强尾部也不稳定”。同样的化学组去重、相同合格行动菜单、固定 tie-break、count/dose 强对照和双方向完整报告是最低条件。阈值须明确 LDH 用 raw MAD 还是 1.4826*MAD，不能在结果后解释。

反对将其作为科研框架的推进门：首板已实测全部候选 endpoint，次板仅确认同一已测动作，没有未测干预传播或研究程序学习；两个 orientation 共用同一批记录，并非独立证据；MT/LDH flags 只是 screen deviation；k20 上 +0.10 仅是 2 个额外 flag，缺乏独立不确定性/实用意义支持。最高剂量或 count 可能已解释收益。双端点可防择优，但也不能把探索变成原先 G0a 的通过。

novelty_advocate 更倾向先认证独立培养/独立功能裁决，再决定是否做该 pilot；反方认为先做低成本描述并非逻辑错误，但同意其当前不能改变 world/RSI 方向。未决点是这项技术解释是否值得消耗下一轮研究注意力，而不是旧门是否失败。

**最终执行决定：本轮不做尾部 pilot。** 原 G0a STOP 保留，CNN 与架构不恢复。保留尾部解释作为失败边界，不通过挑端点或新阈值救原门。任何未来稀疏用途必须另立协议、承认本 dev 已暴露，并先说明它会改变哪项实际研究决定。
