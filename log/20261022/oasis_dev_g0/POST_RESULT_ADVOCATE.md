## 裁决

**原 G0a 失败、G0b 和架构搜索停止的决定正确，必须保留。** MT technical-repeat Spearman 0.3243、化学组 bootstrap 区间 [0.2585,0.3972]；LDH 0.1709、区间 [0.1329,0.2172]，均未满足预注册的 0.60 且下界大于 0.50。dev 覆盖与组数通过不抵消端点重复门失败。这是当前同体系、control-normalized、指定双板/完整观测菜单的技术资格阴性，不是所有形态、细胞模型或药物决策问题的普遍阴性。

**全域 Spearman 不是每一种稀疏决策的必要条件。** 因而现有摘要不能排除少数可复现的强响应；同样也不提供这类响应确实存在的证据。只因为一种新指标可能阳性而继续扫尾部、阈值、剂量或端点，会把资产资格变成结果选择。本轮没有足够理由据此推进 world/Agent/RSI。

## 为什么可能错过稀疏信号

一个纯数学反例即可说明局限，不需要拟合当前数据。设占比 f 的最高响应尾部在两次测量中完全相同且排序一致；其余 1-f 样本在低响应区内的两次排序独立随机，且两区没有混淆。该总体的 Spearman 为：

    rho = 1 - (1-f)^3

取 f=0.05 时 rho=0.142625，虽然最高 5% 的身份及次序完全复现。这个构造证明全域 rank 门可以拒绝一个有完美稀疏尾部的测量系统；**不是说 OASIS 就属于这个构造**。反过来，整体相关高也不保证对某个安全阈值或极端 shortlist 准确。

本摘要的 MT `squared_repeat_discrepancy_over_variance=0.09398` 与低 rank 相关并存，值得解释，但不能凭摘要确定原因。它可能来自大批近 baseline 动作的噪声排序加少量大变化，也可能被少数极值/离群点或尺度差异主导。协议没有在正文给出该比值的完整分母定义，本文不据此反推 Pearson/ICC 或“可靠强损伤”。LDH 相应比值 1.57062 也不能自动映射为特定生物失效原因。

还有三项解释边界：

- 同药八剂量和多个 well 不是独立药物或独立细胞世界；组 bootstrap 区间条件于当前 screen 的 plates/controls。
- 548 个缺 count 孔按原配置计失败是正确的；不能假定它们都是强细胞损失，也不能假定缺失与响应无关。未来功能单独用途若改变完整观测要求，要另立人口/成本定义，不能偷偷重新纳入旧门。
- 此时 MT 与 LDH 均为同时 surrogate。重复同一 signal 不等于独立损伤裁决；MT 降低、LDH 增高及两者不一致都不能直接作为真死亡/assay 伪影标签。

## 对固定 k=20 尾部 pilot 的判断

根代理提出一次独立命名的 dev 暴露 pilot：固定 20 个不同化学组，由第一板指标选 compound-dose，在第二板评价；互换方向仅敏感性。比较 highest-dose、已付费同时间 count 与 hash-random；screen flags 为 MT 低于 control 的 50%、LDH 增加 3 control-MAD；要求 precision@20 超最强 baseline 至少 0.10 且两个方向一致。

**作为一次便宜的技术尾部描述，这个设计可以做；作为改变框架研究方向的证据，单独不够。** 第一板已经测过所有候选目标端点，第二板检验的是这些已测动作能否技术复现。阳性最多保留“直接测量后复核少量强 screen flags”的常规工作流；没有未测药物状态传播，没有 world 必要性，没有新的实验选择机制，也没有程序继承。

50%/3-MAD 是新定义的工程 flags，0.10 在 k=20 时是多两个复现 flags；这些数值需要明确标为新用途约定，不能声称它们由原 G0a 预注册或已经代表药物发现/成本收益。“3 control-MAD”究竟用 raw MAD 还是 1.4826*MAD、one/two-sided、按哪个板计算，应先写死。

若仍执行，只批准一份冻结的新协议和一个预算，不扫 k/阈值。MT/LDH 的提名方向、是否分别为两个主要描述还是固定组合、tie-break、每组只选一动作、baseline 规则与全部比较族必须在开逐动作数值前固定。不能看哪个端点好就晋级它；两方向不算两次独立验证。baseline 与候选获取同一允许历史和实测数据，报告所有 acquisition 成本；随机或最高剂量臂忽略已买信息不意味着现实中同成本。报告原始命中分子/分母、选中集合重叠、失败井和不确定性，不以 episode 数或交换方向制造精度。

因此，我不反对一次注明 POST_HOC_DEV_TECHNICAL 的 pilot，但认为其优先级低于认证独立裁决。**若没有独立复核的可获得路径，不建议仅为试图出现阳性而执行它。** 无论 pilot 结果如何，原 G0a STOP 保持，G0b/CNN/新架构不自动重启。

## 一个足以改变方向的最小真实验证建议

建议收缩为一个新问题：**少量、第一板提名的高响应条件，能否在独立培养/独立实验批次中，比简单 count/dose 提名更可靠地复现预先定义的 readout flag？** 这是新的“稀疏复核”应用；不是广谱连续响应预测，不是 RSI。

最小执行路径：

1. 先仅做来源/实验记录资格，确认是否实际存在同化合物、同剂量、同暴露时长与同细胞体系的独立培养/批次复核。另一个技术 plate 或同一 source 的重复读板不合格。当前没有认证此资源，本文不声称它已存在，也不读取任何新结局。
2. 若存在，先锁定来源和独立性，再由原 dev 第一板按一份固定双端点规则提名 k=20 个化学组；同时冻结 count/dose/hash 基线。冻结各臂提名的并集及全部确切 compound-dose，不挑已知成功的动作进入验证。两个端点完整报告；外部复核不能反过来改原 dev 阈值、排序或 eligibility。
3. 在未供提名优化的真实独立培养/批次上，评价同一 MT/LDH screen flags 的复现，比较最强固定 baseline，并计入为各臂选中条件做复核的全部费用。若有技术机制不同的独立功能 readout，可预先作为生物裁决；若没有，只报告独立培养 readout 复现，不改称真实伤害或临床风险。k、最小有用差和所需精度应根据这个复核用途/成本预先冻结；原 pilot 的 0.10 不能无解释地搬入。

该验证阳性会改变的是资产用途：从不合格的全域 rank/连续 endpoint 任务，转为有可重复真实信号的稀疏复核任务。它仍不提供一个新颖 Agent/world 机制；只有进一步出现能区分更新假说的真实行动菜单与可比较任务流，才值得重新审查原总目标。

停止条件：没有独立培养/批次匹配；复核菜单只有既有政策挑出的成功条件而缺少基线候选；独立 screen flags 不复现；count/dose 已匹配；或者效用差上界低于预先冻结的 δ_use。任何一项失败即停止该稀疏应用，不再用另一个 quantile、更多剂量、另一个 endpoint 或 CNN 救结果。精度不足只记 INCONCLUSIVE，不称支持。未能资格独立裁决时，保留 OASIS 原 STOP 并转向新资产的识别资格。

## 与独立反方的交叉质疑

反方同意旧门 STOP，但否认它是所有稀疏决策的必要条件；认为低 MT 差异比加低 rank 既可能对应中心噪声/少量极值，也可能是 outlier，不能称强损伤。它支持一次廉价 dev 描述而不要求先有外部培养，建议单 MT 方向、单预算/阈值、化学组去重，至少给 count-only 与 dose-only 提名。它同样拒绝 tail 阳性自动重开 G0b。

我接受这些必要对照与结论边界。剩余分歧是投入优先级及端点选择：我最初提出 LDH 单方向，反方偏 MT，根代理建议双端点；三种选择尚无独立于结果的共同用途依据。这恰好要求预先冻结并完整报告，不能择较好端点。我的最终建议是先认证独立裁决可得；反方认为一项廉价 dev 描述本身亦可合理进行。这个分歧不是关于旧门是否继续，旧门均保持 STOP。

前轮 control transport 的最终回应已在本次收到：反方明确接受细胞存在依赖干扰的最小反例，要求同时允许 T/I 更新及 abstain；并指出即使控制完美，固定模块 refit+Bayesian discrimination 也能正确路由。故正确路由是信息/识别资格，不自动构成新算法或 world 必要性。此补记避免把之前暂未收到最终回复误写成永久未决。

等待对“先找独立裁决还是先一次 dev tail 描述”问题的具体最后回应；到达后仅追加，不能把无回复当共识。

## 本轮最终资源决定（追加）

根代理决定 **本轮不执行尾部 pilot**，保持 G0a STOP，G0b/CNN/所有架构搜索 NOT_RUN。支持证据是：原阴性按注册合同有效；新 pilot 只复核已测动作，尚无能改变世界模型/RSI方向的独立裁决；端点与新 flags 的用途依据尚未共同建立。重复改变指标可能把止损门变成追阳性流程。

保留反方异议：一次很便宜、诚实标为 dev 的尾部描述有测量诊断价值，不应因缺外部培养而一概禁止。该异议不否认原 STOP，也不支持重开 G0b。MT 单方向、LDH 单方向和双端点规则的独立选择依据尚未解决；本轮不靠执行其中一种来制造共识。
