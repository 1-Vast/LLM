## 裁决

支持开展有界 dev-only G0，支持先可靠性再信息增量，且不支持在此时实现世界模型、Agent 或 RSI。开放前有一项明确协议偏差应修复：先按身份固定重复板，再附加 QC，不能在筛过数值以后挑首两块合格板。另需预先明确 G0b 的形态预测器选择规则，否则两种模型中挑赢家会使“正下界”含义不明。

## 必须先处理的问题

1. **首两重复板的选择顺序与协议不符。** 当前 main 先取 eligible=dev[observation_pass]，再把 eligible 交给 pairs_for_repeat。若身份菜单的前两块板中一块失败、第三块合格，函数将第三块替补进来。该选择受 MT/LDH/count 数值 QC 影响，违反“首两 distinct plates 与数值独立”。最小修复是在身份完整 dev 菜单上固定首两 distinct (batch,plate)，随后附加两孔的 QC 和变换值；失败对不能由后续重复替补。报告预定配对数、失败配对数和最终完整配对数；相关只对预定完整对计算，且明确条件样本。其他重复可描述，不能救 primary。

2. **不可估计时应明确失败，而非在输出中途抛错。** repeat_summary 未处理某端点常数、bootstrap 重采样后常数、零方差或 NaN。spearmanr/quantile 可产生 NaN，差异除以零可产生 Inf；save_json(allow_nan=False) 随后在已写 Parquet/CSV 后失败。raw LDH identity 的 np.max 也会被一个缺失值变成 NaN。最小修复为明确的 null、原因与 gate=false，并保留缺失计数；不可用 nanquantile 静默删掉坏重采样来获得好区间。无需更改已冻结的门槛。

3. **G0b 中哪一个形态模型必须过门尚不充分确定。** “ridge 与 ExtraTrees 分别报告、同时保守解释”不是统计选择规则。若允许事后挑更好的形态家族，必须对候选选择作同时推断；否则先冻结一个 primary，另一者只作敏感性。另一种严格但更苛刻的选择是要求两个形态家族各自胜过两个 count+chemistry 家族。若 primary 是所有端点与对照的交集，要求每项单侧过门并不额外制造多重比较问题；若是任何一个家族获胜即可，则是并集，需要处理选择。所有选择必须在读分数之前确定。

## G0a 门槛能说明什么

>=90% 物理孔覆盖、>=100 个有配对的化学组、两个端点的菜单级 Spearman>=0.60 且下界>0.50，只是这一固定 screen 中重复排序足够稳定的工程资格。它们不认证独立培养、细胞死亡真值、临床损伤、可获益决策空间、形态增量或世界模型。

总体相关可能主要来自 8 剂量的广范围差异与少数强损伤化合物；同剂量、阈值附近或低细胞损失区域仍可能无法区分。因此不能把 G0a pass 当作“有可学习的新机制”。这些细分只能作描述，不改 primary。

当前相关按 action 行加权，较大化学组含更多化合物/剂量会有更大权重；G0b 则预定 compound 后 chemical-group 等权。两者都可作为各自任务，但不能把前者解释成等权化学组性能。bootstrap 必须保留每次抽到的重复组 multiplicity；代码当前索引拼接做到了这一点。

chemical-group bootstrap 保留了组内剂量依赖，却没有重采共同板、批次与 DMSO 控制的不确定性；多个化合物共享同一控制中心/尺度。区间应明确为固定已观测 screen 的条件区间，而非新培养/新批次总体区间。若后续要声明跨板稳健性，需预先另做板对/批次阻断敏感性或合适的多层估计；不能仅靠大量药物把共同板误差洗成极窄下界。

LDH MAD>0 只保证该变换可定义，极小 MAD 仍可能放大微小差异；高 MAD 也未受到上限约束。没有阳性控制，无法从 DMSO 方差推出动态范围。门失败只关闭这套变换/门配置，不能推出原始测量完全无效。MT/LDH 的尺度不同，两个预定连续目标也不是互相的金标准。

## 假增量风险与最低限度公平比较

- **真实 count 是付费、同一时间的生物观测。** count 比 chemistry 好仅说明购得信息有用；不能称预测状态或 Agent 的贡献。共同 count 条件下再加真实 CNN，只是额外观测信息，不能称世界模型。协议已正确写清，结论必须保持这一边界。
- **共同合格交集才可比较。** 因缺失 count/CNN 或 QC 而缩小的群体，所有主要模型须用同一训练与测试交集；同时保留原始菜单的损失和失败测量费用。chemistry 的更广覆盖不能被悄悄忽略，也不能把失败读数当阴性。G0a 原菜单不得因 CNN 文件可用性重新定义。
- **所有 baseline 共享剂量、行/列、批次和允许的 DMSO 控制。** 同一化学组的别名、剂量、物理重复必须同 fold；训练折拟合 imputer/scaler/残差化。现协议这些要求必要且简洁。test-plate DMSO 在声明的已购 assay 条件下可用；test-compound response 不可用于任何归一化。
- **count+chemistry 必须是主直接对照。** 仅胜过 chemistry 或 count 单独均不足。固定 ridge 与 ExtraTrees 是低成本信息门，不足以证明已超过充分调优的直接预测器；正式世界模型阶段仍需同辅助监督、多输出与简单混合。
- **训练折方差归一化 MSE 的 0.02 是工程阈值。** 它不等于临床重要差异或确认收益。即使两端点都过门，也只允许另立 predicted-state 资格；还应报告原尺度误差与重复误差，避免把几种不同比例误读成实际获益。
- **CNN 前训练来源未排重。** 本门最多是固定公共表征在 OASIS dev 化学组留出的信息筛查，不能叫严格未见预训练化学或独立迁移确认。全数值非 Metadata 特征白名单仍须核验 schema，不可把拼入的功能 Metadata 带入特征。

不增加模型、探针或架构。先修复首两板身份选择，并使不可估计情况以失败状态完整落盘；预冻结形态家族规则。G0a 不通过就停止该配置；G0a 通过再按既定共同群体做 G0b。G0b 无增量只关闭该公共表征/端点配置；G0b 有增量仍不证明 observation repair、世界模型、继承、联合收益或 RSI。
