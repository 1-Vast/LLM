## 新确认的失败事实

限域审计 `data_auditor/target_failure_audit/DIAGNOSTIC.json` 检查全部 72h L 的 288 个 image 记录、96 个井：284 个非负、4 个有限负值；没有缺失、malformed 或非有限项。异常均位于 25µM：

| opaque context / well / image | 导出 L | 已限域打开的 total / D | 关系 |
| --- | ---: | --- | --- |
| mcer-1e3 / H7 / 1 | −2 | 142 / 144 | L=total−D |
| mcer-3e3 / H12 / 1 | −24 | 357 / 381 | L=total−D |
| mcer-3e3 / H12 / 2 | −1 | 468 / 469 | L=total−D |
| mcer-3e3 / H12 / 3 | −15 | 472 / 487 | L=total−D |

四个差值关系精确成立且 D>total。H7 三个 image 的原均值为 26/3，虽为正仍不通过预定逐 image 非负 guard；H12 均值为 −40/3，其 `log2(mean+1)` 在实数域也无定义。因此不能把失败仅归于逐 image guard 过严，更不能用改为先平均来继续原门检验。

这些事实支持所查出口值呈差值式算术，并区分了数值域冲突与文件解析问题。它们不证明制作意图、背景校正原因、真正活细胞定义，或哪种替代 signed likelihood 正确。现阶段应说“注册非负计数观测模型不适配该资产配置”，不能说“整个来源无用”或“所有操作读数均不可靠”。

## 交叉质询后保留的边界

反方认可“信息价值未检验”，并挑战两种可能的过度反应：全盘否定来源，或把非负 total 改称 LIVE 续跑。本人明确拒绝两者。即使未来 total 均非负，也可能是全部标记对象库存，研究问题与活性不同；当前只查了四个坏记录的 total/D，未打开其他未来 total/D，不能提前断言其分布。

本人要求数据审计方将差值式关系与出口意图、viability 和合理 likelihood 分开；审计方明确同意，反方也接受我对来源与替代终点的边界回应。这里没有需要用补测来裁决的代理立场分歧；尚未解决的是证据本身。新的来源或观测模型若值得探索，最低须先认证：一手 assay/字段定义与单位/符号语义，L/D/total 的生成和校正关系，合法前缀/目标/时间零及固定 image panel，以及 physical well、experiment、biological run 的标识与文件重叠。无法认证的 context 继续保留 opaque，不据此主张背景运输。

非负本身不使 total 成为活性指标。未来若以其为新操作终点，需一手测量定义、独立功能关联证据，或将新问题明确限定为该标记总量的预测；只说 GFPtotal≈live 不足以称 viability。任何新任务仍须独立科学理由、暴露声明、新前瞻协议及反方评审，旧 gate 保持资格中止。若声称一般药物机制或核心框架，需真实多药/背景与独立 matched runs；只改同源目标不足。

来源资格通过也不等于机制成立：仍需 D0/D24、强直接预测器、普通拟合与简单混合的公平比较。若要由信息增益升级为 turnover 或 death dynamics 解释，还需独立事件/功能测量及 marker/clearance 资格，不能单靠再加 latent 模块。当前无算法创新证据，普通多变量推断与既有 BESTDR 相关能力仍是直接先例。
