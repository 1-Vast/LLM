Primary useful signal requires out-of-fold macro MAE reduction>=.05log2units AND>=10% versus live_only direct. This is a pragmatic3.5%factor in(meanreadout+1), not an estimated measurement noise floor or small-count guarantee. It was chosen before this distinct dataset's numerical responses and is not a relaxation of the stopped HTS001 test. Report all folds and signs regardless of outcome. To argue a dynamic-dead HISTORY property, also require the same margins versus BOTH dead_initial and dead_snapshot; otherwise only static/endpoint extra-channel value is supported. No statistical significance or universal causal claim from these technical dose strata.

If primary fails and neither kinetic nor pooled-family dual contrast reaches the same useful margins, stop expanding this24h→72h extra-channel application on this asset. This is evidence about these registered models/data, not proof of no headroom or all virtual cells failing. If primary fails but ordinary kinetics suggest benefit, classify mixed/model-dependent and require an independent registered check, not promote a core. Any fitted damage state is an assumed model coordinate, not measured mechanism.

World/agent/procedure/weight/joint/RSI remain separate: this gate tests readout information and ordinary kinetic bias only. No functional AL, executable research-agent, CL, inheritance or improvement-of-improver benefit is measured. Do not add them as decorative modules after a negative.
