The supported engineering workflow is connected: a scoped prediction can inform an explicit selector, an affordable persisted plan obtains a real provider result, typed/QC-qualified observations update evidence and the registered validator controls terminal decisions. This is distinct from establishing virtual-cell decision value. Forecasts do not become measurements. Prediction reconciliation remains process-local and has no new external calibration receipt.

Existing Round 2 results do not establish a general terminal-utility benefit. Both task baseline-versus-fixed uncertainty intervals include zero. Four L1000 well-count discrepancies remain unresolved source linkage; the explained duplicate slot still has an unresolved plate discrepancy. Missing comparable outcomes require declared bounds. Chemical skeleton/component inference remains separate from physical plate/batch dependence; both tasks have one connected physical component, so independent physical confidence intervals are not estimable.

STATE conclusions remain restricted to currently registered, previously exposed conditions. WorldV2 swapping remains unavailable without its saved fitted transitions or a complete frozen forecast bank; no refitting was used. Decision-time measured state, availability times and sample relationships are insufficient, so a true pre-action state-gain arm was not run. Newly supported query refusals do not establish new compound, dose, time or context support.
