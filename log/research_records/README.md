# Retained research records

This directory retains historical protocols, reports and key result summaries previously stored under `research/`. It is the durable report location when the experimental code workspace is cleaned.

Bulk data and external source artifacts are stored in the corresponding `data/raw/`, `data/external/` or `data/processed/` subtree. Consult the [migration plan](../20261023/report_consolidation/DATA_MIGRATION_PLAN.json), migration receipt and archive-location index for exact paths and content hashes. The original [archive manifest](../20261023/report_consolidation/ARCHIVE_MANIFEST.json) records the earlier copy operation; its original archive paths are historical where the later migration map supplies a new data path.

Read the [concise scientific summary](../20261023/report_consolidation/RESEARCH_SUMMARY.md), [registered study summary](../20261023/report_consolidation/LUNA_EARLY_SUMMARY.md) or [recent decision index](../20261023/report_consolidation/STUDY_INDEX.md). Original report bytes retain their historical relative links and context; use these consolidated entry points for current navigation.

Data were copied or relocated as bytes without interpreting protected outcomes. Preserving a report or hash does not establish independent biological replication. Retired exploratory scripts are not promised to remain executable in the current checkout. Experimental implementations belong in `research/`; this operation promotes no code into `src/` or `tools/`.
