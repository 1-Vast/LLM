# MAESTRO: evidence-conditioned histone response transfer

Protocol written before opening numerical GCP outcomes. This is a new exploratory modality; it does not extend the validated L1000 RKT certificate.

## Question and falsifier
Can an agent use newly retrieved, attributed pharmacology to qualify measured reference donors, improving a fixed numerical cross-cell transfer model's experimental choices? Success requires a positive paired compound-bootstrap 95% interval against both the strongest development-selected deterministic policy and a conventional agent with identical numerical information, source access and budgets. A positive prediction metric alone does not prove improved decisions. Failure leaves the scientific method in research.

## Data and isolation
Use Panorama LINCS GCP 2020, 24 h, A375/MCF7/PC3/YAPC, exact same dose within each compound. Metadata-only connectivity hash split uses `gcp-transfer-20261013:` and proportions .6/.2/.2. Exclude DMSO, vorinostat and staurosporine from evaluation and fitting; exclude published semagacestat/BMS906024 examples from test. Eligibility requires all four contexts with at least two retained samples at one common dose; choose the lowest common dose if multiple. Reference, development and test remain separate. The metadata audit predicts 66/27/20 eligible compounds.

Released LVL4 uses whole-plate row medians and can embed held-out outcomes. Instead download LVL3, subtract each probe's same-plate DMSO median, using only identified vehicle wells. Never use treated query wells for normalization. Released upstream sample/probe QC remains cohort-dependent; disclose this limitation. Feature IDs are the intersection across relevant plates. Retain NaNs; fit only features with finite reference means in all four contexts. Missing query target measurements invalidate only that scored prediction, not silently become zero. No numerical outcome-based compound removal beyond this declared missingness rule. Retained samples are not authenticated independent cultures.

## Budget and models
Each evaluation compound supplies one authorized A375 anchor; acquire one follow-up context/feature/sign decision from MCF7, PC3 or YAPC. Donor differences use measured references only. Reference-derived per-feature scales are the pooled standard deviation of vehicle-centered reference means (floor .1 log2); no test fit. The numerical base is cross-cell multi-output ridge with reference leave-one-out lambda selection from 1,10,100,1000. Baselines: reference target mean, shifted anchor, ridge, phenotype five-neighbor residual transfer, chemical five-neighbor residual transfer, and deterministic lexical pharmacology donor transfer. Residual transfer adds the weighted reference (target minus anchor) difference to the query anchor. Structure uses Morgan radius2/2048 Tanimoto; phenotype uses reference-centered cosine. Never infer calibration outside the RNA certificate's scope.

Agent candidate menu is the union of the top eight chemistry and top eight anchor-phenotype reference donors. Each arm receives the query's live PubChem description and may request five donor descriptions, then chooses up to five source-supported donors or abstains. Integrated and conventional arms receive identical base/donor numerical diagnostics; integrated instructions explicitly require competing hypotheses and evidence-gap resolution, conventional instructions request an ordinary scientific analysis. Agent-only omits learned forecasts but retains the observed anchor and empirical donor similarities. Evidence comes from current PubChem descriptive pharmacology, never GCP outcomes; known drug mechanisms/pretraining contamination remain possible. Exact source content/URLs/time/hash, model messages, usage and parsed decisions are cached.

Fixed decoder: average valid selected donors, use phenotype weights if abstention/invalid output; integrate as .5 ridge + .5 donor prediction. Agent-only uses donor prediction without ridge. Also evaluate .5 ridge + .5 phenotype as the no-agent model, source-free initial donor choices, and deterministic shuffled-query donor choices as ablations. No language model may invent response vectors or override numerical decisions. Scientific evidence is retrieved-source evidence, not a new laboratory measurement. API reservation ceiling $2.50 additional, within the pre-existing $10 session authorization; actual token usage retained separately from conservative reservations.

## Endpoint, selection and inference
Select the maximum absolute predicted standardized response over the three target lines and retained features, with predicted sign. A hit requires observed signed vehicle-centered mean >.5 log2 and all available retained replicates having the predicted positive sign (at least two finite replicates). This is an assay-level directional perturbation, not target engagement, viability, disease benefit or causal mechanism. Secondary: centered cosine across all held-out targets; signed response magnitude; hit oracle attainable under this endpoint; source coverage, abstentions, runtime and usage. Development chooses the strongest deterministic baseline by hit rate, breaking ties by mean cosine then declared order. Do not tune the .5 blend or prompt based on test outcomes. Agent calls may run on test after MODEL_FREEZE; all choices must be persisted before the evaluator reads test targets.

Inference uses paired compound bootstrap (10,000, seed20261013) and exact paired discordant sign test. The factorial interaction is (integrated minus no-agent model) minus (agent-only minus shifted anchor); conventional-agent comparison distinguishes scaffolding from access alone. Report all predefined comparisons without selecting a favorable metric; small sample size precludes broad generalization. No empirical biological efficacy claim without independent confirmation. Models and prompts freeze after reference/development feasibility and before any test-target evaluation. Deviations are logged explicitly.
