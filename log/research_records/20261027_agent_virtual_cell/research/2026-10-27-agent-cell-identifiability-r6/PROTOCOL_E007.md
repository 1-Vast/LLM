# PROTOCOL E007（预注册）：那 4% 的反序是**可复现的**还是噪声的？

2026-10-27，R6。**在任何统计量计算前冻结。** 只读 `PAIR_SCREEN.csv`（SHA256 56a4e4a195673160edcb1baa209a15409b3639ff6ab0405558cc5ab3198d5f23）。不下载新数据，不读 sealed/reserve/vault，不调 LLM 生成生物结论。

## 为什么这是下一个问题

R5 得到（探索性）：可读间隔 ≥0.10 的配对里，跨细胞反序 4.00%，同细胞对照 0.29%。**但 4% 里有多少是真的、有多少是跨日期/跨板的额外噪声，R5 没有回答。** 同一细胞对照只覆盖"同一天两块板"的噪声；跨细胞比较还包含不同天的差异。如果 4% 主要是这种额外噪声，那么 R5 的正面结论本身要撤回；如果可复现，则它正是条件世界模型要学的目标。

## 三个可分离的检验

- **T1｜反序的可复现性（主）**：把每个细胞的两块板分成"独立配对"——配对 A 用每个细胞的第一块板，配对 B 用第二块板。同一对细胞、同一对单元在两个配对里各自判定是否反序。若反序是真的、稳定的，两个配对应显著重叠；若纯粹是测量噪声（单次率 ε≈0.29%），重叠率应 ≈ ε² ≈ 0.0008%。**估计量：θ̂ = 重叠率（在"两配对都可读"的单元对上）；可复现比例 = (θ̂ − ε²)/(r − ε)**，其中 r 为单配对反序率。判据：θ̂ 的布局聚类 95% CI 下界 > 3×ε² 才称"可复现"。
- **T2｜反序集中在哪些结构上**：把每个布局的单元对按"跨细胞符号是否一致"展开，问反序是集中在**特定药对**（同一药对在多个细胞对上都反序），还是集中在**特定细胞对**（某些背景组合大量反序）。做法：对每个药对统计它在多少个细胞对上反序（k/m）；对每个细胞对统计它反序多少药对。报告两者的过散度（观测方差 / 二项方差）与矩估计 ICC。
- **T3｜与噪声零分布的对照**：用 R4/E006 已校准的参数零分布（它在"同细胞"对照上预测 0.851、实测 0.896）生成同样规模的 M0 数据，用**完全相同**的流程算 T1 的 θ̂ 与 T2 的过散度。判据：只有当观测明显超出该零分布时才说反序结构不是噪声。

## 判定

- **H010**：T1 的 θ̂ 显著大于噪声预期 → 反序可复现 → R5 的正面结论成立且**升级为可学的目标**；否则 R5 的 4% 主要是跨日噪声 → **R5 的 A 撤回**（记录在案，不换名）。
- **H011**：T2 的过散度在药对或细胞对任一侧显著超出 T3 零分布 → 反序有可条件化的结构（"适用条件"存在）；若两侧都不超出 → 反序在结构上等同随机，**任何条件化模型都无法在该资源上比共享序先验更好**，这条线停止。
- 两者都只作探索性（这些板已被 R2 当评分终点、且跨细胞跨日期）。
