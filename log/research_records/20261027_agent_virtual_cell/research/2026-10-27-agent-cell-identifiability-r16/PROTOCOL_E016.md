# PROTOCOL E016（预注册）：conformal 覆盖-风险曲线——能不能给出"有效的"不确定性

2026-10-27，R16。**在任何覆盖率或 AUC 被计算前冻结。** 只读 `PAIR_SCREEN.csv`（SHA256 56a4e4a1…d5f23）。不下载、不读 sealed、不调 LLM。

## 背景与问题

R12 显示：手搭的 6 特征 logistic **无法**预测"这一次的剂量比预测是否命中"（AUC 0.477）。R15 把该结论收窄为"我们的模型失败"，并指出 conformal 是标准替代、我们没测。本轮正式测它。

具体问题：**在留一布局的分布偏移下，conformal 能不能给出覆盖率有效的误差界？能否用它的区间宽度做选择性预测（弃答）？**

## 单元与预测

单元 = (布局, 化合物对, 留出细胞)。预测 = 其他细胞同格均值表面 → argmin。非一致性分数 = 该单元的 **regret**（所选剂量组合的真实 viability 与真实最优之差，≥0）。

## 两种 conformal

1. **普通 split conformal（按布局留一）**：对每个测试布局 L，校准集 = 其他所有布局的单元；`q_α` = 校准 regret 的 `⌈(n+1)(1−α)⌉` 分位。覆盖率 = 测试单元中 regret ≤ q_α 的比例。
2. **归一化（局部自适应）conformal**：`s_i = regret_i / spread_i`，其中 `spread_i` = 其他细胞该格子表面的标准差在网格上的平均（**只用其他细胞**）。测试单元 j 的界 = `q_α · spread_j`，宽度随单元变化，可做弃答。

α 网格固定为 {0.05, 0.1, 0.2, 0.3, 0.5}。

## 判据（预先写定）

- **H032（覆盖有效）**：普通 conformal 在 α ∈ {0.1, 0.2, 0.3} 上，实测覆盖率与名义值（1−α）之差 ≤0.05，且布局聚类 95% CI 含名义值。
- **H033（弃答有益）**：按归一化 conformal 的宽度从小到大选取子集，其风险-覆盖曲线（AURC）显著优于随机弃答（布局聚类 CI 不含 0，AURC 定义见代码：按选择比例积分的平均 regret）。
- **H034（宽度有信息）**：`spread_other` 与 regret 的 Spearman > 0，布局聚类 CI 下界 > 0。若成立，则 R12 的"不可预判"被**部分推翻**：虽然逐次命中不可预判，但**误差幅度可以被有效上界并排序**。

## 判决含义

- H032 成立但 H034 不成立 → conformal 给出**有效的平均误差界**，但无法区分"这一次更可信"。
- H034 成立 → 我们有了一个**可验证的不确定性信号**（R12 的负面结论要收窄到"命中与否"这一具体标签）。
- H032 不成立 → 说明布局间的分布偏移破坏了可交换性，conformal 在这个切分下也无效；必须报告偏移量并停止该线。

## 不做与边界

不涉及药物选择、机制、未见药物。功能读出只是归一化存活度；探索性（板已被 R2 当终点、跨细胞跨日期）。conformal 的保证依赖可交换性，而布局间存在日期/板差异——这正是本轮要检验的东西，不能假定它成立。
