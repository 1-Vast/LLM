# PROTOCOL E013（预注册）：能不能事先知道"这一次的剂量比预测可不可信"？

2026-10-27，R12。**在任何 AUC 或阈值被计算前冻结。** 只读 `PAIR_SCREEN.csv`（SHA256 56a4e4a1…d5f23）。不下载、不读 sealed、不调 LLM。

## 问题

R11 得到：跨细胞预测"最优剂量组合"平均很好（hit@3 0.671），但**逐化合物对从 0.000 到 1.000**。一个只在平均上成立的预测器不能用。本轮问：**只用不涉及目标细胞的信息，能否事先判断这一次的预测可不可信？** 这正是"有适用条件的预测"里"条件"的具体内容——条件不是细胞类型，而是"这一对化合物 + 这批其他细胞"给出的可辨识度。

## 单元与标签

单元 = (布局, 化合物对, 留出细胞 c)。标签 = R11 的 `mean_surface` 预测器在该单元上的 **hit@3**（是否命中 c 的真实前 3 格）与 **regret**。

## 特征（全部只用 c 以外的细胞）

| 代号 | 定义 |
|---|---|
| `argmin_agree` | 其他细胞两两之间 argmin 一致的**比例**（对每个"其余细胞对"算是否同格，取均值） |
| `gap2` | 池化表面（其他细胞同格均值）的 (第二小 − 最小) / 表面标准差 |
| `plateau` | 池化表面中落在 (最小 + 0.04) 以内的格数占比（0.04 = 文件级噪声的近似） |
| `dyn_range` | 池化表面的 (max − min) |
| `edge` | 池化 argmin 是否落在剂量格边界（1/0） |
| `n_other` | 其他细胞数 |

## 判据（预先写定）

- **H023（可信度可预测）**：用 6 个特征的 logistic，在**留一布局**交叉验证下对 `hit@3` 的 **AUC ≥ 0.65**，且比最好的单特征 AUC 高 ≥0.05。区间用布局聚类 bootstrap。
- **H024（可部署规则）**：存在阈值 t，使 `argmin_agree ≥ t` 的子群 **hit@3 ≥ 0.80 且覆盖 ≥30%** 的单元；同一阈值下子群规模与其 hit 的相对基率提升报出来。
- **H025（校准）**：把预测概率分箱后，预测与实测 hit 率的偏差 ≤0.10（单调性也要报）。
- 若 H023 不成立：判"可预测性本身不可预判"，R11 的 0.671 只能当平均描述，不能当可用工具。

## 不做

不涉及药物选择、机制、未见药物。不做阈值事后调优（阈值网格预先固定为 0.5/0.6/0.7/0.8/0.9）。功能读出只是归一化存活度；探索性（板已被 R2 当终点）。
