# PROTOCOL E077（预注册）：对 triage 规则做**嵌套验证**——阈值也必须在内部选

2026-10-27，R80。**在任何计算前冻结。** 只读 R78 的细胞表。

## 为什么

R79 得到三特征 AUC 0.789，但**阈值是在同一批 LOO 预测上读的**，所以"标记 55%、召回 94%"这个点偏乐观。

要把 triage 规则变成**可用**的东西，必须让**阈值也在内层选**，再在外层留出的细胞上评估。

## 构造

- 外层：留一细胞（123 折）。
- 内层：在 122 个训练细胞上再做留一，得到**内层出折预测**，用它们**选阈值**。
- 选阈值的规则（预先固定）：**在精度 ≥ 0.50 的阈值中，取召回最高的那个**；若无阈值满足精度 ≥0.50，则取精度最高的阈值。
- 外层：用全部 122 个训练细胞重拟合，对留出细胞预测；用内层选出的阈值判断是否"标记为不必个人化"。
- 聚合：外层被标记细胞的**精度**与**召回**。

## 判据（预先写定）

- **H202（嵌套后精度下降）**：嵌套精度 **< R79 的 0.44**（即流程本身没有表面看起来那么好）。
- **H203（triage 仍有用）**：嵌套召回 **≥ 0.70**（即使精度一般，能覆盖大部分"永不获益"细胞）。
- **H204（可用于排除）**：嵌套精度 **≥ 0.70**。
- 若 H204 成立 → **可以做排除**（推翻 R79 的判断）。
- 若 H203 成立而 H204 不成立 → **R79 的"只能 triage"结论加固**。
- 若 H203 也不成立 → **这条规则连 triage 都不够**。

## 边界

- 32 个正例、123 个样本，嵌套估计的方差大；必须先固定规则再跑，不调规则。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
