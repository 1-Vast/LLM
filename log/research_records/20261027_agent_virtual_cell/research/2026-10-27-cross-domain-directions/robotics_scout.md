## 两条原理的映射

**原理一：按任务敏感性分配辨识精度。** R-P1的机制是：任务对各物性误差敏感性不同 → 允许精度不同 → 探索优先估计影响任务的物性。这里可问：哪些响应规律会使新背景的后续未购药物选择不同；允许买的板能否把它们分开？这不是要求重建唯一细胞世界模型。

**原理二：用可实施输入激发缺失方向，且区分功能参数与机制真值。** R-P2显示，一般轨迹覆盖仍可能漏掉决定后续任务的方向；参数补偿可同时产生好预测和错误物性。生物对应是：大量相关孔、同类剂量、同批培养可能只更精确地测已有方向。需要不同的可观测对比，而不只是更多技术重复。FIM主要解决局部参数精度，不等于结构模型鉴别，也不解决候选规律全错。

| 原变量/假设 | 生物对应 | 不可省略的替换条件 |
|---|---|---|
| 同一对象固定物性 | 一个背景内可重用的响应规律/功能性参数 | 细胞状态组成、独立培养和批次可能变化；“固定”只是工作假设。 |
| 同一对象dense state–action轨迹 | 每板/培养批次一次或少数终点；单细胞时间点为不同被破坏群体 | 本方案的状态是**科学家对静态规律的belief**。第t次买板更新belief，不是同个细胞经历第t步反馈控制。 |
| command和探索动作 | 可买整板、剂量、配对参照；未来允许时才有输入历史 | 现有静态板没有的信息，不能用仿真或世界模型生成。 |
| 仿真真实参数与特权策略 | 未购药物响应和机制通常未知 | 不能把自己的世界模型当真值teacher；源方法误差阈值一般不能直接估。 |
| 一次任务与探索成本 | 下一轮验证药物/组合、浪费资源 | 全板、培养、参照、独立重复、失败板、等待和计算/控制成本均计入；本轮未估实际净收益。 |

初始笔记B的输入历史支线保留为条件问题：如静态板完全混淆，未来可比较随机化、可交换独立培养群体在不同历史下的输出分布。它依赖新增历史/培养测量，仍不恢复单细胞轨迹。本轮没有核对足够近期药物顺序先例，不判断其新颖性，也不把它包装成现有数据算法。

## 具体研究问题与最小机制：R-I1 v1

**能否对“新背景的未购药物动作”，刻画实际板对比在消除已知批次混淆后能辨识的响应规律，并找出最小新增什么观测可解除剩余歧义？**

用户是选择下一轮验证药物的药筛团队。可用输出是诊断板、它能排除的规律、它支持的动作范围及成本。令r代表响应规律，`a*(r)`是其最优药物动作。若`a*(r)!=a*(s)`，分开r/s可能改变任务；但若所有允许板P均有`p_r(Y_P)=p_s(Y_P)`，任何自适应策略都无法分辨二者。后验收缩与重复同类孔不改变这个信息边界。

最简版本先审不同结构解释能否在真实板上产生不同**可观测对比**。若它们只通过共同板偏移区别，则不可辨；若存在消除已知偏移后仍分离相反动作规律的对比，才有可试实验。需要什么对比由允许板和混淆决定，不凭先验画一个理想探针。规律集全不适用时应输出拒绝/需新增证据，不能把剩余一个错误模型当恢复机制。

## 正向构造与反例

以下为思维构造；仅核对算术，不是细胞模拟或观察到的收益。两条等先验规律`r=+1/-1`均拟合已有数据。未购买目标药物A/B的效用为

```text
U(A;r)=0.5+0.2r,    U(B;r)=0.5-0.2r。
```

允许买的一整块诊断板含匹配探针和必要对照，其某线性尺度响应为

```text
Y(q+) = b + alpha + 0.05r + epsilon+,
Y(q-) = b + alpha - 0.05r + epsilon-,    |epsilon±| <= 0.01。
```

差值消除共同板偏移b。r=+1的差值范围`[0.08,0.12]`，r=-1为`[-0.12,-0.08]`，故可识别目标动作，而仍不知完整机制。另有高方差板只观测与r独立的背景量；最大方差可能选它，诊断板才改变A/B选择。固定选A的期望regret是0.2；诊断后是0；若**全成本换算为同一效用尺度**为0.05，净改善0.15。

起作用的条件是：板内对比确实消除混淆；分歧超过独立培养误差；探针到A/B的共享功能规律成立。此构造没有证明当前数据满足条件，尤其没有制造未知药物的功能替代关系。

反例：

1. 所有允许板对r/s同分布，只有未购目标药物动作相反：买再多这些板也无信息。
2. q+/q-有不同位置/培养偏移，差值多出未知项：重复同布局会更确定地认错规律；技术重复不能给培养误差上界。
3. 探针准确识别r，但A/B由独立规律t控制：诊断准确、迁移收益为零。这是双重迁移的关键反例。
4. 所有候选规律均错：低方差仍可自信地错误；R-P1自身明确这一边界。

## 强先例、新颖性限度与区分预测

| 比较对象 | 可能不同之处 | 必须承认的等价情形 |
|---|---|---|
| hierarchical/GP | 全局RMSE/方差目标可能买无关高方差板；未正确建模板效应可能混淆。 | 同信息下，正确包含共享规律/批次变量且用决策损失的hierarchical/GP可完全实现正向构造。构造不证明独有算法增益。 |
| BATCHIE/PDBAL | 科学问题可转向实际对比下的不可辨识边界和最小新增观测。 | `d(r,s)=1[a*(r)!=a*(s)]`是有界、非负、对称距离，落在其Eq.26框架内。动作分歧距离、整板选择和反馈更新不够新；加层级批次变量亦不够。 |
| GoBOED、directional设计、普通decision-focused设计 | 关注“什么未购动作在可实施测量下可辨，结构失配后需要什么证据”，而不只在一个给定模型中优化设计。 | regret、chance、CVaR、方向权重、更早停止都有先例；含同结构集与测量约束的robust design可复现，必须作为强基线。 |
| 直接搬机器人SysID | 可继承任务相对精度和输入激励原则。 | 药筛缺同个体dense轨迹、真实参数、可信仿真teacher；若算法仍依赖它们，迁移不成立。 |

区分预测只能是：新增的真实对比会分开此前观测等价且目标动作相反的规律，且此区别在未购药物/背景上改善净决策损失。若只诊断探针拟合更好、同筛表现更好或普通强基线同样受益，则不支持独有算法机制。

**当前贡献判定：** 原理迁移可用于发展问题；单纯目标函数迁移属于已有框架应用。可能有价值的贡献载体是新的生物可辨识条件、测量资源或实验设计，使原先无法回答的未购药物问题可回答。它仍需要真实功能对应、最近先例排除和独立培养证据。本次不声称贡献已成立，也不把验证缺失当否证。局部原文方法证据足以排除笼统新意；没有完成整体F级查新，不能宣布整个具体问题已Done或无先例。

## 最小验证与停止条件（未执行）

1. 冻结一个真实新背景×未购药物任务、可买板、可见信息、所有成本和独立培养单位。只用购板前信息写出至少两个改变目标动作的具体规律。若允许板无可观测差异，报告信息停止门。
2. 核探针—目标的功能对应与独立培养误差；若只有同筛技术重复，最多做算法构造演示，不做生物等价/机制或迁移保证。
3. 同信息/同板/同成本比较random、hierarchical、multi-output GP、PDBAL动作距离、one-step Bayes value of information和decision-focused设计；评价未购药物/背景的净决策损失。
4. 分开“仅更新参数”“允许结构反例但用普通设计”“有/无真实板内混淆消除”。若最强基线相同，贡献可能是测量/边界，而不是新主动算法胜出。
5. 功能映射不保持、培养/批次方差淹没差异、所有规律被拒绝或诊断全成本大于收益时停止具体分支。允许改问最小新增观测，不以模块堆叠挽救原主张。
