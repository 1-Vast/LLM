# R72 记录：**决定性结果**——联合留出下注释模型仍输给药对边际（−2.50 pp）

2026-10-27，Asia/Shanghai。继承 R1–R71，不改总目标。R71 说两向可加赢了注释模型 10.12 pp，但两向可加依赖**细胞边距**。**本轮的检验是：细胞也留出时，注释模型能不能翻身？** 答案：**不能。** 总目标保持 **ACTIVE / NOT_ACHIEVED**。

## 1．结果（联合留出 20% 细胞 + 20% 药物）

**未见细胞（~池大）：**

| 预测器 | 命中率 |
|---|---:|
| 随机 | — |
| 注释模型 | 4.88% |
| 药对边际 | 5.25% |
| 两向可加 | 5.25%（= 药对边际，细胞边距不可用） |

`ridge − drug_marg` = **−0.38 pp** [−2.63, +1.75]（含 0）

**未见药物（~15,374 键）：**

| 预测器 | 命中率 |
|---|---:|
| 随机 | 1.50% |
| 注释模型 | 5.12% |
| 药对边际 | **9.12%** |
| 两向可加 | **10.50%** |

`ridge − drug_marg` = **−4.00 pp** [−7.12, −1.38]；`ridge − additive` = **−5.38 pp** [−8.62, −2.25]

**细胞与药物同时未见（~4,008 键）：**

| 预测器 | 命中率 |
|---|---:|
| 随机 | 2.00% |
| **注释模型** | **4.75%** |
| **药对边际** | **7.25%** |
| 两向可加 | 7.25% |

`ridge − drug_marg` = **−2.50 pp** [−4.62, −0.50]

## 2．判决

- **H182（模型唯一机会，联合留出下赢）：不成立**——反而**输 2.50 pp**。
- **H183（退化检查）：成立**——`additive` 与 `drug_marg` 差**恰好 0.00**，确认细胞边距逻辑按设计退化。
- **H184（两者都优于随机）：成立**。
- 总判决 **`annotation_model_has_no_measured_advantage_anywhere`**。

## 3．这是最终结论

到这里，注释模型在所有可测条件下**全部输给平凡基线**：

| 条件 | 赢家 | 注释模型差距 |
|---|---|---|
| 药物都见过（R71） | 药对边际 5.37% | −1.50 pp |
| 组合没见过（R71，干净） | 两向可加 15.88% | **−10.12 pp** |
| **细胞+药物联合留出（本轮）** | **药对边际 7.25%** | **−2.50 pp** |

**注意最后一行最关键**：联合留出时，注释模型的输入（通路 + 组织）**是它唯一的优势**——细胞身份未知、药物身份未知。**在这种情况下它仍然输给药对边际 2.50 pp。**

## 4．最刺眼的一点

在"未见药物"池上，药对边际对一个**完全没见过的药物**只能填 0（即"不知道"），却仍拿到 **9.12%**，而注释模型（通路注释对未见药物可用）只有 **5.12%**。

**也就是说：知道"这个药的通路"还不如知道"和它配对的那个药的平均协同"。**

## 5．对项目的后果

目标的核心是"**世界模型形成有适用条件的竞争性药理预测**"。本轮的结论是：

> **我们的世界模型（通路注释 ridge）没有找到任何适用条件。**
> 在所有测过的条件下，它都输给"药对平均协同"或"药+细胞边距"。

这**不是**说"协同不可预测"——**协同是可预测的，而且相当可预测**（药对边际 9.12%、两向可加 15.88%）。
**错的是"用通路注释建模"这条路。**

## 6．限制

1. 通路注释是**粗粒度**（38 个通路水平），可能不是"通路无用"，而是"这个注释粒度无用"。
2. `drug_marg` 需要药物在训练集出现过（未见药物填 0）。
3. 组织在联合留出下仍多数可见。
4. 只有一个数据集；回顾性；不涉及机制、临床、药物选择；元学习/RSI 未做。
