## 2. 约束的通用形式（本轮的"逻辑"落点）

每条共享关系写成一个**可否定假设**：

```
C_k = ( A_k: 前件关系, Π_k: 适用条件谓词, B_k: 可测关系(方向/符号/幅度/等级), T_k: 检验统计量, N_k: 零分布, R_k: 违反时的修订动作, F_k: 违反归属的失败类别 )
```

与 LOGICZSL 的差别：LOGICZSL 的规则是固定的（LLM 树 + 模糊逻辑损失，见 prior_art §1），**数据只用于满足规则**；本设计把 `A_k, Π_k, B_k` 全部暴露为可被新反馈推翻的对象，并预先写死推翻后的三类归因（I/II/III）。

## 4. 机制候选（1–2 个；与 A1 互补）

### M1（主）：约束违反三类归因 + 探针选择（Constraint-Violation Triage, CVT）

- 输入：约束库 `C_k`（§3 中当前可检验的 5 条，先只用 C2/C3/C5，C1 作为门控检验，C4/C6 备用）；一个固定更新器（由 A1 提供，A2 不实现）；目标候选池（未测 cell×pair）。
- 流程：① 新反馈批次到达 → 对每条 `C_k` 算违反统计量（按药物/细胞聚类 bootstrap CI）；② 对显著违反者按 §5 判别式归入 I/II/III；③ 按"三类归因的期望区分度"选下一批测量（探针 = 三个竞争修订模型预测分歧最大的 cell×pair）；④ 更新后只在**未测药物选择**上评估（top-k 命中/后悔），不在支持集拟合上评估。
- 可证伪预测（先写死）：
  - **H-A2.1**：在固定 k 次反馈预算下，CVT 选出的反馈使三类归因正确率高于随机/方差/EIG 选点（配对差 CI 下界 >0 且 ≥δ_min）。
  - **H-A2.2**：若所有显著违反都能由"数值重估"（I）解释，CVT 相对仅数值重估无增量 → **停止约束迁移主张**（这是把 C1 之前失败路线收窄的停止条件，不是新算法求胜）。
  - **H-A2.3**：在打乱注释映射的零数据上，CVT 的优势消失（置换零）；若零数据仍有"优势" → 判设计/泄漏失败。
  - **H-A2.4**（反例预测，C1 门控）：若把"同靶点=同功能"写成硬约束，则在 C1 尚未通过的资源上，归因错误率上升且可被预注册统计检出——即**混淆本身可被数据惩罚**；若检不出，说明该混淆在本资源上不可辨识，不得使用。
- 与 A1 接口：A2 只输出 `(C_k, 违反统计量, 归因类别, 候选探针集合)`；A1 决定如何用该信号更新模型/关系表。A2 不重复实现更新器、不评"冲突信号的更新收益"（A1 对象）。
- 与 C130 的关系：C130 只提供"通路替代身份"的**候选关系**；M1 把 C3 写成带 Π（身份缺失、水平已观测）的可否定假设，并在 C1/C3 检验失败时删除关系——**不是**把注释 argmax 当逻辑约束，也不是重推 C130 数字。

### M2（对照，低容量）：适用条件表（Radio: Relation-Applicability Table）

- 只保留 `(A_k, Π_k, sign, 幅度区间)` 四元组；新反馈只检验 `Π_k` 是否成立，不区分 I/III（把 I 与 III 合并为"数值/噪声"）。
- 用途/预测：若真实失败以 II 为主，M2 ≈ M1（CVT 无增量）；若 I/III 常见，M2 显著差于 M1。**H-A2.5**：M1 − M2 的归因优势随 I/III 比例单调上升（类似交互预测）。
- 这是**不需要额外结构的强对照**，防止把"只做条件限制"的简单做法说成机制。

## 5. 三类失败的可操作判别式（预注册，供 A1/A2 共用）

对每个显著违反 `C_k`（bootstrap CI 排除 0，按药物/细胞聚类）：

- **I（数值需调整）**：违反幅度在**保持符号/等级**的前提下可由 ≤2 个标量参数重估解释（预注册参数：总体幅度/尺度、截距）；重估后交叉验证的违反率下降 ≥50%，且训练集外推方向不变。归因更新 = 调整数值层（A1 执行）。
- **II（适用条件失效）**：违反**随声明条件 Π 变化**——条件内（如组织内/水平已观测/浓度档内）一致率显著高于条件外（交互项检验，预注册 δ_scope），符号在条件外翻转或衰减；条件内重估不能消解。归因更新 = 收窄/改写 Π（不改变方向规则）。
- **III（表征遗漏关键状态）**：在声明条件内、重估后仍违反，且违反度与**一个未被表征的状态变量**（预注册候选：细胞谱系/组织/单药敏感度档/剂量占据档）相关（分层检验 CI 排除 0）；需要**状态分层探针**（同一约束在两种状态各测 ≥k 单元）才能确认。归因更新 = 加状态（A1 执行）。
- 不可归因（失败类别 `unresolvable`）：三类判别式都不过 → 记 `inconclusive`，不得说"关系不存在"。

## 6. 最小实验设计（下一轮；本轮不运行）

1. **数据/切分**：R1 GDSC（冻结 SHA）+ R3 映射；主切分 = 按药对留出（leave-pair-out 20%，按药物聚类成折），次 = 留组织（3 组织循环）/留细胞；支持集=训练侧已观测单元，评估=两药未见的未测 cell×pair。
2. **反馈构造（replay，非湿实验）**：从留出集抽 k∈{6,12,24} 个 cell×pair 作为"少量功能反馈"（按药物分组抽，避免同药泄漏）；CVT/M2/random/variance/EIG/无更新各获得同一反馈。
3. **终点**：主 = 三类归因正确率（在人造/确定注入的 I/II/III 反例上，见体检）；副 = 未测药物 top-k 选择后悔/命中；都报配对 CI（按药对聚类 bootstrap）。
4. **功效/MDE**：沿用 P-B 口径 δ_min=0.03（秩水平）。已知 MDE80_two_way：r=0.20 时 **0.1149**、r=0.40 时 **0.0614**（[P-B 报告](../2026-10-27-drugcomb-endpoint/report.md) §14/§21）。k 探针设计的归因正确率 MDE 用**预注册模拟**估计（不做 iid 近似）；若 MDE > δ_min → `inconclusive`，不报"无优势"。
5. **设计体检（先于效果）**：① 零数据置换零校准（type-I ≤0.10）；② 三类反例注入测试（确定构造的 I/II/III 各 ≥20 例，判别式最小正确率预注册，如每类 ≥0.60）；③ 探针分歧非零（三模型预测不同，否则探针无意义）；④ 约束库在开发池上至少有 ≥5 个可检验违反（否则问题不可回答）；任一失败 → 设计无效，不报效果。
6. **泄漏防护**：约束只用训练侧估计；反馈只能来自留出集且只 reveal 被选单元；评估标签不进入选点；R3 SHA 冻结；C1 的 target_name 只用标识表、不用响应；所有选择按药物分组；禁止用同一 96 细胞换聚合救旧结论（C174/C175 边界）。

**停止条件**：H-A2.2 成立（全部 I）→ 停约束迁移主张，退回纯数值更新；H-A2.1 在 MDE 内无差 → 不发展 CVT；零数据上优势不消失 → 判泄漏/设计无效；C1 被推翻 → 只用通路级约束，不用靶点级；C3 在新资源上被推翻 → 删除注释关系，候选降级为纯评估修正。

## 7. 不能声称与缺口

- 不能声称：约束式迁移是新算法（先例见 prior_art §3）；同靶点/同义词=同功能；通路注释=机制；任何收益。
- 缺口：药理"逻辑规则/知识约束"文献只做题录级检索（Q1 27 条，见 prior_art §2），未读全文机制；DrugComb cell→组织映射未建；R2 无浓度数值列；独立培养、靶点占据不可得；C1 的 target 字符串归一存在短别名噪声（52 token）。
- 下一轮入口：先把 C1/C2/C5 的检验脚本与零分布写成 `PROTOCOL` 冻结版（等 Lead 批准），再决定是否做 M1 vs M2 的比较；不先跑效果。
