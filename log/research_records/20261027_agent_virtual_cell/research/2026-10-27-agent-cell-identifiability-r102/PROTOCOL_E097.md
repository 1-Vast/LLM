# PROTOCOL E097（预注册）：同预算下三种预测器——并给出**有适用条件的规则**

2026-10-27，R102。**在任何计算前冻结。** 只读 `gdsc_combinations`。

## 为什么

R101 立住了"注释在药未见时补位"。但要晋升，还缺**与药物边际的同预算对比**——因为药物边际是本项目现行推荐的预测器。

**这一轮的产物应该是一个"条件规则"，而不是又一个"谁更好"。**

## 构造

- 3 池（`one_unseen` / `cell_unseen` / `both_unseen`）× 1 判据（布尔 `Synergy`）。
- **三臂同预算**（同训练行、同 k=20）：
  1. `marginal`：两向可加（药物均值效应，**药未见时退化为常数**）
  2. `identity`：药物 one-hot ridge
  3. `identity+pathway`：两者拼接
- 70 次划分。

## 判据（预先写定）

- **H263（在药未见处组合胜边际）**：`both_unseen` 池上 `identity+pathway − marginal` 的 CI 下界 **>0**。
- **H264（在药见处边际不输）**：`one_unseen` 池上 `marginal − identity+pathway` 的 CI **含 0 或为正**。
- **H265（条件规则成立）**：H263 与 H264 同时成立 → **"药见得多用边际、药未见用组合"** 是一条有适用条件的规则。
- 若 H263 不成立 → **组合没有超过边际**，**不应晋升**（边际仍是唯一赢家）。
- 若 H264 不成立（边际在药见处明显更好）→ 规则要写成"边际优先"。

## 边界

- 三池共用训练集。
- `both_unseen` 池小。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
