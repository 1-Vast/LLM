# PROTOCOL E091（预注册）：C42 的"对池大小不敏感"是不是**由预算规则构造出来的**？

2026-10-27，R96。**在任何计算前冻结。** 只读 `gdsc_combinations`。

## 为什么

C42 的原话是"**弱信号的决策价值对池大小不敏感（预算按比例时）**"。

**那个括号是警报。** 如果预算按比例（取池的 5%），那么"取池的 5%"这个动作**本身就保证了质量大致与池大小无关**——因为百分位相同。

R93/R94 犯的是同一类错：**把由构造决定的量当成发现**（C68 记录了这条教训）。C42 可能也一样。

## 构造

- GDSC；预测器 = **药物边际**（唯一还站着的那个）；判据 = 布尔 `Synergy`。
- **只改池大小**：从全池**均匀子抽样**得到 2k / 5k / 10k / 20k 键（组成不变，只变大小）。
- **两种预算规则**：
  - **(a) 按比例**：k = 池的 5%
  - **(b) 固定**：k = 20
- 每档 60 次子抽样。

## 判据（预先写定）

- **H246（固定 k 下池越大越差）**：规则 (b) 的命中率随池大小**显著下降**（大池 vs 小池的 CI 不含 0）。
- **H247（按比例时基本不变）**：规则 (a) 的命中率随池大小**无显著变化**。
- **H248（C42 的"不敏感"是预算规则的产物）**：H246 与 H247 同时成立。
- 若 H248 成立 → **C42 必须改写成"按比例预算时命中率由百分位决定，与池大小无关（近乎构造）"**。
- 若 H246 不成立（固定 k 也不变）→ C42 是真的不敏感，**不需改**。

## 边界

- 均匀子抽样保持组成不变；真实池差异还伴随组成差异。
- 小池（2k）里 top-20 是 1%，大池（20k）里是 0.1%——这才是"池越大越难"的来源。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
