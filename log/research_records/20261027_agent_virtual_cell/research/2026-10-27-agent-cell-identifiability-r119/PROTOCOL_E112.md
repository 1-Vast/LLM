# PROTOCOL E112（预注册）：组合模型能否迁移到**未见组织**？——C65 只测过边际

2026-10-27，R119。**在任何计算前冻结。** 只读 `gdsc_combinations`。

## 为什么

C65/C70 测过**药物边际**的跨组织迁移（留一组织：5.87% / 8.25%，随机 ~1%，代价约一半）。

**但没测过现在推荐的模型 `identity+pathway` 的跨组织迁移。**

这是迁移轴上**唯一还没验过的一格**，而且它比边际更重要——边际只是身份的一个未收缩版本，组合模型才是要被推广的东西。

## 构造

- GDSC；**留一组织**（训练用另两个组织，测试在被留出组织上）。
- 四臂（同训练行、同 k=20、布尔判据）：
  1. `marginal`（两向可加，C65 的冠军）
  2. `identity`（药物 one-hot ridge）
  3. **`identity+pathway`**（+通路/组织注释）
  4. `random`
- 每组织 60 次子抽样（每次从留出组织里抽 2,000 键）。

## 判据（预先写定）

- **H296（组合模型可迁移）**：`identity+pathway − random` 的 CI 下界 **>0**，**在每个留出组织上**。
- **H297（注释增量在迁移下仍存在）**：`identity+pathway − identity` 的 CI 下界 **>0**（至少 2/3 组织）。
- **H298（组合模型优于边际）**：`identity+pathway − marginal` 的 CI 下界 **>0**（至少 2/3 组织）。
- 若 H296 不成立 → **推荐模型不能跨组织**，C65 的结论不能外推到它。
- 若 H296 与 H298 都成立 → **推荐模型在迁移轴上比边际更强**，这是对 C75 的加固。

## 边界

- 只有 3 个组织，只有 3 折。
- 组织是 `identity+pathway` 的一个特征——**留出组织时该特征在训练中缺失**（只见过另两个组织的值），这是真实的迁移困难。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
