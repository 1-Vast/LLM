# PROTOCOL E018（预注册）：共享注释靶点的化合物对，次序更不稳定吗？

2026-10-27，R18。**在任何反转率或检验被计算前冻结。** 只读 `PAIR_SCREEN.csv`（SHA256 56a4e4a1…d5f23）与本机既有的两个 MAPKG 文件（非本轮下载）。不读 sealed、不调 LLM。

## 背景：R10 的判决需要修正

R10 依据 `moa` 字段判定"靶点/机制参照不可用"（可用机制 2/23 个化合物）。本轮审计发现 `moa` 不是唯一通路：**MAPKG 的 `DRUG-GENE` 表**用 PubChem ID 连到 ENSG 基因与作用类型（inhibitor/agonist/binding/…），而 `DRUG_merged` 提供 **药名 → PubChem ID**。两表 ID 空间完全对齐（168,182/168,182）。

实测覆盖（11 个分析布局）：**90 个化合物中 61 个（67.8%）有 ≥1 个基因注释**；**659 个化合物对中 297 个两端都可注**；其中 **54 个共享 ≥1 个基因**（如 Gefitinib+Erlotinib 共享 62 个、Axitinib+Ibrutinib 共享 12 个）。

因此 R10 的 F6 必须修正为：**"没有测量的 engagement，但有一个弱注释级的基因靶点参照可用"**。

## 问题

**H038**：共享 ≥1 个注释基因靶点的化合物对，其**网格级跨细胞反转率**高于两端可注但不相交的对。

但有一个机械混淆必须先处理：共享靶点的两个化合物往往效力相近，而效力相近会**自动**提高反转率（间隔效应，R6–R14 反复见到）。因此：

- **H039**：在按"网格平均间隔"分层的比较中，H038 的差异仍然存在。

## 构造

- 单元 = (布局, 化合物对)。
- **网格级反转率**：对该对在每个细胞对下，抽 300 个剂量组合对（共同随机数），要求两侧间隔都 ≥0.10 才计入；反转 = 符号相反。取所有细胞对的加权平均。
- **平均间隔**：同一批剂量组合对的 `min(两侧间隔)` 均值（混淆控制变量）。
- 注释：`shared = 1` 当两化合物基因集交集非空；比较集 = **两端都可注但交集为空**。

## 判据（预先写定）

- H038：`shared` 组反转率 − 不相交组反转率 ≥0.01，布局聚类 95% CI 下界 >0。
- H039：在平均间隔的五分位层内，`shared` 的优势方向在 ≥4/5 层中成立，且合并的层内加权差 ≥0.005 且 CI 下界 >0。
- 若 H038 成立但 H039 不成立 → 结论只能是"共享靶点与不稳定相关，但可由效力相近解释"，不得写成靶点效应。
- 若 H038 不成立 → 注释级靶点共享**不能**解释不稳定；机制邻近无证据。

## 不做与边界

- 注释级"共享靶点"**不是**测量的靶点参与，**不是**遗传扰动参照，**不是**机制证明。作用类型（inhibitor/agonist/…）本轮不作区分。
- 不涉及药物选择、未见药物、临床。功能读出只是归一化存活度；探索性（板已被 R2 当终点、跨细胞跨日期）。
