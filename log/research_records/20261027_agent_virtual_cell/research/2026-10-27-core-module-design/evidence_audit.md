## 2. identity 常数与“增益”的实际对象

R196 特征只有两侧药物 ID one-hot 与两侧通路 one-hot；`cell_idx` 只用于聚类/索引，没有进入预测矩阵（`r196.py:238–252`）。模型是标准化后的线性 ridge（`:117–134`）。因此同一外折内：

`ŷ(c,a,b) = intercept + u_a + v_b + α_path(a) + β_path(b)`，预测不依赖 c，也没有 a×b 或 cell×drug 乘积项。

外层同时留出两侧同名药物，训练看不到测试药物 ID 的任何激活；其 ID 系数不能从训练标签学习。测试行在训练活跃 ID 列上的标准化值相同，未见 ID 列系数为零，所以 identity 在**每个折内**必为常数。五折常数不必相同，不能把拼接后的截距差当排序能力。

`rho()` 对常数按明示约定写 0，标准 Spearman 本来未定义（`:77–89`）。JSON 的 gain=0.144657 因而等于 annotation ρ，并非“击败一个可外推的身份预测器”。annotation-only=0.148764，与 ID+ANN 相近且略高；这说明排序不需要 ID 块，**不证明通路因果作用**，也没有该微小差异的显著性证据。

端点名为 synergy 不会使线性预测器自动成为交互机制模型。跨 cell×pair 行得到的总体相关还可来自药对/通路平均倾向、细胞覆盖与实验构成；无细胞特征的模型不能证明能识别同一药对在不同细胞中的反向排序。药物双未见也不等于细胞未见。

## 3. CI 的抽样单位、依赖与撤回

R196 主 CI 是固定预测上的细胞重采样：保持药物划分、训练模型和已观测组合不变，重算每折相关再均值。它描述固定药物集合/模型下的细胞构成波动；125 个细胞簇不是 20,737 个独立样本，也不是独立筛选/实验批次。不能由 cell CI 推出未见药物总体或跨 screen 的精度。

| 固定运行记录口径 | gain 的 95% CI | MDE80 |
|---|---|---|
| cell | [0.121304,0.166746] | 0.032044 |
| directed pair | [0.089770,0.187583] | 0.072102 |
| cell×pair | [0.087238,0.195800] | 0.078285 |
| JSON 所称 drug | [0.013900,0.223292] | 0.152731 |

药物 MDE 超过项目 δ=.05；5 折增益范围 [0.011767,0.295175]，描述性折 t 区间 [-0.0144,0.3037] 含零。外折训练集彼此重叠，折 t 区间不能升级为五次独立实验的认证 CI。新增随机划分也不会凭空新增独立药物/实验。

代码还需比名称更精确地描述：`boot_gain(...,'drug')`（`:443–461`）分别生成 anchor 与 library 两套独立重数后相乘，同名药物跨角色没有共享同一重数；它是角色分开的药物重采样，不能直接宣称已处理全部共享药物节点依赖。pair/bootstrap 同样不能覆盖不同药对共享单药带来的所有依赖。这不改变“当前不可确认”的结论，但提醒后续协议不要把这条 drug CI 当最终标准。

`REVOCATION_R196.md` 已给出有效限制。其科学含义是推断单位和功效未认证，不是“通路无用”。grouped 内层用 pooled Spearman，row-level 对照用折均 Spearman，且扩大 λ 网格；该桥接差异不能单独识别行级调参偏差。协议还披露预冻结 annotation-only 原型约 0.149，不能声称所有相邻结果均在冻结后首次见到。

## 4. annotation/null 与决策性

shuffle 10 seeds 的 mean ρ=0.007690、经验 2.5–97.5% 范围 [-0.043414,0.071207]；capacity 对应 0.000931、[-0.010543,0.008380]。这是有限种子上的负对照，支持“当前药物侧标签所带信息不同于这些随机特征”的诊断用途。它没有排除 study/剂量构成、标签相关的实验选择、其他药物属性或普通均值学习；没有提供 annotation 相对最强非恒定可迁移基线的机制增益认证。

top-5% hit rate=0.372779 只是整体测试池内按分数挑行的回顾性描述。恒定 identity 的 stable-sort 截取由行序决定，并非真正执行的随机分配；“期望 25%”需要随机选择与标签独立，不能由确定行序自动保证。没有按细胞固定候选集合的决策、采样预算/成本、真反馈轨迹、未查询结果封存与强更新器对照，不能称等预算决策收益。

## 5. 现有数据可测试的最小核心命题

**候选 Hmin（未验证）：在事先按元数据匹配的同端点/同方向/同浓度条件中，少量已购买功能对比可预测同一细胞上未查询条件的差分偏移；真实反馈比无反馈、打乱反馈及普通重训带来更低的封存差分损失。** 对比对象先取：

`Q(c,c';p,q)=[y(c,p)−y(c,q)]−[y(c',p)−y(c',q)]`。

Q 代数上消去纯细胞与纯条件加性主效应，但仍可含噪声、批次、方向/剂量错配；“非零 Q”不是机制。R192 已提出该对象，R197 仅规划其同-screen 可预测性。因此这是一条可执行的窄命题，不是新命名就产生的创新。

最小检验顺序：先按元数据而非 Q 值冻结可估的 2×2 闭环与依赖节点，报告覆盖/缺失；分离购买反馈与封存未查询动作，冻结采购轨迹与更新器；比较无/真/打乱反馈，基线至少包括 cell+condition 加性、单药/元数据 ridge、可辨识交互模型、低秩/层级模型和同预算普通重训。评价用未查询 Q 损失，若要主张选药价值再加按细胞固定动作集合的 regret/收益；推断按共享 cell/condition/药物节点与真实批次，而非把差分边当独立样本。

合法信息边界要写清：单药曲线也是功能暴露，必须计入可用信息/成本；冷细胞零反馈与新细胞获得少量反馈是两个不同任务。R197 H197a 规划按细胞节点留出，B3 使用同-screen 单药与元数据；即使未来成功，也只说明该信息预算下的预测，不是零暴露新细胞或跨 screen 机制。

若精度/覆盖不足则未决；若普通重训完全解释增量则是普通学习，不得升级独特算子；若真反馈不优于打乱反馈则停止该反馈传递主张。尚未做这些检验，不能提前给正结论。

## 6. 真正机制主张仍缺的参照

本次已读文件未提供经资格确认、共同索引的“cell×drug（剂量/时间）×靶点参与/占有或遗传扰动×独立功能终点”配对证据。要把 Hmin 升级为靶点/通路机制，需要能区分竞争解释的参照：同细胞药物 target engagement、匹配遗传扰动/救援或耐药突变、选择性相近与 off-target 不同的功能替代药、独立实验条件/筛选的重验。RNA 变化不自动等于药效或靶点参与。未取得这些参照不是科学失败，而是目前只能主张功能预测/经验更新的识别边界。
