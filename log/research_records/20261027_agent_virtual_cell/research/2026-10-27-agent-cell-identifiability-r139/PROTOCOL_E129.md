# PROTOCOL E129（预注册）：给树**公平的机会**，再判定"替代效应是否线性专属"

2026-10-27，R139。**在任何计算前冻结。** 只读 `gdsc_combinations`。

## 为什么

R138 发现 boosting 下"身份缺失"并未带来更大增益（差 +0.0029 [−0.050,+0.052]），但**树用的是未调超参**（`max_iter=200, leaf=40`），且**类别特征被当整数喂进去**。

**在给树公平机会之前，"树抽取得少"只能算暂定。**

## 三种"公平机会"

| 配置 | 超参 | 说明 |
|---|---|---|
| `base` | `max_iter=200, leaf=40` | 复现 R137/R138 |
| `strong` | `max_iter=400, leaf=10, lr=0.05` | 更多容量、更细叶子 |
| **`categorical`** | `max_iter=300, leaf=20` + **`categorical_features` 掩码** | **让树原生处理类别**，未见药用保留类别 id（合法值） |

- 两条件（`full_identity` / `no_identity`）× 两臂（`identity` / `+通路`）。
- **20 次划分**（配置数×条件数×臂数变多，缩减重复数）；种子 **20261042**。

## 预测（写死）

- **H344（公平化后替代效应出现）**：任一配置下，`no_identity` 的增益**显著大于** `full_identity`（差值 CI 下界 >0）。
- **H345（公平化后仍不出现）**：三种配置下差值 CI **均含 0**。

**若 H344 成立 → C106 撤回，替代效应非模型专属。**
**若 H345 成立 → C106 加固为"已排除容量与类别处理两种解释"。**

## 判据

- 每配置报两条件的增益与差值。
- **同时报 `no_identity` 下 `+通路` 的绝对 ρ**，与 ridge 的 0.13 对照（仍属跨模型比较）。

## 边界

- 20 次划分，检定力有限。
- 保留类别 id 只是一种编码。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
