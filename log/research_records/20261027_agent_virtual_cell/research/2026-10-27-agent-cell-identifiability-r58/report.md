## 1．那个算法（四步）

```
1. 特征 = 药物对的通路注释 + 组织（约 41 维）
2. 拟合 ridge（λ=1）→ 点预测 pred、后验方差 var
3. 门控：若候选池 S 远大于预算 k（k=20 时 S≳3,000；k=50 时 S≳10,000）
        排序键 = rank(pred) + rank(var)
   否则 排序键 = pred
4. 取前 k 个
```

**这就是全部。** 没有在线学习、没有元学习、没有自我改进循环。

## 3．成立的 5 条

1. 注释级信号**真的**可迁移（C24/C25/C26）。
2. **组织**是真正起作用的适用条件（+0.0247，92% 细胞）。
3. **利用策略有真实决策价值**（4.5×）——不是"预测更准"，是"决策后果更好"。
4. **池大小**是决策规则的关键变量，阈值对目标定义稳健。
5. **整体指标更好的模型，决策尾部通常也更好**（+0.56）——我原本以为相反，被自己否证。
