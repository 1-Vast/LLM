# PROTOCOL E010（预注册）：公平的决策-AL 检验——异方差先验＋精度加权后验

2026-10-27，R9。**在任何效用数字被计算前冻结。** 只读 `PAIR_SCREEN.csv`（SHA256 56a4e4a1…d5f23）。不下载新数据，不读 sealed，不调 LLM。

## 为什么重做

R8 的决策实验有三处已被自己登记、并限制了其结论的缺陷（AMENDMENT-006）：(i) 同方差先验使 VOI 与利用**解析等价**；(ii) 购买后用实测值**替换**先验，不是贝叶斯更新，导致"买了更差"；(iii) 因此 R8 的阴性**不能**算作对决策主动学习的否证。本轮按同一问题重做，修掉这三处。

## 任务（对每个留出细胞 c）

- 菜单 = 该布局内的双药单元；先验只来自**其他细胞**。
- 预算 k ∈ {1,2,4,8}，买到的方案得到 c 的实测值（该细胞 file 均值）。
- 决策：选 1 个推荐方案；真实效用 = c 的实测 viability，越低越好。c 的未购买方案不使用。

## 修正后的先验与后验

- 每个方案 u：`n_u` 个其他细胞可用；`p_u = mean`，`s_u = sd`。
- **先验 sd（异方差）**：`σ_prior,u = max(s_u / sqrt(n_u), 0.01)`；`n_u < 3` 时用该布局的合并 sd / sqrt(n_u)。
- **测量 sd**：`σ_meas = 0.028`（由同细胞双板的文件级噪声 ≈0.04 / √2 推得；R4/R5 实测范围 0.026–0.041，取中点）。
- **后验**：`μ_u = (p_u/σ_prior,u² + y_u/σ_meas²) / (1/σ_prior,u² + 1/σ_meas²)`，`σ_post,u = 1/sqrt(1/σ_prior,u² + 1/σ_meas²)`。未购买的方案 μ=p。

## 采集策略（同信息同预算）

| 代号 | 依据 |
|---|---|
| `none` | 不买 |
| `exploit` | μ 最小的 k 个（等价于 p 最小） |
| `random` | 均匀随机（20 次平均） |
| `uncertain` | σ_prior 最大的 k 个（经典探索） |
| `instab` | R7 的 per-well 不稳分最大的 k 个 |
| `ei` | **期望改进**：`EI_u = (m_{−u} − p_u)Φ(z) + s_u' φ(z)`，`z=(m_{−u}−p_u)/s_u'`，`s_u' = (1−w_u)σ_meas`，`w_u = (1/σ_prior,u²)/(1/σ_prior,u²+1/σ_meas²)`；批量时贪心：选完一个就把该方案的 σ 换成 σ_post 再重算（均值不提前更新） |
| `instab_ei` | `EI` 与不稳的秩平均（权重 0.5 预先写定） |

## 判据（预先写定）

- **H014**：`ei` 相对 `exploit` 的 regret 低 ≥0.02 且布局聚类 95% CI 上界 <0，在某个 k 上成立 → 决策-AL 有独立价值。
- **H015**：`instab` 相对 `exploit` 的 regret **不低于** −0.02（即无正价值）→ 复现 R8 的阴性。
- **H016（实现校验，理论必然）**：在精度加权后验下，`exploit` 的 regret 随 k **单调不增**。若出现增大，说明实现有错，结论作废。
- 若 `ei` 与 `exploit` 在全部 k 上差 <0.005 → 判"在该菜单上采集策略与利用不可分"。
