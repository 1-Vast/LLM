# PROTOCOL E009（预注册）：不稳信息有没有决策价值？

2026-10-27，R8。**在任何效用数字被计算前冻结。** 只读 `PAIR_SCREEN.csv`（SHA256 56a4e4a1…d5f23）。不下载新数据，不读 sealed，不调 LLM。

## 为什么是这个实验

R7 得到：方案级次序不稳可由**其他细胞**预测（合并 AUC 0.869），但（i）不是跨批次可迁移、（ii）不是已排除位置伪影、（iii）**没有决策价值**。R2 已经得到过一次相关阴性：GP＋随机反馈劣于静态强预测，KG ≈ 随机。因此本轮唯一还值得问的是：**在同等测量预算下，按"预测不稳"去挑要测的方案，能不能比不挑、随机挑、以及按预测值/不确定度挑，做出更好的药物选择？**

## 任务（对每个留出细胞 c）

- 菜单 = 该布局内的双药单元。
- 已有信息：同一批药板在其他细胞上的读数（不含 c）。
- 预算：可以再测 **k 个方案**（k ∈ {1,2,4,8}），拿到的是 c 的真实测量值（该细胞两块板的均值）。
- 决策：从菜单中选 **1 个**（主指标）或 3 个（次指标）推荐方案，真实效用 = c 的实测 viability（越低越好）。
- 严格不看 c 的未购买方案；c 的全部真值只用于**评分**。

## 七个策略（同信息、同预算）

| 代号 | 选择 k 个的依据 |
|---|---|
| `none` | 不买；直接用其他细胞的均值排序 |
| `random` | 均匀随机（20 次重复取均值） |
| `exploit` | 预测 viability 最小的 k 个 |
| `contender` | 预测值最接近预测最优的 k 个（"测对手"） |
| `voi` | 期望改进式：`P(y_u < min_{v≠u} p_v)` 最大的 k 个（高斯、σ 取跨细胞残差的中位标准差） |
| `instab` | 预测"跨细胞反序倾向"最强的 k 个（R7 的 per-well 不稳分，只用其他细胞估） |
| `exploit_instab` | 组合评分 `z(p) − 0.5·z(instab)`，取最小的 k 个（**权重 0.5 预先写定**） |

购买后，未被购买的方案用 p(u) 补齐，再取 argmin；已购买的用实测值。

## 指标

- **top-1 命中**：所选方案是否落在 c 的真实前 3（按真实 viability 由低到高）。
- **regret**：真实 viability(所选) − min 真实 viability。
- **top-3 效用**：所选 3 个方案的真实 viability 均值（越低越好）。
- 区间：布局聚类 bootstrap（1000 次，整布局重抽）。

## 判据（预先写定）

- **H013a（不稳有决策价值）**：在任一 k 上，`instab` 或 `exploit_instab` 的 regret 比 `random` 低 ≥0.02 **且** 比 `exploit` 低 ≥0.02，两侧布局聚类 CI 都不含 0。
- **H013b（决策主动学习有价值）**：`voi` 比 `exploit` 的 regret 低 ≥0.02 且 CI 下界 >0。
- **若 `exploit` 在全部 k 上 ≥ 其他所有策略**（regret 最低或并列）：判 **"该菜单上采集策略无决策价值，利用即最优"**——这是对 R2 阴性的独立复现，属于有效结论，不是失败。
- 任何"有优势"的主张必须同时给出 top-1 命中与 top-3 效用，不得只报一个指标。

## 不做与边界

不训练新模型、不调超参；不做未见药物；不称机制、engagement、选择性、临床。全部探索性：板已被 R2 当终点，且跨细胞跨日期。若 H013a/b 都不成立，主张 C 继续锁定，并在报告首段写明"不稳信号无决策价值"。
