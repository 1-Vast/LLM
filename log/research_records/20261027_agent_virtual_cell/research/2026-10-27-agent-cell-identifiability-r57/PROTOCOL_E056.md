# PROTOCOL E056（预注册）：用**天然变异**检验"预测强度调节混合收益"——125 个留出细胞

2026-10-27，R57。**在任何计算前冻结。** 只读本机 `gdsc_combinations`。

## 为什么

"预测强度调节混合收益"这个假设，被**四次人工操纵**都没能检验（R39 混淆维度、R40 噪声无效、R42 置换无效、R43 分组无变化）——因为注释级信号太稳，压不低。

但换个思路：**不需要操纵**。如果不同的留出细胞天然给出不同的预测质量 ρ，而混合收益又随 ρ 变化，那么**天然变异就足以检验**这个假设。

## 构造

- GDSC 125 个细胞系。对每个细胞系 c：
  - 训练集 = **其余所有细胞**的键；
  - 候选池 = **c 的全部键**（每细胞约 860 键）；
  - 特征 = 通路（38 维）+ 组织（3 维）；ridge λ=1；
  - 计算两个量：**ρ**（预测与真实值的秩相关）与 **mix − exploit**（k=20，命中=池内最强十分位）。
- 得到 125 对 (ρ, diff)，做相关。

## 判据（预先写定）

- **H146（强度调节）**：ρ 与 `mix − exploit` **正相关**（Spearman >0），且 bootstrap 95% CI 下界 >0。
- **H147（不是池大小造成）**：控制池大小后的偏相关仍为正（池大小在各细胞间差异很大，必须排除）。
- **H148（有阈值形状）**：把细胞按 ρ 四分位分组，最高四分位的 `mix − exploit` 比最低四分位高 >2 pp。
- 若 H146 不成立 → **"强度调节"这个解释被否证**（这是第五次，但这次是公平检验，因为天然变异确实存在）。
- 若 H146 成立 → **该假设首次获得支持**，且是用天然变异而非人工操纵。

## 边界

- 每个细胞的池大小不同（~400–2,000），所以 ρ 与池大小天然相关，**必须控制**（H147）。
- 训练集随折变化（留出细胞变大或变小），会同时影响 ρ 与池大小。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
