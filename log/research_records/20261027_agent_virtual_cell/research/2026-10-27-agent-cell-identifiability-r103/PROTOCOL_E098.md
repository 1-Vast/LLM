# PROTOCOL E098（预注册）：防泄漏复核——**打乱药物↔通路的对应关系**，增量应当消失

2026-10-27，R103。**在任何计算前冻结。** 只读 `gdsc_combinations`。

## 为什么

R101/R102 说 `identity+pathway` 显著优于 identity 与边际。**晋升前必须排除"注释特征以某种方式偷看了结果"。**

最直接的检验：**把药物到通路的映射随机打乱**（保持每个药的通路标签分布不变，只切断对应关系），重新拟合。

- **若增量消失** → 信号来自**真实的注释对应关系**，不是结构伪影；
- **若增量仍在** → 说明"多 41 维"本身或别的结构在起作用，**注释的价值不成立，禁止晋升**。

## 构造

- 两个池（`one_unseen`、`both_unseen`）× 布尔判据。
- 三臂：`identity`、`identity+真实 pathway`、`identity+打乱 pathway`。
- 70 次划分；每次划分内**独立打乱一次**。
- 打乱方式：把"药 → 通路"映射在全部药物上随机重排（同一药在两侧的通路标签一致地被替换）。

## 判据（预先写定）

- **H266（真实增量大于打乱增量）**：`(真实 − identity) − (打乱 − identity)` 的 CI 下界 **>0**。
- **H267（打乱后无增量）**：`打乱 − identity` 的 CI **含 0**。
- **H268（防泄漏通过）**：H266 与 H267 同时成立。
- 若 H266 成立而 H267 不成立（打乱后仍有增量）→ **晋升否决**，须先查清 41 维结构效应。
- 若 H266 不成立 → **注释价值不成立，晋升否决**。

## 边界

- 打乱保留了通路分布的边际，但破坏了药-通路配对；这正是要切断的东西。
- 只有 2 个池，若结论相反需扩到 3 池。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
