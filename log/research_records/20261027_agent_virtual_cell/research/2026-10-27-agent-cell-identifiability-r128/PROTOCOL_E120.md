# PROTOCOL E120（预注册）：资源能力审计——目标要求"先核实"的四件事，逐项量化

2026-10-27，R128。**在任何计算前冻结。** 只读 `gdsc_combinations` 与 `PAIR_SCREEN.csv`。

## 为什么

目标第一条是：

> **"先核实药物×细胞交叉、靶点参与/遗传扰动参照、独立功能终点与重复；证据不足则调整问题。"**

**这四件事我在各轮里反复当作已确认的前提，但从没量化过。** 本轮把它们逐项测出来，并据此判断哪些问题**在结构上就不可能回答**。

## 要测的四项（全部只读、可复算）

| # | 项 | 怎么量化 |
|---|---|---|
| 1 | **药物×细胞交叉** | GDSC 里 125 细胞 × 2,025 组合的**实际覆盖**：每细胞测了多少组合、每组合测了多少细胞；覆盖率、以及覆盖是否有结构（按组织/按组合） |
| 2 | **靶点参与** | 只有 `ANCHOR_TARGET`/`LIBRARY_TARGET` 注释（86 水平）。**测不出"结合/占据"**——只能报"有注释、无占据测量" |
| 3 | **遗传扰动参照** | 本机**无**扰动数据（CRISPR/RNAi）。只能报"不存在" |
| 4 | **独立功能终点** | GDSC 的四个协同指标（ΔAUC/ΔEMAX/fAUC/XMID）**是否相互独立**：算它们的相关矩阵与秩相关；**若高度相关，则它们不是独立终点** |
| 5 | **重复** | BATCHIE：同一 (组合, 细胞) 是否在**多于一个 layout** 中被测；报技术重复率 |

## 预测（写死）

- **H318（交叉是稀疏的）**：实际覆盖率 **<20%**（即 125×2,025 的交叉积大部分没有观测）。
- **H319（四指标不独立）**：四个协同指标两两 |Spearman| 中位数 **>0.6**。
- **H320（重复率低）**：BATCHIE 里在 >1 layout 中被测的 (组合,细胞) 比例 **<30%**。

## 判据

- 每项给数字；**若 H318 成立 → "药物×细胞交叉"在本资源上不是完整交叉，抽样偏倚必须写进综合**。
- **若 H319 成立 → "四个独立功能终点"这句话不成立，只有"一个终点、四种口径"**。
- **若 H320 成立 → 技术重复不足以支撑"重复性"主张**。

## 边界

- 只反映本机两个资源，不推广。
- 覆盖的结构性检验只到组织/组合层面。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
