# R128 记录：目标要求"先核实"的四件事，两项不满足——而且**我的"两个判据"从来不是两次独立检验**

2026-10-27，Asia/Shanghai。继承 R1–R127，不改总目标。目标第一条要求"**先核实药物×细胞交叉、靶点参与/遗传扰动参照、独立功能终点与重复**"。这些我在各轮里当作已确认的前提，**从没量化过**。本轮逐项测。总目标保持 **ACTIVE / NOT_ACHIEVED**。

## 1．结果

| 项 | 数字 | 判定 |
|---|---|---|
| **药物×细胞交叉** | 125 细胞 × 2,025 组合 = 253,125 全交叉；**实际 108,259（42.8%）**；每细胞 **288–1,275** 键（4.4× 差异）、每组合 **28–124** 细胞 | **部分（不是完整交叉，且高度不平衡）** |
| **靶点参与** | anchor **40** + library **58** 个注释水平 | **不满足（只有注释，无占据/结合测量）** |
| **遗传扰动参照** | 本机无 CRISPR/RNAi | **不存在** |
| **独立功能终点** | 四个 Δ 指标两两 \|Spearman\| **0.806–0.967，中位 0.893** | **不满足（一个读数的四种口径）** |
| **重复** | 58,828 个 (组合,细胞) 观测中，**仅 1,788（3.04%）** 出现在 >1 块板上 | **不满足** |

**H318（交叉稀疏）、H319（指标不独立）、H320（重复率低）**：**H318 不成立（42.8%）、H319 与 H320 成立**。

## 2．这直接冲击我自己的表述

**我在多轮里写"在 2/3 池 × 2/3 判据上显著"。**

**但两个"判据"（布尔 `Synergy` 与 `ΔEMAX` 四分位）相关约 0.83——它们从来不是两次独立检验。**

> **所以"2/3 判据"这种说法系统性高估了证据：第二个判据几乎不携带第一个之外的信息。**
> **正确的读法是"冗余"，不是"重复验证"。**

## 3．冻结的那条结论受影响吗

**基本不受。**

**它主要靠 `ΔEMAX` 四分位这一个判据**，而它的支撑来自**与该判据选择无关的对照**：
- 同维**随机块**（容量）
- **打乱映射**的块（结构）
- **死块恰好为零**（内控）

**这些对照独立于判据选择。所以冻结结论本身不因此动摇；但全项目里"多判据"的措辞必须改成"冗余"。**

## 4．判决

- **H321（四项核实全部满足）：不成立**——**两项不满足（独立终点、重复）、一项部分（交叉）、一项只有注释（靶点）**。
- **H322（"两个判据"是两次独立检验）：不成立**——**ρ ≈ 0.83**。
- 总判决 **`two_of_the_four_verification_items_are_unmet_and_the_two_criteria_were_never_independent`**。

## 5．按目标要求的"证据不足则调整问题"

目标明确允许在这种情况下调整问题。**这四项的实测结果意味着：**

| 想回答的问题 | 本资源能否回答 |
|---|---|
| "注释对**协同**有用吗" | 能（但只有一个读数、四种口径） |
| "对**独立功能终点**有用吗" | **不能**（没有第二个终点） |
| "对**靶点占据**有预测力吗" | **不能**（只有注释） |
| "结论**可重复**吗" | **只能对 3% 的观测**主张 |

**所以能站住的只有"数据集内的决策增量"，而这正是已经冻结的那一条。**
