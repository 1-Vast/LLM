# PROTOCOL E082（预注册）：BATCHIE 上的**可判别**检验——注释模型能否预测可加性残差？

2026-10-27，R87。**在任何计算前冻结。** 只读 `PAIR_SCREEN.csv` 与 MAPKG。

## 为什么

R86 的 BATCHIE 检验**饱和**：三个预测器都到 ~89%（基准 25%），因为"低存活度"主要由**药物效力**决定，谁都能捕捉。

**要让它可判别，必须把效力成分剥掉。** 剥掉之后剩下的是**可加性残差**——这正是 GDSC 上 C45 测过的那个量（两向可加 vs 注释）。

## 构造

- BATCHIE 高多样性布局，留一细胞。
- **两向可加模型**（在训练细胞上拟合）：`ŷ = 总均值 + 细胞效应 + 药物A效应 + 药物B效应`。
- **残差**：`r = y − ŷ`（若 r 为正 = 存活度**高于**可加预期 = 拮抗；r 为负 = 协同）。
- 任务：在留出细胞里，**按预测的 r 最低取前 k=20**，命中 = 真实 r 落在最低四分位。
- 两个预测器：
  1. `gene`：基因注释 ridge（在训练细胞的残差上训练）
  2. `random`
- **关键**：**边际对残差没有信息**（按构造，边际就是可加模型的一部分），所以这是一个"边际先天失明"的赛场——**注释模型该在这里赢**。

## 判据（预先写定）

- **H221（注释模型能预测残差）**：`gene − random` 的 CI 下界 **>0**。
- **H222（注释模型不能预测残差）**：CI **含 0 或为负** —— 与 GDSC 的 C45 一致。
- **H223（残差确实存在可学信号）**：训练集上交叉验证的 R² **>0**（否则说明残差就是噪声，H222 不能算证据）。

## 边界

- 残差任务噪声大（单细胞、单浓度网格）。
- 若 H223 不成立，**本轮不能说任何关于注释模型的话**——这是必须先过的闸。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
