# PROTOCOL E035（预注册）：等预算下的程序搜索——搜出来的选择程序能否超过固定策略？

2026-10-27，R35。**在任何搜索或命中率被计算前冻结。** 只读本机 `gdsc_combinations`。

## 为什么现在做

目标写着"**仅在独立决策收益与跨任务迁移成立后**探索元学习/RSI，并对照**等预算程序搜索**"。R33 已在 GDSC 上建立独立决策收益（利用 1.43% → 6.5–7.2%，4.5×）；R32/R31 在"重复"上也已成立。门槛已到，按目标该做这一格。

本轮**不是**元学习，而是最小的**程序搜索**：在选择策略的空间里搜一个加权程序，**与固定策略在等预算下比较**，且**在未参与搜索的划分上评估**。

## 构造

- 任务同 R33：一次性预算 k=50，候选池 = 20% 留出键，10 次随机划分。
- 四个**静态排序特征**（都不含真实值）：
  1. `pred`：ridge 预测 delta_AUC（越高越协同）
  2. `var`：ridge 后验方差
  3. `rare`：候选所在组合在候选池中的出现次数（越少越"稀有"）取负
  4. `tissue`：候选组织在训练集中的占比（越小越"少数派"）取负
- **程序空间**：`score = a·rank(pred) + b·rank(var) + c·rank(rare) + d·rank(tissue)`，
  `a ∈ {0.5, 1.0}`，`b,c,d ∈ {0, 0.5, 1.0}` → **54 个程序**（全部对 rank 归一化）。
- **搜索/评估分离**：划分 1–5 用于**搜索**（选平均命中率最高的程序），划分 6–10 用于**评估**。

## 判据（预先写定）

- **H088（程序搜索有增益）**：搜出的程序在**评估划分**上的命中率高于最好的固定策略（`exploit`），配对 bootstrap 95% CI 下界 >0。
- **H089（不是过拟合）**：搜出的程序在评估划分上仍高于 `random`（CI 下界 >0）。
- **H090（搜索空间本身有信息）**：评估划分上，54 个程序的命中率分布的 90 分位 − 10 分位 >2 个百分点（说明"选程序"这件事有得选）。
- 若 H088 不成立但 H089 成立 → **程序搜索不优于最优固定策略**：等预算下没有"搜出来的智能"，只有"一个够好的固定规则"。这是对目标门控的**阴性回答**。

## 边界

- 这是**一次性**程序选择（非顺序、非元学习），不检验"跨任务学到的程序"。
- 4 个特征、54 个程序是很小的空间；更大空间未必有更大收益（也可能更易过拟合）。
- 候选池真实值回顾性揭示；特征只有通路/组织注释。
- 不涉及机制、临床、药物选择。
