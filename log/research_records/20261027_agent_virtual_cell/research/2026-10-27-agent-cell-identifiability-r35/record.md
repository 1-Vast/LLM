# R35 记录：等预算程序搜索——搜出的 50/50 混合程序在**未参与搜索的划分**上比纯利用高 3.6 个百分点

2026-10-27，Asia/Shanghai。继承 R1–R34，不改总目标。目标写着"仅在独立决策收益与跨任务迁移成立后探索元学习/RSI，并对照**等预算程序搜索**"。R33 已建立独立决策收益、R31/R32 已建立重复，门槛已到。本轮做最小的**程序搜索**，并与固定策略**等预算**比较。总目标保持 **ACTIVE / NOT_ACHIEVED**。

## 1．设计

- 任务同 R33：一次性预算 k=50，候选池 20% 留出，10 次随机划分。
- 四个静态排序特征：`pred`（预测 delta_AUC）、`var`（后验方差）、`rare`（组合稀有度）、`tissue`（组织少数派）。
- 程序空间：`a·rank(pred)+b·rank(var)+c·rank(rare)+d·rank(tissue)`，a∈{0.5,1.0}、b,c,d∈{0,0.5,1.0} → **54 个程序**。
- **搜索/评估分离**：划分 1–5 搜索，划分 6–10 评估。

## 2．结果

| 项 | 值 |
|---|---:|
| 搜出的程序 | **a=0.5（pred）、b=0.5（var）**、c=0、d=0 → 即 50/50 混合 |
| 搜索集命中率 | 12.00% |
| **评估集命中率（搜出程序）** | **12.80%** |
| 评估集：`exploit` | 9.20% |
| 评估集：`random` | 2.00% |
| 评估集：`explore` | 4.00% |
| **搜出程序 − exploit（95% CI）** | **+3.6 pp [+1.6, +5.6]** |
| 搜出程序在评估集的排名 | **5 / 54** |
| 程序空间跨度（p90−p10，搜索集） | 6.28 pp |

## 3．判决

- **H088（搜索优于最好固定策略）：成立**——+3.6 pp，CI 不含 0。
- **H089（优于随机）：成立**——12.80% vs 2.00%（6.4×）。
- **H090（程序空间有跨度）：成立**——6.28 pp。
- 总判决 `program_search_adds_value`。

**关键点**：搜出的程序在**未参与搜索**的划分上排名 5/54，说明它不是靠搜索集过拟合——真有一个"更好的权重"存在。

## 4．但必须克制：这不是"搜出了智能"

1. 搜出的程序只是**两个现有信号的 50/50 混合**——不是新机制、不是元学习、不是程序合成。
2. 多样性特征（`rare`、`tissue`）**权重全为 0**，即在这份数据上没用。
3. 空间只有 54 个程序；更大空间未必更好，也可能更容易过拟合。
4. 与 R33 一致：k=50 时混合优于纯利用；R33 里 k=20 时混合更差——所以这是**有预算条件**的结论。
