# PROTOCOL E041（预注册）：用训练样本量干净地扫过预测强度——混合策略有"中间带"吗？

2026-10-27，R41。**在任何计算前冻结。** 只读本机 `gdsc_combinations`。

## 为什么

R39 用换特征集操纵强度（混淆了维度）、R40 用标签噪声（在 n≫p 下无效，Δρ 只有 0.052）。两次都**没做成检验**。

本轮用 R40 定位出的唯一干净路径：**固定 41 维特征，只改训练样本量**。这样 ρ 会从接近 0 扫到 0.325。

## 构造

- 特征：`pathway`（41 维），**固定**。
- 训练样本量 n ∈ {200, 500, 2000, 8000, 20000, 全部（86,607）}。
- 任务同 E037：一次性预算、ridge λ=1.0、40 次划分（前 20 搜、后 20 评）、k ∈ {10,20,30,50,75,100,150,200}。
- 每个 n 在每此划分内**从同一训练集无放回抽样**，保证可比。

## 判据（预先写定）

- **H106（强度被干净扫开）**：候选池上的预测 ρ 随 n 单调**上升**，且 n=200 与全量的差 >0.15。
- **H107（存在中间带）**：至少存在一个 n，使 `mix − exploit` 在**两半上同时显著为正**（某 k 处）；**并且**在最弱端（n=200）不存在这种 k。
- **H108（最弱端无差别）**：n=200 时所有 k 上 `|mix − exploit|` < 1 pp。
- 若 H106 成立但 H107 不成立 → **"强度调节"这个说法不成立**：混合是否有效与强度既非单调也非单峰。这一次将是**真正的否证**（因为前提建立了）。
- 若 H106 不成立 → 操纵仍失败，记为未检验。

## 边界

- 单一数据集、单一特征集、单一强度来源（样本量）。
- 回顾性候选池；`SYNERGY_DELTA_AUC` 是拟合量。
- 不涉及机制、临床、药物选择；不做元学习/RSI。
