# PROTOCOL E045（预注册）：整体指标与决策尾部的"反向"是系统性的，还是三次巧合？

2026-10-27，R46。**在任何计算前冻结。** 只读本机 `gdsc_combinations`。

## 为什么

R45 把"**整体指标与决策尾部指标系统性反向**"列为候选贡献第 1 条——依据是它在 **C19**（整体可加/尾部不可加）、**C28**（混合 vs 利用）、**C34**（层级 ρ 升、precision@10 降）三处独立出现。

但"三处出现"可能只是巧合。本轮把它变成**可测量的关系**：在一个模型族里扫参数，看"整体 ρ 的提升"是否**系统性地伴随**"precision@10 的下降"。

## 构造

- 数据同 R44：GDSC，按组合分组划分，40 次（20 搜 / 20 评），评估只在候选池上。
- **模型族**（同一数据、同一划分、同一指标定义）：
  1. `ridge` × 特征集 `{tissue, pathway, full}` × λ ∈ {0.1, 1, 5, 20, 50, 200}（18 个）
  2. `hier` × λ_inter ∈ {2, 5, 20, 50, 200}（5 个，λ_base=1，特征 = pathway + 组织×通路交互）
- 参照点：`pathway, λ=1`（R37/R43 的基线）。
- 对每个变体，计算候选池上的 **ρ_global** 与 **precision@10**（真实最强十分位）。

## 判据（预先写定）

- **H118（系统性反向）**：跨所有变体，`Δρ_global` 与 `Δp@10`（相对基线）的 **Spearman < 0**，且 bootstrap 95% CI 上界 <0。
- **H119（不是单一族造成）**：只在 `ridge` 变体内、以及只在 `hier` 变体内，相关系数都 <0。
- **H120（量级检查）**：`ρ_global` 与 `p@10` **本身**（不带 Δ）在变体间也负相关，且 |Spearman| >0.3。
- 若 H118 不成立 → **"系统性反向"是巧合**，C34/R45 的表述必须撤回为"观察到三次、但不成系统"。

## 边界

- 单一数据集；只有两个模型族；指标定义固定（ρ 与 top-decile p@10）。
- 变体之间共享数据与划分，所以差的只是模型，不是数据。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
