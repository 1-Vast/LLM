# PROTOCOL E126（预注册）：衰减曲线的**上界端点**——两药都见过、且评估键未见

2026-10-27，R136。**在任何计算前冻结。** 只读 `gdsc_combinations`。

## 为什么

R135 里 `one_seen_only` 是死格：**"两药都见过 + 细胞见过"这个定义把它变成了训练行的子集**，两臂预测数值相同，零增益是构造出来的。

**要拿到"两药都见过"的正确端点，必须换切分方式：留出键，而不是留出药物/细胞。**

- **训练集与评估集按"键"（细胞×组合）对半切**，全部药物与细胞在两侧都出现。
- 这样 `identity` 对每个药物都有系数 → **覆盖率满**，是"身份信息最充分"的条件。
- 评估的是**未见过的具体组合**，不是未见的药。

## 构造

- 200 次划分；种子 **20261039**。
- 每次：按细胞分层，把每个细胞的键随机对半分（训练/评估）。
- 两臂：`identity` / `+通路`。
- 主指标：**评估集上的全局 Spearman(预测, 真实 `ΔEMAX`)**。
- 副指标：**细胞内的 Spearman**（因为 `identity` 无细胞特征，细胞内排序是它最弱的地方）。

## 预测（写死）

- **H338（上界端点：身份充分时通路无增益）**：`通路 − identity` 的全局 ρ 增益 CI **含 0**。
- **H339（通路仍有增益）**：CI 下界 **>0**。

**若 H338 成立 → 衰减曲线两端补齐：身份充分时增益 0，身份归零时 +0.13–0.15。**
**若 H339 成立 → 通路在所有条件下都加一点，"条件"只影响幅度。**

## 判据

- 全局 ρ 与细胞内 ρ 分别报；配对 bootstrap。

## 边界

- 键级切分下同一组合在别的细胞里仍被见过（这是"药见过"的正常含义）。
- 只有本资源。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
