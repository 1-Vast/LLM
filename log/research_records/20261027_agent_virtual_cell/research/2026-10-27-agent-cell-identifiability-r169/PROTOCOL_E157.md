# PROTOCOL E157（预注册）：**前瞻检验要多少测量才够**——把 MDE 反过来用

2026-10-27，R169。**在任何计算前冻结。** 只读 `gdsc_combinations`。

## 为什么

我一直用 MDE 说"这个实验分辨不了"。**从没反过来问：**如果明天去做一次前瞻验证，需要测多少个（细胞 × 药对）组合，才有 80% 把握分辨出这条结论？****

**这是目标里"最小证据"最具体的形式，也是晋升被资源卡住时唯一还能给出的可执行建议。**

## 构造

- `both_unseen` 池、ridge、内层 CV 选 λ（照 R163）。
- **20 划分**；种子 **20261069**。
- 每个划分：训练好两臂后，从评估池里**随机抽 k 个键**，算 `ρ(+通路) − ρ(identity)` 并做 bootstrap CI。
- k ∈ {50, 100, 200, 400, 800, 1600}；每个 k **抽 10 次**；每次 bootstrap **300** 次。
- **检定力** = 该 k 下 CI 下界 > 0 的比例。

## 预测（写死）

- **H402（200 键以内够）**：k ≤ 200 时检定力就 ≥ 0.80。
- **H403（需要更多）**：k ≤ 200 不够，需要 ≥400。

**若 H402/H403 给出确数 → 写成"前瞻验证至少需要约 N 个组合"的显式建议。**

## 判据

- 每 k 的检定力、平均增益、平均增益的 SD。
- **报出达到 80% 检定的最小 k。**

## 边界

- 抽样是**从已有评估池里抽**，那批键的分布与未来新测的可能不同——**这是主要外部效度限制**。
- 只有 ridge、只有本资源。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
