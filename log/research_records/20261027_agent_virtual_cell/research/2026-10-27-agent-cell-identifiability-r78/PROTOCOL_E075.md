# PROTOCOL E075（预注册）：能否**事前**识别"个人化不值得"的细胞？

2026-10-27，R77 之后。**在任何计算前冻结。** 只读 R76 的已存数据 + GDSC 元数据。

## 为什么

R77 发现 **26%（32/123）的细胞在 m≤400 内从未从自身数据获益**。如果这些细胞能被**事前**识别（只用不花钱的信息），Agent 就能决定"**这个细胞别测了**"——这正是目标里"选择最小证据"的直接应用。

## 可用的"事前"特征（都不需要该细胞的测量）

1. `pool`：该细胞的候选池大小
2. `B0`：药物边际在该细胞上的基线命中率（**不需要该细胞数据**）
3. `base`：该细胞池的协同基准率
4. `tissue`：组织

## 判据（预先写定）

- **H197（基线越好越不需要个人化）**：`B0` 在"永不获益"组显著**更高**（Welch t 检验 p<0.05）。
- **H198（越容易越不需要）**：`base` 在"永不获益"组显著**更高**。
- **H199（可用的判别力）**：用 `B0` 单独预测"永不获益"，**AUC ≥ 0.65**。
- 若 H199 成立 → 给出一条**事前判据**（含阈值），可直接用于"测不测"的决策。
- 若三条都不成立 → **事前识别不可行**，只能"测了才知道"。

## 边界

- 只 123 个细胞、32 个正例，**检定力有限**。
- `B0` 是"不测量"就能算的（只依赖训练集与候选池），所以它是合法的事前特征。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
