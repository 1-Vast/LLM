# R156 记录：饿死训练预算 98 倍，**通路优势岿然不动**；而"信息稀缺使通路更值钱"仍未被检验

2026-10-27，Asia/Shanghai。继承 R1–R155，不改总目标。R155 的问题（信息质量是否调节通路价值）在资源里无法检验。本轮**人为造出那个区间**。总目标保持 **ACTIVE / NOT_ACHIEVED**。

## 1．第一版（E156）：设计不对，而且我自己的 bootstrap 有 bug

**E156 的设计**：饿死单个可见药 S（只留 k 个训练键），评估集合 = 组合恰为 {S,H} 的键。

**结果**：每次划分评估集只有 **78 个键**，MDE ≈ **0.04**，而各档增益在 **−0.021 到 +0.027** 之间——**可分辨下界比效应还大**，所以这个零是**无信息**的。

**更糟的是**：我第一次跑的 `k20 − all` 得到 **[−0.0124,−0.0124]**——**零宽 CI**。

**原因**：我在 bootstrap 循环**内部**重新播种 `np.random.default_rng(SEED+201)`，每次重采样完全相同。

**这是"零差 + 零宽 CI"的典型签名，第七次同类问题**（R104/R108/R113/R135/R144/R147/R156）。**修正后 CI 为 [−0.0399,+0.0471]。**

> **注意：`feature_audit` 查的是特征、划分与预测，**查不到 bootstrap 里的重新播种**。检查工具的覆盖面又漏了一处。**

## 2．第二版（E157）：均匀削减预算，评估集大得多

**对每个药只保留 k 个训练键**（两个药都还有预算才保留该键），评估集 = 含任一留出药的全部键（约 15,378 键）。40 划分、种子 …1058。

## 3．能说的：**增益对 98 倍的数据削减稳如磐石**

**训练键从 92,881 削到 943（98 倍），增益是 0.0211 → 0.0214 → 0.0233 → 0.0176，四档全部显著、彼此重叠。**

**所以冻结结论不是"数据充裕的产物"。** 这是个实打实的稳健性结果。

## 4．不能说的：**"信息稀缺使通路更值钱"依然未被检验**

**看 ρ 那两列**：identity 从 0.2591 掉到 0.1971（相对降 24%），**但通路也从 0.2802 掉到 0.2146**——**因为均匀饿死把通路先验也饿死了**。

**两者同步下降，所以差距不变。而我真正想问的是"只饿死身份、不饿死通路"时差距是否扩大——那正是 E156 的设计，而它检定力不足。**

**所以这个问题**仍然悬着**，只是现在我知道它需要**更大的评估集**才能问。**
