# PROTOCOL 修订 AMENDMENT-001（E004）

2026-10-27。在**已**按 PROTOCOL.md 跑过一次全 well 重复估计之后写。修订理由是数据结构的有效性缺陷，不是探针读数方向。两个版本都报告，主判据与判据阈值不变。

## 发现的结构缺陷

PROTOCOL.md 的 N1 把"同一 file 内同 (药名,双方剂量) 的 ≥2 个 well"当作重复。实际归档里这些"重复"绝大多数不是测量重复：

- `Drug 1 = Drug 2 = "high control"`（8576 行）与 `"low control"`（8576 行）是归一化锚点，Viability 按定义恰为 1.0 / 0.0。462 个 file 各含 16 个 high control well（另有 64 well 的块），贡献约 5.5 万对重复，其中 99% 差值恰为 0。
- 因此全 well 版 σ_e = 0.0180 被定义值压小；把控制块和贴边值 (y 恰为 1 或 0) 剔除后，同一估计量给出 σ_e ≈ 0.044–0.048。
- 全 well 版还有一个可诊断的畸变：差值中位数 0.0003、MAD 派生的 SD 0.0003，而 q90 = 0.0380——双峰，正是"定义值块 + 真实重复"两类堆在一起。

## 修订（三条，均为有效性）

1. N1 主体排除 `high control` / `low control` 行。
2. N1 成对差值排除任一端 y 恰为 1.0 或 0.0 的对（归一化贴边，无测量意义）。含贴边与不含贴边两版并报。
3. 主估计量改为**读数水平匹配**的 σ_e：探针 8 个 well 的 y 在 0.63–0.94（A673 均值约 0.78/0.81，BJ 约 0.89/0.88），所以主 σ_e 取重复对中 `mean_y ∈ [0.75, 1.0)` 的分箱；[0.5,0.75) 与全范围作为敏感性。

## 披露

全 well 版（σ_e = 0.0180）下探针检验已经算过：BJ t = −1.92，未过 1.96；A673 t = 15.4。修订后的估计更大（对"存在交叉"更不利），方向与修订动机一致，因此必须明说：这次修订不能当作对阴性结论的独立支持，只能作为**有效性纠正**；两版并列，并各自给出判据结果。真正独立于 σ_e 选择的证据是第 4 条：同条件重复对的 |Δ| 经验分布给出"这个大小的差有多平常"，它不依赖任何参数假设。

4. 追加一个不依赖 σ_e 选择的经验量：探针 |d̄| 在同水平同条件重复 |Δ| 分布中的分位数。
