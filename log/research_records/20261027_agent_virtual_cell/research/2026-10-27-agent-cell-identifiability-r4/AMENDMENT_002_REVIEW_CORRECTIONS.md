# AMENDMENT-002（E004）：独立复核后的更正与撤回

2026-10-27。独立复核由单独子代理完成，它先自行独立估噪并落盘（`challenge/independent_estimate.json`），之后才打开 PROTOCOL/AMENDMENT/脚本/E004_RESULTS 对账；未读 report.md 与 record.md。全文见 [challenge/REVIEW.md](challenge/REVIEW.md)。本文件逐条登记它指出**错误**、**误标**与**遗漏**的地方，以及本轮的处置。更正的计算在 `e004b_corrections.py` → `E004B_CORRECTIONS.json`，冻结脚本 `e004_noise_calibration.py` 与 `E004_RESULTS.json` 保留原样，不覆写。

## 复核的总结论

**主判据成立**：BJ 不可分辨、A673 可分辨、决定落在预注册分支上。它在 8 个可辩护的噪声估计（SD(contrast) 0.058–0.095）上验证：A673 8/8 显著（t 4.15–6.81），BJ **0/8**（t −0.52 至 −0.85）。它还精确复现了本轮全部 σ_e 值（0.018023 / 0.044587 / 0.034894 / 0.040762）与配对计数。所以结论**不是噪声模型选择的产物**。

## 必须补上的遗漏（复核发现、本轮原先没有）

- **E1 可交换性失败（重要）**：4,883 个重复对**全部**来自 `Iteration` 字段缺失的那批文件（复核按 stage 记为第 10、15 轮），**第 11 轮（探针所在 stage）贡献 0 对**（本轮独立核对：`{'−1': 4883}`，stage 11 为 0）。探针所在的是 16×24 主网格，重复对来自 2×2 象限。**σ_e 没有来自它所应用的那个设计的直接支持**，是借用的。方向是安全的（复核自己的 stage-11/几何估计 SD(contrast)=0.0593，比本轮的 0.0577 略大；其 stage-11 数值 0.0472 也高于 0.0408），所以经验上良性，但必须标为"断言而非检验"。
- **E2 尺度低端（重要）**：复核指出本轮的 SE 处于低端。它直接测量对比方差（用同布局重复文件：`diff(w)=y1−y2` 均值 0 → `D=diff(w1)−diff(w2)`，`Var(D)=2Var(d)`，不需要同条件重复 well，也不假设板内相关），得 SD(contrast)=**0.0593**（本轮 0.0577）。差别不大，但方法更干净。
- **E3 设计盲区（最值得记住）**：σ_e 与板偏移**都看不见**"所有重复文件共享的确定性行/列效应"——它在同条件重复里抵消（同位置），在相同布局对比里也抵消，却直接进入 BJ 对比：**N22 与 O22 恰好差一行**。一个 row-O − row-N 偏移 ≥0.035 就能完全解释 BJ 效应。用 high-control 条带可以给出上界：复核得 **+0.0082 ± 0.0038**；本轮独立算得 **−0.0029 ± 0.0066**（n=26 个含 N/O 两行 high-control 的文件）。两个界都在阈值的 1/4 以下，所以结论存活；但这是**设计看不见的那个分量**，原分析没有点名。
- **E4 上下文确实不同（限定读法）**：差之差 = **0.3120 ± 0.0577（t=5.4）**，说明 A673 与 BJ 的 a−b 幅度差异极大。但这是**幅度异质性**，M0 通过每背景形变 h_c 就能容纳；它不是符号反转。阴性结果只能按"反序未被观测到"读，不能读成"两背景相同"。
- **E5 未决的数据质量项**：`Viability` **不是** `Raw count` 的仿射函数（残差 2.4–4.5%，随行结构，与行的相关约 −0.5）；两列给出的 contrast SD 分别为 0.059 与 0.090。复核无法判断哪一列是主读数，于是把所有判断在两列上都做了一遍。本轮采纳同样做法：**主结论在两种读数尺度下都成立**（BJ 在 0.090 下更不显著；A673 在 0.090 下 t 仍约 4.2）。

- `E004_RESULTS.json` **不覆盖**（保留错值的现场），更正另存 `E004B_CORRECTIONS.json`，两者并列引用。
