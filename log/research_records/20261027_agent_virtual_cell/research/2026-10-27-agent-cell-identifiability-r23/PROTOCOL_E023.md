# PROTOCOL E023（预注册）：未见组合能否由化合物主效应预测？

2026-10-27，R23。**在任何相关系数被计算前冻结。** 只读 `PAIR_SCREEN.csv`。

## 为什么

目标要求"检验向…未见药物迁移"。validation 板上双药身份重叠 **0/2,457**，所以那条路一直是"不可检验"。R21/R22 发现高多样性设计有 **6,595 个化合物对、207 个化合物、每个化合物中位 64 对**（最少 16 对）。这是归档里唯一能做**化合物级泛化**的地方。

本轮问最贴近"未见"的可检验形式：**把某一个化合物对整对留出，能否由其他化合物对预测它的 viability？** 这是"未见组合"迁移，不是"未见药物"——必须这样写。

## 构造

- 单元 = (布局, 细胞)，每个单元约 351 个化合物对。
- 模型：`y(pair) = μ + α_A + α_B`，ridge（λ=1.0 固定，**不调参**，在标准化尺度上）。
- **留一化合物对交叉验证**：用 hat 矩阵恒等式 `resid_loo_i = e_i / (1 − H_ii)` 精确计算，不重拟合。
- 对照 1：单元内均值（常数预测）。
- 对照 2：同布局另一细胞对该对的均值（跨细胞池化，仅对可用的对）。
- 指标：Spearman、precision@10。

## 判据（预先写定）

- **H052（优于常数）**：留一对的 Spearman 中位 > 0.15，布局聚类 95% CI 下界 > 0。
- **H053（可观）**：中位 Spearman ≥ 0.35。
- **H054（随覆盖改善）**：按"两化合物在其他对中的出现次数之和"分箱，高覆盖箱的 Spearman 高于低覆盖箱（差 >0，CI 下界 >0）。
- 若 H052 不成立 → 化合物主效应不能预测未见组合；"未见组合迁移"在本归档不成立。
- 若 H052 成立但 H053 不成立 → 有信号但弱，只能算"可检测"，不能算"可预测"。

## 边界

- 这是**未见组合**（两个化合物都见过，组合没见过），**不是**未见药物（化合物本身没见过）。
- 主效应模型假设可加且无交互；这正是被检验的假设，不是前提。
- 无剂量维度；不涉及机制、临床、药物选择。
- 功能读出只是归一化存活度；探索性。
