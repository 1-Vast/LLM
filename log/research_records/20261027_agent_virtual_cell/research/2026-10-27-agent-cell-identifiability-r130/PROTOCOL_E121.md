# PROTOCOL E121（预注册）：两判据的相关，**逐池**核一遍

2026-10-27，R130。**在任何计算前冻结。** 只读 `gdsc_combinations`。

## 为什么

R128 测出**全数据**上布尔 `Synergy` 与 `ΔEMAX` 四分位相关 **0.83**，据此加了"×2 判据属冗余"的规则。

**但 0.83 是全数据的。小池（尤其 `both_unseen`）里 base rate 不同，相关可能明显更低——若如此，那些池上"两判据"确实携带更多独立信息，规则要按池细化。**

## 构造

- 三池（口径同 R124）：`one_unseen`（恰一药未见、细胞见过）、`cell_unseen`（细胞未见且 ≥1 药未见）、`both_seen_cell`（两药未见、细胞见过）、`both_unseen_cell`（两药未见、细胞未见）。
- 对每个池，取该池全部键，计算：
  1. **键级** `Spearman(布尔 Synergy, ΔEMAX)`；
  2. **键级** `Spearman(布尔 Synergy, ΔEMAX 上四分位指示)`；
  3. **基准率**（两个判据各自的阳性率）。
- 另算：**在 `both_unseen` 池里，两判据的阳性集合重叠（Jaccard）**。

## 预测（写死）

- **H325（小池相关更低）**：`both_unseen` 池的 \|ρ\| **比全数据低 0.15 以上**。
- **H326（各池都高）**：所有池 \|ρ\| **均 ≥0.7** → **规则无需按池细化**。

**若 H325 成立 → 规则改为"按池读"；若 H326 成立 → 规则保持全局。**

## 判据

- 逐池报 ρ 与 n；报 Jaccard 重叠。

## 边界

- 池是**键级**划分，键之间不独立（同细胞/同药共享）。
- 只反映本资源。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
