# PROTOCOL E044（预注册）：层级/部分池化模型 vs 平铺 ridge——目标要求的对照，从未真正做过

2026-10-27，R44。**在任何计算前冻结。** 只读本机 `gdsc_combinations`。

## 为什么

目标明确要求"以相同信息和预算对比强预测器、**重训练、层级模型**、随机、GP及决策主动学习"。本项目做过：随机、GP（BATCHIE，R11）、决策-AL（R33–R37）、程序搜索（R35）。**层级模型只在 R11 试过一次，而且退化了**（留出细胞没有细胞效应可估，加性层级模型塌成跨细胞均值）。

GDSC 提供了真正能做层级模型的结构：**125 个细胞、3 个组织、2,025 个组合**，且覆盖不均。本轮做一个**部分池化**的层级模型：允许"通路效应随组织变化"，但对该交互块施加**更强的惩罚**（把组织特异的通路效应收缩到共同通路效应）。

## 构造

- 特征：`base` = 组织 + 锚定通路 + 文库通路（41 维）；`inter` = 组织 × (锚定通路+文库通路) 的 one-hot 乘积（3×38 维）。
- **模型 F（平铺）**：`[base]`，λ=1.0。
- **模型 H（层级/部分池化）**：`[base, inter]`，`λ_base=1.0`、**`λ_inter=20`**（先验固定，不在评估集上调）。
- 敏感性：`λ_inter ∈ {5, 50}` 一并报告（不用于选择）。
- 划分：**按组合分组**（R43 表明这是更接近"新组合"部署的设定），40 次，20 搜 / 20 评。
- 指标：候选池上的 ρ、precision@10（真实最强十分位）。

## 判据（预先写定）

- **H115（层级更好）**：模型 H 的 ρ 高于模型 F，配对 bootstrap 95% CI 下界 >0。
- **H116（增益集中在组织内的通路差异）**：H−F 的 ρ 增益在**组织×通路交互本应有用**的子集上更大——操作化为"按组织分层的 H−F 差"，要求至少 2/3 组织的差为正。
- **H117（precision@10 同向）**：H 的 precision@10 也高于 F（CI 下界 >0）。
- 若 H115 不成立 → **层级/部分池化在本任务上不带来增益**，平铺模型已足够。这是对目标括号里"层级模型"这一项的**阴性回答**（与 R11 的退化不同——这次是公平比较）。

## 边界

- 单一数据集；交互块只做组织级，不做细胞级（细胞级对留出细胞不可用，那正是 R11 退化之处）。
- λ_inter 固定为先验值，只做敏感性，不在评估集上选。
- 回顾性；`SYNERGY_DELTA_AUC` 是拟合量。
- 不涉及机制、临床、药物选择；不做元学习/RSI。
