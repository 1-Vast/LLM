# Innovation validation repair: engineering defects fixed, unique benefit still unestablished

The failure had three causes: an incorrect acquisition calculation, incomplete
implementation of the claimed inheritance mechanism, and a task family largely
served by conventional latent models. Repairing the first cause does not establish
the proposed scientific innovation. The bounded repaired diagnostic now runs and
replays correctly; an ordinary latent model using the corrected acquisition rule
matches or exceeds the inherited model in its development results.

Three independent reviewers examined implementation, statistics and mechanism.
Their claims were cross-checked against source code, stored outputs and analytical
fixtures. This package is an audit and an isolated repair, not an overwrite of the
original study. All 411 preserved non-cache files across the three predecessors
remain byte-identical. No old sealed outcomes, real evaluation backgrounds, API,
external messages or wet experiments were used. Nothing was staged or committed.

## What failed, and what has been resolved

| Cause | Evidence | Resolution and limit |
|---|---|---|
| KG used inconsistent simulated worlds | Continuous-factor outcomes were drawn independently per pair, while posterior updates used correlated Kalman gains. A valuable probe could appear worthless. | Replaced the estimator with expected maximum posterior shortlist utility minus current maximum. Probe outcomes use the correct marginal; target predictions use the matching conditional model. Recorded values stay fixed. |
| Useful continuous probes were screened out | Candidate screening used between-component mean disagreement, which can be zero when latent information is substantial. | A-optimal evaluates every legal action. KG screens across disagreement, continuous information and exploitation, with an actual cap of 40. |
| Gate identity discarded executable content | Same-scope/sign gates with different numerical profiles shared IDs and could be deduplicated. | Full numerical-definition fingerprints; lineage is separate. Program keys can include current definitions and canonical undirected conjunction edges. History versions hash observations and fitted prior parameters, not only cell names. |
| Deployment refitted already-adapted gates | A validated fit was discarded; a second fit could fail, silently leaving a base model behind a deployed-program record. | Cache and reuse the actual gate fit for the same history/definition, including copied program objects. At release boundaries fit once and explicitly record rollback on failure. Stale/missing deployment snapshots raise an error. |
| The verifier waived a failed invariant | `compose_8/rst_kg/checkpoint4` declared a gate but eight anchor rows used no gate. The original replay sample covered only first-generation inherited tasks. | New strict legacy audit does not waive exceptions and covers every archived decisive task model. It correctly returns failure for the old checkpoint; old unarchived anchor fits cannot be reconstructed as historical evidence. |
| Archive and diagnostic-plan claims exceeded implementation | No candidate was added to or retrieved from the archive; probe-order metadata and applicability declarations were not executed. | Corrected archive counts and explicitly label reuse NOT_IMPLEMENTED. Removed the misleading unused applicability/plan interface from the repair. Branching procedure inheritance is a new mechanism still to be tested, not silently added to make the old study pass. |
| H2 did not match resources | Restart had `12 * generation` candidate slots versus 12 for inheritance. | Old H2 is retained only against the expanded-budget restart. Equal-resource H2 stays NOT_TESTED. The new diagnostic matches candidate ceilings and records actual costs, without pretending equal ceilings imply equal CPU. |
| Mechanism controls and scientific labels were too strong | Decoupling altered late-gate marginals and retained other probe-to-target paths; H3 was a conditional gain, not an interaction. | Corrected interpretation in `STATISTICAL_REVIEW.md`. The flawed control is not reused as causal evidence. The post hoc four-arm interaction is separately labelled and does not replace H3. |

The old synthetic mechanisms also have limited rank: alias uses three loading
outer products; compose uses four plus one conjunction outer product, giving
mechanism-only rank at most three and five. A continuous latent comparator can
therefore explain much of the same information. This is a reason the current
representation may be redundant, not a claim that biological responses in general
have low rank or that all future virtual-cell research is futile.

The analytical fixture has one shared Gaussian latent state, a diagnostic probe,
and two competing shortlist targets. It needs no learned model or outcome dataset.
With measurement noise 0.01 its exact KG is `sqrt(2/pi)/sqrt(1+0.01^2)/5`.

| Estimator | Value with seed 0 and 20,000 samples |
|---|---:|
| Analytical value | 0.159568934 |
| Original implementation | -0.001015198 |
| Repaired implementation | 0.160570499 |

The original implementation would stop; the repair would continue. Independent
uninformative probes have zero transfer value, and an analytical truncated-normal

  `INVALID_LEGACY_CHECKPOINT`. The old task estimates are not invalidated by this

## What the repaired diagnostic says

The protocol fixed two new development seeds for each unchanged generator family,
12 drugs/66 pair units, four generations, four queries and shortlist size five.
These are small engineering worlds with a different pool size from the original
study. They are not new independent pharmacological evidence and cannot overturn
the old 378-pair results. All eight runs completed once in 210.77 elapsed seconds.

Mean utility over batches 2-4, pooling the four alias/compose development streams:

| Method | E: queried pairs may be nominated | T: probes and nominated targets are disjoint |
|---|---:|---:|
| Inherited gates + corrected KG | 0.836834 | 0.796345 |
| Restarted gates + corrected KG | 0.836585 | 0.795060 |
| Ordinary rank-3 latent + A-optimal | 0.826630 | 0.795622 |
| Ordinary rank-3 latent + corrected KG | 0.836844 | 0.798870 |

Relative to latent + A-optimal, the inherited pipeline has a development E gain
of about 0.010205. However, its E difference from ordinary latent + corrected KG
is -0.000010, and its T difference is -0.002525. Thus an available conventional
configuration explains the apparent advantage in this diagnostic. It would be
incorrect to report the A-optimal comparison alone as successful inheritance.
There are too few streams for an efficacy claim; no new CI, significance test or
SUPPORT label is produced. The two null worlds deploy no gates. Inheritance
deploys at six of 32 checkpoints, restart at four.

| Cost across all eight diagnostic streams | Inherited KG | Restarted KG | Latent A-optimal | Latent KG |
|---|---:|---:|---:|---:|
| Actual candidate evaluations | 165 | 372 | n/a | n/a |
| Candidate validation task replays | 660 | 1,488 | n/a | n/a |
| Measured process CPU seconds | 70.484 | 113.688 | 0.281 | 15.813 |
| Measured elapsed arm seconds | 74.043 | 119.429 | 0.793 | 16.195 |

Both library arms had a ceiling of 12 candidates per generation; unused slots
were not padded. Consequently actual search effort differs and a fully equal-CPU
inheritance comparison remains untested. Shared history fitting adds 0.047 process
CPU seconds separately. Arm totals include their own fitting, search, validation,
campaigns and artifact storage; library arms additionally run engineering anchors,
so these totals are not a matched task-only efficiency benchmark. Costs are
instrumented diagnostic costs, not inferred assay costs or production estimates.

## Scientific decisions that remain

The original H1 negative result is numerically robust for the original
implementation: a family-stratified 98.333% interval is [-0.001951, +0.005671],
below the registered 0.01 useful-gain threshold at its upper end. That does not
evaluate the repaired algorithm. H2 only tested the expanded-budget restart;
H3 tested policy adaptation conditional on structural adaptation. The descriptive
factorial interaction is -0.000758, 95% interval [-0.002646, +0.000789]. Neither
these computations nor repaired software establish a useful unique innovation.

The original resource columns measured elapsed time, not process CPU, and mixed
96 normal streams with 144 total streams. Correct counts and intervals are in
`STATISTICAL_AUDIT.json`. The old recommendation to procure a 350-pair pool on
12 backgrounds is withdrawn: eight historical backgrounds would leave only four
evaluation units, the synthetic world SD is not a real-background SD, and the
formula used was a precision calculation rather than a powered useful-gain test.
Measured pharmacological utility remains NOT_TESTED.

The current finite binary-factor family is not a demonstrated open-ended
evolution system. The immediate research object should be an actually executable
experimental procedure learned from feedback, with branching measurements,
applicability/unknown exits, and inherited evidence. Test its later-task
measurement or planning-cost benefit against the same response model with fresh
planning, corrected KG/lookahead, and ordinary amortized policy distillation.
Factor inheritance, plan inheritance and their combination must be separated.
If ordinary planning/distillation explains the benefit, stop this novelty claim.
Adding more agents, gate counts or specially favorable generators does not answer
that question. The bounded next-step instructions are in
`log/20261020/NEXT_PROCEDURE_INHERITANCE_PROMPT.md` at the repository root.
