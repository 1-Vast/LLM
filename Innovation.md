# Research contribution: condition-bound evidence acquisition

The proposed contribution is a measurable interaction between a pretrained
virtual-cell world model and an evidence-acquiring agent. It remains a research
hypothesis, not an established biological or LLM advantage.

## Scientific problem

A candidate can have a plausible response prediction while its comparison with
another candidate remains unsupported. Genetic-pharmacological discordance may
reflect incomplete perturbation, intervention-mode differences, multi-target
pharmacology, compensation, context dependence or an unresolved explanation.
RNA response alone cannot separate these mechanisms.

The agent should identify the specific unresolved comparison or prerequisite,
choose a compatible observation and revise the action only when qualified
feedback supports the revision. The world model should expose condition-bound
predictions and limitations that make this acquisition useful.

## Two contributions to test separately

| Component | Proposed contribution | Required comparison |
|---|---|---|
| Frozen STATE world | Predict intervention-dependent responses under exact conditions | Same policy, legal inputs and budget with/without correctly mapped STATE forecasts |
| Agent / acquisition policy | Buy evidence that reduces consequential selection loss and stop when further evidence is not worth its resource use | Same world, tools, observations and budget against strong deterministic and fixed policies |
| Interaction | World forecasts reduce the evidence required for useful decisions | Factorial ablation, equal cost/deadline, independent-source final outcomes |

For an LLM-specific claim, include real semantic tool/evidence choices, an equally
informed deterministic comparator, invalid-action rates and provider costs.
Arithmetic routing or persuasive explanations do not establish agent benefit.

## Current limitation and next test

The latest full-menu boundary policy recovers a comparison missed by a fixed
schedule, but existing KG achieves the same final value and cost. A marginal
error head changes query order without benefit, and the registered stop threshold
never fires. These findings favour learning candidate-pair or selected-set loss
and the value of another legal observation, rather than adding model size.

Develop that correction with strongly shrunk models and nested whole-context
rollouts. Register source qualification, cost, stopping and controls before target
outcome access. STATE saw the reference contexts during pretraining; nested
empirical fitting cannot turn them into independent model calibration. Seek
qualified cheap public independent units before confirmation.

## Refinement after the phenotype-anchored test (2026-10-10)

The interaction hypothesis now carries a precondition that can be checked before any unseen
context is spent. On reference contexts, a *perfect* forecast (observed responses substituted)
must beat the best cheap prior for the decision endpoint by the minimum useful benefit, through a
bridge measured in the same culture unit.

For Tahoe survival selectivity it does not: the margin is 0.003 r over basal-similarity transfer.
On held-out lines, STATE lost to that transfer, as the gate predicted. The world model's held-out
signal appeared only on transcriptomic composition (G1 shift).

The next test of the interaction hypothesis should therefore start from an endpoint where the
reference ceiling clears the gate. Building more model capacity for an endpoint whose ceiling
fails cannot help.

## Measure or predict (block K, 2026-10-10)

The interaction is now a three-way decision. For a later-fate endpoint the agent compares two
estimates, each scored on reference units in the decision's own assay or platform:
* what the world model's forecast of an early state adds to the cheap prior;
* what *measuring* that state adds.

The agent then consults the model, measures, uses the prior, or abstains until more reference
units exist.

The first test located the failure. STATE's line-specific knowledge did not transport to an
independent platform, even though basal profiles aligned 18 of 18. Measuring at 24 h did not beat
a strong DepMap-scale prior on 48 lines; the informative state appeared at 24-48 h. The gate's
point-estimate MEASURE call was wrong, and its own interval had straddled the threshold.

A dual-core advantage therefore needs either a world model qualified inside the decision's
platform, or later or richer early states. It also needs gate intervals narrow enough to act on.
Combining a forecaster with an acquisition rule is not enough.

## What would establish the claim

A positive result must preserve independent-source selection value with fewer
paid observations, or improve value at the same cap and deadline. It must survive
correct/matched-permuted STATE, empirical-only, design/missingness and competent
same-information controls. RNA proxy improvement cannot certify phenotype or
mechanistic conclusions without a supported bridge.

Top-k boundary sampling, Gaussian conditioning, knowledge gradient and active
learning are established methods. Combining their names with STATE or an LLM is
not an algorithmic novelty claim. The substantive hypothesis is a validated,
condition-bound reduction in information cost from the interaction of the cores.
