# Raw experimental inputs

Store raw experimental inputs here, preserving original content and source identity. Downloaded external datasets belong in [external](../external/README.md); derived outputs belong in [processed](../processed/README.md).

Record source, version, paths and hashes in the corresponding [log record](../../log/README.md). Keep code in [research](../../research/README.md). Do not delete unique data when cleaning experimental code. See the [data inventory](../INVENTORY.md).
