# Biological depth of the virtual cell and agent

Does MAESTRO's virtual cell carry **perturbation-specific biology**, or only the response most
drugs share? Do the agent's reasoning components read a measured response mechanistically?
This directory holds the pre-registered test of both questions, run on 2026-09-26.

The frozen protocol is [`PROTOCOL.md`](PROTOCOL.md) with [`protocol.json`](protocol.json) and the
literature anchors in [`anchors.json`](anchors.json); their hashes were recorded in
`log/20260926/README.md` before any response was computed. [`calibration_spec.json`](calibration_spec.json)
is a later, separately hashed addendum for serving intervals. Results, deviations and the claim
boundary are in the day record; the tables there are generated by [`scorecard.py`](scorecard.py).

## Result in one paragraph

SciPlex3 carries the biology: seven of ten literature anchors hold in the measured data. No
virtual-cell arm reproduces more than three of those seven for compounds it never saw, none beats
predicting "no change" gene-wise, and none meets the rule for advisory ranking. The JEPA latent
world model matched PCA and did not beat structure retrieval, so it is not promoted. Retrieval
over measured profiles is the component with depth: it names a held-out compound's class at
0.500 (chance 0.059), where DeepSeek (0.100) and Jev (0.075) cannot, and both follow its evidence
card to 0.425 and 0.475. Two findings changed how the audit itself must be read: an arm that
predicts no change scores 0.130 on the registered specificity metric, and the vehicle null calls
most low-dose noise a response. Both are recorded, with post-hoc corrections labelled as such, in
`log/20260926/README.md`.

## Files

| File | Role |
|---|---|
| `common.py` | Protocol loading, compound identity folding, structure resolution, skeleton folds, clustered bootstrap |
| `prepare.py` | Streams SciPlex3 twice: vehicle means and label verification, then replicate pseudobulks, matched-vehicle shifts, minibulk chunks and the vehicle null |
| `models.py` | Every arm: zero, systematic, ridge, structure kNN, the repository's current learned rung, and PCA / masked-reconstruction / JEPA latent world models with a shared pharmacological transition head |
| `run_cv.py` | Five-fold cross-validation grouped by structure skeleton; held-out responses are set to NaN so no arm can read them |
| `audit.py` | Metrics B1-B8, the ten anchors, the primary comparisons and the frozen verdict rules |
| `calibrate.py` | Cross-conformal coverage of served readouts, per `calibration_spec.json` |
| `agent_probe.py` | DeepSeek and Jev read anonymised measured signatures, with and without a retrieval card |
| `build_library.py` | Packages the verified shifts as the digest-bound library read by `tools/signature_retrieval/` and `virtual_cell.response_rung` |
| `scorecard.py` | Renders the result files as the tables quoted in the day record |
| `posthoc.py` | Post-hoc diagnostics prompted by the audit, labelled as not pre-registered |
| `build_rung_calibration.py` | Assembles the served rung's calibration and informativeness gate from recorded results |

## Reproduction

```bash
python research/biological_depth/prepare.py --output outputs/biological_depth_20260926/prepared
python research/biological_depth/run_cv.py --prepared outputs/biological_depth_20260926/prepared --output outputs/biological_depth_20260926/cv
python research/biological_depth/audit.py --prepared outputs/biological_depth_20260926/prepared --cv outputs/biological_depth_20260926/cv --output outputs/biological_depth_20260926/audit
python research/biological_depth/agent_probe.py --prepared outputs/biological_depth_20260926/prepared --output outputs/biological_depth_20260926/agent_probe
```

The preparation needs `data/raw/sciplex3/SrivatsanTrapnell2020_sciplex3.h5ad` and the HGNC and
Hallmark files under `data/external/`; the cross-validation uses a CUDA device when present; the
agent probe spends against the provider ledger and needs the `.env` keys.

## A data defect found on the way

The SciPlex3 release's feature table opens with a stray header row, so every published gene
label names the neighbouring column. Cell-line identity markers settle it (12 of 12 at offset +1,
5 of 11 as published), and `src/virtual_cell/identity_markers.py` now makes every reader of that
file prove its alignment or refuse. See `data/README.md`.
