# Procedure inheritance audit 1

This is a post-result, read-only audit of the frozen
`procedure_inheritance_20261020` study. It corrects software accounting and
interpretation; it is not another experiment or a reopened evaluation.

The original package, its negative development decision, source freeze, saved
models, query logs, outcomes and timing records remain unchanged. The audit
preservation receipt pins all 46 non-cache files. The original verifier has also
checked its four predecessor packages.

Scope:

1. Recompute invocation costs from ALL 16 task backgrounds, separately from the
   later-12 utility estimand. Divide by the actual invocation count. Preserve
   original values alongside corrected values and expose timer quantization.
2. Require the primary assay-unit saving condition before a corrected future
   decision rule can advance. Preserve the frozen rule and its actual label;
   demonstrate the missing conjunction with a synthetic counterexample.
3. Replay saved artifacts using only public references and logged observations;
   do not generate synthetic hidden truth or refit any model. Compare exit,
   applicability, fallback and student identity fields as well as the recorded
   query sequence, plan identity, branch and nominations. Validate input plan
   JSON content hashes before using the original loader. Reject missing or
   duplicated campaign coordinates and field mutations.
4. Report family/seed dependence, distinct novel backgrounds, transplant
   execution coverage and internal-selection limits. Subgroup calculations are
   descriptive post hoc checks, not replacement endpoints or new significance
   tests. No new seed, generator, threshold, policy or utility evaluation.

No API, raw real dataset, sealed outcome, procurement, external message or
scientific retraining is needed. Tests use small synthetic fixtures and saved
synthetic study records. Audited
engineering correctness must not be labelled biological validation or
open-ended evolution.
