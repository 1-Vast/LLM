# 技术选择与来源核查

核查日期：2026-09-27。用户提供的论文介绍是设计参考，不作为已验证的性能证据。
以下区分原方法、借鉴内容及本次没有实现的能力；没有堆叠所有流行模型。

| 技术 / 可访问来源 | 本次借鉴或判断 | 核查范围与边界 |
|---|---|---|
| [CellFlow](https://github.com/theislab/CellFlow), [2025 预印本](https://doi.org/10.1101/2025.04.11.648220) | 条件群体传输，局部 OT 配对及流匹配；本次实现小型 PyTorch 版本 | 已读官方 README，Europe PMC 核实标题/作者/预印本信息；没有声称复现官方所有编码器、损失或性能 |
| [State](https://github.com/ArcInstitute/state) | 群体层面的预测和分布评估；沿用仓库已有适配器 | 已读官方 README；论文页访问受限。新实现是均值/标准差集合摘要，不是 State Transformer；正式采用权重需考虑许可和预训练数据重叠 |
| [STACK](https://doi.org/10.64898/2026.01.09.698608) | 条件群体能成为上下文；必须检查 prompt 在推理时是否可得 | 核实 Europe PMC 摘要：149M 细胞、tabular attention、群体 in-context learning；未核实用户材料中全部损失/超参，不把细节作为实现依据 |
| [PRESAGE](https://doi.org/10.1101/2025.06.03.657653) | 优先知识来源、效应和功能读数评估，不默认越大越好 | 已核实摘要；主要是遗传扰动。基因敲除先验不能直接当药物靶点结合证据 |
| [CPA / chemCPA](https://doi.org/10.15252/msb.202211517) | 药物结构、剂量、细胞背景的组合条件；保留化学简单基线 | 已读 PMC 全文；不会把药物 ID 的外推能力等同于化学编码器能力 |
| [CellOT](https://doi.org/10.1038/s41592-023-01969-x) | 未配对群体和传输假设；不能声称同细胞前后配对 | 已读 PMC 全文；传输图是建模假设，不是谱系数据 |
| [GEARS](https://www.nature.com/articles/s41587-023-01905-6) | 多基因组合预测可作合适任务的候选基线 | 已读摘要/正文内容；不能用 CRISPR 组合直接替代药物抑制机制 |
| [D-SPIN](https://doi.org/10.1016/j.cell.2026.04.028) | 未来评估基因程序/调控生成模型，与群体结构相符 | 已核实 Crossref 元数据及 Europe PMC 摘要，全文访问失败；未实现，边不自动等于因果真相 |
| [PrePR-CT](https://www.nature.com/articles/s42256-026-01202-2) | 小数据化学响应的细胞类型特异共表达先验 | 已读摘要/正文内容；未来须只用训练数据建图，并与随机图/无图对照，不把 attention 作为因果证据 |
| [泛化扰动预测基准](https://doi.org/10.1038/s41592-025-02980-0) | 分场景和留出背景评估，不从单一表达相关性宣称通用优越 | 已核实 Crossref/Europe PMC 摘要；Nature 直接访问失败 |

用户材料的 Tahoe-x1、SCALE、MultiFlow 细节本次没有充分核查，不以其参数数量、
损失配置或宣传性能支撑实现选择。不能把本次小型群体模型称作“2026 最强模型”。

智能体侧参考：[HEP](https://arxiv.org/abs/2607.09195) 的假设-检验-证据轨迹，
[Biomni](https://doi.org/10.1101/2025.05.30.656746) 的工具执行，
[Coscientist](https://www.nature.com/articles/s41586-023-06792-0) 的真实实验闭环，
[AI Scientist-v2](https://arxiv.org/abs/2504.08066) 的自动研究工作流。
HEP 的材料科学应用、Biomni 摘要、Coscientist 正文及 AI Scientist-v2 摘要仅用于
工程启发；这些论文没有替 MAESTRO 验证生物机制判断或选实验收益。

本次选择修复已有生命周期中的身份和解释确定性，未重建另一套大型状态机。
世界模型提供预测，真实实验和有来源证据才更新科学结论；Jev/LLM 不认证生物真值。
