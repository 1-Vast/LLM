2 Problem Formulation The aim in a contextual optimization setting is to go from context z z to optimal decision x ∗ ​ ( z ) x^{*}(z) , by finding a mapping or policy π : Z → X \pi:Z\to X . Due to the structure of the (potentially combinatorial) optimization problem x ∗ ​ ( ⋅ ) x^{*}(\cdot) , it is challenging to learn this complete end-to-end mapping directly ( Bengio et al., 2021 ) . Considering it as separate prediction and optimization problems (predict-then-optimize) is practical, as both problems have been studied extensively ( Sadana et al., 2025 ) . From the prediction problem perspective, assuming data with feature-label pairs z , c z,c available, a typical learning would be to train predictor ϕ θ : Z → C \phi_{\theta}:Z\to C in a supervised manner by minimizing its predictive error (e.g., mean squared error: ‖ c − c ^ ‖ 2 2 ||c-\hat{c}||^{2}_{2} ). We will refer to this approach as prediction-focused learning (PFL). By contrast, DFL aims at learning a predictive model that minimizes decision error, taking the downstream optimization problem into account. Decision error is a measure of the difference between empirical optimal decision x D ​ ( c ) x^{\text{D}}(c) and the obtained decision based on the prediction x D ​ ( c ^ ) x^{\text{D}}(\hat{c}) (e.g., regret: f ⁡ ( c , x D ​ ( c ^ ) ) − f ⁡ ( c , x D ​ ( c ) ) f(c,x^{\text{D}}(\hat{c}))-f(c,x^{\text{D}}(c)) ). Here x D : C → X x^{\text{D}}:C\to X is the (single scenario) deterministic proxy of stochastic optimization problem x ∗ ​ ( ⋅ ) x^{*}(\cdot) from ( 1 ): Both learning methods lead to a policy π D = x D ∘ ϕ θ \pi^{\text{D}}=x^{\text{D}}\circ\phi_{\theta} . It is natural to consider this deterministic proxy, since in practice we only have data available and therefore do not have 𝒞 z \mathcal{C}_{z} to compute x ∗ ​ ( z ) x^{*}(z) directly. We observe realized pairs z , c z,c , that have an accompanied empirical optimal x D ​ ( c ) x^{\text{D}}(c) . However, at inference time, x ∗ ​ ( z ) x^{*}(z) is the optimal decision and there is no guarantee that x D ​ ( ⋅ ) x^{\text{D}}(\cdot) is able to equal x ∗ ​ ( z ) x^{*}(z) . Proxy x D ​ ( ⋅ ) x^{\text{D}}(\cdot) can be limited to a subset of the feasible space X D ⊂ X X^{\text{D}}\subset X due to its structure, which means that x ∗ ​ ( z ) x^{*}(z) is unattainable if it lies outside X D X^{\text{D}} . Assume we have some capital that we want to grow in the coming t t years. 4.1 Scenario-Based Proxy Based on Theorem 4 we know that in certain cases proxy x D ​ ( ⋅ ) x^{\text{D}}(\cdot) is suboptimal. Since this deterministic variant is introduced to approximate decision problem of interest in Equation ( 1 ), we consider an alternative approximation based on the principle of sample average approximation (SAA) ( Kleywegt et al., 2002 ) : Note that x D ​ ( ⋅ ) = x 1 S ​ ( ⋅ ) x^{\text{D}}(\cdot)=x_{1}^{\text{S}}(\cdot) . SAA is used to approximately solve stochastic optimization problems, when the uncertain parameter distribution is known but does not lead to a solvable optimization problem (non closed-form objective). This approach works by sampling and subsequently solving the SAA. The SAA converges to the true stochastic optimization problem as the number of samples goes to infinity. In the contextual optimization setting this results in the following theorem: Theorem 6 ( Kim et al. (2015) ) . Suppose A ⊂ X A\subset X is nonempty and compact, such that (i) x ∗ ​ ( z ) ∈ A x^{*}(z)\in A , (ii) for sufficiently large n n , x n S ∈ A x^{\text{S}}_{n}\in A and (iii) suppose that f ⁡ ( c , ⋅ ) f(c,\cdot) is continuous at x x a.s. for any x ∈ X x\in X , and that there exists δ > 0 \delta>0 such that the family of random variables { f ⁡ ( c , y ) : ‖ y − x ‖ < δ } \{f(c,y):||y-x||<\delta\} is uniformly integrable. Then x n S ​ ( ⋅ ) → x ∗ ​ ( z ) x^{\text{S}}_{n}(\cdot)\to x^{*}(z) . Based on this theorem, as long as we pick n n large enough we can learn to closely approximate the true distribution and get the optimal decision. In a DFL pipeline however, it would be too costly to pick a high value of n n . Fortunately, the main benefit of DFL is that it can learn to produce high-quality decisions as long as the decision proxy is expressive enough. To achieve this, we predict the scenarios directly instead of sampling them as done in SAA. This results in the following predictor ϕ θ S n : Z → C n \phi_{\theta}^{\text{S}_{n}}:Z\to C^{n} , and scenario-based policy π S n = x n S ∘ ϕ θ S n \pi^{\text{S}_{n}}=x_{n}^{\text{S}}\circ\phi_{\theta}^{\text{S}_{n}} . In the experimental results we see that with as few as n = 2 n=2 scenarios the scenario-based proxy leads to significantly better decisions than the deterministic proxy. This shows that DFL eliminates the need of using many samples. Figure 2 shows a schematic representation of the scenario-based proxy.

## q08 #S6

6 Discussion and Related Work We formally showed cases when deterministic proxies are suboptimal, even in a DFL setting, and introduce effective alternative proxies. This is another step in understanding the applicability of DFL, after Cameron et al. (2022) consider when PFL is worse compared to DFL and Homem-de-Mello et al. (2026) show for a certain class of problems that an optimal single-scenario exists. Similarly, Schutte et al. (2024) discuss the importance of the decision proxy by highlighting the difference between the empirical (deterministic) problem and the true stochastic problem, and introduce loss functions that generalize better. Furthermore, ( Wilder et al., 2019 ) introduced a continuous relaxation proxy to speed up DFL, using a quadratic regularization term on the decision vector. There are several works that consider the true problem as stochastic and use distribution-based decision proxies. These works differ from our work in that we provide theoretical backing on when a deterministic proxy is suboptimal, as well as propose alternatives based on this theory that keep complexity low. Donti et al. (2017) tackle a problem that has a differentiable formulation when assuming the uncertainty is Gaussian. Alternatively they assume the uncertain parameter has finite discrete support, having the predictive model output probabilities for these discrete scenarios. This is a similar assumption as done by Qi et al. (2025) , which is quite limiting as uncertain parameters are often continuous and multi-dimensional, requiring to decide on some discretization that is representative without having too many scenarios. Our scenario-based approach learns representative scenarios and only requires to decide the number of scenarios up front. Elmachtoub et al. (2025) also include a distribution-based approach, assuming a parameterized family of distributions. They show that when the distribution is misspecified, distributional DFL (contextual integrated-estimation-optimization) outperforms distributional PFL (estimate-then-optimize), while in a well-specified distribution case the result is opposite. Jia et al. (2025) use scenarios in a predict-then-optimize routing problem, but do not train end-to-end. Stochasticity is also used to obtain gradients when they do no exist or are zero, but in these cases the deterministic proxy is applied at inference ( Berthet et al., 2020 ; Silvestri et al., 2026 ) . The same is done at inference by Hu et al. (2023) , who consider uncertainty in the constraints and model infeasibility using penalties. We refer the reader to ( Qi and Shen, 2022 ) for an operations management perspective on DFL, and ( Mandi et al., 2024 ) for a general DFL survey.

## q08 #S7

7 Conclusions A prevailing assumption in decision-focused learning is that there exists a single-scenario problem approximation that allows for optimal decision-making. While this is a valid assumption in a wide class of problems, this paper investigates for the first time general theoretical properties of problems for which this assumption is violated. Based on these properties we derive requirements for problem approximations that are sufficient to reach optimal decisions. On three problems we empirically showed the value of the proposed approaches.
Future work includes studying problems where parameterized distributions can easily be assumed and problems from practice, to evaluate the applicability of DFL and different proxies. Given the strong performance of the quadratic proxy, it raises the question how relevant the true objective is in DFL.

4.2 Task Arbitration To investigate the effects of allowing interleaved learning in multi-task settings, we propose a task selection strategy based on the assessment of each task’s learning progress or its discounted version by the neural cost of learning. Unlike traditional multi-task learning approaches that train tasks in a fixed schedule or isolate them entirely, our method continuously evaluates the tasks’ performance trends and selects which task to train next based on these evaluations. By doing so, we aim to emulate the human tendency to switch among tasks. An overview of the proposed interleaved task engagement mechanism is presented in Algorithm 1 , where a non-greedy selection strategy is adopted by giving other tasks a chance to be selected, with an exploration rate ϵ \epsilon , thereby reducing over-reliance on the highest-scoring task. 1. Learning Progress (LP) Based Task Selection LP of a task is computed based on the recent history of the error signal pertaining to it: the error in the last L L ( L = 5 L=5 in the current study) steps linearly regressed against time and negative of its slope is taken as the LP value. To be concrete, let E t 𝒯 i E^{\mathcal{T}_{i}}_{t} be the error at time step t t for task 𝒯 i \mathcal{T}_{i} .
Consider the set of errors { E t − L + 1 𝒯 i , E t − L + 2 𝒯 i , … , E t 𝒯 i } \{E^{\mathcal{T}_{i}}_{t-L+1},E^{\mathcal{T}_{i}}_{t-L+2},\ldots,E^{\mathcal{T}_{i}}_{t}\} . Then, a linear model is fit to these points to estimate the slope β 𝒯 i \beta^{\mathcal{T}_{i}} . If β 𝒯 i < 0 \beta^{\mathcal{T}_{i}}<0 , the error is decreasing, and the task is making positive learning progress. If β 𝒯 i ≥ 0 \beta^{\mathcal{T}_{i}}\geq 0 , it suggests that the error has plateaued or is increasing, implying no recent improvement. 6 Conclusion This paper introduced a biologically inspired interleaved multi-task learning framework that selects tasks dynamically based on learning progress and neural computational energy cost. Motivated by how humans interleave tasks and regulate cognitive effort, our method, IMTL-LP, prioritizes tasks that exhibit positive learning progress, while the energy-aware version, IMTL-EMLP, considers learning efficiency by discounting LP by the energy it takes to achieve it, shifting the preference to the tasks with lower energy consumption. The learning architecture developed follows a shared encoder-decoder structure equipped with bi-directional skill transfer mechanisms that can learn multiple tasks with dynamic task engagement. The developed framework is evaluated on a robotic manipulation scenario where the robot is tasked with learning the effects of its actions in different task environments. The experimental results demonstrate that LP-based task arbitration not only improves overall learning performance and convergence speed compared to baseline strategies like random interleaving, single-task learning, and blocked training, but also facilitates beneficial knowledge transfer across tasks. The results indicate that it is not only the training time allocated for the tasks that affect the learning performance, but also the task scheduling is critical, which is autonomously generated by our model. Moreover, the inclusion of energy-awareness in the task selection process enables a tunable trade-off between learning accuracy and resource efficiency, which is especially valuable in energy-constrained settings. Our ablation studies further validate the complementary roles of the attention mechanism and task flag bits in enhancing multi-task learning dynamics. While the model is tested in a controlled simulation environment with a limited number of tasks, the results point to broader implications for continuous and sustainable learning systems. By drawing from principles of intrinsic motivation and neural efficiency, the proposed framework contributes a novel perspective on how task interleaving and energy-awareness can be adopted in artificial agents. Future work may explore extensions to real-world robotic platforms, integration with reinforcement learning settings, or scaling to larger task sets with more diverse dynamics.

3.2 Shared Heterogeneous Memory Memory combines two sources of experience: the engine’s construction and repair traces, and the policy’s rollout outcomes and failure diagnoses. Following the episodic–semantic–procedural organization of language-agent memory [ 30 ] , we retain individual records ( episodic tier ), abstract recurring failure patterns ( semantic tier ), and compile reusable programs for generation and training ( procedural tier ). Episodic tier: construction and rollout evidence. The append-only trace store ℬ \mathcal{B} records each scene program g g , its verifier ν \nu , and summaries of the generation
trace, including violated constraints and verification outcomes.
For deployed environments, it also records the success rate p ^ ​ ( s ) \widehat{p}(s) over N N rollouts and the learning progress LV ⁡ ( s ) \operatorname{LV}(s) obtained from training [ 49 ] .
The vision–language critic 𝒞 \mathcal{C} uses scene and rollout evidence to produce a failure diagnosis ψ = ( δ , p , c , e ) \psi\!=\!(\delta,p,c,e) , where δ ∈ { task , spatial , attribute , execution } \delta\!\in\!\{\textsc{task},\textsc{spatial},\textsc{attribute},\textsc{execution}\} identifies the attributed factor, p p the trajectory phase, c c a natural-language description of the cause, and e e the supporting evidence. These diagnoses are stored alongside the corresponding traces. The additional label execution covers motor-execution failures. Semantic tier: reusable difficulty modes. similarity between diagnosed causes.
Each mode captures a recurring failure condition that can arise across tasks and policy backbones, such as “an occluder adjacent to the target on the approach side”.
We characterize each mode by two quantities, hardness and importance . Hardness is measured by the policy’s success rate p ^ j \widehat{p}_{j} , with lower rates indicating greater difficulty. Importance w j w_{j} is a running score updated from

A mode can remain hard even when training on it yields little learning progress, or become easy after substantial improvement.
Each mode also carries a validation status determined by control batches ( Section 3.3 ), and

The data engine 𝒢 \mathcal{G} adapts in context by retrieving and executing programs between rounds, while the action policy π θ \pi_{\theta} learns through gradient updates and acts from observations.
We therefore compile the same validated mode into two complementary programs: • Generation programs , stored in Ω \Omega , encode how to reproduce and vary the diagnosed scene conditions.
They retain the parent scene program, validated variants along one factor, compilation-check outcomes, and the required relational structure expressed over symbolic object roles. • Training programs , stored in Φ \Phi , specify how to address the policy failure through subgoal decompositions, potentials, and learning tools. The generation compiler ℛ grind \mathcal{R}_{\mathrm{grind}} produces the former, while Text2potential implements the training compiler ℛ hone \mathcal{R}_{\mathrm{hone}} ( Section 3.4 ). During training, these programs evaluate subgoal completion and compute potentials that shape value targets. At deployment, the trained policy predicts actions from observations and the task instruction without executing these programs.

3.3 Memory-Guided Scene Generation At each round, memory guides which difficulty modes to revisit and how to instantiate them in new environments. We allocate the generation budget across difficulty modes using an upper-confidence rule based on their hardness and observed learning progress. An ε \varepsilon -fraction of the budget is reserved for novel environments, while a separate replay fraction revisits previously encountered modes to detect performance regressions.
A validated generation program is added to the pool Ω \Omega when the policy’s success rate on its variants falls within the designated success band and is removed when success rate is outside that band. For each selected mode, the engine retrieves a generation program specifying the scene conditions to reproduce and the factor to vary.
Generation programs express scene conditions in terms of symbolic object roles, allowing the engine to reuse them across task families by assigning those roles to objects in a new scene (Appendix A ). For each selected candidate difficulty mode linked to a scene factor, the engine generates a targeted batch that varies the identified factor and a control batch that varies a different factor. After verification checks, we evaluate the current policy on both batches.
If the targeted variants yield a lower policy success rate than the control variants, the proposed difficulty mode is compiled into reusable generation and training programs.
The policy learns from its rollouts using the success predicate ν \nu and the potential-based feedback supplied by Text2potential ( Section 3.4 ). A scripted planner also attempts each valid variant, and trajectories that satisfy ν \nu are retained as demonstrations 𝒟 t \mathcal{D}_{t} , providing additional imitation supervision when available.

Appendix D Limitations CoDA relies on foundation models for scene generation,
failure diagnosis, and potential compilation.
Errors in these models’ understanding of objects, physical
interactions, or task requirements can affect the resulting
scenes and training signals.
Physical validity checks and control experiments
help detect such errors, but their coverage depends on the
checks and interventions used.
Results may also vary with changes to the underlying
models, making model versions and configurations important
for reproducibility.
The framework requires additional simulation and model
inference to generate environments, evaluate policy
rollouts, and validate diagnoses.
These costs constrain the number of rounds and task families
that can be explored under a fixed budget.
Our evaluation also focuses on simulated manipulation.
Transfer to physical robots remains to be established,
particularly for tasks sensitive to differences in contact
dynamics, sensing, and actuation.
