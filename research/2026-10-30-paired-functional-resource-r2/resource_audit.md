# Public drug-screen resource admission audit (R2)

Date: 2026-10-30. This audit distinguishes ordinary proxy development from eligibility as matched independent functional feedback. File presence or metadata overlap is not proof of a shared experiment. Large and sealed response payloads were not opened in this audit.

## Summary

No reviewed local resource currently qualifies as a matched transcriptomic-proxy plus independent functional endpoint with verified conditions and biological-replicate identity. PRISM, GDSC, and BeatAML can support endpoint-specific viability or drug-sensitivity analyses. L1000, MIX-seq, and Perturb-seq can support molecular-state proxy work. Cross-resource joins remain predictive associations unless matching conditions and independent function are established.

## Admission rule and unresolved gaps

An eligible paired resource must identify drug, cell/background, physical dose, exposure time, vehicle/control, preparation/plate, independent biological replicate, proxy measurement, and an independent functional endpoint under a shared condition key. Missing fields cannot be borrowed from a different database. Target annotations do not establish cellular engagement or mediation.

The current bridge fails this rule. A future reopening requires verified source/version/license, raw provenance, matched conditions, independently repeated function, and frozen whole-drug/whole-background holdouts. Availability and exposure status must be checked before using a resource as confirmation.

## Audit boundary

This report records metadata and provenance review only; it does not claim new biological effects. It does not read sealed payloads, decode response values from the eLife file, or infer function from transcriptomic states. Detailed source identifiers and hashes remain in the project `data/ASSETS.json` registry and cited local audit records.
