# Public engagement / orthogonal-resource scout (cutoff 2026-10-30)

**Requested model/effort:** `gpt-6.1-sol` / `high` (effective runtime metadata was not exposed to this worker). **Scope:** public, low-cost, downloadable data that can be joined to PRISM/DepMap/GDSC; FLT3/kinase priority. No source code under `src/` or `tools/` was changed and no experiment was run.

## Decision-changing result

`data_unavailable` for a single public table containing **cell line × drug × dose × time × cellular target engagement + CRISPR/GeneEffect + matched orthogonal functional repeat**. The closest practical stack is:

1. **PRISM Repurposing 24Q2** (official Figshare) for replicate-level viability, explicit dose/time, FLT3-annotated compounds and `depmap_id` joins;
2. **DepMap Chronos/GeneEffect** (official Figshare release) for genetic perturbation, kept separate from drug target engagement;
3. a **targeted FLT3 cellular-engagement assay** (public papers/supplement data exist, but only a few AML lines and compounds) to fill the missing mechanistic layer.

Do not treat PRISM `repurposing_target`/`MOA` as measured engagement: they are Drug Repurposing Hub annotations. Do not treat expression as genetic intervention. Do not claim an orthogonal repeat unless the same cell, compound, dose, exposure time and replicate identity are actually present.

## Alignment and missingness notes

- **PRISM ↔ DepMap:** strongest route is `depmap_id` from `Repurposing_Public_24Q2_Cell_Line_Meta_Data.csv`; preserve `ccle_name` only as a secondary alias. PRISM 24Q2 treatment metadata has exact Broad IDs and concentrations.
- **PRISM ↔ GDSC:** names/CCLE aliases require explicit mapping and version checks; do not infer identity from expression similarity. GDSC response is viability-derived and, in the locally inspected Jaaks 2022 combination export, each combination is a fitted single concentration pair rather than a full dose grid. The local data are not a target-engagement resource.
- **Genetic vs pharmacological:** DepMap GeneEffect/Chronos is a CRISPR perturbation readout. PRISM/GDSC target or pathway labels are annotations. Neither is a substitute for direct cellular occupancy/engagement.
- **Matched repeats:** PRISM 24Q2 has three plate replicates and QC (`n.PASS`), but this is repeatability within a pooled viability assay. It is not an orthogonal functional repeat of target engagement. PXD047949 has biological repeats but no matched PRISM dose/time. LT-171-861 has CETSA plus viability/phospho readouts in a few AML lines, but no PRISM/DepMap matrix linkage.

## Access failures and boundaries

- `https://depmap.org/portal/download/api/downloads` and the current data page returned a Cloudflare verification page; I therefore used the official DepMap Figshare release for Chronos/GeneEffect and mark portal dictionary/version inspection as incomplete.
- `https://www.cancerrxgene.org/gdsc1000/GDSC1000_WebResources/Home.html` failed to load from this environment. I did not treat that failure as evidence that GDSC data are unavailable; the report only uses verified local GDSC facts and does not invent a current download URL.
- PRIDE metadata/API were accessible; raw files are public but large, and I did not download the full raw archive.

## Recommendation

For the proposed virtual-cell/drug-discovery work, freeze an analysis-ready **PRISM 24Q2 + DepMap GeneEffect** join first, retain PRISM replicate-level rows and exact `dose`/`screen`/`rep` fields, and label FLT3 target/MOA columns as annotations. Use the public FLT3 CETSA paper only as a **mechanistic assay template/control**, not as external validation. If direct engagement is a decision gate, budget a small targeted cellular FLT3 engagement panel (e.g., MV4-11/MOLM13 plus a DepMap-mapped control line) at the same inhibitor concentrations and a short exposure, with a separate viability/phospho readout; no currently inspected public resource closes that matched cell × drug × dose × time × orthogonal-repeat gap.
