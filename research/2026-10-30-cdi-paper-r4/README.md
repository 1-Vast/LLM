# Paper-informed CDI revision R4

**Status: conditional design hypothesis; data gate remains unavailable.**

The revision narrows the candidate to an intervention-gated same-target drug contrast. The virtual cell predicts functional response across contexts; an Agent selects a matched dose, exposure control, target perturbation/rescue or orthogonal endpoint only when it could distinguish a target-mediated explanation from nuisance explanations at equal cost. Otherwise the system abstains. This is a test design, not a new architecture or demonstrated Agent advantage.

The paper and resource audits do not identify a public row-level dataset containing matched engagement, perturbation, function, exposure and independent preparation. Acquired paper XML, API responses and resource matrices are omitted. See the [episode report](report.md), [candidate v2](candidate_v2.md), [data gate](data_gate.md) and [record](record.md).
