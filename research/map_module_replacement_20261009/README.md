# MAP module replacement experiments

This study tests three distinct uses of MAP knowledge rather than treating a
shared embedding as evidence of biological or decision validity.

| Experiment | Responsibility under test | Comparison | Claim boundary |
|---|---|---|---|
| Residual-transfer kernel | Association used to interpret purchased observations | Exact STATE prior and matched eight-A/five-B budget; empirical covariance, full molecule, knowledge, Morgan and permuted knowledge | Previously exposed, named RNA endpoint; not functional benefit or independent STATE transfer |
| Scarce-history repeats | Feedback with only 4, 8 or 16 historical contexts | Three fixed history seeds per held context, identical observations and nested tuning; seed means grouped within 43 contexts | Sparse downstream labels, unchanged STATE pretraining; not 129 independent biological units per history size |
| Agent source qualification | Retrieval and interpretation of planning evidence | Current lexical retrieval, MAP source-typed retrieval and deterministic qualification with the same external evidence and API budget | Correct interpretation of returned source records, not measured target engagement or LLM biological advantage |
| Hard agent acquisition | Source selection with hidden records, noisy priors and two inspections | Twelve real cases, two difficulty conditions, three presentation orders; 432 actual LLM calls plus deterministic same-tools routing | Isolated prototype prompt and cached source inspections, not the complete production agent or independent biological repeats |
| Molecule-protein alignment | Content in the released shared representation | Genuine projected protein features, molecular-neighbor votes, popularity and shuffled identities | Target-enriched graph-content audit with possible pretraining exposure; not unseen-edge or genome-wide prediction |
| Original relation composition | Ordered MAP fusion with released text, protein and molecule heads | Both prescribed directions, separate canonical name anchors, relation-only, identity permutations and structural controls | Thirty drug identities in the generic primary task; positive known-graph content is not response or decision validity |

Each experiment records its protocol and source/code freeze before scoring.
Inputs remain in their original locations and retain their original hashes.
Results are written once under `outputs/map_module_replacement_20261009`;
canonical execution receipts belong in `log/20261009`. The evidence register,
rather than this entry-point document, owns the scientific conclusions.

The response experiment uses the existing authenticated STATE-ST cache, not an
unverified MAP RNA decoder. Full molecule and knowledge vectors retain their
original dimensions. Protein projection uses released tensors only when their
mapping and compatibility checks pass. Range downloads cannot establish the
SHA-256 of a complete checkpoint that was not downloaded.

No production module is replaced merely because software checks pass. A local
development improvement is a candidate for independent validation. Source
assertions, model predictions, purchased observations and final evaluation
outcomes retain separate authority. The existing agent/world-model execution,
budget and prediction contracts remain the integration boundary.

Verification requires the pinned external assets and ignored original outputs.
It is not an asset-free clean-checkout test. The post-hoc admission gate and
source-derived receipt renderer are research diagnostics; neither silently
repairs the original LLM answers or counts as an agent-reasoning improvement.
