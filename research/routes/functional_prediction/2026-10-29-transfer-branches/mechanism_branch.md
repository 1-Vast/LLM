## v1 深化结论：保留不同的科学对象，本轮无新算法推荐

**最值得保留的对象是“一个可审计化学编辑对应的、两种细胞背景之间的功能差变化，能否跨母体系列复用”。** 这不是把物理剂量局部关系换一个坐标，也不要求组学。下面给出完整可计算版本、能改变未查询决定的构造和失效边界。但该版本可被普通配对差分、全历史交互回归及上下文回归树逐步复现；本分支没有完成超出这些方法的算法增量。不建议以它冻结一个“新共同学习算法”的经验 H，不执行效果试验。可以保留条件科学 lead，待精确化学近邻与有限菜单资格齐备再决定是否值得研究。

开发者先独立保存上面的 v0，再核 5 件原文。之后 root 提醒区分三种矩形/闭环，并要求不能将任意参照细胞称为正常细胞；这些提醒纳入本段，v0 不回写。本分支不是独立挑战，没有 PASS 或算法优先权认证。

### 1. 先把三个容易混淆的对象分开

1. **端点差的有向闭环。** 若边值定义为 `Δ(i→j)=F(j)−F(i)`，则任意闭环的和恒为 0。这是望远镜消去，与有无生物相互作用无关。同一分子、同一 assay 条件不因 SMILES 编辑路径不同而成为两个不同干预。模型预测的环和非零只说明模型/映射/条件不一致，不能直接称实测细胞非交换性。
2. **两个编辑的四化合物方形。** `F(d_ab)−F(d_a)−F(d_b)+F(d_0)` 是二阶非加性；它一般可以非零，但不是上述有向闭环和，也不是两个顺序给药算子的交换子。将这个量作为主要新运算，会直接落回经典交互对比。它还要求有限菜单内确有四个匹配化合物，本轮不把这种结构当普通必备数据，更不提出合成新分子。
3. **一个编辑 × 两种细胞背景。** 这是本 lead 的最低比较单元：同一对现有化合物 `d→d′`，在两个细胞、同一物理剂量/时长/功能格式下的四个响应。它不需要两个化学编辑的四化合物方形。向另一个母体传播仍需要同一编辑在另一对已有化合物上出现；两个不相连的 matched pairs 和一个双编辑化学方形是不同支持。

这里只研究第三种。细胞 `u,v` 是**功能背景对照**；若没有核实正常细胞及合理匹配，不能称肿瘤—正常选择性、治疗窗或临床安全性。若未来要研究这些更强目标，正常参照及其培养可比性属于新增数据条件。

### 2. 输入 → 运算 → 反馈 → 未查询决定

**可用输入。** 一个事先固定的现有化合物菜单、化合物身份/SMILES、cell、数值物理 dose、time、protocol/endpoint、已付费功能读数及观测身份。固定一个共同物理剂量 `x` 和一套 assay，令 `f_c(d,x)` 为该 assay 的平均 inhibition-like 功能响应；不推断靶点、摄取、细胞数或耐药机制。将剂量固定是为避免本轮退回曲线注册，不意味着不同药相同剂量具有相同暴露或作用强度。

化学编辑 `τ` 必须由**结构映射**定义，例如固定切点/连接环境上的片段替换；它不是相近 Tanimoto 分数、药名相似或同靶点。盐型、立体化学、连接位置及映射歧义须在读响应前处理。当前没有运行 MMP 提取，也没有认证本地菜单具备这些边。

**关系对象。** 在两个实际筛过的背景间定义

`S(d)=f_u(d,x)−f_v(d,x)`，

`K(s,τ)=S(d_sτ)−S(d_s)`

`=[f_u(d_sτ,x)−f_u(d_s,x)]−[f_v(d_sτ,x)−f_v(d_s,x)]`。

`s` 标记母体化学上下文，`d_sτ` 必须是菜单内已有分子。假说不是“化学编辑天然可组合”，而是：对某个明确的 `τ` 及其事先可观测的适用范围，`K(s,τ)` 含有可跨母体复用的分量。模型的对象由孤立 cell×drug 数值变为 **cell-background-pair × chemical-edit 的功能增量及其适用范围**。

**最小计算版本。** 对每个已测 matched pair 算上式四项对比；在编辑 `τ` 的范围分组 `g(s)` 内估计共享增量 `θ_{τ,g}`。若使用均方目标，固定分组后就是带已知观测权重的平均/回归。若要允许反例拆分范围，限定一个在读响应前给定的结构特征字典，对每个可行二分比较“全历史残差平方和 + 分组复杂度惩罚”，接受有支持的拆分。未查询子药物预测为

`S_hat(d_sτ)=S_hat(d_s)+θ_hat_{τ,g(s)}`。

父药尚未测时，其预测不确定性仍在，不能当作免费的精确锚点；共享对照造成的协方差也不能丢掉。用多个路径恢复同一分子时必须由同一个节点响应或一致约束合并，不能把路径数当独立证据。上述拆分准则是普通回归树操作，不是本轮发明。

**Agent 的动作和反馈。** Agent 的合法动作是有限菜单内真实可测的缺失读数，既包含有编辑关系的候选，也包含直接测最终目标。若母体在两细胞已测，取得子药物的 `S` 通常仍需两个新 cell×drug 读数；若四角均未测，不能只收一次查询成本。控制、重复、开板及失败孔按实际工作流计费。可以先测本来就需要筛的候选，从它的反馈学习其他编辑实例；这避免把专用探针免费化，但不是新的选点原则。

真实反馈改变 `θ`，或使一个编辑的共享范围拆为两个结构上下文，随后改变**未查询的同编辑子药物**的 `S` 及推荐。动作按这些推荐变化的预期价值与成本选择，若采用通常的期望价值准则，它就是普通目标实验设计/VOI。Agent 无须 LLM 才能执行；将两个模块称为 Agent 和虚拟细胞不增加运算。

**输出与使用者。** 药筛团队在现有 analog 菜单内得到对指定两细胞功能差的候选排序，并知道哪一类编辑增量被数据支持、在哪些母体上出现例外。潜在用途是以普通功能数据研究背景特异的结构—功能规则和优先复测对象。是否节省孔、能否跨系列/实验复用、是否有生物学价值均未验证。

### 3. 解析构造证明“能改变决定”，也证明它不自带新算法或成本优势

以下为无噪声思想构造，不是数据、模拟结果或预注册。固定目标为从 `Bτ` 与已知对照候选 `C` 中选择 `S` 较大的一个。已知母体 `S(A)=0.10`、`S(B)=0.15`、`S(C)=0.30`。两个等概率功能世界只在编辑共享增量上不同：`θ=+0.30` 或 `θ=−0.10`。

| 功能量 | 世界 + | 世界 − |
|---|---:|---:|
| 查询候选 `S(Aτ)` | 0.40 | 0.00 |
| 尚未查询的 `S(Bτ)` | 0.45 | 0.05 |
| 替代候选 `S(C)` | 0.30 | 0.30 |
| 观察 `Aτ` 后的最优决定 | 选 `Bτ` | 选 `C` |

这些差值可以由合法的 [0,1] 响应实现，例如所有所列参照背景响应为 0.20，另一个背景取 0.20 加上表中 `S`。这只是证明构造可行，不假设现实参照背景对化学编辑不变。

未查询时 `E[S(Bτ)]=0.25`，所以选 `C` 的价值为 0.30；辨别世界后的期望价值为 `(0.45+0.30)/2=0.375`，扣成本前增加 0.075。它与旧 A.v1 的固定 B/C 同比例变化例不同：这里两世界确实改变最优候选，因此不是“参数可识别但固定 top-k 的 VOI 恒为 0”的同一个例子。

然而，**普通共享编辑回归会得到完全相同的推断和决定**。直接测 `Bτ` 在这两个世界也能辨别并服务目标；同噪声/同成本时没有理由偏好 `Aτ`。只有真实成本、噪声或多个后续目标的分摊出现差别时，才可能有选择探针的价值；本轮未证明这些条件成立。构造也不证明化学编辑在现实跨母体共享。

### 4. 与最简单公平替代逐运算对照：当前缺口具体在哪里

令 `z=1` 表示子药物、`z=0` 表示母体，`I_u` 表示细胞 u。对每个母体系列 s，普通响应模型

`f(c,s,z)=a_s+b_s I_u+q_s z+θ_{τ,g(s)} I_u z`

中的交互系数恰好就是 `K(s,τ)`；`q_s` 可吸收两背景共同的化学变化。若增加母体特异随机项、药物噪声或结构上下文交互，仍是普通混合效应/交互回归。一个反例触发的结构特征二分就是回归树/分段模型。所有历史、图边、结构描述、允许动作、噪声信息和总成本均给这个对手。

| 候选操作 | 最简单替代的相同操作 | 本轮尚未多出什么 |
|---|---|---|
| 从 SMILES 得到编辑边 | 审计 MMP 映射/特征构造 | 便宜新输入不是新算法 |
| 四角对比去掉母体/背景主效应 | 上式 cell×edit 交互对比 | 统计信息没有增加 |
| 反馈更新可复用增量 | 全历史交互/混合效应重拟合 | 不需要专门“模型编辑”模块 |
| 根据结构反例拆分适用范围 | 预定结构特征上的回归树或混合模型 | OPINE 也已有反例与上下文细分的宽泛运算 |
| 传播到未测同编辑实例 | 相同回归设计矩阵上的预测 | 不构成额外识别或新泛化定理 |
| 选择能改变最终推荐的读数 | 同菜单同预算 VOI/目标实验设计 | 标准获取目标的重述 |

这不是“所有算法可写成 Bayes，所以都不新”的泛化否定，而是对**已经写出的每一个运算**给出可逐步复现的普通实现。没有必要通过效果比赛才承认这项等价；若将来有具体新近似、新估计器或新复杂度/能力边界，则应重新按实际运算比较。

**尚缺的承重步骤：** 一次异常 `K(s,τ)` 并不能确定是编辑的全局规律错误、某母体局部例外，还是噪声/条件差。以 `K_s=θ+r_s` 为例，`θ=k,r_A=0` 和 `θ=0,r_A=k` 均解释 A 上同一个观察，却对未测 B 给不同预测。必须用多个母体的支持或可检验结构假设约束分解。已经观测到 A 的残差不是对 B 适用范围的标签。本轮没有提出一种新的、噪声下可辩护的范围修订运算来解决此识别问题；把残差送给 LLM 命名规则也不能补上。标准统计学习可以在有相应数据/假设时研究它，本结论不否定这种研究价值。

因此，若 root 要冻结“新算法”，当前缺件发生在**由反例决定哪条可复用关系应如何改变**这一环，而非缺一个漂亮架构名。若只冻结科学结构问题，可保留“限定编辑/剂量/细胞背景下，跨母体的功能差增量是否可预测”；它仍需化学近邻与数据资格，不能伪装成已完成算法创新。

### 7. Lead 2 收口：标准选基步骤已能复现，不能夸大 P5 的覆盖

在无噪声、当前 `r×r` 基块 `W=F[I,J]` 可逆的理想情形，功能基表示给出

`F_hat(c,d)=F[c,J] W^(-1) F[I,d]`。

观察一个新交点 `(c,d)` 后，残差为 `ρ=F(c,d)−F[c,J]W^(-1)F[I,d]`。把 c 行、d 列加入基块后，Schur 补给出 `det(W_new)=det(W)ρ`。因此非零残差可迫使增加秩方向；这就是普通消元/CUR/自适应交叉近似的基础运算。噪声下不能将非零残差直接解释为新功能维度，缺失的整行/整列也不是免费的。

这一具体化不需要再造“反馈扩展虚拟细胞本体”术语。P5 是相邻的主动矩阵预算先例，**其矩阵内均匀采样不精确覆盖上述逐交点选基**；本轮停止新算法主张的依据是上述明确的标准线性代数对应和未提出额外步骤，而非错误宣称 P5 已做过所有细节。没有为此另开效果实验或改变旧固定面板阴性。
