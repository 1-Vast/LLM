# C2 v1.1: prefit computational clarification

Read with protocol.md and review/protocol_initial.md. The independent initial assessment preceded this response, all code review and fitting. Candidate, input doses, endpoint, source groups, panel, primary loss and thresholds are unchanged. This amendment specifies computations, not a post-score scientific revision. No model has been run.

1. Each model receives one hyperparameter configuration per outer background, selected globally across all its drugs/query positions by the mean inner-background macro pair-choice regret. All inner fits recompute source statistics from their four fit backgrounds. Ties use configuration order in protocol.md; exact strongest-rival loss ties use panel order. Wrong-shape reuses candidate lambda and receives no independent selection.
2. Define global fit variance as mean[(y_c,d,j-mean_fit_background y_d,j)^2] over every fit background, drug and physical dose, floored at.01; this is population/column centering, not centering by a grand mean. Smooth-GP amplitude uses population variance across fit backgrounds, averaged over that drug's doses, floored at.01. Sample covariance itself divides by n_fit-1 as usual; its observation-noise diagonal is tau*global_fit_variance.
3. For anchored ridge, center A,D within current fit backgrounds and divide by their population standard deviations, each floored at.1. Include an unpenalized intercept, equivalently center r and add its fit mean after the penalized two-feature solve. Constant features thus contribute zero centered variation without a divide-by-zero failure.
4. The source Hill initial vector is(log(max(.1,-min(y))),0,median(logdose)), componentwise clipped strictly inside the specified bounds by1e-8. If a source least_squares result has success=False (including max_nfev termination), use that predetermined initial vector as its fallback and include it in the prior with a failure flag. Do not omit a source. A failed target MAP uses its clipped source-prior mean. Retain every optimizer status/count; a finite successful optimum at a boundary is success. Ordinary solver failure outside these specified optimizer statuses remains an incomplete panel.
5. The tree's source-mean feature for each training row excludes that row's background; at a query it averages all current fit backgrounds. The complete fixed anchor vector is allowed for every background. Training tree rows are the six declared query positions of each fit background/compound. No source mean from an outer-source pool may enter an inner fit.
6. The conditional bootstrap draws np.random.default_rng(1031).integers(0,6,size=(2000,6)) and averages paired background improvements in that index array; use NumPy's default linear percentile interpolation at2.5/97.5. It does not resample drug pairs or imply independent cultures.
7. All14 normalized log-dose grids agree within floating-point precision; wrong-drug shape is a one-place rotation of sorted drug-specific q vectors within that shared grid. Physical-dose intersections for evaluation remain exact numeric matches, never matching normalized indices across differently scaled drugs. Predictions and truth must retain sufficient float precision for deterministic comparisons.

Implementation will use the fixed method labels source_mean, linear, additive_shape, candidate, pooled_shape, full_anchored_ridge, joint_covariance, smooth_gp, hill_map, profile_neighbor, profile_tree, wrong_shape. The original protocol remains preserved. Independent code/amendment checking is required before fitting.
