## Finding that changes the pending decision

Ordinary longitudinal **live-cell counts already support a target-native attempt to distinguish division from death**, without an additional dead-cell channel. BESTDR does this using conditional transition variance as well as the mean, under explicit stochastic population assumptions. Thus neither separate birth/death inference, hierarchical sharing across cell lines, nor reinterpreting variance as biological information can be claimed as a new contribution. The source also makes a concrete unresolved boundary visible: observation noise can inflate the same inferred rates because it is not fully distinguishable from biological process variability. A useful next-measurement principle would have to change what can be decided at that boundary, rather than just fit the existing BESTDR model or add generic uncertainty acquisition.

The practical setting is a screening group with existing longitudinal count imaging that must prioritize compounds/doses across cell backgrounds. The documented need is that normalized endpoint viability depends on assay stopping time and combines distinct changes in division and death. A usable output could be a justified compound/dose decision or an explicit ambiguity that specifies which ordinary additional count/time/repeat resolves it. This is a proposed contribution path, not a demonstrated benefit. No new modality is universally required, and time-lapse imaging is not assumed free or universally available.

Version equivalence to the formal Appendix is unverified.

In these two pinned files, previous count is supplied data, with `mu = count_prev * exp((b-d)*dt)` and process variance `count_prev*(b+d)/(b-d)*(exp(2*(b-d)*dt)-exp((b-d)*dt))`. The vector likelihood is independent Normal terms conditional on supplied previous counts, with standard deviation `sqrt(process_variance + (obs_err*mu)^2)` and one positive `obs_err` parameter; the logistic model substitutes dose-specific birth/death rates. No latent previous true count or explicit cross-time measurement covariance appears in **these two files**. This supports a focused question about serial observation error in this code version; it neither certifies a defect in the formal2025/2026 method nor proves that repairing it would change a drug decision.

## Exact restart/stop boundary

Reopen the older functional-timecourse line only around the new constructive observation that transition variance can carry a kinetic distinction using a common live-only readout. Preserve BESTDR as a strong target-native baseline. A genuine contribution needs an exact operation and a prediction that separates it from (i) a full-history BESTDR-style hierarchical refit, (ii) ordinary dose/time uncertainty sampling, and (iii) a simpler net-growth decision that already suffices. It must show why the proposed additional ordinary observation changes an actual compound/dose decision under the same information and paid-observation budget.

Stop or abstain if the distinction is driven only by measurement noise/model restrictions, does not change a selection decision, depends on unverified independent cultures, or relies on the duplicated advertised file objects as independent evidence. An unresolved but valuable question is whether uncertainty about process-versus-observation variation can itself be resolved by the permitted existing count/time/repeat menu; this pass has **not** supplied an identification theorem or a new acquisition algorithm. No biological winner is selected.
