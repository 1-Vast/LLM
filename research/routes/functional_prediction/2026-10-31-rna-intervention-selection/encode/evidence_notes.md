## KATMAP: close functional prior, original methods inspected (P)

DOI `10.1038/s41587-025-02881-9`; Michael P. McGurk, David C. McWatters and Christopher B. Burge; Nature Biotechnology; Europe PMC PMID41188645 dates first publication 2025-11-04. Publisher original article authenticated from the DOI-specific official Nature path, with three recorded redirects and final full article body, saved as `katmap_publisher.html.hop3`. Relevant main-text/method passages were inspected, not all supplements or code: **P**, not F. Derived text `katmap_reading_text.txt` is a reading aid, not a replacement for original bytes.

Original Methods, **Selecting the knockdown experiments**, **The structure of the KATMAP regression model**, **Defining the splicing changes**, **Defining the training set**, **Scoring motifs with a binding model**, **Scoring the sequences around exons**, **Defining the binding function**, **Predicting changes in regulation from changes in binding**: models use ENCODE hg19 rMATS, sequence specificity from RBNS/RBPamp PSAMs or RNAcompete/CISBP-RNA PWMs. Endpoint is exon upregulated/unchanged/downregulated inclusion after KD, with ashr shrinkage and 94% intervals for labeling. Binding-site affinity/occupancy changes are model assumptions, not paired experimental occupancy measurements. Position-dependent coefficients explain functional splicing changes; optional linear features control expression and pre-KD inclusion. Main analyses use cassette exons, 200 intronic and 60 exonic candidate positions per splice site, grouped into 10-position regions. This is substantially closer than generic binding prediction.

Split evidence, main text immediately preceding **KATMAP robustly infers splicing regulatory activity**: 15 selected knockdowns, 70% of differentially spliced exons train and remaining 30% held out. This is an exon split; gene-family separation and all unchanged-exon split mechanics are not established by that passage. **Evaluating evidence of splice regulatory activity** uses PSIS leave-one-out comparison with a reduced activity-free model. Main text on **inferring perturbations** explicitly applies K562-learned models to HepG2 KD and vice versa; Methods state the other-cell model is always used for the knocked-down factor to avoid circularity. Thus simply proposing cross-cell regulation transfer is not a sufficient prior-art difference. Held-RBP/source independence, supplement split indices and reproducibility of released code are unverified.

Original **Data availability** gives `https://doi.org/10.5281/zenodo.15298341` (pretrained models, inference summaries and target predictions). **Code availability** gives `https://gitlab.com/LaptopBiologist/katmap`. Those repositories/assets were not fetched in this allocation and are not certified executable. Comparison vocabulary in the paper includes MAPP; its method and code were not independently authenticated here. The second query also returns PanExonNet (`10.64898/2026.02.18.706660`), abstract-level (A): sequence and RBP/spliceosome-expression-conditioned context, plus KD RNA-seq training. It is a 2026 preprint and an additional close lead, not a verified fair rival.

## RiNALMo identity and capabilities (P + curated source slice)

DOI `10.1038/s41467-025-60872-5` is **RiNALMo: general-purpose RNA language models can generalize well on structure prediction tasks**, Penić et al., Nature Communications16:5671, first publication 2025-07-01, PMID40593636, PMC12219582. The DOI is not an RBP perturbation-splicing model. Original full XML saved; inspected original Pre-training, Multi-species splice-site prediction, translation-task passages and availability links. Reading level P because the entire relevant supplementary package was not read.

Pretraining: 36 million ncRNA sequences; paper explicitly states no mRNA or UTR pretraining. MLM masks 15% tokens; lengths over 1022 nt are randomly cropped under a 1024-token pretraining limit. This is a training restriction, not a certified architectural maximum. Sizes are 33.5M,148M,650M; repository labels small checkpoint approximately35M and middle150M. Downstream tasks include secondary structure, splice-site detection, ncRNA family classification and mRNA translation readouts. Splice-site method is **binary sequence-level donor/acceptor presence classification on 400nt sequences**, separately fine-tuned donor and acceptor heads, not alternative-splicing consequences of perturbing an RBP.

Article Code availability authenticates `https://github.com/lbcb-sci/RiNALMo`; article weights link `https://zenodo.org/records/15043668`. Saved official README, LICENSE (Apache2.0 text) and pinned source `rinalmo/pretrained.py`. GitHub main commit response is `2c2c5c14a5ae609d8c560a5d9ca32e51e0288955`; source file was fetched at this commit. README and LICENSE were fetched from main immediately before the commit lookup, so exact byte-to-commit equivalence is not independently proved. No weights were downloaded.

README lists base giga/mega/micro, secondary-structure task checkpoints, donor/acceptor checkpoints, MRL checkpoint and ncRNA classification variants. It demonstrates nucleotide representations. The pinned `pretrained.py` maps available model identifiers through `resources/model2gdisk.json`, uses the selected model configuration and loads a state dict; identifiers and all architecture/task-head implementations were not fetched. It can automatically download weights if called, so **it was never imported or executed**. Presence of generic RNA representations or splice-site checkpoints does not authenticate KD response prediction or a CPU-feasible frozen feature pilot. No model recommendation follows.
