## matched fixed_initial10 的识别范围

该对照从相同训练均值、初始 Top10、P0、探针空间和更新器出发，固定探针顺序不使用模型未见细胞响应，消除了原 fixed_global 与 adaptive 在初始目标集合大小上的明显差异。

当查询均有有限反馈时，线性高斯更新的 P 只依赖探针，不依赖测量数值；若名单始终保持 S0，adaptive 与 fixed_initial10 应选择相同序列。因此在这个条件下，比较可以针对反馈导致的目标名单改变提供有用区分。

但固定面板离线设计按“每次都得到读数”缩小设计 P；adaptive 遇缺失则按协议保持实际 P，仅排除已尝试探针。于是即使 S 始终等于 S0，某次缺失后下一探针也可能不同。主差异因此可能包括观察到缺失后调整设计的收益。v2 的“这样能区分名单目标加权与反馈引起的名单改变”应理解为有限条件下的区分，不能作为缺失存在时唯一贡献分解的结论。动作改变和坐标改变的日志不能单独消除此歧义。

对此不提出新对照或改协议要求；结果解释直接限制为冻结策略之间的总策略收益即可。不能从四项通过再跳到“名单变化是收益的唯一原因”。

## 缺失、指标和信息边界

训练资格只用固定 397 行原始有限值，覆盖分母、ddof、均值填补、噪声 mask、近邻矩阵和并列规则已足够具体，可在不看测试结果的条件下实现。共同先验、表征、噪声和训练资格不能使用模型未见细胞的值或缺失模式。预先读 metadata 并作实体去重不等于测试响应泄漏。

测试查询中，已尝试缺失计一次成本且不替换；未选探针缺失 mask 不进入选择器；评分菜单在全部查询完成后只进入评分。按这个接口实现可避免将评分响应或未查询响应用于动作。文件读取实现仍须遵守边界，本检查未认证它。

hit@10 分母固定 10，缺失分别计不命中/命中得到上下界；adaptive 下界减对手上界是保守差值，即使两臂推荐重合亦不会凭缺失制造正收益，只可能更保守。整行缺失保留会降低通过能力，这是已接受的目标队列代价，不能用测试完整性删行补救。

四项配对 bootstrap 的点增益门槛和 CI 正下界分别回答效应幅度与正向不确定性；v2 明确没有宣称总体最小增益的 CI 已超过 5/2 个百分点。全部通过的联合命题不需要靠挑选显著单项成立。细胞 bootstrap 仍只描述该冻结发布和开发队列的跨细胞变化，不能认证独立培养、跨资源或临床泛化。近邻、重拟合等诊断不能替换失败的主比较。

README 确认这是相对 DMSO 的 log2、经 ComBat 和中位合并的发布值。发布预处理早于本次划分，故这里至多是固定处理矩阵的条件预测，不能宣传端到端完全前瞻盲态。没有可从该字典确认的处理时长，也没有本检查认可的独立重复噪声估计。
