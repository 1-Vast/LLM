# 易得数据共同学习：阶段综合

状态截至 2026-10-29。本综合依据本阶段记录、资源与暴露审查、v1/v2 协议及审查、实现审查、冻结文件摘要、实验回执与汇总，DS013 任务、输出、主审和用量，以及独立复核汇总编写。未读取原始功能矩阵、训练模型、查询数值、封存/确认材料或凭据，也没有运行实验；各来源原件保留。**开发重放未达到 H_C2 预设联合支持规则；独立计算复核与原汇总一致，复算一致不证明收益。**

## 科学问题和取得成本

问题是：对旧细胞训练的功能预测模型，给一个模型未见的癌细胞支付 8 次探针反馈，能否更好地从另一固定药物菜单推荐 10 项？反馈同时更新低秩响应模型的细胞坐标，查询策略再依据当前 Top10 改变下一探针。这里的 Agent 是执行查询的软件，未训练 LLM 权重；坐标更新不证明生物因果机制，输出也不是临床用药建议。标准方法承担此任务，不主张算法首创。来源：[protocol_v1.md](protocol_v1.md)、[protocol_v2.md](protocol_v2.md)。

基本重放需要细胞 ID、药物/批次 ID、剂量、筛选来源、响应的行列键及功能响应；组学、遗传或靶点注释不是必要输入。ID 必须经过实体和别名去重，不能把 PRISM 的 broad_id 药物批次直接当独立化合物。剂量和筛选来源必须保留，不能假定所有发布列同剂量。实际协议限制于 HTS、精确 2.5 µM、可解析结构并按规则归组；结构只用于元数据去重，预测与选药不需要结构特征。

本地 PRISM 19Q4 primary 响应文件 41,254,209 B，加两份元数据及字典约 42.49 MB，本机重放无需新下载。单文件 40 MB 是本阶段默认工程预算，不是用户硬约束；超过它不代表数据稀有或难以取得。19Q4 远程直链尚未核通：旧候选返回 404，Figshare 精确搜索无结果。24Q2 官方 API 的文件清单与 CC BY 4.0 已核，官方 CSV 约 72.46 MB；README 确认 Extended Matrix 拼接旧 primary，本项目不打开其响应是旧确认保护约束，并非数据稀缺。公开可得也不证明跨资源普适。GDSC validation 拟合表约 11.77 MB 是较小候选，但其独立性、官方直链及任务适配未由本阶段认证。没有单孔可靠性、实际货币费用、独立重复或现实周转时间的证据。PRISM 值是 DMSO 相对 log2、ComBat 校正、重复中位合并的发布值；19Q4 处理时长仍未知，原方法 EPMC 查询返回 503。资源核查记录见 [cheap_data_evidence.md](cheap_data_evidence.md)。

## 信息保护和协议修正

19Q4 primary 是历史已暴露的内部开发数据，模型未见细胞只是本模型训练未见，不能称为项目未暴露的独立确认。24Q2 响应、CTRP 旧确认终点、secondary 受保护标签及 sealed/confirmation 均不因公开或旧数据暴露而解封。历史 4,528 canonical compounds 与当前 4,686 发布列并非已经逐 ID 对应；直接 SMILES 解析的本轮口径也不同，不能宣称复现旧全集。暴露审查的未发现其他保护合同不等于穷尽历史合同或解除保护。见 [cheap_data_exposure_review.md](cheap_data_exposure_review.md)。

元数据冻结为 HTS 2.5 µM 3,939 列、可解析 1,946 列、1,928 组，568 个细胞分为 397 训练和 171 模型未见开发细胞。训练值资格筛选后回执记录 429 个合格条件，冻结菜单 64 个探针和 128 个评分项；其训练活性富集限定适用范围。查询缺失计一次尝试、不补测，评分菜单在查询后评分，测试缺失模式不用于训练或选择。历史发布级 ComBat 和重复合并发生在本次划分前，因此不能宣称端到端前瞻盲态。

v1 的独立初审指出全菜单固定设计与当前 Top10 自适应目标不同、训练缺失处理存在自由度、8 项查询不等同现实成本。v2 在读功能值前增加同初始 Top10 目标的 fixed_initial10，冻结训练缺失、噪声与近邻规则，并分别报告零查询参考、固定面板一批与自适应最多八轮。H_C2 要求 adaptive 相对 frozen 的最不利 hit@10 差点估计 ≥0.05，且相对 fixed_global、fixed_initial10、random 各 ≥0.02；四项配对细胞 bootstrap 95% CI 下界均须 >0。点阈值不等于总体最小效应的 CI 已超过阈值。独立 v2 检查未发现阻断总策略比较的协议问题，但遇查询缺失时 fixed_initial10 与 adaptive 的设计协方差处理不同，差异不能唯一归因于反馈改变名单。[independent_review_v1.md](independent_review_v1.md)、[independent_v2_check.md](independent_v2_check.md)。

实现静态审查发现最终预算状态遗漏，记录其在功能读取前修复；该审查没有发现当前路径将未选响应或评分真值反馈选择器的缺陷，但同进程 token oracle 并非安全隔离。源码哈希及 CSV 读取曾触及测试响应字节或字符串，锁定前零读取仅指未解析/使用模型未见数值拟合，不能字面解释为零字节读取。参见 [implementation_review.md](implementation_review.md)。

## 已报告结果、负结果和停止条件

[experiment_receipt.json](experiment_receipt.json) 状态为 `executed_pending_independent_verification`，记录 397 训练行、171 测试行、训练合格 429 条件、CPU 1.531 s、墙钟 1.734 s、峰值工作集 55,259,136 B；这是执行回执，不是独立认证。汇总给出的递推与直接解最大均值差 4.44×10⁻¹⁵。独立作者编写的复核由主任务实际运行：[independent_verification.json](independent_verification.json) 记录 717 项检查全部为真、异常为空、最大数值差 7.1054×10⁻¹⁵，四项主比较及 CI 与 [experiment_summary.json](experiment_summary.json) 一致，联合判定 false。复核 CPU 1.016 s、墙钟 1.125 s、峰值 RSS 74,493,952 B；原实验 CPU 1.531 s、峰值工作集 55,259,136 B。复核支持计算一致性，不证明科学收益。

按冻结协议，训练资格不足或模型未见细胞少于 60 须停止测试；超预算、评分信息回流、实体交叉或重拟合误差 >1e−8 须标 invalid 并停止解释。结果后不得修改阈值、菜单、秩、细胞、查询数或 seed 以求阳性。当前报告不证明真实筛选成本收益、独立培养、跨资源泛化或机制；不将文件、算术复核 PASS 或执行成功当科学收益成立。
