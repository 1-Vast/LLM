# Stage1 output arithmetic contract

Inputs/labels and ranks live in `D:/MAESTRO/data/processed/conditional_interventions_20261030/cgi/stage1/`. No numerical output exists at the time this contract is written. Read stage1_protocol.md with stage1_protocol_v1_1.md; the latter controls null/selection/gene identity.

`labels.npz` has `compounds` (N), sorted canonical `genes` (G), boolean `calls` (N,G), `folds` (N), `groups` (N, scaffold hash), and `rounds` (N). N=231; all compounds belong to the frozen development partition. A call is an author's FDR<.05 negative-score S1E call on the representative screen, in the fixed18415-gene universe. Absence is only a non-call, not verified negative biology. Original extraction has a separate receipt/static review; output arithmetic does not independently derive biological truth.

`ranks.npz` has `methods` in order frequency, nearest5, ridge1, ridge10, ridge100; `aligned_indices` and `aligned_scores` of shape(5,N,20); `null_indices` and `null_scores` of shape(49,5,N,20); `null_assignments` shape(49,N). Indices address the sorted genes vector. Each null mapping is destination-row→source-row, a permutation of the development rows. Its reassigned truth is calls[assignment]; the same mapping applies to every train/validation role. Within each scaffold block/ordered-round stratum, source blocks stay complete. All selected indices must be source-fold eligible and unique per query; scores must be finite and descending, with lexical gene ties. All49 mappings, every method and all231 compounds must be retained.

For either aligned truth or each null truth, source-fold eligible genes have call counts>0 and<=.1*n_training. P@20 for each drug is its number of truth calls at the20 saved indices divided by20. Macro means give method scores. Frequency is baseline; choose the best of four chemistry methods by largest macro mean, breaking ties in the listed order. Compute each null maximum-minus-frequency and the tie-inclusive p=(1+number_null_gain>=aligned_gain)/50. Compute per-query oracle=min(20,total eligible truth calls)/20 and recall=top20 calls/total eligible calls (zero when none), retaining zero-call queries.

For the selected aligned model, paired per-drug gain subtracts frequency. Resample full scaffold groups uniformly with replacement, drawing exactly the number of distinct groups each time, concatenate their constituent compounds and take the mean (2000 draws, default_rng seed20261031). Report percentile[2.5,97.5] with NumPy default linear quantile interpolation. This is conditional selected-development uncertainty.

`summary.json` retains methods, per-compound P@20/recall, source eligibility, oracle, aligned best and null maxima. `decision.json` retains the positive-gain/p<=.05 information gate, paired interval and unchanged NO_HELD_OUT_RELEASE status. `run.json` records source/protocol/implementation hashes, settings, complete shapes, runtime and any terminal failure. An independent verifier may read arrays only after authoring/freezing its own code, reproduce arithmetic/completeness and compare current root JSON; it must not refit or infer biology, leakage absence or practical benefit.
