## 最有意义的问题

**给定一族实际可执行的给药时序，现有观测把哪些不同的群体历史合并了；这些被合并的历史对未来功能是否真的等价？如果不等价，最便宜的可执行观测怎样把它们拆开，并使新的群体状态能继续预测后续干预？**

这比“挑哪个最不确定的药物标签”更有研究价值。输出应包括一个具体的观测充分性失败见证，以及可被后续实验推翻的状态补充，而不只是 acquisition 分数。分开两个问题：同一个已知动力学系统的观测投影是否闭合；不同动力学模型是否被现有实验辨别。前者是状态充分性，后者是系统辨识；不能用模型间参数不确定性冒充已经证明的状态不闭合。

该原理有成熟别名。控制/RL 中是可观测性、状态抽象、lumpability/bisimulation 与信息状态；以未来测试概率定义状态则接近 PSR；给历史依赖功能加有限记忆接近 temporal monitor / reward machine。自动机学习中的 distinguishing suffix、反例驱动状态拆分也是结构对应，但本次未读该领域原始算法，不能作为已核方法证据。**本稿的操作完全可以由普通系统辨识、版本空间实验设计和历史状态模型实现；目前没有算法新颖性，也没有 Agent 必要性。**潜在生物研究问题在于：破坏性观测、采集单位与给药时序共同限制了哪些状态充分性检验可执行，以及何种最小证据能支持跨时序功能预测。是否已经有同题工作，本地有限阅读无法裁定。

## 原文改变了什么判断

1. Compositional Behavioral Semantics §4.1 明说，下一观测预测不能反推转移与观测保持；§4.2–4.4 把模型保持、bisimulation 与仅价值相等区分。其附录 F.5 直接构造 S×M 的历史统计增广，F.6 讨论 PSR 和有记忆控制器。这使“反馈后改变状态表示”本身不能成为新机制宣称。
2. DisKO §3.1–3.2 的对象是共享自主动力学下、无个体配对的分布快照，其分布演化须形成确定半群。G.3 Proposition G.2 给出观测分布闭合的充要条件：当前投影分布相同必须推出所有未来投影分布相同。其不可消除误差下界在精确人口分布下仍成立，并明确说额外测量或时间上下文可补缺失速度。因而“用不可辨识性找缺失观测”已在最近原文中出现；不能只换药物背景就称新原理。该文的自主半群条件不能直接视为药物切换下的控制模型保证。

4. Learning Individual Dynamics §3 的静态 context 可辨识动力学群组、共享组内动力学等是显式假设；§9 承认缺失决定动力学的 context 会破坏个体可辨识性。可用这些假设作普通替代，但不能把跨培养物匹配自动当成同单位纵向证据。其空间坐标重参数化歧义也不等于功能决策歧义：坐标不同但所有可执行功能预测相同，并无决策损失。

## 小建设性过程：从测量计划到历史状态

以下全部为解析构造，没有拟合、模拟或真实细胞结果。

设单个单位有二值、可读的功能门控状态 X_t∈{0,1}，初始均匀。候选动力学为对称一阶 Markov 链：P(X_(t+1)=X_t)=p，p 可为 0.9 或 0.1。对于任意整数时点，两模型的分子/形态快照均为 Bernoulli(1/2)；无限多这种独立快照也不能辨别 p。

规定一个**合成的、独立给定且不从快照推断的功能规律**：长疗程 L_n 只有在同一单位连续 n 个检查点均为 1 时才杀死该单位。群体杀伤比例为

`K(L_n)=P(X_0=…=X_(n−1)=1)=0.5 p^(n−1)`。

另有给药 S 的杀伤比例恒为 0.25。单检查点 L_1 功能也完全相同，均为 0.5；但 L_2 在两模型下分别为 0.45 和 0.05，最优给药分别为 L_2 与 S。这才使丢失的时间耦合具有决策意义。若没有独立的功能规律，配对图像本身不能推出杀伤，也不能声称药物收益。

一个可执行的建设性步骤是：

1. 保留两种与当前证据相容、但给药排序不同的模型；列出观测协议 e=(测量指标、时点、单位、是否保留配对、干预、成本)。先核它们能否在 e 的**实际观测分布**上不同，而不是只看隐变量图不同。
2. 同单位相邻时点非破坏性跟踪可测 `q=P(X_(t+1)=X_t)=p`。未配对的两张快照只能给两边际；同培养物也不等于同单位配对。选择此观测是因两解释对 q 有相反预测，而不是因某个终点标签方差大。
3. 获得证据后，可辨别 p；为了规划 L_n 的路径依赖功能，跟踪连续活性长度 C_t，按 `C_(t+1)=C_t+1`（X_(t+1)=1）或重置为 0（X_(t+1)=0）更新。群体规划对象成为 `(X_t,C_t)` 的分布，而不只是 X_t 的边际。未知实际系统也可以用测试概率表示替代显式 C；有限维闭合仍需验证。
4. 用未参与该步骤的更长时长或新切换序列检验功能预测；若偏离，则当前一阶 Markov/历史计数/功能映射至少一项失败，不能只继续缩窄参数置信区间。若任一可行 e 都使两模型同分布，应返回“该观测菜单不能消歧”，而不是强行推荐一个采样点。

必须坦白：在这个小例中，直接购买 L_2 功能端点也可通过 `p=2K(L_2)` 精确辨别模型；因此该构造**没有证明配对观测更省样本、更有效或不可替代**。它只展示了观测协议能增加原来没有的联合信息，并在功能规律成立时给出建设性的跨时长预测。普通 Markov 系统辨识加 reward machine 就能全部完成。

## 真正可失败的区分预测

冻结观测、功能规则和模型族后，两时点配对若给 q≈0.9，预测未见 L_3 杀伤≈0.405；若 q≈0.1，预测≈0.005。两个世界所有单时点快照及 L_1 功能仍相同；把同单位配对索引随机打散会使可见 q 趋近 0.5，但不会改变边际。只有保留配对的观测能在这个信息合同内支持上述两种预测。这里只是设计推导，尚未执行。

这一区分针对“联合信息确实改变了可识别能力”，**不区分 Agent 与普通充分的历史模型**。公平比较必须把同一配对证据、相同协议菜单、预算及完整重训练机会也给普通 HMM/受控 Markov/PSR 或层级历史模型。若它们同样预测正确，应撤去特殊算法主张。进一步，直接获取 L_2 功能的实验设计是更强的替代，不能刻意禁用以制造优势。

真正的生物失败条件包括：q 不稳定随给药前史改变；同一 q 不再对应相同长时长功能；更长历史仍有条件预测力；报告器与实际功能门控脱钩。应以独立培养物/生物重复评估，不能把同一培养物内大量细胞当独立重复。若只检验快照拟合而没有独立功能续段，此预测尚未被检验。

## 不能解决的反例

即使全部相邻两时点配对分布都已知道，仍不保证路径功能可识别。比较：A 为独立公平二值序列；B 为周期 `0011` 的随机相位过程。两者各时点均为 Bernoulli(1/2)，相邻二元组 00、01、10、11 都各占 1/4，所以 q 都是 0.5。但 `P(111)` 在 A 为 1/8，在 B 为 0。

因此上述只购买相邻配对、拟合一阶链的过程会对 B 错误预测 L_3。它无法在这一固定观测类别内消歧；需三时点配对、不同滞后或有信息的其他测量。若追踪本身不可行、允许观测仅是独立破坏性边际，而功能依赖这种三元路径，则此流程不能恢复缺失联合结构。一个有用输出是明确这一不可行性，而不是让生成模型挑一条看似合理的轨迹。有限观察永远不能无条件证成任意长历史下的充分性；必须限制记忆阶数、协议范围或只给部分识别结论。

另一个常被漏掉的边界：若功能只依赖当前状态、观测人口分布在给药下确实 Markov 且动作效应已知，个体时间配对可以完全无助于目标群体决策。没有路径依赖的真实功能需求，不值得为个体轨迹而追踪。

## 生物错配与最强普通替代

- 测量不一定被动：报告器、成像光毒性、染色和抽样可能改变动力学。必须把观测协议的干预效应也列入实验合同。
- 个体可能分裂/死亡，跟踪单位随时间变化；幸存者配对会丢死亡单位，不能拿幸存者 q 当全群体转移率。谱系树、细胞状态与培养物环境是不同层级对象。
- 药物剂量、停药、换药和暴露史可能改变转移规律；自主分布半群或固定 p 的规律不能免费外推。培养物共享环境造成相互依赖，单细胞独立链不自动适用。
- 若目标是条件级平均功能、协议本身已标记历史，重复培养物的分段干预加破坏性测量可能足够；“破坏性”本身不推出必须追踪同一细胞。
- **最强替代 1：**直接对决策相关的长疗程/切换协议做功能实验，采用决策导向 Bayesian 实验设计并完整重训练。若目标动作集合有限，可能最直接。
- **最强替代 2：**给普通受控 HMM、非线性历史模型、PSR、层级模型同样观测菜单；它们可以同时做系统辨识、状态增广和规划，无需 LLM Agent。
- **最强替代 3：**在静态 context 能测到且群组稳定时，按 context 分层的横断面模型；或显式采用有限记忆/质量输运/动力学先验，承认尚未被证实的假设。
- **最强替代 4：**对未消歧模型做鲁棒/部分识别决策；如果动作排序已经一致，停止买消歧观测。机制辨识不应压过决策是否已经确定。
