# Blind source-principle handoff — 2026-10-30

## Decision and evidence status

The most useful newly inspected principle is **validate a recurring predictive failure condition against control variants before reusing it to acquire observations and change training** (CoDA). This opens a static functional-screen question: are virtual-cell errors organized into reusable intervention-conditional failure modes that can be corrected across unmeasured drug/background pairs, rather than merely filled in locally? This is a proposed mapping, not demonstrated benefit or a novelty finding. It needs real crossed measurements and must beat ordinary error-slice active learning. Two additional leads clarify a possible decision objective and the minimum ordinary scheduling rival. No candidate exchange took place before saving `initial_notes.md` or this map.

Initial premise quoted from `initial_notes.md`: “A donor matters only if it changes an identifiable scientific question/capability, acquisition or stopping decision under this observation process. Ordinary matrix completion, Bayesian optimal design, contextual bandits and task-specific active learning are strong rivals.” The sources change the proposed future comparisons/claim boundaries, not an executed biological decision. No baseline score, biological experiment or training run has been produced.

### Lead 1 — Control-validated reusable failure modes (conditional pursue)

**Source:** Yu et al., *CoDA: Co-Evolution of Data Engines and Action Policies*, arXiv2610.22362v1, first public2026-10-15, inspected original HTML `q11.body`. Reading: Methods3.2–3.4 and AppendixD, selected3.5; neither complete proof nor reproduction. Method passages are in `inspected_passages.md`; section IDs survive in HTML.

**Operative original passages:** #S3.SS2 distinguishes hardness from learnability: “A mode can remain hard even when training on it yields little learning progress”; “only validated modes are compiled into procedural memory.” #S3.SS3 creates “a targeted batch that varies the identified factor and a control batch that varies a different factor”; if targeted variants lower success compared with controls the mode is compiled into programs for subsequent generation and training. It explicitly reserves novel-environment and replay budget. #A4 states control coverage depends on the checks/interventions used, incurs additional simulation/model inference, and physical-robot transfer remains unestablished.

**Input → operative rule → scientific output:** Revealed functional observations, pre-feedback predictions, dose/background/drug metadata and remaining obtainable screen entries → propose a *predictive* error condition (for example, failure to transfer a dose-response shape between backgrounds); spend matched measurements on the condition and comparator variants; retain the condition only when a held-out prediction-error contrast replicates; use retained condition both to select subsequent real queries and to revise response training, while measuring held-out learnability → determine whether a recurring failure condition predicts where the virtual cell will fail and where new observations yield transferable correction, including on drugs/backgrounds excluded from discovering the condition. This is about a model's validity domain. It does not identify the biological cause of resistance.

**Variable map / biological restriction:** Simulator scene factors → measured drug/dose/background axes; rollout failure → prediction or predeclared decision error; generation program → query template over *available* functional measurements; before/after policy progress → held-out change in functional predictive/decision capability. Unavailable contexts cannot be generated by an LLM. No trajectories, mechanisms, editing cells or simultaneous drug action are implied. A screen's existing crossed entries are observational comparators, not automatically independent or randomized cultures. A completely sparse matrix may offer no valid control variants, in which case this transfer is blocked.

**Discriminating observation:** A learned error condition must recur in a predeclared unseen drug/background split and direct feedback that corrects other unqueried entries satisfying that condition. Compare the same predictor, labels, warm start, query count/cost, model updates and diagnosis/control overhead against: (a) uncertainty/diversity acquisition, (b) clustering previous residuals and sampling the largest persistent-error slice, (c) a simple learning-progress scheduler, (d) the same discovered conditions held fixed after the first round. Conditions that fail to recur, or whose whole benefit is explained by ordinary residual slicing, defeat the stronger framework claim. Keep control/validation labels in the total query bill; do not supply extra hidden error labels to the agent.

**Exact aliases and overlap:** Source-native: failure diagnosis, targeted/control batches, difficulty modes, memory-guided scene generation. Known ordinary aliases: slice discovery, failure-mode discovery, hard-example mining, error-driven active learning, adaptive curriculum, competence progress, bandit allocation. Target library contains *A Bayesian active learning platform for scalable combination drug screens* (BATCHIE;10.1038/s41467-024-55287-7), *SHIFT-DRP: Dynamic Multi-Scale Active Learning for Drug Response Prediction* (10.1021/acs.jcim.5c02453), and *Data-driven learning of structure augments quantitative prediction of biological responses* (10.1371/journal.pcbi.1012185). These are metadata/prior pointers, not methods newly read by this scout. Target investigator must check whether controlled failure-mode validation plus reusable acquisition/training update is already central there. No novelty recommendation until that check. The source's potential shaping is NOT transferred: it requires sequential states and is unnecessary for static screening.

**What changes:** Future scientific object changes from whole-matrix accuracy to transferable validity/failure conditions; acquisition includes a charged falsification/control stage before adaptive reuse. This is a changed proposed test, not proof of new scientific contribution. It is not enough to add memory or an LLM critic.

### Lead 2 — Decision proxy expressivity before richer virtual-cell outputs (narrow gate)

**Source:** Schutte, Veviurko, Postek, Yorke-Smith, *Sufficient Decision Proxies for Decision-Focused Learning*, arXiv2505.03953v3 (first public2025-05-06; v3 updated2026-09-17), IJCAI2026 DOI10.24963/ijcai.2026/260. Original HTML `q08.body`; inspected Sec2,3,4.1–4.3,6,7, selected assumptions; no proof audit. Crossref metadata and arXiv metadata agree on identity. IJCAI website requests yielded301 and were not followed; method reading relies on official arXiv full text.

**Original passages:** #S3 Theorem1 gives sufficiency of the conditional mean when expected objective equals objective evaluated at the mean; linear dependence on uncertain parameters is a common case. #S3 Theorems3–4 discuss the decision proxy's attainable decisions, with surjectivity sufficient and some stochastically optimal decisions unattainable by a single-scenario proxy. #S4.SS1 predicts a few representative scenarios directly rather than sampling from a full predicted distribution. #S4.SS2 permits a quadratic projection proxy predicting directly in decision space; it explicitly says it need not estimate the true uncertain parameters. This is consequential for distinguishing a decision readout from a scientific virtual-cell representation.

**Input → rule → output:** Common-background multi-drug functional measurements and a declared nonlinear utility over the measured background distribution → first prove whether one deterministic response scenario can attain the desired population-optimal decision; only if it cannot, learn decision-sufficient scenarios with the same labels, and acquire feedback according to remaining uncertainty in that decision → a follow-up drug panel covering heterogeneous measured background responses, or another explicit risk/coverage decision, without needing a full calibrated cellular outcome distribution. A panel is a set selected for separate follow-up assays; it is not a simultaneously administered drug combination.

**Discriminating observation / simple defeat:** If the task is selecting one drug to maximize mean viability reduction, a mean response predictor suffices and this donor adds no essential capability (Theorem1). For nonlinear coverage/risk, compare full response-distribution estimation and empirical background-scenario optimization against learned scenarios and a direct decision predictor under identical labels. If the direct predictor matches benefit, there is decision-readout improvement without evidence of a richer virtual cell. Counts/cost of acquiring cross-drug joint response information must be charged; samples from different backgrounds cannot be substituted for biological replicates at fixed context. Across-background heterogeneity, experimental noise and epistemic uncertainty are different distributions.

**Aliases/priors:** Predict-then-optimize, decision-focused learning, integrated estimation/optimization, stochastic programming, sample-average approximation, scenario reduction, robust drug-panel/portfolio selection, optimal experimental design. Generic goal-driven design already appears in the target library as arXiv2605.26093 and2602.05340, so “decision-focused agent” alone is not new. Target investigator should check resistant-subpopulation drug-panel and drug-portfolio selection precedents before retaining this as a scientific proposal. q12 broad EPMC search found clinical pharmacometrics/MIDD literature explicitly calling sequential updating and decision-focused uncertainty longstanding; abstract-level warning, not a closest-prior resolution.

**What changes:** A mathematical gate before requesting probabilistic outputs; it may remove complexity. It does not by itself couple the agent's learning with a virtual cell. Keep only if a biologically meaningful nonlinear functional decision is already supported by measurements.

### Lead 3 — Learnability, rather than raw error, as the ordinary acquisition baseline (baseline / park novelty)

**Source:** Say, Ada, Ugur, Asada, Oztop, *Interleaved Multitask Learning with Energy Modulated Learning Progress*, arXiv2504.00707v2 (first public2025-04-01; updated2025-07-26). Original `q10.body`; read Sec3,4.2,6, not full architecture/results/reproduction. Robotics effect-prediction tasks are structurally close to static intervention-conditional predictions.

**Original passage:** #S3 the chosen task controls execution/data collection, then updates both task-specific and shared parameters; goal is an action-effect prediction map. #S4.SS2 regresses recent error against learning step, uses the negative slope as learning progress, clips plateau/regression to zero, and chooses maximal progress with some random exploration. Its cost proxy is accumulated neural output; #S6 acknowledges controlled simulation with limited tasks. Neural activation is NOT assay cost.

**Input → rule → output:** Past query batches and a prediction-error trend on comparable evaluation units → allocate next observations among actual background/drug/dose task groups by measured predictive improvement per charged assay/compute cost, with some exploration → learn whether certain functional tasks are currently learnable with available cheap data while others remain persistently hard. Static screen rounds suffice; learning-step time is not cell-state time.

**Discriminating observation:** Large-error/no-progress groups should stop consuming almost all budget, while moderately wrong/improving groups receive labels. Compare uniform, residual magnitude, uncertainty and a one-line learning-progress bandit with the same labels/updates. A feedback learner that cannot beat this should not claim an added co-evolution principle. Error trends must use comparable units; training residual decline can be mere memorization and selection-induced distribution shift can counterfeit progress. Evaluation/control labels count in budget. The donor's current-task improvement can ignore cross-task transfer, so a scientifically stronger variant would need directly observed improvement in a *different held-out intervention family*; that is a new hypothesis, not established by this source.

**Aliases/overlap:** Intrinsic motivation, learning progress, competence progress, curriculum learning, adaptive task allocation, teacher-student bandits, active multi-task learning. Generic feedback-driven task scheduling is inherited. In pharmacology adaptive experimental design/active drug screening already overlaps broadly. No defensible novelty from field substitution. q12 returns many curriculum-in-drug-discovery abstracts; its first10of725 broad search results cannot establish exact absence/presence of learning-progress functional screening.

**What changes:** Adds an essential cheap rival and a stopping/allocation warning; does not independently justify a new drug-discovery method. It sharpens Lead1's test by separating hardness from correction potential.
