### 执行前必须修清的操作定义

1. **PAV 的“块中心”未定义，足以改变预测。** 原文已规定同 x 先加权聚合、标准相邻违背合并，却没定义合并后用于插值的横坐标。“块内按原样本数加权的 x 均值”“块区间中点”或 sklearn 常见的各原 x 断点处理可产生不同分类。最小补法：写出每块横坐标和纵坐标公式，以及只剩一块时的常数预测；独立实现照同一公式，不凭库默认。非增以 -x 后仍按升序拟合和插值，也应明确。

2. **blind 的完整算法尚缺一行。** “付 q 但忽略其值”不唯一决定输出。最小补法：明确每个目标只以训练全体阳性率作为概率、p >= .5 判 1；若有别的训练内规则，则必须在效果前完整冻结。开发值、开发比例和目标类别支持门不得反过来选 blind。

3. **独立回放需要精确 bootstrap 与边界规则。** seed 不能唯一决定随机序列，2.5% 分位也有多种插值规则。最小补法：冻结 PRNG 名称/版本或可复放抽样索引，以及分位数算法；说明从最终开发 cell 清单均匀有放回抽 n 个 ID，每个被抽 ID 的两标签共同带入，三个差共用索引。固定 5 折若出现空验证折可跳过，空训练折、训练 cell 为零或不够产生合法模型则停止；不得临时改折或改 k。kNN 的 min(k,n) 已写清，无须另加调参。

4. **metadata 菜单仍有一处顺序歧义。** “每 drug 选现存浓度”需指明，是在 project=2 且每 cell/drug 最小 ref 之后的候选元数据上取全局唯一剂量，还是所有 ref 的浓度并集。二者可改变完整支持 cell。最小补法：明确固定顺序，冻结选定 drug/ref/dose 键清单、训练/开发 ID 及 SHA256，再消费响应；保留因 metadata 无支持而未入选的数量即可，不按效应修菜单。记录原浓度单位及到 µM 的换算依据，不能仅由数值接近 0.1 推断单位。

### 科学解释必须收紧的地方

- **H 是这一个受限优势主张的工作门，不是所有功能索引的必要条件。** 更准确的限定是：固定菜单、剂量、双目标任务、六模型族、历史数据和一导出坐标预算下，是否存在训练选定 q 的可复放开发优势。失败可停止这条预设优势线；不能推出功能关系一般无用，或所有可能估计器都不存在该信息。training_precondition_absent 尤其只是本菜单/模型族/OOF 选择规则未找到候选，不是条件信息不存在的证据。
- **建设例只证明有这种结构的可能性。** 它不证明实际 q 携带该结构，不证明 common-factor / 靶点作用机制，亦不保证关系跨培养、批次、剂量或细胞群稳定。“q 确有双目标条件信息才应胜”可作为待检验的预测动机，不应由一次性能差反推真实生物关系或机制。
- **当前 direct 已是有意义的强对手。** 自身目标以已付真实标签覆盖、另一目标用完整连续读数、共享训练内模型族；没有把直接读数先二值化或故意限制为固定面板。它是该族内的强对手，不是所有连续 direct 的理论上界。“完整 continuous”指完整输入值，不能写成无方法限制的最强 direct。
- **训练选择与开发角色原则上可成立。** 同一训练 OOF 同时选模型和三元组使训练最大 m 乐观，但不使冻结后的开发比较自动无效；不用在本回放追加一层外部 CV。必须把 OOF 和 m 标作选择用途，不能当无偏泛化结果。开发 oracle QC 已被诚实声明为逻辑隔离；它不是硬隔离，也不是未见字节确认。历史前 20000 行暴露更使此次保持开发性质。
- **bootstrap 只支持受限的组成稳定性描述。** 固定所选模型/三元组后重抽开发 ID，没有重做训练、模型选择或三元组选择，也未证明 ID 独立同分布。它不是生物总体 CI、确认性显著性、测量噪声区间或训练不确定性区间。三个差的分别下分位门是事前联合通过规则，不是一个同时覆盖区间；不能据此声称在总体中有置信度的最小 .025 优势。
- **truth 是导出标签代理。** direct 自身零错和双测零错来自同一导出标签定义，不证明单孔真实无噪判断。lib1_y / lib2_y 同键严格一致能否成立须由资格实际检查；相同导出坐标在多个行/两列复制不增加独立样本数。不清楚 source-well、培养/板次和时点的关系会阻止独立功能/现实 assay 主张，但在方向、单位、实测来源及重复规则足够明确时，不必单独阻止限定导出回放。
- **历史费用账可使解释诚实，但不能消除不等历史。** 先扫描 11 坐标来选任务/q 的成本属于整个发现流程；固定三元组后 reference 的拟合通常要 q/a/b 三列，direct 要 a/b 两列，blind 也需 a/b 标签而付 q 仅为预算控制。应列实际坐标数（训练 n × 列数）、全菜单扫描成本、部署 1 坐标及离线 oracle 单独成本。若结果阳性，只说明一坐标部署条件下在这些既有历史支持下有条件信息；不证明计入历史成本后总体更省。训练计算上限是可执行资源约束，不等于 assay 历史成本。
