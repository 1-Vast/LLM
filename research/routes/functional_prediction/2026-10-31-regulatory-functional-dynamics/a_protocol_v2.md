## Observation and endpoint

For ordered guide pair a,b in culture r, write L_r(a,b;X/Y)=log2((count_X+1)/(count_Y+1)). For each X/Y form

Q_r(a,b;X/Y)=L_r(a,b;X/Y)-median_n L_r(a,n;X/Y)-median_n L_r(n,b;X/Y)+median_(n,m) L_r(n,m;X/Y),

where n,m range over all13 NTCs. The response is the median of Q(DRUG/UT) across the eight ordered two-guide/orientation constructs for each unordered distinct gene pair. The untreated baseline is the same median of Q(UT/T0). This is a double-versus-single difference of log relative-abundance ratios. Common additive log library-size offsets cancel algebraically; raw pseudocount counts are not sequencing-depth invariant. T0 cancellation occurs in each log ratio before medians, and Q(D/U) need not equal Q(D/T0)-Q(U/T0) after median controls; no fitted quadratic label, global target distribution standardization, growth divisor or trajectory is used. Endpoint pseudocount=1 is fixed. The T0 term cancels from the environmental-vs-UT difference, but T0 remains needed for eligibility and untreated features.

Eligibility uses T0 only, never UT or DRUG depletion: retain an ordered targeting construct if both cultures' T0 count>=30. Each guide must have at least5 of13 T0-eligible guide/NTC constructs in each orientation; NTC/NTC median must have at least25 eligible constructs. Use these same identity masks in both cultures for all ratios. A gene needs both guides retained. A distinct gene pair needs at least4 retained ordered constructs and at least1 in each orientation. Medians use only retained identities. Single-target feature for a gene is the median guide/NTC L minus the NTC/NTC median across both orientations and its guides, separately for UT/T0 and DRUG/UT. The shared controls induce dependencies; pair counts are not culture replicates.

No numerical eligibility or headroom has yet been inspected. Abort fitting if fewer than10,000 eligible pairs or1,000 eligible test pairs. After endpoint creation, report cross-culture Pearson and Spearman, abundance/depletion QC and strong-effect counts. Abort fitting if training-pair cross-culture Spearman<0.20 or fewer than500 training pairs satisfy |y1|>=1, |y2|>=1 and equal sign. This is a fixed detectability gate, not evidence for the candidate. No favorable endpoint/condition replacement is permitted.

## Holdout and information contract

Pair fold is SHA256('MAESTRO-EGI-A1|'+min_gene+'|'+max_gene), first8 hex digits interpreted base16 modulo10:0..6 train,7 validation,8..9 test. An unordered pair stays in the same fold across orientations and cultures. All source identity mappings are fixed before numerical access. No held-pair DRUG double counts may affect training, features, graph, normalizers or hyperparameter selection; evaluators alone use them. DRUG singles/NTCs and all untreated/T0 data are allowed prediction-time measurements.

Run both directions with the same fixed model grid: culture1 anchors/validation/features -> culture2 held pairs, and culture2 -> culture1. A direction's predictors may use only its source culture's untreated map, singles and training-anchor responses. No target-culture post-T0 values enter its directional fitting, graph or tuning. The common T0-only eligibility mask is a declared exception: target T0 can change eligibility and hence the source graph/features. The fixed detectability gate also reads both cultures on training pairs only; it does not tune predictors. The source culture's held test response is used only for replicate-confirmed evaluation after predictions. Cross-culture transfer prevents a same-culture UT denominator from directly serving as a test-label noise shortcut. Two cultures and one batch remain the generalization limit.

Use zero imputation for absent baseline pair features and zero diagonal. The entire source untreated map is available, including held pairs; this is explicitly conditional prediction, not de novo prediction of an unmeasured untreated screen. No external graph, expression matrix or model weight is added.

## Fixed ordinary-model/candidate matrix

All models see the same source information; dimensional or graph transforms are fit using source untreated information only. Scalar features: baseline pair value; baseline and environmental single effects represented by sum, absolute difference and product; plus symmetric sum, absolute difference and product of each gene's8-dimensional untreated-map SVD coordinates. Standardize using training feature means/SDs; constant columns get divisor1.

Rivals: zero change; training mean; unregularized baseline rescaling with intercept (least squares on the baseline pair value only); gene-additive Ridge on incidence features; direct Ridge on scalar/SVD features (alpha1,100,10000); ElasticNet on those features (alpha0.001,0.01,0.1; l1_ratio0.5, max_iter3000); HistGradientBoostingRegressor on those features (max_leaf_nodes7 or15, l2_regularization10, max_iter150, learning_rate0.05); symmetric iterative hard-rank matrix completion on the training-anchor response matrix (rank2,8,16; 30 iterations; observed anchors restored each iteration). Ridge incidence alpha1,100,10000. All hyperparameters select source-validation MSE, ties use the listed order. Matrix completion uses no validation/test values in reconstruction.

Candidate: take the selected direct Ridge, then smooth its training residuals over untreated functional-profile neighborhoods. Center each source baseline profile over partner genes, normalize its Euclidean norm and form positive cosine similarities, excluding self. Retain10 largest positive neighbors per gene, ties gene order; normalize each row to sum1 (no positive neighbors -> zero row). Let W be this fixed directed neighborhood matrix, R the symmetric training-residual matrix and M its0/1 anchor mask. Add (W R W^T)/(W M W^T+lambda) to the direct prediction, with lambda0.1,1,10 selected by source-validation MSE. This is an ordinary neighborhood residual smoother. Negative control: the same candidate with the graph's gene identities permuted using numpy default_rng(20261031), with its own lambda chosen on the same validation. Retain the control regardless of outcome.

## Decision, uncertainty and resource limits

Rank test pairs by descending absolute prediction, ties canonical pair identity. TopK=100. A primary signed hit requires |y_target|>=1 and sign(y_target)=sign(prediction); zero prediction is never a signed hit. The source response does not participate in this decisive event. Primary metric=P@100 of target-culture signed strong effects. Joint confirmation (|y1|>=1, |y2|>=1 and both signs equal prediction) and negative-only discovery are descriptive; report MSE, MAE and correlations secondarily. The strict practical gate requires candidate at least5 additional hits per100 over EVERY ordinary rival in each direction, plus at least5 over the permuted-graph control in each direction, and at least20 hits in each direction. A mean-only/MSE gain cannot pass. This is a prespecified screening threshold, not a statistical-power assertion or biological validation.

Report exact hit identities and cross-culture agreement. With only two biological cultures do not claim a population-level confidence interval or p-value based on treating pairs/cells as independent. Show leave-one-gene-out sensitivity of the frozen rankings descriptively; it is not a culture-level confidence interval. No choice of method after test access, no model expansion after failure.

Before real numerical access: independent source/protocol challenge; root response; frozen runnable code and hashes; independent arithmetic checker and source-access review on synthetic fixtures only; archive original review bytes. ## Exact v2 clarifications and interpretation limits

This is substantive revision1 of a maximum2. T1 is addressed by the target-only primary; joint confirmation remains subject to the source-denominator shortcut and cannot carry the gate. T2 is addressed by the explicit baseline-rescaling rival and a narrower interpretation: even an unchanged per-division interaction can produce a nonzero raw response when treatment/control accumulate different population doublings. This endpoint does not establish GI rewiring, rate change, regulatory causation or death. The test asks only whether untreated topology improves prediction of this fixed differential-abundance measurement beyond ordinary rescaling, regression, nonlinear and completion rivals.

All retained masks, including guide/NTC and NTC/NTC masks, use the identical two-culture T0>=30 rule. Medians are numpy.nanmedian, even-length median=arithmetic mean of central values. All graph/SVD inputs use the same eligible gene universe and eligible pair baseline values; absent values=0, diagonal=0. The full uncentered baseline matrix uses numpy.linalg.svd(full_matrices=False), coordinates=U[:, :8]*sqrt(S[:8]); graph profiles alone are row-centered then divided by Euclidean norm, zero norm -> divisor1e-12. Positive-neighbor ties follow sorted source gene labels. Sparse residual/mask entries and diagonal=0. Graph permutation is simultaneous row/column indexing W[perm,perm] from default_rng(20261031).

Matrix completion starts from observed training responses and zero elsewhere; each of30 iterations takes the rank-k SVD approximation, symmetrizes it, restores observed training entries exactly, and sets diagonal0. There is no singular-value shrinkage, intercept or matrix centering. All selected predictors remain trained on the training subset; no refit on validation. Estimator defaults and exact installed versions are pinned in runtime_environment.json before real access; explicit code seeds are20261031. Convergence warnings are retained without grid expansion or rerun. Nonfinite predictions/exception stop the run and preserve artifacts; any spare needs an actual demonstrated implementation/environment fault.

T3's fixed QC: an ordered construct is floor-limited if target UT<10 or target DRUG<10; a pair is floor-limited when at least half of its T0-eligible constructs are floor-limited. Report each method's target floor-pair count among its frozen Top100. Candidate requires <=20 such pairs per direction for a practical PASS. Without refitting or reranking, recompute readouts at pseudocount0.5 and2; require the same >=5-hit margin over every rival/control and >=20 candidate hits in both sensitivity readouts. Store each Top100 pair's raw ordered-construct support and reference-control coverage. These are fixed readout sensitivity checks within the same matrix, not new model executions. No depletion-based postaccess pair exclusion or endpoint replacement is allowed.

The leave-one-gene-out calculation removes that gene's test pairs from each frozen ranking, refills Top100 and recomputes primary precision; no retraining, graph/SVD rebuild or parameter change. Its min/max candidate-minus-best-rival gain is descriptive only.

About70% of pair outcomes train and10% select parameters, plus a full untreated map and environmental singles. This dense retrospective completion probe does not establish sparse assay efficiency, new genes, new drugs, cell backgrounds, independent-batch replication or method novelty. One permuted graph is one control, not a null distribution. Even a practical PASS is incremental evidence under this information budget.
