# 共享药理程序：实证资格与条件预测检查

2026-10-28。本轮完成了新一手来源核读、公开元数据的两种独立实现复算，以及一次先写明预测再执行的精确诊断。**尚无新的真实药物效果、共同学习收益或跨任务迁移结果。长期目标active、未达成。** 继承[当前v3候选](../2026-10-28-agent-a-cell-language-mechanisms/CANDIDATES_v3.md)，不新增其第三次文字修订，不重开已停路线。

最值得继续的主线仍是：**让Agent的作用程序成为虚拟细胞实际执行、实测反馈能够修正的变量。** 程序概率与细胞预测在同一对象上学习，才有机会超出“LLM读报告后调用预测器”。待解决的是程序是否有跨药可复用的观测含义，尚不能把它写成已经成立的算法创新。

## 3. 新原文改变了哪些判断

**CellChain，2026-10-12，arXiv:2610.16346v1。** 已覆盖跨尺度证据图、药敏推理及history归属匹配/交换。其固定cohort的简单历史均值规则就有64.2% compound-weighted accuracy；作者明确这是post-selection cohort诊断，不外推全部候选。百分数是原文报告，未由本Agent复现。因此“给LLM更多历史”“做证据图”“看答案是否改变”不够构成本项目新意，普通历史/数值预测必须是同信息基线。

**ERK原始研究，2021，10.1038/s41598-021-94941-8。** 直接关联早期4h信号恢复与7天后代数量；Fig4有180个始祖细胞，补充说明两次不同日实验。该关联已被原研究提出，不能冒称本项目发现。不同面板有不同密度/处理程序，不能混接为同一暴露；pERK也不是BRAF直接占据。取得DOCX含4个media、无原生表格或charts/embeddings，尚不含raw numeric。

**单克隆研究，2024，10.1186/s12964-024-01742-3。** 25个H1975来源单克隆与125个信号分子RPPA提供功能异质性实例，但没有取得蛋白原始矩阵或真实混合培养。亲本dose curve的4独立实验×2技术重复，不能推广到仅说明4技术重复的全部克隆端点。17页补充PDF有TableS3均值，没有原始重复供生物CI。

后两篇是较早原始生物证据/资源，**不是2025–2026前沿算法**。实际读取段落、附件hash、获取错误与未读范围均见[来源记录](evidence_notes.md)，不称完整全文阅读或全面查新。

## 4. 三种深度共同学习机制的定位

以下继承v3，都是待检验机制；本轮不通过换名再加模块。

### 首选CL1：实测锚定的可执行程序

从NLP推理中介/忠实性原则出发，中介改成有限、物理含义预定的作用程序p。Agent给程序分布π(p|细胞,药物,历史)，虚拟细胞必须执行p才能输出近端作用m与功能Y，没有自由文本数值旁路。真实反馈按`γp ∝ π(p|c,d,E)·P(m,Y|c,p)`同时修正程序概率与执行模型。未知、不可区分程序保留并存，不能靠任意token/振幅/时长暗中编码药物ID。

**可能解决的问题：** 若同一实测作用过程由多种药物实现，修正该过程可能复用于未测化学实现。Agent改变的是细胞模型真正运行的假设，细胞反馈也真正改变Agent下次提什么程序。相较CellQ式表征接入、PertMind/PertReason式过程监督，争取的是中介的实测语义及执行约束带来的迁移。

**最强反例与基线：** 责任更新是标准潜变量学习，不是新算法。普通程序网络、自由潜码+相同近端辅助标签、充分重训练都可能复制收益。要独立近端校准、整药留出，并检查“同程序/背景下药物身份是否仍预测残差”。若普通网络复制收益，撤LLM特有/相应算法优势；若程序语义漂移或跨药不充分，不能解释为机制发现。目前未做效果训练。

### CL2：同一模型的前向预测与逆向提案

迁移SUAVE统一掩码建模原则，同一联合模型学习合法动作、后续状态和实测功能；给动作预测结果，给功能目标提出动作。真实记录同时训练两个方向，Agent提案本身就是世界模型的一种推断。

**可能解决的问题：** 大菜单、反复目标下摊销搜索成本，并让真实反馈同时改善预测和提案。历史行为频率必须与成功率区分；v3的q0参考分布、支持及分配条件继续有效。原SUAVE图像/动作顺序不能原样充当生物前向mask。

**最强反例与基线：** 统一参数/条件采样已有。比较同预算前向枚举/beam/CEM、分开前逆模型、共享多任务、GP/决策AL。本轮反例要求保留背景×动作对应、前向隐藏目标，再用不由提案器挑选的独立实测面板验收。小菜单枚举更便宜或普通多任务复制全部收益时，停止新增算法主张。当前无新联合训练。

### CL4：群体对象作为共同推理语言

迁移Slot-JEPA的稳定对象、变化状态与对象间作用原则。生物对象必须由真实来源/谱系锚定，保留来源内状态分布与绝对活体量。Agent提出“来源内过程还是来源间作用改变”的程序，必须进入同一对象动力学产生数量/状态/功能预测；反馈共同修正对象绑定、相互作用及程序概率。

**可能解决的问题：** 相似末点RNA可由选择、扩增或来源内变化产生，后续再生长却不同。共享对象可让Agent选择辨别读出，并让虚拟细胞预测未见起始组成。视觉slot不自动是谱系，UOT质量不自动是活细胞质量。

**最强反例与基线：** ARTEMIS等已有群体量与动态。DeepSets/SetTransformer、密度感知群体状态空间模型、同对象但无LLM模型必须获得相同来源/数量/功能数据，否则只证明新观测有用。两来源真实混合比例×密度、操作对照及洗脱功能是关键。当前资源未符合，科学问题保留，不能写成已失败。

## 5. 下一步的决定性动作

优先给CL1补一个最小物理闭环，暂不加架构：至少两种化学实现的实测近端过程及后续功能，核定作用量、暴露、背景和独立重复。ERK原始研究提供可行观察，但当前附件缺raw numeric。LINCS/P100是下一轮数据来源线索；本轮仅题录命中，未读方法/数据，不能预称合格。

必要性检验不应被“每条必须同时含RNA”这一额外实现要求卡住。若以信号/活细胞测量作状态，须另冻观察合同，RNA映射仍是后续未验证环节。最终目标仍包括独立药物决策与跨药/背景迁移，一个简化信号体系通过不等于完整虚拟细胞框架成立。

合格数据到位后，先固定反馈比较强直接预测、自由潜码+同样辅助标签、普通程序策略+同执行器、层级/GP及完整重训练；再冻结更新器，同功能测量预算比较随机、直接功能测试、标准决策VOI与候选取证。整药留出先行，整背景单独评估。CI按独立培养/任务，样本量及效应门按实际方差与headroom预先冻结；普通程序模型复制收益、程序语义漂移、跨药残差仍依赖药物或独立功能收益不成立时，停止对应主张。缺数据/功效不足是未决，不记成机制否证。

CL2只在菜单规模/重复目标确有摊销空间时投入；CL4等待来源/数量与实测混合资源。尚不进入元学习/RSI，不晋升src。当前仍有明确可执行的后续证据动作，目标未达成而非真正无路可走。
