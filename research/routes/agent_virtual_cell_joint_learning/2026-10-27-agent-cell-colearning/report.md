# 虚拟细胞与Agent共同学习：方向与核心机制重构

研究启动及检索截止2026-10-27，交付核验2026-10-28。**首选主线：共享干预算子的反事实模型，由Agent按药物决策需求增量构建，再由真实程序反馈统一修订。** 有限细胞材料的联合状态控制是生物场景更鲜明的第二主线。可执行动作接口共同学习可保留，但既有方法覆盖很强，现阶段不宜承担主要创新。

本轮交付九个可分别检验的问题与三种机制假说。九个方向属于三个核心及其能力分支，不是九项独立算法；三种机制也没有被认证为三项首创。已完成证据刷新、原文对照、运算设计与独立质疑，未运行这些新机制的训练、模拟或效果实验。

## 1. 研究对象的实质调整

前轮重点是证据可识别性、测量桥接、顺序读出与靶点实现。这些条件必要，但没有充分回答：**Agent改变虚拟细胞学什么，模型的改变又怎样改变下一次真实干预？** 本轮把共享对象放进模型与策略的更新规则：

- CL1共享“多个给药计划必须来自同一个细胞规律”的反事实集合。Agent提出计划差，决定优先精化哪些关系；实测约束所有复用该干预的计划。
- CL2共享“控制意图实际由哪些药物程序、以多大概率实现”的控制核。Agent改编译策略就改变该核；模型须区分接口变化与细胞响应变化。
- CL3共享“读出后真实剩余的细胞组成、来源和未知动力学”的联合belief。观测改变知识，也改变下一药物作用的物理对象。

三者是备选核心，可单独研究。LLM可提出候选或调用求解器，其存在本身不承担创新归因。深度耦合的证据应来自共享对象的更新及后续决策改变。

## 2. 当前证据允许什么结论

最新ON3正式结果为v1.2，见[执行报告](../2026-10-27-core-module-design/oneil_dev/report_on3_exec.md)和[JSON](../2026-10-27-core-module-design/oneil_dev/on3_exec.json)。B4相对B2的Δρ=0.0730667，95% CI [0.0474620, 0.1003105]，低于冻结门槛0.10，判定`no_increment`。这是**O’Neil内部、non-blind/peeked、开发性描述结果**；两跑约1272/1131秒，超过估计15分钟，报告登记runtime deviation。本协调者核了报告、usage和JSON，未重新运行或独立认证效果。

它既不是“完全没有预测信号”，也不证明更新器优势、机制、真实决策收益或跨任务迁移。QUICK及v1.1 provisional已隔离，不能作为新的独立结果。R196v2/R197v2未决、R199强关系供应失败、Q0外部迁移未准入继续保留。旧单轴、线性编辑、预测分歧采样及伪RSI不因改名恢复。

近邻也要求提高门槛：CoMap已有policy与world model共同更新；CoLA、LAWM、HIJP已有动作/状态/动力学联合学习；MDA已有机制模型池、任务摘要与实验价值；COPEx及BOR已有动态约束和材料规划。共同训练、潜在动作、反例修订、非短视选实验均不能单独算新意。精确阅读范围见[证据记录](evidence_notes.md)。

## 3. 九个值得推进的方向

“近期可做”指形式结果、资源资格与明确基线的研究产出，不表示已有真实闭环数据。实际用户是需要在有限实验与材料下选择药物、剂量或日程的药筛团队；分子机制与临床收益仍需另证。

| 方向 | 核心问题与耦合 | 最先可能形成的成果 | 条件与风险 |
|---|---|---|---|
| **D1 共享反事实模型，首选** | 不唯一的动力学是否仍给出可靠计划差？Agent请求关系，实测共同修订模型 | 低维干预算子的功能识别、正确界及可计算算法；CL1 | 可先做形式研究。真实验证需程序与独立功能；全局solver是强对照 |
| **D2 计算与实验双预算** | 决策不确定来自求解松弛还是缺真实数据？Agent选择继续计算或实验 | 认证误差下的增量推断、总预算曲线 | 与D1同主线；普通约束生成/计算决策已有，节约须证明 |
| **D3 干预程序的组合迁移** | 短程序反馈能否约束未测长程序、新细胞或药物？ | 完整程序留出及新背景少反馈适应 | D1能力分支。残留、增长和隐藏历史可破坏组合；静态组合表不足 |
| **D4 在线干预语义漂移校正** | Agent换实现策略后，如何避免模型误学细胞规律？ | 可定位更新、在线策略变化下的校准与决策稳定性；CL2 | 普通物理model+controller可能完整解决，新意风险高 |
| **D5 跨背景可执行程序传输** | 同一功能意图如何在新细胞中重新落实，旧计划能复用多少？ | 多目标、多步骤程序的低成本重编译 | D4能力分支。须胜过直接动作搜索与LAWM式联合学习；单标量检索不够 |
| **D6 有限群体的材料—信息控制** | 读出移走细胞后，下一药物针对什么剩余群体？ | 来源一致推断/规划及药物选择边界；CL3 | 可面向有限类器官/不可补充研究样本。缺制备、分流、数量数据则停资源门 |
| **D7 同源分支取证与保留** | 测哪个分支、保留多少，改善未测兄弟分支的终局决策？ | 同预算减少材料浪费的决策能力 | D6能力分支。孔号非谱系，分支相关不能抹去；新制备才检验迁移 |
| **D8 决策充分的状态/读出共同选择** | 具体药物选择需要保留哪些状态、测什么？ | 决策状态压缩及明确失效边界 | 任务摘要/value-aware已有，宜作D1/D6子问题；加价值loss不构成主创新 |
| **D9 静态数据中的退化边界** | 共同训练何时可被普通条件模型与控制器消去？ | 可复核等价条件，避免继续在无区分力任务上训练复杂系统 | 可复用当前数据开发，不能充新独立验证；是边界成果，不担任旗舰机制 |

只选一个主线：D1，以D2作为算法问题、D3作为能力目标。获得合格有限材料来源树后，D6+D7可形成第二条完整主线。D4+D5先过强基线门，D8/D9支持主线收敛。

## 4. 机制一：计划差驱动的共同反事实模型（CL1）

**假说。** 在轨迹不唯一的群体观测下，跨计划共享干预算子，让Agent只精化影响选择的反事实方向，可获得逐点预测无法认证的决策界。进一步的算法贡献取决于能否比同信息全局推断更省总预算。

输入为群体观测、观测映射、初始条件、实际药物/剂量/时间、来源与误差合同。相容集M包含全部与真实数据相容的干预规律K。仅在充分状态和匹配条件下共享K，不把不同背景或隐藏历史强绑。模型表示M产生的共同反事实关系，无需指定一条“真实细胞轨迹”。

有限功能状态、长度H的程序p可写J_p(κ)=c_pᵀm_H(κ)，κ为共同核参数，m_H包含各程序共用单项式。维护V=conv{m_H(κ):κ∈M}。计划p的最坏简单后悔是max_q sup_{m∈V}(c_q−c_p)ᵀm；每次计划比较使用同一世界。该式限于声明的合法程序集、同一终局效用尺度，不是完整自适应策略或Bayes后悔保证。

**实际更新：Agent提出计划对→形成差方向→全局oracle返回有效外界或真实可行见证→更新共同V的内外表示→重新比较受影响计划。** 数值缺口足够小时，若相容世界仍导致不同选择，才用普通决策信息价值比较真实实验。反馈收紧M、重验见证、修订共同约束。求解、构图和重认证全部计费。少数已请求方向gap小，不代表全部未请求计划的后悔已认证。

纸面构造：两状态群体µ=(1/2,1/2)，A(p)=[[1−p,p],[p,1−p]]，B制备到第一状态。所有p的单次A边际相同；BA第二状态比例为p，BAA为2p(1−p)≤1/2。逐步独立换p会错误放宽到1。共同集合还能排除分别落在合法区间、联合却不可能的“BA=0、BAA=1/2”。例子依赖同核、质量守恒及充分状态，是代数构造，不是生物发现。

**精确差别与未解点。** CoMap训练教师可见真实完整下一状态；MDA已有任务摘要/机制后验，但不是本方案的共同识别界。普通非矩形控制、矩/SOS、约束生成和计算决策已覆盖一般原则。拟争取的是破坏性群体观测下，按计划差增量建立共同模型、区分计算歧义与数据歧义、用少量真实程序统一修订的可用能力。不是发明上述数学，也未证明优于共享参数后验或同预算全局solver。

最小验证先证明声明族的界和内外近似，再冻结小规模计算比较，随后核真实顺序/功能资源。对照共享参数后验rollout、全局非矩形solver、标准矩/约束生成、相同证书缓存、强历史模型与GP。错误模型族给出假窄界、把局部最大当外界、计算松弛被当生物歧义、标准方法等预算等效或开销超过节约，均停止相应主张。宽界属于未决。

## 5. 机制二：Agent执行语义与细胞响应的分离更新（CL2）

**假说。** Agent不断修改“功能意图u→实际药物/剂量/程序a”的编译器Cφ时，模型若只学习意图响应，会把自己的策略变化误学成细胞规律变化。共同学习须显式追踪这个内生变化，再检验能否低成本传输计划。

记录实际a、意图u、背景/历史h、编译器版本与行为概率。物理响应模型是Pθ(Y|h,a)，供Agent调用的控制核为Tθφ(Y|h,u)=Σ_a Cφ(a|h,u)Pθ(Y|h,a)。真实反馈按a更新P；φ变化先重新组合T；Agent依据当前T与实测目标效用调整C，随后又改变T。功能锚定义u，不用潜在码相似度充当成功。

该式要求h足以支持意图经真实a中介的响应模型；遗漏controller所用的隐含细胞信息时，记录行为概率也不能自动解决混杂。共同支持不足的动作需真实测量。同支持内C的概率变化也会改变T，不能只检查支持集。纯坐标旋转且物理分布不变时，决策应经语义对齐保持不变。

构造：a成功率0.01、b成功率1，细胞响应固定。编译器从偏选a换成偏选b后，同一u的成功率大变，不能据此修改物理细胞规律。反向模型也不能直接认证可靠实现：行为a:b=1000:1时，成功样本仍为10:1，会偏好低成功率的a。

**新意风险最高。** 上述构造由普通物理model+可变controller完整解决。CoLA已有联合动作/世界模型，LAWM有状态条件真实动作decoder，HIJP有hindsight及转移一致性。因此本机制当前是明确的问题假说，而非第三项已成立新算法。真正可争取的是多步骤、多目标、大动作菜单与新背景下可检验的语义校正/计划传输，能否省下真实反馈与计算。静态单端点数据下通常退化成普通目标优化，不承担主要创新。

最小验证先冻结实际动作/意图/行为日志和充分性假设，比较直接物理强模型+优化、已校正controller、普通联合训练及CoLA/LAWM/HIJP式方法，再做跨背景。不给候选免费锚或额外反事实标签。普通方法等效、无支持、锚不足、控制别名或没有预算节约时停止主算法主张，保留正确归因边界。

## 6. 机制三：观测改变剩余群体的联合学习（CL3）

**假说。** 对当前有限、不可补充的材料，破坏性读出既提供信息，也移除细胞。只更新动力学参数θ、却让Agent继续作用于原群体，会遗漏真实状态变化。模型与策略须共享“剩余组成—来源—参数”的联合belief。

输入含真实制备树、分流数量、可观察功能状态、干预历史、读出误差与终局目标。K类状态的原计数x，取n个细胞，样本组成x_s、读出Y；均匀无放回、条件exchangeability下：

`b′(θ,x_rem) ∝ Σ_(x,x_s) b(θ,x) Hypergeom(x_s|x,N,n) O(Y|x_s) 1[x_rem=x−x_s]`。

代理读出不能当真类型，须积分x_s；未知原x也不能因看见样本就认为剩余已知。增长、死亡与选择使用另外的状态转移，不把取样守恒跨越培养时间。同源分支按共同祖先和共享θ联合更新，不能边缘化θ后又假设分支独立。

**双向更新：Agent决定分支、取样量、干预与保留→模型预测信息及剩余材料状态→真实读出同时更新知识和物理状态belief→合法后续动作与目标改变。** 可利用计数状态、共享θ粒子与条件树消息求解；这些工具本身已有，误差/复杂度与实际可用规模仍待建立。

纸面构造：初始只有一敏感、一耐受细胞，θ已知。破坏性取走一细胞并识别类型后，剩余类型相反。两种结果的θ后验一样，下一药物选择却可不同。这说明“只学参数”不充分；完整资源belief planner同样能解决，并非候选独有优势。实际群体很大、取样比例很小时，这一影响可忽略，应停止推广相应收益。

**与先验的实质差别。** BOR已有库存、生产、时程和POMDP；COPEx已有动态约束与非短视实验设计。其静态响应/已知资源转移不直接提供读出移除后的隐藏群体组成，但一般资源Bayes-POMDP扩状态可包含本题。潜在贡献应落在生物制备结构带来的可计算联合推断或新可行能力，不能只声称第一次“材料+信息”。

最小验证先核制备、分支、数量、时程、破坏性观测与独立功能；当前未认证完整本地资源。随后比较同来源、同材料的resource-aware层级/GP、完整belief/dual control、COPEx式方法及plate策略。终局效用应作用于当前剩余材料；若目标实际是未来可无限补样的新制备，该构造不适用。缺来源树、状态不可测、分流有未建模选择偏差、标准方法等预算等效或算力开销抵消节约时停止相应主张。

## 7. 最小验证顺序与共同停止条件

以下均为下一阶段方案，未执行。先选单一核心，不先搭完整平台。

1. **形式/资源门。** CL1需共享算子、真实程序与观测合同；CL2需实际实现和行为日志；CL3需物理来源与剩余材料。静态数据只回答它能回答的问题。资源门随具体窄问题设定，不把旧Q0的大规模确认门套在所有内部分析上。
2. **同一反馈，比较学习。** 所有方法收到完全相同的真实历史；比较联合预测/有效界、可执行计划与独立功能。强预测器、重训练、层级、GP及同信息通用求解器都可用全部输入。先判断共享模型更新是否有用，防止把多取数据当学习机制。
3. **同一更新器，比较取证。** 候选Agent对照随机、plate策略、GP/BOED及决策主动学习，使用相同可执行实验包与费用。CL1的额外求解/认证同样计费，CL3不能获得免费材料或恢复能力。
4. **完整闭环及迁移。** 冻结模型/冻结策略/共同更新用于归因，接口交换前先对齐语义。留出完整制备、细胞背景、药物或程序家族；区分零反馈预测与少反馈适应，所有适应探针计预算。已暴露公共数据只作开发，重复随机切分不恢复独立性。

主要终点是**独立评估上的净药物决策效用或后悔**，包含实验、材料和计算成本；预测分数是辅助终点。按真实独立生物制备/患者等单位做配对区间，技术重复、计划数和随机种子不能充生物样本。样本量由最小有用效应与功效决定，先冻结效应门、预算、噪声及停止规则。无法达到功效则记未决，不强判失败。对模拟器成立只能称计算证据。

若最强同信息方法重现全部行为，撤一般算法新意；若预测提升但净决策无益，停决策主张；若只在当前背景成立，停迁移主张；未核靶点参与/遗传参照时，不作因果药理机制结论。只有独立决策收益和跨任务迁移成立，才讨论元学习/RSI，并与等预算普通程序搜索比较。

## 8. 本轮独立质疑真正改变了什么

v1把区间教师、逆似然和祖先不确定性说得过强。v2撤回了hindsight逆似然的可靠性解释，并给出正确的有限总体更新；但独立质疑又指出：单程序区间loss可同时接受联合不可能的预测。v3遂改为共同反事实集合，并区分数值精度和真实数据歧义。

[v3有界复核](recheck_v3.md)核对了共同支持界、联合反例及最坏简单后悔定义。它是接触讨论后的复核，不是新独立初判，也不证明首创或效果。保留的主要疑问仍是：CL1是否超出标准全局推断/约束生成；CL2是否超出普通model+controller；CL3是否在真实材料限制下带来足够大的可计算收益。

本轮到此收敛。具体冻结定义见[candidates_v3.md](candidates_v3.md)，版本和负结果保留，不再增加模块或改名争取正判。
