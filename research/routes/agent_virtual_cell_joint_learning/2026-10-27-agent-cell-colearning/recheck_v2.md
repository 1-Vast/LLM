## CL1：构造正确，但约束教师的新增能力尚未随之成立

### 1. 共享算子与矩形松弛的区别确实成立

以行向量群体分布记号、B 后状态为 δ0，重复使用同一个 A(p)，第二状态比例为：

`J(BA)=p`，`J(BAA)=(1−p)p+p(1−p)=2p(1−p)`。

对 p∈[0,1]，

`1/2−J(BAA)=2(p−1/2)^2≥0`，所以 sharp 上界为1/2，在 p=1/2 取得。

若把两次 A 的参数改为相互独立的 p1、p2，则：

`J_rect(BAA)=p1(1−p2)+(1−p1)p2`。

取 p1=1、p2=0 即为1。它相对于固定共享核是放宽后的外界，不能声称算出了同一个识别问题的 sharp bound。这个例子确实击中逐步独立选择不确定模型的矩形化方法；不应再用“经典 robust Bellman 已经处理 uncertainty set”将二者直接等同。

此处0.6备选支配 BAA，前提是比较相同 J/终局效用，物理可行性与成本已经统一计入。若0.6是另一个尺度上的“效用”、BAA只算比例而未算成本，则不能直接比较；按 v2 的同一目标解释，支配结论正确。

### 2. 证书的来源条件不能省略

上界来自持久共享、质量守恒、两状态可组合核和声明的 A(p) 结构。它不是从“单次 A 对均匀起点边际相同”这一句话无条件推出的生物事实。在完整、精确的两状态质量守恒 Markov 观测下，均匀分布经 A 保持均匀，确实可把一般两行核约束到这种对称形式；测量误差、隐藏状态、药物记忆、增长死亡会改变相容集与数值界。

v2 已明确这些前提，也允许历史进入状态、背景/剂量/时程不强绑，这是正确限制。实际应用仍须给出观测合同及共享核的适用域。BAA 的0.5不是可以搬到一般细胞模型上的默认界。

### 3. 对同信息全局 solver 仍无区别性运算

给全局 planner 同一相容集、同一共享符号 p、同一目标与真实反馈，它会得到相同多项式和相同证书，亦能直接排除 BAA。对重复子表达式/子程序做计算图复用、缓存证书、约束更新后重算，是合理计算策略；它们目前没有独立于通用全局多项式优化/约束生成/缓存的算法定义。

因此该构造证明的是“保持依赖比矩形松弛更精确”，尚未证明“证书教师比同信息全局 planner 多出学习能力”。没有必要要求现在跑实验获胜，但至少要有更具体的算法差异、正确性/复杂度性质，或重要任务达到可用计算阈值的论证。仅给这次可手算的平方证书，不足以支撑大程序空间节约。

### 4. 单程序区间损失不自动保留跨程序依赖

v2 给出的区间惩罚本身允许网络同时预测：

`J_hat(BA)=0`，`J_hat(BAA)=1/2`。

二者分别都在合法单程序区间 `[0,1]` 和 `[0,1/2]` 内，区间损失可为零；但不存在同一个 p 能同时生成它们。BA=0 强制 p=0，于是 BAA=0。故“从全局相容集导出的单程序区间”与“预测器保持跨程序相容性”是不同保证。

这不构成 v2 最终决策一定不安全的反例，因为它已要求关键程序回原 solver 复核；但也正因此，当前正确性仍由原 solver 承担。不要把独立区间 loss 自动描述为网络学到了共享算子的联合证书教师，更不能用拟合误差低代替联合相容性。

### 5. 与已读原文的关系及结论

MDA 已有 query-relative summary、机制池变化后重学及廉价推断复核，但没有因此实现这里的全局相容集求界；其与 CL1 的区别仍真实存在。[MDA A.4](https://arxiv.org/html/2608.09696v1) 经典 Robust POMDP 的局部 uncertainty sets 及逐时 robust update 也不能直接作为完整覆盖该构造的具体算法。[Osogami §2–3](https://proceedings.mlr.press/v37/osogami15.pdf)

最强覆盖者是候选自己承认的**同信息全局非矩形 solver/planner，加相同表达式和证书缓存**。目前应保留“共享算子下的功能识别与证书复用”形式研究，撤掉已成立的一般共同学习算法新意。未来是否形成贡献由具体运算/计算或科学能力决定，无须预先承诺实证必胜。

## CL2：漂移归因修正成立，仍是普通物理模型与 controller 的分解

### 1. v1 的错误解释已实质撤回

v2 不再把 hindsight 条件逆分布当成功可靠性，按物理 a 更新 Pθ、根据当前 Cφ 重新计算 Tθφ，是正确分解。即使物理系统完全不变，仅改变 controller 的混合权重也会改变意图 u 的响应。若无视实际动作，把 P(Y|µ,u) 变化直接归因物理细胞规律，会产生错误模型更新。

但是，保留真实动作条件的 model、记录行为策略、换 controller 后重算 option/抽象动作的结果分布，是既有物理模型加 controller 的正常操作。v2 自己的固定 P、改变 C 例子恰好可由这一基线完整解决，未排除一般 off-policy/option-model 的覆盖。CoLA、LAWM、HIJP 的联合动作/世界模型先验继续有效，v2 没有新增一个使上述基本分解失效或不适用的运算。[CoLA §3](https://arxiv.org/html/2510.26433v2)、[LAWM §3](https://arxiv.org/html/2512.10016v1)、[HIJP §3](https://arxiv.org/html/2610.23615v1)

### 2. 混合公式所需条件要写实

`T(Y|h,u)=Σ_a C(a|h,u)P(Y|h,a)` 要求 h（可包括 belief/完整决定历史）足以使意图 u、φ 对 Y 的剩余影响经实际动作 a 中介；还要求一致的动作定义、环境条件和观测时程。若选择 a 的 controller 使用了未记录的隐藏群体信息，则观察到的 P(Y|h,a) 不自动等于可以换 C 后沿用的物理因果响应。仅记录行为概率不能弥补未观测混杂或状态别名。

v2 已不再假装观测 µ 必然充分，这化解了初稿的强假设，但具体充分性/识别合同仍未给出。若 h 已充分、P 已可识别，公式和 off-policy 校正是标准组合；若不充分，当前更新规则也没有自动解决该困难。稀有/零支持动作必须真实测量的限制保留得正确。

### 3. “实现范围改变才改搜索”仍有歧义

纯坐标变换经对应对齐后，组合策略的物理分布不应改变，这是正确的一致性要求。但若“实现范围”仅指支持集合，则同支持内 C 的概率变化已经足以改变期望效用与最优计划，不必发生支持集扩张/收缩。例如两种 a、b 的概率从接近全 a 改为接近全 b，两者始终非零，支持完全相同，T 仍可大变。这正是本候选新中心问题本身。

因此实际可达集合、达成概率/混合权重与纯坐标旋转应分清。功能锚对齐也仍不保证多步控制等价；v2 已承认这一点，不能把该边界当已解决的计划传输算法。

### 4. 条件结论

v2 的归因边界更正确，但中心运算仍被普通物理 model + controller 完整表达。大菜单/新背景可能使抽象接口有计算或迁移价值；当前没有给出何种计划传输或校正操作使它不同于已知方法。保留为问题候选即可，不应为满足数量将其判为第三项已成形的新共同学习机制。

## CL3：守恒后验正确，纸面例能区分“只学 θ”，不能区分完整资源 belief planner

### 1. Hypergeom 联合更新正确

在 x 为已声明类型的非负整数计数、N=Σx、取样量 n 已知、均匀无放回分流且条件 exchangeability 成立时，v2 的更新

`b′(θ,x_rem) ∝ Σ_{x,x_s} b(θ,x) Hypergeom(x_s|x,N,n) O_m(Y|x_s) 1[x_rem=x−x_s]`

是正确的 Bayes 边缘化。它同时保留了未知原组成、所取样本与剩余组成之间的负关联；Y 仅为代理读出时积分掉 x_s 也是必要的。真实分流若有类型选择偏差、测量前还发生增殖/死亡，不能沿用相同 Hypergeom 核。v2 已把增长/死亡转移单列，因而没有跨培养时间错误守恒。

直接看到 x_s 时，`x_rem=x−x_s` 是守恒关系；若原 x 未知，则 x_rem 通常仍是后验分布，不能因直接看见样本就说剩余成分已完全知道。v2 的求和公式本身没有犯这个错误。

### 2. 两细胞例成立，但击中的是不完整状态

原始组成已知为一敏感、一耐受，读出破坏性移除一个并看到其真实类型，则剩余类型由守恒确定。θ 已知不变，下一步针对剩余群体的决策可以改变。这确实证明仅保留 θ 和原始群体均值不充分；改变材料对象与更新参数知识不是同一件事。

同信息的资源/有限总体 belief planner 会做完全相同更新。一般 POMDP 把隐藏库存组成纳入状态即可表达这个例子，计数/occupancy 与 Hypergeom 是既有概率模型。因而此例已给出明确的任务必要状态，却没有给出新的推断算法，也不能由此推断在常见大群体低取样比例药筛中有显著收益。v2 已明确小取样比例近似可能足够，这一停止条件应保留。

### 3. 相对于 BOR/COPEx 的区别真实但有限

BOR 已规划库存消耗、生产、时程和未来实验可行性；COPEx 已用动态 constraint state 与非短视 belief 设计。这些先验继续否定“第一次材料与信息共同控制”的泛化表述。[BOR 页2–4](https://web.engr.oregonstate.edu/~afern/papers/icaps16-dolatnia.pdf)、[COPEx §3](https://proceedings.mlr.press/v306/guo26g.html)

不过，BOR 原文的静态 f 与可计量资源类型、COPEx 的已知确定约束转移，并不直接提供隐藏群体组成被读出移除后的条件演化。它们的规划结果树也不是生物制备树。故 v2 明确的剩余组成 belief 是有意义的细胞条件差异；不能谎称上述两篇已经实现完全相同的群体生成模型。反过来，这个差异也尚未建立一个独立于通用 resource Bayes-POMDP 的算法。

共享 θ 粒子、计数化和条件树消息是合理计算选择，但都已知；没有给出误差/复杂度或可实施能力边界前，只能称结构研究方案。实际来源树、样本量与终局目标是否作用在当前剩余群体，仍是前置资源条件。本复核没有认证本地资源，也没有以缺资源否定数学问题。

### 4. 条件结论

v2 已修复祖先状态与跨制备 θ 的混淆，给出有效的即时剩余群体更新和可行纸面例，可以作为三条中问题较清楚的一条。一般新控制/共同学习理论仍未成立。允许将贡献保留为实际细胞任务或特定结构的可计算联合推断；不要求现在先有湿实验或基准胜利。

## 本次复核的停止结论

本次仅完成一次有界复核，不再检索或启动新循环。CL1 的非矩形构造和 CL3 的守恒 belief 通过解析条件核对；CL2 的物理/接口归因修正有效。这些结果证明 v2 更精确，**不证明三项新算法已成立**。

尚需公开保留的最近邻是：CL1 同信息全局非矩形 solver/证书缓存，CL2 同信息物理模型+可变 controller/off-policy，CL3 同来源与守恒的资源 belief planner。若最终交付以条件候选、明确算法缺口与科学任务价值呈现，可以结束本轮发现工作；无需继续修到质疑者全部给正判。
