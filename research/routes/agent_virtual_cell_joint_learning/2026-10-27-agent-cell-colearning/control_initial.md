# 控制与世界模型独立初始线索（未曝光冻结）

2026-10-27。角色：源原理侦察/机制提出者；effective model=unknown。只读本轮 BRIEF 和 innovation-research 指南/idea-development；未读旧候选、协调者讨论或其他 scout。以下均为未验证推导，未检索最近邻，未运行实验。

## A. 由可执行后续干预定义细胞状态，靠反例分裂状态

当前表达相似不意味着控制等价。把细胞培养条件的“状态”改为可执行未来干预序列的响应等价类，而非先拟合表达嵌入再在其上规划。Agent 提出会影响终局排序的策略对；模型判断它们在哪些当前被合并的历史上有不同继续价值；只在该处提出反例实验，并以真实反例分裂状态、重建干预算子。策略由表示限定，表示又由策略反例决定。

正例：两种预处理后终点表达相同，但下一共同药物分别使群体向恢复/死亡方向变化；一次共同后续干预足以要求模型记住预处理历史。反例：没有允许的后续动作能区分，或者历史/暴露无法可靠重复，则不能宣称隐状态识别。普通双层决策聚焦训练、predictive state representations、bisimulation、counterexample-guided abstraction 可能已经覆盖核心。潜在剩余是：破坏性群体读出下，只用可执行分支设计学习“足以决定的最小历史”，而不臆造单细胞轨迹。

## B. 部分识别的动态模型，在策略冲突中学习可收缩的算子集合

群体边际不确定跨时配对。不要选择唯一最优传输配对再做策略；维护所有与真实观测相容的群体干预算子集合，允许计划只依赖其共同结论。Agent 的候选策略形成模型对抗见证：寻找两套观测等价算子但策略排序相反；只有存在可执行实验分开见证时才购买。真实反馈删去违反新群体约束的算子，连带改变哪些策略可以被支配排除。

正例：单次用药终点相同、但两次顺序作用的群体终点不同，顺序实验可消掉行动排序歧义；无需确定单细胞配对。反例：观测等价对所有允许实验都成立，则不会获得机制识别；最坏情形可能永久保守。鲁棒 MDP、Bayes-adaptive dual control、decision-theoretic experimental design 已包含一般思想。真正可研究的是对群体读出建立可执行反例与可控策略商空间；仅写 min-max+选样不是新机制。

## C. 学习可组合的干预代数，让规划中的组合失败反写模型结构

把干预模型表示为一组可组合的群体算子，而非独立条件预测器。Agent 遇到长序列时先使用已获支持的交换、合并、历史截断关系来压缩搜索；为决定最有价值的动作，主动检验会改变最优序列的代数关系。真实顺序效应不是只加一个样本，而是撤销错误的交换/等价约束，新增必要的历史状态/交互生成元，使后续模型训练与搜索空间同时改变。

正例：A 与 B 单药终点均可预测，但 AB≠BA；若组合模型默认可交换，则出现结构性漏解。真实顺序实验撤销交换约束后，Agent 才能提出正确序列。反例：细胞增长、选择与测量时间不同也可产生顺序效应；不能从 AB≠BA 推出分子机制。神经动力学、Koopman 控制、Lie 代数系统辨识、程序归纳均可能覆盖。潜在剩余：在破坏性边际测量下，按决策需要联合学习动作等价关系与最小记忆，而非拟合唯一微观动力学。

## 初步取舍

A 与 C 很可能是同一研究程序的两面，不应凑成两种独立大创新；B 提供无需唯一微观模型也能决策的基础，但有落入常规鲁棒主动学习的风险。值得发展的中心问题是：实验选择能否改变模型可表示的干预组合/历史等价，而这种结构变化能否打开固定表示模型不具备的序列决策能力？必须和同信息、同计算、可重训的通用历史条件世界模型比较，不能只战胜僵硬的无记忆基线。
