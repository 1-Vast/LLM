# 冻结 v1 的独立机制质疑与原始来源

2026-10-27。有效模型 unknown（无运行时 metadata）。先只读 `BRIEF.md`、`candidates_v1.md` 并保存 `challenge_initial.md`，再做本次核查。未读 control_scout、structural_scout 或协调者后续 report；未参与候选改稿。未运行科学实验、模拟或训练，未下载数据/权重、未安装依赖。以下数值例子是解析反例，不是效果结果。

## 结论

三条确实定义了比“条件预测器接查询 API”更具体的闭环对象，但 **v1 不能交付为三项已经有区别性操作的共同学习算法首创**。框架能表达双向影响，不等于给出了新的共同学习机制。也无需先有实证胜利才能交付：当前可交付的是带具体先验覆盖、可行条件和反例的研究候选。

| 候选 | 双向对象是否实质 | 当前新意判断 | 可继续保留的核心 |
|---|---|---|---|
| I-CL1 | 是：相容模型集合约束想象监督；程序反馈改变可监督函数 | 集合求界、任务导向设计及代理蒸馏已有原则覆盖；尚缺新的可计算操作/保证 | 在破坏性群体读出下，区分功能可识别与轨迹不可识别，并限制想象监督 |
| I-CL2 | 定义上是：状态依赖的物理实现关系决定意图控制核 | 覆盖风险最高；静态版本可直接还原为条件逆模型或目标优化，动态版本尚有控制别名 | 有实测锚的控制意图在背景变化中的含义与可执行性，作为尚未解决的问题 |
| I-CL3 | 是：同一动作同时改变材料前沿与 belief，合法动作随历史变化 | 材料库存、非短视设计、共享潜变量均有原则覆盖；树形细胞动力学的具体贡献未给出 | 有真实制备树时，对不可重置群体做来源一致、材料可行的联合推断与决策 |

保留 CL1 和资源合格时的 CL3 比较合理；CL2 暂不能仅以“可执行接口同步”计为第三种新算法。这里没有认定任何一条毫无价值，也没有认定一般 POMDP 的表达能力就足以解决实际细胞问题。

## I-CL1：保留问题，停止把“目标变了”本身当新算法

**最强覆盖。** 对固定声明族，`M_t` 是 set-membership system identification 的相容集；`inf/sup J(K,p)` 是鲁棒/部分识别的函数值求界；找极端模型并添加约束是约束生成；选择能改变终局决策的真实实验是目标导向设计；把已求出的区间教给快速网络是代理学习。实验使约束集合变化，训练目标因而变化，这种双向依赖可直接嵌入既有主动模型学习。

MDA 已进一步说明任务相对的摘要充分性、模型池变化后的重学与廉价推断的原始观测复核，所以“Agent 决定模型需要学什么”和“摘要不必重建全部状态”不能作为 CL1 与 MDA 的精确区别。但是 **MDA 的概率后验/summary-sufficiency 不等于相容集合上的 sharp identification bounds**；不能把这两个区别抹掉，也不能把任意 ensemble 方差冒充识别区间。MDA 原文对 PF 的表述也不赋予其脱离模型族、观测模型和有限粒子误差的物理真值保证。[原文 A.4](https://arxiv.org/html/2608.09696v1)

**双向必要性仍欠一层。** 删除快速预测器，直接由原约束 solver 给 Agent 的程序求界并做 VOI，v1 的主要安全性与纸面二选一用途依然成立。因此快速模型目前是可选计算代理；尚未展示必须“模型和策略共同改变学习对象”的新学习操作。若模型只是可选提案器，正确贡献应落到功能识别/求界或规划效率，而非用必要耦合一词跨过此空缺。

**正例检查。** 两状态例的代数成立：初始均匀群体经过 identity/swap 都不变；B 把两者都送第一态；B→A 的第二态比例为0或1。它证明单次边际不足，复合程序能区分特定核，并且功能可能比完整核更容易识别。但一次真实 B→A 观测已经直接给出该程序功能；相同历史的鲁棒 planner 或历史条件预测器也能改变选择，根本不必想象蒸馏。此例不能区分候选与最近邻。

该例依赖固定、跨程序可组合的 A/B 核、相同时间/起点定义与可比群体，不允许 A 在 B 后改变适用规律。它是可行的数学情形，不是现有单药资源中已知存在的生物现象。

**容易误伤的反证。** 经典 robust MDP 的矩形 uncertainty set 可能允许极端模型在状态/时间间切换；CL1 的一组真实边际约束可能跨状态和时间共享同一个 K。这些优化不必相同。只引用普通 robust Bellman 算法不能证明已计算了此候选的 sharp bounds；但“普通算法不满足此结构”也不自动证明候选已经给出新的解法。Osogami 的具体结构限制应保留。[原文 §2、3](https://proceedings.mlr.press/v37/osogami15.pdf)

**最小真正区分。** 无需先实证胜出，先明确一类破坏性群体约束及其计算对象，证明候选对哪些程序函数给出有效界，在哪些情形能扩大可监督集合，以及同信息的直接集合 planner/全历史重训为何做不到同一运算或需更多计算。若与直接集合 planner 的唯一区别只是缓存其输出，则一般算法新意撤回；若能给出新的结构求界、可证明学习范围或重要计算阈值，仍可形成独立贡献。这是判别要求，不是替候选设计新版。

**条件结论。** 可保留为“证据限制的功能想象学习”研究方向；v1 不支持一般共同学习算法首创。真实资源若只有单步静态表，不能验证动态核或复合程序功能；允许模型族变化时相容集还可能扩大，不能无条件宣称学习范围单调增长。

## I-CL2：普通逆模型覆盖最强，并存在目标条件选择偏差

**已有操作覆盖。** CoLA 已覆盖动态动作表示与世界模型的共同变化；LAWM 已有状态条件 `p(a|s,u)`、latent 控制及支持约束；HIJP 已让 hindsight 目标监督反向作用于表示和 world model，并约束预测动作产生的转移。因此“可变 latent action + decoder + 联合更新 + 计划重估”不是尚未被公开方法使用的必要运算。细胞功能锚、多对多实现与破坏性读出是重要条件差异，但 v1 尚未给出由此推出的区别性算法。[CoLA v2 §3](https://arxiv.org/html/2510.26433v2)、[LAWM §3](https://arxiv.org/html/2512.10016v1)、[HIJP §3](https://arxiv.org/html/2610.23615v1)

**静态退化是精确的。** 若背景固定、所有 a 是当前已知菜单、µ 不承载可演化历史，强条件响应模型可对每个 a 预测功能分布，再直接优化目标 u。C 是这个优化器的摊销近似/检索分布；`T=Σ_a C P` 只是实际动作随机选择后的边缘化。v1 正例中“换背景后 a 不够而 a′ 可达”完全属于该强基线，不能只比较把同药当同效应的弱模型。一个 viability 标量也无法决定后续状态与复合响应。

**具体反例：达成目标后的逆似然不等于可靠实现。** 固定背景，设采集行为为 β(a)，实测达成目标 u 的事件为 G=u。最小化 `−log C(a|µ,g(Y))` 的理想极限是：

`C(a|µ,u) = P_β(a|µ,G=u) ∝ β(a|µ) P(G=u|µ,a)`。

若行为采 a:b=1000:1，a 达成 u 的概率0.01，b 达成概率1，那么达成 u 的样本中 a:b=10:1。仅按该逆似然训练的 C 会偏向成功率1%的 a，而已存在成功率100%的 b。即使无限数据、无函数拟合误差也如此。这不否定用实际达成目标提供训练样本，而是否定将这种证据直接解释为可靠可执行关系。v1 写了“不确定性”及后续 P，因此不能说整个系统必然失败；但该训练式目前没有独立支撑中心可实现性命题。统计行为支持、当前菜单中有真实见证、按概率可可靠达成三者不能混用。

**控制别名与传输。** 两种实际干预可能达到完全相同的已测 g(Y)，却留下不同未测群体组成，从而对下一干预产生不同结果。按 g 的锚对齐只能证明此次观测语义相同，不能证明多步控制等价。部分观测下直接以观测 µ 而非历史/belief 为接口，还可能把必须区分的状态折叠。纯坐标旋转下对齐后策略不变是正确的表示一致性要求，但少量效应锚不保证能唯一恢复对齐，更不证明新算法。

**最小真正区分。** 要先说明意图接口在什么可观察性/支持条件下足以保持下游控制语义，如何区分行为条件逆模型与达成概率，以及与同信息直接响应模型+优化、goal-conditioned inverse model、LAWM/HIJP 风格联合训练的差别。若区别只是训练一个反向 decoder 或多加一致性目标，应撤一般算法新意。此处需要改变“锚足以定义控制语义”或“逆向达成样本足以表示可靠实现”的前提；不能靠改名或增加 latent 维度处理。

**条件结论。** 不宜把 CL2 v1 作为凑够三个的正判。它可保留为需要重新定清识别对象与可靠实现语义的问题。当前没有证明药物名动作规划器原则上无法表达同样控制，也没有证明一维静态表能够检验该动态机制。

## I-CL3：材料—信息双效应真实，但不是库存约束首次出现

**现有覆盖具体到哪里。** ICAPS 2016 的 BOR 已把材料库存、实验资源消耗、制备/生产动作、设施并发、时程及未来实验可行性联合规划，原文明确写成未知 f 的 POMDP。故“准备材料/做实验两类动作”“花材料会改变未来选择”“并非 acquisition 多一项 cost”都已有具体算法先验。COPEx 又把路径/物理状态与预算写成 constraint state，使用 belief 更新和结果分支规划。这两项都应进入强对照谱系。[BOR 页2–4](https://web.engr.oregonstate.edu/~afern/papers/icaps16-dolatnia.pdf)、[COPEx §3](https://proceedings.mlr.press/v306/guo26g.html)

**不能夸大成完全覆盖。** BOR 的 unknown f 静态、库存资源是可计量类型；COPEx 的 `p(y|x,θ)` 与已知确定 constraint transition 不直接表达受干预而演化的同源群体潜状态。其 outcome scenario tree 不是制备来源树。CL3 的随机 split/增长/死亡、同源分支、破坏性观测是实际差异；通用资源 Bayes-adaptive POMDP 可以通过扩状态表达这些差异，但候选还没给出优于通用 belief planner 的具体树形求解法或能力边界。不能由“框架能表达”判定细胞任务已经解决，也不能由“字段不同”判定新控制理论。

**正例的有效范围。** 两份不可补充材料的例子可以证明：若终局行动也必须用这两份材料，穷尽筛选可能不可实施，保留可能更优。若终局只是给未来新制备材料推荐药物，则该例的终局损失变了。它反驳忽略材料的基线，并不反驳同库存、同祖先信息的 resource-aware GP/POMDP。把每个干预后材料状态当静态库存也会漏掉成分改变，因此 v1 比纯成本列更完整；仍需真正的状态转移模型，而不是仅多一张树。

**需修正的统计陈述。** “同源两次读出不能像两个独立制备那样缩小祖先不确定性”混淆了估计目标。设祖先状态 `x~N(0,τ²)`，两次读出 `y_i=x+ε_i`、`ε_i~N(0,σ²)` 条件独立，则：

`Var(x|y_1,y_2) = (τ^(-2)+2σ^(-2))^(-1)`。

两次同源读出确实可继续缩小该祖先状态的不确定性。相反，若目标是跨独立制备的共享参数 θ、制备随机效应为 b_root，那么同源均值的噪声含 `Var(b_root)+σ²/n`，重复读出不能消除 root 随机效应。独立制备有助于后者，不等于更有助于“同一祖先实现值”。候选应区分祖先状态、共享动力学 θ、跨患者/制备外推三个目标；不能把“不算独立生物重复”升级成“对祖先 belief 没有相应信息增益”。

**计算与识别门。** 给定 θ 的树形消息传递可以成立，但 θ 作为共享全局变量仍耦合所有分支；将 θ 积分掉不保证每孔独立，也不保证仅沿树一次传递就解决全部后验。split 的子群体可因无放回分配相互相关；v1 用联合 S(children|parent,n) 是合理形式，若实现改成独立子节点核会破坏材料条件。材料守恒只约束分流，跨时间还需增长/死亡，不识别这两者就不能从剩余量变化自动推断药物机制。

**最小真正区分。** 先确认数据存在真实来源树、材料量、时间史和分支相关读出；板/孔标识不够。再精确定义是任务能力贡献，还是利用特定树/守恒结构的推断或规划算法贡献。后者需要展示一般资源/source-aware 方法在同信息、同计算下无法直接完成的运算，或给出更低复杂度/更可用的保证。若仅能证明“相对忽略库存方法更好”，不足以支持一般算法新意。

**条件结论。** 若上述资源真实存在，CL3 可以是有用的细胞研究任务和结构求解方向，且不会退化成纯静态查询问题；当前资源资格未认证、区别性算法未定。不能因为缺现成数据就称机制已被否定，也不能在静态开发表上宣称已验证。

## 协调者应保留的边界

1. 本次发现了新近且具体的覆盖，尤其 HIJP 与 COPEx；这些是最近邻，不是候选的效果结果。搜索范围有限，未证明穷尽先验。
2. CL1 的求界/识别对象值得发展，CL3 的实际制备树差异值得保留；CL2 目前最需要撤掉笼统首创表述。三者的共同学习对象不同，不足以自动组成“三种新算法”。
3. 所有正例都只击中某些不完整基线；同信息集合方法、强条件响应优化与资源 belief planner 仍是决定性对照。两侧冻结和模块交换可定位贡献，不能单独证明新意。
4. 尚未解决的前提要公开：CL1 的可组合核与可计算非矩形识别集，CL2 的控制充分性和可靠实现含义，CL3 的终局材料约束及祖先/共享参数推断目标。若需实质改变这些前提，由协调者留版本改稿；本质疑者没有共同设计新版本。
