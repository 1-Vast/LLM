## 1. 计划、共享算子、联合矛盾（沿用 v0.1，已 PASS）

- 计划 p：P-dose（4×4 网格的一行 `(d_a,d_b)`×4 技术重复）、P-replace（同成员/角色/剂量在不同伙伴上下文）、P-program（顺序/时点；本资源不支持，仅形式保留）。
- 共享算子 `S_θ=(f_{a,role}, g_{b,role}, h, b_batch, σ_obs)`，`m(p;θ)=c_p^T m_H(θ)`；假设 A1–A4 同 v0.1。
- 联合矛盾：`ε_p=min_θ r_p(θ)`、`ε_{pq}=min_θ max(r_p,r_q)`、`J=ε_{pq}−max(ε_p,ε_q)`；单独合法（`max(ε_p,ε_q)≤τ`）+ `J≥δ_J` = 联合矛盾。证书 `θ*=argmin max(r_p,r_q)`。
- 本资源冻结的主算子族 **S-add**：`y(pair(a,b); d_a,d_b) = f_{a,roleA}(d_a) + g_{b,roleB}(d_b)`（角色**分层**；同一 (drug,role) 的 f 跨计划共享，伙伴函数每计划自由）。秩 1 交互族 S-r1 **不在 P1**（仅未来 P2/敏感性另立预注册）。

## 2. 例 1、例 2（形式证据例子；沿用 v0.1，可复核）

**E1（群体单步边缘相同、联合不可能）**：µ=(1/2,1/2)，A(p)=[[1−p,p],[p,1−p]]，B 制备到第一状态。BA 的第二状态比例 = p；BAA = 2p(1−p) ≤ 1/2。BA=0（p=0）与 BAA=1/2（p=1/2）分别合法，但同一 p 下联合不可能；单独计划区间允许、联合集合排除。

**E2（4×4 剂量网格：成员剂量效应跨伙伴必须一致）**：S-add，`y=f_a(d)+g_b(e)`。
- p1 = (a,b)：`y(d1,e1)=1, y(d1,e2)=2, y(d2,e1)=3, y(d2,e2)=4`；加性一致性 `1+4=2+3=5` ✓ 单独精确拟合，推出 `f_a(d2)−f_a(d1)=3−1=2`（另一列 4−2=2 一致）。
- p2 = (a,b′)：`y(d1,e1)=1, y(d1,e2)=2, y(d2,e1)=4, y(d2,e2)=5`；`1+5=2+4=6` ✓ 单独精确拟合，推出 `f_a(d2)−f_a(d1)=4−1=3`。
- **联合**：不存在同一 f_a（2≠3）→ `J = ε_{p1p2} − 0 > 0`。显式最小二乘（共同参数 c=f_a(d2)−f_a(d1)，4 个约束）：`SSE_joint(c)=2(c−2)²+2(c−3)²`，`min_c SSE=1.0`（c=2.5），`J_SSE=1.0`、RMS=0.5（v0.1 已用）；这是"各计划单独合法、无法由同一 S 产生"的最小可复核例子。

## 3. 例 3：原秩 1 叙述作废（仅示意）；替换为显式 E3（role-agnostic 错族警示，**不作 H_A 形式证据**）

### 3.1 原 rank-1 叙述（v0.1 §5 例 3）
**明确标注：仅示意、不作形式证据，已从形式证据集合中剔除。** 原因：v0.1 只写"构造使 p1 需要 u(d2)/u(d1)=1、p2 需要=2"，未给出 p1/p2 的观测/设计矩阵/参数化/J 显式演算；且秩 1 交互族在 4×4 网格下每计划有自由 `g_b,v_b`，联合可识别条件需显式核算（见 §3.2 的维度条件）。**该例不再被引用为矛盾例子。**

### 3.2 秩 1 族的可识别性核算（为什么必须显式化）
S-r1：`y(d,e)=f_a(d)+g_b(e)+λ u_a(d)v_b(e)`。对**每计划**的自由参数（伙伴侧 `g_b(e),v_b(e)` 各 M 个、λ 1 个）与**共享**参数（`f_a(K)`、`u_a(K)`），两个计划合计未知数 `2K + 2(2M+1)`，观测 `2KM`。只有 `2KM > 2K+4M+2` 才可能有过识别约束；K=M=4 时 32>26 ✓，K=2 时 8<8+4+2=14 ✗（无约束力）。因此"秩 1 矛盾"必须在**大网格/多于两计划**上显式列出设计矩阵与 J，不能靠 2×2 示意；本修订不把 S-r1 作为 P1 族，**不需**该例作为形式证据。

### 3.3 显式 E3（role-agnostic 错族示例；完整可复核；**不计入 H_A 证据**）
**目的**：示范"强行让不同角色的剂量效应共享一个 f"会制造**假矛盾**——因此 P1 必须使用**角色分层** S-add，且需报告角色敏感性；本例如错用 role-agnostic 族，J>0 只反映族错设，不是生物联合矛盾。
**设定**：药物 X 的剂量 d1,d2；p1 中 X 为 role A（成员），伙伴 Y 为 role B；p2 中 X 为 **role B（伙伴）**、Z 为 role A。两计划均为 2×2：
- p1（X role A, Y role B）：`y(d1,e1)=1, y(d1,e2)=2, y(d2,e1)=3, y(d2,e2)=4`。角色分层 S-add 精确拟合：`f_X^A(d2)−f_X^A(d1)=2`（列 e1：3−1；列 e2：4−2），`g_Y^B(e2)−g_Y^B(e1)=1`。
- p2（Z role A at e1,e2；X role B at **同一 d1,d2**）：`y(e1,d1)=1, y(e1,d2)=2, y(e2,d1)=4, y(e2,d2)=5`。角色分层 S-add 精确拟合：`f_Z^A(e2)−f_Z^A(e1)=3`（4−1；5−2），`g_X^B(d2)−g_X^B(d1)=1`（2−1；5−4）。
- **role-agnostic 族**（把 X 的两个角色合成同一 f_X）：p1 给出 `f_X(d2)−f_X(d1)=2`；p2 给出 `f_X(d2)−f_X(d1)=1`（同一剂量值 d1,d2）。
- **J 显式**：共同参数 `c=f_X(d2)−f_X(d1)`；四个约束（每计划两列重复）：`SSE_joint(c)=2(c−2)²+2(c−1)²`，`min_c SSE=1.0`（c=1.5；2×0.25+2×0.25）；单独 `SSE=0` → `J_SSE=1.0`、RMS=0.5（viability 单位）；即 role-agnostic 族下"联合矛盾"成立。
- **正确读法（写死）**：在 **pre-registered role-stratified S-add** 下，p1/p2 **无矛盾**（X 的 A/B 角色函数分开，各自精确拟合）→ **E3 不是 H_A 证据**，只证明 §4 的族设定/角色分层条件必须满足；若 P1 观察到大量"矛盾"，必须先用角色分层族与 role-agnostic 敏感性区分**真联合矛盾 vs 族错设**。

## 4. 可辨识条件 + **P2/ΔW 空集规则（冻结）**

### 4.1 可辨识条件（v0.1 §3 增补）
1. 共享分量（(drug,role) 的 f）在 ≥2 计划中以 ≥2 个共同剂量水平出现；同一剂量刻度；角色分层（E3 反例）。
2. Gauge 固定（加性族每连通分量一个平移自由度；参考剂量固定）；角色不可交换。
3. **过识别度 `over=#obs−rank≥1`**；P1 的检验力来自 `over`（v0.1 资格：每细胞 median 8,745）。
4. 联合约束非矩形；噪声容差 τ 由技术重复/半拆标定；`J>τ` 才可由数据支持。
5. **族设定必须预注册**：S-add 为主；role-agnostic 只作敏感性（不用于 P1 主结论）；S-r1 不在 P1。

### 4.2 空集规则（冻结；challenge 必改 2）
- 对计划对 (p,q) 与容差 τ，**联合可行集** `M_pq(τ)={θ: r_p(θ)≤τ ∧ r_q(θ)≤τ}`；**可能为空**（这正是 P1 的联合不可行）。
- `V_pq = {m_H(θ): θ∈M_pq(τ)}`；**若 `M_pq(τ)=∅`，则定义 `V_pq=∅`**（空集，不是单点、不是 ∞ 点）。
- **宽度定义**：对候选计划集 Q 与 θ，`R_p(θ)=max_{q∈Q}(c_q−c_p)^T m_H(θ)`；对非空集合 `V`：`R_p^+(V)=sup_{θ∈V} R_p(θ)`、`R_p^−(V)=inf_{θ∈V} R_p(θ)`；`W_p(V)=R_p^+(V)−R_p^−(V)`。
- **`W(∅)` 约定（写死）**：`W_p(∅)=+∞`（空集表示联合不可行，宽度无界/未定义；机器实现用 `"undefined_joint_infeasible"` 标记，不参与数值聚合）。
- **ΔW 定义（非空对）**：`ΔW(p,q) = mean_{s∈{p,q}} [ W_s(V_p^sep) − W_s(V_pq) ]`，其中 `V_p^sep` 为**仅用计划 p 自身可行集**（不含 q 约束）；仅当 `V_pq≠∅` 时定义为有限值。
- **P1/P2 适用关系（写死）**：
  - **P1** 对**全部**合格计划对计算 J（含 `M_pq=∅` 的对）；P1 不看 ΔW。
  - **P2** 只对 **`V_pq≠∅` 的对**计算 ΔW；空集对**归入 P1 的联合矛盾证据**，`ΔW` 记为 `undefined_joint_infeasible`，不参与 P2 聚合。
  - **P2 可估条件**：未来若执行 P2，需预注册"非空对数量 ≥ 合格对数量 × 20%"（每折与 pooled 均满足），否则 P2 = `design_invalid: precision_insufficient`，只报告 P1。
  - **A.1 不执行 P2**（Lead 仅批 P0/P1）；上述规则冻结供以后预注册，不得在 P1 结果后改。

## 5. P1 统计量（冻结；与 DESIGN_A_v0_2 §3 一致）

- **检验宇宙**：`U = { (p,q) : 同一 target30 细胞；两个 pair-cell 均为 batch1 complete-case 完整 4×4 网格；两计划共享 ≥1 个 (drug,role) 上下文且共同剂量水平 ≥2 }`。**U 的精确计数由 `qualify_A_v0_2.py` 在数据上确定（只数结构，不读响应）**；P1 对 U 中**全部**对计算，不做事后选择（选择只属 H_A2，未批准）。
- **单计划合法（separate legality）**：对计划 p 的 4×4 网格（行=成员剂量、列=伙伴剂量；行值 = 4 技术重复均值）做加性分解，残差 `R_p = Y_p − r_p1^T − 1c_p^T + grand`，`s_p = ||R_p||²/((K−1)(M−1))`；`p` 单独合法 ⇔ `s_p^{1/2} ≤ 1.96·σ_obs/2`（`σ_obs/2` 为行均值噪声 SD）。
- **配对差异统计量**：共享上下文剂量集 D（K 个共同剂量）：`d = f_p|D − f_q|D`（行均值对齐），`d_⊥ = P_perp d`；`F_pair = [||d_⊥||²/(K−1)] / σ_pair²`，`σ_pair² = σ_obs²/2`（两计划行均值之差）。**δ_J（pair 级）**：`F_crit = 2.60`（F_{0.95, 3, ∞}；K−1=3 冻结；若共享剂量 K=4）。
- **per-cell 统计量**：`T_c = max_{(p,q)∈U_c, 两计划单独合法} F_pair`。**零分布**：行内置换（每 plan-cell 内对 16 行做置换，保持 4 行=成员剂量×列结构，重算 row means 与 F；N_perm=500、seed=20261029），得到 `T_c^{(b)}`；per-cell p 值 `p_c=(1+#{b:T_c^{(b)}≥T_c})/(1+N_perm)`。
- **多重性/FPR（写死）**：30 个 target 细胞用 **Benjamini–Hochberg q=0.05**；P1 阳性 ⇔ **(i) BH 拒绝的细胞数 ≥5** 且 **(ii) pooled 合格对中 `F_pair≥F_crit` 的比例 ≥ 置换零分布 pooled 比例的 Q95**。两者必须同时满足；不得看结果改。
- **FPR 论证（441,867 全宇宙）**：全宇宙只是**描述性计数**；P1 推断只用 per-cell max + BH，故对 U 的 44 万对**不需逐对多重校正**：per-cell max 已把 cell 内 ~10^4 对的多重性吸收进置换零分布，30 细胞再 BH。若未来要用 pair 级计数作证据，必须另立预注册（当前禁止）。
- **其他零模型门**：① **技术半拆**：每行 4 重复拆 2+2，两半独立估计同一计划的 row means；在 H0 下 F 的 FPR 应在名义 5% 内（预注册门：半拆 FPR ≤0.10；否则噪声标定/独立性问题 → design_invalid）；② **算子打乱**：将 (drug,role) 标签在细胞内的计划间随机置换（保支撑），重算 T_c 分布作为第二零模型（应不拒绝）；③ **随机计划对**：仅用于未来 H_A2 选择比较（P1 测全 U，无选择；A.1 不执行）。
- **不变量**：`σ_obs`、`F_crit`、`N_perm`、`seed`、BH q、细胞数 30、δ_W=0.05 全部冻结于本文件/DESIGN v0.2；执行前不得改。
