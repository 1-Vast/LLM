# PROBLEM_A —— R201-A：跨计划一致反事实细胞模型（形式化与可证伪问题）

2026-10-28。对象：R201 主line 的机制 A（CL1）——**Agent 提计划比较；虚拟细胞维护跨计划一致的干预算子；真实反馈统一修订；再改变 Agent 选择**。
本文件只做**形式化与可证伪问题定义**：不运行效果、不拟合预测、不读响应值做效应统计；不声称新颖性/机制/迁移/决策收益。新意**只可能**落在"具体共享对象与更新运算"，一般概念已被 CoMap/LAWM/MDA/COPEx 等覆盖（§8）。

## 0. 对象与边界

- **细胞群体**：固定细胞背景 c 下的功能状态群体（本资源为 O'Neil 组合 viability；仅开发性）。状态用可观测功能读数 y 表征，不主张完整分子状态。
- **计划空间 P**：一个计划 p 是一次可执行干预程序，包含：成员（药物/剂量/角色 anchor vs library）、剂量向量、给药顺序/时点、读出时点 H、读出通道。本资源可支持的最简单计划族：
  - **P-dose**：同一对 (a,b)、同一 4×4 剂量网格上的一行 `(d_a, d_b)`（4 个技术重复为列）；观察值 `y = mean_viability`（或归一化 X/X0；执行期冻结其一）。
  - **P-replace**：把一个成员替换为另一伙伴的同一剂量行，即同一成员 a 在伙伴 b 与 b′ 下的剂量响应（计划对）。
  - **P-program**：多步/时点序列（本资源不支持，仅形式保留）。
- **观测模型**：`y ~ P(Y | p, S, ε)`，S 为共享干预规律，ε 为测量/批次噪声；开发性设计只用 batch1、complete-case、技术重复均值/分半噪声标定；**技术重复 ≠ 独立培养**。
- **不声称**：跨培养/跨端点迁移、真实决策收益、机制、新颖性；不把 O'Neil viability 与 Jaaks ΔEMAX 拼接（§8/§9）。

## 1. 共享干预算子 S

**定义（本文件冻结的抽象层级）**：S 是一个参数化算子族 `S_θ = (f_{m,role}(·), g_{context}(·), h, b_batch, σ_obs)`，对每个计划 p 给出期望读数/矩：
`m(p; θ) = c_p^T m_H(θ)`（`c_p` 为计划效用/读出权重；`m_H` 为 1..H 步矩基）。
**共享分量（必须跨计划保持同一取值）**：
1. **成员剂量响应** `f_{a,role}(d)`：同一药物 a、同一角色、同一剂量刻度上，跨伙伴/跨计划必须一致；角色（anchor/library）分开，除非显式声明可交换。
2. **伙伴/背景函数** `g_{b}(d_b)`、批次效应 `b_batch`。
3. **交互核** `h(d_a, d_b)`：预注册族（加性 h≡0；秩 1/2 低秩；参数化 Bliss/Loewe 型）。
4. **噪声合同** `σ_obs`（来自技术重复/分半标定，不假设 MCAR/MAR）。

**假设（写死；违反则本机制不适用）**：
- A1 同一药物/角色/剂量刻度在计划间可比（批次效应可单独吸收；batch1 内开发）。
- A2 计划族共享至少一个可观测分量（成员剂量响应或伙伴函数），且**重叠足以识别**（§4）。
- A3 群体状态在同一计划族内充分（无隐藏历史/顺序效应）；本资源**不支持**顺序/时点计划，故不声称 A3 对程序族成立。
- A4 噪声标定可分辨"联合矛盾"与测量噪声（容差 τ 由技术重复给出）。

## 2. 计划对的联合矛盾

给定数据 `D = {(p, y_p)}` 与算子族 `Θ`：
- 单计划残差 `r_p(θ) = || y_p − m(p;θ) ||`（加权；执行期冻结权重/范数）。
- **单独可行**：`ε_p = min_θ r_p(θ)`；称计划 p 在容差 `τ_p` 下合法若 `ε_p ≤ τ_p`。
- **联合可行**：`ε_{pq} = min_θ max(r_p(θ), r_q(θ))`（或 `min_θ r_p + r_q`；执行期二选一冻结）。
- **联合矛盾度量**（本文件定义）：
  `J(p,q) = ε_{pq} − max(ε_p, ε_q) ≥ 0`
  **计划对 (p,q) 存在联合矛盾** ⇔ 两者单独合法（`max(ε_p,ε_q) ≤ τ`）且 `J(p,q) ≥ δ_J`。
  含义：**各自都能被某个 S 解释，但不存在同一个 S 同时解释两者**。
- **证书/见证**：`θ* = argmin max(r_p,r_q)`，报告其残差结构；对加性族可用闭式（加性一致性条件 `y11+y22=y12+y21` 等）给出"联合不可能"的代数见证；对一般族用半正定/矩/SOS 或区间证书（不声称这些数学是新的）。
- **决策层矛盾**：`V_p = {m_H(θ): θ∈M_p(τ)}`（`M_p`=单独可行集），`V_{pq} = V_p ∩ V_q`。若 `V_p,Q` 非空但 `V_{pq}` 为空 → **联合矛盾**；或 `V_{pq}` 明显收缩 → 报告**最坏后悔区间宽度差** `ΔW(p,q) = W(V_p)+W(V_q) 的单计划界 − W(V_{pq})`。
- **为什么必须"同一世界"**：分别取 `sup` 与 `inf` 再相减会给更松/不可达的界；联合集合 `V` 的支撑函数 `h_V(d)=sup_{v∈V} d^T v` 才是同一世界下的计划差界。最坏简单后悔 `R(p) = max_q h_V(c_q − c_p)`（限于声明程序集与同一终局效用尺度；不是完整自适应策略/Bayes 后悔保证）。

## 3. 可辨识条件（联合矛盾可检验的前提）

1. **重叠/连通**：共享分量（如 `f_a`）必须在 ≥2 个计划中以 ≥2 个不同剂量水平/伙伴上下文出现；否则单独拟合可吸收任意差异 → 无约束力。
2. **角色与刻度对齐**：同一药物在 anchor/library 角色下的函数分开；剂量刻度（µM vs 相对 IC50）必须同一或显式变换；角色不可交换性写死。
3. **Gauge 固定**：加性族存在平移自由度（`f_a + t, g_b − t`）；固定参考剂量/角色基线；交互族固定尺度/符号 gauge。未固定的 gauge 不能当"矛盾"。
4. **有效观测数 > 参数数（过识别）**：设计矩阵满秩之外的**过识别度** `over = #obs − rank`；`over ≥ 1` 才可能有联合约束；`over = 0` 时任何数据都能被某 θ 精确解释（无检验力）。
5. **约束非矩形**：若参数空间是矩形且每个计划可独立选 θ，联合矛盾测不到；必须要求同一 θ（或显式声明的耦合约束，如质量守恒/秩约束）→ 联合可行集一般非矩形。
6. **噪声容差**：`τ` 由技术重复/分半给出，不假设 MCAR/MAR；`J > τ` 才可由数据支持，否则只记 `evaluation_cannot_distinguish`。
7. **充分状态/无隐藏历史**：同一计划族内不假定平稳 Markov；顺序/时点程序需另立资格（本资源不支持）。

## 4. 反事实查询与决策选择

- **反事实查询**（未测计划 `p*`）：集合值预测 `V(p*) = {m(p*;θ): θ ∈ M_joint}`；报告区间/支撑函数；单点预测不主张。
- **决策**：候选计划集 `Q`；稳健选择 `p_hat = argmin_{p∈Q} R(p)`，`R(p) = max_{q∈Q} h_V(c_q − c_p)`；top-k 按 `R(p)` 排序（k=1,3,5 预注册）；**后悔** `regret = R(p_hat) − min_{p∈Q} R(p)`（模型内界）；评估期用留出计划实测效用计算 realized regret（执行期冻结效用尺度）。
- **双预算**（方向 2 接口）：Agent 在"继续计算缩小 V"与"真实实验收紧 M"之间分配；每步记录计算成本（求解/证书/重认证）与真实成本（wells/plate/轮次）；决策规则预注册（如：若计算可把 `R` 区间宽度降到 <δ 则不再实验；否则买最有 VoI 的计划对）。**求解/认证全部计费**。
- **更新运算**（机制 A 的"新意候选点"）：反馈 `(p, y_p)` → 统一修订 `M ← M ∩ {θ: r_p(θ)≤τ_p}` → 所有复用该分量的计划边界同时更新 → 重算 `V`/`R` → Agent 重新比较受影响计划。**"统一修订"= 一次反馈改所有共享该分量的计划，而不是逐点更新/逐计划重训**。

## 5. 具体矛盾例子（构造/纸面，非数据发现）

### 例 1（群体观测：单步边缘相同、联合不可能；来自本组 candidates_v3 构造）
两状态群体 µ=(1/2,1/2)，计划 A(p)=[[1−p,p],[p,1−p]]，B 把群体制备到第一状态。所有 p 下 A 的单步边缘相同；BA 的第二状态比例 = p，BAA = 2p(1−p) ≤ 1/2。分别看：BA=0 合法（p=0），BAA=1/2 合法（p=1/2）；但**联合要求同 p** → 同时取 BA=0 与 BAA=1/2 不可能。单独区间/单计划拟合会允许，联合集合排除。
**读法**：这是"同一 S（同一 p/同一核）跨计划"的最小代数例子；说明"分别合法"不等于"联合可行"。

### 例 2（4×4 剂量网格：成员剂量效应跨伙伴必须一致）
取加性算子 `y(pair(a,b); d_a,d_b) = f_a(d_a) + g_b(d_b)`（无交互），剂量网格 2×2 简化。
- 计划 p1 = (a,b)：`y11=1, y12=2, y21=3, y22=4`。加性一致性 `y11+y22 = y12+y21`（5=5 ✓）→ p1 单独完全可由加性 S 解释，且推出 `f_a(d2)−f_a(d1) = y21−y11 = 2`。
- 计划 p2 = (a,b′)：`y′11=1, y′12=2, y′21=4, y′22=5`。加性一致性 `1+5=2+4`（6=6 ✓）→ p2 单独合法，但推出 `f_a(d2)−f_a(d1) = 4−1 = 3 ≠ 2`。
- **联合矛盾**：不存在同一个 `f_a` 同时满足 p1、p2（`J = ε_{p1p2} > 0`；单独 `ε_p1=ε_p2=0`）。这就是"各计划单独合法、无法由同一 S 产生"的最小剂量网格例子；执行期用噪声容差与重复标定把"矛盾"和"测量误差"分开。
**读法**：可检验性来自同一成员（a）在不同伙伴上下文中的剂量效应重叠；若两计划不共享成员/剂量水平，则不可识别（§3.1）。

### 例 3（角色/低秩交互：秩约束下的跨计划不可能）
预注册秩 1 交互 `h(d_a,d_b)=λ u(d_a)v(d_b)`。两对共享成员 a 但伙伴 b,b′：p1 单独可用某 `(f_a,u,v_b)` 解释，p2 单独可用另一 `(f′_a,u,v_{b′})` 解释；若两对都要求**同一** `f_a` 且**同一** `u`（成员交互方向），则 `(u,v_b)` 与 `(u,v_{b′})` 的比值约束把两对的观测绑在一起；构造使 p1 需要 `u(d2)/u(d1)=1`、p2 需要 `=2`，则联合不可能而单独可行。
**读法**：联合矛盾的"力度"依赖交互族的结构约束；族越灵活（参数越多）越难矛盾——因此资格审计必须报告**过识别度**（§3.4），不能只报"能拟合"。

## 6. 可证伪问题（本轮不执行）

**H_A（主假设）**：在 O'Neil complete-case/batch1 开发资源上，对预注册的共享算子族 S（成员剂量响应 + 加性/秩 1 交互 + 角色分层 + 噪声容差），
1. **存在层**：存在计划对 (p,q)（同一细胞、同成员/同剂量重叠、不同伙伴或不同剂量行）满足单独合法且 `J(p,q) ≥ δ_J`；且联合可行集相对单计划界把最坏后悔区间宽度收缩 ≥δ_W（δ_J, δ_W 预注册）。
2. **学习层**：Agent 按计划差选择"区分性计划对"、模型**统一修订**共享算子后，在**同信息/同预算**（真实 wells + 计算成本合计）下，对未测计划/未测剂量组合的决策排序（top-k/后悔）不劣于强基线；若 MDE 允许，要求严格优于基线（见 DESIGN_A 的功效门；本资源 30 细胞很可能只能 `evaluation_cannot_distinguish`）。
**可证伪**：若在预注册容差/族下**不存在**计划对满足 1（例如过识别度不足、J 不超噪声、或所有差异被 gauge/批次解释）→ 机制 A 的核心前提在本资源不成立，停止该资源上的效果实验（记录所需测量）。
**竞争解释**（必须排除）：普通全局 solver/共享参数后验/约束生成/全历史重训/层级/GP/随机计划选择在等预算下等效；增益只来自多取数据或只纠正已测点；联合约束只收紧已测点不改变未测计划选择。

## 7. 与先例的关系（不声称新颖性）

- **CoMap**：policy 与 world model 共同更新、有真实完整下一状态教师 → 覆盖"模型+策略共同更新"一般概念。
- **LAWM**：状态/动作/动力学/真实动作解码器联合学习 → 覆盖"动作-状态联合"一般概念。
- **MDA**：机制模型池、结构后验、VoI、query-sufficient 摘要 → 覆盖"任务摘要/机制后验/决策价值"。
- **COPEx**：动态约束、预算、scenario-tree 规划 → 覆盖"约束生成/实验设计"。
- 其他：非矩形鲁棒控制、部分识别、矩/SOS、分离 oracle、列/约束生成、Bayes-adaptive design 都是既有数学。
- **本机制唯一可能的具体新意**（未认证）：把"**多个计划必须共享同一干预算子**"作为**模型与 Agent 的共同监督对象**，用**计划对的联合矛盾**作为可认证的查询信号，并做**一次反馈统一修订所有共享该分量的计划**；以及把"计算歧义 vs 数据歧义"分开计费（方向 2 接口）。**不主张**这些运算未被类似方法覆盖——须由独立挑战/P 方向核验；失败类别与停止条件下，一般方法等效即撤回算法主张。

## 8. 边界（写死）

- 仅开发性：O'Neil viability；技术重复 ≠ 独立培养；batch3 全失；702 个 15 行 pair-cell；无单药/双药参照（单药工作簿未读、需另立资格）；non-blind/peeked（ON3 QUICK 已见，继承披露）。
