## 1. 主假设（每轮一个可证伪假设）

**H_A（主）**：在 O'Neil 开发资源上，预注册的**共享干预算子族 S**（成员剂量响应 `f_{a,role}` + 伙伴函数 + **秩 1 交互** + 角色分层 + 噪声合同）存在**可检测的联合矛盾**：即存在计划对 (p,q)（同一细胞；同成员/角色/≥2 共同剂量水平；不同伙伴或不同剂量行）满足
（i）二者单独在噪声容差内合法（`max(ε_p,ε_q) ≤ τ`）；
（ii）联合不可行 `J(p,q) = ε_{pq} − max(ε_p,ε_q) ≥ δ_J`（预注册）；
且（iii）联合可行集把**最坏简单后悔区间宽度**相对单计划界收缩 `ΔW ≥ δ_W`。
**H_A 可被证伪**：若在预注册容差/族下**没有任何**计划对达到 (i)+(ii)（或达到比例低于预注册下限），或 (iii) 的收缩低于 δ_W，则机制 A 的"联合矛盾可被计划差识别"前提在本资源**不成立** → 停止本资源上的效果实验，记录所需测量。

**H_A2（次，仅条件通过后）**：Agent 按计划差选择"区分性计划对"、共享算子**统一修订**后，在**同信息/同预算**（真实 wells + 计算成本合计）下，达到预注册**模型内后悔界收紧目标**所用的真实 wells 少于强基线（含随机计划对选择、同信息全局求解、共享参数后验、约束生成、全历史重训、层级、GP、决策 AL）。
**H_A2 停止条件**：任一强基线在等预算下等效 → 撤回"新共同学习算法"主张（保留形式/资格成果）；只改善已测计划 → 停"反馈迁移"主张；预测/界改善但决策排序无变化 → 停"决策创新"主张。

## 2. 预注册算子族与估计量（实现细节冻结）

- **观测**：`y(p) = mean(viability1..4)`（或 `X/X0`；**执行期二选一冻结**；本轮不选）。P-dose 计划 = 4×4 网格的一行 `(d_a,d_b)`（4 wells）；P-replace 计划对 = 同成员/角色/剂量在 ≥2 个伙伴上下文中的行。
- **可用数据**：仅 `complete-case` 行（viability1–4 全非空，363,090/368,832=98.44%）；batch1 357,876；**702 个 15 行 pair-cell 排除**（不完整网格）；不插值/不外推；k=1 行不参与标定。
- **噪声合同**：`σ_obs` 由 batch1 **技术重复分半**标定（每行 4 重复 → 2+2 分半；同 cell/pair/dose 位），`τ = z_{0.975}·σ_pair`（`σ_pair = σ_obs·sqrt(2/4)`）；另报告 per-cell/配对的异方差（不假设 MCAR/MAR）。
- **算子族 S（预注册，家族选择不得按结果换）**：
  - S-add：`y = f_{a,roleA}(d_a) + g_{b,roleB}(d_b)`（4+4 参数/对，gauge 固定参考剂量）。
  - S-r1：`y = f_a(d_a) + g_b(d_b) + λ·u_a(d_a)·v_b(d_b)`（秩 1 交互；乘积 gauge 固定）。
  - S-r2（敏感性）：秩 2 交互。
  - 角色分层：同一药物在 A/B slot 分开（不可交换）。
- **联合矛盾**：`ε_p = min_θ r_p(θ)`；`ε_{pq} = min_θ max(r_p,r_q)`（主；`min_θ r_p+r_q` 作敏感性）；`J = ε_{pq} − max(ε_p,ε_q)`；**检测标准**：`max(ε_p,ε_q) ≤ τ` 且 `J ≥ δ_J`。
- **δ_J 与 δ_W（预注册；先于任何效果计算）**：`δ_J = τ`（即超出 95% 噪声界）；`δ_W = 0.05·(效用归一化范围 1.0)`（与 δ_min 同尺度）。
- **反事实与决策**：`V = {m_H(θ): θ∈M_joint}`；`R(p) = max_{q∈Q} h_V(c_q − c_p)`；候选集 Q = 留出计划（见 §4 切分）；决策排序 top-k（k=1,3,5）/简单后悔。

## 3. 比较器（同信息/同预算/同成本；全部计费）

| id | 比较器 | 说明 |
|---|---|---|
| C0 | 常数/均值 | 基线 |
| C1 | **同信息全局求解**（joint solver over all plans） | oracle 级强对照；非免费教师 |
| C2 | 共享参数后验（层级贝叶斯/经验 Bayes） | 共享结构但无计划差查询 |
| C3 | 标准约束生成（COPEx 式） | 动态约束/场景树 |
| C4 | 全历史重训 | 每次反馈后重拟合 |
| C5 | 普通层级模型 | 无共享算子联合约束 |
| C6 | GP/核方法（同特征） | 非参数 |
| C7 | 决策主动学习（VoI/BOED） | 选最有信息量计划 |
| C8 | 随机计划对选择（等预算） | 检验"主动选择"是否必要 |
| C9 | 静态最佳预测器 + 优化器 | 无共同学习 |

**H_A2 的主比较**：`M*（共享算子 + 计划差选择 + 统一修订）` vs `C7`（同预算主动学习，最强竞争）与 `C8`（随机选择，检验计划差增益）；其余 C0–C6/C9 作同预算对照与多重性预指定。
**等信息**：同一 prior 数据（batch1 complete-case 训练行）、同一反馈预算（wells/轮次）、同一计算上限；**不得**给 M* 额外特征/预算/或把求解、证书、重认证成本漏计。
**预算 cap（可核查）**：两轮 × 每轮 ≤16 个计划对（每对 8 wells = 1 个剂量行 ×4 重复）→ 真实预算 ≤256 wells/arm/fold；计算 ≤20 配置、内层 5 折、≤2 CPU-h/arm、≤8 GB；报告逐臂配置数/wall/CPU。超限 → `design_invalid: compute_budget_exceeded`。
**双预算规则**：每步先算"继续计算把 `R` 区间宽度降到 <δ_W 的期望成本"；若计算成本未超 cap 且预期可降到 <δ_W → 继续计算；否则花 wells 买最有 VoI 的计划对；两类成本都入表。

## 4. 切分、覆盖与防泄漏

- **5 折 × 6 细胞（target30，seed 预注册 20261028）**：训练细胞与留出细胞不相交；留出细胞不进任何训练/选择。
- **留出计划**：每折从留出细胞中留出**整 pair-cell**（4×4 网格整块）与**剂量行**（P-dose）；留出对象在训练中不得出现（含其 member 剂量行）。
- **覆盖门**（先于打分）：每折留出计划数 ≥ 预注册下限（按资格审计：每细胞 ~565 pair-cells、~11,600 plan pairs → 每折 6 细胞留出 ≥ 200 pair-cells 可行；具体阈值预注册）；每折训练中可出现该 member 的其它伙伴上下文（否则不可识别）。
- **泄漏审计**：留出 pair-cell 的 wells 不进训练；batch3 不进；单药工作簿不读；Jaaks 不拼接；技术重复只用于噪声标定不作独立单元。
- **说明**：同一 pair-cell 的 16 行共享 wells 与 batch；留出必须按整 pair-cell/剂量行分组，不做随机 well 留出（否则闭包/同 wells 泄漏 → `design_invalid: leakage`）。

## 5. 主/次终点与预注册功效

| 终点 | 定义 | 预注册门 | 结论允许 |
|---|---|---|---|
| **P1（primary）** 联合矛盾存在性 | 满足 (i)+(ii) 的计划对比例/数（每细胞、每折；pooled 描述） | 预注册：在预注册 S-add 下，**≥5 个细胞**各出现 ≥1 个 `J≥δ_J` 计划对，且 pooled 计划对比例 ≥1%（阈值看资格后冻结；不得事后改） | 仅"本资源/本算子族下存在联合矛盾"（开发性） |
| **P2（primary-2）** 界收紧 | `ΔW`（joint vs per-plan 最坏后悔区间宽度） | 每折 ≥ 预注册数目的计划对满足 ΔW≥δ_W=0.05；pooled 中位 ΔW≥δ_W | 仅"联合约束改变可达界"（开发性） |
| **P0（门槛）** 可识别/噪声 | 每细胞 additive 设计 over-id ≥ 预注册下限（资格审计：median 8,745）；噪声标定 `σ_obs`/`σ_pair` 有限 | 不达标 → `design_invalid: coverage/identifiability` | 不得进入 P1 |
| **S1（secondary）** 决策排序 | 留出计划的 top-k 精度 / 归一化后悔；cluster=cell | **MDE 门**：`MDE80_rank=0.7625`（30 cells）> δ_min=0.05 → **`evaluation_cannot_distinguish`**；top-k MDE 0.33–0.36、regret MDE 0.10–0.26 同样 >δ | **只作描述性**；不得写决策收益 |
| **S2（secondary）** 算法/预算 | 达到 ΔW/后悔界目标所需 wells 与计算成本（active vs C7/C8） | 等预算；预注册"非劣/优"规则 | 条件性；任一强基线等效 → 撤回主张 |

**δ_min=0.05**（归一化效用尺度；operational 定义同前轮：秩信息/决策排序最小有用差异；不是决策效用阈值）。**MDE**：`MDE80 = 2.801585×SD_cluster_bootstrap(Δ)`（cluster=细胞），资格审计已给出规划值：rank 0.7625、top-k 0.33–0.36、regret 0.10–0.26（SD 0.2–0.5）→ **均 >δ_min → 决策终点不可认证**；若未来要求决策认证，需 ≥6,283 独立细胞（δ=0.05）或 ≥1,573（δ=0.10），或预先声明放宽 δ。
**因此本设计主终点是 P0→P1/P2（形式/一致性，开发性），S1 仅描述性；决策/迁移主张**不在本设计内**。

## 6. 零模型与负对照（预注册）

1. **计划内/行内置换**：在每 plan 内置换 wells（保 mask/剂量位），重算 J 分布 → 校准 `P(J≥δ_J | H0)`。
2. **算子打乱**：随机置换成员身份/角色（破坏跨计划共享），验证 J 升高来自真实共享结构而非自由度。
3. **随机计划对选择（C8）**：等预算下与主动选择比较 → 检验"计划差选择"本身的价值。
4. **同资源换端点/半拆分**：用 technical-replicate half split 构造"无真实差异"数据 → 估计假阳性 FPR；不把 ΔEMAX 拼入。
5. **零约束对照**：只用每计划独立拟合（no shared θ）→ 应给出更宽/更松界；联合约束只有相对它收紧才算 P2 有效。

## 7. 失败类别与停止条件（冻结）

- `data_unavailable`：资源/覆盖/单药参照缺失且无法在开发性下运行（当前资源合格，预期不触发）。
- `design_invalid: identifiability/coverage`：P0 不达标；`design_invalid: leakage`：泄漏审计失败；`design_invalid: compute_budget_exceeded`。
- `evaluation_cannot_distinguish`：决策终点 MDE>δ_min（**本资源预期**）或 CI 不能分辨 δ。
- `no_joint_contradiction`：P1 不达标（**H_A 被证伪** → 停效果实验、记录所需测量；不写"矛盾不存在"的普遍结论）。
- `no_increment`：H_A2 中 M* 在等预算下不优于 C7/C8（相应主张撤回）。
- `no_decision_benefit`：P1/P2 通过但 S1 决策排序无变化（停决策创新主张）。
- **停止条件写死**：上面任一触发即停对应主张；不得换δ/切分/族/预算/终点；同一资源上不得重跑"改阈值版"；阴性 ≠ 不存在。
