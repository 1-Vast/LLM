# CL2 分支决定：保留问题，暂停统一生成的效果实验

2026-10-28。本文件是本 episode 的独立分支判断，不修改冻结的 CANDIDATES_v3，不构成 v4。只核本地原文、已有数据资格和数学关系；0 联网、0 训练、0 外部模型 API 调用、0 新实验。未读取 sealed 结局或 PRISM 效果矩阵。配置继承父任务，effective_model unknown；没有再次委派。本判断不是对自己新提案的独立复审。

**决定：当前不启动 CL2 训练或闭环。** 有价值的条件问题是：在真实的大组合/剂量菜单中，为不断变化的细胞背景和功能约束选择合法干预时，联合学习能否在有限反馈与总计算预算内，更快找到经独立功能确认的可行解。现有证据尚未说明这个工作负载真实存在，也未证明本地数据能验收它。单纯双向生成、共享参数、同模型复核均不足以重启；这不是生物机制已被否定。

## 有价值的问题，以及目前无法归因的部分

面对大量**实际可执行**的组合/剂量与持续变化的背景，研究团队可能需要在稀少真实测量下找到满足疗效、毒性或其他功能约束的候选集合。若穷举一次都超出实际决策时限，且背景/模型更新使既有缓存失效，摊销的逆推断可能把这项工作变得可行。可用输出是合法候选、实际成功率和所需计算，不是生成一段药理理由。

联合分布也可能保留对多目标选择关键的依赖。一个纯推理例子：两种动作的疗效 E 与安全 S 均有边际成功率 1/2；动作 a 的实测结局类型若是 `(1,1)/(0,0)` 各半，动作 b 若是 `(1,0)/(0,1)` 各半，则 `P(E=1,S=1|a)=1/2`、对 b 为 0。独立边际头会把二者都算成 1/4。这里真正重要的是同一实验单位上的联合功能，而非 token 形式。**相关多输出前向模型和普通联合生成模型都可正确区分，不能用独立边际弱基线证明 CL2。**该例未模拟、未观察到于本地数据。

有限反馈同时更新动作提案与细胞响应，是一种可实现的学习路径；是否超过共享多任务仍是经验问题。把自然语言目标转成可检验事件的接口若固定，同一事件定义必须提供给所有方法；不能给 CL2 独享目标知识，再称其推理更好。

## 最强替代解释：已知的逆推断与普通共享学习

记训练后前向成功概率为 `f_G(a,c)=P(Y∈G|do(a),c)`，参考菜单分布为 q0。冻结 v3 的目标就是

`q*(a|G,c) = q0(a|c) f_G(a,c) / Σ_a' q0(a'|c) f_G(a',c)`。

如果可穷举、条件识别成立且用同一个 f，枚举能精确得到目标。逆向提案没有额外药效信息；它是对已有运算的摊销近似。目标条件采样也不等于最大化效用：有限 shortlist 的重复样本和多样性成本必须计入。

若把这个相容的 q 用作逆监督，单条 loss 为 `−log f_G(a,c)+log Σ_a' q0(a'|c)f_G(a',c)−log q0(a|c)`。这可以引入跨动作的相对成功约束，但标签仍来自同一批真实结局。允许相同标签与目标的共享多任务/对比学习也能获得该约束。相反，任意 mask 下共享 theta 并不自动令各条件严格相容。不能把不相容解释成新的学习原理。

**重复目标本身也不保证摊销优势。**同一背景、同一模型下，强前向基线可以一次批量计算每个动作的多变量预测/样本并缓存；换目标只重算事件或效用。比较账本应为：

`C_enum = T_f + Σ_背景或更新版本 C_批量前向全菜单 + Σ_目标 C_缓存事件筛选`；

`C_joint = T_joint + 所有更新 + Σ_目标(C_逆生成 + C_合法性/去重 + C_前向复核)`。

两边都计训练、调参和失败生成，缓存与向量化同等开放；生成大量不参与决策的状态 token 也计成本。还须比较同预算 beam/CEM/局部搜索。若真正优势只是这张账本更小，它是有条件的推断效率贡献，不是新增生物机制或新逆向决策原理。

对“共享多任务”的定义必须可检验。若它获准用同一 backbone、同一 mask、同一损失和相同输出头，便包含 CL2；这两者没有可独立比较的机制差异。只有事先限定两者不同的、不能靠命名区分的运算，才有算法归因试验。当前不能假定联合生成天然优于这个强模型类。

## 重启所需的数据与信息合同

1. **对象和实验单位：**冻结背景 C、实际动作 A（药物/组合、剂量、时长、载体、顺序）、用药前 Z_now 和 H。Z_next 与外部功能 Y 的对应须有源行、协议、批次/培养/供者和可追溯 hash。不同单位的群体读数只能按核定的条件级分布建模，不拼出不存在的同细胞配对。无正常细胞/毒性配对就不声称治疗窗。
2. **功能与合法菜单：**Y 是真实测量的目标功能，G 与效用在看隐藏结局前固定；RNA、磷酸化、模型生成值不替代 Y。组合与剂量取实际测过或可执行协议，不能靠虚构组合、细分相同剂量或重复 ID 扩大动作数。当前固定反馈试验只在有真实结局可验收的菜单评价，不向未测组合外推效果。
3. **选择与支持：**确认随机化/可说明的混杂控制及行为分配 b；q0 的正支持须在 b 支持内。按 v3 参考加权合同提供全部方法同样的分配信息；未知 b、零支持或不可接受权重方差时不执行原合同。排除 sealed ID 只沿用资格文件的筛除结果，不打开 sealed 结局。
4. **可见性与预算：**前向看实际 A、不看目标终值；逆向只看已冻结 G。测试阶段的 Z_next/Y、检索材料或目标示例不进入训练/选择。所有方法获得相同知识、状态、响应标签、目标事件标签、真实反馈；mask 增广和重复使用数据也计计算。按真实 assay 单位计查询成本，整板不能拆成免费单孔反馈。
5. **独立验收：**整化学实现/整组合组留出，并把整背景迁移作为独立问题；不随机拆孔或细胞。独立功能评价面板不由提案器挑选；若做 prospective shortlist，所有方法候选的并集按同预算方案接受真实测量。CI 按独立培养/供者聚类；阈值重用、重复目标与孔数不能冒充独立样本。样本数与实用差异阈值在源表、方差和决策时限核齐后再冻结，本轮不编造。

## 唯一值得重启的最小试验结构（尚不可执行）

先要一份合格、源表冻结的动作—状态—联合功能面板，以及真实的菜单规模/目标查询频率/缓存失效率与时限。随后只做**固定反馈的一次共同更新**，不引入主动选点：所有方法使用同一初始记录及同一批新真实反馈，预测/候选只在此前隐藏、非选择性面板验收。训练和推断总预算、目标集、留出单元与实用差异预先冻结；不能用多次闭环或新模块挽救结果。

必要比较为：(J) 冻结 v3 的统一模型；(E) 取 J 的同一前向模型做批量枚举与缓存，隔离逆推断本身的成本/误差；(F) 同总预算训练的强相关多输出前向模型，允许缓存与 beam/CEM，防止 E 继承 J 的额外训练成本；(M) 同信息/监督/容量/总计算的共享前逆多任务模型，允许联合功能依赖，隔离普通参数共享。M 若与 J 运算等价，取消这项算法比较并记录不可区分，不人为削弱 M。分开前逆模型可作归因辅助；GP/决策 AL 的原 v3 闭环比较须等固定反馈证据通过后另行冻结，不在本轮偷换成已完成比较。

同一实验同时看：新反馈后隐藏面板的前向适当评分/校准，以及候选实际功能命中或效用在总计算预算下的变化。前逆吻合只作合同检查。若 J 胜 E 但不胜 F/M，最多保留特定实现的摊销效率；若只有前向更准而无实际候选收益，不支持药物决策贡献；若候选收益来自不同反馈、隐藏结局或目标先验，结果无效。只有超过 F 和 M 的预定实用界限，并通过独立功能验收，才值得再问联合学习为何有效；这仍不是语言推理或机制发现的证明。

## 反例、停止和再启动证据

- **低成本小菜单：**前向全量评分一次即可完成；统一逆模型增加训练和去噪成本。停止“逆向必要”主张。
- **同背景反复换阈值：**缓存的联合预测可直接重筛；重复目标没有摊销交叉点。停止用目标数替代真实负载证据。
- **少量单药推未测组合：**多个协同/拮抗机制在已有记录上同样拟合；联合生成不能制造缺失干预信息。没有独立组合结局就不评分这一主张。
- **行为偏倚或目标泄漏：**逆模型学到常测/高频动作，或让前向看到目标功能终值，形成虚假成功。无法执行参考合同即停止，不把截权重或改阈值当自动修复。
- **不可达目标：**若目标在参考支持内没有成功质量，q 的分母为零；输出不可行/证据不足，不能靠逆生成强行给出“成功动作”。
- **两方向共同乐观：**前向复核全部通过，隐藏功能失败。停止相应成功概率/决策主张，保留负结果，不让模型自造反馈。
- **多任务可复制：**M/F 达到同等功能与成本，或 M 在运算上就是 J。撤共享联合生成的额外算法主张，不改名、加模块、扩大预算。

**再启动需要两份具体证据，而非新的候选文稿：**一份通过上述合同的未 sealed 配对源表与独立验收单元；一份真实工作流的动作规模、重复背景/目标、缓存复用及批量前向/强搜索成本账本，证明存在决策相关的计算或反馈效率缺口。二者到位后冻结一次试验。若只是新增 P100 条件、服务器算力、同模型一致性或文字目标解释，维持暂停。

相较已有逆设计，CL2 继承条件生成/成功概率重加权，尚无新的逆向原则；相较已有主动学习，它在固定反馈阶段不改变测什么，只试图改变记录如何同时支持预测与提案；相较普通多任务，额外价值需要上述不可等价运算与实用收益共同成立。当前支持的是一个条件性研究问题与清楚的停止边界，没有正面算法效果、生物机制或药物收益结果。
