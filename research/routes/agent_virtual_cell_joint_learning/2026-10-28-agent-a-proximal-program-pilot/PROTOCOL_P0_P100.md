# P0：实测信号能否区分处理身份（仅数据资格）

2026-10-28，先于首次P100数值分析保存。它不是共同学习/药物效应实验，不替代长期目标的独立功能决策和迁移。

假设：取得的原始P100表中，去除探针基线后，同一化合物的批内处理重复，其响应谱比其他化合物更相似。原始资源已研究过reproducibility，本轮复核仅确定这些具体原件可否承担后续测量接口；不主张发现新生物机制或算法。

输入：本episode下载回执中的3个GCT，288个样本列；A375/MCF7/YAPC分别独立报告，绝不把PRM/DIA及单板差异当纯背景效应。原始文件不改。既有sealed_compounds.csv只读ID集合以排除对应处理，不读旧效果/confirmation。无法核定药物ID的列不与其他缺失ID连接；DMSO仅为参照。

数值语义：官方CFG的L2X及官方PSP `dry.log_transform_if_needed`/`log_transform`规定，未含L2X的非负数据先log2，0置缺失；不加任意pseudocount。每件文件保留其provenance。若出现负数但未含L2X，停止相关分析并标source_semantics_unresolved。不直接使用已跨全板row-median处理的Level4。当前PSP快照只提供解释，不冒充历史执行版本证明。

计算：先记录各原件维度/校验和、正/零/负/缺失数和重复单位；选三件共有且manual suitability=TRUE的探针，不从数值强弱挑探针。对每板各探针，用三份DMSO的log2均值作基线得到处理响应。每个化合物保留3份批内重复。共同有限探针少于20的两谱不算相关。每药计算3组重复间Spearman均值，减去同板与所有其他可用化合物谱的Spearman均值；每药作为一个描述单位，不把探针/孔当独立生物样本。

报告：各板的有效药数、同药/异药相关、平均差及1000次化合物重采样的2.5–97.5%区间，seed=2026102801。该区间是固定板/已选药面板的重采样敏感性，**不是独立培养或跨细胞生物95%CI**。三板不合并求显著，不以p值筛背景。正结果仅说明测量含处理相关信息，不能说明“同靶点等作用”、完整机制或实际功能。

同信息参照即同板不同药的响应谱；不训练预测器，因此不伪称完成强预测器/GP/决策AL比较。后续若检验CL1，普通程序网络、自由潜码+相同辅助标签、充分重训练、层级/GP和取证对照仍须按单独协议执行。

停止条件：源语义不清、原文件hash不符、重复键不成立则停止该件；无有效同药/异药差则暂停把该观测作程序锚，不换归一化/阈值挽救。不因P0通过启动功能模型：现有精确剂量交集若不足两种可比程序实现，仍只记data_not_qualified。预算CPU<60s/wall<120s/内存<1GB、0训练、0wells、0外部模型API。仅执行一次，保存不利结果。
