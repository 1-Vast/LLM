# 跨领域“错误来源辨识 + 最小区分观测”方法图

**用途。** 这是一份面向 Agent × 虚拟细胞药物发现的定向先例图，不是完整综述，也不构成候选方案的新颖性证明。这里的“区分观测”指：在一组仍可解释当前失败的模型/错误假设中，选择一个输入、干预或测试，使候选集合发生可检验的分裂；普通的 Bayesian model comparison、泛化性能评估或单纯增加测试数量不自动满足这一条件。

**检索边界（2026-10-30）。** 本轮使用 OpenAlex（4 组定向检索 + 1 次 DOI 批量题录）和 Crossref（3 个题名检索），共 8 个逻辑公开请求，未下载全文，未运行代码；实际阅读范围是 OpenAlex 返回的 CheckList 摘要、Crossref 返回的题录，以及已知论文的方法定位。原始记录见临时检索工作区 [`research/_tmp_crossdomain/00_index/searched_queries.tsv`](../_tmp_crossdomain/00_index/searched_queries.tsv)、[`done_commands.tsv`](../_tmp_crossdomain/00_index/done_commands.tsv) 和 `raw/`。因此，除 CheckList 外，下面的条目均标注为题录/方法级待全文核验。

## 机制分层

1. **差分测试（DeepXplore）**：先找“模型之间不一致”的输入。它提供了候选反例生成器，但不回答不一致来自表示、标签、测量还是外推层。
2. **行为测试（CheckList）**：先由专家列出能力和预期关系，再系统地产生测试。它能把黑盒失败归因到行为切片，尚未形成按信息增益排序的最小实验序列。
3. **故障诊断（机器人 FDI）**：残差和故障签名直接把观测映射到已定义的故障源。它最接近“错误来源辨识”，但依赖固定模型、故障字典和传感器布置。
4. **干预等价类（GIES）**：干预改变可识别性边界，明确区分“当前数据下不可辨识”和“加入哪类干预后可辨识”。它给出虚拟细胞候选中“观测必须改变哪些机制预测”的因果语言，但不等于主动最小成本策略。

因此，本候选要超出普通 Bayesian model comparison/VOI，至少需要同时满足：

- **错误源显式化**：候选不是只有参数值，而是包含模型层（表示、机制、观测/批次、外推域等）的离散假设；
- **观测可证伪**：每个候选对候选实验的反事实读出分布不同，且能写出方向/不变量/交互项等可检验预测；
- **最小化规则**：下一观测按预先声明的假设分区、成本和安全约束选择，而不是按总体不确定性或预测熵泛化排序；
- **停止条件**：当剩余候选在行动决策上等价，或达到预注册的区分阈值/预算时停止；记录仍未区分的等价类。

## 与相邻术语的判别

| 方法族 | 典型目标 | 何时仍不是“错误来源辨识 + 最小区分观测” |
|---|---|---|
| Bayesian model comparison | 在固定模型集合上用已有数据更新后验/证据。 | 模型只表示参数或预测器，未把表示、机制、读出、批次、外推等错误层作为假设；没有选择下一观测来分裂这些假设。 |
| VOI / Bayesian experimental design | 按期望效用或信息价值选择下一次查询，并计入成本。 | 价值函数只奖励总体预测精度或后验熵下降；若不同错误来源仍给出同一行动，VOI 不会强迫它们被区分。 |
| Active learning | 选择输入或标签以改善预测风险/决策边界。 | 查询目标没有“哪个错误源能解释失败”的结构；得到更多标签不代表知道是模型层、测量层还是分布外层出错。 |
| Multi-fidelity / cheap-to-expensive | 先用低成本近似测量，再把资源集中到高保真测量。 | 只是在成本上分层；若低、高保真差异没有显式误差来源模型，仍不能说明模型分歧来自机制还是 fidelity bias。 |
| 真正的错误来源辨识 | 候选包含离散错误层，观测在候选间产生不同可证伪预测，并按成本选择能最大化候选分区的最小序列。 | 需要报告未区分的等价类和停止规则；单纯性能提升、熵下降或测试数增加都不够。 |

## 可供虚拟细胞试验的“最小区分观测”模板

下面是从先例抽象出的候选机制，不是已经验证的科学结论。每一行都必须在真实数据上预注册并保留“无法区分”的结果。

| 待区分错误来源 | 一次尽量小的观测 | 可证伪的分裂信号 | 对应先例 |
|---|---|---|---|
| 机制交互项遗漏 vs 单药/剂量噪声 | 固定细胞背景，补测一个低成本的交叉剂量点或时间点 | 只有交互模型预测非加和方向，且重复测量误差不足以覆盖差异 | GIES 的“干预打破等价类” + 机器人残差签名 |
| 细胞状态外推失败 vs 读出层偏差 | 同一处理在一个已知状态和一个边界状态上重复同一读出 | 两候选对状态迁移的相对排序相反；若只改变批次而排序不变，则不支持纯读出偏差 | CheckList 的 directional/invariance 测试 |
| 表示/特征遗漏 vs 模型参数不稳 | 选择能使候选模型预测最大分歧的一个药物-细胞组合，再测一个正交读出 | 只有表示缺失模型在正交读出上失败；若所有模型同向失败，不能归因于模型层 | DeepXplore 的差分测试（但需加正交读出） |

## 结论边界

- 这些工作共同支持“把失败拆成候选来源，并用定向观测缩小可行集合”这一**方法学方向**。
- 本轮未找到一篇同时具备“虚拟细胞药效模型 + Agent 自主选择最小观测 + 模型层错误归因 + 成本约束停止”的原始论文；这只能写成**本轮定向检索未见**，不是“首次”或新颖性证明。
- 机器人条目和 DeepXplore 的具体实现细节仍需全文核对；在补全文前，不应据此声称算法已被迁移或性能优于 Bayesian model comparison/VOI。
