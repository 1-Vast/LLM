# 多代理实证续轮：单检查点线性迁移的混合结果

2026-10-28。长期目标仍为 **active / not achieved**。本轮从[前轮三分支探索](../2026-10-28-agent-a-mechanism-branches/report.md)的静态数据入口推进到一次实际预测实验：当前单检查点线性增量配置没有稳定超过简单对照，预注册判决为 **mixed_or_inconclusive**。这不是整个Agent×虚拟细胞方向失败，也不是任意单检查点表示不可能；更没有建立新算法、独立药物决策收益或未见细胞迁移。

数值已被另一代理用独立软件实现复现；它的原进程在拟合和保存预测后发生资源采集错误，因此**数值复现通过，整体执行/资源验证未全通过**。不把这个实现错误计作生物阴性，也不以数值相符掩盖错误。

**实际做了什么。** 两名来源代理分别核查原DOCX/作者条件索引和探针/端点，不读响应值及对方输出。独立新上下文代理审查v1，指出索引假设、函数类主张、跨组标签交叉及实现公式歧义；保留初判后冻结[v2协议](PROTOCOL_v2.md)，一次实质修订完成受限复核。协调者先[冻结14件输入/代码SHA](input_freeze.json)，再一次运行四组五方法。另一新上下文代理先保存自己的全部预测，再读取协调者代码和结果核对。实际代理、请求配置和暴露边界见[团队记录](team_record.json)，资源及预算见[usage](usage.json)和[执行收据](execution_receipt.json)；代理一致本身不作科学证据。

**数据资格没有被分数倒推解决。** 89×99建模矩阵按exp行/node列解释仍是明示假设，未恢复原导出代码。原补表实际有88条条件，缺45；按显式单药行序锚可与作者88条标签一致对应，不补造第45条。8药与4药的剂量数值缩放不同，只保留原token，不认证物理剂量。39项比较含54个不同双药条件、12个单药参照，共66行；存在12个跨组源/目标角色交叉，仅实施逐组算法标签隔离。

Agent与虚拟细胞下一步若要共同学习，需要共同修订一个会实际改变预测、实验合法性和用药选择的对象；当前最具体的对象仍是“在哪些条件下允许复用某种作用/处理关系”。静态MSE和工具调度都没有证明这种修订必要，更没有证明LLM优于普通程序。

下一次应先固定科学问题，再争取能区分它的证据，不在本面板补模型求正判。[结果后发展笔记](post_result_research_note.md)保留两项线索，均为事后提出、待独立证据检验的设想：

- **位移律与到达状态律不同。** 即使共同状态关系`y=F(m)`成立，增量仍为`F(m_C+Δm)−F(m_C)`，一般依赖基点m_C。条件例F(m)=m²，在基点0和1发生同一+1位移，功能增量分别是1和3。因此本轮失败不能否定共同非线性状态关系。下一项证据应在独立校准中固定尺度、合法剂量、到达坐标匹配容差与函数允许范围，再确认跨实现功能；不能让任意F事后插值所有点。绝对F或基点条件化首先是普通非线性回归；已知Y的循环差分和为0只是恒等式，均不得计作算法创新。
- **24h观测与24h后的控制必须分开。** 当前静态表没有24–72h继续/洗脱的随机化轴。未来可在同一前24h处理后分配合法续接，以必要的vehicle、换液、残留控制和独立培养检验72h功能。这样才可能区分已形成的功能承诺与持续给药的影响。普通PK/PD和完整历史模型是强解释；若它们同预算解释全部收益，不能称新状态学习原理。现有矩阵不能生成这些未测反事实。

上述两项先改变要检验的药理复用承诺，不通过叠加网络提高“结合程度”。后续世界模型可维护带基点、未来控制和证据范围的复用关系；Agent购买检验该关系前提的可执行对比，反馈再改变可替代动作/预测状态及下一次取证。这是待证的双向算法路径。标准PSR、完整历史预测、层级模型和决策AL仍可能包含全部运算；在固定反馈、固定更新器及联合闭环比较前，不宣称方法实质增量。新的假说不能用本次已经暴露的39条件充当独立确认集。

**另一Agent确有新产物，但PASS不能直接接收。** [本次S2d核读](auxiliary_s2d_update.md)更新了先前“仅脚本/schema”的状态：现在有完整合成规划比较文件。来源代理读取本次源码、结果及CSV；协调者另核关键评分与比较代码，未重跑。`run_m1_s2d.py:153`仍把conditional-density臂设为`cand.copy()`，其`equivalence_audit`却硬编码false；它不能作为独立条件规划对照。解析评分器将截断均值m1、方差vt的二阶矩写为`vt+2*mu*m1−mu²`，正确恒等式为`vt+m1²`，裁剪前差`(m1−mu)²`。候选选择使用实际样本Y²惩罚，regret评分用另一表达式，因而保存的primary PASS尚不能认证声明奖励下的收益。正确公式重算后的方向未知，不能称机制失败。对方原件、判决和运行均未改动；该快照也不作为本轮五模型的证据。六臂信息/预算不全同、固定64评价背景和20个算法随机重复等范围见核读，不把其区间当生物或新数据任务区间。
