# 分支 C 后续发展：用化学实现交叉证据定位哪层规律失效

本附记在 `branch_c_initial.md` 保存后，由父协调明确提出的替代问题驱动。未读取 B 或其他分支正文；不是独立评审，不覆盖独立初稿。不新增查询、核心来源或实验。

## 改变的研究问题

初稿的续接反例只会说“这些历史不能继续合并”。更有用的实验输出可能是：这次失败发生在**药物化学实现到可测作用的绑定**，还是在**已测作用到独立功能结果的条件规律**？这改变了需要购买的证据。单个化学实现的功能异常不应立即让所有同类作用/状态失效。

这一问题可以发展为共同修订的科学对象，但其两层因果归属尚不成立。需要首先保持以下不对称结论：

- 可测作用不符合旧预测，能直接否定旧的“实现→该可测作用”绑定。
- 可测作用相符但功能不符，只能否定旧的“这些观测足够支持功能复用”的命题；不能仅凭这一点断言真正的下游生物规律发生改变。未测的占据、复合物、暴露或其他靶点仍可解释它。

第二点是这个替代方案的负载条件。若把 pERK 相同当作相同干预、再把功能差异归为细胞状态变化，就会制造机制结论。

## 同一个对象里保留两个待验证映射

不用添加新的神经网络模块，直接为初稿的证据表加入有来源的观测轴：

```text
r = 化学实现/剂量/暴露方案
h = 处理历史与背景
m = 实测近端作用向量（明确其 assay 含义）
e = 固定合法续接

B(r,h) -> Law(m)                实现到可测作用的绑定
F(q(h),m,e) -> Law(Y)           测得作用与状态到真实功能的条件关系
```

两图共享实际实验记录及动作、状态的暂用分组。它们不把m叫作完备作用；没有完备性假设时，F只是可检验的操作性预测关系。2025 live-cell engagement原文实际核读已说明测量平均了构象/激活态/复合物，不能为m的完备性背书。

允许修订的对象因此包括：某个化学实现是否还能实现旧的可测作用；某些历史是否还能共用作用到功能关系；哪些结论因未测作用而不可定位。未知必须保留为第三种输出，不能强制把每个反例二分为B错误或F错误。

## 最小交叉证据及三个有区别的预测

识别一个可操作反例至少要在两种历史h0/h1中，分别测试同一预设作用的两种化学实现r0/r1，共同执行续接e。每格都要有相同实验语义的m及独立功能Y，并有各历史自己的vehicle/必要对照、实际暴露记录和培养重复。破坏性m与Y可以来自随机分配的姐妹培养物，但不能声称两者来自同一个已追踪细胞。

| 实际观测模式 | 可支持的修订 | 对下一项未测实验的预测 |
|---|---|---|
| h1中只有r1的m偏离；其他格的m→Y关系仍符合开发规则 | 暂停r1在h1中的旧绑定B；暂不因该格而拆掉全体状态或同类药物 | 若独立改变r1剂量/暴露可将m恢复到原区间，旧F预言功能也恢复；若不恢复，B单层解释被推翻 |
| h1中r0、r1都能得到与h0可比的m，但其功能都系统性偏离旧F | 旧观测到功能的复用规则无效；可提出状态拆分，或承认m不足 | 在第三种结构不同且可实现同m的化学实现上，预言h1重复这一功能偏离；若仅原两种实现出现，则共享状态修订受到反例挑战 |
| h1中r1与r0测得m相同而Y不同 | 只能定位到“当前m不能支持动作等价”；不能单独归为细胞状态或绑定失效 | 需要新的可测作用、合格的遗传/药理干预或救援证据才能区分；当前数据合同下应保持未决 |

表中的“恢复/偏离”需用预先冻结的等效界限和独立重复判断。直接按m的观测值事后匹配剂量会引入选择问题；应在开发阶段预先确定可执行的剂量/暴露规则，然后在独立批次检验。不能用持出Y来挑选成功匹配的化学实现。

这些预测比“把所有异常都拆状态”更具体：第一类预言局部修订绑定后可以保留其他化学实现的规律；第二类预言功能偏离可跨化学实现复用；第三类预言当前观测无法判别。它们仍是待证的预测，并不由2×2交叉本身推出。

对“第二类确是下游因果规律变化”的更强表述，还需要对未测作用的独立约束，例如有充分控制的靶点抗药救援等；一般遗传敲除或同靶点标签也不是自动等价。当前资源不具备这些条件。应保留操作性发现与分子机制归因之间的距离。

## Agent和虚拟细胞各自被什么反馈改变

Agent首先判断当前失败涉及哪一项具体复用义务，选择能区分该义务的合法补充实验：另一化学实现、预定剂量/暴露、独立培养重复，或可执行的不同作用测量。它不是对全空间计算熵再给一次采样换名，而是在检验上表某个明确可失败的限制条件。不过这仍可被标准顺序实验设计实现，不能因此声称新算法。

模型更新时，m的失败只给相应B绑定记反例；Y在m匹配后失败只给F的观测充分性/复用承诺记反例；未能分离的情况给“未定位”状态记证据，不任意归责。随后动作抽象改变可替代的化学实现集合，状态抽象改变可共享F的历史集合，两者共同影响下一项取证与最终选药。

这种信用是一个被观测定义的限制性分配规则，尚不是因果机制的责任分解。若用黑箱学习到的latent m代替实际m而没有外部锚点，两层映射可以相互补偿，归属会不可识别；必须停止“定位哪层失效”的主张。

## 必须给基线同样的证据和修订机会

最小比较不是“有分层的共同模型”对“只有RNA的平坦模型”。所有方法应得到相同r/h/m/Y、对照、剂量/暴露和新实验动作。

1. 固定交叉反馈，比较共同修订B/F、只允许改B、只允许改状态/F，以及能同时改两者的层级模型/完整历史强预测器完整重训练。固定任何一层的消融只用于机制诊断，不能当最强对照。
2. 固定同一个B/F更新器，比较明确义务取证、标准决策AL、成本匹配覆盖设计。AL也可选择另一化学实现、剂量与assay；不得禁用它需要的交叉动作。
3. 在开发2×2之外持出第三化学实现/新的处理历史与背景，并保留其最终功能。若转移前需要测m，费用计入，各基线获得同一m；应称为近端观测锚定的迁移，不称零样本。
4. 检查收益究竟来自取证与对象修订的交互，还是来自额外近端测量、更完整历史或人为指定分组。全表只够一个小菜单时，缓存/枚举及可从头重拟合同一层级结构的基线必须进入。

在确定、完备m且有限状态/动作的情形，`F(q(h),B(r,h),e)`就是一个受约束的因子化转移/输出模型；扩充字母表的主动自动机、预测状态表示或层级分组可表达同样运算。若它们以同预算复制所有表现，不能把“动作和状态共同修订”单列为算法创新。仍可能留下可被第三化学实现检验的生物学可替代关系和观测充分性边界。

本支随后实际核读了库内 **Generalised Transportability via Causal Abstractions，arXiv:2608.15645** 的 Sec3.1 全4718字符、Sec7导入全4779字符（不含子节）、Sec7.1前5500/5931字符。原文的标准设置共享变量、图和干预语义；TraCA把源SCM当trusted reference，目标未观测时依据先验的shift机制与环境歧义集求单一transport map。C的开放差异是：**干预语义中的“该药物确实实现了同一可测作用”本身也是待验证对象，源绑定也可能失效。** 交叉试验应先检验这项前提能否保留，而非直接把所有失配放进目标domain shift。

这不是对所有因果抽象方法的能力排除。若将化学实现r、背景h和近端作用m都显式放入SCM，因果抽象/层级结构仍可能完整包含B/F；同样地，先重新估计源模型再做TraCA可能处理这类情况。当前P级阅读不足以声称该原理未被其他工作实现。候选贡献应落在“最少何种交叉证据能保留/推翻干预语义与运输资格”的科学问题，而非增加两个预测头。

## 当前可达性与不应增加的模块

按BRIEF已经核定的资源边界，2015四组共享校准读出但每靶点只有一个化学实现，不能提供上述状态×化学实现交叉；P100缺独立功能/量纲合同；2025 FAK–MEK线索缺精确配对的另一化学实现信号。本支未自行读取这些功能数值，也没有补齐新的交叉资源。因此没有可执行的效果验证，不应增加绑定网络、额外LLM或联合训练来掩盖数据缺口。

这一附记提供的是比单纯状态拆分更具体的科学问题、三种有区别的预测与一个不可定位区域。若父协调保留它，最小下一步是核查是否真有公开的历史/背景×多化学实现×同语义近端作用×独立功能交叉数据；在获得它之前不训练。若无法区分m的不足与F的变化，研究输出只能是操作性规律失效或数据合同，不能升级为机制归因。
