## 原理一：以未来可执行干预定义细胞状态

结构名称：机器人/RL 中的 behavioral equivalence、predictive state、bisimulation；也对应自动机的 distinguishing suffix / counterexample-guided partition refinement。相同快照未必是相同状态，只有在允许的后续干预下产生相同决策相关功能分布，才允许合并。

设想：模型内部共享对象不是一个检查点 embedding，而是“历史×后续干预”响应表的可合并状态类；Agent 选择能见证两个状态不可合并的后续干预，真实结果触发状态分裂，同时改变下一轮可转移预测和动作。

判断：已有项目资料包含 Compositional Behavioral Semantics for State Abstraction (arXiv:2606.25357)、Task-Aware Exploration via a Predictive Bisimulation Metric (arXiv:2602.18724)。仅把这些换成细胞和药物没有新的求解原理；普通带历史的 POMDP / 状态空间模型加主动辨识完全可以包含。暂不作为主线。

## 原理二：用药物作用的不可交换性寻找新的功能可达方向

结构名称：机器人/非线性控制的 noncommuting control vector fields、Lie bracket、nonholonomic accessibility；区别于仅要求静态终点可拟合。

问题改变：不只问“同检查点抑制的药物为何功能不同”，而问“两个看似等价的抑制程序，在更换给药顺序后是否打开不同的功能可达方向，且这种顺序效应是否可组合地预测未测方案”。

设想：将每个可执行短处理表示为细胞状态上的转移算子。对同起始培养、同总暴露的 A→B 与 B→A 获取差分；该反对称差分在短时、平滑、充分可观察等条件下包含局部交换子信息。Agent 不再只补一个最不确定终点，而选择能区分“仅剂量/累积效应”与“顺序产生新方向”的可执行调度。真实反馈更新模型内部算子间的组合规律和可达集合，并改变下一轮可选调度。

生物学新能力（未证）：从少量顺序成对探测，判断哪些给药次序能把相近检查点读数引向不同凋亡/细胞周期结局；进一步预测未测时长/未测组合的顺序效应，输出可执行调度及失效范围。

必须防止的冒进：药物顺序效应早已有研究（项目库列有 Cell 2012, DOI 10.1016/j.cell.2012.03.031），因此“顺序影响凋亡”不是创新。全信息非线性受控动力学模型加 dual control 也能包含该机制。可能的研究贡献只能来自一个尚待证明的压缩规律：少量可测算子/交换子能否在真实细胞里迁移到未测方案，并在同预算下改变药物决策。

关键可行性问题：现有 2015 静态 24h / 72h 数据似乎不含顺序给药菜单；必须核查。如无顺序或可对应的时间轨迹，本轮只能提出条件性新方向，不能用终点矩阵伪验证。

下一步选择：发展原理二，因为它改变实验对象为“作用的组合关系”和功能可达性，而不只是换潜变量或采样准则。若菜单不允许任何顺序/洗脱实验，则明确停在信息边界，不回退为普通终点主动学习。
