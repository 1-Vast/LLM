# Branch A：直接学习可组合的给药规律，而非完整细胞动力学

2026-10-28。冻结候选版本 A1。effective_model/effort: unknown。独立初稿见 `branch_a_initial.md`，未覆盖。初稿落盘后只读取共同 BRIEF，未读取其他分支正文或当前 CANDIDATES_v3。本记录是一项条件性机制设想，不是已发现的生物规律或已获益算法。

## 研究判断

值得问的新问题是：**不同化学处理之间是否存在少数可迁移的“调度替换规律”，允许从少量短处理判断未测多步治疗何时可替换、何时会改变功能？** 检查点相同只用来发现值得比较的化学实现，不当作完整状态相同。

选定的求解原理是机器人控制中的非交换作用与有限生成关系。研究对象是处理程序之间的可验证关系；不是再给药物拟合一个潜变量、再把 Agent 接到预测器外。拟议能力是直接学习一组关系并用其推导尚未测量的多步程序，减少必须枚举和实测的程序数。真实成立需要有限闭包和可观察性，本轮数据并未证明。

需要先撤回一个宽泛新颖性主张：本支唯一主题查询找到了 2026-09-16 的直接生物先例《Control theory of aging and longevity for gerotherapeutic drug discovery: state space, vector fields, modalities, safety, and the minimum safe cost of functional restoration》，DOI **10.18632/aging.206422**。它的原始摘要已经明确提出药物向量场、Lie bracket、顺序影响结局、功能恢复与约束调度。因此，**“把 Lie bracket 用于药物顺序/可达性”已经被覆盖**。下面研究的是从稀疏真实反馈学习关系及关系能否压缩预测；不是该概念的首创。对先例尚未取得正文，不能断言它没有相同学习运算。

## 两种原理的选择

1. 未来干预定义状态：机器人/RL 的 bisimulation / predictive state，自动机的 distinguishing suffix。它能使反馈触发状态分裂，但已有项目库直接包含 predictive bisimulation 和 compositional behavioral semantics。只换细胞变量没有新的机制，本支不再发展。
2. 顺序作用定义组合规律：机器人/非线性控制的 noncommuting flows、Lie bracket、有限维作用代数。它把单个终点预测改为程序替换和多步功能可达性。选择这一条；新颖性和实验可行性均保留待检。

## 最小机制

### 输入与共享对象

输入是一份固定可执行菜单：药物、剂量、处理时长、换液/洗脱规则、培养背景、起始批次、可采集的分子/功能读出及每项成本。每次处理从同一来源的独立培养复孔开始；破坏性 RPPA 不当作同一个体的纵向轨迹。模型也保留 vehicle / 自然时间演化，不能把生长漂移误认为药物之间的交换子。

共享对象是带适用域的处理关系，例如在背景 c、剂量范围 D、时长范围 T 中，处理算子 U_A(a)、U_B(b) 是否满足：

- 可交换：`U_B(b) U_A(a) ≈ U_A(a) U_B(b)`；
- 存在有限的非交换闭包：生成元的交换子可由少数已知生成元线性表示，例如 `[L_A,L_B] = λ L_A`；
- 现有闭包失效：短程序可拟合，但保留的多步程序出现超出误差范围的系统残差。

这里的生成元作用于选定可观测量或其充分历史，不宣称对应具体分子靶点。矩阵表示或坐标变换后的等价关系可以作为同一个对象；不以潜坐标名称证明机制识别。它至少同时决定 VC 的程序预测和 Agent 的程序化简、替换、选取及成本核算。

### 具体更新运算

用同起始分布、同总处理时间、同各药暴露的短顺序对 `A→B` / `B→A` 估计顺序反对称响应。短时平滑条件下，其二阶项包含可观测量上的交换子作用，余项随时长变化；必须用至少两档时长检查该缩放，不能凭一个终点给交换子命名。

对候选关系，更新的是结构常数与适用域：在可观察量方向上求带重复测量误差的约束拟合，最小化 `δz_AB/(ab) - Σ_k C_AB^k L_k z_0` 的残差，并检查 Jacobi 等相容约束和保留程序误差。该式只描述局部投影；一个起始培养和几个均值通常无法识别完整算子。需要跨多个允许起始状态/可观察量的激励，且单药方向设计矩阵有足够秩，才可能识别这些系数。没有这项条件，只能保留可观察对比，不称识别了作用代数。已有生成元不能解释且有稳定新方向时，记录“当前有限闭包不成立”；不把新增潜维度自动当作成功。

这些回归、后验更新、保留预测检查均为标准运算。可能的新内容是它们检验和修订的生物关系对象及其迁移规律，不能把拟合操作本身称为创新。

### Agent 动作与真实双向改变

Agent 的动作是一份菜单内完整处理程序及具体测量包，不能只返回抽象的“测更多蛋白”。它优先选择会改变某个药物决策的关系见证，例如两个候选闭包都解释短程序，却对一个可行三步程序预测相反的功能优劣。选择准则可用预计决策后悔或信息价值；这些准则本身沿用已有方法。

VC→Agent：当前关系决定哪些未测程序可以被推导为同类、哪些处理需要实测、怎样用可行剂量/时长替换，以及替换的成本。若一条关系被撤回，Agent 的程序化简和后续搜索空间随之变化。

Agent/反馈→VC：真实短/长程序的响应更新关系系数和有效范围，或撤回闭包；同一变化必须改变 VC 对未测程序的内部组合预测。若结果只写进文字记忆，VC 仍使用旧关系，则本线没有实现所说的共同学习。

双向依赖不要求 LLM。经典规划器可以执行；若固定一次性探测菜单已足够且适应性选择没有独立收益，则 Agent 不是必要贡献。必须把“关系模型有效”与“闭环选取比冻结设计有用”分别验证。

## 一个构造性推导和一个不可忽略的等价基线

以下仅是数学思想实验，未运行、不是细胞机制事实。设作用于一维响应坐标的两个可正向执行处理为：`A(a): x→x+a`，`B(b): x→exp(λb)x`。则：

`A(a)→B(b)` 与 `B(b)→A(a exp(λb))` 有相同终点。

一条非交换关系因此同时产生具体的功能预测和可执行替换；λ 的更新会同时改变 VC 的结果与 Agent 推荐的补偿处理量。这比“AB 与 BA 有差异”更强，因为它预测一族未测时长及多步程序，而非再拟合一个二药交互项。处理量超出菜单时，该替换不可执行，不允许负时间/负剂量。

但这个构造**严格等价于普通一维双线性受控模型** `dx/dt=u_A+λu_B x`。所以它只证明所需推理链可以成立，不能证明新算法。一般的有限维受控 Koopman/双线性模型也可能以相同参数和运算复制本设想；这是必须先查的直接等价，不是“万能模型总能表示”的空泛反驳。

另一个明确等价区：若只保留二阶顺序项，则普通 Volterra / 二阶路径特征回归可以精确复现相同预测。用二阶交换子优于无序终点回归不能建立独立创新。有限闭包要产生额外价值，至少要在未测多步/时长中给出高于任意二阶拟合的可证伪约束，并在同预算下有效。

## 区分性预测与最小验证合同（未执行）

核心命题：少数短程序识别出的关系，能预测**未参与拟合的多步程序/时长**的功能响应与调度替换；失效只在预先限定的适用域外，而非每遇反例再加背景标签。

一个具体可反驳预测：若数据支持二阶中心闭包（所有三重嵌套交换子在相关可观测量上为零），则具有相同每药总暴露及相同二阶有向面积的程序，功能响应应在预设误差内一致。例如 `A(a) B(b) A(a)` 和 `A(a/2) B(b/2) A(a) B(b/2) A(a/2)` 的总暴露与二阶有向面积相同。它们可作为未拟合的三步/五步保留测试。稳定差异将反驳该闭包；它不会自动证明另一个潜机制。该预测也必须由同信息路径特征基线获得，故单独通过它不证明算法优势。

非中心闭包版本则必须预先给出完整关系推导的补偿曲线及至少一个多步预测，不能只展示短时二阶近似。与二阶、三阶路径回归和双线性受控模型比较时，检查新增规律是否减少达到同一独立功能决策误差所需的实测程序数/计算量。不能用本方法独占顺序观测制造优势。

训练/取证集只含预先许可的短程序、分子读出和功能反馈；保留多步程序功能在方向、闭包阶数、读出包、预算和停止条件冻结前不可见。每臂允许同样的实际可执行测量，批次、培养复孔、vehicle、日历时间、洗脱/残留和药物成本计入。冻结构后重拟合是强基线，不能只比较在线增量版本。

初始研究对象应是同一培养背景的**已见药**多步/时长外推。未见药不能只凭同一个检查点映射到同一算子；需要独立近端/顺序指纹足以区分作用。未见背景需要关系可迁移的额外证据。这两项本轮均未获得，不写成现成能力。

## 合法调度反例：AB−BA 不是药物间交换子的证明

以下是解析反例，没有运行模拟。两臂从同一起始培养开始，分别执行 `A(τ)→B(τ)` 与 `B(τ)→A(τ)`，各药外部剂量为 1，总 AUC 均为 τ，总时钟均为 2τ。假设药物只加性累积一个读出 y，但 A 的敏感性随培养时钟增加：`dy/dt = t u_A(t) + u_B(t)`。则前一臂终点是 `τ²/2+τ`，后一臂是 `3τ²/2+τ`，差值为 `−τ²`。在带时钟状态 (t,y) 中，药物专属场 `G_A=t ∂y` 与 `G_B=∂y` 的药物间交换子为零；差异来自时钟漂移 `F0=∂t`，不能解释成 A 与 B 在目标通路上存在所宣称的相互作用。

因此合法菜单必须同时包括位置匹配的 `A→vehicle`、`vehicle→A`、`B→vehicle`、`vehicle→B` 和 `vehicle→vehicle`；这些控制是实际独立培养和测量，计入每臂预算。它们可揭露上述纯延迟解释，但不能普遍消去非线性漂移；若有残差，必须在包含 vehicle 生成元的完整模型里比较。不能把扣了几个均值就当作已分离出药物专属交换子。

另外，同外部 AUC 不保证同胞内暴露、同靶点占据或同存活群体。洗脱后的残留/结合驻留时间可使两臂实际作用窗口不同；早期耗竭、不可逆毒性或敏感亚群先死亡，可使后一药作用于不同细胞组成。必须在处理边界核查可获得的真实暴露/作用持续读出、活细胞数与组成，并设置同样的假换液处理；pERK/pFAK 仍只是药效读出，不能当直接占据。读出不同或采样不充分时，只报告“调度响应有差异”，不归因具体信号机制。

短时 smooth 流近似还要求在所选时长/剂量区间内稳定、无未建模阈值崩溃，响应的时长缩放与余项相容。真实细胞毒性、分裂、耗竭、选择和破坏性取样可能使这些条件失败。观察到任意非零 AB−BA，乃至观察到 τ² 缩放，都不足以排除上面的漂移反例。该反例也是最小验证必须包含延迟/vehicle、洗脱与群体控制的原因。

## 数据合同与停止

事实：2015 来源方法 s4-2-1 描述 IC40 校准、两档单药及配对药物，24h 收样；没有在已读部分发现有序、洗脱或多步程序菜单。s4-2-4 明确 resazurin 72h，细胞周期同一段却先写 24h、后写 72h，需原研究补充解释；不能统称五个功能节点均为 72h。未读功能矩阵值。

推断：该公开矩阵适合核对配对观测语义与选取候选化学实现；**不能检验上述顺序关系和闭包**。静态 A+B 不是 A→B 或 B→A，也不能制造虚拟顺序真值。

停止/降级条件：

- 若授权实验菜单只允许现有静态矩阵，本线停在条件性研究设想，不运行终点替代实验。
- 若普通受控模型/关系候选 Bayesian agent 以同参数及操作精确复制，停止独立算法主张；仍可把新生物关系作为实证科学问题，但须真实证据。
- 若闭包经保留程序反复失败，不能以不断增大阶数/潜维度保持正结论。
- 若洗脱残留、细胞选择或读出不足令两种解释不可区分，结果为不确定；不把它们解释成已发现的药物作用机制。
- 若少量关系有效但同信息强基线同样有效、或适应性设计不节省预算，则分别记录“可能存在规律”和“未见独立决策/效率增量”。
