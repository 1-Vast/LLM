## Decisive test and objections

For a row mean the defining linear ODE is x'=x A(t). Its fundamental matrix satisfies M'=M A(t), M(0)=I. For a continuous time-dependent matrix, its solution is generally an ordered exponential/product integral. A(0) and A(T) having a nonzero commutator is a useful structural witness; by itself it does not prove a nonzero terminal discrepancy, because cancellations can occur. A converged direct difference in the fixed N1 matrix, with C0/C1 near zero and independent numerical agreement at the frozen threshold, refutes the universal identity. There is no need to demand that the selected mixture's total also differ: the identity is a matrix/mean-vector statement, although a total-response difference is useful to record.

C0 (k=0) is a valid constant algebraic control, even if a specific empirical fitting routine restricts k to be strictly positive. C1 is a valid commuting control because both diagonal changes are the same scalar q(t), while off-diagonals remain fixed. Neither control is evidence about delayed drug biology.

The strongest simpler explanation/prior is standard linear nonautonomous ODE theory: omitting time ordering is a familiar mathematical approximation/error, and ordinary ODE integration or ordered matrix products already supplies the reference. The strongest charitable source interpretation is an unstated commutation restriction or an intended shorthand for an ordered exponential. The literal `integral` then `expm` implementation weakens the shorthand explanation for these files. Source-specific fitted parameters might nevertheless make the approximation accurate. Determining that would require inspecting actual executed pipelines and fitted parameters under separately authorized scope.
