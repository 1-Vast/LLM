# Q001：公开给药日程的时间与匹配资格（冻结 v1）

2026-10-28。这是不消费功能响应的资料资格检查，不是机制、药效或算法增益实验。冻结发生在新计数和新配对计算之前；已知两张顺序表分别有32/27行，且正文与脚本时间尺度疑似不一致，这些先验明确保留。不得将该检查伪称盲态检验。

**唯一问题。** 所取得的主文与固定官方源码，是否足以把顺序表中的时间坐标唯一映射为各药物实际小时暴露，并认证至少一个同背景、同代、总药物暴露相同的反序比较？这是数据能否承载后续问题的资格命题，不由它判药序效应或细胞记忆。

**输入与边界。** 使用官方 GitHub yakavetsiv/ml-mf_chemo 的 e38fc0ded24abbf5bc8a87cf6d05f320ed01565c 维护快照；它不等同论文当时的执行版本。只将两张 sequential CSV 的 `seq,t0,t1,gen,number` 读入分析，保留原列名；`cv,cv_err` 不解析为分析数据、不输出、不排序或作选择。可对整个来源字节计算SHA以绑定版本，hash不解释响应。脚本只作AST文本检查，不导入或执行Gryffin。主文为 sources/organoid_PMC12309667.xml（原始JATS），补充PDF未取得。

运行前由 prepare_metadata.py 保存上述原件的路径、SHA和参数投影，再生成DS011源包。随后 run_metadata.py 核SHA不变才计数。DeepSeek仅作同一固定规则的重复核对；主Agent与另一独立实现复核。不得用辅助输出作为时间映射的来源。

**固定操作。**

1. 表行数、代号计数、各代 `(t0,t1)` 最小/最大值、`t0+t1` 的不同值和元数据完全重复数；行身份为原CSV物理行号，number是日程编号，不当培养重复。
2. 对PDO只枚举同代、不同seq且 `t0_i=t1_j`、`t1_i=t0_j` 的无序行对，每对一次。它们只叫原坐标交换候选；需另外证明seq→药物映射及raw→小时映射，才可叫实际暴露匹配。跨代对另报，不作主要候选。
3. FAC只报同代不同seq但原坐标相同的行对，不推定a..f的药物排列或第三段时长。未认证排列时，不将其叫反序或同暴露。
4. 从AST取每段脚本的CONFIG.parameters和时间赋值/约束。报告原坐标逐字代入对应脚本的范围/和约束时有多少行不符；该计数是版本/尺度歧义提示，不能推出数据错误。时间变量可能是离散索引、时长或切换点，不能靠总和或注释猜测。正文的48/96h与4/2h步长作独立锚。
5. 单独列药物×背景交叉、靶点/遗传参照、独立功能终点及重复身份的可读证据与缺口。主文有选择性正交实验，不视为所有表行的独立真值。微孔/同入口嵌套不计独立培养n。

**输出与判定。** 主要结果是时间映射和实际反序匹配可否认证：supported需明确转换、seq药物字典、对应代和至少一对合格记录；contradicted需明确原始定义排除这些条件；缺SI/映射/版本说明时为unresolved。保留候选行对和不一致数，不把未知的真实合格对数写成0。不存在统计显著性、置信区间或机制判断，因为没有消费响应或独立重复。

**预算与停止。** root确定性计算CPU≤60秒、内存≤256MB、不联网、不新增模型调用（DS011另列已授权本轮第3调用）、不装依赖、不训练。一次运行加一次独立实现核对；SHA变化、缺列、无法解释单位时停止受影响部分并继续其他字段。不得拟合响应、尝试多个单位以获得药效阳性、重新编号伪增n或改冻结判据。本轮单假设的科学效果实验额度尚未使用；本资格失败/未决不自动授权它。

**恢复条件。** 获得公开/作者明确的每代raw时间转换及seq映射、独立培养/处理单元IDs后可另立版本复核。即使资格成立，也只能支持给定细胞/药物的局部顺序比较；跨背景药物交叉、共同后续挑战和洗脱残留仍需另外核实。
