## 初始结论

**值得保留的问题是“哪些给药史对于一套实际功能决策可以视为相同”；v1 尚未给出可区别于标准方法的算法增量。** 目前最具体的运算是功能预测状态、受控线性闭合、以及决策相关的主动查询。三者均有强先例。生物问题有实际动机，但现成公开数据尚未认证能检验其核心能力。应保留为条件性研究问题，不把它写成已经成立的新算法，也不因本轮没找到完全同名的生物应用而宣布新颖。

### T1：最强理论重合比“普通 PSR”更直接

1. Singh 等 UAI 2004《Predictive State Representations: A New Theory for Modeling Dynamical Systems》（arXiv:1207.4167，PDF pp.4–5）用未来 tests 的预测定义状态，选取系统动力学矩阵的线性独立列作为 core tests，并通过扩展 tests 的系数递推状态。v1 的 `z_q(h)=E[Y|h接q]` 把 test 换成功能期望，不足以构成新原则。
2. 《Reconciling Rewards with Predictive State Representations》（arXiv:2106.03926，PDF pp.3–4）明确指出观测 PSR 不一定保留奖励；Theorem 1 给出奖励落在 core outcome span 中的条件；Section 4 的 R-PSR 将未来 tests 扩展为 reward-predictive tests。它比“只拟合转录组的虚拟细胞”更公平也更接近本稿。不能通过让 baseline 忽略奖励制造差异。
3. 《Proper Value Equivalence》（arXiv:2106.10316，PDF pp.3–4）定义相对于策略集合的价值等价，允许忽略无关动力学；Proposition 4 的全策略情形保证规划最优性。因此“比完整受控动力学闭合更弱、只保留目标决策所需信息”已有精确理论家族。有限菜单、有限视野可以通过带时间的历史状态表达，但从该一般框架到便宜可测的药物实验条件仍需新内容。该论文不等于已经解决了有噪声、破坏性测量、成本受限的培养实验。
4. 《Deciding What to Model: Value-Equivalent Sampling for Reinforcement Learning》（arXiv:2206.02072，PDF pp.3–4、6–7）把近似价值等价、信息压缩、模型与行动共同更新放入同一算法，已有明确误差/后悔权衡。其定理使用 MDP、在线轨迹等假设，不能照搬为离线培养终点保证；但“Agent 与模型共同学习且只学有用内容”的宽泛措辞已被覆盖。

v1 若提出新的**实验上可验证条件**、在同一终点反馈下更低的有效样本复杂度，或能在破坏性、异质培养条件下给出可信的决策复用界限，仍可能有方法贡献；当前尚未给出这样的条件或运算。未查询后缀上的预测增益是一项有用要求，但它本身不能区分 PSR/R-PSR 和本稿。

### T2：闭合问题的数学核验

令 D 为相关可达状态差分的线性空间。存在投影更新 `K_a` 使 `CT_a=K_a C` 在 D 上成立，至少要满足 `ker(C|D)` 经动作后仍不可被 C 看见；在 D 对动作封闭时，这是标准受控不变商空间条件。换成“有限允许后缀 Q 下功能相同”，直接条件是 `Cδ=0 => cᵀT_qδ=0` 对目标 q 成立。若只要求相同最佳决策，还可只要求每个 C 的纤维内存在共同最优菜单项，但这只是决策充分性的定义，尚不是从少量实验识别它的算法。把这些条件重新命名不能算算法增量。

**明确反例构造（下游将单独执行算术核查）：** 取三个活细胞表型，`cᵀ=(1,1,1)`；a 交换表型 1、2，b 交换 2、3；d 对表型 2 全部杀伤、对 1、3 保留，即 `T_d=diag(1,0,1)`。a、b 都是非负列随机矩阵，d 是非负列次随机矩阵。对 `x=e1`，ab 与 ba 的总存活都为 1，故 κ=0，但共同追加 d 后差值为 +1；对 `x=e3`，同样 κ=0，而追加 d 后差值为 −1。当前相同存活和 κ 并不能保留后续方案优劣。这是正系统的可实现数学反例，不是药物机制或真实效果证据。

即使加入很多已查询后缀，只要在所有已测行上都看不见的状态方向被某个未测后缀显露，就存在不可辨识性。需要结构假设、覆盖设计和误差界，不能仅靠模型之间“预测不同”保证发现所有反例；模型一致也可能一致错误。无限追加坐标可能退化为完整重拟合或枚举所有方案。

### T3：现实近邻及不能误述的差异

- DrugReflector 原文 pp.5–6 已使用配对转录和 Day 7 表型学习签名，用可调步长更新，再在此前未筛的化合物上实测。故“功能反馈修订虚拟细胞后再选药”不是本稿独有。其差异是单药优选和输入签名更新，不是同一处理史的可组合状态递推，也不提供药序后缀闭合。p.12 仅核对数据/代码可得性，不将可下载当复现。
- BATCHIE 原始 JATS Sec14 用一般概率模型的 posterior 与模型距离作 plate selection；Sec16 的 TID 特意关注前 K 个治疗指数候选。故它并非只做总体预测误差，不能把“关心最终药物决策”当作全新点。但其 tensor combination 实例没有证明有药序状态、时间记忆或任意后缀递推；其 TID 也不等于本稿尚未精确定义的 terminal-regret VOI。
- Science Advances 2025 DOI 10.1126/sciadv.adt1851 的主文 Results、Drug screening、Statistical analysis、Fig.3/6 支持真实闭环顺序给药的可行性：MCF-7 为 FAC，PDO 为 OLA/IBET，背景和药物不同。正文报告 FAC 最优顺序存活与同时给药相当而总暴露较低；PDO 顺序没有达到同时给药的活性。不能将两者拼成跨背景机制验证。

### T4：实际价值链中缺证据的位置

使用者可明确为进行前临床培养药筛的团队。可用输出是固定剂量、时间、细胞背景下下一批日程，以及允许复用的历史集合；这是合理的潜在用途。当前替代方案是同样预算的 Gryffin/BO、灵活 dose×time×order 模型，或 R-PSR/受控模型配同一决策查询准则。

但“可以少测许多历史”尚未成立：每个功能后缀仍要从同一历史重建新的独立培养，破坏性读数不能在同一培养上回退；培养间异质性和批次效应可能大于拟合差异。必须计入建立历史、洗脱/残留、药物暴露、终点测量和独立重复的物理成本，而非只数 q。公共 CSV 的 number 不是培养 ID，图中的 3–5 次独立实验也没有给出表行层面的关联。

主文还提供一个直接相关的效用边界：FAC 的 calcein-AM/PI 存活相近时，Ki-67 增殖读数可以不同（Results，Fig.4 叙述）。这不否定预先固定的存活效用，却说明“对该效用充分”不能扩大为抗癌表型等价、耐药记忆或毒性降低。主文的“可能降低毒性”未等同毒性实测。若实际价值要求持久抑制/复发，则需另定义并测量该终点，不能在看到结果后换效用。

### 决定性下一步和停止条件

首先要求作者写出相对 R-PSR/价值等价方法**实际不同的一条运算或可检验条件**；将“更弱条件尚待寻找”与“已经提出条件”分开。随后才判断数据是否能测：同背景、同实际暴露的历史和共同后缀、独立培养 ID、功能单位和时间映射必须闭合。若这些条件缺失，结论是资源资格未决，不是生物问题无价值。

若具备数据，冻结训练可见的后缀集合与完全未查询后缀；给本法、完整重拟合 R-PSR/受控模型、灵活日程回归及相同 terminal-regret 查询器同一反馈、先验、候选和物理预算；以独立培养为单位评价固定效用的末端后悔、实验成本及覆盖率。还须检查坐标扩充是否只是额外测量/拟合能力。没有唯一算法增量且相同预算下无独立决策收益时，不将更复杂描述保留为主创新。
