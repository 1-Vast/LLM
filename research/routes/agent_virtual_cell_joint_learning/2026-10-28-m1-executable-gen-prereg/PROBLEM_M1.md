## 0. 一句话

药物只能改变**随机结果的条件分布**，不能让实验者从同一动作的多次随机实现中挑“幸运的一次”。本预注册研究：把目标生成提案投影到可执行随机核族，先对随机药效取期望再选动作；用合成已知核→高维近似→真实独立功能记录三阶段验证；公式本身（一步投影）已是最大熵控制/受控 Schrödinger 桥近邻，**不称创新**。

## 1. 形式化（冻结）

### 1.1 对象

- 背景/历史 `X`；合法动作 `a∈A(X)`；真实随机药效核 `Pθ(y|X,a)`（θ 只在真实给药结果后更新；可由真实功能反馈学习）。
- 参考动作分布 `π0(a|X)`，在合法动作上有支持；温度 `τ>0`；奖励 `r_g(y)` 有界；目标 `g` 给定。
- Agent 计划由**动作分布 π**与真实核组成；可执行族：
  `Rπ(a,y|X)=π(a|X) Pθ(y|X,a)`。
  **可执行计划不能选择 y**；y 是给药后的随机结果。

### 1.2 目标联合提案

目标条件化生成可使用联合提案：
`Q_g(a,y|X) ∝ π0(a|X) Pθ(y|X,a) exp(r_g(y)/τ)`。
它同时倾斜动作和结果；这是**提案/目标采样分布**，不是新的药效核。

### 1.3 反向 KL 投影（先期望后动作）

在可执行族内最小化 `KL(Rπ || Q_g)`。忽略与 π 无关的常数：
```
KL(Rπ||Q_g) = E_{π(a)Pθ(y|a)}[ log π(a)/π0(a) - r_g(y)/τ ] + log Z
             = E_{π(a)}[ log π(a)/π0(a) - E_{Pθ}[r_g(Y)|X,a]/τ ] + log Z.
```
因此最优动作分布：
```
π*(a|X) ∝ π0(a|X) exp( E_{Pθ}[ r_g(Y) | X,a ] / τ ).
```
**关键**：先对随机药效 `Y~Pθ(·|X,a)` 取期望，再优化动作；不是先选幸运 y 再反推 a。公式是标准 KL/指数倾斜/最大熵控制的一步形式；**不称数学创新**。

### 1.4 数据/更新/物理核边界

- **目标生成样本不成为实测标签**；只有**真实给药后的结果**更新 `Pθ`。
- **有限时程保留物理条件核**：`Rπ=πPθ`；目标倾斜的 Doob 路径核/任意目标条件化 y 不能当作可执行药物。
- 目标倾斜的联合分布对给定动作内的 y 也有倾斜（例如 `Q(y|a)`）；但**可执行 Rπ 的给定动作条件核仍是 Pθ(y|a)**。目标 Q 的 within-action tilt 只用于生成提案，不能替代/训练 Pθ。
- 支持/受限程序：`π*=0` 当 `π0=0`；不能声称无支持动作可达；受限给药程序必须显式编码为合法动作集。

## 2. 反例（构造，仅证风险）

A：10% 得 10，其余 0；B：稳定 2；奖励 `r(y)=y`；τ=1，π0 各 1/2。

- 实际期望：**E[A]=0.1×10=1 < E[B]=2**。
- 目标联合提案质量：`Q_g(A,10)` 远大于其他；**target 采样约 99.67% 选 A**。
- 可执行投影：`π*_B/π*_A = exp(2/1−1/1)=e`，π*_B≈**0.731**；按期望选 B 多数。
- **结论**：目标生成可偏爱幸运轨迹；投影按期望修正。该例**只证明目标条件化风险**，**不证明本候选优于标准随机控制**；标准最大熵控制/随机 MPC 同样能做对。

数值（本实现算术）：`P(target_action=A)=0.99665795`、`P(target_action=B)=0.00334205`；`E_A=1.0`、`E_B=2.0`；`π*_A=0.26894142`、`π*_B=0.73105858`。

## 3. 近邻/新意边界

- **一步投影 = 最大熵随机控制**；**受控 Schrödinger 桥**是其近邻/路径版本；**Diffusion Forcing/HGVD** 覆盖联合生成+历史条件化；**KoopCell/DisKO/TD-JEPA/BATCHIE** 覆盖部分控制/反馈/选择。
- **公式本身不称创新**。候选创新点只能在：**未知随机药效 + 高维群体状态 + 受限给药程序**下，联合生成推断保持**条件药效不被目标引导污染**，并在**同预算**得到规划/校准能力；**尚未证明**，需独立挑战/实验。
- 若只胜过“错误目标条件化”、标准控制等预算等效、目标引导改变 Pθ、或无支持动作声称可达 → 撤主算法主张（`rename_maxent` 等）。
