## 必须先修正或限制解释

1. **方向1的化合物交互不可直接识别（run.py:102–116）。** 所有 withheld 药物在训练完全排除，测试却只使用 withheld 药物。因此它们的 drug 和 drug×tissue 设计列全零，无法学习这些药物自身的组织交互。full 与 background 仍可能因已知药物改变共同系数而数值不同，不能把差异解释为留出化合物特异规则学成。协议提到 evaluation 与留出药物评价，但代码只有留出药物评价。建议在相同反馈后额外评价未反馈的 known 药物，并明确分别报告 known-compound/new-cell 与 withheld-compound；不因负结果换拆分。独立重建元数据得到16家族、96药物，8固定反馈仅覆盖6家族，因此10家族在新细胞上的 family×cell 也完全无反馈。方向1若收益弱，应报告不可识别/反馈覆盖问题，不能声称规则修订被证伪。

2. **方向7未实现冻结协议的误差校准（run.py:143–151）。** 代码按 source 跨细胞响应标准差排序，此量表示生物响应变异，未校准预测误差，亦非GP后验方差。没有 source 留出误差校准、校准阈值或实际分布漂移统计。“高置信错误”当前只是入选低变异子集的 |误差|>1 比例。可以诚实命名为“响应低变异启发式门控最小尝试”，或实现不泄漏 evaluation 标签的 source 留出误差校准；目前不能称为已完成证据门控验证。每细胞coverage有保存，但奇数候选取floor使覆盖低于50%。

3. **方向5的重复定义需写清（evidence_audit/run_audit.py:28–50）。** 协议要求至少3个可独立识别测量重复，执行却使用不同文件数作必要门槛。文件/板/孔并不自动等于独立生物重复，也没有证据证明同文件中的独立实验不可能存在。实际QC通过数据135936行，(file,Well)唯一，完整重复行0；因此不存在原始重复行假增样本的证据。双朝向把同一井放入不同伙伴问题，本身合理；不同设计比较共享同一井，不能把1012615比较视为独立重复。当前保守停止可接受，理由必须是“独立重复身份未验证且>=3文件保守门槛未过”，不是“数据证明无独立重复”或“替换不成立”。

4. **方向5未真正匹配file/Plate或评估重复精度。** grouping只有Cell line/Iteration/partner/两剂量/replacement，源数据有Plate列但未纳入，也未检查不同替换臂/单药来自同板、批次可比或控制归一化。因此协议的“available assay/batch identifiers匹配”尚未满足。当前qualified_equivalence_tests始终初始化为0，没有可运行的Welch/TOST实现，即使未来数据满足门槛也不会执行检验。本轮门槛实际为0，故可记录为数据设计审计受阻，但不能记录为已实际执行等效检验或重复精度验证。

## 信息预算与KG核对

- Ridge训练排除withheld的全部source响应，而GP baseline及kernel使用所有药物的source响应（run.py:130–136）。GP的withheld只是“目标细胞未查询”，并非source响应未知的新化合物。各方向内部对照共同信息成立，但跨方向结果不能当同一unseen-compound任务直接比较。需在输出明确此差异。
- GP所有策略同一updater、8次单标签查询，候选pool与最终test相互不交；未见直接读取evaluation响应来打分查询的代码。按finite response筛选候选使用了缺失性信息，是离线可测候选假设，应披露。
- KG的possible posterior mean公式与高斯一步观测更新匹配，按每次幻想的top3再平均，确实针对test菜单的期望最优top3值。省略当前top3值不改变同一步argmax（常数项）；无需把这点当bug。32次共同随机数是粗近似，预算与seed固定；计算成本远高于随机策略，因此只可声称相同标签预算，不能声称相同计算预算。
- counterexample只是当前药物均值相对family source均值的绝对分歧，并非针对分子机制反例；其负结果只涉及此启发式实现。
- 方向3相同random反馈下比较static/global-bias/GP，信息预算对应，utility和MSE均保存。
