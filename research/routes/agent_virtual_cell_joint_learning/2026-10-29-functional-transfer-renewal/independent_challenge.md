### 1. SIB 的源操作：付费观测是真操作，创新量的效用解释有缺口

PDF 3（2389）§3.1 Eq3/4 是真实未知图像 x 的矩阵采样 `y=A x`，并非先看到 x 再裁掉计算；Eq3 初始统一采样，Eq4 每阶段统一 innovation sampling。PDF 4（2390）Eq5/6 明确在探针前后分别用 `Fs1` 与 `Fs2` 轻量网络重建，再以 Eq7 的重建变化平方估计 innovation。因此源文支持“先花采样预算取得反馈，再改采样分配”这一原则；但两次网络还不是同一个已证明校准的后验均值估计器，重建变化可能混入网络差异/学习偏差。

PDF 3 Eq1 定义 `alpha=||xhat_IS−xhat_HM||²`，随后有原文断言 “innovation is a direct estimation of the decrease in reconstruction error”。Eq1 的第二个等号只把预测差写为两个残差之差，不能推出误差平方差，故这个承重解释不能直接移植成药筛风险保证。原文实验可能成功与这一数学缺口可以同时成立；本挑战未重验其经验性能。

PDF 3 Eq2 与 PDF 4 Eq8 的印刷写法再使用 `||alpha_n||² / sum_n ||alpha_n||²` 分配预算；若 alpha 是 Eq1/7 的非负标量，这就是再次平方，而非直接按期望风险下降线性分配。未核代码，不能排除作者符号/实现另有约定。PDF 4 的每阶段自适应剩余资源表达式扣除了 `SR_IS`，PDF 5 §4.1 给 `SR_init=0.02`、`S=4`、`SR_IS=(SR−SR_init)/(2S)`：探针并非免费额外信息。块采样率还有 `s/S` 上限。整数预算、饱和后再分配与真实设备成本尚未核查。

PDF 4–5 §3.2 是 PCCD-Net 的卷积/PGD 重建；PDF 5 §3.3 Eq18 使用 l1 与 SSIM 组合损失。这是图像重建训练目标，不能凭迁移命名继承为药筛机制或 top-k 决策效用。原文在此范围未提供药筛观测合同。单孔可以对应坐标选择，故“没有任何合法测量算子”会过强；但 dense 图像测量行不能随意当作一次合法药筛孔，图像空间块也不能自动当作有科学效用的药物关系块。

### 2. 代数与 Gaussian 对应：结论基本成立，但噪声条件必须补明

冻结稿逐实现恒等式及反例均正确：令 `d=m1−m0`，有 `R0−R1=2(x−m0)^T d−||d||²`；它与 `||d||²` 相等当且仅当 `(x−m1)^T d=0`。嵌套真值正交投影是充分例，任意 PCCD-Net/refit 没有此保证。这里评价的是平方误差，不能由此反驳或认证 l1+SSIM 的经验指标。

期望等式需要 `X` 平方可积、历史 sigma-field `H_t` 嵌套、`m_t=E[X|H_t]`，以及相同平方损失/目标。其证明来自 `E[X−m_(t+1)|H_(t+1)]=0`，使残差与可测的 `d` 条件交叉项消失。因此 `E[R_t−R_(t+1)|H_t]=E[||d||²|H_t]` 是当前历史条件下对未知真值与下一观测的联合后验平均；固定真实 x 只对测量噪声平均一般不成立。这个恒等式本身不要求 Gaussian，噪声需进入正确概率模型；独立、异方差等形式不影响一般条件均值证明。它也不保证每次读数真实误差下降，不适用于任意错设模型或更换目标后照用旧分数。

对 Gaussian 特例，一个足够明确的条件是给定 `H_t` 后 `(F,Y_q)` 联合 Gaussian，例如 `F|H_t~N(m,C)`、独立 `epsilon~N(0,s²)`、`Y_q=F_q+epsilon`，C 是当前条件协方差、L 预定（或对当前历史可测）、分母 `v=C[q,q]+s²>0`。则

`m_new−m = C[:,q](Y_q−m_q)/v`，

`C_new=C−C[:,q]C[q,:]/v`，

所以 `E[||L(m_new−m)||²|H_t]=||L C[:,q]||²/v=tr(L C L^T)−tr(L C_new L^T)`。

**冻结稿应补的条件：仅说 F Gaussian 与噪声方差 s² 不够。** 非 Gaussian 独立噪声会使后验条件均值一般非线性；上述协方差更新和精确后验风险对应不能仅凭两个方差推出。若改称最优线性更新，可以在较弱矩条件下得到相应线性风险式，但这不是原稿已经写明的精确联合后验身份。相关噪声、随观测再估超参数、多孔同时选择也需另写模型/矩阵公式，不能直接复用这一个标量更新式。

这里的联合 Gaussian 是足以保证这些公式的清晰条件，不声称它在逻辑上是唯一必要分布族；也可另证后验均值确为上述仿射式、且相应条件协方差满足该更新。没有这些证明时，Gaussian F 与已知噪声方差本身不足以保证精确性。

在这些条件下，固定平方线性目标的一步分数精确对应目标加权 A-optimal 方差/trace 下降；若每个 q 成本相等，可直接比较该值，成本不同还需明确相同资源的比较问题。L 只有差值行时消除共同平移也正确。但这一对应只覆盖冻结稿给出的那个**一步期望线性目标适配**，不覆盖 SIB 已实现的探针后逐实现 alpha、alpha² 归一分配、分块/上限、多阶段策略或 learned reconstruction；也不是多步最优性或 top-k 选药风险等价。不能把“该简明适配无新运算”升级成“整个 SIB 已被 A-optimal 精确实现”或“所有 nonlinear 适配皆不可能创新”。

### 3. ISO 的标签、模型增量及成本边界

PDF 3（4941）§3 直接规定 Cf/Cw 事先给定，已标实例从 Du 移到 Df 或 Dw；Algorithm1 第8行只遍历 Du，第15/16行从 Du 移除两种已标样本。故在读到的主算法里未提供 `Dw→Df` 升级动作，有直接原文依据；应继续保留“读到的主算法范围内”这一限定，不能声称穷尽了代码或所有可扩展版本。逐个实例两种标签对应的候选向量如何在一轮采样内排重，文字算法未完整展开；本挑战不将该歧义判为已证实现缺陷。

PDF 4（4942）§4.2 Eq3/4 是固定另一 supervision pool 后，渐增当前 pool 子集的验证准确率增量加权平均，再按样本量归一；PDF 6（4944）§5.3 给 K=5、3 个随机 seed 平均。它不是无成本、无训练的 oracle 边际价值，也不证明单个样本真实增益。Eq1/2 的 `M_level * percentile_uncertainty / cost` 与 PDF 4–5 §4.3 的 VCR 加权特征、近似 k-means++/diversity 批选择，确实是已有具体运算。称“全局 supervision-level 进步估计”为新机制会与这里直接重叠。

PDF 5（4943）§5.1 明确 weak 是 superclass、full 是精细 class。PDF 6 §5.3 规定 `Cf=1,Cw=1/2`，§6.2 和 PDF 7（4945）Fig3/续段测试 `1/4,1/8` 并强调 Cw 在学习前由用户设定、非超参数。原文只给相对注释成本及 non-expert/expert 报酬的设想，不是测得的药筛孔成本或药物曲线标签工时证据。事后分箱不会退还已付连续读数；弱=单点、全=曲线只是另一个尚需定义动作、剂量/时间、共享点与增量费用的合同。

PDF 4 §4.2 原句为 “a small validation set randomly sampled within the budget of a single round”。PDF 6 §5.3 说 full-label validation 从训练数据准备，CIFAR100 为1000、CUB200为500，与每轮 B 的数目相同。前句可以表示费用上限/规模量级，但未说明是否从每轮 B、首次 B 或额外公共预算中扣除；后句也没有解除这个会计歧义。PDF 7 Fig2 横轴为 round，caption 只给 Cf/Cw；PDF 6 §6.1 用五轮=5000、三轮=3/5预算叙述，也未明确验证标签是否加在这些数里。因此冻结稿的“尚未核准”准确；**既不能断言 validation 免费或已漏算，也不能断言已全部收费公平**。如果未来重用此成本结论，具体可补点是核其 validation 样本与 Du/Df/Dw 的拆分、初始标签/验证标签账本、各基线能否共享及总成本分母；本轮不访问代码来填空。
