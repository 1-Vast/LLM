## 1. 一步形式化（冻结；仅诊断/规划）

### 1.1 对象

- `h`：已知背景/历史（含记录到的状态、既往动作与功能读数）；`a∈A(h)`：合法动作。
- `Y∈[0,1]`：同一决策单元上的**独立功能读数**（不是 RNA 替身；本预注册不运行真实数据）。
- `b(a|h)`：实际记录到的随机分配概率（已知 behavior policy；b>0 在目标策略支持上）。
- `π_k(a|h)`：第 k 个**冻结候选策略**（评价/候选选择前冻结；不在同一评价样本上改策略）。
- `mθ(h,a)`：功能均值模型（可为任意预测器；本预注册只讨论一步更新，不假设细胞动力学正确）。

### 1.2 标准一步 DR：

`H_k(h,a)=π_k(a|h)/b(a|h)`；`δ_k=E_{h,a∼b}[H_k(Y−mθ)]`；策略值 `V_k=E_h[Σ_a π_k(a|h)mθ(h,a)] + δ_k`。

- 若 `b(a|h)>0` 对所有 `π_k` 支持动作成立，且**评价样本独立于 mθ 拟合与 π_k 选择**，则 `V_k` 是 `π_k` 真实策略值的标准 DR/重要性校正估计；mθ 可错仍有双稳健性（本预注册把它作为**待核事实**，不称新构造）。
- 若 π_k 支持外动作 b=0 → H 未定义 → `design_invalid: positivity/support`；不得插补/外推。
- 原始 DR 要求评价样本独立；复用同一批数据做模型/策略选择再评价 → `design_invalid: leakage`；需独立评价集/交叉拟合，规则在 Stage 预注册中冻结。

### 1.3 候选更新（功能均值层；待验证）

- `logit m_{θ,ε}(h,a)=logit mθ(h,a) + Σ_k ε_k H_k(h,a)`（或等价的 score-tilt 参数化；m∈(0,1)）。
- 真实反馈拟合 ε：使相应分数 `E[H_k(Y−m_{θ,ε})]` 趋近 0（一步 targeting；不称唯一/有限解）。
- **预先冻结概率/权重截断** `H_k≤C`（C 在 Stage1 预注册时写死）；报告截断后的估计作为有界估计，不当作精确 policy value。
- 有限样本分离/共线：H 共线或某些方向被完全分开时，ε 可能无有限唯一解；报告 `nonidentifiable`/`inconclusive`，不得用任意大 ε 掩盖。
- 该更新只作用于**功能均值头**；没有证明它对应细胞状态/轨迹核的兼容修订，不能称细胞规律改变。

## 2. 共享分数与实验分配（待验证）

- 同一组 `δ_k`/H_k 也用于设计下一批行为分配 `b_next`，目标是降低后续策略评价/决策的不确定性。
- 冻结 m 时，单个策略评价的方差贡献（二阶项）为：
  `Σ_h p(h) Σ_a π_k(a|h)^2 [Var(Y|h,a)+(E[Y|h,a]−mθ(h,a))^2] / b(a|h)`。
- 若世界模型/均值模型错设，`(E−mθ)^2` 偏差平方项非零且未知；**不能只按噪声方差 Var 分配**；须估计/给保守上界，并在预注册中声明分配准则（如最坏情况/上界）。
- 分配必须遵守支持/概率下限（b≥b_min>0）与实际随机化记录；零支持动作→`support/positivity`；极端权重（H 很大）→未识别/不稳定，不以 clip 后结果冒充精确值。
- 该分配与标准 DR 最优设计/批量 AL/GP 采集存在直接重叠；**不声称新颖性**。

## 3. 与标准方法的边界（同信息/同预算；必须作为强基线）

| 基线 | 关系/必须比较的内容 |
|---|---|
| 普通全历史重训 | 同特征/历史/初始数据；只换更新规则；一步线性/静态模型可能复制候选 |
| 重要性加权（IW） | 同 b/π/H、同评价样本；DR 与纯 IW 的偏差-方差对照 |
| DR/TMLE targeting | 标准 DR、TMLE targeting 的一步更新；同 ε 拟合/截断/评价独立性；同预算 |
| value-aware model learning | 同功能目标/反馈；若只改 loss 加权则可能等价 |
| 层级 GP / BATCHIE 适配 | 同信息集、同批量预算、同反馈；GP 不确定性/批量选择对照 |
| 最优实验设计 / 决策 AL | 同 b 支持/成本/查询数；分配比较的非候选强基线 |

**共同合同**：同特征/知识/反馈/调参（每方法≤20 configs）/计算 caps（1800 s、2 h、8 GB）/初始数据/seed；只比较正确的 DR/决策端点；不得用错误基准或仅比随机。
**一步线性退化**：若 `mθ` 为线性、π=b 时 H=1，score 退化为普通加权残差回归；保留等价结果，撤"深世界模型创新"主张。
**序贯边界**：没有完整序贯历史、propensity 记录与删失机制，不宣称序贯 DR/TMLE；本预注册只做一步版本。
**功能 vs 细胞**：只更新功能均值 ≠ 细胞动力学兼容更新；状态轨迹核/机制主张须另立预注册与证据。
