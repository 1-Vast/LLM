# Lead 裁定：R200-D1 停止归档（不采用乐观独立规划）

2026-10-27。依据：D1.1 修订（`d1_information/` v0.2；D1-C1 挑战为 revise）给出明确功效边界：**保守规划**（A0 只读 ICC：cell 0.03943517、cond 0.01428744，ρ_AB=0；Δ=Spearman 差、cluster=目标侧 cell）下 T2（9,154 匹配键）**MDE80=0.0941>δ_min=0.05**；T3 495 键 MDE80=0.2018；T1 18,782 键 MDE80=0.0896；T4 无合格目标（O'Neil 有资源但与 Jaaks 9/39<10、无 A0 匹配键/同端点，判 `not_qualified: data_insufficient`）。唯一能过 MDE 门的是**明示非保守**的"乐观独立规划"（ICC=0、ρ_AB=0 → T2 MDE80=0.0414）。

## 裁定：停止（stop）

- **不采用乐观独立规划**：以 ICC=0/ρ_AB=0 通过 MDE 门属于**换假设/口径凑功效**（D1.1 自己标注"明示非保守"），违反"不得换指标/口径制造收益"；且即使通过，T2 也只是**同平台跨 screen 同键复测**，不能检验"闭包外/新键结构"，更不能支撑独立测量/培养/lineage 迁移主张。
- **D1 线以"信息分解 PASS + 资格/功效边界"归档**：核心结果为 C188（Q 秩 3,005/冗余 96.735%；H197c 100% 可由训练条目精确重建 → R197v2 0.7206 不能作为闭包外结构证据）；目标资格：qualified=0、qualified_with_conditions=1（仅 Validation 跨 screen 同键复测层）、not_qualified=8；O'Neil 分类修正为 `data_insufficient`（非空目录）；Nyman2020 统一 data_unavailable。
- **不执行任何 D1 效果实验**；不写迁移/决策收益/机制/闭包外结构结论；R197v2 0.7206 仍只作 C179 待检验描述性。
- **所需测量规格（升级条件）**：独立组合资源（不同测量模态或独立培养）+ 与 Jaaks 共享 ≥10 细胞/≥10 有向对/≥500 匹配键/四元组 + 原始板孔与两 screen 不相交 + 冻结聚合的组合 Δ 或功能 viability + **保守规划下 MDE80≤0.05**；本地现有资源均不满足。
- **保留**：d1_information v0.1/v0.2 全部产物（含 D1.1 保守/乐观功效表与过门代数阈值：T2 需目标侧秩 ICC≤0.003663 或 ρ_AB≥0.7177）；不删除、不改 SHA；后续若获独立测量资源，须新预注册+独立挑战。
