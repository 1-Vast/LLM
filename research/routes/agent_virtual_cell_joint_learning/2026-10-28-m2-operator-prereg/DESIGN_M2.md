## 0. 冻结形式化（执行时逐条实现）

1. **X/φ**：X 含历史与绝对数量；φ 为小函数族（p 固定、可观测、基固定）；不得把归一化 RNA 当全部状态。
2. **闭合假设（待检验）**：`E[φ(X_Δ)|X_0=x,a]=K_a φ(x)`；仅当真实新矩通过闭合检验才用于多步 K 乘积；失败只报告不可复用作用/时程。
3. **群体矩（固定 π）**：`V_i=Σ_a π_i(a)K_a U_i`；π 已知、先于结果、cohort 间分配、非细胞自由给药、非联用；各组起始分布可交换。
4. **记录态分配估计**：`V_i=Σ_a K_a E[1{A=a}φ(X_0)|i]`；**禁止**边际 π×均值捷径（设计算术 bias 0.2651 非零）；动作标签完整使用。
5. **任务驱动闭环**：从独立功能 f_g 拟合合法动作条件后继 → 依功能目标选起始条件/给药/时点 → 真实新矩检验闭合 → 闭合：K 乘积/已测功能重组；失败：报告不可复用作用/时程。**函数选择/增补/误差控制仍为开放算法问题，不得声称已解决。**

## 1. Stage 1：受控真值测试床（合成；已知 K_a）

- **系统**：隐藏状态 d=4（含历史）；A=3 动作；φ 维 p=5；cohorts=200；timepoints=3；三例：
  ① 线性闭合（positive control，K_a 已知）；② 非线性非闭合（negative control，闭合必须失败：φ=(1,x,x²)、x'=x+a+cx²+ε → 设计算术残差 **3.7577**）；③ 部分支持/不可辨识（negative control：某动作无支持 → K_a 不可辨识）。
- **可辨识性检查**：同 U 时 `K_a U`（design rank=A 时可辨识；仅 mixture 时仅组合可辨识）；full K_a 需每动作 ≥p 纯分配组且 U_i 张成 R^p（设计算术 rank **48/48**；mixed 仅 **40/48**）；gauge `M K_a M^{-1}`。
- **闭合检验**：在**真实新矩**上拟合 K_a 并算闭合残差/预测；闭合残差阈值与不确定性预注册（bootstrap/CI）；失败 → `design_invalid: closure`。
- **随机化/可交换性**：π 先于结果、支持/平衡表、记录态分配估计式；失败 → `design_invalid: randomization`。
- **正交设计示例**（仅算术）：same U 下 pure vs soft mixes 分离 `K_a U`；不识别所有 K、不保证混合优于纯药组。
- **产物**：可辨识性/闭合/随机化检查实现与结果 JSON；只报检查结论，**不报效果增益**。
- **预算**：合成 compute-only、0 wells；wall≤600 s、CPU≤2 h、内存≤8 GB；pilot 设计算术 0.00303 s/rep（stage1 投影 0.1 s）。

## 2. Stage 2：多时间功能数据、固定反馈比较学习（不运行）

- **数据要求**：合格多时间功能/群体快照（同一培养物/背景/批次可交换；剂量/时间/function readout；记录 π 与动作标签；独立培养/板重复；计数保留；正交功能在声称时）；**当前 data_unavailable**（AZ 数据字典/功能数值未取得，C203），不得以导出缺失推断只能新湿实验。
- **比较**：候选模型 vs full-history retrain、hierarchical GP、KoopCell/DisKO 适配、TD-JEPA/后继特征适配、state-space/PKPD；**相同固定反馈**、同信息/同预算/同调参。
- **划分**：先留出程序（procedures），再留出背景（backgrounds）；只换已观测功能权重=有限任务重组（不是零样本迁移）；新功能所有方法同标定。
- **主端点**：独立功能下的实际决策效用/后悔；Stage 2 只比较学习质量与实际决策端点，**RNA/预测校准/算子误差为 secondary**。
- **失败**：标准方法在等预算下复制/超过 → 撤主算法主张；无独立功能增量 → 撤主张。

## 3. Stage 3：固定更新器、比较取证 + 完整闭环（不运行）

- **固定更新器**：同一更新器下比较候选**主动干预选择** vs random、GP 采集、最优输入设计、BATCHIE 适配；同合法实验包/成本/标定。
- **完整闭环**：计培养物/板/对照/失败/重复/标定/计算/调参；预注册停止上限（反馈/实验成本）。
- **启动条件**：Stage 2 通过 + 独立功能数据合格 + 主端点 headroom/MDE 通过；否则 stop。
- **样本/功效**：按独立功能端点分别规划，配对独立单位（培养物/背景/任务）聚类；`headroom=U_max−U0` 先检；`MDE80=2.801585·SD/√n_eff`；6,282 只作 Fisher-z 参考，**不作通用门**；δ=.05 normalized；CI/可达性规则写死。
- **停止**：标准方法复制 → 撤主创新主张；闭合/随机化/测量合同失败 → stop；收益仅 RNA → 撤；成本超限 → stop；CI 无法排除无收益 → inconclusive；跨任务失败 → 限当前任务。

- **Primary**：独立功能决策效用/后悔（per endpoint 定义，δ=.05 normalized）；配对独立单位；cluster 按培养物/背景/任务；报告 mean/CI/多重性校正 p。
