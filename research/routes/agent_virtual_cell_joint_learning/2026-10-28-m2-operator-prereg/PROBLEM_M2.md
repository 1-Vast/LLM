## 1. 形式化（冻结）

- **状态 X**：培养物/cohort 状态，含必要历史与绝对数量（增殖/死亡计数；归一化 RNA 分布不能单独区分数量变化）。**φ(X)∈R^p**：可由实际观测估计的**小函数族**（独立功能读数 + 计数 + 预注册历史项）；基在拟合前固定。
- **闭合声明（待检验，不作默认）**：`E[φ(X_Δ) | X_0=x, a] = K_a φ(x)`，`K_a∈R^{p×p}` 为动作特定算子。这是模型假设，须在真实新矩上检验，不是恒等式。
- **群体矩（固定随机分配）**：cohort i 以已知固定概率 `π_i(a)` 分配动作，各组起始分布相同；`U_i=Eφ(X_0|i)`、`V_i=Eφ(X_Δ|i)`，则 `V_i = Σ_a π_i(a) K_a U_i`。
- **按已记录状态分配的正确估计（写死）**：`V_i = Σ_a K_a E[1{A=a}φ(X_0)|i]`；**禁止**用 `Σ_a π(a)·Eφ(X_0)` 的边际捷径（本设计算术示例：naive 偏差范数 **0.2651**，非零）。
- **动作标签充分利用**：不得聚合/丢弃已取得的动作标签来制造"新难题"。
- **π 语义**：π 是**培养物/cohort 之间**的实验分配，**不是**同一培养物内细胞自由分别给药，**不是**药物联用。
- **动作/时点/处方**：动作 a 为合法的给药/起始条件/时点组合；π 只在预注册合法动作集上有支持。

## 2. 任务驱动主动辨识（核心候选；设计，不运行）

1. 从已测**独立功能** `f_g`（如 viability/apoptosis/regrowth 等）出发，拟合其在合法动作下的**条件后继函数**。
2. Agent 依功能目标选择**起始条件/给药/时间点**，优先辨识**任务相关作用方向**（以信息/秩/投影目标的形式定义；具体选择算法见 DESIGN）。
3. 用真实**新矩**重新拟合作用并**检验闭合**：闭合成立 → 多步程序由 **K 的乘积**计算，新功能在**已测函数范围内重组**；失败 → 报告**哪一作用/时程**不可复用，**不继续强行滚动**。
4. **明确开放问题**（不得声称已解决）：采用哪些函数、何时增补、有限样本下怎样控制误差，仍是待发展的具体算法问题；本预注册只冻结评估协议与停止条件。

## 3. 与 KoopCell/DisKO/受控 EDMD 的差异边界（写死）

- **固定 φ 的线性闭合版本由受控弱 EDMD / 系统辨识 + 最优输入设计直接覆盖**，必须作为**等价强基线**；若同预算下该基线复制（或超过）候选 → **撤主算法主张**（`no_increment`/`rename_edmd`）。
- KoopCell/DisKO 已覆盖部分未配对群体学习，**不能声称新**；TD-JEPA/后继特征已覆盖转移/目标复用（所读使用 (s,a,s′) 转移），**不能声称新**；BATCHIE 已覆盖模型后验+真实反馈+批量选择，**不能声称新**。
- **拟研究的交叉点仅是**：在**破坏性群体测量**下，由**功能任务主动选择实际干预**来辨识**可复用作用**；若该交叉点在等预算下不产生独立功能决策增量 → 撤主创新主张。
- 生物兼容条件：起终姐妹制备在来源/处理历史/批次可交换；不伪配同细胞轨迹；计数保留；反馈策略需策略加权函数闭合，不能把固定混合 K 用于任意反馈策略；新药无相关输入特征/真实反馈时无自动迁移保证。

## 4. 受控真值测试床（Stage 1；已知真值）

- **合成群体系统**：隐藏状态 d=4（含历史项）；非线性转移/非闭合反例；**已知 K_a 真值**（seed 固定，方法不可见）；动作 A=3、φ 维 p=5、cohorts=200、timepoints=3。
- **可辨识性检查**（本设计算术）：
  - 同 U 群体矩：`V_i=Σ_a π_i(a)(K_a U)`；assignment 设计 rank=**3/3** 时 `K_a U` 全部可辨识；若只有 mixture 设计则仅 rank 个线性组合可辨识。
  - **full K_a**：每动作需 ≥p 个纯分配且 `U_i` 张成 R^p → design rank **48/48（A=3,p=4 例）** 时 full K 可辨识；mixed assignments 仅 rank **40/48**（部分可辨识）；无支持动作（positivity 违反）→ K_a 不可辨识。
  - **gauge**：φ 基变换 `K_a→M K_a M^{-1}`；基/符号对称；这些不是可辨识内容。
- **非闭合反例**：`φ=(1,x)`、线性动态 `x'=a x+b+ε` → 闭合残差 **2.7e-15**（闭合）；`φ=(1,x,x²)`、动态 `x'=x+a+c x²+ε` → `E[x'²]` 出现 `x³/x⁴` 项，**闭合残差 3.7577**（不闭合）。合成算术，不外推真实生物。
- **正交设计示例**：相同 U 下 `π=(1,0)` 与 `π=(0,1)` 分离 `K_1U`、`K_2U`；`.5/.5` 只给平均；两种不同混合可分离二者但**不能识别所有 K**，也**不保证混合优于纯药组**；不得声称。
- **随机化/可交换性合同**：π 已知且先于结果、与隐藏状态独立（给定记录历史）、各组起始分布可交换；若分配依赖记录 X0 → 用记录态估计式；检查平衡表/支持/交换性；失败 → `design_invalid: randomization`。
- **pilot 计时**（planning arithmetic only）：10 replicate 设计/估计算术 **0.00303 s/rep**；投影 stage1 **0.1 s**、stage2 **0.4 s**、stage3 **1.5 s**（caps 600/1800/1800 s、CPU 2 h、内存 8 GB）。

## 5. 最小验证三阶段（预注册；本任务不运行）

1. **Stage 1 受控真值系统**：检查可辨识性/非闭合反例/随机化可交换性；不报增益、不称真实证据；合成 compute-only 0 wells。
2. **Stage 2 多时间功能数据、固定反馈比较学习**：在**合格**多时间功能数据（同一培养物/背景/批次可交换；剂量/时间/功能 readout；独立培养/板重复；计数保留）上，以**相同固定反馈**比较候选与强预测器（full-history retrain、hierarchical-GP、KoopCell/DisKO 适配、TD-JEPA/后继特征适配、state-space/PKPD）；同信息/同预算/同调参；**先留出程序，再留出背景**。
3. **Stage 3 固定更新器比较取证**：候选**主动干预选择** vs random/GP/最优输入设计/BATCHIE 适配；同固定更新器与预算；最后**完整闭环**（计培养物/板/对照/失败/重复/标定/计算/调参）。
- 只换已观测功能权重 = **有限任务重组**，不是未测生物终点零样本迁移；新功能给所有方法同样标定；跨任务失败 → 限当前任务。

## 6. 主端点/δ/功效（按端点规划；不用 6,282 通用门）

- **Primary**：**独立功能下的实际决策效用/后悔**（per endpoint 分别定义与规划）；δ=**0.05 normalized**（由决策相关性预注册，不事后降）。
- **先检查天花板/可达性**：`headroom=U_max−U0`；headroom<δ → `unreachable_gate`（不是算法失败）；基线近满分 → 另立 budget-to-target 问题，**不静默换端点**。
- **配对功效**：连续端点 `MDE80=2.801585×SD(D)/√n_ind`、`n_req=ceil((2.801585·SD/δ)²)`；二值端点用 discordant variance；**按独立培养/背景/任务聚类**（技术重复不作独立单位，cluster ICC 计设计效应）；**6,282 只作 Fisher-z 参考，不作通用门**。
- **次端点**（只作 secondary）：预测校准、算子/K_a 误差、RNA 误差；RNA 提分/内部一致性**不能替代**独立功能决策。

## 7. 等预算强基线 / 停止（写死）

**基线**：受控弱 EDMD/工具变量系统辨识 + 最优输入设计（**等价强基线**）；KoopCell/DisKO 适配；TD-JEPA/后继特征适配；状态空间/PKPD；层级 GP；全历史重训。**同信息/同预算/同调参/同合法实验包**。
**停止/撤主张**：
- 标准方法（尤其受控 EDMD+最优输入设计）同预算复制/超过 → **撤主算法主张**（`no_increment`/`rename_edmd`）。
- 闭合/随机化/测量合同不成立 → stop（`design_invalid: closure/randomization`）。
- 收益只出现在 RNA、无独立功能决策增量 → **撤主创新主张**。
- 反馈/实验成本超冻结上限 → stop；CI 不能排除无实用收益 → `inconclusive`；跨任务不成立 → 限当前任务。
