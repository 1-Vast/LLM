# root 独立推导：频率差分不能单独指定增敏机制

2026-10-28。在P9初判返回前独立书写，未向审阅者发送。本项为精确代数反例；不读取真实功能数值，不是药物效果实验或新的候选算法。

待核对象：开发稿的Δ=[q(T,D)−q(T,0)]−[q(V,D)−q(V,0)]。这可以是合法的绝对频率交互，却不能仅由其数值把作用唯一解释成“Doxo敏感性改变”或“经BCL11B中介”。

设两预处理的无Doxo形成频率不同，b_V=4/5、b_T=2/5；Doxo在两者中都把形成概率乘以同一比例r=1/2：q(V,D)=2/5、q(T,D)=1/5。则

Δ=(1/5−2/5)−(2/5−4/5)=1/5，

而两组q(p,D)/q(p,0)都恰为1/2。一般式为Δ=(b_T−b_V)(r−1)。所以即使比例药效相同，基础形成能力也会改变绝对交互；若只看Δ跨救援背景的变化，不能排除救援改变b_g所致。

这不证明风险比天然正确，也不否定绝对功能效用。临床/筛选的绝对减少本来可能重要；比例尺度还会在分母低、测量误差或选择条件化时不稳。应先固定问题与尺度，呈现四格原始频率、每起始细胞/孔的分母和无药形成能力；中介判断另需干预排除条件及有效救援，不能由换公式获得。

停止条件：在原始四格、起始数量与独立培养未核齐时，不用该交互拟合/筛选生物结论，不从图高估值，不启动M2或效果实验。这个反例只限制解释，不认证H1或H2。
