共同边界：一个行动施加于整个培养物；细胞快照是破坏性袋样本而非纵向配对；功能结果需单独付成本；不能把RNA生成的伪功能当真值。可操作单位是可复现培养物/姐妹培养物与已知培养历史。单细胞状态只能作为一次袋观测。

## S1：由任务定义的培养物历史等价类（learning a predictive quotient）

问题：RNA相似的培养物是否应当共享同一个可控制状态？这不由嵌入距离定义，而由未来可执行任务的结果分布定义。借用机器人 predictive state / NLP 最小自动机 的思想，把学习对象改成“历史对未来干预与功能测试的可区分性”。

运算：h=(已记录暴露、历次袋观测、历次真实功能结果)。q为有限长度、整培养物可执行的干预后缀与付费功能测试。定义 h~Q h' 当且仅当，对当前任务允许且有预算的每个q，P(Fq|h,do(q))=P(Fq|h',do(q))。模型学习等价类zQ(h)及其预测表，而非声称还原每个细胞的真实轨迹。新任务扩展Q，会细分旧等价类；真实功能反例会拆分旧类，进而改变可选行动排序。

具体例：两培养物现在的RNA袋及单次存活率相同，但一个经历过可见的应激预处理。任务只是明天存活，两者可合并。任务改成“撤药48h后恢复分泌功能”，后缀q=撤药→付费分泌测试产生0.8与0.2的成功概率，必须拆分。模型下一轮给低恢复类选择恢复处理，给高恢复类保留预算。这里只是假设例，不是生物机制结论。若初始背景与历史完全不可见、且重复培养不能支持条件比较，则只能输出同一观测历史的混合预测，不能给每个培养物识别隐藏类。

最小可发展贡献：证明在袋观测+整培养物行动下，任务诱导的有限后缀等价类何时足以保持最优决策；再给有限功能预算下的拆分类准则。必须对比普通belief-state模型/PSR在同一信息、同一真实反馈与同一预算下的决策。若只是PSR换成RNA输入，则无新算法贡献。

失败条件：后缀不可重复；培养物间非交换性；只依靠袋分布无法识别关键历史；任务族无法以有限后缀闭合；任务变更超过所记录历史的分辨率。不要把主动探测获得更多信息的优势算成表示学习贡献。

预期最近邻（未核对）：Predictive State Representations、controlled causal states、bisimulation metrics、active automata learning；生物中需查任务驱动扰动表示/active perturbation learning。

## S2：任务诱导的可恢复集合，而非未来RNA图像（learning a budgeted recoverability set）

问题：实验者不只需要预测下一张快照，还需要知道“在剩余预算内，当前培养物是否仍存在可执行路径达到目标真实功能”。借用机器人 reach-avoid / viability kernel 思想，将学习对象改成有限预算下的可恢复边界。目标任务改变边界，真实成功/失败改变下一轮选择。

运算：b(h)为与可见历史一致的培养物状态/动力学假设集合，预算k。目标G由付费真实功能界定；坏集合D由约定不可接受功能结果界定。K0={b:功能证据支持G}；K(k+1)={b:存在整培养物行动a，使所有仍可行的下一观测分支b'均不落入D且属于Kk}。若要求鲁棒过强，可事先冻结允许失败概率delta，用后验成功概率替代“所有”。每次真实功能反例删除原来被假定可恢复的分支，重算集合并选择能扩大可认证恢复范围的后续实验。不能由RNA把G免费标注。

具体例：处理A使当前存活率更高但在预算内无法恢复分泌；处理B早期存活略低却可经一次撤药达到目标分泌。单步存活最优策略选A；任务若定义为“2步内恢复分泌且存活不低于阈值”，可恢复集合策略选B。真实功能测试若证实B的恢复路径失败，该路径被删除，下一实验改为验证尚可能的C，而不是继续拟合RNA。假设数值与生物关系均未实证。

最小可发展贡献：在未配对袋观测与昂贵功能验证下，定义可认证的培养物层可恢复区域；输出“尚可恢复/已排除/证据不足”而非虚假细胞命运。应比较同信息的有限时域POMDP、safe RL、reachability/robust MPC。若仅在标准robust reachability上套单细胞编码器，则标准方法等价。

失败条件：无法可靠重建姐妹培养物的反事实分支；对隐藏背景的置信集没有有效覆盖；预算太小导致所有点都证据不足；危险/恢复标签稀疏到边界无法收缩；不可逆生物变化与批次漂移使原边界失效。没有获得真实功能标签的区域必须保持未知。

预期最近邻（未核对）：partially observable reachability、safe active learning / safe Bayesian optimization、viability kernels、robust MPC；生物中需查adaptive treatment、drug scheduling与实验闭环。
