# A1 / M2 continuation v4: task-conditioned evidence coverage

2026-10-28。Parent：M2 candidates_v3 与 Agent A机制合同；本轮初始具体化，旧轮2次修订保留。本候选不重跑旧N1，也不预设独有算法成立。

科学问题：完美拟合已有单步群体响应，何时仍不足以支持新给药程序？Agent应购买哪种实际可执行的前缀处理后证据，让模型学到下一决策需要的作用，而非仅增加同分布重复？

对象：有限培养物状态上的动作条件核P_a；状态可由实际读数分箱，终点功能f独立测量或在合成例中共同已知。μ表示cohort中独立培养物的起始状态分布，不允许逐细胞自由给药。源实验给出μ_i P_a；缺单体配对，不从这些边缘分布臆造核。

操作：维护观测过的起始cohort矩阵M及动作条件输出MP_a。任务给出合法程序与终点f；对程序所需的后继cohort分布，核查其是否在已辨识作用的起始分布张成空间内。若不在，拒绝把点预测当已识别作用；Agent只可选择合法前缀处理后施加目标动作的实验包，使相关作用获得独立约束。真实群体/功能反馈加入矩方程，再计算未查询程序值。估计误差/噪声应另记，空间覆盖本身不保证有限样本精度。

具体构造：两状态，μ=(.5,.5)，f=(1,0)。两世界共享P_A=[[1,0],[1,0]]；P_B分别为I或交换矩阵S。对μ的A/B单步完整输出完全相同。合法同钟长程序A→B与V→B（V=I）；前者功能在两世界为1/0，后者均.5，最优选择相反。无新信息时即使随机策略，其最坏regret至少.25。前缀A可产生(1,0)，该cohort上B的实测功能能在这个确定性二模型构造中区分；真实噪声/多模型条件下不能声称一次实验足够。

必要生物条件：匹配姐妹制备可交换；同剂量/时长、残余A/洗脱、密度/增长均需明确；若A→B期间存在未建模暴露效应，则把完整历史纳入条件，不将B核当无历史药理定律。当前AZ只有同时/终点资源不能执行这个程序验证。源cohort是培养物分布，细胞混合可加性不被免费假设。
