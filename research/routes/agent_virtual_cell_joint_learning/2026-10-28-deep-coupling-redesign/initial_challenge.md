## Initial result

All three candidates name meaningful scientific questions and some mathematical objects. None yet specifies an algorithmic mechanism sufficiently to claim a new capability beyond its strongest existing general method. This is a judgment about the frozen constructions, not a claim that biology is unimportant or that a general POMDP formulation already implements them.

### M1: realizability under a common culture-level action

The stated objective is a policy projection of a target path distribution onto a legal controlled-kernel family. This is a concrete optimization problem, and the common-action counterexample correctly excludes an invalid cell-wise controller. It does not yet distinguish a new solver from constrained control-as-inference, restricted Schrödinger bridge / KL control, or an ordinary correctly specified planner. The decisive comparator must share the same physical culture state, legal dose programs, target functional, observation model, and physical feedback.

Missing construction: the exact target proposal, direction and support of the path divergence, the variables held fixed in each alternating update, and a mathematical reason why recycling the projected distribution changes an answer or efficiency relative to solving the constrained objective once. If Q gives positive mass to physically impossible paths, D(Q||P) can be infinite; the two-action example appears to fall into this case for a hard all-zero target. A finite-gap or infeasibility certificate must be defined before the projection is executable. Updating theta on genuine feedback is appropriate but is also ordinary model-based control; it does not itself establish a joint-learning distinction.

The common culture state X must carry enough information to predict interactions, counts, and history. A single-cell transition kernel plus a common action is not automatically a culture transition kernel. Experimental-unit randomization mixes whole culture outcomes; it does not grant within-culture action assignments or arbitrary mixture states. These are restrictions on the scientific model and useful falsifiers, but not novelty by themselves.

### M2: weak observations of a long-horizon functional operator

Successor / occupancy factorization is a genuine reusable object, but the supplied transfer example is already a standard successor-feature property. The potentially substantive problem is whether the required operator is identifiable from the stipulated unpaired, destructive, culture-level observations. No actual weak-moment estimator or policy-update equation is specified yet.

If only starting and ending marginal distributions are observed, many couplings and generators can agree with them. A semigroup's action on chosen test functions may be identifiable without a cell coupling, but only for the excitation span, time points, actions, and function class actually measured. Iterating a finite-time operator to obtain an infinite-horizon successor object adds Markov, closure, stability, and policy-composition assumptions. Feedback policies require a measured state or belief at each decision time; destructive single-cell snapshots do not furnish a surviving culture's full state at zero cost.

There is an important type distinction: psi of one cell, a population empirical functional, and psi of the sufficient culture state are different objects. Weak population moments need not identify a nonlinear culture-state operator, particularly with density dependence, growth/death, or cell interactions. Need an explicit observation equation linking each measured weak moment to M, without pretending that individually destructively sampled cells form transitions. Same-information strongest baseline is controlled weak-generator / Koopman identification plus successor features and optimal input design. Whether the proposed combination is more than that baseline remains open.

### M3: forward/backward learning of recoverability stopping events

The scientific event is important. Once the physical generator, boundaries, and future policy are specified, the committor is already a backward value equation for an absorbing process. Reusing that generator for forward evolution imposes compatibility, but solving both Kolmogorov equations is not yet a new learning mechanism. A strong survival or absorbing-control model can use exactly the same late functional labels and observation schedules.

Missing construction: a likelihood or moment system for molecular snapshots, counts, stopping outcomes and censoring; identifiable parameter restrictions; and an actual joint update showing which forward and backward information independently constrains theta. If q is computed from L exactly, a residual Lq=0 adds no new data. If q is fitted independently, the proposed shared consistency can be a useful regularizer but its benefit must be measured against the exact same constrained generator likelihood. A learned event predictor must condition on the future policy, or it confounds treatment changes with recoverability.

The endpoint labels must distinguish extinction, no regrowth within finite observation, and irreversible loss of regenerative capacity; these are not interchangeable. Hidden surviving cells and an insufficient follow-up horizon can make an apparent absorbing boundary nonabsorbing. Interval/right censoring and policy-dependent observation cannot be repaired by an ordinary unqualified survival head; they need an explicit observation process and enough positivity. This is a data condition, not automatic extra novelty.

## Cross-candidate gates

1. Separate a useful scientific target from a new algorithm and from demonstrated drug-decision benefit.
2. Specify the state space and measurement map before writing a generator or TD-like relation.
3. Freeze feedback, history, pretraining, functional labels, actions, and computation for the first comparison; then test experimental acquisition separately.
4. A correct general method's ability to express the problem is not an implemented baseline. Conversely, a biologically specialized constraint is not by itself a new solving principle.
5. At present: three mechanism hypotheses, zero independently verified new algorithms or effects. Literature check will test direct coverage, particularly M3; it will not invent revisions or infer whole-paper contents from excerpts.
