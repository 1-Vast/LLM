# 冻结候选 v1 的独立机制质疑

2026-10-28。P4 独立 challenger。requested Sol/xhigh；effective model 无可用 metadata，记 unknown。先读 BRIEF 与冻结 candidates_v1，先保存 initial_challenge.md，随后才交流。未读 scout 初稿/总结或协调者后续报告。追加阅读限于一手论文、官方 README 与 sources 内原样检索响应。新增主题查询 **4/4**；完整工具响应和精确请求存于 sources/challenger。无训练、模拟、安装、数据/权重下载、src、goal 或 Git 操作。

## 结论

三项都可成为有用研究问题；冻结 v1 中**没有一项已足够具体，能独立支持“新算法/新解决原理”正判**。这不证明整套生物任务已经被现有软件完成，也不证明这些方向不值得研究。主要差距是：已有明确运算受到强近邻覆盖，而最可能新增的部分尚未给可执行构造、识别条件及相对同信息强基线的分离证据。

| 候选 | 已成形且有用的部分 | 直接覆盖/核心风险 | 当前判定 |
|---|---|---|---|
| M1 | 真培养物合法共同动作下的可达性与目标路径投影 | 受约束 control-as-inference/SB 已处理合法 policy 实现；尚无不同于其求解的交替机制 | 科学/建模约束明确；算法新意未成立 |
| M2 | 目标可复用的长期功能算子、无配对群体观测 | SF/FB/TD-JEPA覆盖长期策略因子化；KoopCell/DisKO已从未配对快照学习弱算子/表示 | 潜在识别问题明确；新估计器与控制耦合未给出 |
| M3 | 将恢复/灭绝作为停止事件、统一生成器及删失 | committor、停止算子、受控吸收过程的同一生成器前后向方程；残差可能只是定义恒等式 | 科学终点有价值；具体共同学习机制尚未成形 |

“一般 POMDP 可以表达”不算实现覆盖；“培养物而非机器人/分子”也不自动产生算法创新。以下均针对冻结版本，不替候选发明修订。

## M1：可实现路径投影

**原理核查。** [Ito–Kashima, arXiv:2610.17965v1](https://arxiv.org/html/2610.17965v1) §II-A 明确从受输入集合限制的因果 policy 出发，脚注允许将输入参考测度改为 counting measure 以处理离散输入；§III-C 给 policy 重加权及后向递推，§III-D 给有限态近似/Sinkhorn，Corollary 1 处理有限 KL 可行性。因此“目标桥必须由合法动作实现”“后向消息修改合法动作概率”不是空白原理。**覆盖有限制**：所读主要构造基于已知确定性 f_k，不能声称它已完整实现未知、随机、有交互的培养物转移学习。

**缺少的必要运算。** v1 没有指定 Q_g 如何生成、D 取何种散度、交替两步分别固定什么、投影返回下一轮后求解哪个明确目标。若 D 是 KL(Q_g||P^pi)，且 Q_g 给真实共同动作不可能产生的路径正质量，所有合法 pi 的目标都可为无穷。冻结文本已保留“散度/支持先定”，但正因未定，目前仍不是能在其不可达反例上运行的算法。把“有不可达缺口”写在输出要求里不等于已经定义这个缺口的求法。

**反例能证明什么。** identity/swap 例子正确排除逐细胞自由施药。它没有区分 M1 与使用同一培养物状态和真实动作的 MPC/程序搜索/受约束 SB。培养物状态必须承载细胞间相互作用、数量和必要历史；把单细胞核共用一个药物索引，不自动等于正确培养物核。实验单位间随机化也不允许合成任意培养物内部状态。

**必须满足的同信息强比较。** 已知核时先与精确受约束控制、受约束 SB 的有限离散解比较；核未知时允许这些方法使用完全相同的实测反馈和更新器。需要区分“规划误差降低”“目标不可达识别更准”“转移估计变好”的来源。目标指导采样后再更新物理模型也是标准 model-based/dual control 路径；v1 未给除此之外的增量运算。仅胜过自由逐细胞控制或无动作支持的 guidance，不足以正判。

**明确缺口。** 可执行的散度/支持合同与交替更新；相对正确受约束求解器的分离例或复杂度/样本收益；真实培养物状态及观测闭环。当前不予新机制正判。

## M2：弱观测的长期功能算子

**已知长期因子化。** [TD-JEPA, arXiv:2510.00739v1](https://arxiv.org/pdf/2510.00739) §3、Eq.7/9/Algorithm 1，已经共同学习状态/任务表示、策略条件长期 predictor 和 actor；§3.3 从真实 reward 样本线性回归任务向量。其 TD 更新明确用 (s,a,s') 配对一步转移。[FB, arXiv:2103.07945v3](https://arxiv.org/pdf/2103.07945) §3、Eq.5–8 已给长期占用因子化及奖励后定策略；还允许学习中策略采集探索数据。二者不能直接拿无配对细胞边际替换 TD 转移；但“共享长期对象、换目标复用、策略反向训练表示”本身已有具体算法。

**无配对快照也不是未开发前提。** [KoopCell, arXiv:2609.33350v1](https://arxiv.org/html/2609.33350v1) §3.1、A.4.2、B.1 已用弱群体残差、测试函数与闭式回归，在表示/生成器间交替。其理论需要可识别/稳定性等条件，明确不保证实际采样、求积、正则化和优化误差。[DisKO, arXiv:2609.34629v1](https://arxiv.org/html/2609.34629v1) §3 直接把分布作为状态，共学可预测分布观测、有限 Koopman 表示及生成映射；G.3 区分观测充分性、选定统计闭合与全分布重构，并给有限采样时间的生成器混叠。两篇所读构造不等于已实现受药物策略控制、数量增减与独立功能锚定的 M2 全任务。

**识别不能靠措辞完成。** v1 还没有一条把实际可测起点/终点群体矩映射到 M_theta^pi 的具体估计方程，也没说明可执行干预如何改变待辨识矩阵的秩。若 psi 是单细胞函数、M 却条件于整个培养物状态，必须给类型一致的观测映射；若 psi 是非线性培养物函数，经验细胞均值通常不等于该函数的观测。以群体分布为状态能避免部分类型混淆，但并不自动使其在隐藏历史/密度依赖下充分。

举例：均匀圆周群体在静止与恒速旋转下每个时点边际相同，因此不能从该序列恢复单细胞条件占用。若任务只要求该固定群体的平均即时函数，两者反而可能决策等价；不能用这个例子夸大成“所有功能任务均不可识别”。真正要证的是指定观测等价类内，候选所需的目标价值/策略是否相同。反过来，多种可合法制备的初始分布与实测动作可能打破等价；需要明确提供，而非默认 Agent 能任意 reset。

[Guan et al., arXiv:2410.22729v1](https://arxiv.org/html/2410.22729v1) Theorem 4.3/§5.3 给线性加性噪声边际识别条件及 APPEX 的 OT/MLE 交替估计。它说明特殊类里存在实际估计法，也说明不能把有限矩、任意非线性动力学或未知药物迁移一并带过。本次未复核其全部证明或代码。

**必须满足的同信息强比较。** “普通弱生成器/分布 Koopman + SF/FB/决策器 + 系统辨识输入设计”是须具体实现的主比较，而不是只有原版 TD-JEPA。不得让 M2 多获得功能标签、起始条件、计数或调参预算。固定反馈后，辨别所选目标函数的误差与决策遗憾；再固定学习器比较实验激发。长时目标迁移不等于新细胞或新药迁移。

**明确缺口。** 从现有测量到策略条件长期算子的估计构造；目标价值而非全动力学的识别界；相对上述组合基线独有的有效运算。当前不予新机制正判。

## M3：停止过程前后向共同学习

**核实已有的具体内容。** [Data-driven methods to estimate the committor function, NPG 2023](https://npg.copernicus.org/articles/30/195/2023/index.html) §2.3 Eq.5–9 就是生成器的 Dirichlet 停止问题；§2.4 用轨迹构造转移矩阵求 committor。[DGA with memory, JCP 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC10898919/) §II、Algorithm 2、§III C，给停止转移算子方程和投影估计，不只是概念名称。它需要短时序/配对动态数据，不能冒充已解决破坏性分子快照条件。

[Rotskoff et al., arXiv:2008.06334v2](https://arxiv.org/pdf/2008.06334) §III/Eq.24/Algorithm 1 已用当前 committor 网络决定采样窗口，重加权后继续更新网络；“估计的恢复边界指导取证、反馈再改边界”这一抽象闭环并非新原理。其已知 Langevin/Boltzmann 取样条件与真实培养物施药明显不同，不能直接视为 M3 的现成生物实现。4 条主题查询内未找到同时处理 v1 全部生物观测/删失/控制条件的精准同款；**未找到不等于首创**。

**一个可以写出运算的强基线，而非泛称 POMDP。** 固定同一信息预算，考虑培养物层有限隐状态受控 CTMC；固定 pi 后生成器为 Q_theta^pi，令 I 为非终止状态，E/R 为两类停止边界。若 I 暂态且事件定义有效，则同一 Q 同时给出：

- 前向状态分布：p'(t)=p(t)Q。
- 后向事件概率：Q_II q_I = -Q_IE 1，q_E=1，q_R=0。
- 未终止概率：S(t)=p_0,I exp(t Q_II)1。
- E 类事件密度：f_E(t)=p_0,I exp(t Q_II)Q_IE 1。
- 右删失贡献 S(c)；E 类区间删失贡献 integral_l^u f_E(t)dt。

以上是标准有限态停止过程的代数推导，用于指定比较对象；未实现、未运行，也不是替 M3 发明新方案。分子快照可通过观测映射约束对应培养物层潜在分布；与独立培养物事件数据按实际独立单位构造似然，不能伪称同一细胞轨迹。动作变化用相应分段生成器/状态反馈模型处理；信息不足时此基线同样不可识别。

这个基线已经让晚期事件/删失与早期观测共同更新 theta，并由同一个 theta 重算 q 和计划。v1 尚未指出自己的弱残差共同学习增加了哪一个基线不能做的必要运算。如果 q 从 L 精确算出，Lq=0 是定义关系，不是新增证据；若另拟 q，残差是近似一致性约束，其价值需对比同信息联合似然/可微求解，不能仅对比不相容的两个 heads。

**科学解释的额外边界。** q^pi 是后续策略 pi 下的成功概率。一个停药可恢复的培养物也可在强持续治疗 pi 下有高灭绝概率，因此 q^pi 不是内禀不可逆损伤的直接读出。恢复研究必须明示参考后续处理、起算时刻与观察期。灭绝、有限观察期不再生长、永久丧失再生长能力也不是相同实测事件。只要有隐匿残存或迟发恢复，“未观测恢复”就不能默认吸收态。初始样本已在 regrowth 边界时、两边界都永不到达时、非平稳/有限时窗时，需补完整问题条件。

**明确缺口。** 可识别的观测/停止/删失联合系统；可实施的共享更新及其相对上述具体强基线的分离；policy-specific 达成率与恢复科学结论的区别。当前不予新机制正判，不能以“survival head 太弱”充强基线。

## 对成果资格的建议边界

当前可正当宣称的是三个待发展的机制假说和一批已定位的技术缺口；不能宣称三项独立算法创新、元学习/RSI、药物决策收益或生物不可逆机制。M1 的物理动作正确性、M2 的功能可识别性、M3 的操作性恢复终点，都可能形成实质研究工作；是否形成新方法，取决于补出的构造和公平分离，而非命名或闭环图。

不要求立即给全部复杂生物条件的定理，也不以抽象最强 planner 充已跑基线。但在没有关键运算时，应保留未成形判定，而不是为达到数量改名、把能力分支重复计数或将缺数据当作创新本身。
