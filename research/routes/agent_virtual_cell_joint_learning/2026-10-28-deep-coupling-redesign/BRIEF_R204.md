# R204 BRIEF：主线收敛到"Agent 主动学出可复用的药理控制模型"（2026-10-28）

## 0. 用户方向（本轮采纳）
主线 = **Agent 主动学出可复用的药理控制模型**；结合点进入模型学习对象：Agent 的药物目标决定需要学习哪些功能，实验选择改变这些功能的可辨识性，真实反馈修订作用规律，再改变下一轮给药。
- 比"预测—筛选—重训练"更深；但 **CellForge v3（arXiv 2508.02276v3）已能让 Agent 改表示/损失/训练方案** → "Agent 可以改模型"不足以构成创新。
- 九方向（D1–D9）与三机制（M2/M1/M3）见 `research/2026-10-28-deep-coupling-redesign/report.md`；本轮只采纳方向与停止边界，**不声称任何算法首创**，未跑新效果实验。
- 优先级：**D1/M2 首选主线**（任务驱动、主动辨识的群体功能算子）；**D2/M1 另一条独立主线**（可执行生成式规划，保留随机药效）；**D3/M3 支撑研究**（同一组决策反馈分数，先与 DR/TMLE/加权重训充分对照）。
- 近邻不可声称：KoopCell/DisKO（未配对群体算子/观测充分性）、TD-JEPA/Diffusion Forcing（策略条件表征/联合生成）、BATCHIE（模型后验+真实反馈+批量选择）、受控 Schrödinger 桥/最大熵控制（一步投影）、DR 策略评价/TMLE（决策反馈信用）。固定 φ 线性闭合的受控 EDMD/系统辨识+最优输入设计是**直接等价基线**；若同预算复制 → 撤主算法主张。

## 2. 主线执行原则（写死）
- 主端点=**独立功能下的实际决策效用/后悔值**；预测校准、算子误差、RNA 误差为次端点；RNA 提分/模型内部一致性/生成逼真不能替代主端点。
- 三组验证：① 同一份反馈比较学习（等信息/等预训练）；② 固定更新器比较取证（等成本/等合法实验包）；③ 完整闭环（计培养物/板/对照/失败/重复/标定/计算/调参成本）。
- 冻结 δ、可达性/功效，**先检查基线天花板**（不得重演 T1 不可达门）；按独立培养/背景/任务聚类 CI；不得把同药重切分/well/技术重复当新生物样本；多方向筛选保留选择过程，确认数据不参与挑候选。
- 统一停止：等预算强基线复制 → 撤主算法；随机化/支持/观测合同不成立 → 停；反馈成本超冻结上限 → 停；CI 不能排除无实用收益 → 不确定；跨任务不成立 → 限当前任务；不得把算子闭合/DR 校准升级为靶点/通路机制（靶点需干预参照）。
- 不称新颖性/机制/迁移/真实决策收益；不晋升代码；不恢复已停止实验；不改旧判定/门槛。
