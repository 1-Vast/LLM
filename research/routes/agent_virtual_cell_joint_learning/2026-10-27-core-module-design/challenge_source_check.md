## 对中心方法覆盖的核查

**T1 加强，须区分“标准工具能表达”与“已找到完全相同的药理学论文”。**

把 (c,b,m) 视为任务索引，把 a 视为动作，把 y 视为一步终点效用，候选的关系就是任务集合上的近似奖励向量等价：d(a,a′)=sup_{c,b}|y(c,a,b)−y(c,a′,b)|。这不是需要状态转移的全动态 bisimulation；它是更简单的动作/任务抽象。分域 g 后分别计算这个距离，就是条件版本。用普通 f 估计 y，再把距离表按 diameter 约束分组，即可输出候选类；新反馈重训 f，再重分组即可输出反例分裂。这里是结构性归约推导，不是某篇药物论文已经做完全部内容的文献事实。

目前的操作未超出普通响应预测+条件分组+任务主动学习。若“类是 f 的输出”，没有额外共同学习机制；若“类约束 f”，v1 尚需明确参数/约束如何介入及其相对层级/共聚类的差别。一个科学结构可以由标准模型发现，所以这不自动否定药理规律研究价值；它阻止的是把流程本身称新算法能力。

### BATCHIE：直接覆盖的部分

原始文件：research/2026-10-26-agent-cell-evidence/sources/PMC11696745.xml，DOI 10.1038/s41467-024-55287-7。

- **Sec12，全文读取。** 模型联合处理单药和组合，以 drug-dose 为单元；细胞嵌入、单药主效应与三向交互共同构成条件均值，Gibbs posterior 更新。普通同信息模型已能表达细胞条件响应差，不必通过新实体获得该能力。
- **Sec14，全文读取。** PDBAL 从一般参数空间 Θ、实验 X、结果 Y 出发；d(θ,θ′) 可为任意 bounded、nonnegative、symmetric 距离，目标为减小后验平均直径。以多个实验组成 plate 并按预期信息挑整板。**由此可推导**：对有界效用和冻结有限菜单，用替换判定/替换损失分歧构造 d，属于已给的一般接口；不因此成为新主动学习原理。原文没有在此节宣称使用本候选的条件替换类。
- **Sec24，全文读取。** 实际包括均值预测距离和 therapeutic-index-aware 的 top-K 决策距离。因此不能声称前作只会优化全局预测、不支持决策相关反馈。
- **Sec26，全文读取。** 新细胞加入时先覆盖未测 drug-dose 与组合；实际筛选受细胞可用性和整板约束。前期单次板测量出现难发现的随机孔故障，后期改重复板与 QC。这支持将独立重复/真实板成本视为必要实用条件，不能把理论 query 数直接当节省的湿实验数。

### PDTSyn 与 DECANT：相邻覆盖，不能冒充同任务证据

- **PDTSyn，PMC13109062.xml，DOI 10.1093/bib/bbag199：** sec2g 全文、sec2h 开头至式(12)及维度小节开头、sec2r 全文已读；sec2h 后半维度/开销讨论未读。共享 Transformer + 细胞系特征生成共享基的组合系数，已具有共享/背景特异组合表征。sec2r 明确分布对齐假设。未找到于这些段落进行主动反例分裂或最大等价认证的叙述；不能说它覆盖所有 I-CD1 细节，也不能把“共享+特异”本身留给 I-CD1 当创新。
- **DECANT，PMC13587831.xml，DOI 10.1093/bioinformatics/btag662：** 摘要与 sec28 Discussion 全文已读。作者明确转录层面组织并不建立 target engagement、分子机制或因果通路活动；当前 holdout 非 scaffold/family holdout。作者还指出单 prototype 会掩盖多靶点/强背景特异药物的不同模式，并提出 context-stratified/multi-prototype 未来方向。这加强“分背景组织药物表征并非全新未知问题”的质疑，但转录原型不能证明独立药效可替换。

### 抽象与迁移来源的边界

- **arxiv-2606.25357 paper.html：** 摘要、§4.1、§4.4、§5 全文读取。§4.4 将 value-equivalence 明确为 value function 的核，并指出等值不保证相同行为的一步分解；§5 以 strict homomorphisms / exact structural preservation 为现有范围，近似 slack 和实用学习算法是未来工作。不能将它引用为已经给出带噪药物主动分裂算法，但其原理也不支持把“保留任务值的压缩”当 I-CD1 的一般原理首创。
- **arxiv-2608.15645 paper.html：** 仅摘要及目录读取。摘要明确同变量、同图、同干预以及已知变化机制；近似映射导出 certified query intervals。未通读定理，因此不判断其界能否直接迁入药物数据。I-CD1 没有这些结构前提，不能借用其认证标签。
