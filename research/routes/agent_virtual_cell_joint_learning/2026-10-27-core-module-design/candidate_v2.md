# I-CD1.v2：条件功能关系的可迁移修订（冻结复审版）

2026-10-27。v1→v2 为第 1 次实质修订（上限 2）；初判原文见 initial_challenge.md。本版本是研究设计，不是通过验证的创新算法。

## 修订改变什么

- T1：撤下“分裂本身是独有学习算子”。以**是否存在有用、可复验的条件功能结构**为中心科学命题。给出完整的最小统计实现，承认其为受约束的普通模型选择/重训练；独特算法贡献仍未建立。若用户的必要目标是新算法，当前版本只是一项待发展的研究问题，不能包装成已完成算法创新。
- T2：用明示预测表修正原正例。不同成员和不同伙伴的观测各自识别不同解释，不能互换；开放类外解释始终保留。仅在冻结有限假说族内可以识别，不外推成任意真实机制已识别。
- T3：明确三种输出：模型候选范围、独立分布风险估计、有限菜单同时认证。当前只有前者的设计，不用逐点区间认证全域最大损失；不对所有未测条件作保证。
- T4/T5：只有处于活性、非饱和且有实际选择差距的动作才计实用收益；认证、重复、单药/对照成本进入总预算。完整确认资源尚未准入。

## 核心科学对象

对固定端点与合法 dose/time 的 y(c,a,b)，学习同一伙伴下替换药物的差异

`Δ(c;a,a';b)=E[y(c,a,b)]−E[y(c,a',b)]`。

一条规律包含 `(成员范围A，伙伴范围B，背景条件C，dose/time/endpoint，Δ预测及误差，实测支持，反例，证据级别)`。注释/嵌入是可检验先验，不是规律真值。核心假设是：一部分与决策有关的 Δ 能由少量跨成员、跨伙伴、跨背景复用的条件解释；新反例能够修订这一条件并改善**未购买**动作。

类 G 的理想功能直径为 `D(G;C,B)=sup_{c∈C,b∈B,a,a'∈G}|Δ|`。这个定义用于表达目标，当前不声称可从稀疏数据认证其真实上界。近似相似不传递；未知不等价。设计可以用 diameter 约束生成候选类，但这只是统计模型上的候选，必须独立检验。若用一个代表保留单边替换效用，且对全部相关动作真有 |U−U_repr|≤ε，则标准 argmax 推导给 regret≤2ε；此为条件数学界，不是新定理或实测保证。双边替换要覆盖中间动作并累计误差，不能继承单边界。

## 三个必要模块与闭环

### M1 世界模型：带作用范围的竞争规律

最小实现不用新大模型。固定一个允许强特征/层级交互的预测器 fθ，并在开发集冻结有限规则字典 h_j(z_c,z_a,z_a',z_b,m)，例如成员特征 v、伙伴特征 g、背景特征 k 的低复杂度交互。可得侧信息必须在部署前可用；单药响应若购买也计入信息与预算。

候选假说 s 的差分模型为

`Δ_s(x)=Δ_base,θ(x)+Σ_{j∈J_s}γ_j h_j(x)`。

各 s 表示“原关系仍成立”“仅特定成员失效”“成员×伙伴条件失效”“无可支持共享规律”的竞争解释。源数据/目标支持使用共同的函数与可交换角色一致的元数据；目标条件不允许凭未购标签事后选择。规则 h_j 的生物命名需外部证据；未认证时只是功能条件。

### M2 Agent：购买能改变下游动作的最小合法对照包

动作 q 是实际整板/培养包，不是免费标量。包含可执行的 (a,b)/(a',b)、相应vehicle与必要单药/独立重复；跨背景 Q 还需 c/c0 两套匹配数据。用于辨别成员条件与伙伴条件的包可联合选择，联合似然保留共享对照与批次依赖。

用既有决策实验设计实现：`q*=argmin_q{cost(q)+E_o[R(D∪{q,o})]}`，其中 R 为候选最终药物决策的预期 regret/机会损失，成本换算由实验团队给定，不用任意λ产生净收益。也可在固定物理预算内最小化 R。期望依赖校准的竞争假说及开放残差；若全部候选同错，分歧消失不等于安全，应配置计费的独立审计动作。联合包选择与误差检查属于已有主动学习，不主张首创。

### M3 反馈：修改规律的作用范围，再重算所有未测候选

对每个 s，用全部合法历史与新反馈联合拟合 θ,γ；以开发集冻结的复杂度惩罚或分组内层选择抑制任意拆类。一个透明实现为

`(θ_s,γ_s)=argmin Σ_{o∈D} loss(o;Δ_s,Σ_batch)+λ||θ_s||²`，

`score(s)=heldout_loss_dev(s)+κ·complexity(s)`。

拟合目标、λ/κ与字典都在开发范围选择；目标支持只用于既定更新。更新后，若条件规则 h_j 在多个实测单元上更可信，它的 γ 会改变具有该条件的未测 Δ；否则保持宽不确定性或退回非共享模型。这就是“修订影响未测动作”的实际操作，**是普通受约束模型选择/后验更新**。从 f 读出分组而不让规则参与预测的版本是强对照；让普通层级/树/核模型使用相同 h_j、历史及模型选择预算也是必须对照。

一个反例只标记旧范围冲突，不能自动确定 g，也不能给整类贴“补偿/脱靶”标签。若从目标支持探索新的 g，它必须留到另一成员/伙伴/任务重新验证，本任务不当确认。原成立范围的保留通过真实独立参考评估，不能用旧模型输出当真值。

## 冻结有限假说族内的区分例（推理，不是数据）

设 a1、a2 有部署前已知特征v=1，a3为一个尚未取证的同特征成员；b1、b2、b4 有特征g=1，b3有g=0。Δ为相对参考药a0的功能差，负值表示效用下降。新背景只有以下候选，数值只展示逻辑：

| 假说 | a1,b1 | a1,b3 | a2,b1 | a2,b2（不购买） |
|---|---:|---:|---:|---:|
| H0：可替换关系保持 | 0 | 0 | 0 | 0 |
| HD：仅a1在所有伙伴下失效 | -0.30 | -0.30 | 0 | 0 |
| HG：所有v=1成员仅在g=1伙伴下失效 | -0.30 | 0 | -0.30 | -0.30 |
| HP：仅a1,b1这一格异常 | -0.30 | 0 | 0 | 0 |

若依次观察 -0.30、0、-0.30，三个支持包在**这四个候选中**留下HG。a1,b3区分HD/HG，却不区分HG/HP；a2,b1才区分HG/HP；a1,b2无法替代后者。若 a2,b2 的原预测为 .65，替代动作 .50，该规则预测 .35，会改变未购动作选择。真实封存 y 才判断改选是否正确。

a2,b2只是新组合，既不是整新成员也不是整新伙伴；要证明成员/伙伴外推，另留 a3,b4 以及整新细胞。任意 H* 可在上述三个包与HG相同、只在a2,b2反向；有限证据无法排除它。因此这只是“有限假说类+已知特征+稳定共享”下的构造性说明，不是一般辨识定理。新噪声结果用联合似然更新，不按精确数值硬剔除。基线使用同样假说可得到同样结果。

## 证据级别与实用范围

第一层：模型条件下的候选范围和预测区间，允许拒绝；不称安全证书。

第二层：冻结规则后，用独立样本评估特定任务分布的替换损失/越界率及 CI。它不保证罕见最坏点。

第三层：有限菜单若需同时认证，就需合法的同时/序贯误差控制、独立校准或逐单元重复与总成本；当前资源未证其可行。不能从第二层跳到第三层，更不能从有限菜单跳到所有背景。

只在药物有可测活性、功能端点未饱和且决策差距有现实意义时检验压缩价值；无效/全毒区域的大类不作药物发现证据。ε由可接受的效用损失和实验精度预先给定，不按已有CI倒推。正常细胞数据缺失时不能宣称治疗窗/安全性。

## 最小验证与停止

沿用v1的E0资格→E1相同反馈更新→E2相同预算采样→E3独立迁移。新增要求：

- E1必须包含**条件预测器→sup距离→分组→全历史重训**对照、规则参与预测与仅作读出的消融；同源数据/规则候选/模型选择预算。若结果等效，只能归因科学结构，不能归因独特算子。
- 不将 held-out drug IDs 的常数 identity 当主要竞争者；使用强结构/靶点/细胞特征预测器、条件共聚类、低秩/层级、GP、同历史重训。冷行/冷列预测需部署侧特征或明确购买支持，不能让无特征矩阵分解无定义而判输。
- 原始观测单位先划分，再生成Δ/Q；禁止同一raw key穿越support/query、同一cell/drug跨角色泄漏、同一数据重用伪装外部。CI保留cell、drug、condition、batch的共享依赖；固定预测CI与完整重拟合变异分开。
- 一个固定被购买面板无法提供所有自适应策略的反事实回放；需要有完整合法动作覆盖的既有开发数据，或各策略实付自己的真实实验。独立确认只执行冻结策略，不把离线模拟叫新湿实验。
- 主要决策终点为同成本下未购动作的效用/regret；总命中另报。若初筛结果构成最终endpoint，单独做gate-only控制，禁止反馈自证。
- 主要效应CI含零且宽：未决；精度足够且低于预设实用阈值：不支持；若CI尚容许实用收益，不称等效或必失败。阈值需实际预算/损失依据，现阶段不给虚构数值。

尚未资格化确认资源，未运行E0–E3。meta/RSI与动态流模型不属核心；独立决策收益和迁移成立后才考虑，且比较等预算普通程序搜索。v2即使逻辑改好，生物结构与新算法都不会因此被验证。
