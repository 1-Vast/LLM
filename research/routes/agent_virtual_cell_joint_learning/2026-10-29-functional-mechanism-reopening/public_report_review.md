## Required corrections

1. **H_FI target definition is missing from the public paragraph.** It reports 1,058 target labels and four error totals without defining the labels. Add that the two labels indicate whether the selected fixed-dose exported inhibition values for a and b are each `y >= 0.5`; loss is the average of the two binary errors. This is in `functional-index-pilot/protocol_hfi_v1.md`, sections H, allowed fields and main quantity, and in its report. The public evidence JSONs contain the totals but do not restore this omitted task definition. Keep the continuous direct-target input and training-selection limitations intact.
2. **H_L decision loss needs its endpoint and meaning.** Add that the action recommends the lowest dose in the finite menu predicted to reach exported inhibition `>= 0.5`, or abstains. An inactive recommendation or abstention when a reachable dose exists has loss 1; correct abstention has loss 0; a successful recommendation incurs `log(dose/dose_min_effective) / log(dose_max/dose_min)`. These are the exact task and loss in `local-relation-pilot/protocol_v1.md`, section on terminal decision/main quantity. Without this definition, public readers cannot tell what 0.1420083 and 0.1301313 measure. They are not generic curve-fit errors, fitted IC50 or biological killing outcomes.
3. **G1 loss scale is underspecified.** Define it briefly as the mean squared prediction error over 28 pairwise LN_IC50 differences, divided by the common training-only scale `D=1.7239887126603863`. This follows `conditional-response-geometry/protocol_g1_v1_1.md`, prediction/loss section, and the original report. The report already correctly limits the observed information to the measured pair difference and its intervals to stability.
4. **An “accompanying review” is not currently a public artifact.** The final paragraph says independent content review is recorded in the accompanying review, but the current dated public folder contains no such file or link. Either publish and link an explicitly selected review artifact or say that the detailed review is local-only. A local review should not be presented as available in the public supplement.

Precision improvement, without changing the result: C6's fitted-label event uses a strictly interior recorded ln-concentration window, excluding a `1e-8` band at each boundary, as well as finite LN_IC50 `<=0`. The current “within the recorded concentration window” phrase is broadly consistent but omits the exact edge rule. Including the edge rule would prevent boundary ambiguity in a future reconstruction.
