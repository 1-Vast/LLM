## 独立初稿 v0（先于本轮 root / scout 内容）

已读本轮 brief、innovation-research 的 SKILL.md 与 idea-development.md、项目 INDEX 的历史入口；尚未读本轮 root 探索稿或 neutral/scout 文件。记忆只用于定位 R3 的旧等价性与证据边界，历史事实后续以项目文件为准。

初始问题：当一个筛选团队同时需要多个细胞背景中的可用剂量窗，是否应把“哪些功能判断能由另一些已付费判断推出”作为共学对象？虚拟细胞保存有支持条件的关系，Agent 选择能够补齐最多决策证明或揭示关系错误的普通孔。此处“证明”仅指在明确统计/结构条件下成立的决策证书，不是药物作用机制证明。

先比较两种不同承重原则：

1. **学习可撤回的功能蕴含并传播有限决策证书。** 对有限 cell×drug×dose 菜单，以活性/安全阈值形成布尔或区间结论；反馈更新候选关系的可行集合，再传播到多个目标。潜在增量是可增量维护的稀疏证书和违反定位，从而减少全历史重拟合/多步条件获取的计算，而不是“有关系”或“Agent 会选点”。关键未知：关系可否由普通数据学到、跨新药/细胞有效，最近主动规则学习是否已完整实现，能否在同价直接目标对手下取得总成本优势。

2. **学习功能坐标而非固定药物相似性。** 同一药物的剂量水平在不同细胞上对应哪些等效功能水平，关系的组合在哪些局部区域仍成立；Agent 为打破不相容的局部坐标选择普通剂量孔。潜在科学价值是厘清共享剂量变形何时可用、何时结构性失效。已有曲线注册/联合剂量模型很可能覆盖算法，故这是不同科学问题的较弱比较，不预设主创新。

优先发展第一条，但只有在能给出多目标同价建设例、具体更新运算与强对手差异后才保留。不能把阈值化、SAT 名称、零信息的未知关系、或普通不确定性采样当作新增机制。若强全历史联合拟合加相同条件获取完整复现，撤算法主张，保留关系存在性或计算受限分支；不以加模块救回。

当前所有例子均待推导；尚无建设性证明、经验 H 或性能结论。

## v1：把“可撤回证书”落实为付费学习的功能对应表

这是 v0 的第 1 次实质发展：用可明确识别和计费的有限联合功能关系替代泛称逻辑规则。不是新增候选，不重开 G1、H_L 或 C2 的已停设定。本节全为解析推理；没有运行模拟或读取新功能值。

**得到的建设性结果：** 一个普通连续功能读数，确实可能在直接目标同价、同精度、同样可购时，辨清两个独立目标判断。关系未知时，先支付共观测成本，再跨多个对象摊销，也有明确的可行例。**没有得到的结果：** 当前更新及选择运算仍能被普通有限联合模型与跨任务实验设计逐步复制；没有额外算法已成立。

### 研究对象与最小运算

令对象 i 为细胞背景，固定一个普通药物×物理剂量菜单。z_i 是候选参考药在该背景的普通功能读数，y_i1、y_i2 是两个目标药的同类功能读数；也可交换 cell/drug 轴，但那会改变外推单位和证据主张。所有测量都是真实可买的功能实验，直接 y_i1/y_i2 始终在菜单中。

先冻结参考读数的 K 个可分辨区域 b(z)，以及两项目标各自的实际决策阈值。此处刻意使用有限族以便给出精确运算，不把离散化当创新。虚拟细胞的共享对象为：

`g : 参考功能区域 k → 两个目标的决策标签 (b1,b2)`。

未观测区域保留所有候选标签，不填入模型伪标签。当前相容映射集合为 V_t。一个同时具备参考读数 z_i 与目标 j 反馈 y_ij 的付费记录，执行：

`V_(t+1) = {g ∈ V_t : g_j(b(z_i)) = B_j(y_ij)}`。

在下面有界噪声、阈值间隔足够的构造中，B_j 可准确得到；真实噪声条件下不能机械排除一次不符的规律，而应使用校准的似然/集合界并保留例外率。新参考读数改变对象 i 属于哪个区域；新配对目标反馈改变共享 g，进而改变以后同区域对象的目标预测与取证动作。**只有前一件事发生时，是条件预测；两者都实际发生、且共享变化影响后续未测对象时，才具备所称关系共学的操作内容。**

一个具体 Agent 策略是：新对象先测 z；若该区域的两个目标标签已有可靠支持，就输出两个判断；否则补测尚未学清的目标，并更新 g。输出包括两个目标判断、相应支持区域、未辨清项与实际支付记录。它不输出靶点、通路、真实细胞内部状态或临床安全结论。

### 同价直接目标也合法的建设例

以下数值只是解析构造，不是数据。每个新对象独立属于四种类型之一，概率均为 1/4。功能读数越低表示抑制越强；每项目标是否低于 0.5 决定采用候选药还是已知基准。三项测量每项均耗一个相同成本单位；同样测量误差满足 |epsilon|≤0.04。

| 类型 | 参考 z 的均值 | 目标 y1 的均值 | 目标 y2 的均值 | 两个目标标签 |
|---|---:|---:|---:|---|
| A | 0.10 | 0.25 | 0.25 | 有效，有效 |
| B | 0.35 | 0.25 | 0.75 | 有效，无效 |
| C | 0.65 | 0.75 | 0.25 | 无效，有效 |
| D | 0.90 | 0.75 | 0.75 | 无效，无效 |

参考四个观测区间互不相交；两目标的有效/无效区间也互不相交。关系已知时：

- 测 z 一次辨清 A/B/C/D，从而正确回答两个目标，成本 1。
- 测 y1 一次只区分 {A,B}/{C,D}，y2 仍各半；测 y2 同理。**直接目标允许使用完整连续值**；本构造每个标签的条件噪声分布相同，完整值仍不能区分标签内类型。直接完成两个目标需成本 2。
- 多目标收益来自参考通道在相同精度下分辨四种相关功能情形，而每个目标通道仅分辨两种。不是“参考天然比目标更便宜”，也不是把两个目标设置成互为补数。一个目标时，直接测它只需 1，参考不占查询数优势。

因此，过去单一 latent 被任一直接目标完整揭示的反例不排除此多目标情形。但**普通联合模型同样会选 z**；这是有用信息存在的建设例，不是算法优越性证明。若真实目标读数自身有四个可分辨水平并可推出另一个目标，强直接目标策略也能一次解决，参考优势消失。

### 关系本身如何由可见反馈学到

不能把表的对应关系预送给候选、不给对手。先取更困难的族：四个参考区域固定，但各区域的两个目标标签任意未知，共 4^4=256 种映射。真正生成上表的映射只是其中一种。一次 z 读数只确定区域；在尚未见到配对目标时，它不确定该区域的目标标签。只有付费获得同背景、相容条件下的 (z,y1) 或 (z,y2)，才删除不相容映射。

在本构造的确定映射和有界误差条件下，每个区域首次出现时补测两个目标，之后该区域不再补测。设 Q 为需要解决两个目标的新对象数，K_Q 为其中出现的不同参考区域数：

`总成本 = Q + 2 K_Q ≤ Q + 8`；完全直接测两个目标为 `2Q`。

所以 Q>8 时，即便把对应关系的学习成本全部记入，构造中的此策略也严格少于全直接测量。均匀独立四类型时，解析期望为

`E[K_Q] = 4[1-(3/4)^Q]`，`E[总成本] = Q + 8[1-(3/4)^Q]`。

这不是声称该策略全局最优，也不是说 Q>8 适用于真实药筛；它只给出**未知关系仍可能靠重复任务赚回成本**的存在证明。Q 很小、参考区域很多、目标读数自身足够充分时，它会亏损。历史训练若已提供部分共观测，可抵扣对应的新学习成本；所有对手必须获得同一历史，不能只对候选免费。

Q+8 只计算**固定四区域、已知误差/间隔条件下未知对应 g**的学习成本。它没有免费解决区域数/边界选择、误差资格、稳定映射发现或例外认证；这些工作若需要读数，一并进入后文 H。相同成本单位是思想构造的明确条件，不是从真实导出 y 的一行/一坐标推定一个物理孔。

关系识别需要的共观测是相同对象/背景与相容暴露、endpoint 的联合功能资料，不是同一物理细胞被连续读三次。分散于不同孔的平行培养可以构成条件功能均值的资料，但批次、同源培养、控制共享与读数误差必须保留。不同细胞、不同剂量/时长的边际分布不能冒充这种共同支持。

例如，对上表的四个目标标签对作任意置换，z、y1、y2 的各自边际均可完全相同。只有不含对象联结的三列分布时，置换不可识别；重训或语言推理不能找回丢掉的联结。若每个新对象的 g 都任意改变，旧区域标签也不约束新对象，整个摊销论证失效。

### 不把确定构造的低成本外推到真实例外

上面的“每区域测一次”依赖确定映射、已知误差界与部署支持覆盖。真实同区域对象可能有药敏例外；重复同一孔或同一细胞系不能替代新对象的例外率证据。

仅作数量级解析：先固定已学习的区域与映射 g，再以未参与其选择的对象作审计；假设各区域内对象可按所述总体独立抽取，在 K=4、J=2 个区域×目标组合里，每项 n 个独立审计对象均未出现关系错误。用最简单的二项零错误上界并以 union bound 同时控制 8 项，要以 95% 同时置信使每项例外率低于 0.1，需

`(1-0.1)^n ≤ 0.05/8`，即 `n ≥ ceil(log(0.05/8)/log(0.9)) = 49`。

这意味着目标共观测就可能达到 4×2×49=392 项，尚未计寻找各区域的参考测量、培养/控制/重复和未覆盖类型。这只是所述简单认证方案的需求，不是任何可能算法的普遍下界。真实相关对象、非随机采样或类别漂移会使这项计算也不适用。因而“普通数据容易取得”与“关系可低成本认证”必须分开。

实际赚回成本的必要账本是：`学习/审计成本 H + Q×(参考实际成本 + 剩余目标补测成本) < Q×强直接/条件策略实际成本`，且两边达到同一错误容忍度和药物决定要求。若靠更多独立重复获得参考四水平的可分辨性，这些重复全部计入；不能只按 API 中的一条记录算一个孔。

### 强普通对手，以及本稿到底新增了哪项运算

以下对手均得到同一历史、参考区域、候选映射族、噪声条件、目标定义与真实测量菜单。

| 对手 | 具体运算 | 与本稿关系 |
|---|---|---|
| 完整历史联合拟合 | 用同一 256 种映射的似然在全部已付共观测上重算权重；对当前 z 条件化，预测两个目标 | 在上述有界误差确定族中，相容映射与 V_t 逐项相同 |
| 普通条件获取 | 枚举 z、y1、y2，按同一双目标决策损失算观测后的条件风险；关系已知时选择 z | 完全复现关系已知建设例，direct-target 本身同样允许传播 |
| 普通跨任务规划 | 联合状态包含未知映射与当前/未来对象；在相同剩余 Q 上计入现在补测对以后对象的价值 | 可实现同一“先买参考、未知区域补目标”的策略，并可优化短任务时的切换；本稿未证明它更慢 |
| 只看当前对象的一步获取 | 未学映射时，参考观测可能不降低当前两目标的平均风险，因而一直优先直接目标 | 可能错过摊销，但这是短视对手；赢它不能证明超越强全历史/跨任务方法 |

若把“V_t 删除不相容映射”换成概率为 0 的似然更新，把“已学区域查表”换成缓存相同条件预测，则输入、每次更新、输出、下一动作和计算量都可相同。这里给出的是**逐运算的实现对应**，不是“任何方法都可写成 Bayes”的泛化否定。

因此 v0 的稀疏证书/增量传播设想尚未留下一个额外求解步骤。当前缓存只是在确定的小表中存储已观察标签，普通对手也可同样缓存。没有提供超越其计算复杂度、误差保证或可实施能力的结果，不应把它包装为新算法。将来若能在有噪、未知关系族中用一个明确新运算降低联合规划/重拟合成本，须重新给出计算目标与公平同结构对手；本稿没有用这个未完成的可能性请求实验。

科学上仍有价值的对象是：**普通功能读数能否在可重复的测量条件下成为多个药物决定的可复用索引，其关系学习与复验成本能否被真实筛选任务量摊薄。** 本稿只证明这种结构在明确构造中可以存在，不证明现实细胞具有它，也不称本问题首次提出。

本稿四类型构造可直接按该轴解释：同一细胞的普通参考药剂量读数辨清其对两种目标药剂量的功能决定。这使一个**必要前提的科学 H**有意义：某种合法普通参考观测是否支持两项未测药物决定，并且在允许直接测任一目标、允许其完整连续读数向另一目标传播、相同真实成本与误差要求时，仍有净信息/决定价值。这里只说明它值得资格检查后考虑；不代 root 冻指标、阈值、选药或运行协议，也不声称所列资料已经满足条件。

须把两级主张分开：固定训练关系后，新细胞一次读数改善两项目标，是条件功能信息的必要前提；从付费共观测更新共享关系、影响后续未测细胞并赚回关系学习成本，才是更完整的共学问题。只做前者即使阳性，也不能称后者成立。训练关系由预先完整功能表估计时，所有比较都要扣同一历史暴露并给普通全历史联合模型同样资料。

真实数据朝向的决定性不确定性，是训练共观测覆盖与可靠性、跨真实细胞的条件关系可复用性、参考相对直接目标的额外信息、以及真实孔成本。它们尚未由本稿或所述元数据解决。没有新共享更新算法时，不应为新算法优势冻结 H；可以单独研究这项有清晰用途的普通功能关系前提。

## 不同承重的较弱比较与未重启的祖先

v0 的跨细胞功能坐标/剂量变形，已有 `2026-10-29-functional-abstraction-discovery` 的共享剂量缩放/幅度关系与普通联合曲线拟合边界，不再作为新算法发展。保留一个更弱而承重不同的比较：**同药、同背景、固定暴露下的单调阈值夹逼**。若剂量提高时功能读数单调下降，一个可靠越阈值点可回答其上方剂量的同一二元判断；它不需要跨药/跨细胞映射 g。

两者不会互相救回：跨药关系任意时，单药内部单调性仍可能存在；单药双相/促生长或协议不一致破坏单调性时，跨药条件关系也仍可能存在。前者的强基线是同信息的单调回归/夹逼与真实剂量采集；后者的强基线是联合条件模型/跨任务获取。单调夹逼不是本稿发明，不能以其可用替代尚未成立的共学主张。
