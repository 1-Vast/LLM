## Independence and scope

This note was written after reading only this episode's `record.md`, before opening the six specified predecessor reports. The brief requires drug discovery, a functional virtual cell, a feedback-using Agent, and economical accessible data. It does not require mammalian single-cell omics, an LLM-controlled simulator, a particular organism, or a new neural architecture. A coordination message containing preliminary external/scout themes arrived before this note; its proposed history/state theme and literature claims are deliberately not used here. This is independent question generation under the brief, not an independent literature assessment.

For this note a useful capability changes a prospective biological conclusion or a drug-development action: which hit to pursue, which failure is repairable, which condition invalidates a hit, or which cell-population function remains after treatment. A functional virtual cell must state and test a restriction connecting interventions to a cell/background's function; calling a response regressor a cell does not supply that restriction. The Agent earns its place only if feedback changes a discovery action or changes an admissible restriction. Whether it improves efficiency over a fixed panel or conventional sequential design remains a separate empirical question.

Actual public availability, response permissions, screen completeness, biological replication, assay normalization, machine limits, effective model settings, tokens and costs are unknown here. Every data route below is conditional. The constructive examples describe possible worlds, not observed results or claimed biological facts.

## What makes these different questions

The first two ask whether a failure can be **repaired** and which intervention is responsible: cellular access versus functional bypass. The third asks whether a measured hit represents the **needed function**. The fourth asks whether useful effect and collateral harm can be **separated under realistic demand**. The fifth asks whether a hit survives a **cell-population interaction**. The sixth asks which biological distinction is **necessary for a decision**. Those are distinct scientific targets even where the same regression, graph or Bayesian update could express them.

An observational correlation between two response profiles does not establish any of these restrictions. Conversely, the availability of a standard mathematical representation does not alone show that a useful empirical biological restriction is already known. The scientific question is whether a small, explicit, falsifiable restriction enables a previously unsupported decision in a declared domain, and whether matched controls can distinguish it from the strongest conventional explanation.

## Preliminary admission rules, without a winner

- Begin with a concrete failure-to-action story and a locally meaningful endpoint. Do not begin by naming a co-learning architecture.
- Prefer a modest complete screen over a nominally cheap but missing factorial or unmatched cross-database merge. A single assay can support an assay-specific drug-discovery claim; stronger durability or molecular-causal claims need corresponding evidence.
- Separate the gain from a biological restriction, the gain from a conventional model, and any gain from adaptively chosen feedback. A useful virtual-cell restriction can survive even if the Agent adds no advantage; the required full four-core package would remain incomplete in that case.
- Admit only a prospective contrast with a strong rival that receives the same observations, normalization and action budget. A fancy Agent cannot repair an unidentifiable biological question.
- Open archives before choosing among these possibilities. Reject exact failed premises while retaining a different task if its changed observation, intervention or endpoint removes the decisive failure. Unknown resource access is an admission unknown, not a biological negative.

No positive winner is selected. Cellular access, environment-dependent bypass, readout/function decoupling and mixed-population protection deserve different evidence than a general screen-score exercise, but each may already be an established screen practice or may lack the needed cheap matched data. The first useful next result is an actual-source method/data fact that sharpens or closes one of these questions.
