## A. Which intervention can erase another intervention's effect on future susceptibility?

Question: Can a cheap functional test reveal that an intervention removes a particular prior-treatment effect on later drug response, and can this removal rule transfer to another inducing treatment or background?

Minimal object is a conditional cancellation relation among histories and interventions, not a scalar potency. For prior exposure h, candidate recovery/intervention r, and later challenge c, compare matched h-r-c with sham-r-c after accounting for h-r viability/growth and actual exposure. A reusable rule would concern a specified family of h or c, with explicit conditions. An Agent chooses which equal-dose/time comparison most sharply distinguishes an eraser from ordinary delay; the virtual cell stores the changing relation and counterexample, using any ordinary suitable inference method.

Enabling case: two drugs create the same measured cross-protection pattern; an affordable washout or third drug removes that pattern, enabling a previously ineffective second-line challenge. Failure: apparent removal is dilution, selection, residual carryover, time-dependent killing, or arbitrary history-specific dynamics. Important limitation: matching a few functional responses cannot identify biological memory or establish an eraser on unmeasured challenges. Exact prior and negative records decide whether this is just existing hysteresis control or controlled-state modeling.

Fact that changes action: a real factorial dataset containing initial exposure, candidate reset/recovery, subsequent challenge, and contemporaneous viable starting burden could support the relation. Only pairwise switch endpoints without reset or challenge probes cannot support it.

## B. Which pretreatments are functionally interchangeable for a downstream treatment decision?

Question: Can interventions with different immediate potency be substituted in a future treatment schedule because they preserve an explicitly delimited set of downstream susceptibility decisions?

Minimal object is decision-specific substitution: h1 and h2 may differ in growth but induce the same ranking/threshold relation for a defined downstream challenge set after matched recovery. The claimed reusable biological content would have to be a condition under which a new h or c inherits that substitution, rather than a low-rank fitted response table. An Agent probes the downstream challenge most likely to split the tentative class; the virtual cell revises the substitution boundary.

Enabling case: replace a costly/toxic priming drug by a weaker affordable drug that exposes the same vulnerability to a second drug. Failure: downstream agreement is incidental, changes at another dose or duration, or hides resistant survivors. Strong rivals: empirical nearest-neighbor signatures, controlled predictive-state equivalence, low-rank tensor completion, and drug mechanism class pooling.

Fact that changes action: within-source sequences over several initial and challenge drugs with actual physical doses and recovery-time variation; a source containing only one induction pair leaves transfer unsupported.

## C. When does a treatment-created vulnerability become usable before growth recovers?

Question: Is there an identifiable functional interval in which a pretreatment has ceased causing direct suppression but still changes a later drug's efficacy, so that a usable switching window can be predicted for an unmeasured context?

Minimal object is separation of direct recovery and challenge-susceptibility recovery under compatible assays. The schedule chooses a challenge time in the discordant interval. The Agent seeks a paired recovery/challenge observation where the two candidate explanations differ; the virtual cell revises the window boundary, potentially using standard change-point or interval-censoring tools.

Enabling case: growth has recovered while sensitivity to a low-cost drug remains increased, changing which drug/time is selected. Failure: no discordant interval, mismatched inoculum, residual drug, or the same benefit is fully explained by direct growth lag. Strong rivals: time-kill pharmacodynamics with post-antibiotic effects and source authors' established hysteresis mechanisms.

Fact that changes action: independent direct-recovery measurements and delayed challenge assays, ideally at the same density and with drug washout. OD alone can confuse living biomass and killing, making a viability claim unqualified.
