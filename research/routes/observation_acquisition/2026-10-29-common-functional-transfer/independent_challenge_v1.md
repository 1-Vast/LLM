## Scientific event and application: the blocking gap

1. `LN_IC50 <= q10_train(drug)` means unusually low fitted IC50 for this drug relative to this collection. It can be true even when the entire drug's fitted IC50 distribution lies beyond the tested maximum concentration. Finite fit values and SD >= 0.1 do not establish that 50% inhibition was observed, or that a positive represents usable potency. Holding dose windows fixed removes one ambiguity but does not resolve extrapolation, censoring, weak/incomplete efficacy or fit uncertainty. MIN/MAX_CONC and an unverified LN_IC50 scale cannot yet certify threshold reachability.
2. Thus the event can support the precise statement “retrieve more published relative fitted-tail entries under a curve-attempt budget.” It cannot yet support “retrieve more experimentally credible drug-discovery follow-up candidates.” Relabelling the endpoint as requiring future retesting is honest but does not itself make retesting these entries a useful allocation decision. No normal-cell comparator exists; cancer-background quantiles do not establish tumour selectivity or a therapeutic window.
3. Minimal resolution before values: establish from a primary dictionary/source the response scale, tested-window relation, fit censoring/extrapolation policy and available fit-quality flags. Predeclare whether a qualifying training-derived threshold must be demonstrably inside the assayed range and how unobserved/uncertain crossings count. If the available fitted-only table cannot support a defensible observed-potency event, stop the application claim rather than inventing evidence. This is not permission to inspect values and choose an attractive endpoint. A changed event or eligibility gate must be explicitly a prospective substantive revision, with its reason recorded before training/test values; it must not inherit an unearned C4 success claim.
4. If root retains the current event unchanged, the only defensible runnable scope is a methodological/benchmark feasibility question about relative fitted entries. Under the user's stronger requirement of actual drug-discovery decision value, I do not regard that scope reduction alone as resolving the blocker.

Primary evidence: P2 section 3.1 explicitly defines its selective-drug classification using an absolute IC50 <= 1 micromolar event, in compounds active in fewer than 25% of lines; section 3.3 selects MCF7-versus-MCF10A differential activity and verifies six compounds experimentally, including whether IC50 was reached. Those events connect to pharmacology in a way a within-drug bottom decile alone does not. P2 Methods describes its own validation assay at four concentrations and 48 hours; those conditions must not be transplanted onto the separate 25Feb20 GDSC2 file. The Figshare manifest establishes archive identity and licence, not the missing assay/fit semantics.

## Is this a new useful question or an endpoint rescue?

There is a real estimand change from generic activity ranking to within-drug relative-tail discovery and a real accounting improvement from counting all eight probes in the thirteen attempts. These are not logically the same hypothesis as C2; no C2 result was consulted here. But a different estimand is not automatically a useful new scientific question. In particular, a within-drug quantile makes the training global event rate approximately 10% for every drug by construction. A gain against global rankings may partly reflect removing the broad-potency signal that made a global strategy useful for the previous endpoint. This does not make the new endpoint invalid, but prevents interpreting a positive as rescuing the old active-discovery application. The independent application rationale must precede the test and survive the censoring/reachability objection above.

The underlying principle is already established: P2 Methods uses training-only DRP reference panels of about 40–50 compounds; P2 section 3.1 predicts drug sensitivity and prioritises sensitive lines; section 3.3 prioritises compounds for two specific lines. Eight-probe budgeting and explicit feedback-blind controls form a useful bounded benchmark design if the endpoint is meaningful. They are not evidence of a new functional-state mechanism, transfer law or novel Agent principle.

## Comparisons and gain identification

- `probe_blind` is the essential control: identical eight probes, identical available observations/cost opportunities and five additional choices, with feedback deliberately unused. A difference isolates the decision consequence of consuming these particular observations, conditional on this fixed panel/model family. Shared missing events cancelling in paired bounds is correct; adversarial bounds on differing missing entries avoid complete-case optimism.
- Both static comparators receive thirteen attempts, so opportunity cost is counted. The tissue comparator provides a credible practical static alternative. Global event-rate ranking is weak by construction because drug-specific q10 normalises prevalence: absent ties, differences mostly arise from finite sample size, coverage and quantile rounding. Report its near-constant training rates and frozen tie rule; never describe winning this control alone as surprising or general evidence.
- The final five selected curves are the only feedback-dependent choices. Total-hit benefit can include hits among the eight probes, but cannot establish that the selected five are intrinsically better without the matched `probe_blind` comparison. Final-five posterior updates do not influence any action in this protocol, so they cannot contribute additional demonstrated utility.
- `rank1`, ridge and kNN are appropriate cheap same-feedback rivals. The main gate need not demand rank8 beat all of them to test whether feedback can help. However, a rank8-positive result with equal or better simple rivals supports ordinary functional-profile conditioning, not rank8/Agent-specific value. Posterior/action changes alone are process diagnostics.
- Thirteen fitted curve entries are not equal real expenditure: dose points, repeats, assay failures, procurement and an extra feedback-dependent batch are unknown. The protocol acknowledges this correctly. It may claim equal curve-attempt budgets and a two-batch tradeoff, not actual cost matching or savings.
- The three simultaneous superiority conditions are an intersection claim. Requiring each prespecified one-sided lower bound above zero is conservative for the conjunction; testing the conjunction does not by itself require pretending these are three independent replications. Cell bootstrap intervals remain conditional on this fixed training set/menu and do not include training/model/menu uncertainty.

## Metadata identity, hidden leakage and dependence

Aggregate metadata independently inspected: 809 SIDMs, 566 training and 243 model-unseen development SIDMs, 192 name-normalised conditions, 135242 raw metadata rows. Selected condition IDs and selected drug IDs are each unique among these 192. No exact duplicate frozen cell names map across different SIDMs; this cannot detect discarded inconsistent raw metadata or donor relatives. Six names have multiple original raw drug IDs (uprosertib, oxaliplatin, ulixertinib, fulvestrant, dactinomycin, docetaxel). Choosing one ID/window per name avoids direct cross-window probe/target duplication but is not chemical identity validation.

Concrete pre-run fixes/checks, using metadata only:

1. `cells.setdefault` silently preserves the first name/tissue for a SIDM. Assert consistent mappings, and check raw names/COSMIC IDs mapping across SIDMs for obvious duplicate identities. Do not silently merge or choose mappings using outcomes. SIDM-disjointness does not prove donor/subclone independence.
2. Name normalisation strips all non-alphanumerics. Assert that no merged raw names encode materially distinct compounds, stereochemistry or formulations; report ambiguous aliases or stop as already promised. A drug-ID uniqueness check alone cannot establish chemical uniqueness, and absence of structural metadata limits this claim.
3. Modal-window counts currently count raw records, not unique SIDMs after the declared NLME_RESULT_ID rule. Verify whether duplicate records can change the chosen window or exaggerate claimed coverage. The later >=90% finite coverage must use unique training SIDMs after deterministic row selection, never raw record counts.
4. Specify duplicate tie handling when the minimum numeric NLME_RESULT_ID is repeated, and reject a row whose ID is unparseable. A deterministic metadata-only source-row rule is sufficient when identical minimum IDs occur; it is not evidence that multiple fits are independent replicates. No RMSE/outcome-based picking.
5. Freeze/hash the implementation and training artifacts before revealing model-unseen values. Validate access-role enforcement with synthetic values only, rather than trusting that CSV string parsing is isolation. The existing disclosure that an in-process oracle is not a secure boundary is appropriate.
6. Missing probe observations must not silently become an informative feature unless explicitly intended; the protocol should specify how ridge/kNN handle missing input probes. Differences in missingness can otherwise make “feedback” include archive-observation patterns. Missing selected curves must still count attempts, as prescribed.

Biological dependence remains: related lineages, same-donor derivatives, related compounds and one resource's shared fitting pipeline can support interpolation without cross-context transfer. Equal-weight cell bootstrap cannot eliminate this. The current narrow development uncertainty disclaimer is appropriate; do not upgrade its CI to independent biological confirmation. A metadata-only family check is useful if existing identifiers suffice, but opening an external confirmation resource or changing the split is outside this challenge.

## Conditions for interpreting any later run

All the following are plans, not achieved results: training finite-value eligibility, the 64-condition menu, frozen probes, posterior equivalence, thirteen-attempt enforcement, independent reimplementation and the >=0.5 paired lower-bound/positive-CI gate. Nothing in this review certifies them. Keep a distinct stopped/invalid/negative/positive status; a failed identity/fit-semantics gate is not a negative efficacy experiment.

If the event application gap is resolved prospectively and metadata checks pass, one bounded run can test a narrow, falsifiable budget question. If it passes, its supported gain is additional relative-sensitive assay candidates per fixed attempted curve on this published exposed development resource. Independent repeat utility, assay-cost advantage, therapeutic selectivity, novel mechanism and resource-external generalisation remain unestablished. If the gap cannot be resolved with the allowed simple common data, stop rather than spending the run to obtain an application-irrelevant positive.
