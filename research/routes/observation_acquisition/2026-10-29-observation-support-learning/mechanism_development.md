# 机制发展：普通功能观测的可复用学习对象

## v0：先比较对象，再选操作

| 学习对象 | 原理及可能科学产出 | 增量风险/关键条件 |
|---|---|---|
| 全部 cell×drug×dose×time 响应 | 联合拟合使已付反馈可迁移 | 主要是 ALS/GP/张量补全；不足以自称新机制 |
| 不同已观测块间的相对坐标 | 同一局部拟合有多个跨块解释；少量桥接反馈固定相对坐标，使整组未测选择变可判断 | 新意不能是连通图；须给决策驱动的成组测量和更新算法，超越一般补全设计 |
| 每化合物的有效且选择性剂量窗 | 直接学习不同细胞背景下的两个阈值交点，共享反馈移动整组剂量窗 | 有限剂量格、单调/曲线假设需核；容易退化为普通剂量反应拟合及 level-set estimation |
| 观测选择过程 | 学习为何某些药物/背景被测，分离探索偏好与响应结构 | 缺真实采样日志时不可识别；缺失模式本身不等于生物学信息 |
| 暴露史状态 | 同终点、不同前缀的反馈更新可预测状态 | 科学潜力较大，但普通 cell/drug/dose/time 表未必含顺序/洗脱；当前不能假设有菜单 |

暂选第二项展开；剂量窗保留为竞争对象，不能用它悄悄替换主问题。以下全是待核研究假设，不是数据发现。不同块需同终点、可比时间/剂量/归一化；否则所谓相对坐标会吸收批次差异。

核心初想：学习对象不是一个武断选定的低秩完成矩阵，而是与已观测块相容的相对变换集合。Agent 在合法动作中选择能消除具体药物决策歧义的一组观测；虚拟细胞把真实返回的反馈作为变换约束，更新所有受影响的未测响应。普通联合重拟合和最强匹配信息 Bayes 设计是对手；后者可能已经足够。待核：可否存在单点收益弱但补齐一组桥后决策收益突变，且这个构造不是已知主动矩阵补全直接应用。

初始停止条件：若必要改动只有维护置信集、做标准批量 VOI 或引入通用矩阵补全图，则停止算法创新推荐，保留“哪些普通补测能让整组判断成为可学对象”的科学问题；缺真实验证本身不等于已证伪。

## v1：原文核查后的具体机制（本轮第 1 次实质发展）

**最有希望的问题是：跨不同细胞/化合物观测块，是否能只补齐一组药物决策需要的响应方向，而不用先把整个虚拟细胞补全？** 可发展为“决策所需方向的成组补测与共同更新”。它是一个具体算法研究对象，尚不能认领已证实新颖性或真实节省。它不声称推断分子机制，也不要求遗传参照。

### 输入与使用场景

药物筛选团队有多个部分重叠的普通功能响应块，预算有限，需要在固定背景、剂量、时间与读出下给一组化合物作功能优先级/选择性判断。输入为 (cell, drug, numeric dose, time, endpoint, response, observed mask)，外加真正可买的测量菜单、费用与重复误差；SMILES 可不用。这里先固定 dose/time/endpoint，避免把不同实验语义压成一个矩阵。选择性需目标与对照背景的实际可比读出；不把细胞活性当临床安全性。

与常规“补一个最不确定的响应”不同，行动单位是一小组合法测量，它们合起来应消除若干当前化合物判断的自由度。关键不是缺失边数量，而是这些观测是否约束了决策本身。

### 数学对象与可操作更新

设两个内部可拟合的响应块分别为 U_A V_A^T 与 U_B V_B^T，每块的坐标可以任意可逆变换。跨块响应写为 M_AB = U_A T V_B^T；T 是两块之间尚未学到的相对变换。这里不是宣布整份药物响应严格低秩，只是提出一个须由训练数据/重复核验的局部近似。若该近似明显不支持，候选不能启动。

在临时固定局部因子时，跨块测量 e=(c,d) 给出 y_e = a_e^T theta + noise，theta=vec(T)，a_e=v_d⊗u_c。药物差值、背景选择性差值等目标都可写为 g_l=q_l^T theta（两边已经观测的常数项另加）。当前可学方向是已测 a_e 的线性张成空间。**无需识别 theta 的所有 r² 个自由度；只要需要的 q_l 可由所测 a_e 稳定组合，相关判断即可识别。** 这项区别是科学对象的变化；这条线性代数本身不是新发明。

最小可执行算法研究版本如下：

1. 用已观测训练数据拟合局部坐标，并列出尚不能判断且确实影响候选列表的 q_l。保存对坐标变换不变的目标响应区间，不用不同初始化 ALS 的窄离散分歧冒充完整结构不确定性。
2. 对合法菜单枚举预算允许的小测量组 S（首版只需 1–2 或 1–3 个，不做通用规划框架），计算补上这些 a_e 后哪些 q_l 可稳定表示。若 q_l = A_S^T w，则独立同方差噪声下该线性估计的方差为 sigma²||w||²；有协方差时用 w^T Sigma w。因此近乎共线的桥不能仅凭“秩增加”得高分。
3. 用组的总成本与它能支持的决策集合选择 S，且同一个观测支持多个判断只付一次。不是把各个单点 uncertainty 相加：单独任何一条边都可能仍留关键自由度，但一组边可以一起消除它。评分必须同时允许直接测最终目标；不能人为禁止廉价强对照。
4. 收到真实 y_S 后，把新观测加入同一响应模型并联合重拟合局部因子和 T；由更新后的坐标重新生成 q_l、a_e 和下一组测量。这样反馈不仅填入已测数值，也会更新未测化合物判断和后续测量集合。
5. 只有被同一更新模型支持的药物判断才形成输出；附剩余不可辨识方向与下一组区分测量。若新反馈使局部低秩假设明显失配，记录该区域失效并停止相应跨块传播，不通过加秩/改子集反复救一个已冻结检验。

**算法增量的真正候选**是一个“把给定药物决策编译成可共享的小测量组”的具体求解器：它操作的是决定这些判断的方向与其成组依赖，避免为不影响筛选结果的自由度买数据。联合重拟合只是必要更新基线，不是增量；同样，置信区间和 Agent 外壳不计创新。首版无需语言模型替代数值步骤。Agent 的职责是维护合法菜单、执行成组选择、吸收真实反馈、重新规划；虚拟细胞维护被反馈修改的功能映射。若只靠确定性算法即可实现，应如实称主动功能模型，不能以“Agent”字样额外主张科学价值。

### 一个建设性可行情形（手算思想实验，未执行）

局部块各有 r=2，因此一般跨块变换有 4 个自由度。当前任务的一批药物对只依赖 theta 的前两个方向，例如 g_l = alpha_l theta_1 + beta_l theta_2；余下 theta_3、theta_4 影响别的响应，却不影响当前药物判断。菜单有两个廉价桥，其设计向量为 e_1、e_2。测齐两个桥便能估计全部这些 g_l；为恢复整个 T 而继续购买 e_3、e_4 对当前任务无用。

对于 g=theta_1+theta_2，且每个未观测方向的容许范围均足以跨越判断阈值，只有 e_1 或只有 e_2 仍不能保证判断；两者合起来才可能完成判断。没有噪声时它们精确给出 g；有独立方差 sigma² 的噪声时 Var(g_hat)=2sigma²，仅当实际决策间隔明显大于这个误差时才有收益。一对桥若能为很多尚未测药物共同服务，可能比逐药直接验证节省；若只能服务一个二点差值，就未必比直接测量好。

这证明了“局部可复用反馈＋成组补齐”的可行情形和依赖条件，**没有证明相对强 transductive linear design/批量 Bayes 设计的新颖性或优势**。这里的“单点无法保证、成组可保证”是可辨识性/阈值效用，不能泛化成任意概率先验下单点信息增益必为零。

### 失败边界与可区分预测

- 若任务 q_l 铺满 r² 维，或桥接费高，方向压缩不节省；普通完整重拟合/全坐标设计可能同样好或更好。
- 若单个直接目标测量比桥更便宜且没有可复用对象，桥接策略应选择直接测量；否则是算法错误。
- 若局部块本身不可辨识、低秩误差大、桥近共线、单位/时间/终点/归一化不同，span 条件不保证功能预测；批次与细胞效应不能由图连接自动分离。
- 若菜单不含必要桥，算法应显示不可判断，不能把不存在的实验当作可得免费数据。回放研究必须有这些预先隐藏响应，不能用模型自身生成的响应评价自己。
- 在固定局部坐标下，它**严格属于 transductive linear experimental design**；只有重新估计因子的计算策略、成组依赖和可共享查询的具体算法带来新的可证明/实测能力时，才有算法贡献。若只把已有设计换上 drug/cell 名称，则停止新算法推荐。
- 区分性预测：在药物判断集中于少数方向、且两个或三个便宜测量合起来补齐这些方向时，成组策略会在相同预算下较早稳定整组筛选决策；在目标方向铺满、只有单目标或桥不合法时优势应消失。增益应随“任务方向维数/完整变换维数”及共同受益的独立药物数变化，而不是仅随缺失率变化。

## 下一次低成本区分性检查与当前建议

**先做不用响应的代数/最近先例检查，不把这版送入真实功能效果实验。** 把上面的候选求解器与“固定因子 transductive design＋每轮联合重拟合”写成相同输入、状态、动作与更新的两段伪代码：

- 若所有组选择与更新逐项相同，则算法主张被具体最近对手覆盖；保留普通观测支持的科学问题，但不能主推新共同学习机制。
- 若唯一差别是成组搜索，将最强基线也给同样 batch/lookahead 和预算；再检查是否仍有算法差别。单点贪心输给成组不够。
- 若能定位非等价的求解步骤，下一低成本检查只需一个冻结的 rank-2 代数族，同时含任务方向低维的可行情形和全维/桥高价的失败情形。检验“所有臂都已付同样查询成本”和“未测判断被真实新信息改写”，不是追求任意阳性结果。局部秩/坐标不确定时必须计入，不能把 oracle factors 免费给本方法。

这条线值得作为**待完善、待最近先例核对的具体机制**交给root裁决，尚不足以主张已找到算法创新。它比只报告support可靠性更有建设性，因为给出反馈到底改什么、何时一组测量能改变很多决策、以及最强简单对手如何覆盖它。若 root 的其他方向能给出更明确的非等价更新，应优先比较，不因本稿先写而默认它为父线。

保留的较弱竞争对象是“选择性剂量窗”：其输入确实普通、输出直接有用，但最小实现就是联合剂量曲线/level-set active learning；在没有特殊可检验结构之前，不作为新算法退路。暴露史仅在有顺序/洗脱的真实菜单时再开；缺失机制仅在真实采样过程日志可得时再开。G1/C2–C6/Q1不调seed、不换面板、不换名字重新推荐。
