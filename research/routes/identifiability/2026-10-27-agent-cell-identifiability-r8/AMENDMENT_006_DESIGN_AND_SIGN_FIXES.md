# AMENDMENT-006（E009）：一个符号错误、一个解析等价、一个设计缺陷

2026-10-27，R8。首版 E009 跑完后自检发现三处问题，均**在写报告前**发现并修正。首版结果保留为 `E009_RESULTS_INVALID_SIGNS.json` / `E009_per_cell_INVALID_SIGNS.csv`，**不作引用**。

## 1．符号错误（真正的 bug）

首版用 `picks["exploit"] = np.argsort(exploit)[:k]`，而 `exploit = -p`。于是：
- `argsort(-p)` 给出的是 **p 最大**（预测存活最高＝最差）的 k 个，不是最小的 k 个；
- `contender = -|p - min p|` 同理，`argsort` 取到的是**离预测最优最远**的 k 个；
- `combo` 也因此把"低 p"变成了"高 p"。

后果：`exploit` / `contender` / `exploit_instab` 三臂实际在"买最差的方案"，与 `none` 在多数 k 上给出完全相同的决策（所以首版三个数一模一样）。修正为统一的 `top_k(score) = argsort(-score)[:k]`，各臂分数定义为：`exploit = -p`、`contender = -|p-min|`、`instab = inst`、`combo = -z(p) + 0.5·z(inst)`。

## 2．VOI 与 exploit 解析等价（不是 bug，是设计缺陷）

修正后 `voi`、`exploit`、`contender` 三臂**逐细胞完全一致**（差 0.0000，CI [0,0]）。原因是可证的：

在**同方差**高斯先验下（每个方案的先验不确定度都取同一个 σ），
`P(u 最优) = Φ((min_{v≠u} p_v − p_u)/σ)` 是 `p_u` 的严格单调降函数，因此按它排序**就是**按 `p` 升序排序；而 `−|p_u − min p|` 给出同样的次序。于是"决策主动学习（VOI）"这一臂在**本公式下不可能**区别于纯利用。

**结论**：E009 **无法**检验决策主动学习。要让它与利用分离，先验不确定度必须**逐方案不同**（异方差），例如按"该方案在其他细胞上的可用细胞数/残差 sd"给出各自的 σ。首版与修正版都没有做到，这一点必须在报告里写明，不能把"VOI 没优势"当成对决策主动学习的否证。

## 3．设计缺陷：replace-by-measurement 不是贝叶斯更新

本实验购买一个方案后，直接用**该细胞的单次实测值替换**先验均值 p(u)。这不是后验更新：单细胞测量（σ≈0.03–0.04）的精度远低于多细胞先验（σ≈0.13/√13），替换**降低**了已知最好的方案的估计精度。于是：

- k=1、k=2 时"买任何东西都比不买差"（regret +0.027 / +0.015）**主要是这个缺陷造成的**，不是"采集无用"的证据；
- 正确做法是精度加权：`posterior = (p/σ_prior² + y/σ_meas²)/(1/σ_prior² + 1/σ_meas²)`，此时买任何方案都不会变差，问题才变成"买哪一个最能改善决策"。

**本轮的结论因此必须限定**：在 replace-by-measurement 这一实现下，没有采集策略能优于"不买/利用"。这不是对采集策略的普遍否证。

## 4．修正后仍成立的结论

- **不稳信号没有正的决策价值**：`instab` 相对 `exploit` 的 regret 差在 k=2/4/8 分别是 **+0.0028 / +0.0087 / +0.0201**（点估计全部为正＝更差，CI 含 0），在 k=1 为 −0.0170（CI 含 0）。按预注册判据（≤ −0.02 且 CI 上界 <0）**完全不成立**。无论在哪个预算，按"不稳"去买都不优于直接买预测最优。
- **`exploit_instab` 介于两者之间**（k=8 差 +0.0079），说明加入不稳信息只会稀释利用。
- **利用只在较大预算上改善识别**：`exploit` 相对 `none` 的 top-1 命中在 k=4 为 +0.18、k=8 为 +0.28（regret 仅 −0.0003 / −0.0121）。
- 判决维持 `no_acquisition_beats_exploitation`；预注册的 H013a/H013b 都**不成立**。
