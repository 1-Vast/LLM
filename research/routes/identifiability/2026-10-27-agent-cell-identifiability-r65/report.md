# 重算三处散文级数字：C23 全部复现，**C2 有两处重算不出**

2026-10-27。**R64 发现三处数字只存在于散文里、无法机器复核。本轮从存档数据重算。** 结果：**C23 全部复现；C2 的 τ_half 与 CI 下界复现，但 τ_cross 0.712 与 CI 上界 0.291 在任何定义下都重算不出。** 这是五轮审计里**第一次发现实质问题**。

## 1．结果

| 项 | 散文值 | 重算值 | 判定 |
|---|---:|---:|---|
| C2 τ_half 中位 | 0.891 | **0.8907** | ✅ |
| C2 τ_cross 中位 | 0.712 | **0.7367** | ❌ |
| C2 中位差 | — | 0.1392 | — |
| C2 布局聚类 CI | [0.116, 0.291] | **[0.1155, 0.2169]** | 下界 ✅ / 上界 ❌ |
| C23 组合间 sd | 0.032 | **0.0318** | ✅ |
| C23 within/between 比值 | 1.38 | **1.382** | ✅ |

## 2．τ_cross 0.712 重算不出（试了五种定义）

| 定义 | 值 |
|---|---:|
| 192 对总体中位 | 0.7367 |
| 按布局中位的中位（7 布局） | 0.7088 |
| 按布局中位的均值 | 0.6845 |
| 192 对均值 | 0.6759 |

**没有一个等于 0.712。** 最接近的是 0.7088（差 0.003）。

## 3．CI 上界 0.291 也重算不出

| bootstrap 方案 | CI |
|---|---|
| 布局聚类、中位差 | [0.1155, **0.2169**] |
| 布局聚类、均值差 | [0.1288, 0.2642] |
| 细胞聚类、中位差 | [0.1067, 0.1709] |
| 按对、中位差 | [0.1191, 0.1615] |

**下界 0.116 与"布局聚类中位差"几乎完全一致**（0.1155），但**上界差很多**。

**可能原因**：布局聚类只有 **7 个簇**，其中一个**只有 3 对**——这种构型下 bootstrap 上界对**种子与分组**极敏感。0.291 很可能来自另一次分组或种子，而那次**没有存下来**。

## 4．处置

1. **C2 的主张不受影响**：τ_half > τ_cross 在 **192/192** 对上成立，中位差 **0.1392**，布局聚类 CI **[0.1155, 0.2169]**——三项都可复现。
2. **登记表 C2 行已改为可复现值**：`τ_half 0.891 vs τ_cross 0.737，中位差 0.139，CI [0.116, 0.217]`，并注明原引 0.712 与 0.291 **无法重算**。
3. **新增 C40**：记录这一事实（负面核实）。

## 5．这是审计第一次发现实质问题

前四轮 **104 项检查 0 处错值**。本轮是第一次：

- 不是抄错（散文与报告一致），
- 而是**原文引用的数字本身与存档数据对不上**，
- 而且**没有任何种子/分组记录**能让它被重算出来。

**这正是 R64 说的"工件缺陷"的实际后果**：数字只进散文、不进存档，以后就真的验证不了了。

## 6．判决

- **H164（散文数字可重算）：不成立**——三处中只有 C23 完整复现；C2 两项复现、两项不复现。
- 判决串 **`partially_reproducible`**。

## 7．限制

只试了有限种定义，可能存在没想到的第六种；原始种子未知，CI 端点本就无法逐位对齐——所以**上界差异只能算"可疑"，不能算"已证实错误"**；重算依赖 `E006` 里的 `tau_cross` 字段，只能验证"从该字段出发的一致性"；回顾性；不涉及机制/临床/药物选择；**元学习/RSI 未做**。
