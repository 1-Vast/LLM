# E004：配对读数噪声底与序交叉的可检出性（预注册）

2026-10-27。R4 第一项实验。**在计算任何噪声数值之前写定。** 数据文件已在 R1–R3 与八方向审计中多次读取，整个归档不称封存或未暴露；本协议不读取 sealed/reserve/vault，不下载新数据，不调用 LLM 生成任何生物结论。

## 要回答的一个决定

E003 观察到 A673 的 a−b 在两个文件均为正（+0.3031, +0.2518），BJ 均为负（−0.0205, −0.0486）。协议只报了无校准的 ε 敏感性。问题是：**BJ 这一侧的序差，是否大于该读出自身的可分辨噪声？** 若不大于，H007 的"跨背景反序"就没有被观测到，只是噪声符号。这决定 I002.v1 的最小辨假单位是否准入。

## 统计量的选择（为什么不是任意 ε）

把文件 f 中 well w 的归一化存活性写成

    y(f,w) = μ(cond) + b_f + e(f,w)

b_f 是整板偏移（归一化、日期、批次），e 是 well 级噪声。探针 a 与 b 在**同一文件内**，所以 d_f = y(a) − y(b) 中 b_f 精确抵消。K 个文件平均后

    SE(d̄) = σ_e · sqrt(2/K)

因此决定序交叉能否被读出的唯一噪声量是 **σ_e（板内 well 级）**，不是板间偏移 b_f。这与 E003 用 ε 猜阈值有本质区别：σ_e 可从归档内的**同文件同条件重复 well** 直接估计，而 b_f 从**同布局两文件**估计。两者分开报告。

## 预注册估计量

- **N1（板内 well 噪声，主估计量）**：同一 file 内，(Drug 1, Conc 1, Drug 2, Conc 2) 完全相同的 ≥2 个 well。取组内全部无序对的 Δ = y_w1 − y_w2，`σ_e = SD(Δ)/sqrt(2)`。仅用两端 Failed QC 均为 False 的对为主；含 QC 行的版本单列。同时报 MAD×1.4826 的稳健版本，并按 y 水平分箱（[0,.25) [.25,.5) [.5,.75) [.75,1]）报，因为方差随读出水平变化。
- **N2（板间/批次偏移）**：同 cell、同 iteration、well→(药名,双方剂量) 布局完全一致且恰 2 个 file 的动作。按 well 连接后 Δ_plate；`σ_b = sqrt(SD(Δ_plate)²/2 − σ_e²)`，若为负则报 0 并注明。
- 不把 N1 当独立培养重复；N1 是技术重复，低估跨日期变异，因而**对"存在交叉"这一侧最有利**。若在这个最有利的 σ_e 下 BJ 仍不可分辨，阴性结论对该方向稳健。

## 判据（预先写定，不按读数改）

- 主判据：`|d̄_BJ| ≥ 1.96 · SE(d̄_BJ)`，`SE = σ_e·sqrt(2/2) = σ_e`。
- 若通过 → H007 的交叉在板内噪声意义上可检出，I002.v1 的最小单位仍存活，下一门是"撤回后能否确定未测次序"。
- 若未通过 → **H007 的交叉不被观测支持**；M0（共享序）不被这 4 板否定；I002.v1 的最小辨假单位在本资源上未获准入，E003 结果降级为"未决"，且必须调整问题（只接受有可检出效应量的探针，或换用有 ≥3 独立重复的资源）。
- 同时报 A673 侧的可检出性（预期远超噪声），以及为达到 80% 检定力所需板数 n（单侧 α=0.05），作为该资源的**能力上界**，不称其为对任何具体药对的生物结论。

## 边界

- σ_e 来自 QC 过的技术重复，含作者 QC 造成的截断（duplicate 差 >0.5 被标 QC）；以含/不含 QC 两版并报。
- 全部为公开归档的离线分析；无新湿实验；无培养独立性认证；不认证药名→化学实体或 engagement。
- 不产生机制结论，不认证剂量-靶点占用，不声称任何细胞系生物学差异。
- 本实验不是策略比较，不能给出取证收益或主动学习优劣。
