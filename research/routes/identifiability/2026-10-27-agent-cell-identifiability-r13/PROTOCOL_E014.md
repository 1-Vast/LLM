# PROTOCOL E014（预注册）：加性零模型 vs 跨细胞均值——我们的"可迁移"到底是什么？

2026-10-27，R13。**在任何误差或相关被计算前冻结。** 只读 `PAIR_SCREEN.csv`（SHA256 56a4e4a1…d5f23）。不下载、不读 sealed、不调 LLM。

## 问题

R11 得到"跨细胞同格均值"能把最优剂量组合命中 0.671。但组合药理有一个**标准零模型**从未在本项目里测过：**加性**（用被测细胞**自己的单药**反应预测组合）。两个问题：

1. 跨细胞均值是否真的优于加性零模型？若否，则 R11 的"可迁移"其实只是共享的基线，没有学到交互。
2. 交互（观测 − 加性）本身是否跨细胞保守？若保守，迁移的机制解释是"交互是细胞不变的"；若不保守，迁移来自加性部分。

## 数据与构造（每个留出细胞 c）

每个文件都有单药孔：每个伙伴药 7 个剂量、Cytarabine 8–9 个剂量（`dmso + X` 即 X 的单药）。

- **`bliss`**：`ŷ(i,j) = y_A(i) · y_B(j)`（分数存活率相乘）。
- **`hsa`**：`ŷ(i,j) = min(y_A(i), y_B(j))`（最高单药）。
- **`mean_other`**：其他细胞同格均值（R11 的赢家，**不用 c 的任何组合数据**）。
- **`const_other`**：其他细胞组合表面的总均值（常数基线）。
- **`bliss_other`**：其他细胞的平均交互加到 c 自己的 Bliss 上：`ŷ = y_A(i)·y_B(j) + mean_{c'≠c}[Y_{c'} − Bliss_{c'}]`（"加性 + 可迁移交互"）。

## 指标（对 c 的实测组合表面）

RMSE、表面秩相关（63 格）、argmin 的 hit@3、regret。

## 判据（预先写定）

- **H026（跨细胞均值优于加性）**：`mean_other` 的 RMSE 比 `bliss` 低 ≥0.02，布局聚类 95% CI 上界 <0。否则 R11 的可迁移性主要来自加性基线。
- **H027（交互跨细胞保守）**：对每一对细胞 (c1,c2)，交互表面 `I = Y − Bliss` 的秩相关 > 0，且其分布显著高于 0（布局聚类 CI 下界 >0）；同时报同细胞两块板的交互一致性作为噪声上限。
- **H028（加性+可迁移交互最优）**：`bliss_other` 的 RMSE 低于 `bliss` 与 `mean_other` 两者（各自 CI 上界 <0）。
- 判决：若 H026 与 H027 均不成立 → "可迁移"只是加性基线，R11 的主张必须相应缩小（写进报告首段）。

## 边界与不做

不涉及药物选择、机制、未见药物。加性模型是**零模型**，不是机制主张；Bliss/HSA 只是分数存活率的算术组合。功能读出只是归一化存活度；探索性（板已被 R2 当终点）。
