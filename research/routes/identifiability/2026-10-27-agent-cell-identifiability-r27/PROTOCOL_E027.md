# PROTOCOL E027（预注册）：能不能在测量目标细胞之前，先判断"迁移值不值得信"？

2026-10-27，R27。**在任何相关系数被计算前冻结。** 只读 `PAIR_SCREEN.csv`。

## 为什么

R26 的 H063（"主效应份额解释迁移质量"）有个**循环**：算主效应份额需要目标细胞自己的数据，而目标细胞的数据正是要被预测的东西。所以它只能做事后描述，不能当事前条件。

本轮换成**非循环**版本：只看**源细胞之间**是否一致。如果一组源细胞彼此高度一致，那么用它们池化去预测新细胞应当更可靠。这个问题**完全不需要目标细胞的任何数据**，因此可以作为事前适用条件。

## 构造

- 单元 = (布局, 目标细胞 c)，c 所在布局内至少 2 个其他细胞。
- `μ_o` = 其他细胞在共同化合物对上的均值（不用 c 的数据）。
- `transfer_quality` = `μ_o` 与 c 的实测之间的 **precision@10** 与 **Spearman**。
- `source_agreement` = **源细胞两两之间的 Spearman 均值**（同样只用源细胞）。
- 其他协变量：源细胞数、共有化合物对数。

## 判据（预先写定）

- **H064（源一致性能预测迁移质量）**：`source_agreement` 与 `transfer_quality`（Spearman 版）的秩相关 >0.20，单元聚类 95% CI 下界 > 0。
- **H065（对 precision@10 也成立）**：同上，对 precision@10 的秩相关 >0.20 且 CI 下界 > 0。
- **H066（源越少越差）**：2 个源细胞的单元，其 transfer_quality 低于 3 个源的单元（差 >0，CI 下界 >0）。
- 若 H064/H065 都不成立 → **源一致性能不能当事前条件**；适用条件只能来自目标细胞的少量试点数据（两阶段设计），本资源内不可得。

## 边界

- 这是**排序质量**，不是 regret 决策价值；不改 R9 的停止条件。
- 源细胞通常只有 2–3 个，`source_agreement` 的估计本身很粗，结论要按源数量分层报。
- 未见组合，不是未见药物；无剂量维度；功能读出只是归一化存活度；探索性。
