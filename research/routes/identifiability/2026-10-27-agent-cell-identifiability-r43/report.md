# 分组划分做成了，ρ 几乎没动（0.316→0.308）：R42 的"记忆"解释是错的，信号是真的可泛化

2026-10-27。**R42 说根因是"模型记住见过的组合"，并给了修正方案（按组合分组划分）。本轮照做，ρ 几乎没变。** 即使候选池的组合**完全不出现在训练集**，ρ 仍是 **0.3076**，只比"全见过"低 **0.008**。所以 R42 的归因必须撤回——**通路特征天生可泛化**。同时发现一个更重要的副作用：**分组划分下 R37 的混合优势不再显著**。总目标仍 ACTIVE / NOT_ACHIEVED。

**跨度 0.008**（要求 >0.10）→ H112/H113/H114 全不成立。

## 2．为什么：通路级信号天生可泛化

特征是**通路 one-hot**。一个新组合（A×B）的通路对，几乎必然在训练集出现过（很多组合共享同一通路对）。模型学的是"**通路对 → 协同**"这个可泛化映射，**不需要见过该组合本身**。

这与 R29（留一药物，ρ=0.20）方向一致：**注释级信号是真能迁移的，不是查表**。

**R42 的"记忆"归因撤回。**

## 3．更重要的副作用：分组划分下**混合不再显著**

R37（**键级划分**）：k=50 搜索 **+3.7 [+1.3,+6.3]**、评估 **+2.1 [+0.4,+3.7]**。

本轮（**分组划分**，更接近"新组合"部署）：k=50 搜索 **+0.6 [−2.4,+3.4]**、评估 +3.9 [−0.9,+9.4] ——**两半都不显著**；所有 α、所有 k 都**没有一个**满足两半同时显著。

**R37 的混合优势依赖"同一组合跨多个细胞重复出现"**——那是键级划分的产物。

## 4．对已有结论的处置

1. **R42 根因撤回**（不是记忆）。
2. **C28 下调**：预算规则**只在键级划分下成立**；分组划分下不显著。这比之前"仅 GDSC+pathway 特征"更严格。
3. **四次强度操纵全失败**（换特征 / 标签噪声 / 标签置换 / 分组划分），ρ 最低只到 **0.186**，从未接近 0。
4. **"中间带"仍未被检验**，而且在本资源上**很难检验**——注释级信号太稳。

## 5．限制

α 同时改变池的组成（见过/没见过组合的比例）；分组划分下每组合的键数变少，池内结构也变了；回顾性；`SYNERGY_DELTA_AUC` 是拟合量；不涉及机制/临床/药物选择；**元学习/RSI 未做**。
