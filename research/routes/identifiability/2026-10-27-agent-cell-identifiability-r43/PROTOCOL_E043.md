# PROTOCOL E043（预注册）：按组合分组划分——终于能把强度压到低区，并检验中间带

2026-10-27，R43。**在任何计算前冻结。** 只读本机 `gdsc_combinations`。

## 为什么

R42 找到根因：键是 **(细胞, 组合)**，同一药物对同时落在训练集与候选池，所以任何"标识药物集合"的特征都保留信号，ρ 压不到 0。

本轮按 R42 的结论做**分组划分**：**候选池里的组合不出现在训练集里**（或只部分出现）。用"重叠比例" α 控制：

- **α = 1.0**：候选池的组合**都**在训练集里出现过（不同细胞）——即 R37 的设定，ρ≈0.325；
- **α = 0.0**：候选池的组合**完全没在训练集里出现**——真·未见组合，ρ 应显著下降；
- 中间档 α ∈ {0.75, 0.5, 0.25} 给出中间强度。

## 构造

- 组合总数 2,025。先固定一个"held"集合（20% 的组合，405 个），其余为"seen"。
- 对给定 α：候选池由 α 份额的 **seen 组合的键** 与 (1−α) 份额的 **held 组合的键** 组成；**训练集排除所有候选池组合的键**。
- 池大小控制在 ~21,600 键。
- 任务同 E037：一次性预算、ridge λ=1.0、40 划分（20 搜 / 20 评）、k ∈ {10,20,30,50,75,100,150,200}。

## 判据（预先写定）

- **H112（强度被干净扫开）**：ρ 随 α 单调上升，且 α=1 与 α=0 的差 >0.10。
- **H113（中间带的下边界存在）**：在 α=1 与中间档上，存在两半同时显著为正的 k；而在 **α=0** 上**不存在**这样的 k。
- **H114（α=0 时混合无差别）**：α=0 时所有 k 上 `|mix − exploit|` < 1 pp。
- 若 H112 不成立 → 分组划分也没能把强度扫开，记为未检验。
- 若 H112 成立且 H113 成立 → **"中等预测强度"这条适用条件成立**（第三条经双半验证的条件）。

## 边界

- 单一数据集；α 同时改变"组合是否见过"，也轻微改变池内组合与细胞的分布。
- 回顾性；`SYNERGY_DELTA_AUC` 是拟合量。
- 不涉及机制、临床、药物选择；不做元学习/RSI。
