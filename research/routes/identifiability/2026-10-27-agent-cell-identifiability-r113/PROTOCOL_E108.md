# PROTOCOL E108（预注册）：Agent 能否**在线用上**那条条件规则？

2026-10-27，R113。**在任何计算前冻结。** 只读 `gdsc_combinations`。

## 为什么

R112 给出条件规则：**先验 ≲9% 时个人化值得做；≳12% 时不要做（交叉点约 11%）**。

**规则若不能被 Agent 在线应用，它就只是一条事后描述。** 本轮测：**测一小段探针 → 估计先验水平 → 决定是否继续个人化**，并对照两个固定策略。

## 构造

- 125 细胞留一；两个先验强度（训练 10% 与 100% 的其他细胞）。
- **探针**：先测 20 条，用其真实标记估计先验的 precision@k。
- **决策**：估计值 < 9.5% → 个人化；否则只用先验。
- 三个策略：`never`、`always`、`adaptive`；另报 **`oracle`**（每细胞取更优者）。
- 每细胞每档 3 次抽样。

## 判据（预先写定）

- **强制 sanity**：top-20 必须确实被改变（>50%）。
- **H286（Agent 能用上规则）**：`adaptive` 同时显著优于 `never` 与 `always`。
- **H287（用不上）**：至少一个对比不显著。
- **必报**：探针估计的先验水平是否接近真实（9–11%）——**可辨识性检查**。

## 边界

- 探针 20 条对 k=20 而言**很小**。
- 两个先验档只夹住阈值。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
