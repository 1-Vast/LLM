# PROTOCOL E064（预注册）：弱信号有没有决策价值？——在**未见药物**的候选池上检验利用 vs 随机

2026-10-27，R66。**在任何计算前冻结。** 只读本机 `gdsc_combinations`。

## 为什么

两条结论一直分开摆着：

- **C24**：未见药物的协同只能**弱预测**（ρ=0.200、**R² 仅 0.029**）。
- **C27**：在**一般池**上，利用策略有真实决策价值（基准 1.43% → 6.50%，4.5×）。

**从没有人把两者接起来问**：如果预测这么弱，它在**未见药物的池子**上还能不能挑出更好的组合？

这不是"预测准不准"，而是"**弱预测是否仍然有用**"——正是目标里"最小证据改善决策"的核心问题。

## 构造

- GDSC 108,259 键、65 药物、2,025 组合。
- **按药物分组留出**：随机留出 20% 药物（13 个）作为"未见"。
- **训练集** = 两个药物**都在**已见集合里的键。
- **候选池** = 至少含一个未见药物的键（另设一个"两个都未见"的更严子集）。
- 特征 = 药物对的通路注释 + 组织（与之前一致）；ridge λ=1。
- k ∈ {20, 50}；40 次划分；20 搜 / 20 评。
- 对照：`exploit`（按预测排序）、`random`（同 k 随机）、以及**已见池**上的同口径利用（作为参照）。

## 判据（预先写定）

- **H165（弱信号仍有决策价值）**：未见药物池上 `exploit − random` >0，配对 CI 下界 >0。
- **H166（价值随信号减弱而缩小）**：未见药物池上的增益**小于**已见池上的增益。
- **H167（更严子集同样成立）**："两个药物都未见"的池上 `exploit − random` 仍 >0。
- 若 H165 不成立 → **弱预测没有决策价值**，C24 的 R²=0.029 就是它的上限，算法在未见药物上应为随机。

## 边界

- 单一数据集；药物级分组留出，细胞仍可能重叠（未见药物≠未见细胞）。
- 候选池的大小随留出药物数变化，必须报告。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
