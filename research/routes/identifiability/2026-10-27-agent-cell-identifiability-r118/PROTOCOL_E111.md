# PROTOCOL E111（预注册）：BATCHIE 的**配对级**赛场——跨数据集复现的第三次尝试

2026-10-27，R118。**在任何计算前冻结。** 只读 `PAIR_SCREEN.csv` 与 MAPKG。

## 为什么

C78 判定"跨数据集不可完成"，依据是**键级**赛场的两种失败：

- **原始存活度饱和**（R86：预测器都 ~89%）；
- **残差赛场的 identity 反预测**（R105：9.85% vs 机会 25%）。

**但两次都是键级。** 键级 residual 噪声极大（每键一个残差）。

**配对级可以消噪**：把同一组合在多个细胞上的残差**平均**，得到"这个组合整体有多偏离可加"，这正是 GDSC `Synergy` 标签在配对级的类比物。

**如果配对级上 `identity+gene` 仍胜过 `identity`，那 C78 的"不可完成"就要改成"键级不可完成、配对级可以"。**

## 构造

- 每个布局：拟合剂量感知可加零模型（每药截距 + log 剂量斜率）→ 残差。
- **配对级目标**：该组合在**所有细胞**上的残差均值。
- 特征：`identity`（化合物 one-hot，两侧）vs `identity+gene`（+ 基因 one-hot）。
- **按组合哈希 80/20 划分**（同一组合不会同时在训练与测试里）。
- 指标：**测试集上的 Spearman ρ** 与 **R²**；配对 bootstrap 比较两臂。

## 判据（预先写定）

- **H293（配对级可判别）**：`identity` 的 ρ 显著 >0（赛场本身有信号）。
- **H294（注释有增量）**：`identity+gene` 的 ρ **显著高于** `identity`。
- **H295（注释无增量）**：两者差 CI 含 0。
- 若 H295 成立 → **C78 维持**（跨数据集确实不可完成），且这次是**换了单位**也不可完成。
- 若 H294 成立 → **C78 需放宽**：配对级可以复现。

## 边界

- 配对只有约 351 个/布局，样本小。
- 残差仍依赖可加零模型的设定。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
