# PROTOCOL E046（预注册）：混合优势真的随"同一组合在池中重复的细胞数"增长吗？

2026-10-27，R47。**在任何计算前冻结。** 只读本机 `gdsc_combinations`。

## 为什么

R37 在**键级划分**下验证了"k≥50 用混合"，R43 在**按组合分组划分**下发现该优势消失。我把它写成候选贡献"**预算规则的失效边界依赖划分方式**"。

但那只是**两个数据点**。R46 的教训是：**"在几处看到过"不等于规律**——必须把它变成可测量的关系。

本轮直接测量机制：**同一组合在候选池中重复出现的细胞数 r**。

## 构造

- **固定池大小 ≈ 4,000 键**，只变 r：
  - r ∈ {1, 2, 4, 8}；池中组合数 = 4000 / r（即 4000/2000/1000/500）。
  - 每个池组合取 r 个**不同细胞**的键。
- 训练集 = 其余所有键（因此池中的组合**也**在训练集里出现——即键级重叠）。
- 任务同前：ridge（pathway 特征，λ=1）、40 次划分（20 搜 / 20 评）。
- k ∈ {50, 100}。

## 判据（预先写定）

- **H121（机制成立）**：`mix − exploit` 在 k=50 上随 r **单调上升**，且 r=8 与 r=1 的差 >0，CI 不含 0。
- **H122（r=1 时无优势）**：r=1 时 k=50 的 `mix − exploit` CI 含 0。
- **H123（不是池大小造成）**：因为池大小固定为 4,000，若 H121 成立即可排除"池变大"的解释。
- 若 H121 不成立 → **候选贡献"边界依赖划分方式"缺少机制支持**，应降级为"观察到两种划分下结论不同，原因未定"。

## 边界

- 单一数据集；只用 pathway 特征；只用两个 k。
- r 同时改变"池中组合数"（4000/r），所以组合数与重复度不完全分离——这一点在报告里必须写明。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
