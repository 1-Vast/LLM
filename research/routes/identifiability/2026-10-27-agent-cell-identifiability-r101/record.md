# R101 记录：全检定力下**跨池跨判据成立**——注释在"药物未见"时最有价值

2026-10-27，Asia/Shanghai。继承 R1–R100，不改总目标。R99 显著、R100 不显著，差别在检定力。本轮**把 R99 的检定力搬到所有条件上**（80 划分 × 10 随机块 × 3 池 × 2 判据）。总目标保持 **ACTIVE / NOT_ACHIEVED**。

## 3．最有意思的一点：效果**在身份最没用的时候最大**

| 池 | `identity` 有多好 | 注释增量（主 / 次） |
|---|---|---|
| `one_unseen` | 8.81%（好） | +2.19（不显著）/ +4.25 |
| `cell_unseen` | 8.44%（好） | **+2.81 / +5.00** |
| `both_unseen` | **1.00%（几乎没用）** | **+2.88 / +11.44** |

**`both_unseen` 池里 identity 基本无效（1.00%），而 `identity+pathway` 到 4.31%——是它的 4.3 倍。**
次判据上更明显：**24.00% → 35.88%（+11.44 pp）**。

> **这在机制上完全说得通：药物身份对没见过的药没有信息，而通路注释还能用。**
> **注释不是身份的替代品，而是它在"药未见"时的补位——这正是它该起的作用。**

## 4．一个反讽

R99 那个"最好的证据"来自 `one_unseen` 池——**而全检定力下，恰恰是这个池唯一不显著**（+2.19，CI 含 0）。

所以 R99 不只是"过早宣布"，**它挑中的还是最弱的那个池**。R100 的低检定力又把这个弱信号放大成了"全都不行"。**两次都错，错在不同方向。**

## 5．这次凭什么说它成立（与 R99 的区别）

| | R99 | **R101** |
|---|---|---|
| 池 | 1 个 | **3 个** |
| 判据 | 1 个 | **2 个** |
| 显著 | 是 | **2/3 池 × 2/3 判据** |
| 方向一致性 | 单项 | **6/6 点估计为正** |
| 机制解释 | 无 | **效果随 identity 失效而增大** |

**仍然是同一句限制**：三池共用一个训练集、一个数据集；只有 2/3 池显著。

## 6．限制

1. `one_unseen` **不显著**——不能说"在所有池里都成立"。
2. 三池共用训练集，**不独立**。
3. `both_unseen` 池只有 ~1,830 键。
4. 回顾性；不涉及机制、临床、药物选择；元学习/RSI 未做。
