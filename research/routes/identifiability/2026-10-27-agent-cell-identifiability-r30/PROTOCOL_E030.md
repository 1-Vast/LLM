# PROTOCOL E030（预注册）：留一细胞系——组织是不是一个可用的"适用条件"？

2026-10-27，R30。**在任何相关系数被计算前冻结。** 只读本机 `gdsc_combinations`（Jaaks 2022 figshare）。

## 为什么

R29 做了留一药物（注释级、弱但非零）。本轮做**留一细胞系**：125 个细胞系、2,025 个组合、三个组织（Breast 51 / Colon 45 / Pancreas 29）。这比 BATCHIE 的 13 个细胞大一个量级，且提供了 BATCHIE 没有的一个候选"条件"——**组织**。

问题：**一个没见过的细胞系，它的协同谱能不能由其他细胞预测？同组织的细胞是不是更好的源？**

## 构造

- 单元 = (细胞系, 组合)，组合 = (ANCHOR_NAME, LIBRARY_NAME)；指标 = 该 (细胞, 组合) 的 `SYNERGY_DELTA_AUC` 均值（每对有 1–2 个浓度）。
- 对每个留出细胞 c，对每个在 c 中出现的组合：
  - **预测 A（全体）**：其他所有有该组合的细胞的均值。
  - **预测 B（同组织）**：同组织其他细胞的均值。
  - 只保留其他细胞数 ≥5 的组合。
- 指标：对每个细胞算 Spearman（预测 vs 实测），配对比较 A 与 B。

## 判据（预先写定）

- **H073（未见细胞可预测）**：预测 A 的逐细胞 Spearman 中位 >0.10，且 95% CI 下界 >0。
- **H074（同组织更好）**：预测 B − 预测 A 的中位差 >0，配对 bootstrap 95% CI 下界 >0。
- **H075（异质性大）**：逐细胞 Spearman 的四分位距 >0.20（即"有些细胞可预测、有些不行"）。
- 若 H074 不成立 → **组织不是可用的适用条件**；"适用条件"在这份数据上没有细胞层面的候选。

## 边界

- 特征完全来自**其他细胞**（不含任何细胞注释、不含 c 的数据），所以这是纯"邻近样本"迁移，不是特征化迁移。
- 组织只有 3 个；同一组织内细胞系仍差异很大。
- `SYNERGY_DELTA_AUC` 是拟合量；每 (细胞,组合) 只有 1–2 个浓度。
- 不涉及机制、临床、药物选择。
