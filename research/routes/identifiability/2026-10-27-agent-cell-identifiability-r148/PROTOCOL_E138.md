# PROTOCOL E138（预注册）：**重测 C106**——去掉死特征后，树还有"单调衰减"吗？

2026-10-27，R148。**在任何计算前冻结。** 只读 `gdsc_combinations`。

## 为什么

**C106 说**：增益随身份缺失单调这件事只对线性模型成立（树：完全供给 +0.015、身份缺失 +0.018，无增长）。

**R147 发现**：R138 的树带着**在评估行上全为保留码 −1 的死身份块**；去掉它之后，树单用分组就达到 **0.1074**（≈ ridge 的 0.1254）。

**所以 C106 的"树只有 0.032"很可能是编码假象，不是模型家族的差异。**

## 构造（同一次运行、同一批种子，两个条件都**不含死特征**）

- **60 划分**；种子 **20261051**；树配置同 R147（`max_iter=200, lr=0.08, depth=4, leaf=40`）。
- **条件 A（键级留出，药全见）**：
  - `drug_only`：`[a_code, b_code]`
  - `drug+pathway`：`+ [ap_code, lp_code]`
  - **`gain_A = ρ(drug+pathway) − ρ(drug_only)`**
- **条件 B（药物留出，两药未见）**：
  - `pathway_only`：`[ap_code, lp_code]`（**不带药身份**）
  - `random_only`：同数目随机分组码（地板，用于确认无信息基线 ≈ 0）
  - **`gain_B = ρ(pathway_only) − 0`**（常数预测的 ρ = 0）

## 预测（写死）

- **H362（衰减在树下也成立）**：`gain_B − gain_A` 的 CI 下界 **>0** → **C106 撤回**。
- **H363（衰减仍只在线性模型）**：CI 含 0 → **C106 在"无死特征"版本下保留**。

## 判据

- 两个 gain 的配对 bootstrap，以及两者的差。
- 报 `random_only` 的 ρ 以确认地板确实为零。

## 边界

- 60 划分、单一树配置、整数编码（未用原生类别）。
- 条件 A 与 B 的评估池不同（键级 vs 药物级），**所以是"增益"的比较，不是同一池内的两臂比较**——这与 R138 的口径一致。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
