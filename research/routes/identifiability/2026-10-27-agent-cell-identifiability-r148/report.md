# C106 与 C107 都撤回：衰减是普遍性质，R138 的零是我编码造成的

2026-10-27。**R147 指出 R138 的树带着死身份块，本轮两边都不带死特征重测。结果把 C106/C107 两条都推翻了。**

## 1．结果（60 划分、同一树配置、种子 …1051）

| 量 | 值 |
|---|---:|
| `A_drug_only`（键级留出，药全见） | 0.4065 |
| `A_drug_path` | 0.4217 |
| **`gain_A`（身份完全供给）** | **+0.0152** |
| `B_pathway_only`（药未见，只给分组） | 0.0984 |
| `B_random_only`（地板） | 0.0004 |
| **`gain_B`（身份缺失）** | **+0.0984** |
| **`gain_B − gain_A`** | **+0.0832 [+0.0595,+0.1062]** |

## 2．判决

- **H362（衰减在树下也成立）：成立**；**H363（仍只在线性模型）：不成立**。
- **`the_decay_is_model_independent_and_C106_C107_are_withdrawn`**

## 3．形状与 ridge 几乎一样

| 模型 | 完全供给 | 身份缺失 |
|---|---:|---:|
| ridge（R133–R136） | **0.000** | **0.13** |
| **树（本轮）** | **0.015** | **0.098** |

**两者都是“接近零 → 接近 0.1”的形状。**

## 4．错在哪

**R138/R139 的 `no_identity` 臂都把药身份码放进特征，而那些码在评估行上全是保留码 −1——死特征。**

**本轮直接量到：只给分组时树达到 0.0984，而带死特征的设计只有 0.032。所以那个“树的零”是我编码造的，不是树的性质。**

## 5．撤回与保留

| 主张 | 处置 |
|---|---|
| **C106**（衰减是线性模型性质） | **撤回** |
| **C107**（加固同一个死特征设计） | **撤回** |
| **C105**（完全供给下零冗余只对线性模型） | **保留**——R137 干净条件下 +0.0152，本轮**精确复现 +0.0152** |
| **C115 / C113 / C114** | 保留 |
| **冻结结论** | 不受影响（一直是 ridge 结果） |

## 6．这是这一类错误的第五次

**“某特征在某条件下不再携带信息，而它仍在改变模型行为”**——R135、R144、R147 第一版、R138/R139、本轮确认。

**第九条规则我立了，却靠下一轮才真正执行。所以补一句：规则必须落成检查代码，不能只写在文档里。**

## 7．限制

**60 划分、单一树配置、整数编码**；条件 A 与 B 评估池不同，比的是**增益**而非同池两臂；只有本资源；回顾性；不涉及机制/临床/药物选择；**元学习/RSI 未做**。

## 8．下一步

**把“每个特征是否携带信息”做成可复用检查代码**，在任何多臂比较前运行，输出每特征在评估集上的标准差。**这比再做一个实验更有价值——同类错误已出现五次。**
