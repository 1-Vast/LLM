# 药对层面的主动学习也没有优势——而且原因不是粒度，是估计已饱和

2026-10-27。**早期主动学习失败在细胞层面；R174 已证模型对同一药对内所有细胞给相同预测，所以细胞层面的选择结构上无事可做。本轮在药对层面测一次。**

## 1．结果（10 划分、λ=54、每臂补 50 对 ≈ 1,835 行）

| 量 | 值 |
|---|---:|
| 补测前增益 | **+0.1454** |
| 补测后（不确定选对） | +0.1442 |
| 补测后（随机选对） | +0.1482 |
| **变化量（不确定）** | **−0.0012** |
| 变化量（随机） | +0.0027 |
| **两臂之差** | **−0.0040** [−0.0127,+0.0054] |
| MDE80 | 0.0142 |

## 2．判决：H439 成立——没有优势

**点估计略负，区间跨零。按不确定度选药对，在这个粒度上买不到任何东西。**

## 3．这个阴性有多强——必须限定

**能排除**大于约 **0.014** 的优势；**不能排除**比这更小的正优势。

**所以诚实的说法是：在这个样本量与预算下检不出优势，而不是“优势被证明不存在”——与 R182/R183 需要加的同一个限定，只是方向相反。**

## 4．为什么这个阴性在事后看是必然的

**补了约 1,835 行（整整 50 个药对），增益只动了 −0.0012 / +0.0027。也就是说：这个量与这类数据已经饱和。**

> **若“再加这类数据”几乎不改变估计，那么“选择加哪些数据”也几乎帮不上忙。主动学习加速的是学习曲线；它救不了一条已经压平的曲线。**

**这与 C129（29 倍数据量变化下持平）、C144（分配几乎不影响精度）是同一条事实的第三个侧面。**

## 5．这让“主动学习”这条线真正关闭

| 阶段 | 粒度 | 结果 | 原因 |
|---|---|---|---|
| 早期 | 细胞层面的预测分歧 | 失败 | **结构上无事可做**（C141） |
| **本轮** | **药对层面的不确定度** | **无优势** | **估计已饱和** |

**目标里“Agent 选择可执行且能区分假设的最小证据”这半，在本资源里我已看不到未测的表述形式。**

## 6．限制

只补 50 对、**k 未扫**；MDE 0.014、**小优势不可排除**；单一 λ、单一模型族、单一资源；评估集固定、训练增长；回顾性；不涉及机制/临床/药物选择；**元学习/RSI 未做**。

## 7．下一步

**把“饱和”这件事单独确认一次**：在**初始训练更小**（例如 30% 而非 60%）的设定下重跑，**若主动学习在低数据端显出优势、在高数据端消失**，那本轮阴性就有了边界——“主动学习只在欠数据时有意义”。这是本轮唯一还没做的区分。
