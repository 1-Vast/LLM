# PROTOCOL E055（预注册）：保留组织特征重跑留一组织检验——负结果来自群体，还是来自特征？

2026-10-27，R56。**在任何计算前冻结。** 只读本机 `gdsc_combinations`。

## 为什么

R55 得到负结果：留一组织时阈值**不迁移**（一致率 50%）。但 R55 **去掉了组织特征**（为了让训练与留出可比），而 R51/R53 用了组织特征。这是一个**未分离的混淆**：

- 若负结果来自"群体不同" → 保留组织特征后仍然不迁移；
- 若负结果来自"特征配置不同" → 保留组织特征后会改善。

## 构造

与 R55 **完全相同**，唯一改变：训练时**保留组织 one-hot**（3 个水平）。

- 训练集含两个组织的行：这两列有变异，**留出组织那一列在训练中恒为 0**；
- 因此留出组织的系数恒为 0，预测时该列为 1 也不贡献——**等价于"留出组织的组织效应不可知"**；
- 但**通路系数现在是"调整过组织"的估计**，与 R55 的未调整估计不同。**这正是要分离的差异。**

其他全部固定：S ∈ {500, 1,000, 2,000, 3,500}、k=20、命中=池内最强十分位、20 次划分、同 seed。

## 判据（预先写定）

- **H144（群体效应为真）**：保留组织特征后，阈值决策一致率**仍 <75%** → R55 的负结果不是特征伪影。
- **H145（过零点位置仍低）**：留出组织的过零点仍在 {500, 2,000} 范围内，而**不是**移到 3,000 附近。
- 若 H144 不成立（一致率升到 ≥75%）→ **R55 的负结果部分来自特征配置**，C38 必须改写为"在去组织特征时阈值不迁移"。
- 若 H144 与 H145 都成立 → **R55 结论加固**：阈值不迁移是群体效应。

## 边界

- 组织分层仍是同一数据集内的群体，不等于跨数据集任务。
- 留出组织的组织效应**结构上不可知**，所以本检验测的是"是否调整组织"这一差异。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
