# PROTOCOL E066（预注册）：**细胞与药物同时未见**时，排序价值还剩多少？

2026-10-27，R68。**在任何计算前冻结。** 只读本机 `gdsc_combinations`。

## 为什么

- **C25**：未见细胞可预测（ρ≈0.50，组织是条件）——但那时药物都见过。
- **C41**：未见药物仍有决策价值（+3.50 pp）——但细胞都见过。

**两者同时未见**是目标里最硬的迁移情形，**从未测过**。此时预测只能靠**通路注释 + 组织**（细胞身份未知、药物身份未知）。

## 构造

- GDSC。**联合留出**：随机留出 **20% 细胞系** 与 **20% 药物**。
- **训练集** = 已见细胞 × **两个药物都见过** 的键。
- 四个候选池（互不替代，分别报告）：
  1. `cell_unseen`：未见细胞 × 两药都见过
  2. `drug_unseen`：已见细胞 × 至少一个药物未见
  3. `both_unseen`：未见细胞 × 至少一个药物未见
  4. `strict`：未见细胞 × **两个药物都未见**
- 特征 = 通路注释 + 组织；ridge λ=1；k=20；40 次划分；搜索/评估各半。

## 判据（预先写定）

- **H171（最硬情形仍有效）**：`strict` 池上 `exploit − random` 的评估半配对 CI 下界 >0。
- **H172（价值逐级下降）**：增益满足 `strict ≤ both_unseen ≤ drug_unseen`（允许 1 处违反）。
- **H173（细胞侧不是瓶颈）**：`cell_unseen` 的增益仍 >0——若成立，说明"未见细胞"本身不致命，难在药物。
- 若 H171 不成立 → **排序价值依赖至少一侧可见**，这是明确的适用边界。

## 边界

- 联合留出后训练集显著变小（约 64% 键），模型本身变弱，所以"下降"可能部分来自训练数据减少——必须报告训练集大小。
- 组织特征在未见细胞上仍可用（组织见过），所以"完全陌生"并不成立。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
