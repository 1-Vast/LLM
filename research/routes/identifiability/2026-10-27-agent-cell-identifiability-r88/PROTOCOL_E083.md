# PROTOCOL E083（预注册）：上一轮的零结果可能是**建模失败**——把剂量放进可加模型再试

2026-10-27，R88。**在任何计算前冻结。** 只读 `PAIR_SCREEN.csv` 与 MAPKG。

## 为什么

R87 的残差模型 CV R² = **−0.034**，我据此判定"残差是噪声"并拒绝下结论。

**但 R87 的可加模型把每个（配对, 剂量）**平均**成一对一个值**——把 BATCHIE 的**剂量结构整个丢掉了**。只用"每药一个效应"去过 351 行，几乎必然欠拟合。

**所以那个负 R² 更可能是"我的加性模型太弱"，而不是"协同不可学"。** 这必须先排除。

## 构造（与 R87 的关键差别）

- **不按配对平均剂量**：每个（配对, 剂量组合）孔是一行，样本量从 351 增到约 3,000/细胞。
- **剂量感知的两向可加模型**：
  `y ~ 细胞截距 + Σ_d [1(drug=d) + 1(drug=d)·log c]`（对药 A、药 B 各一组）
  → 每个药有自己的**截距与剂量斜率**，这就是一个粗糙的 Loewe 型可加零模型。
- 残差 `r = y − ŷ`；留出细胞，用训练细胞的残差训练基因注释 ridge，按预测 r 最低取 top-k，命中 = 真实 r 最低四分位。
- 闸门（同 R87）：训练集 **CV R² > 0** 才允许对注释模型下结论。

## 判据（预先写定）

- **H224（剂量放进加性模型后残差可学）**：CV R² **> 0**（R87 是 −0.034）。
- **H225（若闸门过，注释模型赢）**：`gene − random` 的 CI 下界 **>0**。
- **H226（若闸门过而注释仍输）**：CI **含 0 或为负** → **这一次可以说"注释模型在 BATCHIE 上也输"**。
- 若 H224 不成立 → **R87 的结论维持**（残差不可学），但**理由要改成"连剂量感知的可加模型都留不下可学信号"**。

## 边界
