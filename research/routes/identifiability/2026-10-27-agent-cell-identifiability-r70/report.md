# 药对边际均值比注释模型更好或持平——"决策价值"不能归给我们的模型

2026-10-27。**R69 刚说"排序（A）可晋升"。晋升之前必须先问：它凭什么比一个更平凡的基线更好？** 本轮用"药物边际均值"（不用注释、不用模型）做对照。**结果推翻了我对 A 的归因。**

## 1．结果

**药物都见过的池（~35,042 键）：**

| 预测器 | 命中率 |
|---|---:|
| 基准率 | 1.52% |
| **注释模型（ridge）** | 3.88% |
| **边际均值** | **5.37%** |
| 随机 | 2.25% |

- `ridge − 边际均值` = **−1.50 pp** [−3.50, +0.63]
- `ridge − 随机` = +1.62 pp [−0.25, +3.75]（**CI 含 0**）
- `边际均值 − 随机` = **+3.12 pp** [+1.50, +4.62]

**至少一个药物未见的池（~19,088 键）：**

| 预测器 | 命中率 |
|---|---:|
| 基准率 | 1.26% |
| 注释模型 | 5.75% |
| **边际均值** | **6.75%** |
| 随机 | 1.87% |

- `ridge − 边际均值` = **−1.00 pp** [−3.50, +1.87]
- `ridge − 随机` = **+3.88 pp** [+1.75, +6.13]
- `边际均值 − 随机` = **+4.88 pp** [+3.12, +6.75]

## 2．判决

- **H176（已见池上边际均值不弱于模型）：成立**（CI 含 0，点估计偏向边际均值）。
- **H177（未见池上模型有独占价值）：不成立**（点估计 −1.00 pp）。
- **H178（两者都远好于随机）：不成立**（已见池上 `ridge − 随机` 的 CI 含 0）。
- 总判决 **`marginal_baseline_dominates_somewhere`**。

## 3．为什么边际均值在"未见药物"上也能打

我的"任一药物未见"池，**绝大多数是一侧见过、另一侧未见**的配对。边际均值对**见过的那一侧**有信息，未见那侧填中位数即可。**这不是"模型必须靠自己"的场景。**

## 4．真正只有模型能做的场景，表现也很弱

真正让边际均值失效的是**两药都未见**（两边都填中位数 → 排序接近随机）。R66 测过：注释模型比随机只高 **+1.25 pp [+0.00, +2.63]**，**CI 下界恰好 0**。

> **在边际均值能用的地方，它比注释模型更好或持平；
> 在边际均值不能用的地方，注释模型比随机只好一点点（+1.25 pp，边缘）。**

## 5．这对前面的正面结果意味着什么

**C27/C41 的"决策价值"是真的**（利用确实优于随机），但**归因错了**：

- 那份价值**主要来自"药物平均协同"这个标签**，不是来自通路注释或 ridge；
- **"我们的算法"约等于"按药物边际协同排序"**——比 R69 说的还要平凡。

**不否定"排序有用"，但否定了"注释模型有独立贡献"。**

## 6．限制

边际均值是本轮我构造的基线，**不是文献最优**；未见药填充中位数是刻意的"不知道就排中间"；已见池上 `ridge − 边际` 的 CI 仍含 0，所以严格说是"**不能声称模型更好**"，而非"已证明模型更差"；回顾性；不涉及机制/临床/药物选择；**元学习/RSI 未做**。

## 7．下一步

要钉死归因，需要一个**只用边距均值的完整基线**（含细胞侧边距、药×细胞交互）与注释模型同预算对比。若它也打平，则本项目所有"决策价值"都应改挂到"边距均值"名下。
