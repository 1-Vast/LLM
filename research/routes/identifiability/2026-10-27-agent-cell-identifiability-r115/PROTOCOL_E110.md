# PROTOCOL E110（预注册）：规则能不能**事前**应用？——先验强度能否由组织预测

2026-10-27，R115。**在任何计算前冻结。** 只读 `gdsc_combinations`。

## 为什么

R114 关掉了"用探针在线判断"这条路（C87：100 条探针的噪声是要检测差距的 3 倍）。

R114 自己留下的可操作说法是：**"不要在线判断，直接用先验强度的事前估计"**。

**但"事前估计"有没有信息，从来没测过。** 如果能用组织/细胞系元数据事前知道"这个细胞的先验强不强"，规则就能在**不测量任何键**的情况下应用。

## 构造

- 每个细胞（留一）算先验（`identity+pathway`）在该细胞键上的命中率。
- 按**组织**分组（Breast / Colon / Pancreas），算：
  1. **组织内**先验强度的均值与离散度
  2. **组织间**差异（是否跨越 C85 的 ~11% 交叉点）
  3. **组织解释的份额**（ICC 形式：组间方差 / 总方差）
- 另算：**每个组织的个人化增益**（沿用 R112 的每药残差写法）。

## 判据（预先写定）

- **H288（组织能分辨 regime）**：组织间的先验强度差异**跨越 11%**，且组间方差份额 **≥0.30**。
- **H289（不能）**：组间份额 **<0.30** 或差异不跨 11%。
- 若 H288 成立 → **规则可以按组织事前应用**（不测任何键）。
- 若 H289 成立 → **事前应用也没有依据**，条件规则只能事后描述。

## 边界

- 只有 3 个组织，组间估计很粗。
- 先验强度与组织都可能与细胞的其他性质混杂。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
