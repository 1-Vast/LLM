# PROTOCOL E113（预注册）：**决定性分解**——增量来自通路还是组织？

2026-10-27，R120。**在任何计算前冻结。** 只读 `gdsc_combinations`。

## 为什么

R119 发现：**组织留出下，加注释反而比 identity 更差**（−1.17 / −2.08 pp 显著）。

我对此的解释（已写进 R119 结果文件）：**组织本身就是注释块里的特征**；C74/C80 的三个池里**组织都完全可见**，所以那个"注释增量"**可能主要是组织信息**。

**这是可以一刀切开的**：把注释块拆成"只有通路"和"只有组织"。

## 构造

- 与 C74/C80 相同的三池（`one_unseen` / `cell_unseen` / `both_unseen`）× 两判据（布尔 `Synergy` / `ΔEMAX` 四分位）。
- **五臂**（同训练行、k=20）：
  1. `identity`（药物 one-hot）
  2. `+pathway`（**只有通路**，无组织）
  3. `+tissue`（**只有组织**）
  4. `+both`（C74 的原组合 = 通路 + 组织）
  5. `+random`（与通路块同维的随机块，容量对照）
- 60 次划分。

## 判据（预先写定）

- **H299（通路独立携带信号）**：`+pathway − identity` 的 CI 下界 **>0**，在 **≥2/3 池**。
- **H300（增量主要是组织）**：`+pathway − identity` **不显著**，而 `+tissue − identity` 显著且量级更大。
- **H301（两者都独立有用）**：`+pathway` 与 `+tissue` 各自在 ≥2/3 池显著。
- 若 H300 成立 → **C74/C80 必须改写成"组织信息"，"通路注释"这一说法撤回**。
- 若 H299 成立 → **通路确实独立携带信号，C74/C80 的表述可保留**（但需注明组织也贡献）。

## 边界

- 通路只有 38 个水平（17+21），组织只有 3 个水平。
- 三池共用训练集。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
