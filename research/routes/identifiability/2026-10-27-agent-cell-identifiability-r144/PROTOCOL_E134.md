# PROTOCOL E134（预注册）：C75 的"边际臂"在两药未见时是否退化？

2026-10-27，R144。**在任何计算前冻结。** 只读 `gdsc_combinations`。

## 为什么

晋升表里有一条 ✅：**"同预算对比药物边际——C75 三池全胜"**。

**但两向可加边际预测器需要每个药自己的均值。两药都被留出时，这些均值在训练数据里不存在**——那一臂应当塌成全局均值。

**若如此，C75 在 `both_unseen` 池上的"胜利"是对一个常数的胜利，证据上等于空。**

**这与 R135 的 `one_seen_only` 死格是同一类问题。**

## 构造

- 同样的药物留出协议（20%）、60 次划分、种子 **20261047**。
- 计算边际臂在 `both_unseen` 与 `one_unseen` 评估池上的**预测离散度**。
- **用容差判零**（`sd < 1e-12`），不用 `== 0`。

## 预测（写死）

- **H354（边际臂在两药未见时退化）**：`both_unseen` 上 sd **全部 < 1e-12**。
- **H355（不退化）**：sd 明显非零。

**若 H354 成立 → 晋升表的该 ✅ 必须加限定"仅在边际可定义处"，`both_unseen` 池排除。**

## 边界

- 只有一种边际实现（两向可加药物均值）。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
