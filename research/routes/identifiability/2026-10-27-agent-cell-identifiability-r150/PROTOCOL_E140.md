# PROTOCOL E140（预注册）：给检查加**近似退化**档

2026-10-27，R150。**在任何计算前冻结。** 只读 `gdsc_combinations`。

## 为什么

R149 的检查用**精确**判据（`std < 1e-12` 才算恒定、`unseen_frac > 0` 才算未出现）。

**R147 第一版那种情形它抓到了（UNSEEN 1.000），但另一类抓不到**：某列在评估集上**方差极小但非零**——线性模型几乎用不上，却不会被判为恒定。

## 要加的档

在特征级加两项，**阈值参数化**（`ratio_threshold` 默认 0.05）：

1. **`std_ratio = std_eval / std_train`**；若 `< ratio_threshold` → `NEAR_DEGENERATE`。
2. **`dominant_frac`**：评估集上出现最多的取值所占比例；若 `> 0.95` 而训练集上 `< 0.80` → `DOMINATED_ON_EVAL`。

## 验证（本轮的实验）

| 用例 | 期望 |
|---|---|
| `clean_design`（R148 的干净设计） | **PASS**（无误报） |
| `dead_code`（全 −1，R138 复现） | FLAG（恒定，原档） |
| `near_degenerate`（**构造**：把某通路列在评估集里几乎全置零，留极少数 1） | **FLAG（新档）** |
| `dominated`（**构造**：评估集 96% 取同一值、训练集 60%） | **FLAG（新档）** |

## 预测（写死）

- **H366（新档有效且无误报）**：四个用例全部符合期望。
- **H367（新档误报或漏报）**：任一用例判断错误。

**若 H366 成立 → 检查覆盖面从"精确退化"扩到"近似退化"，且不牺牲干净设计的通过。**

## 边界

- 两个构造用例是**人工注入**的，不代表真实设计中已出现过这种形态。
- 阈值 0.05 / 0.95 是拍的；本轮只验证它不误报干净设计，不验证它是最优阈值。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
