# R17 记录：规则边界修订在本资源上无空间——两条规则不互补，oracle 只多 0.0035

2026-10-27，Asia/Shanghai。继承 R1–R16，不改总目标。目标要求"依据反馈修订规律边界"。本资源上唯一还能诚实检验的形式是**规则选择**：R13 发现池化（A）在排序上好、加性+迁移交互（B）在数值上好，那么能否用不涉及目标细胞的信息学出一条边界，决定每个留出细胞用哪条？总目标保持 **ACTIVE / NOT_ACHIEVED**。

## 1．结果

192 个留出单元、6 个布局（本轮要求每个布局 ≥4 个细胞，以便用 ≥3 个"其他细胞"估计边界特征；比前几轮的 210/9 少，**这是口径变化，已披露**）。

| 量 | 值 |
|---|---:|
| 规则 A（池化）的 regret | **0.0206** |
| 规则 B（加性+迁移交互）的 regret | 0.0617 |
| **oracle（每单元事后取较好者）** | **0.0170** |
| B 优于 A 的单元比例 | **9%** |
| oracle 相对最好固定规则（A）的改善 | **−0.0035** |

| 边界规则胜出的布局数 | **0/6** |

**嵌套选阈值**：6 个留出布局全部选出 t=0.6（等价于"几乎总是用 A"）；即便如此，在 `f86030d0cfa5` 上仍放进了 B（0.0376 vs A 的 0.0041），把整体拉差。

**边界特征**：`inter_consistency` 与"B 优于 A"的秩相关 **−0.143**，CI [−0.386, +0.136] → 含 0，且**方向相反**（交互越一致，B 反而越不占优）。

## 2．判决

- **H036（存在可修订空间）：不成立。** oracle 只比最好的固定规则好 **0.0035**，低于预注册的 0.010 门槛。
- **H035（边界规则有效）：不成立**，且嵌套选择后比固定规则更差。
- **H037（特征有定向性）：不成立**，点估计方向还相反。
- 总判决：`no_headroom_rule_selection_line_stops`。

**这不是"没学好边界"，而是"没有边界可学"**：A 在 91% 的单元上就比 B 好，oracle 的天花板只有 0.0035。在这种情况下，任何边界规则最多只能拿回 0.0035，而选择过程本身的方差远大于此。

## 3．与 R13 的"指标分裂"如何一致

R13 说 B 在 **RMSE** 上好、A 在**排序**上好。本轮在**排序**（regret）上确认 A 几乎处处更好（91%），因此 oracle 在 regret 上几乎没有空间。RMSE 侧的头寸对本研究**没有决策用途**（决策线已在 R8/R9 停止），所以"在 RMSE 上做规则选择"这个问题不再有意义。
