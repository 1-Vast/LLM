# 没有边界可修订：池化在 91% 的单元上就更好，oracle 天花板只多 0.0035

2026-10-27。**本轮检验目标里"依据反馈修订规律边界"这条，结论是负面的——而且不是"没学好"，是"没有边界可学"。** R13 发现两条规则各有适用面（池化在排序好、加性+交互在数值好），但本轮显示：在排序这个有决策意义的指标上，**池化在 91% 的单元上就更好**，事后 oracle 也只比最好的固定规则好 **0.0035**（低于预注册的 0.010 门槛）。总目标仍 ACTIVE / NOT_ACHIEVED。

## 1．设计

- **规则 A（池化）**：其他细胞同格均值表面。
- **规则 B（加性+交互）**：留出细胞自己的单药 Bliss 加性 + 其他细胞的平均交互（R13 的 `bliss_other`）。
- **边界特征**：`inter_consistency` = 其他细胞两两交互表面的秩相关均值（只用其他细胞）。
- **边界规则**：`inter_consistency ≥ t` 时用 B，否则用 A；t 在预注册网格上取，且**外层按布局留一**——选 t 用其他布局，评 t 用留出布局。

## 2．结果

192 个留出单元、6 个布局（本轮要求每布局 ≥4 个细胞，以便估计边界特征；比前几轮 210/9 少，属口径变化）。

| 量 | 值 |
|---|---:|
| 规则 A 的 regret | **0.0206** |
| 规则 B 的 regret | 0.0617 |
| **oracle（事后取较好者）** | **0.0170** |
| B 优于 A 的单元比例 | **9%** |
| oracle 相对 A 的改善 | **−0.0035** |
| 嵌套选边界后的 regret | 0.0255（**比 A 更差**） |
| 边界规则胜出的布局数 | **0/6** |

6 个留出布局**全部**选出 t=0.6（等价于"几乎总是用 A"）；即便这样，在一个布局上仍放进了 B（0.0376 vs A 的 0.0041），把整体拉差。

**边界特征无定向性**：`inter_consistency` 与"B 优于 A"的秩相关 **−0.143**，CI [−0.386, +0.136]——含 0，且方向相反。

## 3．判决

- **H036（存在可修订空间）不成立**：oracle 只比最好固定规则好 0.0035 < 0.010 门槛。
- **H035（边界规则有效）不成立**，嵌套选择后比固定规则更差。
- **H037（特征有定向性）不成立**。
- 总判决：`no_headroom_rule_selection_line_stops`。

**关键区别**：这不是"选择方法不够好"，而是**没有可学的边界**。A 在 91% 的单元上就赢，oracle 天花板 0.0035；任何选择过程的方差都远大于这个天花板。

## 4．与 R13 的指标分裂如何一致

R13 说 B 在 **RMSE** 上好、A 在**排序**上好。本轮在排序上确认 A 几乎处处更好（91%），所以 oracle 在 regret 上没有空间。而 RMSE 侧对本研究**没有决策用途**（决策线已在 R8/R9 停止），因此"在 RMSE 上做规则选择"不再有意义。

## 5．对目标的意义

"依据反馈修订规律边界"这一条，**在本资源上以可检验的形式被否定**。至此目标里在本资源上**可检验的部分**都有了明确结论：

- **正面**：最优剂量比跨细胞可预测（hit@3 0.671）、conformal 给出合并口径有效界（α=0.2 时 0.80→0.800，界 0.034）、交互部分保守（ρ 0.353）。
- **负面**：机制不可做（无靶点/遗传参照）、未见药物不可检验（身份重叠 0/2,457）、采集策略无判决力（检定力不足）、逐次可信度不可判（两种方法都失败）、规则边界无空间（本轮）。

剩下的都需要**换资源**。
