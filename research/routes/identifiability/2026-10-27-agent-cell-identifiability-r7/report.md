# 次序不稳可以预测——但只能在同一批药板内、跨细胞；"可迁移"和"非位置伪影"都已撤回

2026-10-27。**结论：存在真实、可重复、超出间隔的预测信号；但它不是"跨批次可迁移"，也不能证明"不是位置伪影"，实用价值未建立。** 独立挑战把我原来那句头条打掉了：**可部署的数字是合并 AUC 0.869**，不是 0.916（后者只覆盖 176 个细胞对里 136 个有阳性的，被排除的 40 个阳性数为 0，所以上升是机械的）。总目标仍 ACTIVE / NOT_ACHIEVED。

## 1．问题

R6 发现反序集中在**药对**侧（ICC 0.294 vs 0.028）。本轮问：**只用其他细胞的信息，能否预测某药对在未见细胞上的反序倾向？** 留两细胞（排除所有含目标细胞的细胞对），四个预测器：常数、间隔、药对倾向、两者合用。

## 2．有效的部分（挑战后仍成立）

| | AUC |
|---|---:|
| 常数基线 | 0.500 |
| 只用间隔 | 0.828 |
| **药对倾向（合并口径，可部署）** | **0.869** |
| 药对倾向（仅 136 个有阳性细胞对的 n 加权均值） | 0.916（**不作头条**） |

- 药对倾向 − 常数：**+0.416**（布局聚类 CI [0.359, 0.448]，97% 细胞对为正）。
- 药对＋间隔 − 只用间隔：**+0.095** ［0.059, 0.126］，82% 为正。
- **打乱标签对照**：把药对倾向在布局内打乱，合并 AUC 0.869 → **0.463**。信号来自身份，不是支撑度或收缩。
- **噪声 well 对照**：1,519 个单元对里 1,511 个（99.5%）同细胞重复不一致率为 0；把预测限制在这些稳定对上，AUC 0.8746 → 0.8719，几乎不变。

**独立挑战做了四项破裂测试，没有一个把合并 AUC 拉下来**：换成药对级间隔基线（0.812，比我的 0.828 还低）后药对项仍 +0.067 [0.050, 0.087]；间隔五分位内 AUC 保持 0.90–0.94；去掉近并列带 AUC 反而升到 0.965；同细胞双板反序近零。所以**"超出间隔"这一条是稳的**。

## 4．修订后的主张（本轮的最终版本）

1. **是**：在同一批药板、这些细胞系内，某方案的次序不稳可由**其他细胞**的信息预测；合并 AUC **0.869**，超出间隔，且在四项破裂测试下不降。
2. **不是**跨批次可迁移；**不是**已排除位置伪影；**不是**"药对"而应写作"方案"。
3. **实用/决策价值未建立**：对象只有约 200 个、命中率 32%、回顾性、新细胞只有 0–1 板的情形未测。主张 C 仍锁定。
4. **反序率的量级不变**（R6 的校准零分布与可复现性不受本轮影响）。
