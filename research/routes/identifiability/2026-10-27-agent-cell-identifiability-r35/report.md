# 等预算程序搜索：搜出的 50/50 混合程序在**未见过的划分**上比纯利用高 3.6 个百分点

2026-10-27。**目标里那个条件句——"仅在独立决策收益与跨任务迁移成立后…对照等预算程序搜索"——门槛已到，本轮把它做了。** 在 54 个加权程序的搜索空间里，用划分 1–5 搜、划分 6–10 评估：搜出的程序是 **50/50 的"预测 + 不确定度"混合**，评估集命中率 **12.80%**，超过纯利用的 **9.20%**（**+3.6 pp** [+1.6, +5.6]），是随机的 **6.4 倍**；而且它在评估集里排名 **5/54**，**不是靠搜索集过拟合**。总目标仍 ACTIVE / NOT_ACHIEVED。

## 1．结果

| 项 | 值 |
|---|---:|
| 搜出的程序 | **a=0.5（pred）、b=0.5（var）**、c=0、d=0 |
| 搜索集命中率 | 12.00% |
| **评估集命中率（搜出程序）** | **12.80%** |
| 评估集 `exploit` | 9.20% |
| 评估集 `random` | 2.00% |
| 评估集 `explore` | 4.00% |

| 程序空间跨度（p90−p10） | 6.28 pp |

## 2．判决

- **H088（优于最好固定策略）成立**（+3.6 pp，CI 不含 0）。
- **H089（优于随机）成立**（12.80% vs 2.00%，6.4×）。
- **H090（空间有跨度）成立**（6.28 pp）。
- 总判决 `program_search_adds_value`。

**关键点**：搜出的程序在**未参与搜索**的划分上排名 5/54——真有一个更好的权重，不是搜索集过拟合。

## 3．必须克制：这不是"搜出了智能"

1. 搜出的程序只是**两个现有信号的 50/50 混合**——不是新机制、不是元学习、不是程序合成。
2. 多样性特征（`rare`、`tissue`）**权重全为 0**——在这份数据上没用。
3. 空间只有 54 个程序；更大空间未必更好，也可能更易过拟合。
4. 与 R33 一致：k=50 时混合优于纯利用；**k=20 时混合更差**——这是**有预算条件**的结论。

## 4．对目标的意义

那个条件句的第一步做完了：

- 独立决策收益：R33（4.5×）；
- 跨设计一致性：R30/R31/R32；
- **等预算程序搜索：本轮（+3.6 pp，5/54）**。

**元学习/RSI 仍未被尝试**，而且按本轮结果也不该现在做：**一个两参数的混合就够了**，没有证据支持更复杂的程序合成。

## 5．下一步

唯一还值得试的：**k 的条件性**。R33 示 k=20 时混合更差、k=50 时更好；系统性扫描 k ∈ {10,20,50,100,200}，给出"何时该用混合"的阈值。可执行、可证伪、对决策直接有用。
