# PROTOCOL E033（预注册）：预算下的真实决策评估——选哪 k 个 (细胞,组合) 去验证？

2026-10-27，R33。**在任何 selection 或命中率被计算前冻结。** 只读本机 `gdsc_combinations`。

## 为什么

R8/R9 在 BATCHIE 上判"决策线检定力不足"——那里只有 9 个布局、几十个候选。GDSC 有 **4,725 个 (细胞,组合) 键、125 个细胞、2,025 个组合**，检定力问题应当不再成立。

本轮做**真实决策评估**：给定预算 k，从候选池里选 k 个去"测量"，看**真实协同命中率**。这不是排序代理指标，而是决策后果。

## 构造

- 特征：锚定药通路 / 文库药通路 / 组织 one-hot（同 R29，**不含药物与细胞身份**）。
- 模型：ridge（λ=1.0 固定）。**后验方差** `σ²(x) = x'(X'X+λI)^{-1}x` 作为不确定性。
- 划分：按 key 随机 80% 训练 / 20% 候选池，**重复 10 次**（共同随机数）。
- 策略（在候选池里选 k 个，**不看真实值**）：
  1. `random`
  2. `exploit`：预测协同最高（越负越协同）
  3. `explore`：后验方差最大
  4. `mix`：预测分位数与不确定分位数之和（各占一半权重）
- 目标（真实值）：
  - **A**：`Synergy` 为真（原筛基准率 3.2%）
  - **B**：真实 `SYNERGY_DELTA_AUC` 落在候选池的**最低十分位**（"强协同"）
- k ∈ {20, 50, 100, 200}。

## 判据（预先写定）

- **H082（利用优于随机）**：`exploit` 在目标 A 与 B 上的 precision@k 中位均 ≥ 2× `random`，且配对 bootstrap 95% CI 下界 >0。
- **H083（探索优于利用）**：`explore` 或 `mix` 的 precision@k 高于 `exploit`（配对差 >0，CI 下界 >0）。**这是本轮真正的新问题**——R9 在 BATCHIE 上因同方差先验得到 EI≡利用，此处用异方差后验重测。
- **H084（稳定）**：H082 在全部 4 个 k 上成立。
- 若 H082 不成立 → 连"利用"都不优于随机，决策线在本资源上也停。
- 若 H082 成立但 H083 不成立 → **决策价值来自利用，不来自探索**；R9 的阴性在更大资源上被确认。

## 边界

- 不是顺序主动学习（一次性选 k），所以不检验"反馈更新"那一环。
- 目标是**回顾性**的：候选池的真实值是已测的，不是新测的。
- 特征只有注释；`SYNERGY_DELTA_AUC` 是拟合量；三组织。
- 不涉及机制、临床、药物选择。
