# PROTOCOL E076（预注册）：三特征模型能否把事前识别的 AUC 推到 0.65？

2026-10-27，R79。**在任何计算前冻结。** 只读 R76/R78 的已存数据。

## 为什么

R78 的三个单特征都没达到预注册标准（`B0` 的 AUC 0.629 < 0.65）。**唯一还值得做的一步**是把它们合成一个小模型。

## 构造

- 样本：123 个细胞；标签 = "永不获益"（32 个正例）。
- 特征（**全部事前可得，不需要该细胞的标签**）：`B0`、`base`、组织（3 水平 one-hot）。
- 模型：**L2 正则 logistic**（`C=1.0`，标准化特征）。
- 评估：**留一细胞交叉验证**（LOO），报 AUC 与 95% CI（bootstrap）。
- 对照：只用 `B0` 的同口径 LOO AUC。

## 判据（预先写定）

- **H200（三特征过门槛）**：LOO AUC **≥ 0.65**。
- **H201（优于单特征）**：三特征 AUC > `B0` 单特征 AUC，且差值 bootstrap CI 下界 >0。
- 若 H200 成立 → **给出一条可操作的事前判据**（含阈值的"测不测"规则）。
- 若 H200 不成立 → **事前识别到此为止**，C52 维持阴性，不再追加特征。

## 边界

- 32 个正例、123 个样本，**LOO AUC 的方差很大**；CI 必须报。
- 只有 3 个特征、其中组织只有 3 个水平；不做特征搜索（避免过拟合）。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
