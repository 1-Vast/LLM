# PROTOCOL E132（预注册）：通路先验**为什么**能替代——药物层面的留一检验

2026-10-27，R142。**在任何计算前冻结。** 只读 `gdsc_combinations`。

## 为什么

R136 说通路是身份的粗化、R140 说内容有意义、R141 说价值随内容正确比例分级。

**但"为什么能替代"从没在它实际作用的层次上测过。** 替代的机制是：**未见药继承同组药的行为**。

**那么就该直接问：一个药的平均行为，能否由它的通路同伴预测？**

## 一个先说清的限制（决定设计）

**"用数据重建分组"对未见药是不可能的**：没测过就没有行为画像——**这恰恰是注释存在的理由**。

**所以本轮不问"能否重建分组"，而问"分组是否真的把药按行为分了类"。**

## 构造（药物层面、留一药物）

1. 每个药（作为 anchor 与 library 分别算）取其**平均 `ΔEMAX`**，记 `y_d`。
2. **留一预测**：`ŷ_d = 同通路其他药的平均 y`（不含 d 自己）。
3. **对照**：`ŷ_d = 全局平均`（无信息）。
4. 指标：**Pearson 与 Spearman(ŷ, y)**，以及 **R²**；另报**组间/总方差比（类内相关 ICC）**。

## 预测（写死）

- **H350（分组按行为分类）**：留一通路预测的 R² **> 0** 且 **显著优于全局平均**（配对 bootstrap）。
- **H351（分组与行为无关）**：R² ≤ 0 或不优于全局平均。

**若 H350 成立 → 替代机制得到直接证据：通路把行为相近的药归在一起，未见药继承同伴的平均即可。**
**若 H351 成立 → R136–R141 的"先验"说法必须撤回，改为"注释的作用来源不明"。**

## 判据

- 主判据：留一通路预测 vs 全局平均的配对差。
- 另报置换零分布（打乱通路标签）以校准。

## 边界

- 只有 111 个药物实例（46 anchor + 65 library）。
- 药物平均会抹平细胞间差异。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
