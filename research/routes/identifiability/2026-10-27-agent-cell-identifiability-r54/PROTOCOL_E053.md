# PROTOCOL E053（预注册）：判定式能否跨任务迁移？——双向检验

2026-10-27，R54。**在任何计算前冻结。** 只读 `PAIR_SCREEN.csv` 与 `gdsc_combinations`。

## 为什么

R53 在 GDSC 上学到阈值 **S\* = 3,000**，判定式在该任务内**6/6 取到最优固定策略**。

目标要求"**检验向未见细胞和药物迁移**"。本轮做**双向**迁移检验：

- **方向 A（GDSC → BATCHIE）**：BATCHIE 的池是 80/160/320，**全部 < 3,000** → 判定式预测"**永远用利用**"。若 BATCHIE 上确有 `exploit > mix`，预测成立。
- **方向 B（BATCHIE → GDSC）**：BATCHIE 上只有小池，若 `mix − exploit` 在所有可得大小上都 <0，则**"最小正值 S"不存在 → 阈值无法从 BATCHIE 学到**。这说明规则的**可迁移性有方向性**。

## 构造

- **方向 A**：BATCHIE 43 个细胞单元、池 80/160/320、k=20、20 次划分（同 R50）。应用 GDSC 的阈值（3,000），**不做任何调整**。
- **方向 B**：只用 BATCHIE 的搜索结果判断阈值是否存在。
- 同一信息、同一预算；两个任务都只做"取前 k 个"。

## 判据（预先写定）

- **H138（方向 A 成立）**：BATCHIE 三个池大小上 `exploit > mix`（各自 CI 下界 >0 表示 mix 显著更差），与判定式的"永远用利用"一致。
- **H139（方向 B 的不可学性）**：BATCHIE 上不存在 `mix − exploit > 0` 的池大小 → 阈值不可学。
- **H140（方向性结论）**：H138 与 H139 同时成立 → **规则只能从"跨度覆盖过零点"的任务迁移到小池任务，反之不能**。
- 若 H138 不成立（BATCHIE 某池大小上 mix 更好）→ 判定式**迁移失败**，C36 必须限定在 GDSC。

## 边界

- BATCHIE 池最大 351，永远触不到阈值，所以方向 B 是**结构性不可学**，不是"学了但不好"。
- 两任务命中定义不同（协同旗标 vs 最低四分位），只比方向与判定式的一致性。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
