# PROTOCOL E069（预注册）：联合留出下的四预测器——**两向可加失去细胞边距后，模型能赢吗？**

2026-10-27，R72。**在任何计算前冻结。** 只读本机 `gdsc_combinations`。

## 为什么

R71 的决定性结果是：**在没有组合重叠的池上，两向可加（药+细胞边距）15.88% 完胜注释模型 5.75%（−10.12 pp）**。

但两向可加**依赖"细胞在训练集出现过"**。如果细胞也未见，它就只剩药边距。**这正是注释模型唯一可能翻身的地方**——因为注释模型的输入（通路+组织）对未见细胞仍然可用（组织通常见过）。

## 构造

- **联合留出**：20% 细胞 + 20% 药物。
- 训练集 = 已见细胞 × 两药都见过。
- 池 = 未见细胞 **或** 至少一个药物未见（并标记 `combo_seen`）。
- 四个预测器（同一训练行、同一信息）：
  1. `ridge`（通路 + 组织）
  2. `drug_marg`（两药均值平均）
  3. `additive`（药边距 + **细胞边距**；未见细胞 → 细胞边距 = 0，即退化成 `drug_marg`）
  4. `combo_marg`（查表，未知则退回 additive）
- k=20；40 次划分。

## 判据（预先写定）

- **H182（模型唯一机会）**：联合留出池上 `ridge − drug_marg` 的 CI 下界 **>0**。
- **H183（退化检查）**：`additive` 与 `drug_marg` 在该池上应当**几乎完全相同**（差 <1 pp）——若不相同，说明我的细胞边距逻辑有 bug。
- **H184（与随机比）**：`ridge − random` 与 `drug_marg − random` 都 >0。
- 若 H182 不成立 → **注释模型在任何可测条件下都无优势**，这是最终结论。
- 若 H182 成立 → 注释模型的价值被定位为"**冷启动细胞**"，这才是有意义的贡献。

## 边界

- 组织在联合留出下仍多数见过，所以"完全陌生"仍不完全。
- 联合留出使训练集约 50%，四个预测器共享同一缩小的训练集。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
