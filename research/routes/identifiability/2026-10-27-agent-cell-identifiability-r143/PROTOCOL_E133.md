# PROTOCOL E133（预注册）：用**收缩估计**替换粗糙均值——机制链条的最后一环

2026-10-27，R143。**在任何计算前冻结。** 只读 `gdsc_combinations`。

## 为什么

R142 发现：通路分组与药物平均行为**确有相关**（置换 p=0.000、Pearson 0.44），**但留一组均值太噪声**（平均 5 药/组），MSE 打不过基线。

**我的推断是：要用上这个先验，需要收缩。** 本轮直接检验。

## 构造（药物层面、留一药物）

**经验贝叶斯收缩**：
1. 由数据估计方差成分：`σ²`（通路内、药物间方差）与 `τ²`（通路间方差，矩估计，负则截为 0）。
2. 收缩权重 `λ_g = τ² / (τ² + σ²/n_g)`。
3. **留一预测**：`ŷ_d = λ_g·(同组其他药均值) + (1−λ_g)·(全局均值)`，其中 `n_g` 用**去掉 d 之后**的组大小。

**对照**：
- `grand`（全局均值，无信息）
- `crude`（R142 的粗糙留一组均值）

## 预测（写死）

- **H352（收缩后可用）**：`shrunk` 的 MSE 改进相对 `grand` 的 CI 下界 **>0**，且优于 `crude`。
- **H353（收缩也不能救）**：CI 含 0。

**若 H352 成立 → 机制链条闭合：先验真实 → 收缩后可用 → 模型层面替代成立。**
**若 H353 成立 → "需要收缩"这个推断是错的，机制解释必须另找。**

## 判据

- 主判据：`shrunk − grand` 的 MSE 改进配对 bootstrap。
- 另报 `τ²`、`σ²`、平均 `λ`，以量化先验强度。

## 边界

- 只有 111 个药物实例、21 个通路水平。
- 矩估计不是 REML；`τ²` 截为 0 的处理会影响 `λ`。
- 回顾性；不涉及机制、临床、药物选择；不做元学习/RSI。
