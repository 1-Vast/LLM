# 嵌套验证推翻了 R79 的"可用于 triage"：阈值诚实地选，召回从 0.94 掉到 0.53

2026-10-27。**R79 得到 AUC 0.789，并说"可用于排序"。但那个结论建立在"阈值在同一批预测上读"之上。本轮把阈值放进内层选，重评整条规则——结论被推翻。**

## 1．结果（外层留一细胞，内层选阈值）

| 指标 | 值 |
|---|---:|
| 外层折数 | 123 |
| 正例 | 32（基准率 0.260） |
| 被标记细胞 | 37（**30.1%**） |
| 真阳性 | 17 |
| **嵌套精度** | **0.459** |
| **嵌套召回** | **0.531** |
| R79 表观（阈值 0.2） | 精度 0.44、召回 **0.94** |

内层选出的阈值：均值 0.353、范围 0.281–0.419。内层自估：精度 0.507、召回 0.571。

## 2．判决

- **H202（嵌套后精度下降）：不成立**——精度 0.459，与表观 0.44 持平。
- **H203（triage 仍有用，召回 ≥0.70）：不成立**——召回 **0.531**。
- **H204（可用于排除）：不成立**。
- **`rule_does_not_survive_nested_validation`**

## 3．这一轮推翻了什么

**R79 说"可用于 triage（标记 55%、覆盖 94%）。R80 说：那个 94% 是假的。**

诚实选阈值后：只标记 **30%** 的细胞、只覆盖 **53%** 的"永不获益"细胞、精度 **46%**。

> **它既不能排除（精度 46%），也不能有效 triage（漏掉近一半）。**

## 4．为什么会这样

R79 的阈值 0.2 是在**同一批预测**上挑的——它捕捉的是特定样本的尾部，不是能在新细胞上复现的操作点。内层每次只有 122 个细胞、约 31 个正例，选出的阈值本身就在抖（0.281–0.419）。

这也解释了"精度没掉、召回掉了"：内层规则要求"精度 ≥0.50 再最大化召回"，在 122 个样本上几乎总落在高阈值端 → 外层标记变少、召回变低。

## 5．这条线的完整轨迹

| 轮次 | 结论 |
|---|---|
| R78 | 单特征 AUC 0.63，未过 0.65 |
| R79 | 三特征 AUC 0.79、精度 0.50 → 声称 triage 可用 |
| **R80** | **嵌套验证：召回 0.53、精度 0.46 → 连 triage 都不可用** |

**结论：不能事前识别"该不该个人化"。这条线关闭。**

## 6．限制

32 个正例使所有嵌套估计都很噪（精度 CI 约 ±0.16）；阈值规则在跑之前固定（精度下限 0.50 → 最大化召回），无调参空间，但也可能不是最优规则；回顾性；不涉及机制/临床/药物选择；**元学习/RSI 未做**。

## 7．下一步

这条线已关闭。若还要碰"最小证据"，只剩诚实说法：按 C50/C51，新细胞要测池的 5–8% 才值得；**而测之前无法判断该不该测**。
