# 强度操纵失败：90% 标签噪声只把 ρ 从 0.325 压到 0.273——假设因此**未被检验**

2026-10-27。**本轮没能做成本来要做的事，而这件事本身就是结论。** 用固定 41 维特征 + 训练标签加噪来操纵预测强度，结果**整条噪声曲线只把 ρ 从 0.3252 压到 0.2731（Δ=0.052）**，远低于预注册要求的 0.15。所以"混合只在中等强度有用"这个假设**没有被检验**（不是被否证）。总目标仍 ACTIVE / NOT_ACHIEVED。

## 1．操纵失败的直接证据

| 噪声 p | ρ |
|---:|---:|
| 0.00 | 0.3252 |
| 0.15 | 0.3249 |
| 0.30 | 0.3241 |
| 0.50 | 0.3231 |
| 0.70 | 0.3177 |
| **0.90** | **0.2731** |

## 2．为什么：样本量把噪声平均掉了

训练集 **86,607 行、41 个参数**。即使 90% 标签被随机替换，仍剩 **8,660 个干净标签**估 41 个参数——ridge 足以平均掉噪声。

**方法学结论**：在 n≫p 下，**标签噪声不是有效的强度操纵**。要真正降强度应减少**样本量**或加**特征噪声**。

## 3．三条判据都无效，但不是阴性

- **H103 不成立**（操纵没成功）。
- **H104、H105 不成立**，但**原因是前提没建立**——不能说"中间带不存在"。
- 脚本打的 `no_intermediate_band_relationship` 是**误标**；正确标注：**`manipulation_failed_hypothesis_untested`**。

## 4．两件顺带观察（不作结论）

1. `noise=0` 时 **k=50–200 两半同时为正**（k=50 搜索 +2.8、评估 +5.1）——与 R37/C28 一致，是本轮的**有效对照**。
2. 高噪声下 exploit 的 k=10 命中率升到 **0.0825**（对照 0.0300），而 ρ 几乎没变——最可能是**系数收缩**改变了尾部排序。**未检验，仅记录。**

## 5．这轮真正的价值：把方法缺口定位清楚

- R39 的问题：换特征集 → **强度与维度混在一起**；
- R40 的问题：改标签 → **在 n≫p 下强度改不动**。

**两种常规操纵在这份数据的规模上都不可行。** 唯一干净路径是**缩减训练样本量**。

## 6．限制

单一数据集、单一噪声机制；只污染训练标签；高噪声下 exploit 上升未解释；回顾性；单一 λ；不涉及机制/临床/药物选择；**元学习/RSI 未做**。

## 7．下一步

**用训练样本量操纵强度**：n ∈ {200, 500, 2000, 8000, 86000}，特征固定 41 维。这样 ρ 会真正从接近 0 扫到 0.325，才可能看到"中间带"。
