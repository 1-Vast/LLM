# PROTOCOL E012（预注册）：剂量格上的最优组合位置——可预测吗？边界会移动吗？

2026-10-27，R11。**在任何统计量计算前冻结。** 只读 `PAIR_SCREEN.csv`（SHA256 56a4e4a1…d5f23）。不下载新数据，不读 sealed，不调 LLM。

## 对象（R10 更正后）

每个 validation 布局含若干**化合物对**，每对是一张 **7（伙伴剂量）× 9（Cytarabine 剂量）** 的剂量格，每格在多个细胞系上各有 2 块重复板。本轮研究两件可证伪的事：

1. **最优组合的位置可预测吗**（用其他细胞的信息）；
2. **剂量比边界会移动吗**（跨细胞的边界差异是否超出同细胞重复的噪声上限）。

**"边界"的定义**：对每个伙伴剂量档 `i`（7 档），`j*(i) = argmin_j y(i,j)` 是该行最有效的 Cytarabine 剂量（9 选 1）。`j*(·)` 就是"在固定伙伴剂量下，最优点落在哪个 Cytarabine 剂量"的边界曲线。

## 任务与对照（留一细胞）

对每个 (布局, 化合物对, 留出细胞 c)：只用**其他细胞**的信息预测 c 的 63 格表面，然后取 argmin。

| 代号 | 依据 |
|---|---|
| `random` | 63 格里随机（20 次平均） |
| `corners` | 最大剂量角（"越多越好"的药理平凡基线） |
| `mean_surface` | 其他细胞同格均值（强静态预测器） |
| `hier` | 加性模型：格效应 + 细胞效应，经验贝叶斯收缩（层级/重训练对照） |
| **`gp`** | **二维高斯过程**（RBF 核，坐标 = 归一化 log 剂量），用其他细胞的全部观测拟合，含测量噪声；这是本项目第一次能构造真 GP——因为剂量格有度量 |

指标：①`hit@3`（预测 argmin 是否落在 c 的真实前 3 格）；②`regret`（预测格真实 viability − 真实最小）；③**表面秩相关**（预测与真实 63 格的 Spearman）。

## 边界移动性

- **同细胞上限**：c 的两块板各自的 `j*(i)` 的一致率（7 档中几档相同）。
- **跨细胞**：c 与 c′ 的 `j*(i)` 一致率。
- **H021（边界会移动）**：跨细胞一致率显著低于同细胞上限（配对，布局聚类 95% CI 不含 0）。

## 判据（预先写定）

- **H020（GP 有增量）**：`gp` 的表面秩相关比 `mean_surface` 高 ≥0.02，且布局聚类 CI 下界 >0。
- **H020b（静态已足够）**：若 `mean_surface` 在全部指标上 ≥ `gp`，则判"该任务上 GP 无增量"，这是有效结论。
- **H022（可预测性存在）**：`mean_surface` 的 `hit@3` 显著高于 `random` 与 `corners`（CI 下界 >0）。
- 若 H021 不成立 → 边界在细胞间**稳定**，那么"条件化到细胞背景"对这个对象没有必要性，本项目的主张必须相应缩小。
- 所有比较必须同时报三个指标，不得只报一个。
