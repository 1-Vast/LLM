# PROTOCOL E042（预注册）：把预测强度扫到接近 0——用"通路标签置换"补上弱端

2026-10-27，R42。**在任何计算前冻结。** 只读本机 `gdsc_combinations`。

## 为什么

R41 用训练样本量把 ρ 从 0.325 压到 **0.186**（跨度 0.1394，未达预注册 0.15），所以"中等强度带"的**下边界没有建立**。要补上弱端，必须把 ρ 压到接近 0。

标签噪声（R40）在 n≫p 下无效；缩样本（R41）到 200 仍有 5:1 观测/参数比。本轮改用**破坏特征-结果关系**的办法：**在药物之间置换通路标签**。

## 构造

- 固定 41 维特征、固定全量训练集。
- 置换比例 f ∈ {0, 0.25, 0.50, 0.75, 1.00}：随机选 f 比例的**药物**，在它们之间重排 `ANCHOR_PATHWAY` 与 `LIBRARY_PATHWAY` 标签（列水平集固定，保证维度不变）。
  - f=0：原样；f=1：完全打乱 → 特征与结果无关。
- 任务同 E037：一次性预算、ridge λ=1.0、40 划分（20 搜 / 20 评）、k ∈ {10,20,30,50,75,100,150,200}。
- 每一步**重新抽样置换**（40 次划分各自独立置换），避免单一置换的偶然性。

## 判据（预先写定）

- **H109（强度被扫到接近 0）**：ρ 随 f 单调下降，且 f=1 时 ρ < 0.05；跨度 >0.25。
- **H110（中间带，两端都不利）**：存在某个 f 使 `mix − exploit` 在两半上同时显著为正；且 **f=0 与 f=1 处都不存在这样的 k**。
- **H111（强端利用占优）**：f=0 时，`mix − exploit` 在所有 k 上 ≤0 或 CI 含 0。
- 若 H110 成立 → **"中等预测强度"这条适用条件成立**（这是本项目第三条经双半验证的条件）。
- 若 f=1 处混合仍显著更好 → 说明"混合"在无信息时也能赢，那它不是"利用不确定度"，而是别的机制（需重新解释）。

## 边界

- 单一数据集；置换只作用于通路标签，不改变药物/细胞身份。
- 回顾性候选池；`SYNERGY_DELTA_AUC` 是拟合量。
- 不涉及机制、临床、药物选择；不做元学习/RSI。
