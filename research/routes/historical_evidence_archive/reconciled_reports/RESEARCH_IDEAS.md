# MAESTRO 研究想法总表

本文用于集中记录 MAESTRO 的研究想法及其待验证问题。条目记录的是设想，不代表已经完成查新、数据评估或实验验证；有新想法时可继续追加条目。

## 想法 1：知识增强智能体 × 虚拟细胞

- **记录日期：** 2026-10-26
- **状态：** 待验证
- **来源：** 用户粘贴文本《知识增强智能体 × 虚拟细胞：从“理解生物知识”到“自主发现药理规律”》

### 1. 当前核心想法

研究知识增强科研智能体与虚拟细胞（Virtual Cell, VC）的协同，目标从“检索或使用更多生物知识”推进到“通过实验反馈发现可复用的药理规律，并改善后续研究决策”。

暂定研究命题：

> 知识增强科研智能体能否通过主动质询虚拟细胞世界模型，发现可复用的药理作用规律，并在未来任务中提高实验决策效率？

英文表述：

> Can a knowledge-grounded scientific agent learn reusable pharmacological rules by actively interrogating a virtual cell world model, and use those rules to improve future experimental decisions?

设想中的关键过程是：

**生物知识 → 可检验假设 → 诊断实验 → 机制知识修订 → 跨任务决策收益**

潜在创新点不在于知识库、工具或代理数量增加，而在于验证这条过程能否产生独立、可迁移的后续决策收益。

### 2. 问题定位

当前设想区分三类知识增强：

| 层次 | 主要方式 | 目标能力 | 当前判断 |
|---|---|---|---|
| 知识检索增强 | RAG、文献检索、知识图谱查询 | 找到已有信息 | 可作基础功能，单独创新性有限 |
| 知识推理增强 | 机制推导、假设分解、证据检查 | 更规范地使用知识 | 有一定价值，仍需与已有智能体工作区分 |
| 知识发现增强 | 主动实验、反例验证、条件性修订 | 发现知识成立或失效的条件 | 潜在价值较高，尚待验证 |

设想中的区别：知识增强 VC 侧重细胞状态和干预响应预测；知识增强 Agent 侧重科学假设、证据、实验行动及知识适用边界的判断；Agent × VC 则尝试让预测与机制判断相互约束和修正。

### 3. 候选系统分工

- **知识增强科学 Agent：** 形成机制假设、判断证据、提出反事实预测、识别冲突、设计诊断实验，并根据反馈保留、收窄、修订或拒绝假设。
- **虚拟细胞世界模型：** 在给定细胞状态、干预及机制假设等条件下，预测响应、差异和不确定性；模拟结果须受其训练数据支持范围约束。
- **实验反馈：** 提供独立观测，用于更新 VC，并检验或修订机制假设；结果和适用条件应可复验、可追溯。

Agent 维护仍可能成立的科学解释，VC 估计这些解释成立时会观察到什么。双方出现分歧时，应将分歧转成可测量的问题；不能默认 Agent 的机制先验正确，也不能把 VC 的模拟本身当作独立实验事实。

#### 候选知识单元

将知识表示为带条件、预测和证据状态的假设，而非只有关系三元组：

`h = (C, A, P, E, U)`

- `C`：适用背景，如细胞类型和分子状态。
- `A`：干预条件，如药物、剂量和时间。
- `P`：可检验的响应预测。
- `E`：支持或反对该假设的证据。
- `U`：不确定性及尚未检验的适用范围。

### 4. 假设性案例（不是实验证据）

以 MEK 抑制剂为例：若两种肿瘤细胞背景都出现早期 ERK 通路抑制，但只有背景 A 预测出 72 小时存活降低，可考虑多种解释：

- **H1：补偿性存活机制。** 背景 B 的替代性存活程序削弱长期生长抑制。
- **H2：时间依赖的信号恢复。** 背景 B 在早期响应后发生适应性反馈。
- **H3：模型或测量问题。** 早期转录响应与功能端点对应不足，VC 对背景 B 的存活预测可能不可靠。

候选流程是让 VC 比较各解释下的可观测后果，再由 Agent 选择能区分竞争解释、且可能改变后续药物选择或验证路径的测量。实验结果若支持某个解释，则按背景、剂量、时间和测量方式修订知识，并保留独立验证状态。上述情境和机制均为说明流程的假设例子。

### 5. 候选核心机制：决策条件化的知识发现

当前更聚焦的研究问题是：智能体能否用有限实验发现哪些药理知识会改变后续药物选择，并将这些知识迁移到新任务中。

实验选择的价值不只看不确定性或信息增益，还看不同结果是否会改变后续决策，并考虑实验成本。原文也指出，决策导向的 Value of Information / 主动学习已有相关研究，不能单独作为创新点。

每轮反馈包含两个概念上不同的更新：

- **VC 更新：** 根据新数据更新响应预测模型。
- **知识更新：** 根据新数据和更新后的 VC，修订知识及其适用条件；更新需受证据、假设复杂度和统计检验约束。

核心验证目标不是知识条目变多，而是：**允许知识跨任务继承后，后续研究决策收益高于不继承知识的情形**；该差异须在未参与知识发现和修订的独立任务中检验。

### 6. Agent 能力训练的候选方向

可探索的任务包括：

| 输入 | 候选输出能力 |
|---|---|
| 表达谱与机制证据 | 形成有条件、可检验的机制假设 |
| 机制假设与 VC | 提出可区分的实验结果 |
| 模型预测与真实观测 | 识别冲突及其条件 |
| 多个候选实验 | 排序可能改善后续决策的测量 |
| 新旧证据与历史假设 | 有证据地保留、收窄、修订或拒绝假设 |

初期候选实现是冻结 LLM，由其提出结构化假设和候选实验；用可复现的数值程序完成 VC 预测、假设评分、实验排序和修订检验。若该流程稳定改善决策，再考虑将研究轨迹蒸馏成专用 Agent 模块。是否训练模型及采用何种目标仍待验证。

### 7. 候选验证设计

#### 对照方法

- 强直接预测模型。
- VC + 固定知识。
- VC + 常规主动学习。
- VC + 决策导向主动学习。
- 知识 Agent（不使用 VC 模拟）。
- VC + Agent（不修订知识）。
- VC + Agent + 知识修订。

#### 消融与主要指标

- 置乱知识关系，检查收益是否来自有效知识结构，而非额外特征。
- 禁止跨任务继承知识，检查知识迁移是否产生独立贡献。
- 在相同实验预算下比较候选命中、simple regret、选择后可靠性及跨任务迁移。
- 检查完整联合机制是否超过强直接预测、普通主动学习和固定知识融合。

原文特别指出，MAESTRO 中已有反馈闭环的运行基础，但知识迁移、Agent 独立贡献及相对强固定策略的稳定增益仍需正面验证。

### 8. 第一阶段范围设想

- **应用：** 有限预算下确认未见药物响应并进行候选排序。
- **候选数据：** Tahoe-100M 或 SciPlex3 扰动表达数据；若需要独立药效端点，再寻找能够严格匹配的药物存活数据。
- **VC：** 从简单、可校准的状态条件预测器开始。
- **Agent：** 提出机制差异、生成可检验假设并选择下一项测量。
- **反馈方式：** 按封存协议逐步揭示历史实验结果并离线回放。
- **资源设想：** 本地常规模型和少量 LLM 调用，不先训练大型基础模型。

历史数据回放只能支持既有测量空间内的策略比较，不能等同于湿实验验证。若要提出药物发现价值主张，还需独立来源的功能端点或真实新实验。知识与文献的可用时间边界需预先冻结，封存测试标签不得提前用于机制修订。

### 9. RSI 的阶段定位

RSI 暂不作为第一阶段必要目标，可作为后续方向分层考虑：

1. **知识积累：** 实验反馈产生更可靠的机制知识，改善后续预测和实验设计；这本身不等于 RSI。
2. **研究策略改进：** Agent 从任务历史中学习哪些冲突值得调查、哪些实验有区分力，并改善新任务效率。
3. **递归自我改进：** 改进后的 Agent 在相同起点、数据和预算下，比旧 Agent 更能产生有效的下一代改进策略。

第三层需通过条件匹配的独立比较验证，不能仅凭累计经验增加后的性能上升作结论。

### 10. 当前优先级判断（待查新与验证）

| 方向 | 当前想法中的优先级判断 |
|---|---|
| 生物知识 RAG Agent + VC | 作为基础功能，创新空间较低 |
| 知识任务训练 Agent + VC | 值得验证 |
| 机制冲突识别 + VC | 优先考虑 |
| 反例驱动的知识修订 + VC | 重点研究，但需处理已有工作重叠 |
| 面向未来实验决策的知识发现与继承 | 当前最推荐，取决于独立验证 |
| 上述机制进一步实现 RSI | 作为第二阶段方向 |

### 11. 尚待验证的问题

- 与 Biomni、Co-Scientist、Robin、STELLA、POPPER、MAP、PIE、GEMOT 及决策导向主动学习等工作的准确关系和新颖性边界是什么？本记录未核实原文中的文献描述。
- 可用数据是否包含足以支持状态、药物、剂量、时间及功能端点匹配的观测？VC 的预测范围是否覆盖候选诊断读数？
- 反馈、知识修订和跨任务继承能否在严格封存下回放，且不发生标签或文献信息泄漏？
- 评估能否证明知识修订带来的独立决策收益，而非 Agent、VC、额外特征或实验预算本身的收益？
- 离线回放的证据是否足以支持拟提出的结论；还需要哪种独立功能数据或湿实验？
- 在收益成立前，是否应保持 LLM 冻结；后续何时才值得训练专用模块或推进 RSI？

## 想法 2：跨背景可迁移的机制鉴别与共同学习

- **记录日期：** 2026-10-26
- **状态：** 待验证；当前方向判断与先例描述来自用户提供的定向检索总结，本次仅记录，未独立复核。
- **来源：** 用户补充的研究分析；完整报告路径为 `D:/codex/2026-10-26/tf-rna-agent-agent-llm-agent/outputs/virtual_cell_agent_research.md`。

### 1. 收紧后的研究问题

保留“智能体与虚拟细胞共同学习”的设想，但把问题聚焦为：

> 系统能否用有限的真实实验，辨别药物响应为什么在新细胞背景中发生变化，并把有效的辨识经验迁移到下一个背景？

当前更值得保留的科学价值，是发现具体的机制鉴别关系、所需的最小测量条件及其迁移边界；暂不主张已经形成新的通用 Agent 算法。

### 2. 对跨背景泛化的限定

“模型学到了 TF 或通路，但不会运用”只是一个待检验解释。模型表征中存在 TF 或通路结构，不等于掌握了可迁移的因果规律；共表达关系本身不能说明干预哪个节点会改变结果，也不能说明作用方向是否依赖细胞背景。

跨背景预测失败还可能涉及药物作用编码、训练数据覆盖、隐藏状态或预测目标。因此，需要区分至少三种外推任务：

| 外推任务 | 实际要求 |
|---|---|
| 新药 + 已见背景 | 从药物结构、靶点或其他先验推断作用 |
| 已见药 + 新背景 | 判断背景变化如何改变药物作用 |
| 新药 + 新背景 | 同时处理新药与新背景两种陌生因素 |

待研究的问题应是：哪些规律能够迁移、迁移需要哪些条件，以及模型能否识别条件已失效。用户提供的检索总结称，2025 年线性基线研究在四个遗传扰动数据集上未发现所测深度模型稳定超过简单基线，而 State 报告了新背景预测的正结果；这些范围和结论需查阅来源后再采用。

### 3. 时间预测与机制辨识的区别

动态预测、机制拆分和因果辨识不是同一个问题。增加时间点可能缩小解释范围，但不保证机制唯一：

- 流匹配中的计算时间从 0 到 1，不自动对应给药后的生物时间。
- 常规单细胞 RNA 测序是破坏性测量；不同时间点通常是不同细胞群体快照，不是同一细胞的连续历史。
- 即使轨迹拟合良好，多条调控路径仍可能产生相似 RNA 变化。
- 某类细胞状态减少，可能源于状态转变，也可能源于该群体优先死亡；更多 RNA 时间点未必能区分两者，绝对细胞计数、死亡测量或谱系信息可能更关键。

由此形成一个更具体的候选问题：

> 系统能否判断，当前机制歧义需要更多时间点，还是需要另一种测量或干预？

用户提供的定向检索列出 CellFlow、ARTEMIS 及快照动态推断理论研究作为相关背景；具体方法能力、发表状态和适用边界待核实。

### 4. 分子读出与药效结局

RNA、蛋白磷酸化等分子响应是药物响应的一部分，但不能自动代表增殖、死亡、耐药、免疫功能或组织及个体结局。RNA 改变可能是补偿反应；蛋白磷酸化可能先于转录；表达恢复也不保证功能恢复。

加入药物分子、靶点和 RNA 等模态，只有在能排除具体竞争解释时才有价值。药物作用也不能直接等同于相应基因敲除：抑制程度、作用时间、多靶点及脱靶效应都可能造成差异。多药组合与协同暂不作为起步范围；须先定义结局、剂量、时间及协同参考，表达变化的非加性不能直接解释为杀伤协同。

用户提供的定向检索以配对化学与遗传扰动研究作为药物干预和遗传扰动不等价的依据；该来源的具体证据待核实。

### 5. Agent × 虚拟细胞的候选共同学习目标

本设想不把简单套用 Agent 或笼统的“共同改进”视为贡献，而要说明究竟改进了什么：模型代码、预测器参数、实验策略，还是文字记忆与评分目标。

在机制鉴别任务中，双方可承担不同的学习目标：

- **虚拟细胞学习：** 在真实数据约束下维护仍相容的解释，并预测不同解释对下一项干预或测量的差异。
- **实验策略学习：** 学会面对某类歧义时，哪项可执行实验最值得做，以及这一经验在新背景中是否仍有效。

关键前提是竞争机制必须产生可信且不同的实验预测。普通 RNA 生成器的采样分歧或 LLM 生成的不同叙事，不足以构成机制分歧。机制也可能共存，不应预设互斥的二选一。

用户提供的定向检索总结称，VCHarness、免疫衰老虚拟细胞验证研究、CXCL9 机制建模及 Deep Adaptive Design 等工作分别与 Agent 改进预测流程、真实筛选反馈、主动机制实验或适应性实验设计相关。DGM、AlphaEvolve 可供借鉴的是生成可执行候选、接受外部评价和保留有效修改；其成果不能直接证明生物学闭环有效。以上工作与本设想的关系及新颖性边界均待独立查证。

### 6. 候选验证顺序

1. **证明有信息可学：** 找到一对有独立机制参照、初始表型相近的状态，并确认某项实际实验能可靠地区分它们。
2. **检验跨背景复用：** 完整留出新的细胞背景，并与固定专家实验顺序、强贝叶斯实验设计或 DAD 类方法公平比较。
3. **拆分双方贡献：** 分别冻结预测模型和实验策略，并设置真实反馈、打乱反馈及无反馈对照。
4. **评价独立证据：** 比较可靠区分机制所需的实验成本、错误确信是否减少，以及未见干预的功能结果能否预测正确。

### 7. 证据边界与范围控制

- 若已有数据只有终点 RNA，结论应限于预测表现和已测实验回放；不能把虚拟细胞生成的结果当作新机制真值。
- 不必先构建完整数字细胞；适用范围清楚且能够被实验纠正的局部模型也可能支撑研究。
- 离线回放、真实功能测量和新湿实验的证据层级应明确区分。
- 起步阶段聚焦跨背景机制鉴别，不同时铺开全部模态、药物组合、协同和完整 RSI。

**记录边界：** 本条记录的是研究问题、假设和验证顺序。文中列出的论文及相关工作结论来自用户提供的定向检索总结，未在本次任务中复核；不能据此视为已确认的新颖性或实验结论。

### 1. 八方向尝试后的当前结论

后续执行报告对八个方向都做了不同程度的最小尝试。当前不能把方向 1 称为已获支持的主线，也不能把其余方向概括成同一种“生物学假设被否定”：失败分别属于本次实现无收益、证据门槛未过或尚未实现原方向的完整主张。

| 方向 | 执行报告中的结果 | 当前判断 |
|---|---|---|
| 1. 反例驱动的条件药理规律 | 固定交互选择在已知药物新背景上的 top3 效用未优于普通 refit；相对 refit 差为 −0.041601，95% 探索区间 [−0.087350, 0.003983]。实现只是两个固定交互族的代理，机制 P0 未过。 | 本次修订实现未获决策收益；不启动机制主张，不能据此否定所有规则修订方法。 |

整体证据边界：药敏结果是探索性离线开发；无新湿实验、独立 screen 确认、真实机制标签或完整 LLM/Agent 训练。数据划分不能消除 PRISM 的历史暴露问题。独立检查复算了决策效用及配对汇总，但未独立重拟合全部模型。故八项均不能作为已验证创新方向推进；方向 7 的内部收益也不能升级为独立方法贡献。

**当前停止决定：** 暂不启动方向 1 的机制主实验，不扩展架构或启动大型 RSI。若要重启，优先补方向 1 的正交机制参照，或追溯方向 5 的独立重复与暴露信息；仅在新增证据解除当前门槛后再决定。

### 3. 收紧后的主问题（待重新满足证据门槛）

> 当一条药理规律在新背景中失效时，系统能否辨别应该修订细胞背景条件，还是修订可代表该作用的药物范围，并使修订后的规则在未见背景、未见化合物中仍然有效？

例如，背景 C0 中药物 A 有效，背景 C1 中 A 无效。此时不能立刻把规则改成“C1 不响应”。如果名义同靶点但化学结构不同的 A′ 在 C1 仍有效，可能需要修订药物范围，而非排除整个背景；如果 A 与 A′ 在 C1 均无效，则共同背景限制得到支持，但具体机制仍未确定。靶点参与、适当遗传干预等证据可以帮助区分解释；证据不足时不得直接归因于脱靶或旁路。

潜在研究产物是带有明确背景条件、干预范围和证据边界的可迁移功能规则，而不是未经证实的机制真相。所谓共同学习必须让规则修订实际改变预测和药物选择；若 Agent 只改写文字解释、预测器行为不变，则没有实现所设想的耦合。

### 4. 曾提出的两项分离验证（尚未证明有效）

1. **相同反馈，比较修订能力：** 所有方法接收完全相同的数据，比较证据约束的规则修订是否优于普通重新拟合或同等复杂度的条件模型。该实验隔离“如何修订规律”的贡献。
2. **相同预算，比较取证策略：** 固定规则更新方法和实验预算，比较反例选择是否优于固定专家顺序、强贝叶斯实验设计、目标导向主动学习、GP 或 exploit-first 等强基线。该实验隔离“如何获得证据”的贡献。

两项结果需分开报告。否则，更多标签、更好的采样或额外文献知识都可能被误归因于规律修订能力。

### 5. 方向 5 的进入条件

备选问题限定为：在给定细胞背景、伙伴药物和暴露条件下，A′ 能否替代 A，同时保持指定的功能效果？检验必须基于真实测量的 A+B 与 A′+B。

- 单药效果相似、靶点相同或 RNA 签名接近，不足以推出组合中的可替换性。
- 必须排除两者都无效、B 单独解释全部效果，以及检测落在地板或天花板等平凡成功。
- “差异不显著”不等于等效；需要预先定义功能终点、等效界值和剂量/暴露条件。
- 与标准组合模型对响应差值的校准预测比较；若常规基线已经找到同一替换关系，增加“算子”命名或结构本身不构成方法贡献。

### 6. 先例边界与方法主张

用户提供的筛选材料指出：[LOBICO](https://doi.org/10.1016/j.cell.2016.06.017) 已学习多条件药敏规则并跨资源验证，[MERIDA](https://doi.org/10.1093/bioinformatics/btab546) 已整合多组学和知识先验、迭代纳入标志物；因此“反例出现后增加条件并累积知识”不足以单独构成创新。[DiscoBAX](https://proceedings.mlr.press/v202/lyle23a.html) 已围绕最终干预选择获取信息，[BATCHIE](https://doi.org/10.1038/s41467-024-55287-7) 已进行主动组合筛选、模型更新及治疗指数评价；决策感知自我校正应主要作为评价目标和强基线。

该材料也将选择性预测、知识增强、Agent 主导实验设计、动态流模型和 RSI 等列为已有相近工作的区域。具体论文结论及本研究与这些工作的边界，须在正式研究前按原文复核。当前可保留的主张是一个待检验的具体科学问题，不宣称已有新的通用 Agent 算法或规则修订算法。

### 7. 数据可行性记录与 P0 门槛

下列状态转述自用户提供的研究筛选报告，本次未独立复核或重新合并数据：

- **PRISM：** 有功能药敏、剂量、药物和批次信息，可作为条件规则与封存回放的候选；尚未计算支持跨背景、跨化学实现验证的有效交集。
- **BATCHIE：** 公开清单包含双药和三药数据；尚未确认有足够匹配的替换实例及等效检验精度。
- **PerturbFate：** 有配对多组学与并行功能读出；组学采样在 day 6，不能直接视为多时间点动态轨迹。
- **CCLE / GDSC：** CCLE 部分综合数据已引入 GDSC 药敏标签；不能仅凭数据库名称不同推定训练和测试独立。

**P0 停止门槛：** 先为方向 1 找到具有真实交叉支持的药物家族，证明现有证据能够区分“背景限制”与“化合物例外”。若缺少这种交叉结构或独立参照，不启动主实验，也不以增加 Agent、流匹配或 RSI 来弥补信息缺失。

### 8. 原拟验证顺序与结论边界（需由新证据触发）

1. 审计药物、细胞背景、干预、剂量、批次和独立功能终点的交叉覆盖；预先确定封存拆分及数据独立性。
2. 建立简单 VC 与静态知识增强模型，确认其相对强常规预测基线的表现。
3. 在相同反馈下比较条件规则修订与普通重新拟合。
4. 固定更新方法，在相同预算下比较反例获取策略与主动设计强基线。
5. 在未见背景和未见化合物上评价功能终点、规则迁移、实验成本及错误确信。
6. 只有前述一次修订和迁移收益成立后，才考虑诊断元学习；RSI 更后置。

数据拆分、剂量匹配、时间点和实验批次须预先审计。PRISM 与 GDSC 不能只因数据库来源不同就当作独立验证。Virtual Cell Challenge 的未见扰动背景表达预测可作跨背景预测参考，但不是药物功能筛选终点的替代品。
