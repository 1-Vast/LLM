## 1. 三类失败的 operational 定义（冻结用）

记号：对一次**测量**，`x = (细胞 c, 有向/无序药对 p, 剂量设计 d, 测量条件 m)`；`y` 为功能端点（本主线沿用 `SYNERGY_DELTA_EMAX` 或组合敏感性类端点；不在此重定义）。`φ(x)` 为**用药前可得**的冻结表征（项目惯例：identity one-hot / 通路 one-hot / 表达·突变·组织等细胞状态特征）。`g` 为已测的**测量组/背景**（screen、批次、时间窗口、培养条件；必须是可辨认的组，不是同日 barcode 分半）。`s` 为**未进入表征的状态变量**（未测，或测了但被省略）。

三种竞争解释：

| 类 | 生成模型（竞争假设） | 一句话 |
|---|---|---|
| **F1 关系失效/适用条件失效** | `y = f_g(φ(x)) + ε`：同一关系在不同背景 `g` 下形式不同；背景内**可重复**的偏移/符号翻转是 `g` 的函数 | 关系本身"换了适用条件"，不是缺测量 |
| **F2 数值调整** | `y = f(φ(x)) + b + ε` 或尺度/正则/聚合/标定问题：残差是零均值/可标定的数值偏差；校正后消失 | 数字没调好，不是缺信息 |
| **F3 表征遗漏关键状态** | `y = f(φ(x), s) + ε`：状态 `s` 在固定 `x` 内有**决策相关**变异；`s` 未被 `φ` 表示，且不是 `g` 的函数（或 `g` 只是 `s` 的粗代理） | 表征漏了一个会改变决策的状态 |

**关键约束（防止"只换模型名"）**：F3 的判定必须涉及**一个新的状态变量**（已测但未入表征，或新测量）与**决策相关的变化**；不得把"换模型/换损失/换正则"称为表征遗漏。F3 与 F1 在 `g` 被测量时天然混淆：`g` 可以当 `s` 的粗代理；**必须**用 §2 的 state-matched/within-group 变体区分。

## 2. 可观测签名（operational，先冻结）

以下签名只用已有观测/元数据即可实现；每个都给出**零模型与对照**。

### Sig-A：条件偏移符号翻转的"可解释性"（flip explainability）

- **单元**：同一细胞 `c`、同一条件对 `(p,q)`（沿用 A0/A1 的 controlled_anchor 分层）、在 **≥2 个独立测量组** `g1,g2` 中均测得。
- **统计量**：`Q_{g}`（组内条件偏移，或等效的 ΔEMAX 差）；`flip = 1[sign(Q_{g1}) ≠ sign(Q_{g2})]`。
- **噪声地板**：用同组内技术重复/barcode 分半或独立重复估计 `P(flip | 纯噪声)`（A0 已记录 1,312 个重复齐全回路可做噪声标定；但注意 A0 的 barcode 是**同 screen/同批**，只给技术噪声，不给跨批）。
- **嵌套预测**（同一 CV 口径、同一变量集）：
  - M0：仅噪声/先验；
  - M1：已知协变量 `K`（组织、表达 PC、突变、剂量设计、已测批次/时间）；
  - M2：`K + 测量状态 S`（已测未表征的 state：培养代理、表达/突变特定轴等）；
  - M3：`K + S` 的置换/随机对照（容量匹配）。
- **判定签名**：F3 要求 **(a)** `flip` 率显著高于噪声地板；**(b)** M2 对 M1 的**样本外**增量（AUC/部分 R²）CI 下界 >0 且 ≥δ_min；**(c)** M3 无增量、置换 `S` 后增益消失；**(d)** 在**同组内**（state-matched：`g` 固定、`s` 变）仍可复现，或在新独立组中可预测。
  - F1 签名：`flip` 由 `g`（已测背景）解释，M2 无增量；组内重拟合/按 `g` 分层后消失。
  - F2 签名：`flip` 率≈噪声地板；M1/M2 均无样本外增量，校正后残差零均值/尺度结构。

### Sig-B：表征外推距离–残差单调性（extrapolation distance vs residual）

- **距离**：在冻结表征 `φ` 的状态空间，对每个 `(c,x)` 定义到训练背景的最小距离 `d_φ(c)`（表达 PC/突变/培养/组织距离）与条件新颖度 `d_x`。
- **统计量**：残差 `r = y − f_ref(φ(x))` 的**幅度与符号**随 `d_φ`/`d_x` 的变化（分层中位数、Spearman、单调性检验）。
- **零模型/对照**：① 用已知协变量/剂量/批次解释残差（M1）；② 用相同 `d`、但打乱细胞标签的容量匹配对照；③ 在相同 `n` 的近距离/远距离分层内比较（控制样本量）。
- **判定签名**：F3 要求距离–残差（尤其**符号**）在**样本外细胞/条件**上单调且可预测，且不能被 M1 或校准（F2）解释；F1 要求残差由组 `g` 解释（距离是 `g` 的代理，组内无距离效应）；F2 要求残差只有可校正的均值/尺度。

### Sig-C：状态增广后的未测动作改善（state-augmented decision gain）

- 定义**决策动作**：在候选 `(c,x)` 集合中，对**未测**项选择"会翻转/会失败/值得测"的对象（或对状态条件的风险排序）。
- 比较（同一信息、同一调参/预算）：无更新；数值重标定；按 `g` 分组的 F1 式重拟合；加入已测状态 `S` 的更新；加入**新测量** `s` 后的更新；容量匹配随机状态；`S` 置换。
- **判定签名**：F3 要求加入 `S`/`s` 的**未测动作排序/选择收益**优于上述所有基线（CI 下界 >0 且 ≥δ_min），且置换状态后消失；F1 要求分组重拟合足够、状态无增益；F2 要求重标定足够。
- 本签名涉及效果估计，**本轮不执行**；写入 [protocol_draft.md](protocol_draft.md) 作为未来冻结项。

### Sig-A/B/C 的联合判决（phenotype table）

| 观测模式 | F1 关系失效 | F2 数值调整 | F3 表征遗漏 |
|---|---|---|---|
| `flip` 率 vs 噪声 | 高且组间稳定 | ≈噪声 | 高且与状态相关 |
| M1（已知协变量）解释力 | 高（组/协变量） | 中（可标定） | 低 |
| M2（+状态）样本外增量 | 无 | 无 | **有** |
| M1 vs 分组重拟合（F1 对照） | **分组重拟合足够** | — | 分组重拟合不足 |
| 校准/重标定（F2 对照） | 不足 | **足够** | 不足 |
| 状态置换/容量对照 | 无变化 | 无变化 | **增益消失** |
| 距离–残差（Sig-B） | 组解释距离 | 仅尺度 | **单调、符号可预测** |
| 决策改善（Sig-C） | 分组条件够 | 重标定够 | **状态增广新增** |

- 若以上证据不能分离 → 记 `inconclusive_design`（不是 F1/F2/F3 任一成立）。
- **强制性措辞**：F3 成立只表示"在该设定/该状态变量集上，存在可复现、决策相关、不被已知协变量解释的状态结构"；不表示机制/因果/临床结论，也不表示该状态变量是唯一或真实生物学状态。

### 3.3 "可立即检验 / 需新增测量 / 不可检验"清单（冻结）

**可立即检验（不新增测量；只做预注册诊断/描述）**
1. Sig-A 的**噪声地板 + flip 率 + 已知协变量解释力**：Jaaks Original vs Validation（96 共享细胞、A0 92,039 controlled_anchor 观测、1,312 个重复齐全回路（噪声标定））+ 组织/表达/突变/培养注释做 M1。
2. Sig-B 的**状态距离–残差**描述：DepMap 表达/突变/培养距离 vs A0/A1 已定义残差结构（用既有冻结关系/矩阵，仅设计；不得重估效果）。
3. **状态代理**（DAY1/GR/DT、barcode 板）与条件偏移的关联（同 screen；必须作为"同批技术状态"解读，不得当独立状态）。
4. **Mix-seq 时间**描述：285 键 6h/24h 的状态差异（单药；不作组合/决策结论）。
5. **BeatAML 患者状态**与单药响应的状态关联（非组合；仅作状态变量覆盖核验，不作本项目结论）。

**需新增测量（最小清单）**
1. **同一 (细胞, 条件) 的独立批次/日期/培养重复**（≥2 独立批次；用于把状态与同批技术噪声分开）。
2. **per-measurement 培养状态**：培养基/氧/接种密度/传代/汇合度；至少一个可控操纵。
3. **同一 (细胞, 组合) 的功能时间序列**（≥3 个时间点；Mix-seq 只有 2 个时间点且为单药）。
4. **同 screen 内配对的状态读数**（组合响应同批测转录组/活力/生长），用于 Sig-C 的"状态增广"真实检验。
5. 若要做**跨 screen 条件复验**：满足 A3 修正后规格（≥2 独立组合 screen、≥200 共享细胞、≥10,000 匹配条件单元且剂量等价可验证；A3 当前 41/4,179 不合格，ERRATA_A3 已限）。

**不可检验（本机现有资源/本任务边界）**
1. 体内/微环境/免疫/药代暴露（无数据；不把体外当体内）。
2. 靶点占据/通路因果状态（Klaeger 是 lysate binding，不同细胞/条件；本项目旧记录中的旁证不构成占据）。
3. 克隆异质性/谱系状态、细胞周期分辨状态（无分选/单细胞配对数据）。
4. 任何"遗漏状态"的**因果**结论（F3 只到"可复现、决策相关、可由该状态变量解释"；需干预/独立功能证据才升级）。

**权力/功效边界（必须写在任何 F3 检验前）**：A0 已测 within-pair 细胞排序 MDE80=**0.240**（双向聚类）> δ_min=0.05；A1 跨 screen 主 Q `inconclusive`（MDE80_obs 0.2042 > δ_min_obs 0.0893；n_eff≈189，96 细胞）；A3 跨 study 大规模结构 `not_qualified`（ERRATA_A3：只限冻结大规模门槛）。因此上述"可立即检验"项目在**效应级**很可能只能得到 `inconclusive`，不得把阴性写成"F3 不存在"或"表征无信息"。

## 4. 与 A1/A2 的互补关系（不重复、不替代）

- **冲突信号线（任务中称 A1）**：判断反馈与冻结功能关系是否"不相容"；本文件要求该冲突信号必须再做**状态条件化分解**（已知协变量 vs 状态 vs 残余），否则无法区分 F1/F2/F3。
- **A2（逻辑约束）**：把硬约束（单药加减、方向/单位/剂量可比性）排除出"冲突"；A4 的 F3 检测只处理**约束之外**、可由状态解释的残差。
- **A4（本文件）**：把冲突残差进一步路由为 **measure-state 动作**（F3）vs **revise-relation 动作**（F1）vs **recalibrate**（F2）；输出"需要什么测量"而不是先改模型。
- 机制候选（见 §5）就建立在这个路由上；不声称是新的预测算法。

## 5. 机制候选（1 个）：状态条件化冲突信号（State-Conditioned Conflict, SCC）

**候选陈述（可证伪）**：在药理组合/细胞背景设定下，部分"关系冲突"不是关系失效，也不是数值问题，而是**表征遗漏了可测量的状态变量**；用**已有的状态变量**对冲突残差做条件化，可以（i）把可由状态解释的冲突从"关系失效"中分离出来（诊断），并（ii）把"该去测什么状态/条件"作为动作建议，改善未测组合/细胞的选择（决策）；加**新测量**状态后，同一冲突应消失或变为可预测的状态校正。

**与 A1/A2 的接口**：输入 = A1 的冲突信号 + A2 的约束可行域；输出 = 对每个冲突的标签（F1/F2/F3）与测量动作（测哪个状态变量/哪个条件）；不替代更新器，也不宣称优于普通更新（需对照）。

**可证伪预测（先冻结后测）**
- **P1（签名存在）**：在 Jaaks O/V matched 四元组上，条件级 `sign-Q` 翻转率高于技术噪声地板，且超出已知协变量（组织/表达 PC/突变/剂量设计）可解释部分；`flip` 的样本外 AUC 对"已知协变量+状态" > "仅已知协变量"（ΔAUC ≥ 0.10，CI 下界 >0；置换 `S` 后消失）。
- **P2（不是 F1）**：按组（screen）分层/组内重拟合后，状态增量仍在（或仅在 state-matched 子集内仍有）；若分组重拟合完全吸收 → 判 F1（关系失效），不是 F3。
- **P3（不是 F2）**：只做标定/重标定（截距/斜率/λ/方差）不能消除状态增量。
- **P4（决策相关）**：在未测选择上，状态条件化冲突信号优于残差幅度、后验方差、距离/leverage 的强基线（未来效果协议；本轮不测）。
- **P5（干预）**：最小实验中对状态作可控操纵，条件级符号/幅度按预注册方向改变；state-matched 对照不变；`S` 置换后预测失效。

**失败类别**：`numeric_only`（F2）、`relation_invariant`（F1）、`missing_state_supported`（F3 签名成立）、`state_irrelevant`（F3 但状态无决策相关）、`inconclusive_power`、`manipulation_failed`、`confounded`。

**最小实验设计（若 A4 从设计进入执行）**
- **Phase 0（零新增测量，先做诊断）**：Jaaks O/V + A0 四元组 + DepMap 状态 → 估计 flip 率/噪声地板/M1 vs M2；预注册 δ_min=0.10（ΔAUC）、α=0.05、按细胞分组 CV；MDE 用置换/分层 bootstrap 预计算；**若 MDE > δ_min 或 flip 率≈噪声地板 → `inconclusive_power` 停，不进入 Phase 1/2**。
- **Phase 1（最小新增测量）**：选择 Phase 0 中 flip 候选（平衡 flip/non-flip）→ **2 个细胞系 × 2 个状态操纵（如同一细胞的两种接种密度/培养基/氧条件，或 ±一个可测状态诱导）× 6 个条件对 × 2 个独立批次（不同日/不同培养）× 2 重复 = 192 孔**（可扩展到 4 细胞系 × 6 条件 × 2 状态 × 2 批 × 2 重复 = 384）；同一剂量矩阵与端点，配合同批状态读数（活力/生长/基态表达）。
- **对照**：同批技术重复（噪声）、state-matched 对照、已知协变量-only、重标定、按批分组重拟合、容量匹配随机状态、`S` 置换、A1 冲突信号 A2 约束（逻辑上被排除的冲突不进入 F3 检测）。
- **停止条件**：状态操纵检查失败（无可测状态变化）→ `manipulation_failed`；flip 率不高于噪声地板 → 停（F3 无签名）；MDE>δ_min → `inconclusive_power`；状态增量被分组重拟合/标定完全解释 → F1/F2（不升级）。
- **升级条件**：Phase 1 支持 F3 后，才允许 Phase 2 决策实验（固定更新器，比较状态采集动作 vs 普通采样；未测动作净收益，同预算同成本；预注册 MDE/δ_min）。**本轮两步都不执行。**
