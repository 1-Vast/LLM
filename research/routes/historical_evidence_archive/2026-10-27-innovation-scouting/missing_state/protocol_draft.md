## 2. 变量集（先冻结；所有状态变量不来自响应）

- **K_known（已知协变量，模型"已测"部分）**：
  1. `Tissue`（Jaaks 3 水平，one-hot）；
  2. 表达 PC（在 DepMap 1,249 细胞上**无监督**计算，固定 20 维；不接触响应）；
  3. 突变状态（预注册基因集：`target_map` 的 72 个映射基因 + 预注册驱动基因；离散 0/1；不按响应筛）；
  4. 剂量设计（anchor/library 浓度序号/秩；预注册离散化）；
  5. 若用于跨组对照：已测背景 `g`（screen、plate/barcode 需要时作为**已知组**处理，见 §3）。
- **S_state（已测未表征状态，候选 F3 变量）**：
  1. Jaaks 同 screen 培养代理：`DAY1_NORM_MEAN`、`DAY1_NORM_SD`、`GROWTH_RATE`、`DOUBLING_TIME`（97.7% 行；**测量时状态**，不是响应）；
  2. DepMap 细胞级培养注释：`culture_type`（66/125 Jaaks）、`culture_medium`（67/125）、`sample_collection_site`（125/125）、`primary_or_metastasis`（113/125）、`age`（104/125）、`sex`（125/125）；
  3. 表达/突变的**预注册轴**（与 K 不重叠：例如按预注册的 3–5 个状态轴投影；不得用 K 已含的 20 PCs 重复计入）；
  4. 缺失值处理预注册（缺失=显式 missing indicator；不做响应条件插补）。
- **New-state（需新增测量；Phase 1 才可出现）**：per-measurement 培养基/氧/接种密度/传代/汇合度；同一 (细胞,条件) 时间序列；同批状态读数（基态表达/活力/生长）。

## 3. 单元与统计量（先冻结估计器）

- **单元**：A0 controlled_anchor 四元组（`cell pair (c,c') × condition pair (p,q)`）；仅用 O/V 两侧均可得且符合 A0 资格的单元；同一细胞/条件节点的依赖保留（不按独立边近似）。
- **组**：`g ∈ {Original, Validation}`（跨 screen，**不是**同日 barcode 分半）；barcode 只在组内作技术重复/噪声地板，不升级为独立组。
- **主统计量（Sig-A）**：
  - 对每个单元定义 `Q_g = (y_{c,p} − y_{c,q}) − (y_{c',p} − y_{c',q})`（与 A1 同定义；A4 不重开 A1 判定）；
  - `flip = 1[sign(Q_O) ≠ sign(Q_V)]`（仅用两侧 |Q|>预注册阈值/非零的单元，阈值按 A1/A0 已冻结口径；未见结果前写死）；
  - **噪声地板**：A0 已记录的 1,312 个重复齐全回路上的 `flip_noise`（同 screen 技术重复，不跨批）；主分析同时报告 barcode-split 半样本 flip 率；
  - **嵌套模型**（同一调参/同一 CV）：M0 常数/噪声先验；M1 `K_known`（线性/岭，预注册 λ 网格，内层 CV）；M2 `K_known + S_state`；M3 `K_known + 容量匹配随机 S`（S 置换或随机同维特征）；M4 `K_known + g`（F1 对照；g 是已测背景）；
  - **主指标**：flip 预测的**样本外**（按细胞分组 CV；O/V 双侧评估）AUC；`ΔAUC(M2−M1)`。
- **次统计量（Sig-B）**：对冻结关系残差 `r`（由 A1/A0 冻结口径，不重训），用 `S_state` 空间距离 `d_S(c)` 分层；检验 `|r|` 与 `r` 符号对 `d_S` 的样本外单调/可预测（Spearman + 分层中位数），并同 M1/M4 对照。
- **Sig-C（决策；Phase 2）**：未测选择（top-k/selection regret）——只在本协议 Phase 2 执行，Phase 0 不测。

## 4. 判定（冻结；先于打分）

令 `ΔAUC` 为 M2−M1 的样本外差值，CI 按**细胞聚类**（并报条件/双向聚类敏感性）。

- **`missing_state_supported`（F3 候选）** 当且仅当：
  1. `flip` 率显著高于噪声地板（bootstrap/置换 p<0.05，且 barcode-split 不解释）；
  2. `ΔAUC` 点估计 **≥ δ_min=0.10** 且 CI 下界 >0；
  3. M3（容量/随机状态）与 S 置换无增量；M4 分组重拟合**不能**完全吸收 M2 增量（或仅在 state-matched 子集内仍有）；
  4. 重标定（F2 对照：截距/斜率/方差/λ 调整）不能消除增量；
  5. MDE80（预注册模拟）≤ δ_min（否则 `inconclusive_power`）。
- **`relation_invariant`（F1）**：M4（g）或分组重拟合吸收增量；或 flip 由组/已测背景解释、M2 无增量。
- **`numeric_only`（F2）**：flip≈噪声地板；重标定后残差零均值/尺度且无状态增量。
- **`inconclusive_power`**：MDE80>δ_min 或覆盖率不足（见 §5），或 flip 单元数不足预注册阈值。
- **`state_irrelevant`**：F3 签名成立但 Sig-C（Phase 2）无决策增益 → 保留诊断、撤决策主张。
- 所有判定同时报 delta/CI/MDE/单元数/覆盖率；阴性完整记录，不改写旧结果。

## 5. 设计体检（先于判定；不过 → `inconclusive_power`，不救）

1. 覆盖率：O/V 两侧可算 Q 的单元数 ≥ 预注册阈值（用 A0/A1 已有计数与依赖单位计算；A1 的 n_eff≈189、96 细胞为边界，必须在协议里写明预期 MDE 与"很可能 inconclusive"的先验）。
2. 噪声地板可估：重复齐全回路 ≥ 预注册数（A0 已记录 1,312 个重复齐全回路）。
3. `flip` 事件数 ≥ 预注册下限（按朴素 10 events/variable 或 bootstrap 稳定性的最小事件数；未见结果前写死）。
4. 单元独立性/依赖：按细胞/条件节点聚类 CI；报告 dyadic 对比方差与独立边近似差异（A1/ERRATA_Q2 的 10.33× 反例作为 sanity check，不重复推导）。
5. 先验 MDE 模拟：固定种子、预注册模型/口径；若 MDE80 > δ_min → `inconclusive_power` 停（与 A0/A1 一致）。
6. 泄漏审计：状态变量无响应派生；CV 按细胞分组；O/V 分组不混；测试标签只用最终打分一次；变量集/阈值预注册；记录 SHA 与随机种子。

## 6. Phase 1（仅当 Phase 0 通过才执行；最小新增测量）

- **目的**：把"已测未表征状态"升级为"可操纵状态"，检验 flip 是否随状态改变（P5），并给 Phase 2 决策实验提供状态读数。
- **设计（最小、可买）**：Phase 0 flip 候选（平衡 flip/non-flip）中选 **2 细胞系 × 2 状态操纵（同一细胞两种接种密度或两种培养基/氧条件；一次只操纵一个变量）× 6 条件对 × 2 独立批次（不同日/不同培养批）× 2 重复 = 192 孔**；若扩到 4 细胞系 × 6 条件 × 2 状态 × 2 批 × 2 重复 = 384 孔。同一剂量矩阵/端点/检测；每板记录状态读数（活力/生长/基态表达，若预算允许）。
- **对照**：同批技术重复（噪声）、state-matched 对照、已知 K-only、重标定、按批分组重拟合、S 置换、A1 冲突信号、A2 约束（逻辑排除的冲突不进 F3）。
- **主检验**：状态操纵 × 条件对符号的交互（混合效应模型/分层符号检验）；预注册方向；状态操纵检查（必须检出可测状态变化，否则 `manipulation_failed`）；MDE 按 pilot 噪声与 2 比例功效预先算（预注册 δ_min；不给具体效应则先 pilot）。
- **Phase 2（仅当 Phase 1 通过）**：固定更新器，比较"状态条件化冲突信号 + 补测动作" vs 普通残差/不确定性/距离/GP/后验方差/整板设计（BATCHIE/PDBAL 类动作距离）在同预算/同成本下的未测选择净收益；预注册 MDE/δ_min/停止；不宣称决策收益除非区间排除最小无用区间。

## 7. 停止/升级条件（冻结）

- 停：Phase 0 设计体检不过 / flip≈噪声地板 / M2 无增量且 MDE≤δ_min（阴性有效）/ M4 或重标定完全解释（F1/F2）/ Phase 1 状态操纵失败。
- 升级：Phase 0 出现 `missing_state_supported` 且 MDE≤δ_min → Phase 1；Phase 1 支持 P5 且决策相关初测成立 → Phase 2。
- 任何阶段：若区间不能排除最小无用区间，写 `inconclusive`，不写"不存在/无效"。
