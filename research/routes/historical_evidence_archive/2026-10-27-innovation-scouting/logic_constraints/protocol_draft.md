## §1 对象与目标

- 科学目标（主线的 A2 半边）：把共享关系写成**可被少量功能反馈否定**的约束库，并预注册一套判别式，把违反归入三类失败——(I) 数值需调整；(II) 共享关系适用条件失效；(III) 表征遗漏关键状态；用于**未测药物选择**（不用于机制/临床）。
- A1/A2 分工：A2 提供 `(约束, 违反统计量, 归因, 探针候选)`；A1 提供更新器与冲突信号处理。**A2 不实现、不评估更新器收益**。
- 非目标：新算法首创；同靶点=同功能；通路=机制；任何湿实验；任何"阴性=不存在"。

## §3 约束库（冻结候选）

**进入主检验（3 条）**：
- **C2 通路对交互方向跨语境共享**：前件 = (A,B) 的路径注释对；Π = 两者通路水平在训练侧均已观测（C149）且两药身份缺失/部分缺失（C130 regime）；B = 交互（主端点）符号与等级；T = 组内符号一致率/组均值秩相关；N = 通路标签在药物间分层置换（保组大小/药物类型）；违反 → I/II/III 判别（§5）。
- **C3 通路替代性先验的适用条件**：前件 = 通路共属组；Π = 两药身份均缺失 ∧ 水平已观测 ∧ 覆盖非零（C150 双峰→只取被 >200 行覆盖的水平）；B = 组均值排序对未测药对的信息；T = both-unseen 子集上的增量 ρ（与 identity/尺寸匹配随机比）；N = 药物↔通路映射打乱 + 尺寸匹配随机块；**C3 若被推翻→删除注释关系**（不是调整数值救）。
- **C5 单药解释界**：前件 = 同 cell 的单药读数；Π = 单药剂量/匹配条件可比；B = 交互与加性基线的偏差有界、且交互与单药读数有可解释份额；T = 交互方差份额/偏相关（δ_min=0.10 预注册）；N = 打乱 pair↔单药配对；违反 → II（若随条件变化）或 III。

**门控检验（决定约束是否可用）**：
- **C1 同靶点≠同功能（否定性门控）**：T = 同 target 组内单药功能谱相似度 − 匹配零；若 ≤ 零分布上 95% → **C1 推翻**，删除靶点级关系（只保留通路级；**禁止"同靶点=同功能"硬约束**）。

**不进主检验（冻结时登记理由）**：C4 组织适用性（GDSC 仅 3 组织且组织×通路稀疏；DrugComb 无组织列）→ 仅作探索性子分析，不作主判定；C6 注释谱系（argmax 单标签 + 并列率高，降为描述性）；C7 浓度条件（R2 无浓度数值列；GDSC 可部分做但只作分析性）；C8 已测药对先验（同源泄漏）；C9 独立培养（不可得）；C10 靶点占据（不可得）。

## §4 统计量与零分布（写死）

1. 违反统计量 `V_k`：组内一致率（C2）、增量 ρ（C3）、方差份额（C5）；均给 **95% bootstrap CI**（按药对 2,000 次；次口径按细胞）。
2. 零分布：置换 ≥1,000 次；置换必须**保持**：组大小、药物类型分层、水平可观测性；报告置换零的 95% 分位与 p。
3. 多重比较：每个约束族内 BH q=0.10；跨族不做合并 p，分别报。
4. 显著违反 = CI 排除 0 且 p_BH<0.10；否则记 `no_significant_violation`（不是"关系成立"）。
5. 所有区间/检验按**预注册单元**；不把 cell×pair 当独立，不做 iid 近似（C174）。

## §5 三类失败判别式（预注册阈值）

对每个显著违反 `V_k`：

| 类 | 判别式（全部满足才归该类） | 更新动作（A1 执行） | 反例/混淆 |
|---|---|---|---|
| **I 数值** | 保持符号/等级；≤2 标量参数重估后 CV 违反率下降 ≥50%；外推方向不变 | 调整数值层参数 | 若重估后符号翻转 → 不是 I |
| **II 条件** | 违反随 Π 变化：条件内一致率 − 条件外 ≥δ_scope（预注册 0.20）；条件内重估不能消解 | 收窄/改写 Π | 若条件外样本不足（每组 <10 单元）→ 不可判 |
| **III 状态** | 条件内、重估后仍违反；与预注册状态变量（谱系/组织/单药敏感度档/剂量档）分层相关 CI 排除 0；状态分层探针（每状态 ≥k=6 单元）复现 | 加状态表征 | 若与所有候选状态无关 → `unresolvable`（inconclusive） |

- 归因不可判率必须报告；不得把 `unresolvable` 写成"关系不存在"。
- **正对照**：向约束库注入人造 I/II/III 反例（每类 ≥20），判别式最小正确率 ≥0.60（设计体检 §8）；否则协议作废重写。

## §6 回放实验设计（下一轮，非湿实验）

- 反馈 = 从留出集抽取 k∈{6,12,24} 个 cell×pair（按药物分组抽，禁止同药跨支持/评估泄漏），只 reveal 主端点真实值给更新器；A2 只负责**选点规则**（探针 = 三竞争修订模型预测分歧最大者）与归因。
- 臂（同信息、同等 k）：① CVT（M1）；② 适用条件表（M2，低容量对照）；③ random；④ 方差/EIG；⑤ 无更新。每臂 ≥20 个切分种子（配对设计）。
- 主终点：三类归因正确率（在人造/复现的违反上）；副终点：未测药物 top-k 选择的后悔/命中（top-k k 预注册，如 10）；都报配对差 CI。
- **不**把支持集拟合优度、总响应相关、保持旧预测作为收益证据。

## §7 δ_min、MDE 与功效（数值口径）

- 秩水平 δ_min = **0.03**（沿用 P-B 口径，operational 理由来自冻结结论量级）。
- 已知 MDE80_two_way：r=0.20 → **0.1149**；r=0.40 → **0.0614**（[P-B 报告](../2026-10-27-drugcomb-endpoint/report.md) §14/§21；该报告判定 `endpoint_not_usable`，此处只借用其**测量体制/MDE 口径**，不重开其判定）。
- 本协议的归因正确率 MDE：**预注册模拟**（参数取 §4 零分布与 §6 样本量），不做 iid 近似；MDE 必须 ≤ 预设最小有用效应（δ_min_attr = 0.15 正确率绝对差，operational）才允许执行；MDE 报 80% 与 95% 两档。
- 报告必须含：实际扫描范围、失效类别、MDE、停止原因。

## §8 设计体检（先于任何效果/回放）

1. 零数据置换零校准：type-I ≤0.10（≥500 次模拟）。
2. 人造 I/II/III 注入：判别式每类正确率 ≥0.60，且不可判率 ≤0.25。
3. 探针分歧：三修订模型在候选池上的预测 Spearman <0.95 且 top-10 集合不完全相同（否则"探针"无区分力）。
4. 违反存在性：开发池中 C2/C3/C5 各自显著违反数 ≥5 个可分析组；否则问题在该资源上不可回答（`design_uninformative`，不得报阴性）。
5. 覆盖/依赖检查：每组 ≥10 单元；按药对聚类有效 n 报出。
- 任一失败 → `design_invalid`，不执行回放。

## §9 泄漏与可比性防护

- 约束只用训练侧数据估计；反馈只能来自留出集且只 reveal 被选单元；评估标签不参与选点/超参。
- 内层 CV 按药物分组选参（R163 教训）；不按行调参。
- 同信息强基线：无更新、全量重训、普通残差 ridge/GP、置换零；各臂共享同一来源/表征/支持标签/调参预算/板成本口径。
- 端点、切分、k、δ、判别式阈值一次冻结；禁止事后换端点/换聚合救结论（P-B/C167 教训）。
- 打乱映射零（C97 式）、尺寸匹配随机块（C152 式）必须同时报。

## §10 失败类别与停止条件（写死）

- 失败类别：`leakage` / `coverage` / `power` / `construct` / `dependency` / `degeneracy` / `design_informative_fail`。
- 停止条件（任一满足即记录，不救）：
  1. 设计体检 §8 任一失败 → `design_invalid`；
  2. H-A2.2：所有显著违反都归 I（CVT 相对仅数值重估无增量）→ **停约束迁移主张**，退回数值更新；
  3. H-A2.1 在 MDE 内无差（MDE ≤ δ_min_attr 仍无差）→ 不发展 CVT；
  4. 打乱注释映射零上 CVT 优势不消失 → 判 `leakage`，停止；
  5. C1 被推翻 → 永不用靶点级硬约束；C3 被推翻 → 删除注释关系；
  6. 资源门（每组 <10 单元 / 组织映射不可得）→ `inconclusive`，不报"不存在"。
- 即使全部预期成立，也只能报"在本资源、本切分、本端点下，约束违反的三类归因可被少量反馈识别并改善未测药物选择"，**不得升级为机制/临床/新颖算法**。
