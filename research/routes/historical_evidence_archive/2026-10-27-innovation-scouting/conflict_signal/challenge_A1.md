## 2. ① 三类签名是否真可区分

### 2.1 构建性反例复核（A1 spec §4）：**算术成立，PASS**
用只读脚本复算（`tmp/challenge_A1_checks.py` B 段）：
- X=(20,10,30,20)：Q=**0**，相对常数参考残差范数 **14.142**，加性模型残差 **0.000**（精确可被细胞+条件加性吸收）→ 残差大但**不是**关系冲突。
- Y=(10.5,10.0,10.0,10.5)：Q=**+1.0**，相对常数参考残差 **0.5**，加性残差 0.5；per-cell 差 c1=+0.5、c2=−0.5（**符号翻转**）→ 残差小但关系被违反。
- Q 对比权重 (+1,−1,−1,+1) 对细胞主效应/条件主效应正交（每细胞权重和 0、每条件权重和 0），故 `C_conf` 与 nuisance 方向可分离（D 段）。
- "同一 C_conf 不同 J_min"：已复核可构造（3 条件 2 细胞：case1 `Q(p,q)=1, Q(p,s)=0` vs case2 `Q(p,q)=1, Q(p,s)=1`，`C_conf` 同为 1、J_min={r1} vs {r1,r2}）。
- **判定**：A1 的"关系冲突不是残差/距离/leverage 的改名"在这一层**成立**；spec §4 注"只证明量不是同一件事，不说明真实数据存在任何一类"是诚实的。**这一部分 PASS，是本规格最值得保留的内容。**

### 2.2 `X_flip` 的最小可辨识设计：**FAIL（算术不可能）**
spec §2(ii) 判据要求"被违反关系在 S 的 **≥2 个独立上下文**中的符号/排序一致翻转率（相对参考上下文）；要求**二项检验下显著**"；§2.1 最小设计写"关系集覆盖 S 中**至少 2 个上下文**×至少 2 条件"。
- 若每个上下文给出一个符号，n=2 的单侧最小 p=**0.25**；n=3→0.125；n=4→0.0625；**n=5→0.03125**（脚本 A 段）。即按写死的"≥2 上下文"设计，`X_flip` **在任何真实数据上都不可能显著**，必然触发 `not_identifiable` 或被迫改判据——这违反"冻结后不得事后调整"。
- 且 `X_flip` 无功效/MDE/最小 n 预注册；上下文间相关（同细胞/同 screen）会进一步降低有效 n。
- **必改**：把"≥2 上下文"改成"**n_min 个可分辨、可复验上下文，n_min 由预注册功效推导且 ≥5**（或改用每上下文配对差+按细胞/药对聚类的 bootstrap/置换零，并把 n_min 与 type-I 校准写死）"；同时把 `X_flip` 的零分布与多重比较（多条关系）写死。

### 2.3 单批反馈不可分类与 `not_identifiable` 出口：**WEAK→需写死**
- 优点：spec §2.1 明确"单上下文/单测量组/状态不可测 → 必须输出 `not_identifiable`，不得分类"；protocol §5 列了不可判条件；这比硬分类诚实（PASS 部分）。
- 问题（**致命**）：
  1. **无上限、无成本**：`not_identifiable` 与 spec §5 的 `ambiguous_conflict` 都无预注册允许比例（例如 ≤10–20%），没有"超过上限即判设计无效/停止"的规则 → 任何失败都可用它退场，分类主张不可证伪。
  2. **无"注入类恢复"体检**：协议没有要求先用**人造的 (i)/(ii) 反例**（如 spec §4 的 X/Y）注入反馈流程，验证判类器能按预注册正确率回收；没有这一步，"能区分"从未被 constructively 验证。
  3. **不可判的边界未与"测量不足"区分**：`not_identifiable` 应绑定"所需追加测量/所需预算"（M2 有这个思想，但协议未把它写成 `not_identifiable` 的必填字段与后续动作）。
- **必改**：`not_identifiable`/`ambiguous_conflict` 必须预注册上限、触发条件、必须附"追加测量清单/预算"；上限触发即按失败类别停止（不是继续换判据）。

### 2.4 第四种解释缺失与分类顺序偏置：**FAIL→WEAK（可通过必改修复）**
- 三类 taxonomy（spec §2）**没有**"模型/噪声/区间设定错"这一类；spec §5 M1 仅在"释放代价超上限"时才转"（iii）/噪声模型失败分支"，而协议 §6 失败类别表里**没有 `model_misspecified` / `noise_model_invalid` / `interval_miscalibrated`**。后果：一个错误的噪声模型、错误的 σ、或参考区间 winner's curse 造成的不可行，会被判成 (ii) 关系冲突或 (iii) 表征遗漏，而不是"设定错"。
- M1 顺序规则（先解约束；不可行→最小释放；释放代价小就 (ii)）在**小 S** 上几乎总能找到一个廉价释放（释放 1 条关系通常可行），即 **`J` 非空几乎恒真** → 分类**系统性偏向 (ii)**。没有对称的多解释模型比较（i/ii/iii/设定错各自的复杂度/代价/留出改进），(i) vs (ii) 不是"可区分"，而是"更便宜的修复先被选中"。
- `χ²(S;θ') ≤ q_{1−α}(χ²_{|S|})` 用 **iid |S| 自由度**，但 S 内单位共享细胞/药对、且 Q 型对比是 dyadic（C174 已给出 dyadic 方差与独立边近似差 ~10.33× 的确定性反例）→ 阈值不可用；σ 估计的不确定性也未传播。
- 另：class (i) 的 `||P_Aδ||/||δ|| ≤ ε` 与"可行+残差在噪声内"并不等价：区间约束下，合法更新可沿关系行空间在 slack 内移动（非 nuisance），会被 ε 规则误杀；`d_rel` 应降为描述量，不作为判类必要条件。
- **必改**：加第四解释（合并为 `setup_error` 或写进 (i) 的"设定重估"分支）并做**多解释比较**（预注册复杂度/代价/留出拟合）；χ²/σ 用**聚类/依赖感知零分布**与 σ 不确定性敏感性；`d_rel` 降级。

### 2.5 其它
- `R_abs`/`L_lev`/`C_conf`/`J_min` 的**独立性只是构造性**；spec §7 P7 把"真实数据上是否可分"列为可证伪预测（诚实，PASS），但协议没有为 P7 写判据（两个独立评分流程的**不一致裁决规则**缺失）。

## 3. ② 机制 vs 先例

### 3.1 M1 PRU-CC
- **先例披露诚实（PASS）**：prior_art §1.1 明确 AlphaEdit 是"保护旧输出/零空间"，线性移植=约束回归/投影核；§2 表明确"约束回归/不可行诊断/最小释放集=数学常规，不主张算法新意"。这一层无可指摘；**不等于**机制有增量。
- **等价性表述有数学漏洞（WEAK→必改）**：
  - AlphaEdit 的"精确保护旧键输出"对应**等式约束** `a_r^Tθ = a_r^Tθ_old`，其（高斯线性、固定先验）后验均值恰为**投影核/核岭回归**形式；
  - M1 用的是**区间约束** `l_r ≤ a_r^Tθ ≤ u_r`（保护"误差带"而非精确输出）。区间版即使"不释放"，只要某约束**激活（binding）**，解就**不等于**投影核回归（是 truncated-Gaussian/QP 解）；只有约束全部**不激活**时才退化为普通 ridge。
  - 因此 protocol §3 第 5 条"投影核等价控制…必须与 M1 无释放情形数值等同，若不等同需解释实现差异"**在区间版下不可能要求"数值等同"**——需要改成两个明确对照：(a) **等式保护投影核**（AlphaEdit 精确对应）；(b) **同区间约束、无释放的 constrained ridge**（隔离"约束"与"释放"的作用）。否则"投影核等价"会变成一个不合格的稻草人对照。
- **缺对照臂（必改）**：除 (a)(b) 外必须加 (c) **soft-penalty/层级先验**（把关系当先验惩罚，而不是硬约束）——否则 M1 的增量可能只是"硬约束 vs 软先验"的已知差异，而非"冲突证书/释放结构"。此外把"关系全部保护、不释放"与"释放"分别报，才能说 `J_min` 结构有增量。
- **增量位置需重写（防循环）**：P1 声称"控制 R_abs/L_lev/后验方差后，C_conf/J_min 预测普通更新的退化"。但"退化"的定义依赖 U 的真实结局（评估时才有），且 C_conf 在构造上就与"关系被违反"同源 → P1 有循环/近似同义反复风险。**必改**：把 P1 明确为"评估期诊断量对基线退化的**样本外**预测增量（预注册嵌套模型 + 置换零 + 尺寸匹配）"，并声明它不是机制收益的替代；机制收益只看 P2（J_min 释放 vs 同尺寸随机释放）与主指标。
- **计算可行性**：最小释放集是**基数/代价约束的可行性恢复**（一般 NP-hard；IIS/MCS 诊断是常规操作但精确最小集非多项式）。spec 未写规模（关系数、|J| 上限）、近似算法与保证 → freeze 前必须写死近似方案（如 greedy/LP 松弛 + 上界）与运行时间预算。
- 结论：**M1 = 约束最小二乘 + 不可行诊断/最小释放 + 诊断证书的组合**；机制成分全部有先例（数学常规 + AlphaEdit 启发），**没有可主张的算法新颖性**；其科学价值只能由"释放结构是否改善未查询决策"（P2）与"诊断是否样本外预测退化"（P1，改写后）来承担。

### 3.2 M2 DPG
- **与 Poke&Strike 的差异是真实的（PASS）**：Poke&Strike 是 RL 参数辨识的 task-informed exploration，依赖仿真特权真值；M2 删掉仿真真值、用可购买菜单/动作翻转概率/拒绝购买，差异成立（prior_art §1.4 已登记其不能支持什么）。

## 4. ③ 关系集/可执行性（**FAIL**）

**做对的部分（PASS）**：protocol §2 给出 Q 型对比构造、nuisance 正交检查、分半误差带、"不得用 S 增删关系"；record 明确"关系集尚未构造，是冻结前独立步骤"；§6 `data_unavailable` 写了"关系集/φ/成本无法冻结→停"。**前置条件有意识**。

**不可执行的部分（必须修）**：
1. **无定量验收标准**：`R_max=若干条`（protocol §2）没有数字；没有 `R_min`、每条关系的最小上下文数、分半稳定性阈值、误差带宽度上限（相对 σ 或对 U 决策的影响）。没有这些，"关系集不可构造"无法被判定，冻结无法通过/失败。
2. **关系单位与 `Cond_r` 未定义（最重要的科学漏洞）**：Q 型对比是"2 细胞×2 条件"的 dyadic 量。如果一条关系只是"某个四元组的 Q 区间"，换一个细胞就会变；在 Jaaks 里细胞是不同细胞系（组织只有 3 类），**普通细胞异质性会被读成"关系适用条件失效"**。关系必须定义在**细胞组/方向/剂量布局的可预注册类**上（如"同一组织×同向×同剂量布局内的 Q 的组均值/收缩估计 + 细胞级随机效应"），`Cond_r` = 该细胞组，并写死**新 S 是否在 Cond_r 内的判定规则**。否则 (ii) 与噪声/异质性不可分。协议现文只说"显式检查 nuisance 正交 / 按细胞级分半"，没有给池化单位。
3. **S 与参考可能不 disjoint（泄漏）**：§1.3 说"参考对象只在开发参考集上构造（不得含 Validation 反馈批）"，而 S "从开发资源里按响应盲规则抽取"。若参考与 S 都取自 Original 且参考用了 S 的单位，则 S 的 y 已进入关系/θ_old 估计 → 反馈独立性被破坏。**必改**：写死"参考构造单位 ∩ S = ∅"（例如按细胞或四元组分组切分），或参考=Original、S=Validation 并**显式披露 screen 混淆**（不能同时声称独立测量）。
4. **区间估计的 winner's curse**：用"两半同向且 |统计量| 超阈值"挑关系，再在同一参考数据上算误差带 → 区间过窄、C_conf 虚高。**必改**：构造半（选关系）与校准半（估区间）分离，或对区间做选择校正（如 split-half 交换、bootstrap 校正）。
5. **Jaaks screen/批次不可分（继承 R193-A0）**：Original vs Validation 的 barcode 交集=0、screen 与"独立组"完全混淆（A1 record/spec 已引）。`C_conf`/`X_flip` 若用跨 screen 反馈，无法区分"关系适用条件失效"与"换 screen 的系统偏移"；协议目前没有把 screen/批次放进 nuisance 子空间或对照。**必改**：把 screen/batch 作为显式 nuisance/对照（如 same-screen 内验证 + screen 交换敏感性），或明确 Stage 1 只在 within-screen 做分类（则 S 与参考同 screen → 又回到第 3 点，需要 disjoint 单元切分）。
