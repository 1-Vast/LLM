## 0. 边界与不变式（不变）

- **不声称新颖性**：机制成分（约束最小二乘、不可行诊断/最小释放集、投影核/核岭、VOI/决策聚焦设计、层级/GP 更新）均有先例；M1/M2 是组合与评估对象，不是新算法。见 §9 的 v2 先例补充。
- **不越 C141/C154/C160/C167/C171/C172/C174/C175/C176/C177 边界**：只排组合不排细胞（C141）；主动学习阴性只在其粒度/资源内（C154）；细胞状态分支停于检定力非"无信息"（C160）；R192 `not_replicated` 非阴性（C167）；R193-A1 `inconclusive` 非阴性（C171）；1.43% 仅加性条件主效应份额（C172/C174）；R195 `not_qualified` 只对冻结大规模门槛（C175）；R196/R197 已作废（C176/C177），本设计**不复活**它们。
- **三类失败的归类是 `operational 归因`（operational attribution），不是已证实的生成原因**；报告措辞模板见 §10。
- 本版相对 v1 的关键修订：(a) X_flip 可成立（n_min/MDE/多重比较）；(b) 第四解释与多解释比较；(c) 关系集可执行/无泄漏；(d) 机制对照补齐与 P1 去循环；(e) 协议可执行性。

## 1. 设定（修订后）

- 单位：`u=(c,p,d)`；c=细胞（归属预注册细胞组 g(c)）；p=有向药对 anchor→library；d=剂量布局；端点 y（冻结列，候选 `SYNERGY_DELTA_EMAX`，须先过端点可比性/饱和性协议）。任何换端点=新轮。
- 表征 φ(u)（购板前可得；细胞基线特征 + 药物/药对粗注释 + 设计元数据；不得含反馈）。
- 参考对象：固定预测器 f_old=φᵀθ_old 与**审计关系集** R_old（施工与验收见 §5、[relations_check_design.md](relations_check_design.md)）。
- 新反馈批 S（响应盲抽取；与参考**构造单位不相交**，见 §5.3）；未查询菜单 U（固定动作/成本/效用；C141：U 是**组合**菜单，不排细胞）。
- 噪声：σ_S 及其不确定性区间 `[σ_lo,σ_hi]` 预注册（由参考重复/技术重复估计，不得用 S 自身调 σ）。
- nuisance 空间 `N = span{细胞主效应, 药对主效应, 剂量主效应, screen/batch 主效应}`；关系对比 `a_r` 必须对 N 正交（构造检查写死）。**screen/batch 一律进 nuisance**（见 §5.4）。

## 2. 四类 operational 定义（v2：三类失败 + 第四解释）

### (i) 数值调整（numeric adjustment）
存在 θ'=θ_old+δ 使：
1. 所有关系满足（区间 + 噪声容差 τ_r）；
2. 反馈拟合可行：`r_num = χ²_dep(S;θ') ≤ q_dep`（**依赖感知零分布**，§3.2）；
3. 更新在 nuisance 空间占优：`d_rel = ||P_Aδ||/||δ||` **仅作描述量**（v1 曾把它当必要条件，区间约束下合法更新可沿关系行空间 slack 移动，会误杀；v2 降级）。

### (ii) 共享关系适用条件失效（relation conflict）
在 S 的预注册适用条件（Cond_r，§5.2）内，存在关系 r 使：
- **关系空间违约**：`C_conf,r = dist(a_r^T y_S, [l_r,u_r]) / σ_r` 超过预注册阈值，且该违约不能用 N 吸收（a_r⊥N）；
- **跨上下文可复验**：在**≥ n_min 个可分辨、相互独立的上下文**中，被违反关系相对参考方向的**一致翻转**（X_flip）；上下文与独立性判定、n_min/MDE/多重比较见 §3.1；
- **结构**：最小释放集 `J_min`（规模上限 `J_max`，§6.3）非空且稳定；
- 判 (ii) 还必须满足 §4 的**多解释比较**（不是"有廉价释放就判 (ii)"）。

### (iii) 表征遗漏关键状态（representation missing state）——**本轮不判类，只输出 `proxy_only`**
v1 已声明 (iii) 在现有组合资源不可认证（无配套可测状态）。v2 保留为**诊断代理旗标**：全释放后结构化残差 + `O_rep` 高；**计入类判定需可测状态 z 且通过留出增量（当前不可得）**。与 R198-A4（missing_state）协调：A4 的资源结论若给出可测状态，本 §的测量请求随之更新；A4 未成立前，任何"三类已区分"措辞禁用。

### (iv) 设定错误（setup_error，新增第四解释；对应挑战必改 2）
噪声模型错设、σ 错估、参考区间 winner's curse/区间错估、未知批次效应。签名：
- **区间覆盖诊断**：参考区间在留出校准半上的覆盖率显著低于名义水平（如 95% 区间实际覆盖 <90%）；
- **σ 不确定性敏感**：分类结论在 `σ ∈ [σ_lo,σ_hi]` 带内翻转 → 不能归 (ii)/(i)，归 setup_error 或 `ambiguous_conflict`；
- **残差诊断**：残差方差随细胞/药对/批次系统变化（异方差/聚集），iid 模型被拒；
- **释放后残差仍可由批次解释**：加入批次 nuisance 后 `C_conf` 消失。
**setup_error 不是"失败"**：先做设定重估（区间/σ/批次重估）；重估后若关系仍被违反，再进 (ii)。
失败类别写死为 `model_misspecified`（含 `noise_model_invalid`/`interval_miscalibrated` 子标签，见 protocol_v2 P6）。

## 3. 可区分对照量与可成立的判据（v2 核心修订）

### 3.1 X_flip：n_min、MDE、多重比较（修复 v1 FAIL）
- **上下文**：一个"上下文"= 预注册可分的（细胞组对, 方向, 剂量布局）中的一组独立复验单位（如同一 Cond_r 内的一个 cell-pair 组），上下文之间不得共享细胞/barcode（独立性规则见 relations_check_design §4）。
- **n_min = 12**（写死）：每个被检验关系至少 12 个相互独立上下文。理由（精确算术）：n=2 时单侧最小 p=0.25（挑战指出）；n=5→0.031；n=12 时，k≥11/12 翻转的精确单侧 p=0.00317，k=12 时 0.000244。
- **主判据**：每个关系用**精确单侧符号检验**；α=0.01（每关系）；并在被检验关系族内用 **Benjamini–Hochberg FDR q≤0.10** 控制多重比较；只有通过 FDR 的关系才可进入 (ii) 的候选集。
- **MDE（写死）**：n_min=12、α=0.01、真实一致翻转率 p1 下的功效：p1=0.95 → P(X≥11)=0.882；p1=0.90 → P(X≥11)=0.659。因此**预注册 MDE = 真实一致翻转率 0.95 时 80% 功效**；若事前预期 p1<0.95，必须按模拟增大 n（或预注册降低主张，不得事后放宽 α）。
- **敏感性统计**：若用连续量（上下文级 Q 的符号加权均值），用细胞/药对聚类 bootstrap（≥2,000 次）+ 预注册置换零（打乱上下文标签），效应量 δ_flip 与 MDE 用同一聚类结构模拟；结论必须与符号检验一致，否则 `ambiguous_conflict`。
- 关系族规模：**预注册 primary 关系 ≤10 条**（Holm/FDR 在此族内）；其余为 exploratory（BH q≤0.10，只报告不参与判类）。这样避免用 R_max=200 的搜索空间制造"显著"。

### 3.2 χ² 与 σ：依赖感知零分布（修复 v1 iid 问题）
- 单位共享细胞/药对/底层键：`Q` 是 dyadic。v1 用 `χ²_{|S|}` 自由度不可用。v2 写死：
  - 零分布 = **按细胞与药对双层聚类/块置换**（block bootstrap / permutation，≥2,000 次）；或
  - 用**设计效应方差膨胀**：`Var_eff = κ · Var_iid`，κ 由参考数据估计（C174 的确定性例示：词典定向对比的 dyadic 方差与独立边近似可差 ~10.33×；因此 κ 必须从数据估、不得取 1）；
  - 阈值用对应零分布的 (1−α) 分位；`χ² ≤ q_dep` 才判 (i)。
- **σ 不确定性**：σ 取 `[σ_lo,σ_hi]` 带内网格；分类（i/ii/setup/ambiguous）必须在全带内一致，否则 `ambiguous_conflict`（记录翻转的 σ 边界）。
- `d_rel` 降级：仅作描述/诊断，不参与判类硬条件（见 §2(i)）。

### 3.3 判类禁止顺序默认（修复"系统性偏向 (ii)"）
- 预注册四个解释的候选模型族：
  - M_i：仅 nuisance 更新（无关系变化）；
  - M_ii(J)：释放关系子集 J 的更新（J 从预注册候选族/最小释放算法生成）；
  - M_setup：区间/σ/批次重估后的更新；
  - M_iii：状态增广（仅代理，不计入判类）。
- 用**同一数据、同一预算**比较：预注册准则 = {样本外预测拟合（留出上下文/细胞）, 惩罚复杂度（J 的规模/代价, 设定重估维度）, 决策相关量 Δ_pred(U)}；以 penalized fit（如 dyadic 有效 n 的 BIC/WAIC 型）同时评估；**不允许"先看不可行→选最便宜释放"**。**释放廉价本身不是 (ii) 的证据**；必须有可证伪对照：与同尺寸随机释放、soft-penalty、无释放 constrained ridge 比较（§6）。
- 若 M_i 与 M_ii 的惩罚拟合差小于预注册 δ_fit，或不同解释对 U 的预测不同 → `ambiguous_conflict`（不是 (ii)）。

## 4. 关系集（v1 FAIL 的核心修订）

### 4.1 关系单位与 Cond_r（避免把细胞异质性读成关系失效）
- **关系 r 不是单四元组**：r 定义在**预注册细胞组 × 方向 × 剂量布局 × 端点**的类上：`r = (a_r, l_r, u_r, Cond_r)`；`a_r` 是 nuisance-正交的 dyadic 对比（如 Q 型权重）；`l_r,u_r` 是**该类内细胞级随机效应下的收缩区间**（不是单点）。
- `Cond_r` 写死为元数据可判定字段（细胞组标签、方向、`ANCHOR_CONC`、`LIBRARY_CONC`、端点），**不得用响应值定义**。
- S 的新单位只有在 `u ∈ Cond_r` 的判定规则通过时，才可用于检验 r；否则该单位对 r 记 `out_of_cond`（不计入也不判失败）。

### 4.2 定量验收（写死数字）
- `R_min = 20`（少于 20 条通过验收的关系 → `data_unavailable`，停）；`R_max = 200`（搜索空间上限，防止多重比较膨胀）。
- 每条关系：独立上下文数 ≥ `n_ctx_min = 12`（与 §3.1 一致）；**构造半/校准半分离**（见 4.3）。
- 稳定性：构造半与校准半方向一致率 ≥ **0.90**（≥10/12 且两半交换后仍通过）；不一致→丢弃。
- 区间宽度：`w_r = (u_r−l_r) ≤ w_max = 2.0·σ_r`，且 `w_r ≤ 0.10 × 决策效用范围`（二者取更严者）；超宽→丢弃。
- 覆盖：通过验收的关系必须覆盖候选单元空间 ≥ **50%**（按 cell-group × 方向 × 布局计数；不足→`data_unavailable` 或缩小问题，不得放阈值）。
- 关系表在接触 S/U 响应**之前**生成并 SHA 冻结（`relations_check.json` + `relations.csv`）。

### 4.3 防 winner's curse
- 参考细胞按预注册分成 **构造半 A（选关系：方向/阈值）** 与 **校准半 B（估区间）**；交换 A/B 重跑一遍，只有两次都通过的关系进入 `R_old`；区间只由校准半估计；禁止在同一半上选关系又估区间。
- 分半种子/规则冻结；两个半的细胞组互不重叠。

### 4.4 S 与参考 disjoint（防同源泄漏）
- **主设计（写死）**：参考、S、U 的**细胞集合两两不相交**（同一 screen 内按细胞组切分；例如参考 64 细胞 / S 16 细胞 / U 其余）。这样 screen 相同、批次可作为 nuisance 对照，且 S 未被参考拟合。
- 可选**跨 screen 敏感性**：参考=Original、S=Validation（或相反），但必须**显式披露 screen/批次与"独立组"完全混淆**（R193-A0 已登记），该臂只作敏感性，不得当主设计。
- S 抽取规则（响应盲）、抽样代码、S 的键集合 SHA 在接触 y 前冻结；U 的读数代码级隔离，违反即判 `leakage`。

### 4.5 screen/batch 进 nuisance
- 主设计同 screen 内切细胞，screen 不成为混淆；每批/板/barcode 的批次作为 nuisance 协变量（或随机效应）进入 f_old 与更新器。
- 跨 screen 敏感性：两臂分别做 screen 内验证 + 交换 screen（A→B/B→A）敏感性；若结论依赖 screen → `conflict_only_in_development` 或 `ambiguous`。

## 5. 判据统计与对照（v2 重写）

### 5.1 M1 机制对照（§6.1）
M1 必须与下列对照同信息/同预算比较：
1. **等式保护投影核**（AlphaEdit 精确对应）：等式约束 `a_r^Tθ = a_r^Tθ_old`；在线性高斯+固定先验下其解=投影核/核岭；
2. **同区间无释放 constrained ridge**：同 `[l,u]` 约束但不做任何释放（隔离"释放"与"约束"）；
3. **soft-penalty/层级先验**：把关系当惩罚项（非硬约束）；
4. **尺寸匹配随机释放**：随机释放与 `J_min` 同尺寸/同代价的关系（P2 主对照）；
5. 全量重训、普通适配、层级模型、GP（沿用 v1 列表）。
**等价性表述写死**：M1 无释放情形只有在**等式约束且无激活约束**时才等价于投影核/普通 ridge；**区间约束有激活绑定时是 QP 解，不等价**——因此不得要求"数值等同"，只要求报告差异并证明实现正确（KKT/自校验）。

### 5.2 P1/P2 重写（去循环）
- **P1（降为诊断预测，不是机制收益）**：在**样本外**评估，`C_conf/J_min`（评估期诊断量）对"普通更新在未查询动作上的退化"的**增量预测**：预注册嵌套模型（基线 = R_abs/L_lev/后验方差；加诊断量）、置换标签零分布、尺寸匹配随机对照；报告 ΔR²/AUC 与 CI。若增量被基线解释→撤诊断主张。
- **P2（主机制检验）**：`J_min` 释放 + 保护其余关系 vs 同尺寸随机释放 vs 无释放 constrained ridge vs soft-penalty，在未查询决策损失上比较；只有 P2 出现可归因增量才支持机制。
- MDE/功效：Stage 1 的决策损失配对比较按细胞/药对聚类；预检 80%@δ_min；δ_min 定义见 protocol_v2 P5（未冻结→blocked）。
- **最小释放集算法**（写死规模与近似）：|R_old|≤200；精确最小释放集对 |R|≤30 用分支定界/LP，时间上限 60 s/单元；否则贪心 + LP 下界，报告 gap；`J_max = min(5, ceil(0.10·|R_old|))`；若 60 s 内无认证解 → `ambiguous_conflict`；运行时间/解规模入账。

### 5.3 M2 先例补充与对照（修复 v1 必改 4）
- 补充先例：decision-focused sequential design（[arXiv:2602.05340](https://arxiv.org/abs/2602.05340)）、GoBOED（[arXiv:2605.26093](https://arxiv.org/abs/2605.26093)）、EVSI/ENBS（决策价值 vs 样本量/成本，临床设计成熟框架）、Poke&Strike（[arXiv:2509.00178](https://arxiv.org/abs/2509.00178)）。
- M2 = "VOI/decision-focused design + 解释集辨识 + 拒绝购买规则"的变体；**Stage 2 对照必须含 VOI/decision-focused baseline**（不只 random/贪心/不确定性）；与 Poke&Strike 的差异：无仿真特权真值、用可购买菜单与决策翻转概率、在无合法区分测量时拒绝购买/拒绝宣称。
- Prior-art 边界：以上均**有先例**，M2 不主张新颖性；只检验"在无合法区分测量时必须拒绝"这一可证伪性质（P5）。

## 6. 三类/四类签名与数据可算性（v2 表）

| 签名 | 定义 | 类别 | 现有数据可算？ | v2 处理 |
|---|---|---|---|---|
| `R_abs` | 反馈相对参考的原始残差/σ | 非特异（四类都可能大） | Jaaks/DrugComb 可算（需下一轮） | 仅对照 |
| `C_conf` | nuisance-正交关系空间违约（dyadic 对比） | (ii) 必要 | Jaaks 匹配宇宙可算；需 §4 关系集 | 必须同时报 `R_abs`/`L_lev` |

| `setup_sig` | 区间覆盖/σ 敏感性/异方差/批次吸收 | (iv) 设定错误 | 部分可算（参考半） | 先重估再判类 |

| `r_state`/`ΔR²_state` | 全释放后结构化残差；加可测 z 的留出改进 | (iii) 认证 | **不可算**（无配套可测状态） | 只输出 proxy；依赖 A4 |
| `ℓ(f;U)` | 未查询动作决策损失 | 终局 | 需冻结 U/成本/效用 | Stage 1 主指标 |

现有数据映射（不运行）：Jaaks Original/Validation（R193-A0：6,223,367 匹配四元组、96 细胞/98 有向药对；剂量只到设计列、screen/批次混淆、单药参照待解禁）；DrugComb（R190–R192 边界）；BeatAML 单药；sciplex3/Tahoe 仅状态侧；ComboCat `unqualified`；O'Neil 独立培养不足。**本设计只用 Jaaks 参考数据构造关系（Stage 0）**；S/U 的细胞组必须 disjoint（§4.4）。

## 8. 机制候选（v2 更新）

**M1 PRU-CC**（受保护关系更新 + 冲突证书）：
- 状态/保护：θ_old；保护对象 = R_old（全部或预注册子集），区间 `[l_r,u_r]`；关系由 §4 验收。
- 更新：`θ_new = argmin ||W_S(Φ_Sθ−y_S)||² + λ||θ−θ_old||² s.t. l≤Aθ≤u`（λ 内层药物分组 CV；τ_r 噪声容差）。
- 冲突检测：依赖感知 χ²；多解释比较（§3.3）；最小释放集（§5.2）；证书字段 = {J, C_conf, X_flip, Δ_pred(U), setup 诊断}。
- 拒绝/回退：无认证释放/多解释对 U 预测不同 → `ambiguous_conflict`；全释放仍不可行 → setup 重估/`model_misspecified`/`not_identifiable`；单噪声驱动 → 不判 (ii)。
- **对照必比**：§5.1 的 (1)(2)(3)(4) + 标准基线。

**M2 DPG**（决策精度门控）：
- 候选解释集 E={i, ii(J), setup}（(iii) proxy 仅旗标）；对 U 每动作算 `[min_E U,max_E U]`；若 argmax 唯一且损失差 ≤δ_action → 提交最简解释（不买）；否则枚举可购买菜单 B，按"每成本决策翻转概率"选测量；**无任何 b 使 E 预测分布不同 → `no_discriminating_measurement`，拒绝购买/宣称**。
- 停止/精度：只要求动作区分精度 δ_action；预算上限冻结；所有成本/算力入账。
- **对照必比**：VOI/decision-focused（2602.05340、GoBOED、EVSI/ENBS）+ Poke&Strike 式精度；random/贪心/不确定性（Stage 2）。
