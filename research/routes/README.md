# Research routes

Navigate by scientific question. Route placement does not establish validation or reopen frozen stops. Each episode retains its original evidence scope; historical source IDs remain available through the [record reader](../../log/README.md).

| Route | Scientific purpose |
|---|---|
| [agent_virtual_cell_joint_learning](agent_virtual_cell_joint_learning/) | Shared executable response programs, M1/M2/M3/N1 synthetic contracts, feedback and joint-learning diagnostics. |
| [combination_resistant_transfer](combination_resistant_transfer/) | Combination response, unseen-drug annotation transfer, resource qualification, and parental/resistant transfer. |
| [coordination_and_tools](coordination_and_tools/) | Administrative handoff and local audit tools. DeepSeek task paths remain at research/deepseek. |
| [functional_prediction](functional_prediction/) | Ordinary cell–drug–dose–function prediction, calibration, dose/response relations and bounded replay. |
| [historical_evidence_archive](historical_evidence_archive/) | Registered historical implementations, residual records and caches; preserve frozen identities and inspect registry before retirement. |
| [identifiability](identifiability/) | R4–R188 sequence: what observed functional contrasts can identify, distinguish or reproduce. |
| [innovation](innovation/) | R189–R202 coordinated innovation rounds, hypotheses, challenges, approvals and scoped stops. |
| [literature_cross_domain](literature_cross_domain/) | Primary-source qualification and CV/NLP/robotics principles with explicit biological analogy boundaries. |
| [observation_acquisition](observation_acquisition/) | Paid observation, probe reuse, information cost, acquisition and decision value under matched budgets. |
| [target_engagement_mechanism](target_engagement_mechanism/) | Proximal engagement, genetic references, functional endpoints, induction/maintenance and mechanism qualification. |
