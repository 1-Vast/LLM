# R194/Q2 勘误（ERRATA，2026-10-27；依据独立重审 `research/2026-10-27-cross-domain-directions/late_results_audit.md` 与 Lead 对 q2.py 的核对）

> **状态**：C172 的**测量结果仍有效**（σ²_cond=0.000371、share=1.43%、p=0.001 等为已执行统计量），但其**解释与推断**必须按本勘误收窄；**不得**据此写"可迁移条件规律只有 1.43%""不应以条件级共享规律为前提"。本勘误不改变 A1 的 `inconclusive` 状态。

## 1. 1.43% 只是"加性条件主效应"份额，不是可迁移规律总量

- Q2 模型 `Q_ij = μ + a_i(condition-pair) + b_j(cell-pair) + c_ij + ε` 估计的是**与 cell-pair 无关的条件主效应**；目标中的背景依赖规律恰恰可能位于 `c_ij`（交互）中。
- **确定性反例（已核）**：共享秩 1 规律 `Q_ij = u_i v_j`，取 `u=v=(1,−1)` → 矩阵 [[1,−1],[−1,1]]，行/列均值均为 0（加性主效应恰为 0），但只要 `u_i` 可由购板前特征识别，规律完全共享、完全可学。**因此 1.43% 不能推出"只有 1.43% 可迁移"或"条件级共享规律可忽略"。**
- 正确读法：**在该加性分解下条件主效应份额小**；**残差 `c_ij` 是否由可复用背景×条件结构预测，A2 未检验**（需要低秩/层级/非线性强预测器 + 留出评估，见 R197）。

## 2. 加权矩估计的代数不一致（影响 bootstrap CI/SE，不直接改变当前未加权点估计）

- `q2.py` `moment_estimator` 计算条件对加权协方差时用 `Tc − 2μ Sc + μ² W2c`，其中 `Sc=Σ w y`、`Tc=Σ w y²`、`W2c=Σ w²`；若主张观测对权重 `w_j w_k`，排除对角项应为 `Σ w² (y−μ)²`，即需 `Σw²y`、`Σw²y²`。当前式**混用一次与二次权重**。
- 确定性例（已核）：`y=(1,3), w=(2,1), μ=5/3` → 正确加权观测对残差积 **−8/9**；代码式 **−37/18**。`w≡1` 时两式相同，故当前**未加权点估计不受影响**；但 **bootstrap CI/SE（以及建立其上的 power/type-I）** 需用修正式重算。
- 结论：C172 的 CI/可靠性/功效数字**不能按原样引用**；需重核（R197-A0）。

## 3. 依赖单位：435 个细胞对不是 435 份独立信息

- 固定条件对，`z_c = y(c,p)−y(c,q)`，则 `Q_ab = z_a − z_b`；同条件对的不同 Q 共享细胞与底层键：`Cov(Q_ab,Q_ac)=Var(z_a)`、`Cov(Q_ab,Q_bc)=−Var(z_b)`；同一 barcode 测量也被多个 Q 重用。
- **确定性反例（已核）**：对 n 个细胞的全部词典定向对比取均值，系数为 `(n−1−2i)/C(n,2)`，真实方差 `4(n+1)/(3n(n−1))·σ²`；n=30（435 cp）时与独立边近似 `2/C(n,2)·σ²` 相差约 **10.33 倍**。因此 **0.868 的条件级可靠性不是由"435 cp 平均"认证的实测可靠性**；需以真实节点/键依赖与测量层级校准。
- 另外：逐观测打乱 condition-pair 标签破坏布局/缺失/共享键结构；双向 bootstrap 把 229 cp / 1,501 cell-pair 独立重抽，不自动保留节点/键依赖；设计功效模拟只生成独立 a、b 与逐格噪声、且只校准 z>1.645 分支，不是"CI+置换+可靠性"完整规则。

## 4. 其它必须收窄的表述

- 噪声标定仅覆盖 **1.43%** 观测（1,312 个重复齐全回路），外推到全部 92,039 回路；分半/奇偶稳定性不足以证明跨细胞同方差/各键独立/独立培养。
- `int/noise ≈ 48.5%/46.1%` 是**该误差模型下的分割**，不是已测生物机制比例；不得当"交互 vs 噪声"的生物学结论。
- Validation 探索性条件级 Spearman 0.177（CI [0.055,0.296]）是有效报告的探索性数值；其 bootstrap 仍承受共享药物/细胞/条件依赖，**不能当外部复制成功**；也不能因"不参与判定"而说没有任何跨 screen 描述性观察。
- **下一步（R197）**：先重核 Q2 代数与依赖单位；再用低秩/层级/强预测器检验 `c_ij` 是否可由可复用背景×条件结构预测（留出细胞对/条件对评估）；没有稳定增量才停止该资源上的规律研究。
