# 第二 pass：原文原则到廉价功能药筛的映射

日期：2026-10-29。角色：候选暴露前中性结构 scout，不是终审。requested Sol/high；effective unknown。本轮初判 1 pass + 本次来源发展 1 pass，已用尽约定 2 pass；0 网络、0 科学实验/训练、0 原功能 CSV、0 安装、0 子代理。只写本文件，不选择最终机制。

## 原文使初判发生的实质改变

H-Net 与 DC-DiT 支持“表示粒度可依赖内容、内层计算不必平均分配”，但不支持“这种路由已经解决下一次测哪一个实验”。两者首先处理全部既有输入，再压缩内层表示，并保留向细粒度输出传递信息的路径。廉价药筛若没有相应实测点，不能借 dechunking 补出独立证据。

SimMLM 的决定性启发是把同一样本的不同信息集合拿来比较，但其具体约束不能原样搬来：它从完整训练模态出发、随机丢模态，并倾向要求每个样本更多模态的任务损失不更高。在药筛，缺测往往受历史选择影响；协议不兼容、低质量测量或冲突证据也可能使单个样本的结果变差或不确定性变大。应比较新增证据对明确定义的功能判断有无作用，而不能按信息件数强制排序。

因此，初判第一条“测量关系与可识别边界”仍是前提；第二条应拆开“既有数据的计算压缩”与“昂贵观察的选择”，不能让前者为后者背书；第三条应从“化学结构与功能对齐”进一步改成“在适用条件下，哪一类证据真正能改变哪个功能结论”。这些修正改变了监督和信息流，比新建一个多模态网络更具体。

## H-Net：改变的是可学习压缩，不是实验支持集

§2.1 的关键结构是 encoder → chunk → main network → dechunk → decoder，且 decoder 同时获得 encoder 的细粒度残差；main 可以递归为 H-Net。这里的粗细层是同一条已输入序列的内部表示，不是外部测得的群体统计与细胞系数据。

§2.2 的路由由相邻 encoder 表示投影后的余弦差构成，式 (4) 为 p_t=(1-cos(q_t,k_(t-1)))/2，阈值 0.5 选边界，首位置固定保留。downsampler 直接选边界位置向量；dechunk 的 EMA、因果重复和 STE 用于信息传播及可训练性；ratio loss 约束目标压缩率，和自回归目标共同优化。Footnote 7 特别说明路由量并未作为形式概率使用。因此，p_t 不能当作实验置信区间、缺测概率或生物证据充分性。

可迁移原则：代表点/粒度应由上下文与下游问题决定，固定平均池化可能丢掉边界附近信息；压缩后的推理仍需要保留细节与来源路径。

失效映射：字节相邻不等于细胞系邻近；SMILES 字符邻近也不等于功能连续。剂量有有序轴，但只观察少量剂量时，局部 encoder 看不到真实曲线转折，不能对未测区间做同样的“低信息”认定。H-Net 的语言训练目标更没有验证剂量单调、机制同一性或功能等效。

限制：作者 §4 讨论当前实现训练可能比 isotropic 模型慢约至 2 倍、动态显存与批处理问题，且未试 3-stage；这提醒要计端到端成本，不能用内层 token 降低替代墙钟或实验成本证据。该处是作者报告，未被本角色复现。

## DC-DiT：弹性计算预算有完整输入前提

§3.1 从已有 latent 图像 P=1 网格开始，encoder 已混合局部信息；router/elastic chunk 减少送入 DiT 的 token，保留原 2D 位置，dechunk 后加 encoder 残差，再输出扩散预测。不是先拍低分辨率图，再支付费用拍高分辨率图。

§3.3 根据局部 3×3 预测的瓶颈特征残差，经 scorer 得到边界概率。自然边界集 B={i:p_i>0.5}，tail dropping 仅进一步丢掉 B 中分数较低部分。同一 checkpoint 可改 rho 调内层计算；它没有评价另做一次测量带来的生物收益。局部“难预测”也可能是噪声；在药筛把大残差直接当作高价值补测点会把噪声与机制歧义混在一起。

§3.5 与 A.3 明确处理预算变化的训练分布偏移：先无 tail-drop warmup 5K，后从 {0,.1,.2,.3,.4,.5,.6} 均匀抽 rho；ratio loss 在自然边界集上算，任务损失跨预算训练。A.3 将 DC-DiT 总步骤配到对应 400K-step DiT 的训练 FLOPs，可因每步便宜而训练更多步骤。这里配平的是计算，不是独立训练样本、药物条件数或实验次数。

A.2 计算成本包含 encoder/router/decoder、各算子、采样步骤与 CFG 两分支，并按实际变长序列计 attention 而非 padding 最长序列。这可迁移为成本记账原则：不能只记选中的剂量数，还要记路由所用先验、预先拥有的全曲线、重复、批次、标签获取及 Agent 调用成本。它不是额外测量收益的证据。

可迁移原则：必须让训练/校准时的信息预算覆盖实际部署预算，并把压缩外围开销计入；任务无关的统一分辨率未必合理。但如果训练先拥有完整曲线再随机遮点，最多得到该完整屏内回放结论，不能自动覆盖真实选择性缺测或新批次。

## SimMLM：嵌套信息比较有启发，逐样本“更多一定更好”不能照搬

§3.1 明确假设训练集包含每个样本的全部 M 模态，目标是测试缺模态鲁棒性。§3.4 从同一个 full 样本随机生成严格嵌套集合 x− ⊂ x+ ⊆ x_full，并用同一个 y 计算两者任务损失。MoFe 为 max(0, loss(o+,y)−loss(o−,y))，总目标同时包含两组任务损失。这不是无标签一致性；完整配对和目标标签是承重条件。

可迁移的监督单位是“同一目标、不同可用证据集合”的配对，而不是把组织均值和细胞系标签强行对齐。这能直接问：给定既有信息，新证据是否改变该功能问题的可回答程度？

不能照搬的假设：

1. 便宜药筛通常没有完整配套组学/图像，不具备 full-modality 样本。SMILES 和协议可能可得，但单独协议往往不能预测该细胞药物的功能结果，不满足每模态均 predictive/complementary 的便利设定。
2. 随机 dropout 是人为的信息剥夺，真实未测条件常受预筛、药物可用性、浓度窗和实验选择影响。两者的缺失机制不同。
3. “更多信息的最优期望决策风险不更坏”不推出“当前模型每一个样本的实测损失都不更坏”。新增冲突重复可纠正先前错误自信；不应强制置信度增加、区间单调收缩或每例精度提高。
4. 从不同浓度窗/协议拿来的观测若改变了目标，根本不是同一个 y 上的嵌套信息集。拼入一张另屏曲线不能按“更多”加分。
5. 化学结构不是缺测 y 的另一个观测视角；它给的是条件先验。把部分已测功能点作为输入、同一曲线派生量作标签时，应冻结可见点和留出点，防止 full 标签回流。

§5 的 CR 指标将少模态结果更好视为 counterintuitive；它本身与训练约束方向一致，不能仅凭降低 CR 就证明真实选择性缺测下获益。作者在 §6 把 broader training-time missingness 列作扩展方向；supplementary 提及的附加实验本角色未读，不能断言论文完全未涉及训练缺失。

## 可发展的机制：以有条件功能可区分性决定剂量粒度

下面是一条具体开发线，而非最终推荐或新颖性结论。核心问题是：两个药物在指定细胞系、时间、读出与共同剂量窗内，现有证据能否判定一个预先规定的功能差异？把“所有点都拟合得准”改成“判定这个功能关系还缺哪一个可测观察”。它保留初判原则二，同时受原则一约束；化学结构是可移除的可选先验，不是核心。

**输入。** 同屏/可校准协议下，一个细胞系的两种单药已有实测 (浓度,读出,重复/噪声信息)，明确共同窗 W、时长和读出归一化；预先规定差异幅度 delta。目标例如“两药在 W 内的平均功能读出差是否超过 delta”。只使用已测点及其支持窗；无重复就明确噪声范围依赖外部校准假设。SMILES 指纹、组织先验不是必要输入。这里是药物差异判断，不是组合协同或分子机制识别。

**运算。**

1. 为每个药物建立与实测点及已声明误差规则相容的响应函数集合。最小实现可以是分段区间界；单调性只有在本数据端点与条件有依据时才加入，并记录去掉该假设后的结论。不能用一个窗外 Hill 拟合代替这个集合。
2. 在共同窗 W 上计算功能差的可行范围 [L,U]。若 L>delta，给出支持差异的条件化结论；若 U≤delta，则不能支持该幅度差异；其余标为尚不可判。区间覆盖率取决于误差模型与函数假设，目前没有“认证”证据。
3. 将浓度轴上所有可行函数对该目标给出相同答案的区域合并；只保留可改变目标结论的局部歧义。这个粗细粒度是“功能判断需要的分辨率”，不是 learned semantic token。
4. 若允许下一次实验，在事先枚举的可测浓度与重复动作中，比较每项动作消除目标歧义的预期收益/成本。预测分布尚无可靠依据时，只做保守最坏情形比较或列出无法排序，不能捏造信息增益。所有新增测量与重复计费；扩展 W 是一个新目标/新实测动作，不能默认为已有信息。

**输出。** 对这一细胞系与条件的功能差结论/尚不可判、结论依赖的浓度区间和实测支持、下一步应补哪药哪个浓度或哪次重复，以及不做实验时保留的不确定性。Agent 若存在，只负责执行信息边界、调用这些计算和记录动作；当前没有证据说明必须使用 LLM 或 Agent 才能获得该能力。

**区分预测。** 在具有完整实测曲线与可估噪声的公共屏内，冻结共同初始点，以等测量数/重复成本离线回放：目标相关分辨率应比均匀补点更早解决那些仅在局部发生决策分歧的样本；对高噪声样本应偏向重复，而不是追逐曲率。在结论早已由初始点决定、或所有可测点都不能区分的样本中，应停止并保留正确的确定/不确定状态。最关键的反例是：普通成熟的目标导向设计已经取得同等结果，此时没有独立机制增益。

## 与既有简单原则究竟差在哪里

| 比较对象 | 这条开发线的可明确差异 | 不能据此声称什么 |
|---|---|---|
| 标量“高/低保真”预测或常规 multi-fidelity BO | 不把组织统计、另一浓度窗和高剂量默认排成更高保真；首先要求同一功能目标和相容测量关系；选择动作以判定特定功能关系 | 成熟多保真方法也能容纳偏差、成本及目标依赖。这些要求若已被已有决策/level-set/robust design 覆盖，就不是新解决原理 |
| 最大预测方差/固定网格补点 | 对目标无影响的不确定区间可不测；重复与新剂量都作为候选动作，按同一目标比较 | 决策导向主动学习与最优实验设计本来就能如此，必须直接列作最强基线 |
| 普通条件化回归 | 除点预测外明确保留实测支持、目标可识别范围与尚不可判，并输出必要观察位置 | 条件化贝叶斯模型/形状约束模型配合适当决策规则可实现同样行为；单独加“尚不可判”标签不是创新 |
| 指纹邻近插值 | 核心不依赖结构相似，直接检验观测允许的功能关系；结构先验若加入必须可移除、单独计信息收益 | 仍无结构到功能的新迁移证据；如果指纹邻近已在相同条件下完成任务，就应降低该线的新颖性判断 |
| H-Net/DC-DiT 式 token 路由 | 粒度由特定功能事件的可判定性定义，选择的是真实可计费观察；不预先看到完整曲线来决定未测点重要性 | 源论文没有给出该功能可识别集合或实验选择方法，本线是待检验推导，不是源论文已验证的生物迁移 |

需要下一轮单独查新的目标领域术语至少包括：剂量反应 level-set estimation、active classification/threshold learning、目标导向或稳健实验设计、shape-constrained uncertainty、functional equivalence testing、带偏差与支持集约束的 multi-fidelity design。本轮未联网查这些原文，不能说“尚无人做过”。不要用新缩写替代这项查新。

## 另一原则仍须保留

与上述主动测量路线不同，仍保留“聚合信息能否识别单细胞系功能”的基础路线。它的下一步是核清组织统计的成员、权重、端点、浓度窗以及是否含目标本身，先分析前向聚合是否确定、哪些细粒度结论存在等价解释。即使完全不选择新实验，这也可能产出可用的边界或严谨负结果。H-Net 的递归层级并不使这一聚合逆问题自动可解；SimMLM 的 full/partial 配对也不能替代它。

当前最强结论是三篇原文帮助澄清了边界，并提供了表示预算、部署预算匹配和嵌套信息监督三个可检验原则；它们没有证明廉价药筛中存在新机制、Agent 必要性或超越成熟决策设计的能力。本轮第二 pass 完成，未选择最终机制，也没有科学实验结果。
