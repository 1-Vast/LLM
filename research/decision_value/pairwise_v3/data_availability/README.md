# Metadata-only source recovery

The pinned public source supports exact HTTP range reads. `AVAILABILITY.json`
records three complete-menu exposed training contexts and their condition,
plate, sample and QC coverage. All 12 initial payload hashes match archived
censuses; only 3,230,358 metadata bytes were downloaded.

`SOURCE_RECOVERY_PLAN.json` provides a precise low-cost control-only queue for
NCI-H661 and SW 1088. The two most frequent source plates cover 92/146 original
candidate bindings. After a second metadata pass, cumulative transferred
bytes are 5,083,146. The plan contains eight sample groups, 250 full-QC reference
cells and every future RNA byte span: 2,000,000 more bytes, for 7,083,146 total.
No expression or outcome byte was requested; no STATE inference was run.

The 39-gene variance study is blocked by the missing authenticated native
gene axis. The historical full-axis receipt names 1,969 coordinates and leaves
31 unresolved; it was established by matching X_hvg columns with log1p(raw X),
not by assuming source gene order. Recover the original identity JSON with
the registered hash or register a bounded equality audit on matched control
rows first. Keep null coordinates null. Until then, do not download control
RNA or claim a named-gene variance result. Cached replay inputs remain ready.

The plan is a metadata-verified acquisition queue, **not a preregistered or
completed RNA experiment**. `SOURCE_HASHES.json` captures provenance after
metadata retrieval; it is not a pre-outcome scientific freeze. A future
noise experiment must freeze its authenticated axis, source revision, row
selections, producer and endpoint before reading the specified RNA spans.

Sources are cheap in money and compute: no GPU, model training, API purchase,
or full multi-gigabyte HDF5 download is required. This narrow diagnostic asks
whether scalar gene covariance and reference-cell sampling need better
measurement-noise treatment. Sample/plate association cannot establish
independent cultures, functional effects, decision benefit or causal batch
variance fractions.
