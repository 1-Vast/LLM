# Decision-value development

This study freezes the existing STATE-ST forecasts and tests decision utility,
protected selection and admission separately. RNA is an RNA endpoint. No fitted
RNA-to-functional bridge, independent model-risk certificate or utility-unit
price is available for this packet, so the strict execution policy refuses A
purchases. Two explicitly uncosted shadow policies test model assumptions; their
Monte Carlo lower bound controls integration error only.

The full-menu experiment evaluates 43 complete reference contexts with strict
leave-one-context-out fitting and five already exposed target contexts. The other
two references remain masked training data and receive blocked evaluation records.
These are development units, not new independent STATE confirmation. Matched
no-screen and KG comparators use the same menu and maximum budget; no-screen
spends only five B units. Detailed source qualification is in [SOURCES.md](SOURCES.md).

Restore exact sources and packet2 files in `FREEZE.json`. In the maestro environment:

```powershell
D:/anaconda/envs/maestro/python.exe -m pytest research/decision_value/test_utility.py
D:/anaconda/envs/maestro/python.exe -m research.decision_value.validation --packet research/astra/boundary_acquisition_20261007/packet2 --out outputs/decision_value_validation_20261009
D:/anaconda/envs/maestro/python.exe -m research.decision_value.verify
```

The run refuses to overwrite an existing output directory. All model choices and
forecasts are saved before target evaluator opening. Only explicitly purchased A
scalars reach the decision code; B is scored after commitment. Canonical conclusions
belong in `research/EVIDENCE.md`; execution receipts belong in `log/20261009`.
The user-mentioned earlier validation package was absent locally. This registered
implementation does not claim to reproduce that package's pair-loss numbers.
