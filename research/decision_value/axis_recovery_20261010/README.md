## Why the compact calibration failed

The allocation protects rare positive detections, but identity requires a
distinct trajectory. Genes that occur in the same sparse cells can share
equal normalized single-count values. Negative/zero contrasts can discriminate
such genes, yet a positive-coverage objective need not select them. All 23 c44
and 16 c45 failures are nonunique matches; no unique match has the wrong expected
name, and no endpoint fails the registered nonzero count.

This is a calibration-selection defect and a remaining identifiability gap,
not proof that the historical names are wrong or the virtual-cell feedback
mechanism is biologically false. `calibration_v2/diagnosis/` contains a separate
post-result, offline-only support-pattern diagnostic. It cannot alter the frozen
certificate, validate unseen numerical values or authorize another RNA read.

That diagnostic finds unique binary support patterns for all 39 expected genes
in each full retained pool, versus 15/39 and 17/39 in the current discovery
panels. A deterministic heuristic proposes 11 extra discovery cells per file
while keeping holdout fixed. Its exact projected new paired cost is **340,068
bytes**; no additional values are read. Binary uniqueness is a selection proxy,
not a numerical certificate, and the proposed count is not a proven minimum.

The discovery/holdout split uses disjoint cells from the same source samples;
both sides were selected using CSR presence. Only their expression values were
withheld. This is a numerical consistency check, not independent culture-level
validation.
