# Pairwise correction under scarce feedback

This study tests whether one purchased RNA observation improves a decision,
rather than assuming that lower global prediction error or richer knowledge
must improve a candidate ranking. The original authenticated STATE prior is
fixed. This is development on the existing exposed scalar packet, not a new
pretrained inference run or independent biological confirmation.

The protocol defines 146 complete-menu actions, 43 evaluable backgrounds,
history sizes 4/8/16, three fixed nested history draws and nine boundary pairs
per episode. Eight historical backgrounds is the primary condition. Baseline
ranks 3--5 versus 6--8 and the one shared A action are fixed before target
observations. All feedback arms receive the same charged A result. They commit
five B actions before evaluation can access B.

The conditional mean adapter uses a tensor-product kernel over pre-treatment
basal state and full-dimensional drug representations, fitted only to
cross-fitted historical residuals. Ridge correction can be disabled. MAP,
molecule, Morgan and identity-permuted knowledge use identical grids. Feedback
uses coherent candidate-score updates, exact-dose/unit propagation eligibility
and training-selected reliability. Strong controls include no update, fixed
shrink, cross-validated shrink, equally gated empirical shrink and an empirical
update matched to the knowledge model's training-implied movement strength.

This does not introduce a new Gaussian conditioning formula. Its scientific
question is whether decision-focused tuning, condition support and retained
knowledge semantics improve previously frozen candidate comparisons. Gaussian
probability inflation and observation-dependent robust covariance are model
diagnostics, not independent risk certification. The registered gate requires
benefit against five controls, meaningful flipping coverage, low harmful flips
and a calibration diagnostic. All final comparisons average history seeds
within backgrounds first.

## Execute and verify

Use the `maestro` environment from the repository root. `prepare` persists all
training choices and pre-A plans; `commit` charges and releases one A observation
and freezes predictions; `evaluate` scores B only after commitments. Each phase
refuses to overwrite its artifacts.

```powershell
D:/anaconda/envs/maestro/python.exe -m research.decision_value.pairwise_20261009.run --phase prepare
D:/anaconda/envs/maestro/python.exe -m research.decision_value.pairwise_20261009.run --phase commit
D:/anaconda/envs/maestro/python.exe -m research.decision_value.pairwise_20261009.run --phase evaluate
D:/anaconda/envs/maestro/python.exe -m pytest research/decision_value/pairwise_20261009/test_pairwise.py
```

For a fresh numerical repeat, provide a new `--out` directory and use
`--phase all`. Do not replace the registered outputs. The separate independent
verifier reconstructs the original models and scores; its own freeze must
precede scored-output inspection.

## Asset and interpretation boundaries

`ASSET_STATUS.json` validates the historical hashes of available scalar inputs
and authentic feature caches. A compact portable archive will contain their
exact code/input closure for cached CPU replay in an isolated directory. This
does not restore absent upstream Tahoe/STATE files, the checkpoint or original
gene-coordinate assets. Raw pretrained-model reconstruction remains blocked.
Missing inputs must fail; no synthetic response substitutes for a real outcome.

The B endpoint is the packet's signed 39-gene RNA scalar. It is not functional
viability, apoptosis phenotype, target engagement or clinical benefit. A/B
partitions do not establish independent experimental cultures. The fixed
0.001 RNA ambiguity-band sensitivity is not a measured noise interval. Cost
is six simulated profiles with feedback versus five without; no currency or
certified net information value is inferred.

The evidence register owns conclusions, while `log/20261009` owns the canonical
execution receipt. Protocol and raw historical records remain intact. No
production promotion follows from software checks or this development gate.
Adaptive acquisition and new LLM calls are deferred until the one-A result
shows a reproducible benefit.
