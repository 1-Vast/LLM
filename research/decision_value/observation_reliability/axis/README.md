# Control-only source-axis authentication

The original coordinate asset was not recovered by bounded searches of the
workspaces, Git history or four local research archives. Archived compatibility
checks refer to a separate `hvg_identity.json` and report 1,972 named coordinates,
whereas the missing registered feature-name asset reports 1,969 named/31 null.
Those historical receipts do not recover either mapping or resolve the count
difference.

The alternative audit froze its producer, source censuses, original endpoint,
later-control plan and row selection **before expression reads**. It selects
448 full-QC DMSO cells from NCI-H661 and SW 1088 at source revision
`fdf87abece385feea6fa5e9944ab46e173b6af50`. Every selected cell is disjoint from
the 250 cells reserved for the later noise pilot. No treated expression or
STATE inference was requested.

The historical endpoint is the equal-positive-weight mean of 39 mapped RNA
coordinates (`1/39` each). Positive and negative expression changes are retained;
these weights are not a signed biological program and the endpoint is not
apoptosis, viability or protein activity.

Authentication compares each selected X_hvg coordinate against `log1p(X)`
for all 62,710 named source columns jointly across multiple cells. Source X
is stored normalized expression, not raw UMI. A coordinate passes only with
one numerical match, the exact expected gene symbol, a singleton symbol in
source metadata, at least two nonzero cells per file and maximum discrepancy
at most `1e-5`. All other coordinates remain unnamed. This certifies dataset
coordinate identity only, never STATE checkpoint output semantics.

The frozen audit completed without a software or network failure. It read
19,037,820 response-body bytes including 1,852,788 preparation metadata bytes,
within its 20 MB cap. Its 1,101 retained HTTP 206 spans preserve original bytes
and hashes. Raw-CSR index/value transfers target exact selected-control slices;
coalescing joins only touching selected slices. HDF5 indexing metadata and
row-offset pointers are distinct from expression values. Full filtered CSR
chunks and full HDF5 files were not downloaded.

The scientific certificate is **BLOCKED/AXIS_AUTHENTICATION**: NCI-H661 uniquely
authenticates 27/39 endpoint coordinates; SW 1088 authenticates 34/39. In the
latter, CD38, PLCB2, IFNB1, F2 and TNF are zero in every sampled control cell and
therefore indistinguishable from many other zero columns. More cells of the
same type cannot be assumed to fix this. The original 250-cell pilot remains
unopened. No endpoint variance result was produced.

`RESULTS.json` preserves every partial coordinate match and failure reason.
`MAPPING.json` deliberately remains all null when the required complete
certificate fails. Partial matches remain available in the per-file records;
they do not silently reduce or rename the endpoint. `VERIFY2.json` independently
reconstructs all matches from retained HTTP bytes without importing the producer
or making a network call. The earlier `VERIFY.json` is retained; the second
verifier adds source-address, row-selection, disjointness and derived-pass checks.

Next, inspect official metadata for an explicit ordered HVG reference. If none
exists, the concrete repair is recovery of the original hash-matching coordinate
asset or a separately frozen source-axis experiment with controls that express
the missing genes. An uninformative vehicle coordinate cannot be certified by
its proposed name or by assuming it means zero. The failed protocol, outputs
and receipts remain unchanged.
