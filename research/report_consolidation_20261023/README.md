# Research-record consolidation and publication

Maintenance code here inventories and archives records, separates data from reports, retires reviewed exploratory code and prepares compact GitHub reports. The [consolidation decision](../../log/20261023/report_consolidation/DECISION.md) and [publication record](../../log/20261023/main_publication/README.md) describe the performed operations and limits.

Reports, operation receipts and key results belong in `log/`; datasets and model artifacts belong in `data/`. Generated upload payloads are disposable local intermediates. Historical cleanup scripts describe already-completed operations and should not be rerun as a generic cleanup command. No runtime promotion or scientific validation follows from these maintenance scripts.
