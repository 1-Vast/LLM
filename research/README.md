# Research

Experimental fitting, selection policies and scientific evaluation belong here.
Only verified reusable contracts are maintained in `src` and `tools`; engineering
verification does not qualify a scientific method for default use.

## Read

- [REPORT.md](REPORT.md): the current scientific synthesis and next bounded work.
- [EVIDENCE.md](EVIDENCE.md): study-specific results, limitations, literature and reproduction.
- [Experiment records](../log/INDEX.md): dated executions and publication checks.
- [Operating contract](../task.md): permitted inputs, evidence and acceptance gates.

These are the authoritative narrative entry points. Duplicate reports and
superseded narrative indexes are removed. Historical manifests retain their
original identities; the release records authorized consolidation explicitly
rather than rewriting old hashes to claim unchanged bytes.

## Maintenance

| Area | Current ownership |
|---|---|
| `astra` | Bounded STATE/agent development, condition qualification and immutable scientific inputs/results |
| `certified_discovery`, `case_memory_integration`, `scientific_optimization` | Earlier qualified contracts and historical evaluation/model dependencies |
| Other scientific blocks | Historical studies, retained executable protocols and reproduction dependencies; no parallel default controller |
| `topics`, `analysis`, design-only blocks | Scientific context consolidated into the report/evidence register |
| `data`, `experiments` | Declared inputs and execution assets; large source data remains external where registered |

No new backend, agent population or complete recovery framework is being added.
The current task is to test whether correctly bound pretrained forecasts and
purchased feedback reduce the loss or information cost of a candidate comparison.

## Run scopes

```bash
python -m pytest
python -m tools.research_validation --help
```

Core contracts are asset-free. Registered regression packages require explicit
recovery; complete research requires its raw data, checkpoints and caches.
Missing assets are a blocker, not a passing scientific result. Use fresh output
paths and the retained frozen protocol/source identities for scientific replay.
The compact boundary packet replays without raw RNA, GPU inference or API calls;
its exact command and exposure limits are in the evidence register.
