# ASTRA research

ASTRA contains experimental STATE/agent decision studies and their executable
protocols, source receipts and numerical results. It is not a second supported
production controller.

Read the [consolidated report](../REPORT.md), [evidence register](../EVIDENCE.md)
and [dated experiment log](../../log/INDEX.md). The research root owns the single
maintenance index; study findings are no longer repeated in individual report
and README variants.

Retained research code owns fitting and experimental policies. Production
CaseStore owns plans, results and budget. `tools.datasets.condition_sources`
owns literal condition/source resolution; neither it nor a retrieved annotation
certifies present-cell mechanism or efficacy. Pretrained official STATE weights
remain the foundation, with exact condition and coordinate boundaries.

The latest boundary acquisition study tests consequential candidate comparisons
on previously exposed public RNA profiles. Canonical scalar data and run facts
remain available for reproduction; superseded construction paths are retired
only with explicit identity and replacement records.
