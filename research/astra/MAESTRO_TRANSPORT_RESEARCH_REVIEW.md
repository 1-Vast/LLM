MAESTRO / ASTRA：动作差值迁移、真实状态增益与下一轮实验研究报告

审查日期：2026-10-02。核对版本：GitHub main `ce9c8c7020c50dcf3a1082f4cd06de2c9ef9d73f`；原预测器来自 `15fec7c53c5334ceca96832e8342ae2ebc1fde75`。本报告延续已有研究，保留冻结历史，提出新的诊断和实验设计。

**研究判断**

应当调整推进顺序和验收条件，保留“停止当前播种密度扩展、保留背景模型作为比较对象”的决定。接下来的中心问题应是：在明确的实验环境和动作菜单中，能否可靠预测动作差值，并利用决策前可获取的信息提高独立实测策略价值。

本次复核支持三个更具体的判断。第一，背景模型有明显的平均动作差值偏移，同时仍可能保留部分区分不同样本响应差异的信息；“均值方向错误”不等于“所有排序信息都消失”。第二，原代码已经用动作差值误差选择模型，把当前多输出 Ridge 简单改成差值 Ridge 不构成实质修复。第三，背景策略胜过全部固定动作可以成为背景策略自身的确认标准，但不应成为收集、研究真实动态状态的必要前提。

下一轮应以完整三动作、随机孔位、独立启动的可行性 pilot 为载体，同时解决时程、QC、真实状态可读性和成本记录。pilot 的首要产出是可信测量、重复性与方差估计；它目前不是已经具备功效的确认实验。暂不增加 STATE 推理或智能体架构复杂度。

**2．最新结果意味着什么**

| 冻结两动作任务中的策略 | 加权 ATP 抑制效用 | 解释 |
|---|---:|---|
| 开发阶段固定 PD0325901 | 13.022% | 预先指定比较对象 |
| 冻结背景策略 C2 | 17.230% | 相对固定 PD 为 +4.207 点 |
| 固定 PLX-4720 | 18.191% | 打开结局后的完整固定动作诊断；C2 相对它为 −0.961 点 |

“模型胜过开发时选出的固定动作”仍是正确的描述性结果。但它不能单独建立目标环境中的个体化决策价值，因为开发时固定动作的总体优势发生了变化。固定 PLX 在这批记录中表现更强，也不能被倒写成预先选定、已经独立确认的新部署策略。

新的两动作问题不含可比 Afatinib，因此不能检验原三动作策略相对 Afatinib 的收益，也不能关闭原 PD 推荐分支对 Afatinib 的问题。CTRP 的近似剂量或另一个 MEK 抑制剂可以用于另行定义的探索任务，不能补写为原菜单的实际结局。

应明确三个不同目标：背景策略的价值、真实状态在背景之上的增量价值、补证调度策略的增量价值。每个目标需要自己的信息集合、比较对象、预算和终点。

**3．新增诊断：模型可能保留区分信息，但当前选择边界不可靠**

令观测动作差值为

\[
d_i^{\mathrm{obs}}=U_i(\mathrm{PD})-U_i(\mathrm{PLX}),
\qquad \hat d_i=\hat U_i(\mathrm{PD})-\hat U_i(\mathrm{PLX}).
\]

所有归一化权重沿用冻结结果：每个亲本/component 总权重相同，其内部多个 scan 平分该权重。按冻结策略自身的两类推荐分组，得到：

| 冻结推荐 | scan 数 | 总权重占比 | 平均预测 PD−PLX | 平均实测 PD−PLX |
|---|---:|---:|---:|---:|
| PLX | 71 | 34.694% | −2.660 点 | **−12.127 点** |
| PD | 129 | 65.306% | +7.374 点 | **−1.472 点** |

两个推荐组的实测平均值都偏向 PLX；但 PLX 推荐组的 PD 劣势明显更大。因此，当前证据更符合“存在平均偏移，可能仍有部分响应异质性信息”，不能简化成模型完全没有信息。这里是按既有推荐分组的观测关联，不能声称这些组在未来仍维持相同差异。

对应的策略价值分解为：

\[
V(C2)-V(\mathrm{PLX})
=\sum_i w_i\mathbf 1\{C2_i=\mathrm{PD}\}d_i^{\mathrm{obs}}
=-0.961\text{ 点},
\]

\[
V(C2)-V(\mathrm{PD})
=-\sum_i w_i\mathbf 1\{C2_i=\mathrm{PLX}\}d_i^{\mathrm{obs}}
=+4.207\text{ 点}.
\]

这说明模型相对固定 PD 的收益来自它切换到 PLX 的那部分样本，而在保留 PD 的样本上，它尚未建立平均优势。需要检验的是预测分数到实际差值的关系及其零点，不能只看全体平均误差。

加权预测差值与观测差值的相关系数为 **0.270**。按布局分别为 231：**0.006**，284：**0.297**。两个布局样本量分别只有 22 和 178，不能据此给出稳定性认证；合并相关也不能自动推广到任一新环境。相同背景输入只产生 47 个不同预测差值，与 47 种组织／生长方式／培养基组合相对应，未包含培养启动层面的实测动态状态。

用于描述平均偏移与剩余误差的恒等式是：

\[
\mathrm{MSE}_w(\hat d-d^{\mathrm{obs}})
=\overline{(\hat d-d^{\mathrm{obs}})}_w^2
+\mathrm{Var}_w(\hat d-d^{\mathrm{obs}}).
\]

平均误差为 +9.061 点，RMSE 为 26.975 点。去除这批数据自身的平均误差后，剩余均方根误差仍为 **25.408 点**；平均偏移的平方约占原 MSE 的 **11.28%**。

这个计算不是新校准策略的性能。它只说明整体平移不能消除大部分样本级误差；剩余部分可能包含可学习异质性、测量噪声和环境混杂，目前不能分开。同时，11.28% 也不表示校准没有决策价值：零点附近较小的修正可能改变重要选择，必须独立评价最终策略价值。

**4．模型应怎样修复：先排除无效改写，再做最小校准**

原 `gdsc_screen.py` 的 `fit_candidates` 已根据交叉验证 `cv_contrast_mse` 选模型，而不只是按绝对响应误差选模型。当前选择是共享输入变换、样本权重和 alpha 的多输出 Ridge。

对给定输入设计矩阵 Z、权重 W 和相同惩罚，Ridge 对结果 y 的拟合是线性映射 H，因此有：

\[
H y_{\mathrm{PD}}-H y_{\mathrm{PLX}}
=H(y_{\mathrm{PD}}-y_{\mathrm{PLX}}).
\]

截距以相同方式处理时这一结论仍成立。因此，用相同特征、样本、权重与惩罚把两输出改成一个差值输出，会得到相同的预测差值，数值求解误差除外。只有改变信息、估计目标、正则方式或校准资料，才可能产生实质改善。

下一轮建议冻结很少的候选方案：

| 方案 | 要回答的问题 | 所需新增信息 |
|---|---|---|
| 原 C，完整保留 | 原模型在新实验条件下能否迁移？ | 无目标拟合 |
| 动作间截距校准 | 是否主要是总体动作优势变化？ | 独立校准面板 |
| 截距＋一个共享收缩系数 | 原响应差值的尺度是否还能使用？ | 独立校准面板；另留评价样本 |
| 上述最简单可用模型＋一种实际状态 | 状态是否解释背景后的动作差异？ | 决策前可读、合法配对的 X |

两动作时可写成候选关系 `d_cal = alpha + beta * d_old`。本次复核没有把当前 200 个已打开结局拟合成新部署规则，也不建议直接将所有预测减去 9.061 点后宣布模型得到修复。需要独立的校准数据和后续评价数据。

三动作时可用共享尺度和每个动作的偏置：

\[
q_a^{\mathrm{cal}}(C)
=\beta\left(q_a^{\mathrm{old}}(C)-\frac{1}{3}\sum_bq_b^{\mathrm{old}}(C)\right)+b_a,
\quad \sum_a b_a=0.
\]

它只保留影响相对选择的分量，并保证三组两两差值彼此一致。不要分别随意拟合三条独立比较规则，造成 A 优于 B、B 优于 C、C 又优于 A 的循环选择。

判别逻辑是：若独立面板支持稳定的正向差值关联且偏移修正能提高后续策略价值，继续简单校准；若关联接近零或跨环境不稳定，先修订输入或任务条件。不能用一个总体偏置替代状态特异的反转。若简单校准已足够，无需升级预测器复杂度。

训练与评价应保留动作差值误差，但增加相对每个固定动作的策略价值。一般的 predict-then-optimize 研究指出，预测误差与下游决策误差并不等价 [3]；这支持改变验收目标，不构成当前任务需要复杂 SPO 算法的证据。

**5．迁移原因怎样区分**

已复核到布局 231 的两药孔位分别为 PLX 723、PD 1155；布局 284 分别为 PLX 627、PD 1108。每个布局内药物仍固定绑定位置，所以现有结果无法分离药物、位置及其交互。

| 可能解释 | 有判别力的设计或分析 | 仍需保留的边界 |
|---|---|---|
| 总体动作优势变化 | 在完整菜单中比较冻结分数的截距、分组差值与后续价值 | 平均修正有效不代表个体化价值成立 |
| 背景响应关系不迁移 | 在保持部分背景可比的独立启动中检查预测分数与差值关系 | 混合人群的相关不能替代环境内检验 |
| 孔位或药物×孔位效应 | 同一培养启动的动作在不同位置随机分配并有重复 | 单纯换一张固定布局仍不足 |
| 历史背景注释失真 | 决策前记录实际培养条件；预先区分历史注释版与实际背景版预测 | 两种输入合同是不同策略，不能事后挑优 |
| 时间、培养平台或批次变化 | 增加跨启动、跨日期的桥接对照；需要时让同一参考材料跨平台测量 | 所有因素同时改变的 pilot 不能唯一追责 |
| 终点读数的生长／代谢依赖 | 配对时间零和适当的正交表型、量化技术变异 | 更换终点须另行注册，不能追求哪个更显著 |

随机孔位 pilot 可以解除新实验中的药物与位置固定绑定，但若旧实验与新实验同时改变板型、培养条件和日期，新实验失败也不能单独证明旧结果源于孔位。对根因的强归属需要桥接或受控变化；验证一个实用策略是否可迁移，则不必一次解释全部根因。

**6．真实状态的价值应怎样定义和检验**

设 C 为背景，X 为加药前实际状态，E 为实验环境，mu_a(C,X,E) 为规定实验条件下动作 a 的预期效用。状态可提高决策的关键在于它能改变或更准确识别动作差值：

\[
\Delta_{ab}(C,X,E)=\mu_a(C,X,E)-\mu_b(C,X,E).
\]

如果 X 只同样提高全部动作的预期效用，绝对响应预测可能变好，但动作不会因此改变。例如 `mu_a = m(C,X,E) + g_a(C,E)` 中，公共项 m 在两药差值中抵消。应检验 X 对动作差值的增量信息，而不是仅检验 X 与 ATP、增殖或生存的相关。

不应设置“只有 C 先胜过所有固定动作，才能研究 X”的必要门槛。一个逻辑例子是：同一背景下两种等概率状态的 PD、PLX 效用分别为 `(0.6,0.4)` 和 `(0.4,0.6)`。背景无法区分状态，任何固定动作的期望效用都是 0.5；准确读出状态可达 0.6。该例子只是说明逻辑关系，不是本项目的实验数据。

建议在已经准备的完整动作 pilot 中同步取得一种便宜真实状态，避免未来再做一次完整面板。优先问题是决策前实际细胞量或经验证的图像读数，而非更多历史背景字段。贴壁与悬浮细胞必须分别验证读法；不能把汇合度算法直接套用到所有细胞。若加入第二次成像以估计短期生长，它是额外测量，也应记录时间与成本。

每种 X 必须有可执行的信息合同：测量什么、从哪一份样本取得、与干预样本是什么关系、测量与处理何时结束、何时能够进入决策、测量是否改变后续样本、失败如何处理。现有 destructive sister time-zero ATP 只有在结果实际可及时返回并且 sister 关系成立时，才可能成为决策输入；它不能因名为 time-zero 就自动获得可用性认证。

状态验证至少包含四步：

1. 检查同一细胞系不同培养启动中 X 的真实变异及测量重复性。
2. 检查这种变异是否对应动作差值的变异，区分稳定身份信息和当前培养状态。
3. 在独立启动或独立细胞系上，比较可用背景模型与加入 X 的模型；二者共享合法信息与资源规则。
4. 检查增量实测策略价值、相对全部固定动作的价值以及状态测量成本。

“已知细胞系的新启动”和“未见细胞系”是不同推广任务，分别报告。以细胞系内置乱 X 辅助诊断时，应维持日期与实验块等必要结构，先检查可交换性；当前每系只有两个启动，不足以把置乱变成高功效证据。不能用测试期未来数据构造部署时不可取得的个体均值或标准化参数。

ReSisTrace 提供了一个相关方法学先例：通过 sister-cell 关系连接处理前状态与后续命运，并专门使用无处理对照分析实验过程本身的选择效应 [4]。它支持认真验证配对与控制的必要性，并不证明本任务的廉价成像、现有 sister ATP 或 STATE 已经有效。

**7．现有 pilot 的具体修订项**

当前生成器是 12 个细胞系、各 2 次计划独立启动、4 个计划日、每天 6 个培养。每个培养有三药各三复孔、3 个 vehicle、2 个 blank，另有 2 个 sister baseline 技术复孔；共 336 个终点孔＋48 个 baseline 孔、8 张板。所有实际执行标记仍为 false。这些数量和其可行性定位应保留。

| 修订项 | 核对发现 | 建议 |
|---|---|---|
| 加药时程 | 生成器与协议写有 `four-day exposure` | 明确拆分播种到加药、加药到终点；不得把 DURATION=4 自动当作加药 96 小时 |
| 原 QC 的对照数 | 历史冻结 QC 要求至少 3 个有限且不同孔的 NC-1 和 B；pilot 每培养只有 2 个 blank | 若沿用原数量要求，改成 3 个 blank；否则明确冻结并验证新 QC，不能假称原规则直接适用 |
| 板型变化 | 生成器使用 96 孔；GDSC2 官方流程是 1536 孔 | 作为明确的新实验环境记录并校准，不能称为全部条件相同的复刻 |
| baseline 定义 | sister baseline 尚缺完成的 blank／校准配置 | 补齐其配对对照与量纲认证；不得直接把 ATP 当作 GR 所需细胞计数 |
| 状态假设 | `actual_state_test` 明确尚未注册 | 现在增加一个低成本、决策前可读的状态问题和时间合同 |
| 抽样目标 | 每类原推荐各取 4 系，属于富集抽样 | 用于覆盖分支和可行性；不把等权均值说成原目标总体收益 |
| 独立性 | 24 启动来自 12 系，跨 4 日 | 保留技术孔、培养启动、细胞系／亲本、日期的层级 |
| 失败与成本 | 当前账本未执行、未填数 | 从启动即登记；保留未执行、失败、重做与等待，未知数不得填零 |

关于时程，Sanger 官方说明是 GDSC2 播种 24 小时后加药，再过 72 小时测量，合计约四天 [1]。这与“加药暴露四天”不是同一个合同。当前数据门使用 `DURATION == 4` 并检查日期先后；它并不恢复逐孔加药时间。在协议中，尚无法从原记录证实的时点应标为未知，拟执行的时程应单独明确。

如果将终点 blank 从每培养 2 孔增加至 3 孔，终点孔总数变为 **360**，每天 90 孔；在现有四张 96 孔终点板上仍放得下，每日剩 6 个终点孔。加上原有 48 个 baseline 孔是 **408 个已分配孔**，尚未包括 baseline 侧新补的 blank／校准孔。板数可暂不增加，但新增耗材与操作不是零成本。是否采用这一版本取决于最终 QC 合同，旧分配记录应保留。

ATP 是存活细胞量的一种代理读数。要应用 GR，需要适当的初始量与终点量以及测量关系认证；增长率、培养条件和测量时程会影响常见药物敏感性读数 [2]。主分析可继续保留 ATP，另预注册一个明确的正交读数；不能在多个终点中挑最有利者作为新主结果。

**8．pilot 与确认实验的验收必须分开**

pilot 可以估计技术重复误差、同系跨启动差异、状态的可读性和变异、完整菜单的可执行率，以及真实成本。它不能仅凭“12×2×3 复孔”推导出充分功效，也不能把所有孔当独立生物学样本。

这里只有四个日期／终点板批次。常规按孔 bootstrap 或大样本聚类区间不能自动解决少簇问题；相关统计文献也明确指出少簇时的区间过窄与推断失真风险 [6]。应使用 pilot 的层级方差与保守范围模拟确认实验的功效，分别考虑细胞系、启动、日期和技术重复。模拟用于设计，不计为真实获益证据。

确认实验应预先确定目标总体、一个实际最小收益 delta、主要比较、失败处理及分析方法，并使用未参与修订的后续数据。若要声称策略优于所有固定动作，目标是：

\[
\Gamma(\pi)=V(\pi)-\max_{a\in\mathcal A}V(a)
=\min_{a\in\mathcal A}\{V(\pi)-V(a)\}.
\]

必须报告对每个固定动作的配对差值。可采用预先声明的同时区间来支持各项主张；若只进行一个“优于全部”的交并检验，也应事先明确其定义，不能见到赢家后才改变比较。强固定动作在同一评价集上的经验最大值具有选择性，不能把它当成无误差的总体最优固定效用。

状态增量另定义为 `V(pi_CX) - V(pi_C)`。若状态策略优于旧 C 但不优于任何可用强简单方案，应报告“模型增量”而非“部署价值已成立”。反过来，C 没有获益也不消灭 X 的潜在信息价值。

继续、修改与停止的规则建议如下：

| 观察 | 决策 |
|---|---|
| 测量不稳定或状态不能及时返回 | 先修测量／时程；不以此判定全部生物学状态无效 |
| 差值区分信息稳定，独立校准后有实际策略增益 | 继续最简单校准方案 |
| 背景策略无增益，但同背景下有可重复、可预测的动作差异 | 可以继续限定的状态研究 |
| 状态仅改善共同响应，未改善动作选择 | 停止当前状态读数的决策扩展，保留其他用途的可能性 |
| 当前方案增益的可信上界低于预设 delta | 停止该方案、该目标总体下的扩展 |
| 区间宽、缺失失败分母或状态变化不足 | 结论保持未知，按具体缺口决定是否补证 |

没有显著优势不等于证实不存在优势；“停止某方案”也不等于否定所有廉价状态或所有细胞模型。

**9．STATE 与智能体分别需要什么证据**

STATE 的认证不能从当前普通 Ridge 的 ATP 比较继承。若以后重新接入，至少需要以下链条：决策前可合法取得的输入 → 适用范围内的表达预测 → 独立验证的表达到目标效用关系 → 独立动作价值评价。训练暴露和评估样本关系应另行记录。

EGR1 ReLU 截断审计说明旧代理评分分辨率存在问题，但不授权把截断前负值改作评分。也不能用同一小面板同时开发表达评分、选择动作并报告独立成功。没有经验证的 RNA→ATP／目标表型关系时，STATE 的输出变化仍不能作为策略优势的实证依据。

智能体目前不应承担“让三个预测值的 argmax 更聪明”的任务。适合下一步检验的任务是：有限预算下，决定补做哪类信息，并在合法时间内决定干预或停止。例如，一类实验主要估计批次的总体动作偏移，另一类便宜测量主要估计当前培养状态，第三种操作是直接采用已冻结的简单策略。

需要先建立可检验的补证环境：每个候选测量有真实价格、延迟、失败率和隐藏实测结果；只有选择并支付资源后才揭示。对已公开数据可以开发回放接口，但正式评价必须隔离后续结局，且模型不能读取未揭示的相邻结果文件。

比较对象至少包括不补证的最强可用策略、固定补证顺序、简单一步信息价值选择器、同资源强单智能体。所有方案计算、等待、实验和失败重做成本要公平计入。静态 argmax 仍应保留为必要基线，多智能体只有在同等资源下提高最终实测效用或减少达到同一精度的成本，才有额外贡献证据。

特别需要处理时序：药物校准面板通常需要等待终点；不能在同一批细胞尚未加药前即时知道其若干天后的校准结果。若使用提前运行的参考培养，要记录真实等待、参考材料和目标材料的批次关系，以及结果跨时间迁移的不确定性。智能体不能通过离线数据访问便利绕过真实时间约束。

**10．成本与失败怎样闭合**

从每次计划启动开始记录全部尝试，并区分未开始、培养失败、状态测量失败、药物执行失败、终点测量失败和可分析结果。每次重做产生新的执行记录，不能覆盖首次失败。QC 后可分析分母与所有计划／已启动分母应同时报告。

记录状态测量、样本处理、培养等待、干预、终点、计算、重做及操作劳动。未知成本保持未知。先给出成本、耗时、失败率与 ATP 效用的并列表，若尚未约定 ATP 点数与资源的兑换权重，不强行计算一个净效用数字。

若拒答或等待是合法选择，要定义它最终触发的动作：固定动作、补测、终止还是其他操作，并计入结果和代价。拒答率下降、少犯一次排序错误或减少一次调用均不是自动的真实效用提升。

生物学知识可以帮助选择有判别力的输入和竞争机制，但不能恢复没有记录的执行、失败、时间或成本，也不能把 ATP 差异升级为机制因果证据。

**11．下一轮最小执行路线**

1. 保留当前 200 scan 结果作为已经打开的迁移诊断，保留原模型和全部冻结文件。将本次分组均值、误差分解及孔位核查标注为新的事后描述，不对这些数据宣布新的确认胜利。
2. 在 pilot 新版本中解决时程、blank 数、baseline 校准、板型与目标总体；增加一个真实状态输入合同和全尝试成本账本。原版本保留。
3. 实际执行可行性 pilot，首先产出方差、重复性、状态可读性与失败事实。对所有固定动作和原 C 做完整报告，不把富集样本当作总体确认。
4. 根据 pilot 判断是需要简单动作偏置校准、需要修订背景信息，还是值得加入一种真实状态。限制候选数量；在另外的开发资料上完成拟合并冻结。
5. 用独立的后续启动／细胞系及日期完成确认，比较全部固定动作、原 C、校准 C、校准 C＋X，报告正确层级的配对差值和成本。没有实测方差前不声称已经完成样本量设计。
6. 只有形成合法、可计价、可按时取得的不同补证选择后，才开展智能体调度比较。STATE 另按输入、终点桥接和训练暴露合同验收。

这一路线允许两个研究方向并行推进：修复背景模型的迁移校准，以及验证一种真实状态是否含有背景之外的动作差异信息。二者的证据应分别报告，最终都接受强固定动作、强简单策略和真实成本的检验。

**12．下一次研究汇报应回答的问题**

| 问题 | 必须拿出的证据 |
|---|---|
| 当前究竟优化哪个效用？ | 菜单、剂量、终点、播种／加药／测量时间、目标总体、delta |
| C 的问题主要是均值偏移还是区分信息不足？ | 独立校准与评价中的截距／分组差值、预测差值关系和策略价值 |
| 是否胜过全部固定动作？ | 同一完整面板中的各项配对差值与正确层级不确定性 |
| 真实状态 X 是什么，何时可用？ | 测量合同、原始记录、处理完成与决策时间、sister 配对与测量误差 |
| X 带来身份信息还是当前状态信息？ | 同系跨启动分析及相应的独立评价任务 |
| X 是否改变相对响应和选择？ | X 对动作差值及策略价值的增量，不能只给绝对响应相关 |
| pilot 中哪些变化被控制？ | 孔位随机分配、实际培养条件、板型、启动与日期记录 |
| 成功、失败和重做的完整分母是多少？ | 从计划启动开始的不可覆盖执行账本 |
| 增益是否值得测量与等待？ | 成本／延迟／失败与效用的联合报告 |
| STATE 或智能体究竟多贡献了什么？ | 独立终点桥接或同预算补证任务结果；没有则明确未验证 |

新增描述性复算的核心代码如下。输入是上面固定提交的 `policy_evaluation.csv`；它不训练模型、不调整推荐、不生成新策略结果。

```python
import numpy as np
import pandas as pd

d = pd.read_csv("policy_evaluation.csv")
w = (1 / d.groupby("unit").unit.transform("size")).to_numpy()
w = w / w.sum()
x = 100 * d.predicted_PD_minus_PLX.to_numpy()
y = 100 * d.observed_PD_minus_PLX.to_numpy()
e = x - y
bias = w @ e
rmse = np.sqrt(w @ (e * e))
centered_rms = np.sqrt(w @ ((e - bias) ** 2))
for action in (0, 1):  # 0=PLX; 1=PD
    keep = d.C2_action.to_numpy() == action
    print(action, keep.sum(), w[keep].sum(),
          np.average(x[keep], weights=w[keep]),
          np.average(y[keep], weights=w[keep]))
def weighted_corr(x, y, w):
    xc = x - np.average(x, weights=w)
    yc = y - np.average(y, weights=w)
    return np.sum(w * xc * yc) / np.sqrt(
        np.sum(w * xc * xc) * np.sum(w * yc * yc))
print(bias, rmse, centered_rms, bias**2 / rmse**2)
print(weighted_corr(x, y, w))
```
