# Scientific contract after the two reviews

## Three separate claims

1. **Prediction information:** lawful measured RNA reduces held-out outcome error relative
   to an identical world model with a context-matched, independent development reference.
2. **State/action interaction:** lawful state changes the expected utility difference between
   actual supported actions, reproducibly across independent samples.
3. **Decision value:** the resulting choices improve observed terminal utility relative to
   a context-only policy and fixed action, with state acquisition and waiting costs included.

STATE sensitivity and a different model's ReSisTrace accuracy cannot jointly prove any
STATE policy benefit. Technical execution, identity hashes and policy switches alone cannot
prove prediction accuracy. RNA is a measured component of state, not complete cell biology.

## Current registered diagnostic

The three historical NCI-H596 endpoint-control pools, seeds 17/42/103, three Trametinib doses
0.05/0.5/5 uM, 16 requests per action, checkpoint and 2000-coordinate representation are fixed.
The original utility is negative predicted EGR1 and the numerical tie tolerance is 1e-6.
The actual sampled baseline tensor and order are shared across actions, checked at model entry.
The official homogeneous per-action model loop and its separate control prediction are retained.
Outputs are predictions, never observed response samples. The control pools do not become
predecision aliquots and assay plates do not become independently cultured batches.

Report raw and action-centered contrasts, double-centered interaction, exact zeros, top ties,
concrete top-action changes, abstention changes and seed averages separately. A ranking change
between inferior actions has no demonstrated selection value. Numerical abstention is not a
validated safety policy. The returned nonnegative predictions do not identify preactivation
values; zero counts cannot distinguish biology from the model's output boundary by themselves.

This menu may favor the largest dose in every state under a monotone response and a one-sided
endpoint. Keep that negative result visible. Do not introduce arbitrary dose penalties to
force crossing. A different mechanism menu or efficacy/toxicity constraint requires authentic
observations, an independently justified utility and a new frozen protocol.

## Admission for the next biological experiment

Accept a matched sister-sample panel only after verifying parent culture, splitting/randomization,
multiple executed actions, matched controls, outcome validity and all attempted units. A
randomized policy comparison or randomized action log can also qualify through its own design
contract; the latter additionally needs trusted conditional assignment probabilities, support
and interference handling. A destructive RNA measurement is not a same-cell trajectory.

The input timeline must establish collection, processing completion/readability, decision,
allocation, action execution and endpoint, using authentic events or justified protocol bounds.
Neither a time-zero record nor `StateRef(role="predecision")` supplies those proofs. Record
missing or failed attempts, costs, source IDs, raw hashes and units without silent defaults.
If missing action observations cannot be identified, retain only predeclared credible bounds;
model predictions cannot fill missing observed outcomes or invent a failure denominator.

Keep independent parent cultures and physical batches within one split. Shared controls and
plate dependence must be explicit. Technical cell splits can diagnose measurement noise and
shared-control cancellation in action differences; they cannot generate physical replication
or physical confidence intervals. Pilot feasibility is not a confirmation power calculation.

## Development and confirmation

Use unopened independent development units to assess whether any authentic menu has repeatable
top-action headroom. The existing opened ReSisTrace outcomes are descriptive diagnostics.
For mean-plus-residual models report kappa and v; admit lambda=0 and select any shrinkage only
inside development folds. Freezing a transformation after inspecting old tests does not make
those tests a new confirmation set. Knowledge priors require trustworthy direction and potency;
adding graph coverage alone is not evidence of a useful state interaction.

Before opening confirmation outcomes freeze data version/split, model checkpoint, actual input
and axis, preprocess, blind reference, sampling/order, menu, utility, QC, cost, refusal and code.
Compare matched-context simple prediction, same world model visible/blind, the same selector
under both predictions, and fixed action on the same problems and resource rules. Check
state permutation, future-response replacement invariance and paired-input equivalence.

Report prediction error/calibration; top-choice, wrong/undetermined/refused counts; measurements,
waiting and compute time; complete physical costs; terminal utility and refusal contributions.
The information comparison can give both arms the same state collection and waiting; the
deployment comparison separately credits the blind arm's saved state costs. Unknown training
exposure, ambiguous RNA coordinates and the existing reconstruction precision failure remain
unknown or failed until independently resolved. No tolerance changes are justified by a desired
positive result. No current ASTRA result passes this biological admission gate.
