              <h1 class="human">Human MSigDB Collections
                
                <span style="float: right">
                  <img src="images/UCSDlogo.png" width="146" height="33" border="0" style="padding-left: 5px; padding-right: 5px;" />
                  <img src="images/BroadLogo.png" width="131" height="33" border="0" style="padding-left: 5px;" />
                </span>
                
              </h1>
            
          

<p>The 35361 gene sets in the Human Molecular Signatures Database (MSigDB) are 
  divided into 9 major collections, and several subcollections. 
  See the table below for a brief description of each, and the 
  <a href="msigdb/human/collection_details.jsp">Human MSigDB Collections: Details and Acknowledgments</a> page for more
  detailed descriptions. See also the <a href="https://docs.gsea-msigdb.org/#MSigDB/Release_Notes/MSigDB_Latest/">latest MSigDB Release Notes</a>.</p>

<p>Click on the "browse gene sets" links in the table below to view the gene sets in a collection. Or download
  the gene sets in a collection by clicking on the links below the "Download Files" headings.
  For a description of the 
  <a href="https://docs.gsea-msigdb.org/#GSEA/Data_Formats/#gmt-gene-matrix-transposed-file-format-gmt">GMT file 
  format</a> see the <a href="https://docs.gsea-msigdb.org/#GSEA/Data_Formats/">Data Formats</a> guide in the
  <a href="https://docs.gsea-msigdb.org/#">Documentation section</a>.
  The gene sets can be downloaded as NCBI (Entrez) Gene Identifiers or HUGO (HGNC) Gene Symbols.  There are also JSON bundles containing the 
  Human gene sets using HUGO (HGNC) Gene Symbols along with some useful metadata.
  <a href="#ALL">A SQLite database</a> containing all the Human MSigDB gene sets is available as well.
</p>
