# Exposed-data certification prototype

This is an unfinished developmental Gate 0/1 prototype. The [original protocol](../../log/20261023/certified_discovery_gates/PROTOCOL.md) and its October 23 amendment describe its scope. No prototype output is a mathematical certificate: nuisance fitting, pseudo-null construction, conditional validity and shared-plate dependence remain unresolved. Gate 1 labels are explicitly diagnostic and missing required pools cannot pass.

Key summaries and receipts live in `log/20261023/certified_discovery_gates/`; prepared arrays, fitted weights, traces and detailed replay tables live in `data/processed/certified_discovery_gates_20261023/`. The code defaults implement this separation. Synthetic temporary data stay in their explicitly supplied data directory.

The [current optimization record](../../log/20261023/evidence_portfolio_optimization/README.md) replaces a full model-based campaign with a smaller Jaaks repeatability diagnostic. Neither AZ reserve opening nor production promotion is authorized by this prototype's diagnostics alone.
