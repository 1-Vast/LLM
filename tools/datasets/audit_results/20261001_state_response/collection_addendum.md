# 最小采集补充：从本轮技术与回顾性结果闭合前瞻证据

本文件追加到[此前五张关系表和采集规范](../20261001_state_prospective/collection/README.md)，不覆盖模板或历史冻结。它是可执行采集要求，不是已经完成的物理实验。辅助 RidgeRNA、原 Tahoe STATE、替代 Replogle STATE 必须分别命名。

1. **在采样前冻结模型输入路线。** 原 Tahoe 仍须取得全部 2,000 坐标官方轴及原始 UMI→X_hvg 配方，不能用 31 个多解匹配代替。替代 Replogle 已有完整 6,546 轴，但目前仅认证指定存储基因全集的研究重建，配对输出容差失败且历史导出配方不全；不得把该模型的基因干预与 Trametinib 药物菜单混用。即使先收数据，也保留完整原始计数、Ensembl/参考 release、文库总量、重复 ID、QC 及处理软件/配置/哈希，避免只存丢失身份的 HVG。

2. **盲参考先于测试培养冻结。** 在匹配细胞背景、平台、处理流程的开发培养中建立 RNA 参考池，保存独立启动、传代、培养、物理批次和 QC 原始证据；整培养进入同一划分，共享亲本/对照连通组不跨划分。测试结束时的 vehicle 不能回填为当次决策的 basal。ReSisTrace rep1 的开发参考不能认证原 STATE 盲池。

3. **每个独立亲本至少有 baseline、等待漂移、A、B、vehicle 五种 aliquot 角色。** 随机将 sister aliquot 分给两个真实候选动作和匹配对照。先取 baseline，完成 RNA 处理并导出可读取 artifact，再允许决策；所有待处理 aliquot 保持同等待条件，动作执行时另取漂移测量。baseline 为破坏性 RNA，不写成同一细胞前后。至少三次独立启动培养只作为操作 pilot；不是功效充分的确认样本量。

4. **追加不可替代事件。** 每条事件保留事件 ID、亲本/aliquot/attempt ID、真实时间与时区/精度、时钟同步依据、原始文件 SHA/source row：采集、处理完成、发布可读取、模型读取、决策、随机分配、命令、执行确认、取消/失败、终点采集、终点 QC/发布。保留动作菜单、实际命令、执行证据和有效响应的差别。协议只有偏序时保存原文和可信时间界限，不生成精确时刻。

5. **完整分母先建账。** 所有 planned aliquot 和已入组 question 在动作前入账，保留未执行、超时、污染、建库/测序/仪器失败、QC 不通过及排除原因。响应缺失不能以预测、零表达或死亡补齐。单独报告“沉积 RNA 可评分覆盖率”和“全部入组完成率”；本轮 ReSisTrace 的 4.83%/11.28% 是前者，不是后者。

6. **成本与拒答。** 保存实际耗材、测序、人工/设备占用、计算、处理和等待时间、失败重试成本，币种及换算版本；未知不是零。冻结超时/拒答动作及后续终点处理规则。信息贡献在双方都采状态时只改可见性；部署价值另计盲策略节省的测量、等待、漂移及失败成本。没有成本不会阻止 RNA 预测，但不得输出净价值数字。

7. **先验收技术稳定性，再冻结确认研究。** 相同基线配对输出、查询占位/独立未来文件不变性、非法轴/动作/背景/基线拒绝、推理失败不计有效预测，全部保留原始输入和错误。替代路线当前输出容差失败不能改标通过；精度误差预算必须在新的确认数据前按测量和决策需求重新制定并独立验证，不能仅为了本例通过而放宽。

8. **pilot 的状态选择验收独立于预测精度。** 固定终点、菜单、种子数和选择器，比较同池种子波动、不同池变化、动作排序及拒答。当前 EGR1 三种子均值都选 5 µM，且拒答变化占多数；后续只在开发期根据方差估计确定更充分的抽样数量/池大小，冻结后不得按测试响应挑正结果或调阈值。若固定动作持续占优，如实记录没有可利用的选择空间。

五表最低主键保持：`questions.question_id`、`actions(question_id,action_id)`、`attempts.attempt_id`、`state_samples.state_sample_id`、`response_samples.response_sample_id`。每次真实 attempt 对应实际执行/取消证据；虚拟模型查询只能为 `prediction_request`，不能算 experiment、sample 或入组。现有 `state_panel_contract` 校验结构后，仍逐条人工/程序定位原始证据，不能靠填写 `true` 获得科学通过。

Pilot 验收：100% 入组可追溯到执行或明确失败/取消；100% 被称为前瞻的决策可证明读取在先；每批 A/B/control 覆盖与全部 QC 可追溯；基线/响应不串组，共享培养/对照不跨划分；合法模型输入和独立开发参考通过；真实成本与拒答规则完备。任何一项缺失时只在对应较低层级报告结果。

确认研究的最少功效参数：独立培养级成对误差或净效用差的均值/方差、组内相关、共享对照协方差、状态/结局测量可靠性、缺失选择机制、动作切换率、拒答/超时/失败率、状态等待漂移、成本分布、领域最小有价值差 δ、α、功效与多重比较方案。用这些参数模拟完整比较设计；不能把细胞数或技术重复数替代独立培养数，也不能用本轮三个技术池给出物理层级置信区间。
