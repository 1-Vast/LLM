# 可执行采集导出规范：单次决策、同亲本随机 sister aliquot

这是采集与验收规范，不是已经执行或冻结的效用实验。五个 CSV 是空模板。
现有研究代码能直接校验填好的表；没有任何虚拟查询被写成样本或尝试。

## 最少采集单元

使用一个平台、一种经鉴定的 NCI-H596 细胞背景、一类药物干预。
开发 pilot 从 **3 个分别启动的亲本培养**开始，仅用于检验操作和估计方差，
不宣称它足以做功效验证。培养来源、启动时间、传代、细胞批号、支原体/QC、
培养基和器材批号附在 `protocol_sha256` 对应的原始记录中。

每个亲本最少准备五个有明确亲本关联的 aliquot：

1. **基线 RNA aliquot**：先采样；保存全基因原始计数、测序及处理版本。
   RNA 是破坏性测量；后续处理的是 sister aliquot，不能标为同一细胞轨迹。
2. **等待漂移 aliquot**：与待处理 aliquot 同条件等待，在动作执行时取样。
   它检验采样到执行的状态漂移，属于诊断结局，不能回流到当次决策输入。
3. **动作 A aliquot**：Trametinib 0.05 µM。
4. **动作 B aliquot**：Trametinib 0.5 µM。
5. **匹配 vehicle aliquot**：统一最终溶剂浓度；原始实验记录必须认证对应
   `[('DMSO_TF', 0.0, 'uM')]` 的含义，不能把标签的 0.0 当成实际 DMSO 百分比。

两个药物标签已实查存在于登记 STATE 映射。登记资料记载的暴露时长为 24 小时；
具体复现实验的加药、溶剂、培养和终点 SOP 仍须实验负责人核对原协议后签署。
模型没有独立的时间输入。不得把新时长自动视为 checkpoint 支持的查询。
五个 aliquot 对应至少五次 RNA 测量：基线、执行时漂移、两个处理终点、vehicle 终点。
细胞数、测序 lane 或重复测量不增加独立培养数。

## 必须发生的时间顺序

记录原始时钟、时区、精度、软件/仪器时钟同步依据：

`基线采集 ≤ RNA处理完成 ≤ 可读取 < 决策 ≤ 动作随机分配 ≤ 命令 ≤ 经证据确认的执行 < 终点采集 ≤ 终点可读取`。

随机分配记录保存算法、种子或随机服务返回、分配单位和完整分配表；
若从菜单中随机抽取动作，另存给定历史的实际分配概率。完整 sister panel 可将
预先登记的 aliquot 随机映射到 A/B/vehicle；不要求同一个细胞同时观察两个潜在结局。
记录等待期间的培养条件、漂移测量和所有超时、取消、污染、加药失败及 assay QC。
仅发命令不等于已经执行，执行字段须关联独立的加药/仪器回执或操作记录。

历史协议只有偏序时，保留偏序原文及界限，使用独立科学审查；本采集验证器要求
实际带时区时间，不把计划时刻填成实际时刻。未知项留空并注明原因，不填默认零。

## 五张关系表的填写规则

| 表 | 主键与用途 |
| --- | --- |
| questions.csv | question_id；完整菜单、亲本、物理培养、状态 ID、决策及预算/QC/成本/终点/拒答版本 |
| actions.csv | question_id + action_id；精确药物/剂量/时长、设计菜单和对照动作 |
| attempts.csv | attempt_id；**全部登记尝试**，包括 planned/cancelled/failed/commanded/executed；所有成本和回执 |
| state_samples.csv | state_sample_id；基线 RNA、处理及可读取时刻、亲本、独立培养、sister 证据和等待成本 |
| response_samples.csv | response_sample_id；真实终点及 QC、关联 attempt、同亲本对照，禁止模型补值 |

`expected_attempt_ids` 为完整入组/随机化账本中的 JSON ID 列表；`ledger_evidence`
定位这份独立账本。不能从成功结局列表反向生成分母。
`source_record_id/source_row/source_file_sha256` 定位原始记录。
原始仪器/实验记录附带未执行原因、人员和仪器占用分钟、处理耗时、等待耗时、
耗材/测序/计算/失败成本。表中的 `cost_CNY` 是这些明细按冻结公式汇总后的实际值，
使用其他币种时须冻结汇率规则。漂移 aliquot 使用独立诊断记录，不能伪装成决策时基线。

共享亲本、培养、control group 的全部记录进入同一划分；不能跨 development/test。
严格结构校验命令（空模板会按预期返回非零）：

```powershell
& 'D:\anaconda\envs\maestro\python.exe' -m tools.datasets.state_panel_contract --input <填好的五表目录> --output <新的校验结果.json>
```

结构通过仍需逐证据审核可识别性。完整成本未取得、失败分母未知、动作不具支持时，
不得用任意效用范围替代证据。失败尝试保留在分母，未观测动作不以预测补齐。

## Pilot 验收条件与确认阶段冻结

- 每个亲本都有完整原始入组账本；100% 已登记 aliquot 能关联到状态、动作或取消原因。
- 100% 决策使用处理完成且可读取的状态；可读取时刻/执行回执不能由模型推断。
- 每批都有两个候选动作和 vehicle；任何失败仍完整保留。缺失结局的成本和处理规则
  已有实验依据，否则该批仅用于可行性，不宣称效用可比较。
- 无亲本/培养/共享对照跨划分。至少 3 个独立培养完成端到端导出，供开发估计；
  若不完整，记录失败并修复导出，不补造独立重复。
- 实验负责人在开发阶段设定 RNA library/QC/细胞数、允许等待漂移、预算和最大延迟
  数值；确认阶段开始前签署冻结。当前没有证据支持在这里随意给数值阈值。
- STATE 新 RNA 接口目前**不通过生物学准入**：须补齐 31 个未知坐标的官方有序身份、
  全部原始计数到 X_hvg 的变换契约、独立开发盲参考池和训练暴露记录。
  本轮技术前向成功不解除这些限制。原始全基因计数可先采集保存。
- 在开发 pilot 上查看状态是否能改变动作排名。若 A 总是占优，记录没有选择空间；
  不按测试结局挑选批次或重调阈值。
- 确认前冻结数据清单、整培养划分、checkpoint/辅助模型、知识库、预处理、盲参考、
  菜单、selector、QC、成本、预算、终点/效用、拒答、种子和分析代码。

四组 A/B/C/D 分别为盲参考/可见状态 × 无/有额外知识。当前辅助知识模型与 STATE
分别命名；同一次因子比较使用同一模型族、相同训练预算和同一选择器。
任何额外知识训练或检索都只在开发期完成；禁止测试样本自身结局进入知识库。

终点可在开发阶段选择 RNA surrogate（例如指定的 EGR1 坐标差值），但不能称为
存活或临床获益。需预先定义正确/错误/未定/拒答与失败终点；拒答也计实际成本。
信息贡献比较在两组都采集并支付状态/等待成本，只改变可见性；部署比较另计
盲策略不采状态可节省的费用、延迟和漂移。支持范围外的策略价值不估计。

## 确认实验功效所需参数

开发期估计每个**独立培养**的成对效用差均值/方差、动作改变率、状态与结局可靠性、
组内相关及共享对照协方差、失败/取消/拒答比例、各项成本和延迟分布、漂移与效用关系。
另需领域定义的最小有价值净效应 δ、α、目标功效及多重比较安排。
近似起点为 `n = (z_(1-α/2)+z_power)^2 * Var(培养级成对差) / δ^2`，
随后用 pilot 的缺失、拒答、成本及共享结构做预先定义的模拟校正。
本轮没有合格培养级差值，不能给出有依据的确认样本量或物理层级置信区间。
